# SoringP1 research recovery, 2026-11-25

Historical research archive, not a restart of the project. Original agent
claims, conjectures, counterexamples, negative results and attempts are
evidence, not certified theorems. Do not infer mathematical proof from an
agent's terminal state. The original Lean library and main branch are unchanged.

## Start here

- [Research synthesis](SYNTHESIS.md): principal results, barriers and open questions.
- [Thematic front index](THEMES.md): all 750 ledger questions, grouped heuristically.
- [Original ledger reports](fronts/README.md): 717 investigated, 33 blocked.
- [Board discussions](board/README.md): 3,725 messages from two closed issues.
- [Board findings and review index](BOARD-INDEX.md): navigate result and verdict markers.
- [Workspace archive](workspaces/README.md): 1,574 directories, 5,565 source
  entries, 1,906 unique content objects, 4,909 historical Git patches, with provenance.
- [Additional material](supplement/README.md): 1,827 source references to
  251 unique objects, including retired worktree archives and Viche records.
- [Assistant reports](assistant-reports/README.md): 1,646 sessions containing
  10,295 text parts, plus 35 additional retained agent text parts.
- [Local verification notes](state/): historical small-instance experiments.

## Caveats

The archived text is historical, and it has not all been independently checked
during recovery. This is an archive, not an integration of experimental Lean
files or an endorsement of every result. Historical patch records preserve
textual diffs, not every original commit object or binary. Identical baseline
files were not duplicated per workspace. Credential-like strings were
redacted; build outputs, caches, private reasoning and unrelated projects
were excluded. Eight permitted source entries were absent or symlinks in the
workspace scan; a broken Git worktree's source files were recovered separately.
The supplemental omission list records 570 cited scratch path strings that
did not exist at the exact paths at recovery time. Some may be examples or
placeholders. The archive cannot establish recovery of artifacts already
deleted before this effort. Original reports on the board and ledger may still
contain their substantive results. No agents were restarted.
