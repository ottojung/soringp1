LOWER BOUND PROOF [deduction]:
(1) Adversary answers YES to each of the first n-2 comparisons. A YES to (i,j), i<j, imposes the constraint x_i <= x_j. Since every relation goes from a smaller to a larger index, the accumulated constraints form a poset P that is a subposet of the natural order on [n]. YES is always a legal answer (consistent with the all-ones input). No leaf can be reached during these n-2 steps (see (3): the class count is >= 2 throughout).
(2) Lemma: if P is generated by k relations i<j, its number u(P) of up-sets (bit vectors satisfying all constraints) satisfies u(P) >= (k+2) * 2^(n-k-1). Proof: the undirected graph of the k relations is acyclic (edges strictly increase the index), hence a forest. For a tree component on s vertices the number of up-sets is >= s+1 (induction on s: delete a leaf v with neighbor w; every up-set of the remainder extends in >= 1 way, and an up-set distinguished by membership of w gives at least one more extension). With component sizes s_i = a_i + 1, sum a_i = k, u(P) >= product(s_i + 1) * 2^(n-k-m) = 2^(n-k) * product((a_i+2)/2), where m is the number of components. Splitting a into b+c >= 1 increases product((.+2)/2) because (b+2)(c+2)/4 > (b+c+2)/2 (difference bc/4 > 0), so the product is minimized by a single component a_1 = k, giving (k+2)/2. Equality is attained by a chain, so the bound is tight. Redundant YES answers only leave fewer generating relations, which makes u(P) larger.
(3) The number of order-classes consistent with P is c(P) = u(P) - s + 1 >= u(P) - n, where s <= n+1 is the number of suffix up-sets {a+1,...,n}, all of which give the identity output and collapse to one class. At k = n-2 this gives c(P) >= n * 2 - n = n.
(4) From that state the adversary answers to keep the larger class-branch: after j further comparisons c_j >= c / 2^j >= n / 2^j. A terminal leaf has c = 1, so j >= ceil(log2 n). Total height >= (n-2) + ceil(log2 n). QED.
