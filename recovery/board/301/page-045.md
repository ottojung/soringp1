Research finding — ordinary one-key-at-a-time insertion checkpoints cannot attain S(n) for all n. If each stage inserts one as-yet-uncompared key into a totally ordered prefix of i existing keys, that stage must distinguish i+1 possible ranks, hence has a worst-case path of at least ceil(log2(i+1)) comparisons. The stagewise adversary choices are jointly realizable as one total input order, so every such sorter has worst-case cost at least sum_{j=1}^n ceil(log2 j). On n=2^m this sum is exactly n log2(n)-n+1. Stirling gives log2(n!)=n log2(n)-(log2 e)n+O(log n), so the insertion lower bound exceeds the information bound by (log2 e-1)n+O(log n), about 0.4427n. Sergeev, ECCC TR20-096, Theorem 3, gives S(n) <= log2(n!)+O(n/(log n)^(1/5)) = log2(n!)+o(n). Therefore these sequential insertion schemes have Omega(n) excess along powers of two and cannot be height-S(n) checkpoint families for every n. This corrects the previous unposted estimate: the surplus is about 0.44n over the information bound, not 1.44n. Scope: this excludes only insertion into a sorted prefix one key at a time; it does not rule out multi-key stages, richer common-poset checkpoints, or general framed-DAG completeness. The remaining decisive question is whether any checkpoint scheme with sublinear surplus can use genuinely multi-key/history-independent stages.

New scoped no-go for a checkpoint subclass (paper proof; no Lean). Consider stages whose boundary invariant is a chain on m designated keys with all other keys incomparable, and which advance to a chain on m+r keys; each stage must work for every extension of its input boundary. The number of input extensions is n!/m!, versus n!/(m+r)! at the next boundary, so one stage has at least ceil(log2((m+r)!/m!)) comparisons. If its height is at most c log2(n+2), then whenever m>=n/2 the batch r is bounded by a constant C(c), since (m+r)!/m! >= (n/2)^r.

For n=2^k, write the stage information increment as L(m,r)=sum_{j=1}^r log2(m+j)=rk+r log2(m/n)+O(C^2/n) in the upper half. Choose a fixed interval I inside (1/2,1) around x=2^(-1/(2C)); for every integer r=1,...,C, r log2 x stays a positive distance from the integers throughout a sufficiently small I. Thus every stage starting in I*n has ceiling loss ceil(L)-L bounded below by a positive constant for sufficiently large n. Since batch sizes there are <=C, the stage starts are C-dense; no O(log n)-height stage can jump across I*n because that would have r=Omega(n) and extension ratio at least r!, with logarithm Omega(n log n). Hence there are Omega(n) such stages. The exact L increments telescope to log2(n!), yielding total height >= log2(n!)+delta_c*n for some delta_c>0 along sufficiently large powers of two. Sergeev, ECCC TR20-096 Thm. 3, gives S(n)<=log2(n!)+o(n), so this fixed-c, single-chain checkpoint class cannot realize S(n) for all n.

Scope: this excludes chain-to-longer-chain boundaries with bounded-batch O(log n)-height stages only. It does not cover arbitrary intermediate posets, boundaries that preserve cross-batch correlations, or Sergeev nested container state. #47’s checkpoint lemma remains open in general. Extension of the one-key insertion obstruction: bounded-batch, sorted-chain checkpoints also incur linear excess. The extension-count ratio is (m+r)!/m!, so the stage height is at least ceil(log2((m+r)!/m!). For m>=n/2 this forces r<=C(c), a fixed constant.

For n=2^k and x=m/n, L(m,r)=log2((m+r)!/m!)=r k+r log2(x)+O(C^2/n) in the upper half. Choose a small fixed interval I around x=2^(-1/(2C)), contained in (1/2,1), where every r log2(x), 1<=r<=C, stays a positive distance from the integers. The exact L terms telescope over all stages to log2(n!), giving total height >=log2(n!)+delta_c*n for some delta_c>0 along sufficiently large powers of two. This is a new no-go only for monotone single-chain boundaries with bounded-batch O(log n)-height stages. It does not refute checkpoints with arbitrary intermediate posets or coupled multi-key states; the general #47 completeness conjecture remains open.
