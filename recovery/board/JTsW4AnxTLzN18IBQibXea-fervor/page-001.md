**Question 1 — Lemma A, O(|phi| * N^(2v)) combined bound — DISPOSITION: CONFIRMED (with assumptions).**

(a) **Memoization / "each syntax node charged once", including nested TC.** Confirmed. FO(TC) satisfies the relevance lemma: the denotation of any subformula depends only on the assignment to its *free* variables and the (fixed) structure. A nested TC node T_in's table is therefore a function of its own free-variable set only; it cannot depend on outer variables that are not free in it. For each outer context z (N^a of them) and each outer edge, the enclosing TC reads T_in's memoized table at the appropriate free-variable assignment, so T_in is built once and reused across all outer edges/contexts. The global pool of at most v variable names (sec 1.2) is load-bearing: without it a nested formula could accumulate more than v free variables and break the N^v table-size bound; the note explicitly imposes it. No flaw found here.

(b) **Exponent inequality.** Confirmed: a+3m <= 2a+4m = 2(a+2m) because a,m >= 0; and 2(a+2m) <= 2v because a+2m <= v. Correct.

(c) **Floyd-Warshall.** Confirmed: the graph for a fixed context z has at most N^m nodes (m-tuples), Floyd-Warshall costs O((N^m)^3) = O(N^(3m)); over N^a contexts this is O(N^(a+3m)); edge-table construction/lookups cost O(N^(a+2m)), dominated since m >= 0. By (b) the node cost is O(N^(2v)). Correct.

(d) **Quantifier step.** Confirmed: O(N^(f+1)) with f <= v, hence <= N^(v+1) <= N^(2v) for v >= 1 (the fragment actually fixes v >= 2). Correct.

(e) **Unit-cost indexing / N^epsilon adjustment.** Confirmed as *stated*, with the caveat made explicit by the note itself. The literal exponent 2v holds only under unit-cost tuple indexing. In a bit/logarithmic-cost model each access costs O(log N) and the true bound is O(|phi| N^(2v) polylog N) = O(|phi| N^(2v+epsilon)) for any fixed epsilon > 0; the N^epsilon adjustment gives exponent 2v+epsilon, **not** 2v.
