# Recovered quarantined ABC completeness experiment

Original directory: /var/lib/lubko/wd/viche-state/quarantine/soring-scratch-1795496493/antichain-abc.

Research source, reports, logs and census outputs preserved; larger text files are losslessly gzip-compressed. The 2.06 GB p11.txt is a generated enumeration input, not a computed census result. Its SHA-256 is recorded; genp.py and genp_par.py preserve its generation procedure (using nauty 2.8.8 genposetg). Third-party nauty distribution, compiled binaries, caches, and redundant full board API response post_result.json are not duplicated here. The board text is separately archived in recovery/board.

Historical reports are not newly validated. In particular, see the corrected census runs alongside earlier outputs rather than treating every historical number as authoritative.
