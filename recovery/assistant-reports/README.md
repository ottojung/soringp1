# Recovered historical assistant reports

Assistant-visible text recovered from project-scoped OpenCode sessions and
retained Antonina agent outputs. No hidden reasoning, user prompts, raw tool
results, credentials, or unrelated project sessions were intentionally exported.
Some passages are intermediate reports rather than final mathematical results.
The session and agent indexes retain provenance. Identical extra agent output
already present in the session export is not duplicated. Non-JSON log lines
were skipped. See summary.json for counts.
