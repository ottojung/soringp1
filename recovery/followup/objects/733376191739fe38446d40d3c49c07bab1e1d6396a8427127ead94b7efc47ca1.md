# FO(TC) strategy programs for exact optimal sorting

## Model (strategy language)
A strategy program is a tuple (Q, q0, δ, out) where Q is a finite state set
(mutable knowledge), q0 initial, δ : Q × {<,>} → Q selects next comparison
pair (i,j) as function of state, and out : Q → permutation emits sorted order.
Cost = number of comparisons along worst-case path. Program size = |Q|+|δ|.

## Soundness/time bound
For fixed program text of size p(n), interpreter runs comparisons in
O(p(n)·n) time per input order; universal quantification over n! orders
gives Sigma_2^P membership for the subclass of representable strategies.

## All-n completeness statement
Conjecture: for every n there exists a strategy program of size poly(n)
with worst-case comparisons = S(n) and interpreter runtime poly(n).

## Findings (PROVED/CONDITIONAL/REFUTED)
- PROVED: split-schema fixed-m programs need >= S(m)+C(m,n) comparisons; penalty +1 at cells (3,6),(4,6),(4,7),(6,9).
- CONDITIONAL: no super-polynomial growth of C(m,n) observed through n<=9; fixed-m exactness fails for every fixed m at some n.
- REFUTED: a program that exhaustively searches for optimal tree does not satisfy runtime condition.
