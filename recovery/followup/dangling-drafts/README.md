# Abandoned staged research drafts

The second Git audit checked all 784 identified SoringP1 Git stores for
dangling blobs and trees, including abandoned staged changes. The audit
manifest records original Git object IDs and available original paths.
A blob with no path is preserved as text evidence, not as a file that
can be automatically restored to an exact historical location.

These are historical source/draft versions. No new theorem or code
integration is claimed. The maintained library remains unchanged.
