# Pull request #20: Show asymmetric posets retain quadratically many comparison-pair orbits

Upstream: https://github.com/ottojung/soringp1/pull/20

Phoebe-only signed commit f1bf25d, exploration-first mathematical negative result. Construct height-two staircase posets P_m on n=2m keys with B_i<T_j iff j<=i. Every key is fixed by all automorphisms (distinct in/out degrees), but exactly 3*binom(m,2)=Theta(n²) pairs are incomparable and hence singleton candidate-comparison orbits; extend to odd sizes by appending a global maximum. Therefore **automorphism-orbit reduction alone cannot guarantee subquadratic pair branching for all poset states**. IMPORTANT: this is NOT an Ω(n²) time lower bound for deciding sorting numbers and does not rule out other structural/pruning algorithms or prove a class separation. Self-contained code and 6 bounded tests pass (n<=8 brute-force automorphism verification). Independent mathematical review and green GitHub CI required before merge.
