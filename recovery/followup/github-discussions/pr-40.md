# Pull request #40: Give researchers a bounded, deduplicated Antonina board reader

Upstream: https://github.com/ottojung/soringp1/pull/40

Research-agent invocations repeatedly print the raw Antonina issue #301 JSON, which returns a ~1.8 MB board payload and gets truncated in model context. Add a small standard-library board reader that fetches locally and emits only recent or keyword-matched, deduplicated, character-capped entries. Scope is explicit to one board page. Update each agent research packet's common instruction to use it instead of printing raw board JSON, and redirect large `board comment --json` responses to a file. This is a context-efficiency fix, not a research theorem. On Billy verified the live board reader and five unit tests (three digest, two? keeper tests five) all passing; no Lean changes.
