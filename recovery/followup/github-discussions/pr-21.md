Signed Phoebe-only branch 8a0cca2, small n<=5 research prototype inspired by Stober–Weiß ALENEX2023 (arXiv:2206.05597). Enumerates *reachable* labelled poset states only (not arbitrary 2^(n!) permutation subsets), computes memoized exact F once to supply a partial confirmed-YES advice table, then measures un-memoized forward DFS with YES shortcut and crucial UNKNOWN != FALSE soundness. n5 partial budget B=5 yields 82,913 vs 107,659 forward nodes; B=6 yields 3 forward nodes but full precomputation is substantial and excludes construction cost from reported forward-node comparison. All five quick unit tests passed. **Epistemic warning:** This does NOT implement Stober–Weiß's actual predecessor-enumerating backward search, efficiency-threshold Lemma 4.2 completeness, or polynomial-space algorithm. It is a labelled precomputed-winner advice surrogate and a practical negative assessment, not a new speedup theorem or improved upper bound. Require independent math/code review and green CI before merge.
