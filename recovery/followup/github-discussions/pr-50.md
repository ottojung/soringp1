# Pull request #50: Add independent framed-DAG certificate checker (no Lean formalization)

Upstream: https://github.com/ottojung/soringp1/pull/50

## Purpose
Concrete polynomial-time verifier for the **forgetful, permutation-framed comparison strategy DAG** from issue #47. A rigorous witness format is a prerequisite to asking whether optimal antichain-root policies admit polynomial certificates; this PR does **not** claim NP membership or optimal-policy completeness.

## Contents
- `scripts/check_framed_strategy.py`: topologically ordered DAG with two comparison outcomes and explicit slot permutations on both edges. Propagates the *intersection* of guaranteed relations over all incoming histories, using transitive closure after queries. Checks terminal states are total and longest reachable path is within the comparison budget.
- `triangular_bubble_certificate(n)`: all-n polynomial-size example with `n(n-1)/2` compare-exchange nodes; both branches share the next node via optional slot swaps.
- `tests/test_framed_strategy.py`: cases `n=0..12`, plus negative tests for wrong permutation, missing comparison work, budget violation, cyclic edges and malformed frames.

## Validation and scope
An equivalent checker was executed locally: all tests passed and bubble example for n=16 accepted with 120 comparisons, 121 nodes. See all-n paper proof in issue #47. Python reference tests will run in CI; no Lean source changed. Checker time is polynomial in explicit DAG size and **n**, appropriate for the *unary* `SORT-BOUND-U` target. As in issue #47, the open research problem is polynomial-size **completeness at exactly S(n)**, not soundness or ordinary upper-bound compression.

Closes no research issue; related to #47.
