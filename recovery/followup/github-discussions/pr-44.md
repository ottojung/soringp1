# Pull request #44: Correct unary hardness error; AC⁰ circuits and sharp one-comparison no-go

Upstream: https://github.com/ottojung/soringp1/pull/44

**Research correctness correction (not a Lean milestone).** This PR updates only `docs/research-encoding-consequences.md`; no Lean source was added.

1. **Fix a false sparse NP-hardness example.** The old text treated φ↦1^{⟨φ⟩} as a polynomial-time many-one reduction from SAT. Under conventional binary Gödel coding its output is exponentially long. The unary-padded SAT example is actually in P by decoding an O(log N)-length formula and brute-forcing it in time polynomial in its unary input length N. Replaced with a concrete decidable tally language outside P, using polynomial-time-decodable repeated-machine diagonalization in (2^{O((log n)^2)}) time; it remains in P/1.

2. **Theorem 3.10: `SORT-BOUND-U∈nonuniform AC⁰`.** At any fixed length L, valid YES-instances `1^n#1^k` occupy an initial interval of delimiter positions because (n+S(n)) is strictly increasing. A depth-two DNF with O(L²) literals tests those positions. This does **not** give a uniform P or NP algorithm. As a restricted consequence, PARITY does not reduce to this unary threshold language by fixed-output-length nonuniform AC⁰ many-one reductions (Håstad's bound).

3. **Theorem 6.6: a tight *artificial* one-comparison-gap no-go function.** Let (I(n)=lceillog_2(n!)ceil). At the efficiently enumerable positions (t_m) where (I(n)-I(n-1)<lceillog_2 nceil), beyond index 8, encode the m-th bit of the tally diagonal H, setting (G(n)=I(n)+b_n) and (b_n=0) elsewhere. This (G) is computable, nondecreasing, obeys (I(n)le G(n)le I(n)+1), the insertion recurrence (G(n)le G(n-1)+lceillog_2 nceil), the standard merge recurrence (G(a+c)le G(a)+G(c)+(a+c-1)), and the same nonuniform depth-two AC⁰ property. Yet its **unary threshold is outside uniform P**: (1^{t_m}#1^{I(t_m)}) queries the m-th bit of H and has length polynomial in m. All-n proofs are included; the stronger merge-inequality constant is verified by Pascal's identity and the binomial row 9 bound.
