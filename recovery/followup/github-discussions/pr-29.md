**Uniform encoding-specific upper bound** for the *unary threshold decision* language. With `N=n+k+1` actual input symbols, read-only input and working bits, first accept when `k` exceeds a constructive sorting bound, else call budgeted transcript DFS at depth `d=k`. At most `n(n-1)` children per node, depth `k`, polynomial-cost node checks, and `(k+n)log(n+2)` working bits yield:

`SORT-BOUND-U ∈ DTIME(2^{O(N log N)}) ∩ DSPACE(O(N log N))`.

The existing bound for the **numeric unary function** `S_unary(1^n)` remains `2^{O(n log² n)}` time and `O(n log² n)` space because the algorithm invokes threshold tests at budgets `Θ(n log n)`. This is a derived sharpening of how to account for the threshold input length, not a new algorithm or a P/NP result.
