# Pull request #27: Reduce exact sorting-number evaluation to O(n log² n) work space

Upstream: https://github.com/ottojung/soringp1/pull/27

## Exceptional theoretical result about the special S(n)

The existing exact budgeted minimax DFS takes `2^{O(n log² n)}` time. Represent its state as a shared mutable comparison transcript and evaluate partial-order comparability by graph reachability on demand. A stack depth of `d ≤ O(n log n)` and O(log n) cursor/transcript data per level, plus one O(n log n) reachability workspace, give O((d+n)log(n+2)) bits per budgeted query and **O(n log²(n+2)) bits overall**. Previously the repository recorded `O(n³ log n)` from copying a full n×n relation per frame. This is a strictly improved uniform *space* bound, not an improvement in P/NP/PSPACE classifications or in the time exponent.

The same approach for an explicitly encoded, read-only **dense transitive-comparability matrix** of length N gives GEN-SORT in `DSPACE(O(√N log² N))` (encoding-sensitive, not a hardness statement).
