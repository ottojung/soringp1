"Independent all-n research for SoringP1 #301, strictly narrower than unrestricted sorting. Prior result #301 `sha256:7cd1kTboJdu24eGMk8kx98wnWfVSIMiTlih2e8F3MTg` proves every fixed binary merge tree using standard head-to-head linear merge has worst case at least n log2 n-n+1, hence linear surplus. Do NOT repeat that result. Investigate the next genuinely distinct question: let M(a,b) be the minimum worst-case number of adaptive pairwise comparisons to merge two already sorted runs of lengths a,b (arbitrary optimal merge decision tree; comparisons only between members of the two runs). For a fixed full binary tree T with singleton leaves, each internal node fully sorts both child runs before calling such a merge procedure. Establish carefully whether the optimal architecture cost is exactly A_T=sum_v M(a_v,b_v), with a single compatible global permutation simultaneously realizing all node worst cases; account for identity-dependent procedures and recursively chosen child orders. Then attack the sharp all-n dichotomy: does A(n)=min_T A_T satisfy A(n)-ceil(log2(n!))=Omega(n), or can you construct an explicit tree family and valid merge procedures with sublinear (ideally o(n)) surplus? Read and use primary sources, especially Hwang–Lin (1972), Stockmeyer–Yao (1980), Li–Sun–Zhang (2016), and the project’s exact M(a,b) discussion in docs/research-obstruction-next.md §3.3. Derive only bounds justified by sources/proof; M(a,b) is not generally a+b-1. Any computation is diagnostic, never the all-n proof. Report either a rigorous all-n bound/construction or the precise obstacle and a minimal meaningful correction. Explain consequence: an Omega(n) result rules out this broader fixed independent-completion/optimal-merge architecture for all sufficiently large n; an o(n) construction only meets Sergeev’s asymptotic ceiling and does NOT prove exact S(n). Scope excludes arbitrary algorithms that interleave comparisons across unfinished recursive subproblems. No Lean or code edits; no general sorting or complexity-class claim."
