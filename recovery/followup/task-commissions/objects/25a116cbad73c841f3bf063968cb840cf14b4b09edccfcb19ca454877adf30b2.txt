Reduction you should start from, which I have checked independently and which narrows the target a lot:

1. For any incomparable pair x,y, the linear extensions split exactly by the relative order of x and y, so e(P) = e(P+x<y) + e(P+y<x). Therefore for e(P) <= 12 a pair fails the balanced test only if one child has 8..12 extensions and the other has e(P)-8 at most. The only bad split shapes are (8,4), (8,3), (8,2), (8,1), (8,0), and the same with the heavy side on the other orientation, plus heavy 9..12 with light <=3 (only possible when e(P) >= 9).
2. Kahn-Saks already bounds the heavy child by floor(8e/11) <= 8 for e <= 12, so the heavy side is exactly 8 whenever e(P) <= 11 is bad, and 8..12 is possible only for e(P)=12.
3. Consequently the lemma is NOT about bounding a heavy child; it is about excluding the family of posets where every incomparable pair isolates at least 8 of the at most 12 extensions on one side.

Useful structural tools, in this order of preference: (a) e(A ord-sum B) = e(A)e(B) and e(A disjoint-union B) = e(A)e(B), so ordinal-sum and parallel decomposition reduce the problem to indecomposable factors; (b) the classification of posets with very few extensions (e <= 4, and the known small-e shapes), applied to the light child; (c) if a bad poset exists, its light child has at most 4 extensions, so the pair x,y is \"almost determined\" and you should be able to derive a contradiction from how the remaining elements sit relative to x and y.
