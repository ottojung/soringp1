# Historical research task commissions

These texts were inputs to Antonina-managed coding/research agents in
SoringP1-scoped OpenCode sessions. The task prompts contain mathematical
questions, candidate falsifiers, literature leads and instructions for
historical independent verification that sometimes were not repeated in
assistant reports. Identical texts are stored once; index.json retains the
session ID, message ID, sequence and workspace for each retained occurrence.

Only agent task inputs with identified project/math topics were included.
Generic continuation and operational messages, unrelated sessions, private
reasoning, raw tool outputs and credential-like strings were excluded.
These historical instructions are not live tasks and must not be executed.
