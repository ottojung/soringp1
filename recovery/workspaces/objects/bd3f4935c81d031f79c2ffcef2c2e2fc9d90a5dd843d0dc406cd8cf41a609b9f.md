open at the proof/formula level.

**Required single minimal failing lemma/formula/proof gap.**

> **[open:CKS-AV-MDALT-HALT.BACK_E_RANK] (consistent BackE retry-cycle
> rank).** Give an explicit, consistent well-founded rank on
> `I_{M_D}`-reachable encoded configurations such that every non-halting
> `D_*` step strictly decreases it, and in particular the BackE existential
> retry cycle is ranked consistently:
>
> 1. `D_sort_pick` (`M_Eval,CtrlSort`, cursor rank `r`) creates/preserves a
>    `M_BackE,RetNone` waiting frame with advanced cursor rank `r' < r`
>    (or otherwise decreases at the modified frame).
> 2. `D_eval_rej_ret` to `M_BackE` pops the E-child and changes the waiting
>    `M_BackE,RetNone` parent (same stored cursor rank `r'`) to
>    `M_BackE,RetRej,NextIncomp` (or `NoNextIncomp`/terminal path) with
>    strict decrease at that frame.
> 3. `D_backE_rej_next` from `M_BackE,RetRej,NextIncomp` (cursor rank
>    `r'`) selects `NextIncomp_c`/advances by `SuccLex2`, pushes an E-child,
>    and sets the same BackE parent to `M_BackE,RetNone` with cursor rank
>    `r'' < r'`, with strict decrease at that frame.

> `pi(BackE,RetNone)=4`, `pi(BackE,RetRej,NextIncomp)=3`, `ex=rlex`, so (2)

> post-state phase of `BackE,RetNone` ambiguous. A consistent repair is
> routine (e.g. compare `rlex/ex` before the cycling BackE phase for these
> states, or use an explicit `(rlex, BackE-subphase)` order that gives
> `RetNone(r)->RetRej(r)->RetNone(r'')` as
> `(r,wait)>(r,rej-next)>(r'',wait)` with `r''<r`), but it must be stated as
> one explicit global measure/table and checked case-by-case for every
> non-halting `D_*`.

## Conclusion

The halt-fix makes meaningful progress: it replaces the MDALT realization
audit’s informal `(Brem,Sphase,Cphase)` sketch with a whole-configuration
per-frame rank attempt, explicit `SuccLex2`/`rlex` cursor component, and a
full `D_*` case table. However, **[CKS-AV-MDALT-HALT] is not discharged**
because the BackE existential retry cycle is not given a consistent explicit
well-founded rank. The single minimal failing gap is
**[CKS-AV-MDALT-HALT.BACK_E_RANK]**: supply one global, internally
consistent measure (final table + tuple order) that makes
`CtrlSort --D_sort_pick--> BackE,RetNone --child RetRej--> BackE,RetRej,next
--D_backE_rej_next--> BackE,RetNone` strictly decreasing by advancing `rlex`
while also preserving decreases for the adjacent return/pop cases. After
that formula/measure repair, the rest of the case analysis should be
rechecked against the same final `V` definition; no other new contradictory
transition was identified in this audit.
