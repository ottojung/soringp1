# Framed-certificate bounded-class completeness on small n (exec report)

**Front:** `framed-certificate-bounded-completeness-smalln`  
**Status:** research report (definitions, small-`n` experiments, deductions). Not Lean-checked. No claim of NP membership, hardness, or an all-`n` completeness theorem.

## Question and consequence

Define precise, checkable bounded classes of framed/permutation-DAG sorting certificates and test whether any bounded class is complete for **optimal** height `S(n)` on known exact values `n <= 12` (or as far as feasible), measuring class/distinct-state growth.

A fixed-parameter or polynomially-bounded class complete at height `S(n)` for all `n` would be evidence toward a succinct strategy witness for `SORT-BOUND-U`; a concrete incompleteness witness or forced superpolynomial growth inside a natural class would be a barrier for that certificate route. (It would not by itself settle NP membership; see `docs/research-framed-certificate-frontier.md`, `docs/research-strategy-certificates.md`.)

**Feasibility:** experiments below cover `n <= 6` by exhaustive optimal-minimax enumeration over reachable labelled posets (`S(1..6)=0,1,3,5,7,10`, literature/checked baseline). `n=7` has `A001035(7)=6,129,859` labelled posets and was not attempted in this run.

## Model (fixed)

- Deterministic adaptive comparison sorting of `n` distinct labelled keys; `S(n)` is optimal worst-case comparison height (`docs/problem.md`).
- A **framed/permutation-DAG certificate** is as in `scripts/check_framed_strategy.py` / `docs/research-framed-certificate-frontier.md`: acyclic comparison DAG, slot permutations on arcs, guaranteed strict partial order `R_v` propagated by transitive closure + relabelling, and **intersection** of feasible incoming guarantees at joins; every reachable leaf must guarantee a total order; depth `<= k`. The checker validates explicit certificates in time polynomial in explicit graph size and `n` (**[literature/tooling]**).
- **Semantic state** of a certificate node: its guaranteed strict partial order `R_v` on current slots (up to the certificate's frame). The classes below are defined on `R_v` / certificate structure and are checkable from an explicit certificate (or, for the semantic optimal-policy tests, from enumerated optimal poset states).

## Bounded classes (definitions)

### C1. State-width-bounded certificates `W(w)`  (**definition, checkable**)

Parameter `w ∈ ℕ, w >= 1`.

A framed certificate `C` is in `W(w)` if for every node `v`, `width(R_v) <= w`, where `width(R_v)` is the size of a maximum antichain (Dilworth width) of the guaranteed strict partial order.

- **Check:** compute width of each `R_v` (for `n<=` small, exact by antichain enumeration; in general by comparability/chain-cover algorithms). Polynomial in explicit certificate size for fixed/small `n` contexts.
- **Completeness question (optimal):** for given `n`, is there any correct framed certificate of height `S(n)` in `W(w)`? Equivalently for semantic optimal strategies: can one choose optimal comparisons so every reached guarantee has width `<= w`?

### C2. State-identity join DAGs `I^{=}` with parameters `(D, Δ)`  (**definition, checkable**)

A framed/permutation-DAG certificate is in `I^{=}` if every join is **state-identical**: whenever multiple feasible incoming arcs reach the same node, they deliver the same guaranteed relation on that node's slots (intersection is identity). This is the framed realization of hash-consed/state-DAG sharing (no weakening by intersection beyond equality).

Parameters measured:
- `D(n)` = number of distinct reachable certificate states (nodes) under optimal play,
- `Δ(n)` = maximum indegree counted as number of distinct parent states feeding a node (state-sharing fan-in).

- **Check:** from explicit certificate, compare incoming propagated relations at each multi-parent node; count distinct nodes/indegrees. The existing semantic object is the all-optimal state DAG on labelled posets.
- **Bounded subclasses:** `I^{=}_{D<=p(n), Δ<=q(n)}` for bounds `p,q`. Completeness at fixed polynomial bounds is the substantive question.

### C3. Rank-envelope / pending-window class `R(p,r)`  (**definition, not fully tested**)

Inspired by `docs/research-framed-certificate-frontier.md` §3. Parameterize a guarantee `R_v` as: a certified increasing chain structure plus at most `p` pending elements, each constrained to an interval/rank window of width/description bounded by `r` relative to the chain (and stable under the allowed relaxations/joins of the grammar).

- **Check (intended):** membership decidable from a structured annotation or by recognizing the envelope form of `R_v`.
- **Status here:** precise grammar instantiation and a small-`n` optimal-completeness test were **not** completed in this run; included as a required candidate class to define, with no experimental completeness claim.

## Methods (experiments)

**[experiment]** For `n=1..6`:
1. Compute minimax values `F(P)` for all reachable labelled poset states from the empty antichain using the standard recurrence `F(total)=0`, else `1+min_{(i,j) incomparable} max(F(P+i<j),F(P+j<i))` (same model as `scripts/strategy_dag_probe.py` / `scripts/state_compression.py`).
2. Enumerate **all optimal-reachable states**: states reachable from root by any comparison that attains `F(P)`.
3. For each such state compute `width(R)` and incomparability count.
4. **C1 realizability:** decide whether some optimal policy (choice of one optimal move per reached state) keeps all reached states in `W(w)` (memoized DFS over optimal choices).
5. **C2 measurements:** on the all-optimal state graph, count distinct states, internal states, nodes with `>1` distinct parent state (state-identity sharing), max parent-state indegree, min/max/avg optimal move choices, and total optimal outcome-edges.

This is an exhaustive semantic test on abstract poset guarantees for `n<=6`; it does not enumerate explicit slot-permutation framed DAG files except conceptually.

## Findings and claim types

1. **[deduction] Concrete incompleteness witnesses for fixed-width `W(w)`.** The root guarantee is the empty strict order (antichain) on `n` slots, so `width(R_root)=n` in every correct certificate for `n` elements. Therefore, for any fixed `w`, class `W(w)` contains **no** correct certificate (optimal or not) for any `n >= w+1`. Witness: `(n,w)=(w+1,w)`, node = root. Consequently `W(w)` is not complete for optimal `S(n)` beyond `n=w`.

2. **[experiment]+[deduction] Minimal optimal state-width equals `n` for `n<=6`.** For each `n<=6`, every optimal-reachable state set includes width `n` only at the root count 1 but the root is unavoidable; the realizability search found `w_policy(n)=n` and no optimal policy can stay within `W(n-1)` (root already violates). This is an **incompleteness-at-`n-1`** witness for the bounded subclass `W(n-1)` at instance `n`, for `n<=6`.

3. **[experiment] No sublinear state-width compression along optimal strategies for `n<=6`.** All-optimal reachable guarantees attain every width `1..n`; optimal play cannot be confined to a uniformly width-bounded (in `n`) subclass. This rules out `W(c)` fixed-`c` completeness for all `n` (already by root) and shows no evidence of bounded-width optimal realizability as a function smaller than `n` on these cases.

4. **[experiment] `I^{=}` (state-identity joins) is semantically realizable at optimal height but exhibits rapid parameter growth.** State-identical sharing is abundant (e.g. `n=6`: 59040/65551 states have >1 parent-state, `Δ=23`) yet distinct optimal states grow to `D(6)=65551` with 392310 optimal outcome-edges. This is **consistent with** superpolynomial/exponential growth in the natural size parameters (cf. winning-frontier/state-count barriers in repo docs) but `n<=6` does **not** distinguish asymptotic rates; **no** polynomial bound for `I^{=}` parameters is established or refuted here.

5. **[definition/open] `R(p,r)` rank-envelope class.** A precise, checkable envelope grammar remains the relevant structured candidate (frontier doc §3, §5), but optimal-completeness on `n<=6` was not mechanically tested in this run; no claim made.

## Relation to falsifier

- **Concrete incompleteness witness produced:** for `W(w)`, any `n>=w+1` (e.g. `n=w+1`) requires root width `n>w`, so not realizable in `W(w)`. For each tested `n<=6`, `W(n-1)` is not realizable by any optimal-height strategy/certificate. (**deduction/experiment**)
- **Superpolynomial/exponential growth forced?** Not proved. `D(n), Δ(n)` for `I^{=}` grow quickly on `n<=6` (consistent with barrier-scale growth) but the range is too small for an asymptotic conclusion; this does not by itself falsify polynomial-bounded completeness of some other framed class.

## Obstacles

- **Root antichain dominates width-based bounds:** any class bounding guarantee-width below `n` is trivially incomplete; informative width bounds must be non-uniform in `n` or apply after/with a different representation.
- **Search/scale:** explicit optimal framed DAG synthesis with nontrivial joins (weakening intersections, not just state identity) is harder than semantic poset enumeration; `n>=7` optimal-state enumeration is substantially larger.
- **Expressivity vs size:** joins can compress representation only when guarantees can be safely weakened/intersected; soundness constraints (frontier doc §1, §4) limit admissible forgetting.
- **Rank-envelope formalization gap:** turning §3 constructions into a complete, checkable `R(p,r)` membership test for arbitrary optimal certificates requires a fixed grammar and audit.

## Next decisive question

Can one define a **nontrivial** checkable framed class `C(n)` (e.g. a rank-envelope grammar with parameter `r(n)`, or a join class allowing controlled forgetting/intersection loss) that (a) excludes the trivial root-width obstruction by construction and (b) admits an optimal-height certificate for all `n<=7` with measured parameters, yet for which either a first incompleteness witness appears at some small `n` or a rigorous lower bound forces superpolynomial parameter growth? Concretely: implement a verifier-recognizable rank-envelope annotation for merged/pending states and test realizability against optimal strategies for `n<=6` (and `n=7` if feasible) to discriminate "structured compression plausible" from "small-`n` obstruction".
