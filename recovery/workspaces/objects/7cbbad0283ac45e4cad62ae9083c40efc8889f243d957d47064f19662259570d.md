## 1. Question

Can `SORT-BOUND-U = {1^n # 1^k : S(n) <= k}` be shown to be in `NP` by exhibiting, for every `n,k` with `S(n) <= k`, a polynomial-size (in `N = n+k+1`) **framed permutation certificate**: an acyclic comparison DAG whose nodes are labelled by permutations/partial orders, edges are comparisons with explicit frame permutations, joins intersect guaranteed relations, and whose soundness and height `<= k` are checkable in polynomial time? Equivalently, does every height-`S(n)` sorting strategy have a polynomial-size framed DAG representation, or is there a family requiring super-polynomial framed DAGs?

Consequence if yes: `SORT-BOUND-U ∈ NP` (a genuine membership upper bound, not hardness). If no for a family: a barrier against succinct certificates for this proof system.

## 3. Findings

### 3.1 What is proved

- **[deduction] Verifier.** The framed-DAG grammar is sound and checkable in time polynomial in the explicit graph size and `n`: transitive-closure/poset validity, edge validity, join intersection, terminal totality, and height DP (`research-strategy-certificates.md` Theorem 1.1; `scripts/check_framed_strategy.py`). This is a certificate *checker*, not an existence proof.
- **[deduction] Explicit tree witness is exponential.** Every correct reduced comparison tree has exactly `n!` leaves and `2n!−1` nodes, so the naive tree certificate is `2^{Θ(N)}` in unary and doubly exponential in binary (`research-certificates-barriers.md` Claim C; `research-strategy-certificates.md` Theorem 2.1).
- **[deduction] Single-policy DAG = tree.** Hash-consing saves nothing in one optimal policy: distinct nodes have distinct labelled posets, so `DAG(1) = 2n!−1` (`n ≤ 6` verified; theorem for all `n`).
- **[literature] Sparsity barrier.** `SORT-BOUND-U` is sparse; many-one NP-hardness would imply `P = NP` (Mahaney). This blocks hardness routes but does not imply membership.
- **[literature+deduction] Upper bound.** `SORT-BOUND-U ∈ PSPACE` via the alternating game `G(n,k)` (`research-certificates-barriers.md` Claim A). No `NP`/`coNP` membership is known.

### 3.2 Polynomial framed constructions, and why they do not certify `S(n)`

| Construction | Size | Height | Status for exact `S(n)` |
|---|---:|---:|---|
| Bubble sort triangular DAG | `Θ(n²)` nodes | `n(n−1)/2` | Not `S(n)` except tiny `n`; height far above optimum. |
| Merge sort framed DAG | `O(n²)` nodes (balanced: `O(n log n)` path length) | `n log₂ n − n + O(log n)` | Exceeds `S(n)` by `Θ(n)` for large `n`: Sergeev gives `S(n)−log₂ n! = O(n/(log n)^{1/5}) = o(n)`, while merge sort exceeds the information bound by `(log₂ e −1)n + O(log n) ≈ 0.4427n`. |
| Ford–Johnson / rank-envelope DAG | `O(n²)` query nodes (plausible) | `F_FJ(n) = ∑_{j=1}^n ⌈log₂(3j/4)⌉` | Matches known `S(n)` for `n ≤ 22` (checked `n=10..22`: `F_FJ = 22,26,30,34,38,42,46,50,54,58,62,66,71`), but `F_FJ` is an upper bound, not proved equal to `S(n)` for all `n`; Sergeev's asymptotically sharper bound excludes any fixed `Θ(n)` excess for large `n`. The complete recursive frame construction and odd case are not independently audited. |

Thus the strongest known polynomial framed constructions certify either a trivially loose bound or an upper bound (`F_FJ`) that is not established to equal `S(n)`. None gives an all-`n` certificate at height exactly `S(n)`.

### 3.3 Small-n evidence (all-optimal poset DAG)

From `scripts/strategy_dag_probe.py` (verified by `tests/test_strategy_dag.py`):

```
 n   S(n)   DAG(all)   log2(DAG(all))/n   quotient(all)
 1     0          1               0.00              1
 2     1          3               0.50              2
 3     3         19               1.00              5
 4     5        181               1.25             12
 5     7       1551               1.40             19
 6    10      65551               2.67            134
```

- `DAG(all)` is the hash-consed union of all optimal strategies (poset-state nodes). It is much smaller than the unshared all-optimal tree (`26541` at `n=5`) but still grows rapidly.
- The quotient by `S_n` relabelling reduces the count by ~489× at `n=6` (`134` vs `65551`), but the quotient itself jumps `19 → 134` from `n=5` to `n=6`.
- The normalized log `log2(DAG(all))/n` is increasing over `n=3..6`. This is **consistent with** super-polynomial growth, but `n ≤ 6` cannot distinguish polynomial, `n^{Θ(log n)}`, `2^{Θ(n log n)}`, or `2^{Θ(n²)}` growth.

Quotient-certificate edge-relabel overhead (from `research-strategy-certificates.md` Table 3): `4` bits at `n=2` to `9960` bits at `n=6`, for input length `N = 17` at `n=6`. This is in the range between `N³` and `N⁴` but again only a finite data point.

### 3.4 Why this does not settle the question

- The all-optimal **poset** DAG is only an upper bound on the size of a framed DAG, not a lower bound. A framed DAG may coarsen annotations (as merge sort does with queue lengths) and use forgetful joins, provided the coarsened poset still has minimax value `≤` the remaining budget. For branches with slack, coarsening may be allowed.
- Conversely, on worst-case tight paths the remaining budget equals the exact minimax value of the current poset, so arbitrary coarsening can invalidate the certificate. Whether a polynomial-size framed DAG can navigate this trade-off for all `n` is exactly the open completeness question.
- No proof is known that every polynomial-size framed DAG has height `> S(n)` for infinitely many `n`. Such a result would be a proof-system lower bound, and none is available in the cited literature or in this repository.
- The FO(TC) policy route is also blocked as a generic certificate: worst-case depth checking for FO(TC)-expressible policies is coNP-complete (`research` front `fo-tc-policy-interpreter`), so an NP certificate must use a normal form with locally checkable bounds (such as framed DAGs).

## 5. Stop condition

Condition (b): no all-`n` construction and no barrier were proved in this pass. The question is an open membership/completeness question for a specific proof system, not a known separation. Further progress would require either:

1. An independently audited all-`n` framed DAG construction at height exactly `S(n)` (which would put `SORT-BOUND-U` in `NP`), or
2. A proof that every polynomial-size framed DAG has height `> S(n)` for infinitely many `n` (a barrier), or
3. A new compact canonical object for optimal play that is checkable in polynomial time.

None of (1)–(3) is available from the cited notes, literature, or small-n data. The small-n evidence (`n ≤ 6`) is consistent with super-polynomial growth but does not decide it. No further progress is possible this pass without new mathematics.
