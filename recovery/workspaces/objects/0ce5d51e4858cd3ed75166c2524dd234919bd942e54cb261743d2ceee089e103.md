## Detailed mathematical analysis

**Model:** Let the input be split into two parts at the # delimiter: party A (Alice) receives the prefix encoding of n as $1^n$, party B (Bob) receives the suffix encoding $1^k$ preceded by # (or equivalently just $k$ in unary). This is the natural two-party partition of the pair $(n,k)$.

**Function:** $f(n,k) = 1$ iff $S(n) \le k$ where $S(n)$ is the minimum worst-case number of pairwise comparisons to sort $n$ distinct elements.

**Rectangle:** A combinatorial rectangle $R = X \times Y$ where $X$ is a set of possible $n$ values, $Y$ a set of possible $k$ values, such that for all $(n,k) \in R$, $f(n,k)$ is constant (monochromatic). For an exact rectangle cover of the 1-set, every $(n,k)$ with $f(n,k)=1$ is in some monochromatic 1-rectangle.

**Construction:** For each fixed $n \ge 0$, define
$$
R_n = \{n\} \times \{k \in \mathbb{N} \mid k \ge S(n)\}.
$$
Each $R_n$ is a rectangle. For every $(n,k) \in R_n$, we have $k \ge S(n)$ so $f(n,k)=1$; hence each is monochromatic-1. For any $(n,k)$ with $f(n,k)=1$, we have $k \ge S(n)$ so $(n,k) \in R_n$. Thus $\{R_n\}_{n\ge 0}$ is an exact cover of all 1-inputs.

**Size:** The number of rectangles is equal to the number of $n$ values for which there exists some $k$ with $(n,k)$ in our domain. For inputs of total length $N = n + k + 1 \le M$, $n \le M-1$, so at most $M$ rectangles are needed to cover all 1-inputs of length $\le M$. This is polynomial (linear) in $N$.

**Comparison/partial-order constraints:** Each rectangle $R_n$ is anchored to a fixed $n$ (fixed number of elements in the sorting instance). The condition $k \ge S(n)$ means the budget is sufficient for the comparison complexity of that fixed $n$. This respects the comparison model because $S(n)$ is defined via pairwise comparisons on $n$ elements, and the rectangle doesn't mix different comparison problems in an inconsistent way - it covers the threshold for each problem size separately. All rectangles are "comparison-feasible".

**Disproof of the front:** This construction shows that a polynomial-size rectangle cover exists using only comparison-feasible rectangles. Therefore, the claim that "every exact rectangle cover of SORT-BOUND-U contain some rectangle that is 'comparison-infeasible' in a way forcing super-polynomial cover size" is false for this natural partition model. The falsifier is satisfied.

**Note on other partitions:** While other cuts of the input string might induce more complicated partitions in fixed-position models, the standard combinatorial partition of the function $f(n,k)$ is the product partition, and even under other partitions the threshold structure of this monotone function typically admits polynomial covers. The key point is that the comparison-infeasibility obstruction is not necessary.
