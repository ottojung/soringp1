## Disjoint-union defect `F(A ⊔ B) - F(A) - F(B)` (exact exhaustive, small `n`)

**Question (tested).** For nonempty finite posets `A,B` on disjoint ground sets with `|A|+|B|>=3`, is
`F(A ⊔ B) >= F(A) + F(B) + min(|A|,|B|) + 1` (strengthening a two-comparison defect bound)?

**Outcome (this computation).** **No violation found** in the exhaustive class enumerated below; boundary evidence only (no all-`n` proof claimed). The inequality holds for every checked unlabelled pair with `3 <= |A|+|B| <= 8`, and is tight in several splits (margin 0).

### Definitions / model
- A state is a (transitively closed) strict partial order `P` on labelled keys `[n] = {0,…,n-1}`, encoded as successor bitmasks: `succ[i]` has bit `j` set iff `i < j` in `P`.
- Minimax remaining comparison cost (worst-case adaptive comparisons to identify the unknown linear extension / complete the order), as in `docs/problem.md` / `SoringP1/Model.lean` (`S(n)=F(∅_n)`):
  - `F(P)=0` if `P` is a total order (no incomparable pair).
  - `F(P)=1 + min_{(i,j) incomparable} max(F(P ∪ {i<j})^*, F(P ∪ {j<i})^*)` otherwise, where `^*` is transitive closure.
- Disjoint union `A ⊔ B`: on ground set `[|A|+|B|]`, keep all relations of `A` on its block and all relations of `B` shifted by `|A|` onto the second block; **no cross relations**. Encoding: `succ_{A⊔B} = list(A) ++ [m << |A| for m in B]` (shift is required so B-relations stay internal).
- Defect `δ(A,B)=F(A ⊔ B)-F(A)-F(B)`, tested bound `b(A,B)=min(|A|,|B|)+1`, margin `m=δ-b`.

### Enumeration scope
- Unlabelled posets enumerated as isomorphism classes for each size `n=0..8` via canonical representatives: all states reachable in the exact minimax DP from the antichain of `n`, canonicalized by refined colour refinement + lexicographically least encoding over colour-preserving relabellings (`quotient_classes`). Class counts matched OEIS A000112: n=0..8 -> 1,1,2,5,16,63,318,2045,16999.
- Checked all **unordered-by-component-size** pairs of unlabelled posets `(A,B)` with `1 <= |A| <= |B|` and `|A|+|B| <= 8` (disjoint union commutative up to isomorphism, so `(A,B)` and `(B,A)` give the same `F`/defect form). Total pairs: **3933**.
- Per-split pair counts `( |A|,|B| ): pairs` = (1,2):2, (1,3):5, (1,4):16, (1,5):63, (1,6):318, (1,7):2045, (2,2):4, (2,3):10, (2,4):32, (2,5):126, (2,6):636, (3,3):25, (3,4):80, (3,5):315, (4,4):256.

### Exact results
- **Minimum defect over all checked pairs:** `min δ = 2`.
- **Violations of `δ >= min(|A|,|B|)+1`:** **0** (out of 3933).
- **Tight pairs (`margin == 0`, i.e. `δ == min(|A|,|B|)+1`):** 38.
- **Margin distribution** (`m = δ - (min(|A|,|B|)+1)`): `m=0: 38, m=1: 2690, m=2: 1097, m=3: 108`.
- **Min defect by total size** `|A|+|B|=s`: s=3:2, s=4:2, s=5:2, s=6:2, s=7:2, s=8:3 (max observed δ grows to 7 at s=8).
- **Min margin/defect by split `(a,b)= (|A|,|B|)`**: (1,2): min δ=2,m=0; (1,3):2,0; (1,4):2,0; (1,5):2,0; (1,6):2,0; (1,7):3,1; (2,2):3,0; (2,3):3,0; (2,4):4,1; (2,5):4,1; (2,6):4,1; (3,3):4,0; (3,4):5,1; (3,5):5,1; (4,4):6,1.
- Interpretation: the strengthened bound is **not** uniformly stronger in effect than `+2` except through `min(|A|,|B|)`; when `min=1` the bound is `+2` and is tight for many B (overall min δ=2). For `min>=2`, the bound `min(|A|,|B|)+1 >= 3` is also met in all checked cases and is tight at least at (2,2),(2,3),(3,3).

### Solvers and cross-check agreement
Two exact minimax implementations (same recurrence, different state handling), cross-checked:
- **S1 (labelled-state memo):** recursive minimax `F(P)=0` if total else `1+min_{i<j incomp} max(F(extend(P,i,j)), F(extend(P,j,i)))` with memoization keyed by the full successor-bitmask tuple of the reachable state (from a given `P`).
- **S2 (iso-canonical quotient DP / class table):** `quotient_classes(n)` computes `F` for every isomorphism class of size `n` by the same recurrence but canonicalizes every reached state to a refined-colour lex-min representative (`make_refined_canon`), yielding a table `class_rep -> F`. `F(P)` obtained as `table[canon(P)]`. Also used for enumeration (A000112 counts reproduced for n<=8).

**Agreement:**
- Spot cross-check S1 vs S2 on 168 class representatives across n<=7 (all reps for n<=5, random 40 each for n=6,7): **0 mismatches**.
- Per-pair S1 spot cross-checks on resulting unions: 4 sampled pairs during the `|A|+|B|<=8` run: **0 mismatches**. (For the complete `|A|+|B|<=7` fast run, 1 sampled pair checked: 0 mismatches; class counts A000112 matched exactly throughout, a strong consistency condition on S2/canon/transitive closure.)
- Transitive-closure extension `extend` and disjoint-union encoding follow the standard successor-bitmask closure used in `scripts/benchmark_symmetry_quotients.py` / `scripts/parallel_module_probe.py`.
