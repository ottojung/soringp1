## 1. Falsifiable question (all `n`)

> Can any **sound exact** state/move quotient for `F(P)` / `S(n)` beyond relabelling, order duality, and `Aut(P)` move orbits (e.g. modules, decomposition, canonical forms) be proved to reduce the asymptotic state count or time exponent for exact evaluation of `S(n)` / `SORT-BOUND-U`, or is there a barrier showing such quotients cannot shrink the exponent (in light of winning-frontier/reachable-state counts)?

**Consequence if positive:** a proved sound quotient with asymptotically fewer states/transitions would yield a strictly smaller exponent in `n` for an exact evaluator of `S_unary` / `SORT-BOUND-U` than the best quotient-DP baseline, a direct upper-bound advance on the active frontier (`docs/problem.md`, `docs/research-plan.md`).

**Consequence if negative (barrier):** whole families of exact quotient/compression methods are ruled out for exponent reduction; progress on the exponent must come from non-enumerative/selective/symbolic evaluation rather than finer exact equivalence on the reachable/winning state space.

## 2. Definitions and fixed model

- **Model (definition).** `S(n)` is the minimum worst-case number of adaptive pairwise comparisons to sort `n` distinct labelled keys; height/worst-case path length (`docs/problem.md`). `S_unary(1^n)` returns the binary representation of `S(n)`; `SORT-BOUND-U = {1^n # 1^k : S(n) <= k}` with unary input length `N = n + k + 1`.
- **State/minimax (definition/literature-in-repo).** A state is a strict partial order `P` on `[n]` (transitive closure of outcomes). `Ext(P)` are its linear extensions. 
  - `F(P)=0` if `P` total; else `F(P)=1 + min_{x‖y} max(F(P+x<y), F(P+y<x))`.
  - `S(n)=F(∅)`; this equals the partial-order minimax/`adv univ` value (A24 correspondence, kernel results). Reachable states are exactly labelled posets (OEIS A001035), nonisomorphic classes A000112 (`docs/research-state-compression.md`, `docs/research-compression-next.md`).
- **Sound exact state quotient (definition).** An equivalence `~` on states such that (i) `F` is constant on classes and (ii) the transition is well-defined on classes in the minimax sense: for `P~Q`, the multiset of unordered successor-class pairs `{{[P+x<y],[P+y<x]} : x‖y in P}` equals that for `Q` (pairing preserved; flattening is insufficient). Value-invariance alone is not a usable DP state (`docs/research-compression-next.md` §4, §6c).
- **Sound move quotient (definition/deduction).** A reduction of the `min` range per fixed state that preserves `F(P)` (e.g. one representative per orbit with equal `T({x,y})=max(F(P+x<y),F(P+y<x))`). State and move quotients are independent axes (`docs/research-compression-next.md`).
- **Exponent language (definition).** All counts/times below are in numeric `n` unless stated; unary input is `N=Θ(n log n)` for the function regime of interest, so `2^{poly(n)}` is exponential in `N` but statements here are compared by exponents in `n` (`n^2` vs `n log n` vs `n log^2 n`).

## 4. Candidate quotients/decompositions beyond baseline (analysis)

### 4.1 Comparability-graph / linear-extension coarsenings (canonical-form candidates)
- **Candidate:** identify states by comparability graph `G(P)` or by extension count `e(P)=|Ext(P)|`.
- **Analysis:** `e(P)` is a comparability invariant (**literature**, Stanley / cited via McDiarmid–Penman–Iliopoulos), tempting for compression.
- **Falsification (experiment, cited):** `e(P)`/`L(P)` does not determine `F` (`n=5`, two posets with `L=8`, `F=3` vs `4`, `research-state-compression.md`). Comparability graph does not determine `F` (`n=7`, isomorphic graphs but `F(A)=6`, `F(B)=7`) and its transition is ill-defined (`n=5`) so it fails both value and transition requirements of a sound state quotient (`research-compression-next.md` §6c). Balanced-greedy (move/strategy restriction by extension balance) fails optimality at `n=9` (`20 > S(9)=19`, `research-state-compression.md`).
- **Verdict:** **unsound** as exact state/strategy quotient; cannot be used for exact `S(n)` evaluation.

### 4.2 Gallai/autonomous modules and modular decomposition (MDT)
- **Candidate:** quotient by reversing Gallai modules / canonicalize by modular decomposition tree (up to reversal), exploiting prime-quotient orientation structure (**literature:** Gallai 1967; Golumbic; McConnell–Spinrad).
- **Structural facts (deduction, cited):** module reversal `σ_S(P)` preserves poset structure, comparability graph, and `e(P)` (`research-orientation-modules.md` Lemma 1, Thm 2). Reversal of an **interval module** (every outside element comparable to the module) preserves `F`: `P = P|_A ⊕ P|_S ⊕ P|_B` and `F` is additive over ordinal sums and invariant under duality of a summand, so `F(σ_S(P))=F(P)` (Thm 3, Cor. 4, using `research-series-decomposition.md` and duality).
- **Falsification (experiment, cited):** exhaustive module reversals are `F`-preserving for `n<=6` (3308 reversals) but fail at `n=7`: 8 of 22494 reversals change `F`, forming two mixed classes of size 4; all violating modules are strong modules of size 4 with **prime quotient** (series 0/933, parallel 0/675, prime 8/20886). The same `n=7` pair defeating comparability graph is connected by module reversals and shares the same reversal-canonical MDT, so **MDT up to reversal does not determine `F`**. Quotient sizes at `n=7`: iso 2045, iso+dual 1082 (exact), MDT-up-to-reversal 931 (**not sound**), iso×module-reversal 824 (**not sound**). Parallel-quotient reversal empirically preserved `F` for `n<=7` but is unproven (`research-orientation-modules.md`).
- **Verdict:** arbitrary module/MDT reversal **unsound** for exact evaluation. Interval-module reversal is **sound but only a restricted, local symmetry** subsumed by ordinal-sum/duality structure; no asymptotic state-count theorem is known, and available evidence shows it does not bypass the global `2^{Θ(n^2)}`/winning-frontier regimes.

### 4.3 Series/ordinal-sum and parallel decomposition
- **Candidate:** decompose `P` into series/parallel components and recurse/combine.
- **Analysis (deduction/experiment, cited):** ordinal sum is exact for `F` (`F(P⊕Q)=F(P)+F(Q)` in the cited decomposition note) but reachable states from the antichain root are rarely nontrivial ordinal sums in a way that collapses the search; it "does not shrink the state space" for exact evaluation of `S(n)` (`research-series-decomposition.md`, summarized in `research-plan.md`). For disjoint/parallel unions, `F` is **not** additive because comparisons may interleave components across the boundary; no sound merge recurrence for the minimax value is known (`research-compression-next.md` §7, `research-state-compression.md`).
- **Verdict:** series exact but non-shrinking in exponent; parallel **no known sound exact recurrence**.

### 4.4 Cheap/heuristic canonical forms and move surrogates
- **Degree-based move identification:** unsound (`n=6` witness, equal `(in,out)` degree signatures but move values 4 vs 5, `research-compression-next.md`).
- **2D colour-refinement pair signature as orbit surrogate:** no counterexample for `n<=6` but **unproven**; a coarsening, not a proved reduction (`research-compression-next.md`).
- **Verdict:** not proved sound; cannot support an "all `n`" exact exponent reduction claim.

## 5. Quantitative bound / obstruction (all `n`, asymptotic)

### 5.1 Total exact state space remains `2^{Θ(n^2)}`
Relabelling+duality identify only symmetry-equivalent states and leave the class of nonisomorphic posets of size `A000112(n)` up to constant factors (**literature/deduction**): `log2 A000112(n) = Θ(n^2)`. Therefore no quotient that is a refinement/coarsening solely within these exact symmetries, nor any sound canonical form that must still distinguish non-equivalent nonisomorphic states, can reduce the **state-count exponent** below `Θ(n^2)` unless it merges asymptotically almost all nonisomorphic states while preserving the minimax transition — a property contradicted for all broad structural candidates tested above and incompatible with the distinct winning-frontier witnesses below unless a very special equivalence is exhibited (none known).

### 5.2 Winning-frontier barrier (paper-level theorem, cited)
`docs/research-winning-frontier-barrier.md` proves (**paper proof, independently auditable, not Lean-checked**): for infinitely many `n=2^(2r)`, at a common depth `t <= k` (with `k=ceil(log2(n!))`, and extendable to `k=S(n)` via Sergeev's `S(n)-C(n)=o(n)`, asymptotic only) there are at least
`2^((1/4 - o(1)) n (log2 n)^2)`
**pairwise nonisomorphic** partial orders `P` that are (1) reachable from the antichain by `t` legal outcomes and (2) winning with `F(P) <= k-t`. Finite witnesses: `n=224, >2^39` nonisomorphic winning states; `n=256, >2^148` (exact integer inequalities, test-cited in-repo).

**Implications (deduction):**
- These states are already quotiented by relabelling (nonisomorphic) and are not artifacts of the information cutoff alone (winning; also at exact optimum asymptotically). Duality/constant factors cannot remove the `2^{Θ(n log^2 n)}` exponent in their count.
- **Excluded:** any uniform `2^{O(n log n)}` algorithm whose method necessarily outputs/enumerates all reachable winning partial orders (or otherwise materializes one record per such nonisomorphic frontier state) at the relevant budget — the frontier is `2^{Ω(n log^2 n)}`.
- **Not excluded (important):** selective minimax search, proof-number search, stronger compression, symbolic/parametric/DAG evaluation, or any method computing/evaluating `S(n)` without listing the full frontier; not a time/space lower bound for arbitrary solvers, and no NP/PSPACE hardness claim.

**Relation to the quotient question:** a sound exact *DP state quotient* that is useful to a frontier-enumerating/DP-table method must assign canonical identities and support transitions; it can reduce exponent for such a method only by identifying a superpolynomial fraction of these nonisomorphic winning states under a transition-compatible equivalence. No candidate beyond relabelling/duality is proved sound with such collapse; the broad tested structural invariants (comparability graph, `e(P)`, module/MDT reversal) fail soundness before or at `n=7`. Conversely, the barrier alone does **not** prove that *no conceivable* sound quotient exists (one would need to show every sound equivalence keeps `2^{Ω(n log^2 n)}` representatives, which is stronger and unproved here).

### 5.3 Time-exponent considerations
- A state-count reduction below `2^{Θ(n^2)}` would help memoized/quotient DP whose time scales with represented states×transitions, but the best known exact time exponent for the decision/function task already follows a different route (budgeted transcript DFS, `2^{O(n log^2 n)}` time, `2^{Θ(n^2)}` not enumerated). Thus: (a) the winning-frontier barrier blocks `2^{O(n log n)}` via **frontier enumeration** specifically; (b) it does not by itself force time `2^{Ω(n log^2 n)}` for all algorithms; (c) no proved sound quotient beyond the baseline is known to shrink either the DP state exponent or to improve the DFS time exponent.

## 6. Falsification record (relevant)

- `e(P)` / comparability graph as state: **falsified** (value/transition). 
- Balanced-greedy optimality: **falsified** at `n=9`.
- Module reversal / MDT-up-to-reversal as exact quotient: **falsified** at `n=7` (prime quotients); interval-module reversal **proved sound** but narrow.
- Degree-based move merge: **falsified**; dual-branch dropping: **falsified**.
- Colour-signature move reduction: **not falsified at `n<=6`, not proved**.

## 7. Conclusion and consequence

- **Definitions:** sound state quotient requires value + equivariant paired-transition correctness; move quotients reduce per-state branching (`Aut(P)` orbits). Baseline exact quotients are relabelling, order duality, and `Aut(P)` move orbits.
- **Candidate analysis:** examined module/decomposition/canonical-form candidates (comparability graph, `e(P)`, Gallai/MDT reversal, interval/series/parallel, heuristic signatures). Beyond interval-module/ordinal-sum structure already aligned with known symmetries, candidates are either **unsound** (falsified), **unproven**, or **sound but without demonstrated asymptotic exponent reduction**.
- **Quantitative obstruction:** the reachable nonisomorphic state universe is `2^{Θ(n^2)}`; independently, a `2^{((1/4-o(1)) n log^2 n)}` family of pairwise nonisomorphic, reachable, winning states exists (infinitely many `n`, extendable to budget `S(n)` asymptotically). This **bars any `2^{O(n log n)}` method that must enumerate/materialize the full winning frontier**, and it sharply limits the room for exponent shrinkage by any quotient that would have to keep these states distinct under frontier-based evaluation.
- **Direct answer to the falsifiable question:** 
  - **No sound exact state/move quotient beyond relabelling, order duality, and `Aut(P)` move orbits is currently proved (in the cited record) to reduce the asymptotic state-count or time exponent for exact evaluation of `S(n)` / `SORT-BOUND-U`.** 
  - **Partial barrier:** frontier-enumeration routes cannot reach `2^{O(n log n)}` because of the `2^{Ω(n log^2 n)}` nonisomorphic winning frontier. 
  - **Open:** a stronger, general barrier that every possible sound quotient leaves a `2^{ω(n log n)}` (or `2^{Ω(n^2)}`) unavoidable representative set for *all* exact evaluation methods is **not established** here; likewise no positive all-`n` quotient theorem with exponent reduction is established. The question is therefore **unresolved in full generality but constrained**: any future "beyond" quotient must (i) be transition-sound (not merely value-invariant), (ii) survive known `n<=7/9` falsifiers, and (iii) either collapse a proven large fraction of the winning frontier or enable a non-enumerative evaluator that escapes frontier materialization.
