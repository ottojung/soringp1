# G(12,29) refuter / G(12,30) yes-certificate size (framed DAG grammar)

**Task (SoringP1 #301, billy-dev).** Falsifiable: attempt to construct/check a
concrete compressed adversary refuter/DAG for `G(12,29)` (`S(12)>29`,
`SORT-BOUND-U` no-instance) OR a concrete exact-height-30 compressed
yes-certificate for `G(12,30)` with an explicit checker-verifiable format and
measured size; if impossible with available methods, give a precise finite
obstruction/size lower-bound argument for the tested certificate grammar. Raw
search output is not a short certificate. No separation claim.

**Model / labels.** Adaptive pairwise comparison sorting of 12 distinct labelled
keys; unary `SORT-BOUND-U = {1^n#1^k : S(n)<=k}`. `S(12)=30` and `S(12)>29`
are `[literature]` (Wells 1965/1971; Peczarski; Stober–Weiß; see
`docs/literature.md`, `docs/research-n12-nontightness.md`). `G(n,k)` is the
minimax game of `docs/research-certificates-barriers.md`. Certificate claims are
`[experiment]` when checked by `scripts/check_framed_strategy.py` and
`[deduction]`/`[open]` otherwise. This note is not Lean-checked.

## 1. Tested certificate grammar (yes-side)

The only checker-verifiable framed format available in-repo is the yes-side
sorting-strategy DAG of `scripts/check_framed_strategy.py`
(`docs/research-framed-certificate-frontier.md`): a topologically numbered DAG
with root 0, nodes `{"compare":[a,b],"lt":{"next":v,"perm":[...]},"gt":...}` or
`{"leaf":true}`, explicit full-slot permutations, transitive-closure/intersection
soundness, and longest-path depth `<= budget`. It accepts a sorter strategy
proving `S(n)<=k`; it has **no refuter / adversary format**. `[definition, code]`

Verifier complexity is polynomial in explicit graph size and `n`
(`check_framed_strategy.py:2-9,67-111`).

## 3. G(12,30) exact-height-30 yes-certificate attempt

**Target.** A concrete, checker-verifiable framed yes-certificate for
`G(12,30)` with depth `<=30`, i.e. an explicit strategy proving `S(12)<=30` in
the tested grammar.

**What is known.** `[literature]` `S(12)=30` (Wells; merge insertion/Ford–Johnson
achieves 30, `F_FJ(12)=sum_{j=1}^{12} ceil(log2(3j/4))=30`). A balanced merge
sort gives worst-case 33 comparisons for `n=12` (depth 33, so not exact).
`docs/research-framed-certificate-frontier.md` §2 gives an **all-n paper
construction** for adaptive merge sort as an `O(n^2)` framed DAG with path
length `O(n log n)` and comparison-node identity `sum pq = n(n-1)/2 = 66` for
`n=12`; §3 gives a **plausible, pending independent frame/boundary review**
polynomial framed certificate for the standard Ford–Johnson upper bound
`F_FJ(n)` (30 for `n=12`). Neither a checked merge-sort JSON (depth 33) nor a
checked exact Ford–Johnson framed JSON (depth 30) was produced here.

**Construction attempt (measured).** `[experiment, partial]` A direct sequential
merge-sort composition was implemented against the checker's edge/closure
semantics for the schedule giving `sum pq=66` comparison states. The compacted
reachable object had 67 nodes but was **rejected** by the checker
(`leaf 0 does not sort 0,1`) because correctly encoding queue-exhaustion/append
boundaries in this grammar requires carrying the already-established internal
queue order across merge boundaries in the edge-propagated relation; the naive
jump/continuation encoding did not preserve a checkable total order at the final
leaf. This is an implementation/encoding failure in the tested attempt, not a
soundness failure of the §2 paper construction and not evidence that such a cert
does not exist. The attempt does establish that a correct depth-33 merge cert in
this exact format is **nontrivial to hand-encode** and, in any case, would miss
the exact budget 30.

**Conclusion for G(12,30).** With available methods in this worktree I did
**not** produce a concrete exact-height-30 checker-verifiable framed
yes-certificate for `G(12,30)`. Available concrete yes artifacts are: checked
bubble depth 66 (8082 bytes, budget-infeasible for 30), and literature/paper
witnesses (Ford–Johnson achieves 30; framed merge/FJ constructions are paper or
pending review). This is an availability/encoding obstruction, not a proof that
no exact-height-30 framed certificate exists.

## 4. G(12,29) no-instance / adversary refuter attempt

**Target.** A concrete compressed adversary refuter/DAG for `G(12,29)` proving
`S(12)>29` (a `SORT-BOUND-U` no-instance) in an explicit checker-verifiable
format with measured size.

**Grammar obstruction.** `[deduction]` `check_framed_strategy.py` verifies a
*sorter* strategy (`∃` next comparison, `∀` outcomes, all leaves sorted within
budget). A refuter for `S(12)>29` is the dual: for **every** sorter comparison
choice, the adversary supplies **some** feasible outcome after which the sorter
cannot force a total order within 28 more comparisons. This is an
`∀ sorter / ∃ adversary` strategy object, not representable in the tested
yes-side grammar. No refuter checker exists in the repository; producing a
checked refuter would require a different explicit format and verifier.

**Search-trace non-certificate.** `[literature]` The published proofs of
`S(12)>29` (Wells; confirmed by Stober–Weiß, Table 2 `sortable=no` for
`n=12, C=29`) are exhaustive searches over partial-order states / efficiency
pruning, not compact refuter objects. Raw search output is therefore not a short
certificate under the task rule. `[deduction]`

**Finite size/structure lower-bound argument (tested grammars / natural
refuters).** `[deduction]`

1. **Explicit reduced comparison tree (yes or refuter tree unfolded).** Any
   correct deterministic comparison decision object that distinguishes all
   `12! = 479001600` input permutations has at least `12!` reachable leaves and
   `2*12! - 1 = 958003199` nodes as a reduced full binary tree
   (`research-certificates-barriers.md` Claim C). For `N = n+k+1 = 42` (input
   `(12,29)`), `958003199 = 2^(Θ(N log N))` nodes is super-polynomial in the
   unary input length. This rules out explicit unfolded tree certificates in
   either direction.
2. **Yes-side framed DAG.** A yes certificate for `G(12,29)` would be a depth-29
   sorter strategy, which cannot exist because `S(12)=30>29` `[literature]`. So
   no accepting yes-side framed DAG exists for budget 29; the obstruction is
   semantic (the instance is false), and the only *accepting* framed DAGs are
   for budgets `>=30`.
3. **Adversary-strategy refuter (natural).** A complete adversary refuter must,
   at each sorter node, respond to every incomparable-pair choice available to
   the sorter (up to `C(12,2)=66` initially, varying by state) with a feasible
   child that remains winning for the adversary for the remaining budget. Even
   with perfect hash-consing to distinct poset states, the labelled-poset state
   universe for `n=12` is `A001035(12)=414864951055853499` (`2^58` scale), far
   beyond explicit materialization; without a proof that optimal/forced adversary
   play stays in a polynomial or otherwise small subclass, a compressed explicit
   refuter DAG has no known small bound and no in-repo checker. The Wells proof
   certifies the refutation only as an exhaustive computation, which this task
   excludes as a short certificate.
4. **Root/forced-adversary caveat.** `[deduction]` A bad reachable poset is not
   by itself a refuter: it must be forceable against **every** height-29 root
   sorter strategy (`research-framed-certificate-frontier.md` §5, issue #48).
   Therefore small local witnesses (single posets, slack ratios, or
   non-monotone `e(P)` examples from `research-n12-nontightness.md`) do not form
   a complete refuter for `G(12,29)`.
