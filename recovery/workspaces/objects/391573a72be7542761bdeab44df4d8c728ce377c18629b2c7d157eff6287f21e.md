## Verdict (summary)

The artifact is a **credible symbol-level expansion attempt** of the standard Vardi/Immerman/Abiteboul–Vianu FO(PFP) capture route for the explicit PSPACE DTM `M_D^alt`, building on the prior CKS/AV local semantics. It makes concrete: the fixed ordered input signature `A(w)`, a fixed tape/address space `Cell = W^r` with `r:=4`, a finite tape alphabet and frame layout, fixed-arity configuration relations, an explicit FO `Init_{M_D}`, explicit FO local evaluation of `StepPosBit` / `PostBudget` / `YieldE` / `YieldA0` / `YieldA1` / `ConfigAcc` on encoded frames, and a finite-case DFS control schema for the one-step transition `Δ_{M_D}`. It gives an explicit FO(PFP) halting/acceptance schema and a conditional equivalence chain to `S(n)<=k`.

It **does not** discharge a complete fixed syntactic FO(PFP)/IFP sentence proof. The gap is localized correctly and narrowly as **`[open:CKS-AV-Δ_D]`**: the complete, total, functional, invariant-preserving, no-spurious-transition FO formula for the full deterministic DFS stack discipline of `M_D^alt` (frame boundaries, push/pop, return propagation, lex cursor, universal `C0/C1` sequencing), specialized to the fixed layout/relations and local move semantics. This is narrower than the prior `[open:CKS-AV-FORMULA]` in that §§1–4 and the fixed-point form are explicit, but it remains the blocking symbol-level closure.

The artifact **avoids A001035 / `PACK-REPR` total tuple-coding**: `Cell=W^r` addresses tape cells, `PosBit` stores only the current frame’s closure, `StepPosBit` computes from current bits, and no relation names all `A001035(n)` posets. **No `P`, `FO(LFP)`-on-bare-word, `NP`, `coNP`, or complete fixed-sentence overclaim** is found.

## 1. Fixed signature / cell / frame layout

**Status: explicit and fixed (paper-level).**

- **Input signature (§1).** `A(w)=(W,<,One,Hash)`, `W={1,...,N}`, `w=1^n#1^k`, `N=n+k+1`. FO-definable guards/parameters are enumerated (`Succ, Min, Max, HashPos, WellFormed_w, Malformed, Key, Ctr, Zero, MaxK, SuccCtr, HasBudget, KeyNe, Lex2, LexTuple_r`) by reference to the prior CKS/AV artifact. This is fixed and independent of `n,k` except through the interpreted structure.
- **Cell/address space (§1).** Fixes `r:=4` and `Cell := W^r`, with FO-definable lex order, `SuccCell`, endpoints, and fixed-constant offsets. The space bound justification (`M_D^alt` uses `O(N^3)`, `N^r` for fixed `r>=4` gives polynomial margin) is standard for Vardi/AV/Immerman PSPACE addressing. Using fixed `r` independent of `N` is appropriate and does not enumerate all `Pos` states.
- **Tape alphabet (§2.1).** Finite `Γ` is fixed and independent of `n,k`: blanks/bits, frame markers `S/E`, DFS modes (`M_EVAL, M_BACK_E, M_BACK_A0, M_BACK_A1, M_RET_ACC, M_RET_REJ, M_HALT_ACC, M_HALT_REJ`), encoded control tags (`Q_SORT,Q_ADV,Q_ACC,Q_REJ`), and `SEP`. Equivalent fixed finite codings are allowed.
- **Frame layout (§2.2).** A frame is a fixed-order record with conceptual fields: `mode`, `ctrl`, `used` (a `Ctr` index/value), `sel_a,sel_b`, `cursor_a,cursor_b`, `child`, and `pos_matrix` (an `n×n` bit block indexed by `(u,v)∈Key×Key` in lex order storing the **current** transitive-closure relation). The artifact correctly states that the `Pos` block stores one current frame’s closure, not names for all posets, and that depth `<=2k+1` gives `O(N^3)` tape use.
- **Configuration relations (§2.3).** Fixed-arity relations are listed: `H`, `Blnk`, `Sym_σ` (finite family), optional `Val`, `PosBit(c̄,u,v)`, `Top`, `Frame`, and finite control `State_q`. The note allows packing into a fixed finite subset/encoding with fixed arities (e.g. `T(c̄,s̄)`), which is the right standard normal-form flexibility.

**Audit notes.** The layout is concrete enough to constrain `Δ_{M_D}` and the PFP capture, but several symbol-level choices remain schematic in the standard way (exact bit packing of metadata, exact frame-size/addressing discipline, exact finite encoding of `Sym_σ`/`State_q`). Those choices are inside `[open:CKS-AV-Δ_D]` / formula expansion, not hidden local semantic gaps. The key structural design — current closure content in frames, not global poset names — is correct.

## 2. `Init_{M_D}`

**Status: discharged at the intended tape-semantics/obligation level.**

Section 3 gives an explicit FO formula/schema:
```text
Init_{M_D} := WellFormed_w ∧ State_{q0} ∧ ∃c̄ (Top(c̄) ∧ ZeroCell(c̄) ∧ H(c̄))
            ∧ one well-delimited initial frame encoding Init_{N_G}
            ∧ every cell outside that frame is blank.
```
The initial frame encodes `M_EVAL`, `ctrl = Q_ACC` if `Total(empty_n)` else `Q_SORT`, `used = Zero`, empty selection, cursor `(MinKey,MinKey)`, `child=0`, and all `PosBit` false.

**Assessment.** This matches the prior semantic `Init_{N_G}` (antichain, used zero, no selection, accept iff `n<=1` else sort). The artifact’s obligation (2) claim is supported: `Key,Ctr,Zero,Total(empty_n)` are FO over `A(w)` and the frame occupies an FO-definable initial `Cell` block. A symbol-level proof would need to fix the exact field encoding and frame boundary, but that is part of the `Δ_{M_D}`/encoding closure rather than a missing initial semantic fact.

## 3. Local move evaluation: `StepPosBit` / `Yield` / `PostBudget`

**Status: locally explicit and semantically discharged; stack-propagated move realization conditional.**

Section 4 evaluates local `M_G` predicates on the encoded current top frame `F`:

- **Frame accessors.** `FramePos_F`, `FrameUsed_F`, `FrameSel_F`, `FrameCtrl*`, `ValidPos_F`, `Incomp_F`, `Total_F`, `HasBudget_F`, `ConfigAcc_F`, `ConfigRej_F` are FO over `A(w)` plus current frame fields.
- **`StepPosBit` (§4.1).**
  ```text
  StepPosBit_F(x,y;u,v) := FramePos_F(u,v)
                        ∨ ((u=x ∨ FramePos_F(u,x)) ∧ (v=y ∨ FramePos_F(y,v))).
  ```
  This is the correct incremental transitive-closure update on a current encoded closure matrix, with parameters `x,y` and access to current `Pos` bits. The artifact appeals to the prior incremental TC lemma/standard argument; that lemma is the right local semantic foundation (assuming stored matrix is a transitive closure and the selected pair is incomparable).
- **`PostBudget` (§4.2).** Three-way resolution (`Total -> Acc`; non-total + `HasBudget -> Sort`; non-total + exhausted -> `Rej`) is explicit and matches `G(n,k)` budget/totality semantics, instantiated for unchanged or updated `Pos'/Used'`.
- **`YieldE`, `YieldA0`, `YieldA1` (§4.3).**
  - `YieldE_F(a,b)`: sorter/existential phase from `Q_SORT`, non-total, budget available, selects incomparable `(a,b)`; `ChildE_F` preserves `Pos/Used`, sets `Sel'=(a,b)`, `Ctrl'=Q_ADV`.
  - `YieldA0_F(a,b)` / `YieldA1_F(a,b)`: adversary/universal phase with selected incomparable `(a,b)`, compute `Pos'` by `StepPosBit_F(a,b;·,·)` or `(b,a;·,·)`, advance `Used'` by unique `SuccCtr`, clear selection, and resolve by `PostBudget`.

**Assessment.** These formulas discharge the **local mathematical move content** of obligations (ii), (iii), (2), (3): legality (incomparability, budget, phase), incremental closure, budget consumption, and accept/continue/reject resolution. The preservation/reflection claim is plausible and consistent with the prior CKS/AV artifact.

**Caveat (correctly handled).** Section 5/7 states that full parent/child propagation of these local moves — pushing child frames, pop/return routing by mode, cursor resumption, universal `C0`-then-`C1` sequencing — is inside `[open:CKS-AV-Δ_D]`. This is the right split: local semantics are explicit; complete stack-machine realization is not yet discharged.

## 4. `[open:CKS-AV-Δ_D]` isolation

**Status: precise, minimal relative to the stated expansion, and correctly blocking.**

The artifact isolates a single minimal failing lemma:
> **[open:CKS-AV-Δ_D] (complete one-step transition for the full DFS stack discipline).** Provide a complete, case-closed FO formula `Δ_{M_D}` over the fixed relations of §2 whose every satisfying update is exactly one legal transition of the explicit deterministic DFS stack evaluator `M_D^alt` (including: frame-boundary addressing, push of an `N_G` child frame derived by `YieldE`/`YieldA0`/`YieldA1`, pop/return propagation to the parent frame's `mode/cursor/child-result` fields, lex enumeration of `Key×Key` incomparables for existential phases, and the universal two-branch `C0`-then-`C1` sequencing), together with a proof that `Δ_{M_D}` is total on non-halting encoded configurations, functional on encoded configurations, preserves the frame well-formedness invariant, and has no spurious transition.

**Audit assessment.**
- The isolation is useful because §§1–4 already provide the hard project-specific local semantics (`A(w)`, `PosBit` encoding, `StepPosBit`, `PostBudget`, `YieldE/A0/A1`). The residual is not “invent local game formulas” but “close the deterministic stack tableau.”
- The required properties are the right ones for a deterministic TM/FO(PFP) one-step capture: totality on non-halting encoded configurations, functionality, invariant preservation, and no spurious transitions.
- Section 5 gives an explicit finite-case schema for `Δ_{M_D}` (`Δ_halt, Δ_eval_acc, Δ_eval_rej, Δ_sort_pick, Δ_sort_fail, Δ_sort_child_ret, Δ_adv_eval_A0, Δ_adv_A0_to_A1, Δ_adv_A1_ret, Δ_pop/propagate`) and concrete local ingredients such as `NextIncomp_F`. This supports the claim that the local content is present and the stack discipline is the remaining detail.
- The artifact frames `[open:CKS-AV-Δ_D]` as narrower/stronger-localized than `[open:CKS-AV-FORMULA]` from the prior CKS/AV artifact: assuming §§1–4, only the stack/control closure of `M_D^alt` remains. That is a fair characterization.

**Residual caution.** “Routine in standard constructions” does not discharge this lemma. A complete proof must fix frame addresses/sizes/offsets, the exact representation of return channels and cursors, and a full case distinction showing every reachable encoded configuration has exactly the intended successor.

## 5. FO(PFP) acceptance schema and `S(n)<=k` equivalence chain

**Status: schema explicit; end-to-end discharge conditional.**

Section 6 gives the standard FO(PFP) halting/acceptance form:
```text
ACC(Conf) := halting accepting configuration ∨ ∃Conf'(Δ_{M_D}(Conf;Conf') ∧ ACC(Conf')).
Φ_{M_D} := ∃Conf0 (Init_{M_D}(Conf0) ∧ [PFP_{ACC} ψ_ACC](Conf0)).
```
It notes standard DTM capture on ordered finite structures and allows an IFP/inflationary normal form on ordered structures in standard presentations. It explicitly states this does not place the property in `FO(LFP)` on the bare ordered word and does not imply `P`, `NP`, or `coNP`.

The equivalence chain (§6.3), conditional on `[open:CKS-AV-Δ_D]` and standard FO(PFP) DTM-capture soundness/completeness, is:
```text
A(w) |= WellFormed_w ∧ Φ_{M_D}
  iff  Init_{M_D}(Conf0) and ACC(Conf0) in the PFP semantics
  iff  M_D^alt accepts w
  iff  alternating DFS evaluation accepts the initial M_G/G(n,k) state
  iff  sorter wins G(n,k)
  iff  S(n) <= k
  iff  w ∈ SORT-BOUND-U.
```

**Assessment.** The chain is the right one and is correctly decomposed: FO(PFP) capture gives formula↔DTM; `Δ_{M_D}` correctness gives DTM transition faithfulness; local yield/reflection and `M_D^alt` correctness give DTM↔alternating `M_G/G(n,k)`; game characterization gives `G(n,k)`↔`S(n)<=k`↔`SORT-BOUND-U`. The artifact does not present this as fully discharged; §0, §6.2, §7, and §8 make the conditionality explicit.

## 6. A001035 / `PACK-REPR` avoidance

**Status: correctly avoided.**

Section 7 checks the A001035 falsifier at every level:
- `Cell=W^r` codes polynomially many tape addresses, not poset states.
- `PosBit` stores the current frame’s closure (`n^2` bits of content), not a tuple name for an arbitrary member of all `A001035(n)` labelled posets.
- `StepPosBit` computes a closure from current bits and a selected edge; it does not decode a global poset code.
- PFP relations range over configuration/tape/address tuples of fixed arity, as in standard PSPACE capture.

**Audit assessment.** This is the crucial distinction carried forward from the prior CKS/AV audit: total tuple-coding of all valid `Pos` states (falsified by `A001035(n)=2^{Θ(n^2)}` vs fixed `|W|^r`) is not required. One current relation-valued state may be stored as polynomial-size tape/frame content. The artifact does not claim restricted polynomial-capacity poset domains, total `W^r` names for all valid posets, or any hidden `D_{n,k}`-style packing.

## 7. Overclaim check

**No prohibited overclaim found.**

- **No `P` claim.** No assertion that `SORT-BOUND-U ∈ P` or that `S` is polynomial-time computable.
- **No `FO(LFP)`-on-bare-word claim.** §6.1 explicitly states the normal form does not place the property in `FO(LFP)` on the bare ordered word.
- **No `NP` / `coNP` claim.** §6.1 and §8 explicitly state no `NP` or `coNP` claim is made.
- **No complete fixed-sentence overclaim.** §0, §6.2, §7 table, §8 repeatedly state the construction is not a complete discharged fixed syntactic FO(PFP)/IFP sentence proof and isolate `[open:CKS-AV-Δ_D]`. The acceptance formula is a schema/conditional chain, not presented as a fully expanded discharged sentence.
- **Scope discipline.** Unary `SORT-BOUND-U` over ordered `A(w)` only; no binary workstream; no separation claim.

Minor wording caution: “routine in standard DTM-to-FO(PFP) constructions” appears as motivation for localizability; it should not be read as discharging `[open:CKS-AV-Δ_D]`. The artifact’s own verdict prevents that reading.
