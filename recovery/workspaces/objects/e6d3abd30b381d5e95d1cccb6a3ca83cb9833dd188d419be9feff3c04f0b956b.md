## 1. Whole-configuration state (unchanged)

`[definition]` For well-formed `w=1^n#1^k`, `N=n+k+1`, let `E=E(\bar R)` be an
`I_{M_D}`-reachable encoded non-halting configuration (`¬HaltAcc(E) ∧
¬HaltRej(E)`). By `I_{M_D}` (SYM/SYM-TOP, realization Cor. 4.2): unique `Top`,
exactly one mode per live frame, functional `Parent` on active non-root frames,
functional `UsedF` over `Ctr={0,...,k}`, and coherent `HasSel/SelA/SelB`,
`HasCur/CurA/CurB`, `RetNone/RetAcc/RetRej`, `Ctrl*`/`PosF` fields.

Let the unique active root-to-top stack path be
```text
P(E) = (F_0,...,F_d),  F_0=root, F_d=Top(E),  0 <= d <= 2k+1.
```
`d <= 2k+1` is inherited from realization Theorem 5.1/DFS discipline: only
`PushChildA` applies `SuccCtr`; `PushChildE` copies `UsedF`; `UsedF∈Ctr`; A1 is
pushed only after A0 returns to the same `BackA0` snapshot; one active
root-to-top path is maintained.

For `F_i` on `P(E)`, `b(F_i)` is the unique value with `UsedF(F_i,b(F_i))`.

## 2. Explicit existential cursor rank

`[definition]` Fix `D_lex=Key×Key`, `|D_lex|=n^2 <= N^2`. Let `idx(p)` be the
1-based position of `p` in the fixed `Lex2` enumeration of `D_lex`, extended by
`idx(exh)=n^2+1` for exhaustion. Set
```text
L       := n^2+1,
rlex(p) := L - idx(p) ∈ {0,...,n^2},   rlex(exh):=0.
```

`[deduction]` `NextIncomp_c(curA,curB;x,y)` returns the lex-minimal incomparable
pair `(x,y)` at or after the cursor (unique by `I_{M_D}` and lex-minimality).
`D_sort_pick` and `D_backE_rej_next` consume that candidate and advance the
stored BackE cursor by `SuccLex2(x,y)`. Therefore the stored cursor position is
strictly after `(x,y)`, and
```text
rlex(SuccLex2(x,y)) <= L-(idx(x,y)+1) < L-idx(x,y) <= rlex(curA,curB).
```
When `NextIncomp_c` holds, `idx(curA,curB)<=n^2`, so `rlex(curA,curB)>=1`.
Exhaustion is represented separately by `NoNextIncomp_c` / terminal reject-exhaust
states with `ex:=0`. No hidden DFS search order is used.

## 3. Global per-frame key and whole-configuration measure

`[definition]` For every active frame `F` on a non-halting `I_{M_D}`-reachable
path define
```text
V(F) := ( bcost(F),  q(F),  ex(F),  ph(F) )
      ∈ B := {0,...,k} × {0,1,2} × {0,...,L} × {0,...,6}
```
with **lexicographic order** on `B` in this component order:
`bcost` first, then `q`, then `ex`, then `ph`. Components:

- `bcost(F) := k-b(F)` (remaining `Ctr` capacity).
- `q(F) ∈ {0,1,2}`: pending adversary outcomes at `F`.
- `ex(F) ∈ {0,...,L}`: existential cursor rank `rlex` of the frame's current
  stored cursor when the frame is in an existential-search state; `0` otherwise.
- `ph(F) ∈ {0,...,6}`: finite control/return phase.

Complete table for every non-halting `I_{M_D}`-reachable active stack frame:

| Reachable frame state | `q` | `ex` | `ph` |
|---|---:|---:|---:|
| `M_Eval,RetNone,CtrlSort,¬Total,Budget,NextIncomp_c` | 0 | `rlex(Cur)` | 6 |
| `M_Eval,RetNone,CtrlAdv,HasSel` | 2 | 0 | 3 |
| `M_BackA0,RetNone` waiting below A0 | 2 | 0 | 2 |
| `M_BackA0,RetAcc` A1 pending, same snapshot | 1 | 0 | 1 |
| `M_BackA0,RetRej` returnable | 0 | 0 | 0 |
| `M_BackA1,RetNone` waiting below A1 | 0 | 0 | 2 |
| `M_BackA1,RetAcc/RetRej` returnable | 0 | 0 | 0 |
| `M_BackE,RetNone` waiting below E-child (advanced cursor stored) | 0 | `rlex(Cur')` | 5 |
| `M_BackE,RetRej,NextIncomp_c` retry pending (same stored cursor) | 0 | `rlex(Cur)` | 4 |
| `M_BackE,RetRej,NoNextIncomp_c` exhaust pending | 0 | 0 | 0 |
| `M_BackE,RetAcc` returnable | 0 | 0 | 0 |
| `M_Eval,RetNone` non-root returnable terminal (`CtrlAcc∨Total∨RejectEval_c` as handled by return/halt cases) | 0 | 0 | 0 |

**Completeness.** Root terminal eval states take `D_root_acc/D_root_rej` and are
not in the non-halting active domain. A `CtrlSort` state without
`NextIncomp_c` has `RejectEval_c` and takes a reject/halt/return case, so it is
a returnable terminal (`ph=0`), not `ph=6`. `CtrlAdv` has `HasSel` by
`I_{M_D}`/schema. Backtrack frames have `RetNone` only while waiting below
their active child and `RetAcc/RetRej` only after a popped child writes the
marker (A1--A3,A6 below). All other combinations are excluded by `I_{M_D}`
coherence and the `D_*` precondition partition.

`[definition]` Let
```text
Ω := ⋃_{d=0}^{2k+1} B^(d+1),
μ(E) := (V(F_0),...,V(F_d)) for P(E)=(F_0,...,F_d),
```
ordered by root-to-top lexicographic order `<_bf`: the first index `i` with
`V(F_i) != V'(F_i)` decides by lex order on `B`.

`[deduction]` `B` is finite and `d<=2k+1`, so `<_bf` is well-founded on `Ω`.

## 4. Stated local facts used (no hidden DFS semantics)

`[deduction]`

A1. `PushChildA` (`D_adv_push_A0`,`D_backA0_acc_A1`) sets
`UsedF'=SuccCtr(UsedF(parent))`, so `b(child)=b(parent)+1`,
`bcost(child)=bcost(parent)-1`. `PushChildE` copies `UsedF`.

A2. `PushChildA` children are `M_Eval,RetNone,Ctrl∈{Acc,Sort,Rej}` by
`PostBudgetFrom`, never `CtrlAdv`; hence `q(child)=0`.

A3. `PushChildE` children are `M_Eval,RetNone,CtrlAdv,HasSel`, with copied
`PosF/UsedF`; hence `V(child)=(k-b(parent),2,0,3)`.

A4. `D_sort_pick`/`D_backE_rej_next` use `NextIncomp_c` and `SuccLex2` and set
the parent to `M_BackE,RetNone` with the advanced cursor: `ex` strictly
decreases by §2.

A5. A0/A1 same snapshot: `D_backA0_acc_A1` preserves `Sel/PosF/UsedF/Cur` of the
same `BackA0` parent and pushes A1 with `StepPosBit(parent,b,a)` and
`SuccCtr(UsedF(parent))`. `D_adv_push_A0` pushes A0 from the preserved parent
snapshot with `StepPosBit(parent,a,b)` and `SuccCtr(UsedF(parent))`.

A6. Return-pop cases remove `Top=F_d` and apply `MarkRetAccOn/MarkRetRejOn` to
the unique `Parent(F_d)=F_{d-1}`; lower stack frames except the designated
parent marker/mode (and any field-preserving `BackA0/BackA1` invariant
already stated) are preserved.

A7. Budget-exhausted/non-total, `CtrlRej`, and `NoNextIncomp_c` after search
take reject/halt/exhaust cases, never pushes.

A8. `I_{M_D}` gives unique `Top`, unique `Parent` on the active non-root path,
unique mode, unique `UsedF`, and coherent cursor/selection/return markers.

## 5. Case-complete strict decrease

`[deduction]` **Theorem 1 (strict progress).** For every `I_{M_D}`-reachable
non-halting `E` and every non-halting macro-step
`E --δ_{M_D^alt}^{sch}--> E'`, `μ(E') <_bf μ(E)`.

*Proof.* Let `P(E)=(F_0,...,F_d)=Top`. Frames `F_i`, `i<j`, are unchanged
unless stated. For a push, the modified existing frame is at index `j=d` and the
new child at `d+1` is above `j`, so `<_bf` is decided at `j`. For a pop/return
marker to an existing parent, the first changed frame is `j=d-1`. Every
non-halting `D_*` of realization §3.2 is checked using `V=(bcost,q,ex,ph)`:

| `D_*` (non-halting) | `j` | `V` change at `j` (lower unchanged) | reason |
|---|---:|---|---|
| `D_eval_acc_ret`, parent `M_BackA0` | `d-1` | `(k-b,2,0,2) -> (k-b,1,0,1)` | A6: A0 consumed, A1 pending; `q` down |
| `D_eval_rej_ret`, parent `M_BackA0` | `d-1` | `(k-b,2,0,2) -> (k-b,0,0,0)` | A6: A0 rejects; `q` down |
| `D_eval_acc_ret`, parent `M_BackA1` | `d-1` | `(k-b,0,0,2) -> (k-b,0,0,0)` | A6: `ph` down |
| `D_eval_rej_ret`, parent `M_BackA1` | `d-1` | `(k-b,0,0,2) -> (k-b,0,0,0)` | A6: `ph` down |
| `D_eval_acc_ret`, parent `M_BackE` | `d-1` | `(k-b,0,r',5) -> (k-b,0,0,0)` | A6: BackE becomes `RetAcc`; `ex` down or, if `r'=0`, `ph` down |
| `D_eval_rej_ret`, parent `M_BackE`, `NextIncomp_c` | `d-1` | `(k-b,0,r',5) -> (k-b,0,r',4)` | A6: waiting -> retry pending, same cursor; `ex` same, `ph` down |
| `D_eval_rej_ret`, parent `M_BackE`, `NoNextIncomp_c` | `d-1` | `(k-b,0,r',5) -> (k-b,0,0,0)` | A6,A7: exhaust pending; `ex` down or `ph` down |
| `D_sort_pick` | `d` | `(k-b,0,r,6) -> (k-b,0,r',5)` | A3,A4,§2: selects `NextIncomp` at/after `r`, stores BackE waiting with `r'=rlex(SuccLex2)<r`; child `(k-b,2,0,3)` at `d+1`; `ex` down |
| `D_backE_acc_ret`, parent `M_BackA0` | `d-1` | `(k-b,2,0,2) -> (k-b,1,0,1)` | A6: `q` down |
| `D_backE_acc_ret`, parent `M_BackA1` | `d-1` | `(k-b,0,0,2) -> (k-b,0,0,0)` | A6: `ph` down |
| `D_backE_acc_ret`, parent `M_BackE` | `d-1` | `(k-b,0,r',5) -> (k-b,0,0,0)` | A6: `ex`/`ph` down |
| `D_backE_rej_next` | `d` | `(k-b,0,r',4) -> (k-b,0,r'',5)` | A3,A4,§2: from BackE retry `r'=rlex(Cur)>=1`, selects `NextIncomp`, advances to `r''<r'`, stores BackE waiting; child `(k-b,2,0,3)` at `d+1`; `ex` down (**BackE cycle repair**) |
| `D_backE_rej_exh_ret` | `d-1` | parent waiting -> parent `RetRej` (terminal for that BackE obligation): `(k-b,0,r',5) -> (k-b,0,r''',4)/(k-b,0,0,0)/(k-b,2,0,2)->(k-b,0,0,0)/(k-b,1,0,1)/(k-b,0,0,0)` as by actual parent mode; in all cases first changed `B` component decreases | A6,A7: `F_d` is BackE exhaust pending `(k-b,0,0,0)` popped; its parent `F_{d-1}` receives `RetRej` and follows the corresponding `*_rej_ret`-to-parent decrease |
| `D_adv_push_A0` | `d` | `(k-b,2,0,3) -> (k-b,2,0,2)` | A1,A2,A5: parent becomes `BackA0,RetNone`; A0 child `(k-b-1,*,0,*)` at `d+1`; `ph` down |
| `D_backA0_acc_A1` | `d` | `(k-b,1,0,1) -> (k-b,0,0,2)` | A1,A2,A5: same snapshot, A1 consumes second outcome; A1 child `(k-b-1,*,0,*)` at `d+1`; `q` down |
| `D_backA0_rej_ret` | `d-1` | pop `F_d=(k-b,0,0,2)`; parent receives `RetRej` and decreases as a return target | A6 |
| `D_backA1_acc_ret` | `d-1` | pop `F_d`; parent receives `RetAcc` and decreases | A6 |
| `D_backA1_rej_ret` | `d-1` | pop `F_d`; parent receives `RetRej` and decreases | A6 |

**BackE cycle check (explicit).**
```text
CtrlSort, r
  V=(k-b,0,r,6)
--D_sort_pick; NextIncomp at/after r gives r'=rlex(SuccLex2)<r-->
BackE,RetNone(wait), r'
  V=(k-b,0,r',5)          [decrease: ex r>r']
--child evaluates; D_eval_rej_ret to BackE, NextIncomp_c holds at r'-->
BackE,RetRej,next, r'
  V=(k-b,0,r',4)          [decrease: ex same, ph 5>4]
--D_backE_rej_next; NextIncomp at/after r' gives r''=rlex(SuccLex2)<r'-->
BackE,RetNone(wait), r''
  V=(k-b,0,r'',5)         [decrease: ex r'>r''; ph may rise 4->5 but ex is compared first]
```
All three steps strictly decrease in the single global key `(bcost,q,ex,ph)`.

Excluded halting cases: `D_halt`, `D_root_acc`, `D_root_rej`,
`D_backE_acc_root`, `D_backE_rej_exh_root`, `D_backA0_rej_root`,
`D_backA1_acc_root`, `D_backA1_rej_root`.

No case increases `bcost` on an existing frame (A1 only for pushed A-children).
`ex` decreases whenever a sort cursor is advanced (A4,§2) and is not increased
on existing frames. `q`/`ph` handle finite A0/A1/E return obligations (A1--A6).
Lower frames are preserved except the designated return marker/mode (A6,A8).
Therefore `μ(E') <_bf μ(E)`. ∎

## 6. `I_{M_D}` preservation and halting consequence

`[deduction]` **Corollary 1 (`I_{M_D}` preservation).** `δ_{M_D^alt}^{sch}` is
unchanged. By realization Theorem 4.1/Cor. 4.2 and SYM/SYM-TOP, `I_{M_D}` is
preserved on every step; Theorem 1 applies to every `I_{M_D}`-reachable
configuration from `Init_{M_D}^{sym}`.

`[deduction]` **Corollary 2 (halting).** For well-formed `w=1^n#1^k`, every
`I_{M_D}`-reachable non-halting configuration has a `δ_{M_D^alt}^{sch}`
successor with strictly smaller `μ ∈ Ω`, and `<_bf` is well-founded on `Ω`.
Hence no infinite `δ_{M_D^alt}^{sch}` computation exists from an
`I_{M_D}`-reachable state, and every run from `Init_{M_D}^{sym}` reaches
`HaltAcc` or `HaltRej`.

## 7. Falsifiable/checkable claim and scope

**Falsifiable claim.** The tuple order is `(bcost,q,ex,ph)` (lex), and the table
in §3 is the complete frame assignment for all non-halting `I_{M_D}`-reachable
active states. A counterexample would be either (i) an `I_{M_D}`-reachable
non-halting active frame state not covered by the table, or (ii) some
non-halting `D_*` transition whose actual post-state assigns a `V` not strictly
below the pre-state `V` at the first changed root-to-top index. The BackE cycle
specifically checks as: `ex: r>r'` on `D_sort_pick`, `ph:5>4` at same `ex=r'`
on `D_eval_rej_ret` to BackE with `NextIncomp_c`, `ex:r'>r''` on
`D_backE_rej_next`.

**Scope/non-claims.** No A001035/`PACK-REPR`. No hidden DFS semantics: progress
uses explicit `NextIncomp_c`/`SuccLex2`/`SuccCtr`, return markers, and
`I_{M_D}` uniqueness. P1/P2/PACK-REACH/model bridge remain conditional. No
complete end-to-end FO(PFP)/IFP discharge beyond that conditional chain. No `P`,
no FO(LFP) on the bare word, no NP, no coNP, no separation.
