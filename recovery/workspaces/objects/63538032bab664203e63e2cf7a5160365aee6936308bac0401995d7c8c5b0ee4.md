## 0. Fixed objects and primitives `[definition]`

Input `A(w)=(W,<,One,Hash)`, `w=1^n#1^k`, `N=n+k+1`, `Cell=W^r`.

```text
Rbar includes Globals := (Top,CurBase,EmptyStack,HaltAcc,HaltRej)
and frame fields including FrameLive, M_*, Ret*, Ctrl*, UsedF, HasSel/SelA/SelB,
HasCur/CurA/CurB/CurExhausted, PosF, Parent.
Fld(c) := ⟨Mode,Ret,Ctrl,UsedF,HasSel,SelA,SelB,HasCur,CurA,CurB,CurExhausted,PosF,Parent⟩
Back*(c) := M_BackE(c) ∨ M_BackA0(c) ∨ M_BackA1(c).

FrameFieldsEq'(x) := equality of all Fld components for x,x', no implicit liveness change.
FrameEq'(x)       := FrameFieldsEq'(x) ∧ (FrameLive'(x) <-> FrameLive(x)).
FrameInactive'(x) := ¬FrameLive'(x).
LowerStackPreservedExcept(S) := ∀x(FrameLive(x) ∧ ¬S(x) -> FrameEq'(x)).

Globals_pop(p,c) :=
  Top'(p) ∧ ¬Top'(c) ∧ ∀z(Top'(z) -> z=p) ∧ CurBaseUnchanged ∧
  HaltAcc' <-> HaltAcc ∧ HaltRej' <-> HaltRej ∧ EmptyStack' <-> EmptyStack.

PreserveNonMarkerFields(p) :=
  FrameLive'(p)
  ∧ preserve every Fld component of p except Ret
  ∧ (RetAcc'(p)∨RetRej'(p)∨RetNone'(p) decided only by the row's marker clause).
  -- includes Mode,Ctrl,UsedF,HasSel,SelA,SelB,HasCur,CurA,CurB,CurExhausted,PosF,Parent.

MarkRetAccOn(p) :=
  FrameLive'(p) ∧ RetAcc'(p) ∧ ¬RetRej'(p) ∧ ¬RetNone'(p) ∧ PreserveNonMarkerFields(p).

MarkRetRejOn(p) :=
  FrameLive'(p) ∧ RetRej'(p) ∧ ¬RetAcc'(p) ∧ ¬RetNone'(p) ∧ PreserveNonMarkerFields(p).

PopTo_base(p,c) :=
  Top(c) ∧ Parent(c,p) ∧ FrameLive(c) ∧ FrameLive(p) ∧
  Globals_pop(p,c) ∧ FrameInactive'(c) ∧ LowerStackPreservedExcept({p,c}).
```

```text
CurExhaustedState(c)  := CurExhausted(c) ∧ HasCur(c) ∧ CurA(c,MinKey) ∧ CurB(c,MinKey)
```

## 4. Exact `MarkRetAccOn`/`MarkRetRejOn` non-marker preservation `[definition][deduction]`

### 4.1 Exact preservation contract

For `MarkRetAccOn(p)` (row cases 4,9,17) `[definition]`:
```text
FrameLive'(p)=1
RetAcc'(p)=1, RetRej'(p)=0, RetNone'(p)=0
Mode'(p)=Mode(p)            -- M_Eval/M_BackE/M_BackA0/M_BackA1 preserved
Ctrl'(p)=Ctrl(p)            -- all Ctrl* preserved
UsedF'(p,·)=UsedF(p,·)
HasSel'(p)<->HasSel(p), SelA'(p,·)<->SelA(p,·), SelB'(p,·)<->SelB(p,·)
HasCur'(p)<->HasCur(p), CurA'(p,·)<->CurA(p,·), CurB'(p,·)<->CurB(p,·)
CurExhausted'(p)<->CurExhausted(p)
PosF'(p,·,·)<->PosF(p,·,·)
Parent'(p,·)<->Parent(p,·)
```
For `MarkRetRejOn(p)` (row cases 5,12,14,19): same except
`RetRej'(p)=1, RetAcc'(p)=0, RetNone'(p)=0`.

`[deduction]` Consequences:
- **Mode preserved.** If `p` was `Back*`, it remains `Back*` and receives a
  matrix-consumable return marker. If `p` were `M_Eval` (excluded on target-2
  valid receivers by `MarkerReceiver_Is_BackStar` under I7), the marker would
  preserve `M_Eval` — hence the separate no-Eval+RetMarker-top obligation.
- **Cursor coherence preserved (schema-level).** Because `HasCur,CurA,CurB,
  CurExhausted` are preserved componentwise, `CursorCoherent(p)` is preserved:
  `CurNormalState'(p,a,b) <-> CurNormalState(p,a,b)` and
  `CurExhaustedState'(p) <-> CurExhaustedState(p)` when witnesses are unchanged.
- **BackE NI/NNI consumer basis preserved.** For row 5/12 receivers that become
  `Top'(p)∧M_BackE'(p)∧RetRej'(p)`, `NI_p`/`NNI_p` (v2: `NI_p := ¬CurExhausted∧
  CurNormalState∧∃x,y NextIncomp`; `NNI_p := CurExhausted∨(¬CurExhausted∧
  CurNormalState∧NoNextIncomp)`) are unchanged at `p` by the marker step itself.

### 4.2 Exact non-preservation (intentional)

`MarkRet*On(p)` intentionally does **not** preserve `Ret`:
- `MarkRetAccOn` sets `RetAcc'` and clears `RetRej',RetNone'`.
- `MarkRetRejOn` sets `RetRej'` and clears `RetAcc',RetNone'`.

`MarkRet*On(p)` does **not** apply to `c`: `c` is given `FrameInactive'(c)` by
`PopTo_base`. `MarkRet*On(p)` does **not** constrain frames `x ∉ {p,c}`: they are
covered by `LowerStackPreservedExcept({p,c})`.

### 4.3 `CurExhausted` / cursor-coherence falsifier shapes `[falsification]`

- Cursor component omitted in implementation/realization:
  ```text
  D_i(E), i∈{4,5,9,12,14,17,19}, MarkRet*On(p)

     ∨ ∃a(CurA'(p,a) xor CurA(p,a)) ∨ ∃b(CurB'(p,b) xor CurB(p,b))
  ```

## 6. `MarkerReceiver_Is_BackStar` `[deduction][open][falsification]`

**Lemma statement** (normalized Enc §4.1; marker-receiver sketch §2):
```text
MarkerReceiver_Is_BackStar :=
  I_{M_D}(E) ∧ (D_eval_acc_ret(E,c,p) ∨ D_eval_rej_ret(E,c,p))
  -> Back*(E,p).
```

**Status.** `[open]` on base `I_{M_D}` alone as a fully discharged invariant
proof; `[deduction]` **proved as a schema-level proof sketch conditional on
(I7) `LiveBackParent` and (I9) parent discipline** (following
`det-succ-marker-receiver-reachability.md` Lemma 2.1).

**Proof sketch.** Assume `I_{M_D}(E)`, `D_eval_acc_ret(E,c,p)` or
`D_eval_rej_ret(E,c,p)`. Then `Top(E,c), M_Eval(E,c), NonRoot(E,c), Parent(E,c,p)`.
By (I1)/(I2), `FrameLive(E,c)`. By (I9), `FrameLive(E,p)`. By (I7)
`LiveBackParent`, `Parent(E,c,p) -> Back*(E,p)`. Rows 4/5 apply
`MarkRetAccOn(p)`/`MarkRetRejOn(p)`, preserving `Mode'(p)=Mode(p)` and
`FrameLive'(p)`, hence `Back*'(p)`.

**Refutation condition.** The lemma is refuted for the deterministic-successor
candidate if an `I_{M_D}`-reachable eval non-root return has a non-Back* parent.

`[falsification]` (exact witness shape):
```text
I_{M_D}(E) ∧ (D_eval_acc_ret(E,c,p) ∨ D_eval_rej_ret(E,c,p)) ∧ M_Eval(E,p).
```
Consequence: row 4/5 gives `Top'(p)∧FrameLive'(p)∧M_Eval'(p)` by `MarkRet*On`
mode preservation and `Globals_pop`, plus `RetAcc'(p)`/`RetRej'(p)`, yielding
the `No_Eval_RetMarker_Top` falsifier. (Other non-Back* modes are excluded if
`ExactlyOneMode` holds.)

## 7. `No_Eval_RetMarker_Top` `[deduction][open][falsification]`

**Lemma statement** (normalized Enc §4.1):
```text
No_Eval_RetMarker_Top :=
  ¬∃E,c. Reach_{I_{M_D}}(E) ∧ Top(E,c) ∧ M_Eval(E,c) ∧ (RetAcc(E,c) ∨ RetRej(E,c)).
```

**Status.** `[open]` as a fully discharged induction; `[deduction]` schema-level
proof sketch conditional on (I7) (marker-receiver sketch Lemma 3.1). The row
family 4,5,9,12,14,17,19 is the only family that can create a return marker on a
frame that becomes `Top'`.

**Proof sketch.** Init has `M_Eval(root),RetNone(root)`. Direct `M_Eval'`
creators (`PushChildE/A`) set `RetNone'`. Marker creators are rows 4,5,9,12,14,
17,19: they set `Top'(p)` and `RetAcc'/RetRej'(p)` but preserve `Mode'(p)`.
- Rows 4,5: consumed child is `M_Eval(c)`; by (I7) and `Parent(c,p)`,
  `Back*(p)`, so `Mode'(p)` is Back*, not `M_Eval`.
- Rows 9,12 consume `M_BackE(c)`; 14 consumes `M_BackA0(c)`; 17,19 consume
  `M_BackA1(c)`. The receiver `p` is a live parent of a Back* top child; (I7)
  gives `Back*(p)` and preserved Back* mode.
No row sets `M_Eval'∧RetAcc'/RetRej'` on the same frame.

`[falsification]`:
```text
Reach_{I_{M_D}}(E*) ∧ Top(E*,c) ∧ M_Eval(E*,c) ∧ (RetAcc(E*,c)∨RetRej(E*,c)).
```
Under normalized rows this would require a `MarkRet*On(c)` while `c` preserves
`M_Eval`; rows 4/5 are the only eval-return producers and are blocked by (I7);
other pop rows consume Back* tops and would additionally need a non-Back*
receiver.

## 8. `No_BackStar_RetNone_Consuming_Top` (target-2 context) `[deduction]`

**Lemma statement** (normalized Enc §4.1):
```text
No_BackStar_RetNone_Consuming_Top :=
  no I_{M_D}-reachable state requires a return-consuming matrix row from
  Top(c) ∧ Back*(c) ∧ RetNone(c).
```
Stronger reachability form (marker-receiver sketch Lemma 4.1):
```text
¬∃E,c. Reach_{I_{M_D}}(E) ∧ Top(E,c) ∧ Back*(E,c) ∧ RetNone(E,c).
```

**Status.** `[deduction]` schema-level proof sketch on base `I_{M_D}` plus
normalized `Top'/Ret'` discipline (no I7 needed). The target-2 rows are the
key positive producers of consumable Back* tops: every row 4,5,9,12,14,17,19
makes `Top'(p)` and applies `MarkRetAccOn/MarkRetRejOn(p)`, so
`¬RetNone'(p)`.

**Interaction with target 2.** Push rows create `Back*'(c)` frames with
`RetNone'(c)` but set `¬Top'(c)` and `Top'(d)` on an `M_Eval,RetNone` child.
Target-2 rows create `Top'(p)` but force `RetAcc'/RetRej'`. Thus no normalized
row creates `Top'∧Back*'∧RetNone'`.

`[falsification]`:
```text
Reach_{I_{M_D}}(E*) ∧ Top(E*,c) ∧ Back*(E*,c) ∧ RetNone(E*,c)
∧ (no D_i consumes E* ∨ two D_i consume E*).
```
The reachability conjunct is schema-refuted by the push/pop `Top'/Ret'`
assignments; a remaining risk is realization/row-encoding omitting the explicit
`RetAcc'/RetRej'` marker on a pop row.

## 9. Row-by-row induction schema for rows 4,5,9,12,14,17,19 `[open checklist]`

Let `J(E)` be the target-2 invariant package over `I_{M_D}`-reachable `E`:
```text
J(E) :=
  No_Eval_RetMarker_Top(E)
  ∧ (∀c,p. EnabledEvalRet(E,c,p) -> Back*(E,p))      -- MarkerReceiver_Is_BackStar form
  ∧ (∀c. Top(E,c)∧Back*(E,c) -> RetAcc(E,c)∨RetRej(E,c)) -- TopBackMarker/No_BackStar_RetNone
  ∧ (∀c. RelevantBackE(E,c) -> CursorCoherent(E,c))    -- cursor coherence where used
  ∧ ParentFunctionalActive(E)
  ∧ ExactlyOneTop/Mode/UsedF/Ctrl/Ret coherence slices as needed.
```
`J` is `[open]` as a full preserved invariant; this section gives the row-by-row
schema obligations.

**Base.** `Init_{M_D}^{sym}`: no pop enabled; `M_Eval,RetNone,CursorCoherent` root;
unique top/live frame. Thus target-2 conjuncts relevant at init hold
(schema-level).

**Step, row 4 `D_eval_acc_ret`, `S={p,c}`.** Assume `I_{M_D}(E), J(E), D_4(E,c,p)`.
- `PopTo_base(p,c)`: `Top'(p),¬Top'(c),!z,CurBaseUnchanged,Halt* preserved,
  FrameInactive'(c), LowerStackPreservedExcept({p,c})`.
- `MarkRetAccOn(p)`: `FrameLive'(p),RetAcc'(p),¬RetRej',¬RetNone'`, all
  non-`Ret` Fld preserved (incl. `Mode,Ctrl,UsedF,Sel*,HasCur,CurA,CurB,
  CurExhausted,PosF,Parent`).
- Obligations: from (I7)/(I9), `Back*(p)`; preserved mode => `Back*'(p)` and
  not `M_Eval'∧RetMarker`; preserved cursor => `CursorCoherent'(p)` if `J(E)` had it.
- `[falsification]`: `M_Eval(p)` or missing cursor preservation.

**Step, row 5 `D_eval_rej_ret`.** Same shape as row 4 but `MarkRetRejOn(p)`.
Critical for BackE: receiver `p` may become `Top'(p)∧M_BackE'(p)∧RetRej'(p)` and
must preserve `HasCur,CurA,CurB,CurExhausted,PosF,UsedF,Sel*,Parent,Ctrl,Mode`.
- `[falsification]`: `BackE_Cursor_Preservation` failure — any non-`Ret` BackE
  cursor/PosF/snapshot field mutated on `p`.

**Step, row 9 `D_backE_acc_ret`.** Guard has `M_BackE(c),RetAcc(c)`. Receiver gets
`MarkRetAccOn(p)`. (I7) on `Parent(c,p)` gives `Back*(p)`. Preserved cursor on
`p` is irrelevant to BackE acc consumption but must remain coherent by
`PreserveNonMarkerFields`.

**Step, row 12 `D_backE_rej_exh_ret`.** Guard consumes `M_BackE,RetRej,NNI_c`.
`MarkRetRejOn(p)` preserves `CurExhausted/cursor` of `p`; it does **not** read or
alter `NNI_c` of popped `c` except by inactivating `c`. `NNI_c` complementarity
is an upstream BackE obligation (rows 5/6/10/11/12, BackE v2).

**Step, row 14 `D_backA0_rej_ret`.** Guard `M_BackA0,RetRej`; receiver gets
`MarkRetRejOn(p)`. Row 15 snapshot adequacy depends on BackA0 parent state
before 14/15 paths, not on row 14 mutating `p` except the explicit `RetRej`
marker.

**Step, row 17 `D_backA1_acc_ret`.** Guard `M_BackA1,RetAcc`; `MarkRetAccOn(p)`.

**Step, row 19 `D_backA1_rej_ret`.** Guard `M_BackA1,RetRej`; `MarkRetRejOn(p)`.

**Common off-`S` obligation.** `LowerStackPreservedExcept({p,c})` must preserve
`FrameEq'(x)` for all live `x ∉ {p,c}`. In particular no target-2 row may change
