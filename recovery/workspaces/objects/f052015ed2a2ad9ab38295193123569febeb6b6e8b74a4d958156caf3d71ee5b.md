# Exec report: n12-obstruction-invariant (computable poset invariant generalizing S(12)>C(12)?)

**Question.** Is there a computable poset invariant `I(P)` with `C(P)=ceil(log2 e(P)) <= I(P) <= F(P)` strictly above `C(P)` on an infinite/structurally characterized class, generalizing `S(12)=30 > C(12)=29`? Consequence if yes: a uniform, checkable strengthening of the information bound certifying non-tightness on that class and narrowing the exact-search window for `S(n)`.

**Candidates attacked.** (1) one-ply `L1`; (2) two-ply `L2` and the `L_k` hierarchy; (3) merge-factor/ordinal-sum bound `B`; (4) low-dimensional scalar invariants. Plus a test of whether any "local pair-split invariant" can lift a balanced antichain root.

## Results (evidence-labeled)

### 1. `L1` cannot lift any antichain root (deduction + computation)

`L1(A_n) = 1 + min_pairs max(C(child))`. Every first comparison from the antichain splits `n!/2, n!/2`, and all pairs are isomorphic, so `L1(A_n) = 1 + C(n!/2) = C(n)` for all `n`. Verified `n=12`: `e=479001600, C=29, L1=29`. (Consistent with prior front: 0 antichain lifts through n=12.)

### 2. `L2` (and the whole `L_k` hierarchy) cannot lift any antichain root (deduction + computation)

**Theorem (balanced-path obstruction).** Let `P_t` be the poset obtained from the `n`-antichain by fixing `t` disjoint ordered pairs `a_i < b_i` (the rest free). Then `e(P_t) = n!/2^t` and, for every `t >= 0`, the free–free comparison is available and splits extensions exactly in half (`n!/2^{t+1}` each), while free–head and free–tail comparisons are more unbalanced. Hence

```
L1(P_t) = 1 + C(n!/2^{t+1}) = C(n) - t = C(P_t).
```

Inductively, for any `j >= 0`, `L_j(P_t) <= C(P_t)` (use the free–free split at each level: `L_{j}(P_t) <= 1 + L_{j-1}(P_{t+1}) <= 1 + (C(P_t)-1) = C(P_t)`), and soundness gives `L_j >= L0 = C`. Therefore `L_j(P_t) = C(P_t)` for all `j,t`, and in particular

```
L_k(A_n) = k + C(P_k) = k + (C(n)-k) = C(n)   for all k, n.
```

Computation (n=12): `L_j(A_12) = 29` for `j=0..8`; `L1(P_t)=C(P_t)` for `t=0..8` (`P_1`: e=239500800, C=28, free-free max branch ceil=27; free-head/tail max branch ceil=28, so the min is the free-free split, value 28). So two-ply lookahead gives no antichain lift and no improvement on the `P_t` family.

**Corollary (obstruction for the pair-split T-hierarchy).** Let `J` be any sound, isomorphism-invariant lower bound (`J <= F`) with `J(P_t) <= C(P_t)` for all `t` (in particular `J = L0, L1, ...`), and define `T_J(P) = 1 + min_{incomp pairs} max(J(child), J(child))`. Then `T_J^r(A_n) <= C(A_n)` for every `r >= 0`. Thus no invariant generated by iterating such a local pair-split operator over an info-scored child scorer can be strictly above `C` at a balanced antichain root.

### 3. Merge-factor / ordinal-sum bound cannot lift the antichain root (deduction)

`B(P) = sum_i ceil(log2 e(P_i)) + sum_i delta_i` over series blocks. The antichain is a single incomparability block with no certified merge gap, so `B(A_n) = C(n)` for all `n`. Strict improvements occur only on decomposable/merge states (smallest `Merge(2,4)`, n=6: e=15, C=4, B=F=5), not at the antichain root. (Prior front and `docs/research-structural-lower-bounds.md`.)

### 4. Low-dimensional scalar invariants refuted (literature + prior experiment)

`F` is not a function of `e` (n=5: e=8 gives F=3 and F=4); non-monotone in `e` (n=6: e=13,F=5 vs e=14,F=4); `(e, width, #min, #max)` collisions with different `F` at n=6 (e.g. (13,2,2,2) -> F in {4,5}); symmetry neither necessary nor sufficient (loose posets with |Aut|>1 at n=6). No scalar can be a sound separator. (Prior front; `docs/research-n12-nontightness.md` H1–H6.)

## Conclusion

**Outcome (b): concrete obstruction, not a new invariant.** No candidate in the surveyed families (one-ply `L1`, two-ply/`L_k`, merge-factor/ordinal-sum, low-dimensional scalars) — and more generally no invariant in the local pair-split T-hierarchy over an info-scored child scorer — can be strictly above `C` at a balanced antichain root. The balanced free-pair path `P_t` keeps every level at the information bound, which is the obstruction. This is a barrier ruling out a whole family of methods (local per-pair `e`-count refinements), not a complexity separation.

**Honest limits.** `F` itself satisfies `C <= F` and `F(A_12)=30 > 29`, but computing `F` is the minimax problem itself; it is not a "local/computable" invariant in the sense needed and provides no provably-cheaper certification. Whether there exists an invariant computable strictly faster than `F` yet provably lifting an infinite family containing 12 remains open. The n=12 obstruction in the literature (Wells/Peczarski/Stober–Weiss) is established by exhaustive strategic search and no compact invariant is known. No new lower bound on `S(n)` for n>=23 is established here.
