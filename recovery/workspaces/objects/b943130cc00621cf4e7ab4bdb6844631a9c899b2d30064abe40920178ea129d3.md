## 1. Why the previous `ψ_reach` failed (and what is repaired)

`[falsification]` The PACK audit rejected §4.1 of `fopfp-cks-av-delta-d-pack.md`
because it defined an IFP over a single arity-`1+A` relation accumulating tagged
tuples:
```text
ψ_reach(t,\bar y, S) := Init^#_{tuple}(t,\bar y)
  ∨ ∃s∃\bar z (S(s,\bar z) ∧ Step^#_{tuple}(s,\bar z; t,\bar y)).
```
A whole `Δ_{M_D}` configuration is not a single tagged tuple; it is the full
interpretation of all component relations (all tagged tuples of one
configuration, including `PosF` over all `Key×Key` pairs of the active frame,
control/stack/cursor/selection fields, etc.).  If `S` accumulates tuples from
all iterations, `Decode_i` over `S` reads a union of many configurations, not
one reached configuration; if `Step^#_{tuple}` were tuple-to-tuple, it would not
implement whole-configuration `Step^#`.

**Repair.** The fixed-point variables must represent a **whole current
configuration**.  We therefore use simultaneous fixed-point variables
`R_1,...,R_m` (decoded representation) or, equivalently by PACK Lemma 3.2, the
single packed relation `Cnf` as the current whole configuration together with a
deterministic FO successor operator on whole configurations.  We use the
standard Vardi/Immerman/AV deterministic configuration-capture form via PFP of a
functional operator, combined with standard simultaneous-to-single equivalence.

## 2. Whole-configuration representation (decoded and packed)

`[definition]` A whole configuration is either:
- the simultaneous interpretation `Rbar=(R_1,...,R_m)$ over $A(w)$, where each
  $R_i \subseteq W^{a_i}$ is the $i$-th component relation; or
- a single packed interpretation $Cnf \subseteq W^{1+A}$ whose decode is
  $decode(Cnf)=Rbar^Cnf$, $R_i^Cnf(\bar x)\iff Decode_i(\bar x,Cnf)$.

`[deduction]` By PACK Lemma 3.2, these representations are equivalent for the
initial/step predicates:
```text
Init_{M_D}(Rbar)           iff  Init^#(Cnf)      for Rbar=decode(Cnf),
Δ_{M_D}(Rbar;Rbar')       iff  Step^#(Cnf;Cnf')  for decoded/encoded pairs.
```
The acceptance sentence below is stated over fixed $A(w)$ using the decoded
component representation for the simultaneous operator and is equivalent to the
packed whole-configuration reading by this correspondence.

`[falsification]` No component relation and no packed tuple names arbitrary
members of the $A001035(n)=2^{\Theta(n^2)}$ labelled posets.  $PosF$ stores the
current transitive-closure bits of the active frame over $Key\times Key$;
packing tags index finitely many fixed component relations.  This is unchanged
from PACK Lemma 3.2 and delta-d §8.

## 3. Deterministic FO successor operator (whole configuration)

`[definition,inherited assumption]` The case-closed $\Delta_{M_D}(Rbar;Rbar')$
of delta-d-dfs-stack §5 is a finite disjunction of mutually exclusive cases.
For each case, every next-step component $R_i'$ is given explicitly as a
function of the current configuration $Rbar$ (and fixed FO predicates over
$A(w)$): unchanged lower-stack/frame contents, copied/cleared fields, unique
`SuccCtr` updates, `StepPosBit$ updates for `PosF'$ on pushed universal children,
lex-unique `NextIncomp_c$ selections, and finite control/mode/stack-pointer
updates.  Under the determinism/totality/functionality properties inherited from
delta-d-dfs-stack §6, there are FO formulas $\psi_1,...,\psi_m$ of fixed arity
such that for every well-formed encoded configuration $Rbar$ satisfying
$I_{M_D}(Rbar)$,
```text
Δ_{M_D}(Rbar;Rbar')  iff  for all i=1,...,m and all \bar z∈W^{a_i},
                           R_i'(\bar z) ↔ ψ_i(Rbar,\bar z),
```
where
```text
ψ_i(Rbar,\bar z) := \/_{C ∈ Cases(Δ_{M_D})}
   ( Guard_C(Rbar) ∧ Update_{C,i}(Rbar,\bar z) ).
```
Here $Guard_C$ is the FO precondition of case $C$ on current $Rbar$, and
$Update_{C,i}$ is the FO body defining membership in $R_i'$ in that case.
Halting is represented by an absorbing operator clause:
```text
ψ_i^{abs}(Rbar,\bar z) :=
   ((HaltAcc(Rbar) ∨ HaltRej(Rbar) ∨ MalState(Rbar)) ∧ R_i(\bar z))
 ∨ (¬HaltAcc(Rbar) ∧ ¬HaltRej(Rbar) ∧ ¬MalState(Rbar) ∧ InitOrStep_i(Rbar,\bar z)),
```
with
```text
InitOrStep_i(Rbar,\bar z) :=
   (EmptyConf(Rbar) ∧ Init_{M_D,i}(\bar z))
 ∨ (¬EmptyConf(Rbar) ∧ ψ_i(Rbar,\bar z)).
```
$EmptyConf(Rbar)$ is the FO test that all $R_i$ are empty (the PFP initial
stage), and $Init_{M_D,i}(\bar z)$ is the $i$-th component of $Init_{M_D}$
written as a pure FO formula over $A(w)$ (no $Rbar$ dependence).  $MalState$
covers the finitely many ill-formed non-initial states outside $I_{M_D}$ by an
absorbing reject convention if desired; on intended well-formed inputs
$I_{M_D}$ is preserved and this branch is not semantically used.

`[deduction]` This is a standard deterministic-operator extraction: a
case-closed functional FO transition gives an FO definition of the unique
successor interpretation.  The extraction does not change $Δ_{M_D}$; it uses the
same guards and updates.  The whole configuration after one step is exactly
$Rbar' = (\psi_1^{abs}(Rbar,\cdot),\ldots,\psi_m^{abs}(Rbar,\cdot))$.

**Evidence/explicitness.** The case list and field updates are explicit in
delta-d-dfs-stack §5 (root/non-root accept/reject, existential
`NextIncomp_c`/`PushChildE`/`BackE` cursor advance, universal
`PushChildA`/`BackA0`/`PushChildA1`/`BackA1`).  A complete symbol-level
expansion of every $Update_{C,i}$ from that schema (including final
helper/marker encoding choices) is the finite formula-elaboration work
inherited with assumption (2); the present whole-configuration reachability
construction needs only that the induced successor is the deterministic FO
operator above, which follows from those inherited properties.

## 4. Simultaneous PFP acceptance (whole-configuration reachability)

`[definition]` Let $\Psi^{abs}=(\psi_1^{abs},..., \psi_m^{abs})$ be the
simultaneous FO operator from §3.  Define its simultaneous partial fixed-point
stages over $A(w)$:
```text
Rbar^0 := (\emptyset,...,\emptyset),
Rbar^{α+1} := ( \{ \bar z ∈ W^{a_1} \mid A(w),Rbar^α \models \psi_1^{abs}(\bar z)\},
               ...,
               \{ \bar z ∈ W^{a_m} \mid A(w),Rbar^α \models \psi_m^{abs}(\bar z)\} ).
```
Since $A(w)$ is finite, either some stage repeats, in which case the
simultaneous partial fixed point $\operatorname{PFP}(\Psi^{abs})$ is that stage,
or no stage repeats and the PFP is taken as $\emptyset$ by the standard PFP
convention.

`[definition]` The simultaneous whole-configuration acceptance formula is
```text
Φ_{M_D}^{sim} := WellFormed_w ∧
  \operatorname{HaltAcc}\!\left[\operatorname{PFP}_{R_1,\bar z_1;\ldots;R_m,\bar z_m}
    (\psi_1^{abs},\ldots,\psi_m^{abs})\right],
```
i.e., after expanding the standard simultaneous PFP syntax, the $HaltAcc$
component (a nullary/fixed-arity component relation in $Rbar$) holds in
$\operatorname{PFP}(\Psi^{abs})$.

`[deduction]` **Whole-configuration correctness.** For well-formed $A(w)$:
- $Rbar^1 = Init_{M_D}$ as an interpretation, by $EmptyConf(Rbar^0)$ and
  $Init_{M_D,i}$.
- If $Rbar^\alpha$ is a non-halting well-formed configuration satisfying
  $I_{M_D}$, then $Rbar^{\alpha+1}$ is the unique $\Delta_{M_D}$-successor by
  §3 and inherited assumptions (2): $Δ_{M_D}(Rbar^\alpha;Rbar^{\alpha+1})$.
- If $Rbar^\alpha$ has $HaltAcc$ or $HaltRej$, then $Rbar^{\alpha+1}=Rbar^\alpha$
  (absorbing).
- Therefore the PFP stage sequence is exactly the unique deterministic
  $M_D^alt/\Delta_{M_D}$ computation orbit from $Init_{M_D}$, truncated at the
  halting configuration when halting occurs.  It is **not** a union of tagged
  tuples across different configurations: each $Rbar^\alpha$ is a complete whole
  configuration interpretation.

Consequently
```text
A(w) |= Φ_{M_D}^{sim}
  iff the PFP orbit of Ψ^{abs} from Init_{M_D} reaches a whole configuration
      whose HaltAcc component is true
  iff HaltAcc is reachable by iterated whole-configuration Δ_{M_D} steps
      from Init_{M_D}.
```
Using PACK Lemma 3.2, the same reachability is equivalently "packed $HaltAcc$
reachable": there is a sequence $Cnf_0,\ldots,Cnf_t$ with $Init^#(Cnf_0)$,
$Step^#(Cnf_j;Cnf_{j+1})$, and $decode(Cnf_t)$ satisfying $HaltAcc$.

This repairs the exact PACK-REACH failure: acceptance is read from the fixed
point of a whole-configuration operator, not from accumulated tuple evidence.

## 5. Simultaneous-to-single normal form and fixed FO(PFP)/IFP sentence

`[literature, deduction]` Standard finite model theory gives simultaneous
IFP/PFP the same expressive power as single IFP/PFP on finite (in particular
ordered) structures.  Concretely, for fixed $m$ and fixed arities
$a_1,...,a_m$, introduce a single relation variable $X$ of fixed arity
$1+A$ (or $1+\max_i a_i$) and define
```text
X^{code}(c_i,\bar z,\bar 0)  represents  R_i(\bar z),
```
with FO tag predicates $Tag_i$ as in PACK §2.2 and a fixed FO translation
```text
\chi(X, t,\bar y) :=
  \/_{i=1}^{m} (Tag_i(t) ∧ Pad_i(y_{a_i+1},...,y_A) ∧
                \widehat{\psi}_i^{abs}(X, y_1,...,y_{a_i})),
```
where $\widehat{\psi}_i^{abs}(X,\cdot)$ is obtained from $\psi_i^{abs}(Rbar,\cdot)$
by replacing every atom $R_j(\bar u)$ with $Decode_j(\bar u,X)$ (the same
decode/encode translation discipline already used by PACK).  Then the
simultaneous PFP of $\Psi^{abs}$ is encoded by the single PFP of $\chi$, and
```text
A(w) |= Φ_{M_D}^{sim}
  iff A(w) |= Φ_{M_D},
```
where
```text
Φ_{M_D} := WellFormed_w ∧
  ∃t∃\bar y (
    [\operatorname{PFP}_{X,t\bar y}\chi](t,\bar y)
    ∧ Tag_{HaltAcc}(t) ∧ Pad_{HaltAcc}(\bar y)
  ).
```
(For a nullary $HaltAcc$, the padding/fixed witness tuple is the canonical
$Min$ tuple.)

`[literature]` On ordered finite structures, FO(PFP)=FO(IFP), so the same
property has an equivalent FO(IFP) sentence in the standard presentation.
Equivalently, one may use the inflationary simultaneous fixed point of the same
positive-in-position reachability operator over the *deterministic stage graph*
in a standard configuration-capture normal form; the PFP form above is the most
direct for a deterministic functional transition operator and is standard in
Vardi/Immerman-style PSPACE capture.

`[deduction]` This gives the required fixed FO(PFP)/IFP sentence/operator over
fixed $A(w)$ using the packed relation/decoded component representation: $X$ is
the packed whole-configuration relation, $Decode_j$ is the FO projection from
PACK, $\widehat{\psi}_i^{abs}$ is the packed operator induced by $\Delta_{M_D}$,
and the simultaneous-to-single equivalence is the standard normal form applied
to this operator.

## 6. End-to-end proof

`[deduction]` Let $A(w)$ interpret $w=1^n # 1^k$.

1. **Sentence to whole-configuration fixed point.** By §5,
   $A(w)\models \Phi_{M_D}$ iff $A(w)\models \Phi_{M_D}^{sim}$ iff the
   simultaneous/single PFP of the whole-configuration operator $\Psi^{abs}$
   contains $HaltAcc$.
2. **Fixed point to packed $HaltAcc$ reachability.** By §4, the PFP orbit is the
   unique deterministic whole-configuration orbit $Rbar^0,Rbar^1=Init_{M_D},
   Rbar^2,\ldots$ under $\Delta_{M_D}$ until halting; it contains $HaltAcc$ iff
   $HaltAcc$ is reachable by iterated whole-configuration $\Delta_{M_D}$ steps
   from $Init_{M_D}$.  By PACK Lemma 3.2 (§2), this is equivalent to packed
   $HaltAcc$ reachability by $Init^#, Step^#$.
3. **Packed/$\Delta_{M_D}$ reachability to $M_D^{alt}$.** By inherited
   assumption (2), $\Delta_{M_D}$ is functional/total on relevant non-halting
   states, invariant-preserving, and has no spurious transitions relative to the
   semantic DFS evaluator $M_D^{alt}$; $M_D^{alt}$ halts on well-formed inputs.
   Therefore iterated $HaltAcc$ reachability under $\Delta_{M_D}$ from
   $Init_{M_D}$ holds iff $M_D^{alt}$ accepts $w$.
4. **$M_D^{alt}$ to $G(n,k)$.** By inherited assumption (4),
   $M_D^{alt}$ accepts $w$ iff alternating DFS evaluation accepts the initial
   $M_G/G(n,k)$ state iff sorter wins $G(n,k)$.
5. **$G(n,k)$ to $S(n)$ and $SORT-BOUND-U$.** By the fixed model
   (inherited assumption 4, `docs/problem.md`,
   `docs/research-certificates-barriers.md`), sorter wins $G(n,k)$ iff
   $S(n)\le k$.  By definition of the unary threshold language,
   $S(n)\le k$ iff $w=1^n#1^k\in \mathrm{SORT\!-\!BOUND\!-\!U}$.

Combining (1)--(5):
```text
A(w) |= Φ_{M_D}
  iff packed HaltAcc reachable
  iff HaltAcc reachable by whole-configuration Δ_{M_D} from Init_{M_D}
  iff M_D^alt accepts w
  iff sorter wins G(n,k)
  iff S(n) <= k
  iff w ∈ SORT-BOUND-U.
```
This is the required end-to-end chain.  All project-specific semantic
assumptions are stated in §0; standard descriptive-complexity/capture facts are
used only where cited.

## 7. A001035 / `PACK-REPR` avoidance and non-claims

`[deduction,falsification]` The construction uses a fixed finite family of
fixed-arity relations, a single packed relation of fixed arity $1+A$, FO tag
projections/decodes, and simultaneous/single PFP over those whole-configuration
relations.  It does **not** use a tuple name for an arbitrary member of all
$A001035(n)=2^{\Theta(n^2)}$ labelled posets and does **not** make $PosF$ range
over global poset codes: $PosF$ is the current-frame closure relation over
$Key\times Key$; $\Delta_{M_D}/\psi_i$ compute local closure/stack updates.
Tagging/packing indexes fixed component relations, not global $Pos$ states.
Therefore no `PACK-REPR` total tuple-coding is introduced.

**Non-claims.** No claim of $P$, no $FO(LFP)$ on the bare ordered word, no
$NP$, no $coNP$, no separation claim, no $SORT-BOUND-B$ work, and no Lean
formalization.  The result is paper-level and conditional on the inherited
semantic assumptions in §0, especially the final symbol-level closure of
$\Delta_{M_D}$ helper/marker cases and the CKS/AV/$M_D^{alt}$/$G(n,k)$ semantic
equivalences.

## 8. Discharge status and residual check

`[deduction]` The single minimal failing subformula/lemma named by the PACK
audit was:
> whole-configuration IFP/PFP acceptance normal form over the packed
> `Δ_{M_D}` operator.

This note supplies that normal form: a simultaneous FO PFP operator on whole
configurations $\Psi^{abs}$ extracted from deterministic case-closed
$\Delta_{M_D}$, with acceptance read from the $HaltAcc$ component of its PFP
orbit; equivalently a single packed PFP sentence $\Phi_{M_D}$ via standard
simultaneous-to-single normal form and the discharged PACK decode/encode
correspondence.  The tuple-accumulation error is avoided because the fixed-point
state is the whole current configuration, not a reachability set of tagged
tuples across configurations.

No further `PACK-REACH`-specific failing subformula is isolated here.  Any
remaining work lies in the inherited assumptions of §0 (final symbol-level
closure/proof of the $\Delta_{M_D}$ case analysis and the project semantic
equivalences), not in the whole-configuration fixed-point acceptance normal form
itself.
