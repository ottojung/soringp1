## 3. Route (a): restricted domain

### 3.1 What is sound

The route-(a) requirements are appropriate for a fixed-arity global coding
attempt: a domain `D_{n,k}`, explicit `Code/Decode` or equivalent, capacity
`|D_{n,k}| <= |W|^r` (or bounded-index equivalent), and obligations (2)–(4)
(initial encoding, transition preservation/reflection, acceptance
soundness/completeness). `[definition,deduction]`

The central emphasis is correct: alternating acceptance is universal on
adversary outcomes. A restricted domain cannot keep only a favorable existential
branch; it must be closed (or proved sufficient) for **both** `YieldA0` and
`YieldA1` successors along every acceptance-relevant universal branch (§4.3).
This is the right failure mode to test. `[deduction]`

The candidate table (§4.2) identifies the main natural families:
- all valid states — capacity fails by `A001035`;
- reachable states — sufficiency by definition, capacity unproved;
- states on some accepting run — insufficient because universal branches are not
  all covered;
- strategy-tree / optimal-play states — semantically close, but size is open;
- structural poset subclasses — generally insufficient for exact `G(n,k)` unless
  a closure theorem is proved. `[deduction,open,falsification target]`

### 3.2 Caveats

1. **Reachability capacity is not a proof of failure.** The artifact says all
   reachable configurations have “no polynomial bound proved; counting not ruled
   polynomial here only by A001035, but no polynomial bound known” — this is
   careful and acceptable. An auditor should not read it as a proof that
   `G(n,k)`-reachability is superpolynomial for fixed-r coding purposes.
   `[open,caution]`
2. **Optimal-play/strategy-relative domain is strategy-dependent.** Defining
   `D_{n,k}` as adversary-closed descendants under some accepting strategy is
   semantically sufficient only conditionally, and makes the domain depend on
   acceptance. The artifact correctly flags this circularity and the missing
   uniform FO/PFP-definable description (§4.3). `[deduction,open]`
3. **Structural poset subclasses need explicit falsification per class.** The
   table marks interval/dimension-2/N-free/series-parallel restrictions as
   “falsification target / not sufficient for exact `S(n)`”. That is plausible
   because the adversary can realize arbitrary comparison outcomes consistent
   with the current order, but a complete proof would show, for each proposed
   class, a legal comparison sequence forcing a state outside the class while
   preserving relevance. The table is therefore a risk assessment, not a
   completed class-by-class theorem. `[caution,open]`
4. **Capacity form.** The artifact states `|D_{n,k}| <= |W|^r = N^r` or a
   directly equivalent bounded-index argument. This is the right fixed-arity
   tuple-name capacity test; an alternative coding (e.g. relation-valued
   second-order objects not representable as fixed tuples) would not satisfy the
   intended normal form and should not be smuggled in. `[deduction]`

**Route (a) audit conclusion:** not discharged; no restricted domain with
explicit `Code/Decode`, proved polynomial capacity, and proved sufficiency for
(2)–(4) is exhibited. `[deduction,open]`

## 4. Route (b): Vardi/AV / global FO(PFP)-IFP instantiation

### 4.1 What is sound

The artifact makes the key separation:

- `[literature,deduction]` A standard descriptive-complexity capture theorem
  gives that PSPACE properties of ordered finite structures are definable in
  FO(PFP)/FO(IFP) (Vardi 1982; Abiteboul–Vianu 1991; Immerman; Ebbinghaus–Flum).
  Combined with Claim A (`SORT-BOUND-U ∈ PSPACE`), there exists **some**
  FO(PFP) sentence defining `SORT-BOUND-U` on the relevant ordered structures.
- `[caution]` Existence of such a sentence is **not** the same as a concrete
  instantiation that starts from the project's local `M_G` formulas and gives a
  complete simulation/correspondence proof for alternating acceptance of
  `G(n,k)`. The task asked for the latter, and the artifact does not claim to
  have it. `[deduction]`

The representation point in §5.2 is helpful: a single DTM configuration over
`N^r` cells can be represented by fixed-arity relations (`Head`, `State_q`,
`Sym_a`) using lexicographic successor from `<`. Also, `Pos/Used/Sel/Ctrl` are
already fixed-arity relations over `W`. Therefore the obstacle is **not**
merely “one state cannot be written down”; it is the global alternating
acceptance closure / tuple naming / proof of equivalence to `M_G`. `[deduction]`

The direct alternating normal-form attempt (§5.3) correctly identifies the
split: naming whole configurations as tuples reintroduces packing/capacity;
evolving current state relations expresses local evolution but not, by itself,
the full universal–existential acceptance table over all relevant descendants.
`[deduction,caution]`

### 4.2 Caveats

1. **DTM simulation route remains open, not refuted.** Section 5.4 states that an
   explicit polynomial-space DTM `M_D` equivalent to `M_G` plus a complete
   `M_D ~ M_G ~ G(n,k)` correspondence and a standard FO(PFP) reachability
   instantiation would discharge the Vardi/AV-style proof obligation for that
   `M_D`. The artifact does not supply `M_D`; it also does not prove `M_D`
   cannot be concretely derived from the local formulas. So route (b) is
   *undischarged*, not *impossible*. `[open,caution]`
2. **FO(PFP) vs FO(IFP) normal form details.** The artifact mentions FO(PFP)/
   FO(IFP) together, as standard on ordered finite structures for PSPACE. This is
   acceptable at the literature boundary, but a discharged instantiation should
   name the exact calculus, positivity/inflationary conditions, simultaneous vs
   nested form, and the structure/ordering conventions actually used.
   `[literature,caution]`
3. **Alternation is the proof burden.** APTIME=PSPACE gives existence of an
   equivalent DTM; using it abstractly bypasses the requested concrete
   instantiation for local `M_G`. A route-(b) discharge that cites APTIME=PSPACE
   must still carry out or explicitly construct the simulation/correspondence.
   The artifact's criticism on this point is fair. `[deduction]`
4. **Local formulas are necessary but not sufficient.** The presence of explicit
   FO `Init/YieldE/YieldA0/YieldA1/ConfigAcc/PostBudget/StepPos` formulas is a
   useful local layer, but local step correctness does not automatically give a
   global fixed-point acceptance theorem over encoded configurations.
   `[deduction]`

**Route (b) audit conclusion:** not discharged as a concrete instantiation for
local `M_G` formulas with complete simulation/correspondence proof.
Existence of some FO(PFP) definition of `SORT-BOUND-U` is a separate
literature-level consequence and is not presented as a project discharge.
`[literature,deduction,open]`

## 5. A001035 / reachability / capacity

- `[literature,deduction]` **A001035 falsifier:** labelled posets on `n`
  elements number `A001035(n)=2^{Θ(n^2)}` (Kleitman–Rothschild; OEIS A001035).
  For `W={1,...,N}` with `N=n+k+1 = O(n log n)` on informative unary inputs, a
  fixed-arity tuple code can name only `|W|^r = N^r = n^{O(1)}` objects. Since
  `2^{Θ(n^2)}` eventually dominates `N^r` for every fixed `r`, the total
  all-valid-state tuple-packing route is correctly falsified in capacity.
- `[deduction]` **Reachability:** `G(n,k)`-reachable states form a subset of
  valid `N_G` states/projected posets under legal play. This gives sufficiency
  by definition if used as the semantic domain, but no polynomial capacity bound
  is proved. Reachability from the antichain is not obviously equal to all
  labelled posets after budget/control restrictions, so A001035 alone does not
  prove reachability-count capacity failure. The artifact handles this as open.
  `[open,caution]`
- `[open]` **Optimal-play state count:** states on *some* height-`S(n)` optimal
  strategy, closed under adversary replies, are the compression-relevant object.
  `research-certificates-barriers.md` §8 lists this as open. The artifact
  correctly treats it as unproved and not a discharged route-(a) domain.

## 6. `[open:ALT-PACK]` isolation

The isolated lemma is:

> provide a fixed standard global FO(PFP)/FO(IFP) normal form over ordered
> `A(w)` and a complete proof of obligations (2)–(4) for alternating `M_G`
> acceptance of `G(n,k)`, using the local formulas as transition semantics.

Audit assessment:

- **Strengths.** It is concrete (fixed signature/arity, initial formulas,
  existential and both universal move preservation/reflection, alternating
  acceptance fixed point, soundness/completeness to `S(n)<=k`). It avoids two
  weaker moves: merely citing FO(PFP)=PSPACE, and merely restating the already
  explicit local layer. `[deduction]`
- **Scope caveat.** The name `[open:ALT-PACK]` emphasizes packing/coding, but
  the lemma as stated also admits a discharge by an explicit deterministic DTM
  simulation/reachability instantiation if that instantiation is fully proved
  against the local `M_G` semantics. This is acceptable because both are forms of
  “fixed global normal form + complete obligations (2)–(4)”; the note should not
  be read as excluding a proved DTM-reachability normal form. `[caution]`
- **Minimality.** It is a reasonable minimal *global* blocker after the local
  formulas are fixed. One could split it further into (i) global configuration
  encoding / state-evolution normal form and (ii) alternating acceptance
  equivalence proof, but those sublemmas are tightly coupled in the current
  attempts. `[deduction,open]`

**Isolation audit conclusion:** `[open:ALT-PACK]` is a defensible minimal
failing lemma for the stated task.

## 8. Final audit conclusion

The reviewed artifact is a careful negative/partial research note. Its core
technical judgments are sound: the total valid-state packing route is blocked by
`A001035`; restricted domains must satisfy adversary-closed sufficiency, not
only existential-path inclusion; and a Vardi/AV-style global result is not the
same as a completed instantiation for local alternating `M_G` formulas. The
remaining work is correctly isolated as `[open:ALT-PACK]`. No Lean, PR, main, or
board action is warranted by this audit alone. `[deduction,open]`
