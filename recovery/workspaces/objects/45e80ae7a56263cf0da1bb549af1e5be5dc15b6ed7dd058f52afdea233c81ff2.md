## 1. `A1_Snapshot_From_Parent`

### 1.1 Precise statement

`[definition][open][lemma A1_Snapshot_From_Parent]` Let `E` be an
`I^{+}_{M_D}`-reachable state and let row 15
```text
D_backA0_acc_A1(E,c̄,a,b) :=
  Top(E,c̄) ∧ M_BackA0(E,c̄) ∧ RetAcc(E,c̄) ∧
  HasSel(E,c̄) ∧ SelA(E,c̄,a) ∧ SelB(E,c̄,b)
```

be the unique consuming row. Then the row-15 update
`SetParentBackA1(E,E',c̄); PushChildA(E,E',d̄,c̄,a,b,1)` satisfies:

1. **Parent snapshot source.** The A1 child fields are constructed only from
   `PosF(E,c̄,·,·)`, `UsedF(E,c̄,·)`, `SelA(E,c̄,·)`, `SelB(E,c̄,·)`, `a,b`,
   `d̄=FreshChild(E)=CurBase(E)`, and fixed local formulas

## 2. `FreshChild_Fresh_On_IMD`

### 2.1 Precise statement

`[definition][open][lemma FreshChild_Fresh_On_IMD]` For every push row `D_i`
(`i ∈ {6,7,10,15}`) and every `I^{+}_{M_D}`-reachable state `E` satisfying its
guard with fresh child `d̄ := CurBase(E)`,
```text
d̄ = CurBase(E)
-> ¬FrameLive(E,d̄)
   ∧ ∀x̄(FrameLive(E,x̄) -> x̄ != d̄)
   ∧ ¬Top(E,d̄)
   ∧ LowerStackPreservedExcept(S_i)(E,E') is not invalidated by aliasing d̄ to
     any frame x̄ with FrameLive(E,x̄) ∧ x̄ ∉ S_i.
```
Equivalently, under the bump discipline, `CurBase` is a fresh `Cell` allocator
for active/lower-stack frames on all `I^{+}_{M_D}`-reachable push states.

### 2.2 Proof sketch over `Init_{M_D}^{sym}+I^{+}_{M_D}` and normalized rows

`[deduction]` (schema). `Globals_push(c̄,d̄)` requires `FreshChild(d̄)` i.e.
`CurBase(d̄)` and `CurBaseBump`: `∃b̄∃b̄'(CurBase(b̄)∧SuccCell(b̄,b̄')∧CurBase'(b̄'))`.
Every push row (6,7,10,15) uses `Globals_push(c̄,d̄)` and sets
`FrameLive'(d̄)`; every non-push, non-terminal row uses
`CurBaseUnchanged`/`Globals_halt_absorb`/terminal conventions as stated.
No normalized row sets `CurBase` backward or reuses an old `CurBase` value.

`[needed strengthening]` The normalized schema states bumping but not the
global freshness consequence. `I^{+}_{M_D}` should add an explicit
**allocator freshness** clause, e.g.:
```text
CurBase_Fresh(E) :=
  ∃!b̄ CurBase(E,b̄)
  ∧ ∀x̄(FrameLive(E,x̄) -> BelowLive(E,x̄,b̄))
  ∧ ¬FrameLive(E,b̄),
```
where `BelowLive(E,x̄,b̄)` is a fixed total order/separation witness in the
`Cell=W^r` encoding implying `x̄ != b̄` and excluding reuse of live/preserved
addresses. The realization uses `ZeroCell` root and `SuccCell` bump; a natural
concrete strengthening is
```text
CurBaseMonotone(E) :=
  ∃b̄(CurBase(E,b̄) ∧ ∀x̄(FrameLive(E,x̄) -> x̄ <_{lex,Cell} b̄)).
```
This is stronger than needed and must be checked against the actual `Cell`
model; the weaker separation `x̄ != b̄` plus no-reuse history suffices if the
encoding does not rely on `<_{lex}`.

`[deduction]` (init). `Init_{M_D}^{sym}` (realization §2.1) sets
`Top=ZeroCell`, the only live frame is `ZeroCell`, and
`CurBase=SuccCell(ZeroCell)`. Under functional `SuccCell` and
`ZeroCell != SuccCell(ZeroCell)`, `CurBase_Fresh` holds initially.

`[deduction]` (push preservation). If `CurBase_Fresh(E)` holds and row `i`
pushes with `d̄=CurBase(E)`, `b̄'=SuccCell(d̄)` becomes `CurBase(E')`, and
`FrameLive(E')` is `FrameLive(E) ∪ {d̄} \ (if any popped, none here)`. To
preserve `CurBase_Fresh(E')` it suffices that `SuccCell(d̄)` is not live and
not equal to any frame in `FrameLive(E) ∪ {d̄}`. This follows from
`CurBaseMonotone`-style strict advance, or from an explicit no-reuse allocator
invariant. The normalized text states bump but not strict monotonicity; hence
this is a strengthening obligation.

`[deduction]` (non-push preservation). Rows with `CurBaseUnchanged` preserve
`CurBase(E')=CurBase(E)`. Pops make a top frame inactive (`FrameInactive'(c̄)`)
and do not create live frames except marker updates to an already-live `p̄`;
thus the set of live frames does not gain `CurBase(E)`. Terminal/absorb rows
either preserve `CurBase` or move to halting states outside the push
freshness domain.

`[deduction]` (alias consequence). If `d̄` were equal to some live
`x̄ ∉ S_i`, `FrameLive'(d̄)` and/or push field writes to `d̄` would conflict
with `LowerStackPreservedExcept(S_i)` requiring `FrameEq'(x̄)`. Therefore the
stated no-alias consequence is equivalent, under the 19-row discipline, to the
allocator freshness clause.

### 2.3 Reachable falsifier shape

`[falsification]` Allocator reuse / alias:
```text
I_{M_D}(E) ∧ D_i(E,...) is a push row (i∈{6,7,10,15}) ∧ CurBase(E,d̄)
∧ ( FrameLive(E,d̄)
    ∨ ∃x̄(FrameLive(E,x̄) ∧ x̄!=d̄ ∧ x̄ = d̄)   -- impossible equality written for shape
    ∨ E' after push violates LowerStackPreservedExcept({c̄,d̄}) at a live x̄
      because updates to d̄ alias x̄ ).
```
The concrete falsifier is
```text
I_{M_D}(E) ∧ push guard D_i(E) ∧ CurBase(E,d̄) ∧ FrameLive(E,d̄),
```
or
```text
I_{M_D}(E) ∧ push guard D_i(E) ∧ CurBase(E,d̄) ∧ FrameLive(E,x̄) ∧
LowerStackPreservedExcept({c̄,d̄}) fails for x̄ due to alias x̄=d̄.
```

### 2.4 Verdict for this obligation

`[deduction]` **Conditional paper-level support, not discharged.** The bump
discipline is present (`CurBaseBump` on all pushes, `CurBaseUnchanged`
elsewhere), and `Init_{M_D}^{sym}` initializes `CurBase` after the root.
However, the normalized `I_{M_D}` text does not explicitly state a
`CurBase_Fresh`/monotonicity separation invariant; without it, reuse/alias is
not excluded by the row matrix alone. No explicit `I_{M_D}`-reachable
falsifying witness was found in the audited schema, but the obligation remains
open until the allocator invariant is added to `I^{+}_{M_D}` and preserved by
all 19 rows.

## 3. `Parent_Functional_Active_Preserved`

### 3.1 Precise statement

`[definition]`
```text
ActiveNonRoot(E,c̄) := FrameLive(E,c̄) ∧ ∃p̄ Parent(E,c̄,p̄).
RootLive(E,c̄)      := FrameLive(E,c̄) ∧ ¬∃p̄ Parent(E,c̄,p̄).

ParentFunctionalActive(E) :=
  ∀c̄(ActiveNonRoot(E,c̄) -> ∃!p̄ (Parent(E,c̄,p̄) ∧ FrameLive(E,p̄))).
ParentRootDisjoint(E) :=
  ∀c̄ ¬(RootLive(E,c̄) ∧ ∃p̄ Parent(E,c̄,p̄)).
DFSParentCorrect(E) :=
  ParentFunctionalActive(E) ∧ ParentRootDisjoint(E)
  ∧ the active root-to-top path is the unique Parent-chain from Top(E) to a
    RootLive frame, with every intermediate frame FrameLive.
```

`[definition][open][lemma Parent_Functional_Active_Preserved]` Over
`Init_{M_D}^{sym}+I^{+}_{M_D}` and the normalized 19 rows:
1. `Init_{M_D}^{sym} -> DFSParentCorrect`.
2. For every row `E --D_i--> E'` with `I^{+}_{M_D}(E)`,
   `ParentFunctionalActive(E') ∧ ParentRootDisjoint(E')`.
3. For every non-root pop row with guard `NonRoot(E,c̄) ∧ Parent(E,c̄,p̄)`,
   the `PopTo_base` target is the unique DFS-active parent `p̄` of `c̄`:
   `∃!p̄(Parent(E,c̄,p̄) ∧ FrameLive(E,p̄))` and that `p̄` is the row target.

### 3.2 Proof sketch over `Init_{M_D}^{sym}+I^{+}_{M_D}` and normalized rows

`[deduction]` (init). `Init_{M_D}^{sym}` has one live root frame `ZeroCell`
with `¬∃p̄ Parent(ZeroCell,p̄)` and no other live frames. Thus
`ParentFunctionalActive/RootDisjoint/DFSParentCorrect` hold.

`[deduction]` (row cases). Let `E` satisfy `I^{+}_{M_D}` and consider `E --D_i--> E'`.

- **Row 1 (`D_halt`, `S=∅`)**: `Globals_halt_absorb` preserves `Top'` shape per
  halting convention and `LowerStackPreservedExcept(∅)` gives `FrameEq'` for all
  live frames; `FrameLive/Parent` unchanged on preserved frames.
  `DFSParentCorrect` is preserved on any frames still considered, or the halting
  convention makes active-frame obligations vacuous if frames are cleared;
  the convention must be fixed consistently. `[needed strengthening]` terminal
  frame-clearing must state `Parent/FrameLive` behavior explicitly.

- **Rows 2,3,8,11,13,16,18 (terminal root/global halt, `S` terminal)**:
  `Terminal_ClearFrames := ∀x̄ ¬FrameLive'(x̄)`. Thus
  `ActiveNonRoot(E')` is empty and `ParentFunctionalActive(E')` holds
  vacuously. `RootDisjoint(E')` holds vacuously. No pop target is used except
  the root terminal branch itself.

- **Push rows 6,7,10,15 (`S={c̄,d̄}`)**: `ChildFrameBase` sets
  `FrameLive'(d̄)` and `Top'(d̄)`; `PushChildE/PushChildA` set `Parent'(d̄,c̄)`.
  `LowerStackPreservedExcept({c̄,d̄})` preserves `FrameEq'` for live
  `x̄ ∉ {c̄,d̄}`, hence preserves their `FrameLive/Parent`. The parent `c̄`
  remains live in all these rows (`SetParentBackE_Advance`/`SetParentBackA0/A1`
  keep `FrameLive'(c̄)` and preserve `Parent` of `c̄`). Therefore the only new
  active non-root frame is `d̄`, with unique parent `c̄`, and `c̄` is live:
  `Parent(d̄,c̄) ∧ FrameLive(c̄) ∧ ∀p̄(Parent(d̄,p̄)->p̄=c̄)`. Existing active
  non-root frames keep their unique live parent. Root frames remain root
  (no `Parent'` added to them). DFS path becomes `Top'(d̄)=d̄, Parent'(d̄,c̄),`
  followed by the old active path of `c̄`.

- **Pop/return rows 4,5,9,12,14,17,19 (`S={p̄,c̄}`)**: `FrameInactive'(c̄)`
  removes `c̄` from active non-root/root-live sets.
  `LowerStackPreservedExcept({p̄,c̄})` preserves `FrameEq'` for live
  `x̄ ∉ {p̄,c̄}`. The target `p̄` is live before and after (`MarkRet*On`
  preserves `FrameLive'(p̄)`) and its `Parent` field is preserved by
  `PreserveNonMarkerFields(p̄)`. The guard supplies `Parent(E,c̄,p̄)` (and in
  all these rows, `NonRoot(c̄)`/`Parent(c̄,p̄)` is explicit).
  By `ParentFunctionalActive(E)`, `p̄` is the unique live parent of `c̄`.
  No row assigns a new `Parent'` to any frame except `d̄` in push rows; pop rows
  do not create parent links. Therefore every remaining active non-root frame
  keeps its previous unique live parent, and `p̄` becomes the DFS top.

`[needed strengthening]` To make (3) fully formal, `I^{+}_{M_D}` should
include the **DFS active-path** clause:
```text
DFSPath(E) :=
  ∃!c̄ Top(E,c̄)
  ∧ FrameLive(E,c̄)
  ∧ (RootLive(E,c̄) ∨ ∃!p̄(Parent(E,c̄,p̄) ∧ FrameLive(E,p̄)))
  ∧ every FrameLive non-root frame is reachable by a unique finite Parent-chain
    to the unique RootLive frame and lies on/defines the intended stack discipline.
```
The weaker `I_{M_D}` text states "functional `Parent` on active non-root frames;
root-to-top active path discipline" but does not spell out the unique-parent
use in every pop guard; the row guards do include `Parent(c̄,p̄)`, so the proof
obligation is to show this is the same as the DFS-active parent.

### 3.3 Reachable falsifier shape

`[falsification]` Non-functional parent on active frames:
```text
I_{M_D}(E*) ∧ FrameLive(E*,c̄) ∧ Parent(E*,c̄,p1) ∧ Parent(E*,c̄,p2) ∧ p1!=p2.
```
Wrong pop target / broken DFS parent:
```text
I_{M_D}(E*) ∧ D_i(E*,c̄,p̄,...) is a pop row
∧ Parent(E*,c̄,p̄) ∧ (¬FrameLive(E*,p̄) ∨ DFS-active parent of c̄ in E* is q̄!=p̄).
```
Root/parent conflict:
```text
I_{M_D}(E*) ∧ FrameLive(E*,c̄) ∧ ¬∃p̄ Parent(E*,c̄,p̄) on active path interior,
or FrameLive(E*,c̄) ∧ Parent(E*,c̄,c̄).
```

### 3.4 Verdict for this obligation

`[deduction]` **Paper-level support, not discharged.** The 19-row discipline is
structurally compatible with preservation: only push rows create
`Parent'(d̄,c̄)` to a currently live top; only pop rows inactivate `c̄` and
retarget `Top'` to the supplied `p̄`; all other live frames are preserved by
`LowerStackPreservedExcept`. The remaining gap is a complete `I^{+}_{M_D}`
induction with an explicit `DFSPath` clause and consistent terminal
frame-clearing semantics. No explicit `I_{M_D}`-reachable falsifying witness
was found in the audited schema.
