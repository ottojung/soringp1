# Ford–Johnson framed DAG certificate, n=5

Front: `ford-johnson-framed-dag-n5-check` (falsifiable, independent audit).

## Question

Can an explicit permutation-framed strategy DAG certificate for the standard Ford–Johnson upper-bound procedure on n=5 be constructed per `docs/research-framed-certificate-frontier.md` §3 and verified sound by `scripts/check_framed_strategy.py`?

## Construction basis

I constructed an explicit permutation-framed comparison strategy in the verifier format (`compare`/`lt`/`gt`, each edge with `next` and slot `perm`) following the standard Ford–Johnson (merge-insertion) comparison schedule for `n=5` on initial slots `0..4` (identity initial frame):

1. Pairwise comparisons `(0,1)` and `(2,3)` to form pairs `(s1,l1)` and `(s2,l2)` with `s_i < l_i` (larger element is the pair winner, as in `scripts/upper_witness.py:fj_sort`).
2. Compare winners `l1,l2` to obtain ordered winner chain `w_a < w_b` with corresponding pair-losers `s_a < w_a`, `s_b < w_b`.
3. Insert `s_a` into `[w_a]` (known bound before `w_a`; no comparison needed on feasible branches).
4. Insert straggler slot `4` by binary search into the current chain `[s_a,w_a,w_b]`.
5. Insert `s_b` by binary search into the prefix of the current chain before `w_b` (Ford–Johnson bound).

The certificate is generated by an adaptive tree expansion over all 120 permutations consistent with each path (script logic prototyped in `/tmp/make_fj5_v3.py` during this run), with identity edge permutations on every arc. Because branches are split only when both outcomes are feasible, every compare node has two realizable outcomes; leaves are reached only when the propagated relations form a total order (as required/checked by the verifier).

This realizes the Ford–Johnson comparison procedure/upper bound for `n=5` as a sound framed strategy DAG in tree form. It does **not** implement the §3 rank-envelope *join* optimization (shared nodes via relaxed common windows/intersection after different insertion ranks); here states are not joined, so size is tree-sized rather than the O(n²)-node joined form discussed for all-`n`.

## Obstruction / confirmation

- **Confirmed (this instance):** an explicit, verifier-sound permutation-framed strategy DAG certificate following the standard Ford–Johnson procedure on `n=5` exists and is mechanically checkable, achieving height `F_FJ(5)=S(5)=7`.
- **Not achieved / remaining difficulty:** a joined rank-envelope DAG in the sense of §3 (sharing post-insertion states across different chosen ranks via the relaxed common invariant, with explicit nontrivial slot permutations/frames enabling intersection/meet) was not constructed. The difficulty is not soundness checking but **construction/correctness of the frame-and-boundary bookkeeping**: after inserting an element at different ranks the concrete slot layout differs, so a join requires (i) a canonical relabelling/frame per branch so that pending elements occupy comparable slots, and (ii) a proof that the intersected guaranteed relation preserves the exact relaxed rank windows needed for subsequent Jacobsthal insertions (including the odd/straggler case and the full recursive winner sort). Getting these lifted permutations and boundary widths wrong yields unsound joins; deriving them explicitly for FJ’s adaptive insertions is the substantive step §3 flags as needing independent frame/boundary review. For `n=5` the unjoined tree is small (239 nodes), so joining is unnecessary for verification but remains the open construction challenge for the all-`n` polynomial-size claim.
