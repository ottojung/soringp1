# Exec report: minimum size/conditions for nonzero defect in disjoint-union poset states

**Task:** fresh independent tack on previously blocked front `disjoint-union-defect-min-size`.

**Date:** 2026-11-17.

## 1. Definitions (model)

- Fixed adaptive comparison model as in `docs/problem.md`: `S(n)` is the minimum worst-case number of pairwise comparisons to sort `n` distinct labelled keys; equivalently `S(n)=F(∅_n)` for the partial-order minimax value
  `F(P)=0` if `P` is total, else `F(P)=1+min_{x∥y} max(F(P+x<y),F(P+y<x))` (`docs/upper-bound.md`, A24 correspondence).
- For a finite poset/state `P`, `e(P)` is the number of linear extensions, and
  `info(P)=⌈log₂ e(P)⌉` is the information (leaf-counting) lower bound, so `F(P) >= info(P)` (**literature/deduction**, standard decision-tree lower bound).
- **Information defect:** `d(P)=F(P)-info(P) >= 0` (integer). `d(P)>0` means the minimax/adversary cost strictly exceeds pure leaf counting at `P`.
- **Disjoint union (parallel composition):** for posets `A,B` on disjoint ground sets, `P=A ⫫ B` has all relations of `A`, all relations of `B`, and every cross pair incomparable (**definition**). Encoding invariant: when represented on concatenated labels, `B`'s successor bitmasks must be shifted by `|A|` (`docs/research-parallel-duality.md`).
- Combinatorial identity: `e(A ⫫ B)=C(|A|+|B|,|A|)·e(A)·e(B)` (**deduction**, interleaving count).
- **Chain merge factor:** `Merge(a,b)=C_a ⫫ C_b` where `C_k` is a `k`-chain. Let `M(a,b)=F(Merge(a,b))` be the exact minimax two-list merge cost and `δ(a,b)=M(a,b)-⌈log₂ C(a+b,a)⌉` its merge gap (since `e(Merge(a,b))=C(a+b,a)`). Certified values used below (`docs/research-structural-lower-bounds.md`, citing Hwang–Lin 1972; Stockmeyer–Yao 1980; Christen 1978; Murphy–Paull 1979): `M(1,b)=⌈log₂(b+1)⌉`; `M(a,b)=a+b-1` for `a <= b <= ⌊3a/2⌋+1`; other `M(a,b)` treated as uncertified here.

## 2. Falsifiable question (all-`n`)

For disjoint-union states `P=A ⫫ B`, determine the minimum total size `n=|A|+|B|` (and conditions) with nonzero information defect `d(P)>0`, and whether this yields any all-`n` structural/lower-bound/certificate consequence for `F`/`S(n)` or a clear obstruction.

## 3. Claim

**Claim (deduction + bounded experiment).**
1. **Minimum size is 6.** For every disjoint union `P=A ⫫ B` with `|A|+|B| <= 5`, `d(P)=0`. There exist disjoint unions with `|A|+|B|=6` and `d(P)=1`.
2. **Sufficient certified condition (chain-merge defect).** If `P=Merge(a,b)` is in the certified tape range `a <= b <= ⌊3a/2⌋+1`, then `d(P)=δ(a,b)=(a+b-1)-⌈log₂ C(a+b,a)⌉`. The smallest such nonzero case is `(a,b)=(2,4)`, `n=6`, `e=15`, `info=4`, `F=M(2,4)=5`, `d=1`.
3. **Necessary/actual `n=6` landscape (exhaustive over isomorphism-class pairs).** Among all disjoint unions `A ⫫ B` with total size 6 (all splits and all isomorphism classes of `A,B`), exactly 70 ordered class-pairs have `d(P)>0`, and in every case `d(P)=1`. These include chain-chain merges (e.g. `Merge(2,4)`) and also unions where a component has `e>1` (non-chain internal structure), e.g. splits `(1,5),(2,4),(3,3),(4,2),(5,1)` with various `(e(A),e(B))`.
4. **All-`n` consequence/obstruction:** this is a **local structural refinement only**. It shows the global information bound is not tight already at the smallest nontrivial parallel state size 6, so any exact/state-lower-bounding scheme that relies solely on `info(P)` is strictly dominated on some disjoint-union states (Theorem-B style block/merge tightening applies when certified). However, because `SORT-BOUND-U ∈ PSPACE` is already proved and `d(P)` is a state-level quantity (computing/using it does not by itself yield a uniform asymptotic exponent improvement or a certificate), no consequence for the uniform complexity of evaluating `S(n)` or for separating `SORT-BOUND-U` from P/NP follows. This identifies a finite obstruction to information-only pruning, not an all-`n` complexity separation.

## 4. Argument and computation

### 4.1 Deduction (certified chain merges)
For `Merge(a,b)=C_a ⫫ C_b`, cross pairs are exactly the incomparabilities between the two chains and `e=C(a+b,a)`. In the certified tape range `M(a,b)=a+b-1` (**literature**), hence
`d(Merge(a,b))=(a+b-1)-⌈log₂ C(a+b,a)⌉ = δ(a,b)` (**deduction**). Evaluating certified pairs of total size <= 6:
- `(1,1..5)`: `δ=0`; `(2,2),(2,3),(3,3)`: `δ=0`; `(2,4)`: `M=5`, `C(6,2)=15`, `⌈log₂ 15⌉=4`, `δ=1`.
Thus the smallest certified chain-merge defect is total size 6 at `(2,4)`.

### 4.2 Exhaustive computation (all disjoint-union class-pairs, `n <= 6`)
Script (inline, using repo scripts' poset machinery; successor-bitmask states, transitive-closure updates, DP linear-extension count, exact minimax `F`): for each `n<=6`, enumerate isomorphism-class representatives `A` of size `a`, `B` of size `b`, `a+b=n` via `scripts/benchmark_symmetry_quotients.py:quotient_classes`; form `P=A ⫫ B` via `scripts/parallel_module_probe.py:disjoint_union`; compute `e(P)`, `info(P)`, `F(P)`, record `d(P)>0`.

Results (**experiment**, deterministic):
- `n=1..5`: 0 strict disjoint-union pairs (`d(P)>0` none).
- `n=6`: 70 ordered class-pairs with `d(P)>0`, all with `d(P)=1`.

Representative `n=6` instances (split `a,b`; `e(A),e(B),e(P),info(P),F(P),d`):
- `(2,4; 1,1; 15,4,5,1)` — `C_2 ⫫ C_4 = Merge(2,4)`.
- `(1,5; 1,5; 30,5,6,1)` — isolated element union a 5-element poset with 5 extensions.
- `(3,3; 2,3; 120,7,8,1)` etc., covering all splits.

This establishes minimum total size 6 and exhibits conditions (a parallel state whose interleaving/counting underestimates minimax by 1 at that size); it does **not** enumerate labeled posets beyond class representatives.

## 5. Falsification attempts

- **Hypothesis H1 (defect appears earlier):** "some `A ⫫ B` with `|A|+|B| <= 5` has `d(P)>0`." Refuted by exhaustive class-pair check for `n<=5` (0 cases) and consistent with certified merge gaps being 0 there (**experiment/deduction**).
- **Hypothesis H2 (only chain-chain merges at minimum size):** "all `n=6` disjoint-union defects are `Merge(a,b)`." Refuted: 70 class-pairs include splits `(1,5),(2,4),(3,3)` with nontrivial `(e(A),e(B))` (non-chain components), though all share `d=1` (**experiment**).
- **Hypothesis H3 (large/unbounded defect at `n=6`):** not observed; every `n=6` case has `d=1` (**experiment**, bounded).
- **Scope falsification:** an all-`n` uniform-complexity consequence would require an asymptotic/state-count or certificate bridge; none is derived. The data give a finite-size phenomenon only, so claiming impact on `S(n)` evaluation complexity would be a model/error overreach (cf. `docs/problem.md` §"Realistic outcomes").

## 6. Consequence

- **Structural:** the information defect for disjoint-union (parallel) states first appears at total size 6. `info(P)` is exact for all parallel states up to size 5 but can be 1 below `F(P)` at size 6; merge/structural lower bounds (e.g. `ceil(log2 e)+δ` on certified factors, and block-local bounds as in `docs/research-structural-lower-bounds.md`) are the relevant tightening where applicable.
- **For `F/S(n)`:** a concrete, checkable obstruction to information-only local bounds on parallel subgames; motivates incorporating certified merge gaps/block defects in pruning. This does **not** change known exact values, asymptotic bounds, or the uniform complexity status of `SORT-BOUND-U`/`S(n)` (and cannot, by the separation barriers noted in project docs).
- **Open/next:** characterize for all `n` (or asymptotically) the minimum/typical `d(A ⫫ B)` beyond certified chain merges, and determine whether any controlled defect family yields a provable all-`n` search-space or certificate improvement (a different, stronger question than settled here).
