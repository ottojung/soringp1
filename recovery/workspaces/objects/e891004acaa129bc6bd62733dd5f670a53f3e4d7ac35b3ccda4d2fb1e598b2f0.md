## Single minimal failing formula/lemma

> **[open:CKS-AV-Δ_D/SYM-TOP] (push transitions must determine global `Top` uniqueness).**  
> In every push case, the written FO transition creates a fresh child top but does not constrain the previous top to become false. Concretely, `ChildFrameBase(d̄,c̄)` (§4) asserts `Top'(d̄)` but not `¬Top'(c̄)` / `∀z̄(Top'(z̄)->z̄=d̄)`; and `Δ_sort_pick_push`, `Δ_backE_rej_next`, `Δ_adv_push_A0`, `Δ_backA0_acc_push_A1` (§6.4,6.5,6.6,6.7) add `PushChildE/PushChildA` and `SetParentBackE_Advance`/`SetParentBackA0`/`SetParentBackA1`, none of which negate the old `Top(c̄)`. `LowerStackPreservedExcept(c̄)` preserves only relations for `FrameLive(z̄)∧z̄!=c̄`, so it does not constrain `Top'(c̄)`.  
> Therefore, for a state where `Top(c̄)` holds, a primed interpretation satisfying the written push disjunct may still have `Top'(c̄)` true alongside `Top'(d̄)`, violating `ExactlyOneTop`/`I_{M_D}.4` and breaking the claimed determinism/functionality and invariant preservation (§7.2–7.5).

**Explicit evidence (artifact text):**
- §4, `ChildFrameBase(d̄,c̄)`: `FrameLive'(d̄) ∧ Parent'(d̄,c̄) ∧ Top'(d̄) ∧ ∃b̄(CurBase(b̄)∧d̄=b̄) ∧ ∃b̄∃b̄'(CurBase(b̄)∧SuccCell(b̄,b̄')∧CurBase'(b̄')).`
- §6.4, `Δ_sort_pick_push`: `∃d̄(FreshChild(d̄) ∧ PushChildE(d̄,c̄,x,y)) ∧ SetParentBackE_Advance(c̄,x,y) ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack'∧LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).`
- §6.5, `Δ_backE_rej_next`: `∃d̄(FreshChild(d̄)∧PushChildE(d̄,c̄,x,y)) ∧ SetParentBackE_Advance(c̄,x,y) ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack'∧LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).`
- §6.6, `Δ_adv_push_A0`: `∃d̄(FreshChild(d̄)∧PushChildA(d̄,c̄,a,b,0)) ∧ SetParentBackA0(c̄) ... ∧ LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).`
- §6.7, `Δ_backA0_acc_push_A1`: `∃d̄(FreshChild(d̄)∧PushChildA(d̄,c̄,a,b,1)) ∧ SetParentBackA1(c̄) ... ∧ LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).`
- Contrast (pop is correctly determined): §3.1/3.4 `PopTo_base(p̄,c̄)` states `Top'(p̄) ∧ ∀z̄(Top'(z̄)->z̄=p̄) ...`.

**Minimal fix (formula-level, not claimed discharged here).** Add to `ChildFrameBase(d̄,c̄)` (or to every push case) `∧ ¬Top'(c̄) ∧ ∀z̄(Top'(z̄)->z̄=d̄)`, using the fact that `c̄` is the unique pre-state top in the applicable push cases. No change to local move semantics, DFS discipline, or A001035 avoidance is required.

## Final conclusion

`[open:CKS-AV-Δ_D/SYM]` is **not discharged as claimed**. The single minimal failing formula/lemma is **[SYM-TOP]**: push transitions must explicitly clear the previous `Top` and enforce `∀z̄(Top'(z̄)->z̄=d̄)` (or equivalent) so that `Top` uniqueness, determinism/functionality, and `I_{M_D}` preservation hold for the symbol-level `Δ_{M_D}^{sym}`. With that formula fix, the artifact’s realization would still remain a paper-level discharge conditional on the already stated inherited semantic equivalences (`M_D^alt`/alternating DFS/`M_G/G(n,k)` and `G(n,k)`/`S(n)`/`SORT-BOUND-U`), and it would not by itself constitute a complete end-to-end discharged FO(PFP)/IFP theorem or a concrete `δ_{M_D^alt}`.
