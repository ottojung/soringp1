# Obstruction: enumeration of reachable winning states is exponential in n (log n)^2

**Status:** barrier theorem (paper argument), independently auditable. Not Lean-checked. 
Labels: `[definition]`, `[literature]`, `[deduction]`, `[experiment]`.

**Model:** adaptive comparison sorting of distinct labeled keys (per AGENTS.md/problem.md). 
S(n)=min height of correct adaptive tree. SORT-BOUND-U = {1^n # 1^k : S(n) <= k}. 
Resources measured in actual input length N = n+k+1.

## Falsifiable question (single)
If a uniform algorithm A computes S(n) (or decides SORT-BOUND-U) by the following method class M_enum:
"A maintains or enumerates, explicitly or by producing a complete description that is in one-to-one correspondence with, all partial orders P reachable at some depth t on some root-optimal/near-optimal comparison strategy such that P is winning at budget k = O(n log n) (F(P) <= k-t), identified up to isomorphism or as labeled states counted with multiplicity >=n! per class",
is M_enum ruled out for uniform 2^(O(n log n)) time/space?

**Answer (consequence):** Yes for the stated class. The obstruction is not a lower bound on all algorithms, but a necessary condition violation for this family.

## Definitions
- State = transitively closed partial order P on n labeled elements (antichain P0 at root).
- e(P)=#linear extensions, L0(P)=ceil(log2 e(P)), F(P)=min worst-case further comparisons to sort extensions of P.
- k = C(n)+d(n)=ceil(log2 n!)+o(n) (and in particular k=S(n)+o(n) by Sergeev; at exact optimum k=S(n), d(n)=S(n)-C(n)>=0).
- P is reachable at depth t if obtainable by t comparison outcomes from P0.
- P is winning at budget k iff F(P) <= k-t.

## Proof sketch (from research-winning-frontier-barrier.md)
Take s=L=2^r, n=s^2. Build rectangular s-column × L-level chain family: t0 = s(L-1) known edges forming s disjoint chains; add m = k-t0-B extra edges between adjacent levels in all possible ways (M=(L-1)(s^2-s) possible), B = (s-1)+(n-1)ceil(log2 s) = O(n log n) the merge cost for s chains. 
For each subset A of m extra edges, P_A is reachable at t = t0+m = k-B and winning (F(P_A) <= B). All P_A are distinct as labeled posets. Each isomorphism class has size <= n!. 
With k = ceil(log2 n!)+o(n) (Sergeev), m = Θ(n log n), M/m = Θ(sqrt(n)/log n), and
log2 (number of nonisomorphic winning reachable states) >= m log2(M/m) - log2(n!) = (1/4 - o(1)) n (log2 n)^2.
At k=S(n) the o(n) surplus leaves the leading term unchanged (log2(M/m)=Θ(log n), contribution o(n log n)).

Finite witness: n=224, s=16,L=14 gives > 2^39 nonisomorphic winning reachable states at depth t=524 with remaining budget B=907, k=1431. Certified by tests/test_winning_frontier_barrier.py.

## Obstruction statement
Let Alg be a uniform algorithm that decides SORT-BOUND-U. Suppose for infinitely many n it enumerates (explicitly or by a complete description in one-to-one correspondence) all nonisomorphic reachable winning states at budget k=S(n). Then the list has size >= 2^((1/4-o(1)) n (log2 n)^2). For unary input length N = n+k+1 = O(n log n), this is 2^(Omega(N (log N)^2 / log log N)) which is super-polynomial in N. Thus M_enum is ruled out for uniform 2^(O(n log n)) time/space.

## What this does NOT rule out
- Selective minimax search / proof-number search that prunes without enumerating the frontier.
- Strong state compression/quotients that merge many winning states if equivalent for the minimax recurrence (separate question: root-reachable certified quotient).
- Symbolic/parametric recurrences or algorithms not listing states.
- General space/time lower bounds for all solvers; NP/PSPACE hardness separation alone.

## Concrete necessary condition
To stay in M_enum with uniform 2^(O(N log N)) time/space is impossible by the count. Any algorithm claiming to "examine" the frontier must do so implicitly.

## Residual gaps
- Quotient: can P_A merge into a polynomial/checkable quotient sufficient for root recurrence? (frontier question)
- Implicit representation: generating/counting without explicit listing?
- Effective finite threshold for exact S(n) is asymptotic; barrier is asymptotic.
- Transfer to succinct certificates: unclear.

## Deliverable
Proof sketch + definitions + finite witness + precise falsifier for enumeration class. Relevant to upper bounds on S(n)/SORT-BOUND-U without claiming class separation.
