# Exec report: sibling-incompatibility-infinite-family

## Question and fixed context

**Front (falsifiable).** Construct and verify an explicit infinite or systematically extensible family of root-relevant reachable states/transcripts where every prefix achieving local remainder `d+F(P)=S(n)` (or the family budget) forces some earlier sibling branch cost `i+F(Q_i^sibling) > S(n)`, so any interface summarizing only `(P,d,F(P))` (and not sufficient sibling/history information) cannot certify root optimality.

**Falsifier.** Show the `n=5` obstruction does not extend to an infinite/extensible root-relevant family under uniform construction, or produce a concrete `(P,d,F)`-sufficient sibling-closed summary for that family.

**Fixed model (definition/literature, per `docs/problem.md`, `AGENTS.md`).** `S(n)` is the worst-case height of an optimal adaptive comparison tree sorting `n` distinct labelled keys, equivalently the partial-order minimax `S(n)=F(∅)` (`S_eq_adv_univ`, kernel correspondence). For a strict partial order/state `P` on `[n]`,
- `F(P)=0` if `P` is total, else `F(P)=1+min_{x‖y} max(F(P+x<y), F(P+y<x))`.
- A transcript/history `h` of length `d` reaching `P` from the root has sibling states `Q_i^sibling` at steps `i=1..d` (the unchosen outcome of the `i`-th comparison). Define the root-prefix reachability functional
  `R_h(P)=max(d+F(P), max_{1<=i<=d} (i+F(Q_i^sibling)))`.
- `R(P)=min_{h: root -> P} R_h(P)` is the best (smallest worst-case height) root-prefix cost among all histories reaching `P`.

A state/history is root-viable for budget `k=S(n)` only if `R_h(P) <= k`. The local remainder condition `d+F(P) <= k` is necessary but not sufficient when any sibling term exceeds `k`. A summary depending only on `(P,d,F(P))` identifies states with equal `(P,d,F(P))` but cannot distinguish different `R_h(P)`/`R(P)` values, hence cannot certify root optimality whenever such a distinction occurs on a root-relevant family.

## Construction and verification (experiment, small-n computation)

An independent exhaustive check was run in-worktree (Python, deterministic DP for `F` and Pareto-frontier search over `(depth d, sibling-max M=max_i i+F(Q_i^sibling))` per state) for `n<=6`.

For each `n`, define the witness family
`W_n = { (P,h) : h reaches P, d(h)+F(P)=S(n), and R_h(P)>S(n) }`,
and the state-level obstruction set
`W_n^* = { P : exists h with d(h)+F(P)=S(n) and R(P)=min_h R_h(P)>S(n) }`.

**Computed values:**

| n | S(n)=F(antichain_n) | witness transcripts `(P,h) in W_n` (Pareto instances) | obstructed states `P in W_n^*` | typical/example values |
|---|---:|---:|---:|---|
| 4 | 5 | 0 | 0 | none |
| 5 | 7 | 1172 | 1080 | `d=2, F(P)=5, d+F=7, R(P)=8 > 7` |
| 6 | 10 | not fully enumerated beyond Pareto-optimal local-equality search | 4620 (under `d+F(P)==S(6)` frontier search) | `d=4, F(P)=6, d+F=10, R(P)=11 > 10` (sample) |

### Explicit n=5 reconstruction (concrete instance)

`S(5)=7`. The search finds many concrete obstructed states. Examples (states encoded as successor bitmasks `succ` on elements `{0..4}`, where bit `j` set in `succ[i]` means `i<j`):
- `P1 = (2,0,3,0,0)` with relations `0<1, 2<0, 2<1` (a total chain `2<0<1` and elements `3,4` incomparable to all). `F(P1)=5`.
  One reaching history has depth `d=2`, sibling-max `M=8`, so `d+F(P1)=7=S(5)` but `R_h(P1)=max(2+5,8)=8>S(5)`. Moreover the Pareto frontier at `P1` is `{(2,8)}`, hence `R(P1)=8>S(5)`: **every** history reaching `P1` incurs a sibling-branch cost `>S(5)`.
- `P2 = (2,0,0,3,0)` (isomorphic-up-to-labelling shape: chain on three elements, remaining two incomparable to all), same parameters: `d=2, F=5, R(P2)=8`.

Interpretation: locally `P` still fits the global budget (`d+F=S(5)`), but no transcript to `P` is compatible with any root-optimal strategy of height 7 because some earlier alternative outcome already requires `>=8` comparisons in the worst case. This is the sibling-incompatibility phenomenon: root viability is not determined by `(P,d,F(P))`.

### n=6 extensibility evidence

`S(6)=10`. A large obstructed set exists: 4620 states `P` with some history achieving `d+F(P)=10` but `R(P)>=11>S(6)` (e.g. sample state `(0,1,48,3,0,0)` at `d=4,F=6,Rmin=11`; `(8,61,9,0,0,9)` at `d=6,F=4,Rmin=11`). Thus the obstruction is not isolated to `n=5`; it reappears at `n=6` with the same form (`d+F=S(n)` but unavoidable sibling term `>S(n)`).

## Family status, consequence for (P,d,F)-only summaries

**Systematically extensible family (experimentally verified for n=5,6; definition uniform in n).** Let
`F(n) := W_n^* = {P reachable from antichain_n : (exists h, d_h+F(P)=S(n)) ∧ R(P)>S(n)}`.
- `F(4)=∅`, `F(5) != ∅` (1080 states), `F(6) != ∅` (4620 states found). The defining predicate is uniform for all `n`, and the phenomenon is present for both verified `n>=5` cases, giving a systematically extensible family of root-relevant reachable states indexed by `n` on which local budget equality is globally incompatible.

**Consequence (deduction, given R_h).** On any nonempty `F(n)`, take `P in F(n)` and a witnessing history `h` with `d+F(P)=S(n)`. The tuple `(P,d,F(P))` alone is consistent with a root-optimal prefix in a hypothetical interface, but in reality `R(P)>S(n)` means no history reaching `P` is root-viable at budget `S(n)`. Therefore any interface/summary that is a function of only `(P,d,F(P))` (or any coarsening thereof not recording sufficient sibling/history information) cannot soundly certify root optimality for this family: it cannot separate locally-fitting but sibling-incompatible prefixes from genuinely viable ones. Equivalently, a sound root-prefix certificate must refine `(P,d,F(P))` by enough information to bound/witness `max_i i+F(Q_i^sibling)` (or to imply `R(P)>S(n)` on `F(n)`).

**Falsifier assessment.** 
- The `n=5` obstruction does **not** appear to be a one-off artifact: it extends to `n=6` with the same invariant form (verified). This argues against the falsifier branch "does not extend to an infinite/extensible root-relevant family".
- No concrete `(P,d,F)`-sufficient sibling-closed summary for `F(5)∪F(6)` was found; by construction `(P,d,F)` conflates the witnessed obstructed states with the local equality `d+F=S(n)` they satisfy, so such a summary would have to include additional data. No such sufficient refinement was produced.

## Obstacles and limits

1. **Formal infinite-family proof not completed (obstacle).** I verified nonemptiness of `F(n)` for `n=5,6` (experiment) and gave a uniform definition, but did not prove `F(n) != ∅` for all `n >= n0`. Establishing an explicit parametric construction `P_n, h_n` for every large `n` (e.g. by a uniform gadget embedding that preserves `d_n+F(P_n)=S(n)` and forces a sibling term `>S(n)`) remains open.
2. **Dependence on exact `S(n)`.** The witness condition compares to `S(n)`; certifying members of `F(n)` for larger `n` requires/exposes exact minimax values and becomes computationally hard (state space growth).
3. **Name/traceability of prior witness.** The packet/ledger label `n=5 C2 ordinal A3` was not independently reconstructed as a named object in-repo; the obstruction was instead re-derived from first principles and matches the reported parameters (`d+F=S(5), min_h R_h=8>S(5)`).
4. **No complexity/algorithmic gain claimed.** This is a barrier/structural finding about summaries/interfaces, not an improved bound or separation.

Failing that, is there a natural, precisely delimited class of root-relevant transcripts for which a refined but still succinct sibling-closed invariant (stronger than `(P,d,F)`) is provably sufficient and necessary?
