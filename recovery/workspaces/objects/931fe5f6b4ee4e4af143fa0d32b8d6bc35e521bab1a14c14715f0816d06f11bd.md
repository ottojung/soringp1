**Not discharged.** The existing fix has the right proof shape
(whole-configuration root-to-top frame tuple, explicit `rlex` over fixed
`Lex2`/`SuccLex2`/`NextIncomp_c`, `bcost=k-UsedF`, finite control phases,

reachable state forms, so no single final `V`/`μ` is defined that makes all
required BackE transitions strictly decrease.

## Single minimal failing lemma / formula / case

> **[open:CKS-AV-MDALT-HALT.BACK_E_RANK] (consistent global BackE retry-cycle
> rank).** Give one explicit final per-frame rank `V` and global order used in
> every case such that, for all `I_{M_D}`-reachable non-halting
> `δ_{M_D^alt}^{sch}` steps, `μ(E') < μ(E)`, including the complete BackE
> retry cycle at the same modified frame index `j`:
>
> 1. **Pick / create wait.** `D_sort_pick` from
>    `M_Eval,RetNone,CtrlSort,NextIncomp_c(Cur; x,y)` with cursor rank
>    `r=rlex(Cur)` produces/keeps a `M_BackE,RetNone` waiting parent with
>    advanced stored cursor `r'=rlex(SuccLex2(x,y)) < r` (and pushes the
>    `CtrlAdv` E-child), so `V_j` strictly decreases at `j`.
> 2. **Child rejection enters retry-pending.** `D_eval_rej_ret` to that
>    waiting `M_BackE,RetNone` parent (stored cursor `r'`) pops the E-child
>    and marks the same BackE frame `M_BackE,RetRej,NextIncomp_c` with the
>    same `r'`; `V_j` strictly decreases at `j`.
> 3. **Retry advances cursor.** `D_backE_rej_next` from
>    `M_BackE,RetRej,NextIncomp_c` (cursor `r'`) selects `NextIncomp_c`,
>    advances by `SuccLex2` to `r''=rlex(SuccLex2(...)) < r'`, pushes the next
>    E-child, and sets the same BackE frame to `M_BackE,RetNone` with `r''`;
>    `V_j` strictly decreases at `j`.
> 4. **Exhaust / success / return edges.** `D_eval_rej_ret` to
>    `NoNextIncomp_c`, `D_eval_acc_ret` to `BackE`, `D_backE_acc_*`,
>    `D_backE_rej_exh_*`, and all parent return-pop interactions remain
>    strictly decreasing under the same final `V`.
>
> **Why the existing fix fails this lemma/formula.** In
> `fopfp-cks-av-mdalt-halt-fix.md` §3 the per-frame table gives
> `BackE,RetNone waiting -> ex=rlex(Cur'), ph=4` and
> `BackE,RetRej,NextIncomp -> ex=rlex(Cur), ph=3`, with
> `V=(bcost,q,ex,ph)`. Under that table:
> - step (2) is plausible as `(k-b,0,r',4) -> (k-b,0,r',3)`;
> - step (3) is **not** a decrease: `(k-b,0,r',3)` would compare to
>   `(k-b,0,r'',4)` and increases by `ph` (`3<4`) even though `r''<r'`.
>
> §6 rows/paragraph 278–282 attempt a correction
> (`BackE,RetRej,next ph=3 -> BackE,RetNone after advance ph=2`; `CtrlSort
> ph=6 -> BackE,RetNone after advance ph=2`; and `BackE,RetNone waiting ph=4`
> in the surrounding text), but the §3 table is not replaced by one final
> consistent table, and `D_sort_pick`/return-pop rows then refer to
> contradictory `BackE,RetNone` ranks. The fix therefore contains an
> inconsistent `pi/ph`/`ex` formula, not a complete discharged proof.

A routine repair shape (example, **not** claimed discharged here) is to use
one global order where the cycling BackE cursor rank dominates the BackE
retry subphase, e.g. compare `(bcost,q,rlex,BackEPhase,phRest)` with
`BackEPhase(wait,r)=2 > BackEPhase(rej-next,r)=1 > BackEPhase(wait,r'')=2`
decided by `rlex` first (`r > r''`) and a fixed finite local phase second for
equal `rlex`; `CtrlSort(pick,r)` must map to a state strictly below
`(r,·)`/above the chosen wait form consistently. Any repair must be given as
**one final table + one final tuple order** and rechecked against every
non-halting `D_*`.
