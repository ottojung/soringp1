## (1) `CtrlSort` `NoNextIncomp_c` exhaustivity: text/case placement

### Easy text/schema fix

`[definition]` (case-matrix §1/§3, formula-check §6.5). The audit found a
misleading explanation: row 6 (`D_sort_pick`) requires `NextIncomp_c` and does
**not** consume `NoNextIncomp_c`. The correct closure is:
```text
CtrlSortNoNextReject_c :=
  M_Eval(c̄) ∧ CtrlSort(c̄) ∧ RetNone(c̄) ∧ ¬Total_c ∧ Budget_c
  ∧ NoNextIncompAtCur_c
  -> RejectEval_c.
```
with
```text
RejectEval_c :=
    CfgRej_c
  ∨ (CtrlSort(c̄) ∧ ¬Total_c ∧ ¬Budget_c)
  ∨ (CtrlSort(c̄) ∧ ¬Total_c ∧ Budget_c ∧ NoNextIncompAtCur_c).
NoNextIncompAtCur_c := ∃a∃b(CurA(c̄,a) ∧ CurB(c̄,b) ∧ NoNextIncomp_c(a,b)).
```

**Replacement text (obligation, easy).** Replace case-matrix §3.3’s parenthetical
with:
> On an `I_{M_D}`-reachable `M_Eval, CtrlSort, RetNone, ¬Total_c, Budget_c` top,
> either `NextIncompAtCur_c` (row 6, `D_sort_pick`) or `NoNextIncompAtCur_c`
> (hence `RejectEval_c`: row 3 `D_root_rej` if `Root(c̄)`, row 5
> `D_eval_rej_ret` if `NonRoot(c̄)`).

### Precise closure obligation

`[open][lemma CtrlSort_Exhaustive_On_IMD]`
For every `I_{M_D}`-reachable `E` with unique `Top(c̄)` and
`Guard_pre := ¬HaltAcc(E)∧¬HaltRej(E)∧M_Eval(c̄)∧CtrlSort(c̄)∧RetNone(c̄)`:
```text
Guard_pre(E) -> (CfgAcc_c(E) ∨ RejectEval_c(E)
              ∨ (¬Total_c(E) ∧ Budget_c(E) ∧ NextIncompAtCur_c(E))).
```
Moreover `CfgAcc_c, RejectEval_c, (¬Total_c ∧ Budget_c ∧ NextIncompAtCur_c)` are
pairwise disjoint on `I_{M_D}`-reachable `Guard_pre` states.

### Explicit falsifier witness shape

`[falsification]` A reachable witness `E*` with
```text
I_{M_D}(E*) ∧ Top(E*,c̄) ∧ M_Eval(c̄) ∧ CtrlSort(c̄) ∧ RetNone(c̄)
∧ ¬Total_c(E*) ∧ Budget_c(E*) ∧ ¬NextIncompAtCur_c(E*) ∧ ¬RejectEval_c(E*),
```
or, equivalently, `NoNextIncompAtCur_c(E*)` but no root/non-root eval-reject row
fires because `RejectEval_c` omits the no-next branch or places it in a
non-consuming/incompatible case. This blocks exhaustivity of the guard matrix.

## (3) BackE `SetParentBackE_Advance` last-pair/cursor-after-selected convention and NI/NNI complement on consuming `M_BackE + RetRej` top

### Easy normalization (schema)

`[definition]` Fix the cursor convention relative to the **selected** pair
`(x,y)` (not the pre-search cursor):
```text
NextIncomp_c(a,b;x,y) := Lex2(a,b,x,y) ∧ Incomp_c(x,y)
                       ∧ ¬∃u∃v(Lex2(a,b,u,v) ∧ Lex2(u,v,x,y) ∧ Incomp_c(u,v)).
NoNextIncomp_c(a,b)   := ¬∃x∃y(Lex2(a,b,x,y) ∧ Incomp_c(x,y)).
```
`NextIncomp_c` is functional in `(x,y)` given fixed `(a,b),PosF(c̄)`.

Advance stores the search position *after* the just-selected `(x,y)`:
```text
AfterSelected(x,y,x',y') :=
     (SuccLex2(x,y,x',y'))
   ∨ (IsLastLex2(x,y) ∧ BackE_NoFurther(x',y')),

BackE_NoFurther(x',y') := SentinelLast(x',y')  -- fixed sentinel in Cell×Cell encoding
                          (or equivalent NoNextIncomp-forcing cursor state).

SetParentBackE_Advance(c̄,x,y) :=
    FrameLive'(c̄)
  ∧ M_BackE'(c̄) ∧ ¬M_Eval'(c̄) ∧ ¬M_BackA0'(c̄) ∧ ¬M_BackA1'(c̄)
  ∧ RetNone'(c̄) ∧ ¬RetAcc'(c̄) ∧ ¬RetRej'(c̄)
  ∧ CtrlSort'(c̄) ∧ ¬CtrlAdv'(c̄) ∧ ¬CtrlAcc'(c̄) ∧ ¬CtrlRej'(c̄)
  ∧ HasCur'(c̄)
  ∧ ∃x'∃y'(AfterSelected(x,y,x',y') ∧ CurA'(c̄,x') ∧ CurB'(c̄,y'))
  ∧ ∀a∀a'(CurA'(c̄,a)∧CurA'(c̄,a')->a=a')
  ∧ ∀b∀b'(CurB'(c̄,b)∧CurB'(c̄,b')->b=b')
  ∧ (HasSel'(c̄)<->HasSel(c̄))
  ∧ ∀a(SelA'(c̄,a)<->SelA(c̄,a)) ∧ ∀b(SelB'(c̄,b)<->SelB(c̄,b))
  ∧ ∀t(UsedF'(c̄,t)<->UsedF(c̄,t))
  ∧ ∀u∀v(PosF'(c̄,u,v)<->PosF(c̄,u,v))
  ∧ ∀p̄(Parent'(c̄,p̄)<->Parent(c̄,p̄)).
```
`[deduction]` This replaces the ambiguous “keep last” normalization with an
explicit sentinel/no-further state so selecting the last lex pair cannot
produce a reachable `M_BackE∧RetRej∧NextIncompAtCur` that reselects `(x,y)`.

Consuming BackE reject split:
```text
BackE_RetRej_Top(c̄) := Top(c̄) ∧ FrameLive(c̄) ∧ M_BackE(c̄) ∧ RetRej(c̄).
NI_p  := ∃a∃b(CurA(p̄,a)∧CurB(p̄,b)∧NextIncomp_p(a,b;x,y)).
NNI_p := ∃a∃b(CurA(p̄,a)∧CurB(p̄,b)∧NoNextIncomp_p(a,b)).
D_backE_rej_next      consumes BackE_RetRej_Top(p̄) ∧ NI_p.
D_backE_rej_exh_root  consumes BackE_RetRej_Top(p̄) ∧ NNI_p ∧ Root(p̄).
D_backE_rej_exh_ret   consumes BackE_RetRej_Top(p̄) ∧ NNI_p ∧ NonRoot(p̄).
```
Pop+mark effect (from `D_eval_rej_ret` to `M_BackE` parent, formula-check §4.1):
```text
PopTo_base(p̄,c̄) ∧ MarkRetRejOn(p̄)
=> Top'(p̄) ∧ M_BackE'(p̄) ∧ RetRej'(p̄)
 ∧ CurA'(p̄,·)=CurA(p̄,·) ∧ CurB'(p̄,·)=CurB(p̄,·)
 ∧ PosF'(p̄,·,·)=PosF(p̄,·,·) ∧ UsedF'(p̄,·)=UsedF(p̄,·).
```

### Precise closure obligations

`[open][lemma BackE_Cursor_Preservation]`
If `D_eval_rej_ret` (or any BackE-reject-producing pop row) produces
`Top'(p̄), M_BackE'(p̄), RetRej'(p̄)` from an `I_{M_D}`-reachable state, then
`HasCur',CurA',CurB',PosF',UsedF',HasSel',SelA',SelB',Parent'` of `p̄` are
exactly as preserved by `PreserveNonMarkerFields(p̄)` and no other row mutates
`p̄` before the next consuming BackE `RetRej` step.

`[open][lemma BackE_NI_NNI_Total_Complement]`
For every `I_{M_D}`-reachable `E` with `BackE_RetRej_Top(E,p̄)`:
```text
∃!a∃!b(CurA(p̄,a)∧CurB(p̄,b))
∧ (NI_p(E) xor NNI_p(E))
∧ (NI_p(E) -> ∃!x∃!y NextIncomp_p(a,b;x,y)).
```

`[open][lemma BackE_AfterSelected_NoReselect]`
For row 6 or 10 selecting `(x,y)` by `NextIncomp_p(a,b;x,y)` and applying
`SetParentBackE_Advance(p̄,x,y)`, any later `I_{M_D}`-reachable consuming state
`Top(p̄),M_BackE(p̄),RetRej(p̄)` has cursor `(x',y')=Cur'(p̄)` with
```text
NI_p(x*,y*) -> Lex2(x,y,x*,y*) ∧ (x*,y*) != (x,y)
```
(or `NNI_p`), including the `IsLastLex2(x,y)` sentinel case.

### Explicit falsifier witness shapes

`[falsification]` BackE cursor NI/NNI gap/loop:
```text
I_{M_D}(E) ∧ Top(E,p̄) ∧ M_BackE(p̄) ∧ RetRej(p̄)
∧ ¬NI_p(E) ∧ ¬NNI_p(E)
```
(non-total cursor), or
```text
I_{M_D}(E) ∧ Top(E,p̄) ∧ M_BackE(p̄) ∧ RetRej(p̄)
∧ NI_p(E,x,y) ∧ NNI_p(E)
```
(non-exclusive), or a last-pair loop
```text
IsLastLex2(x,y) ∧ SetParentBackE_Advance(p̄,x,y) ⊢* Top(p̄)∧M_BackE(p̄)∧RetRej(p̄)
∧ NI_p(x,y)
```
(reselects just-tried last pair). Any such reachable witness falsifies
determinism/exhaustivity or no-spurious BackE retry at this locus.

## (4) Marker-receiver reachability lemmas/falsifier shapes

### Precise obligations

`[definition]` Marker primitives (normalized, Back* receivers only):
```text
PreserveNonMarkerFields(p̄) := preserve Mode,Ctrl,HasSel/HasCur,Sel*,Cur*,UsedF,PosF,Parent,FrameLive.
MarkRetAccOn(p̄) := RetAcc'(p̄)∧¬RetRej'(p̄)∧¬RetNone'(p̄)∧PreserveNonMarkerFields(p̄).
MarkRetRejOn(p̄) := RetRej'(p̄)∧¬RetAcc'(p̄)∧¬RetNone'(p̄)∧PreserveNonMarkerFields(p̄).
PopTo_base(p̄,c̄) := Top(c̄)∧Parent(c̄,p̄)∧FrameLive(c̄)∧FrameLive(p̄)
                   ∧Top'(p̄)∧¬Top'(c̄)∧∀z(Top'(z)->z=p̄)
                   ∧FrameInactive'(c̄)∧CurBaseUnchanged
                   ∧LowerStackPreservedExcept({p̄,c̄}).
```

`[open][lemma MarkerReceiver_Is_BackStar]`
Every non-root eval return row `D_eval_acc_ret`/`D_eval_rej_ret` from an
`I_{M_D}`-reachable state has a parent `p̄` satisfying:
```text
Parent(c̄,p̄) -> (M_BackE(p̄) ∨ M_BackA0(p̄) ∨ M_BackA1(p̄)).
```
Consequently `MarkRet*On` is applied only to Back* frames and preserves a
matrix-consumable `Mode'(p̄)`.

`[open][lemma No_Eval_RetMarker_Top]`
No `I_{M_D}`-reachable consuming state has
```text
Top(c̄) ∧ M_Eval(c̄) ∧ (RetAcc(c̄) ∨ RetRej(c̄)).
```

`[open][lemma No_BackStar_RetNone_Consuming_Top]`
No `I_{M_D}`-reachable state requires a return-consuming matrix row from
```text
Top(c̄) ∧ (M_BackE(c̄)∨M_BackA0(c̄)∨M_BackA1(c̄)) ∧ RetNone(c̄).
```
(If such a state is reachable but non-consuming under a refined invariant, state
the invariant; otherwise it is an exhaustivity gap.)

### Explicit falsifier witness shapes

`[falsification]` Eval+Ret marker top:
```text
I_{M_D}(E*) ∧ Top(E*,c̄) ∧ M_Eval(c̄) ∧ (RetAcc(c̄)∨RetRej(c̄)).
```
Falsifies mode/return separation and may make `MarkRet*On`/eval guards overlap or
leave `E*` underdetermined.

`[falsification]` Back*+`RetNone` consuming top:
```text
I_{M_D}(E*) ∧ Top(E*,c̄) ∧ (M_BackE∨M_BackA0∨M_BackA1)(c̄) ∧ RetNone(c̄)
∧ no D_i guard consumes E* (or two guards consume it).
```
Falsifies matrix exhaustivity/mutual-exclusion on the reachable orbit.

`[falsification]` Non-Back* marker receiver:
```text
I_{M_D}(E) ∧ D_eval_{acc,rej}_ret(E,c̄,p̄) ∧ M_Eval(p̄).
```
After `MarkRet*On(p̄)`, `Mode'(p̄)=M_Eval` with `RetAcc/RetRej` creates the
Eval+RetMarker falsifier shape above (or an unmodeled state).

## (5) A1 preserved snapshot, `FreshChild` allocator freshness, `Parent` functional on active non-root frames

### A1 preserved snapshot

`[definition]` (case-matrix rows 7,15; realization `D_adv_push_A0/D_backA0_acc_A1`):
```text
SetParentBackA0(c̄) := M_BackA0'(c̄)∧RetNone'(c̄)∧FrameLive'(c̄)
  ∧ HasSel'(c̄)∧SelA'(c̄,a)∧SelB'(c̄,b)    -- same selected (a,b)
  ∧ HasCur'(c̄)∧CurA'(c̄,·)=CurA(c̄,·)∧CurB'(c̄,·)=CurB(c̄,·)
  ∧ PosF'(c̄,·,·)=PosF(c̄,·,·) ∧ UsedF'(c̄,·)=UsedF(c̄,·)
  ∧ Parent'(c̄,·)=Parent(c̄,·).

SetParentBackA1(c̄) := M_BackA1'(c̄)∧RetNone'(c̄)∧FrameLive'(c̄)
  ∧ same preserved HasSel/SelA/SelB/HasCur/CurA/CurB/PosF/UsedF/Parent as c̄.

D_backA0_acc_A1 consumes Top(c̄)∧M_BackA0(c̄)∧RetAcc(c̄)∧HasSel(c̄)∧SelA(c̄,a)∧SelB(c̄,b)
  and performs PushChildA(d̄,c̄,a,b,1) with SetParentBackA1(c̄),
  reading PosF/UsedF/Sel from c̄ (preserved parent snapshot), never from A0 child.
```

`[open][lemma A1_Snapshot_From_Parent]`
For every `I_{M_D}`-reachable row-15 state, the `(b,a)` child is constructed
from `PosF(c̄), UsedF(c̄), SelA(c̄,a), SelB(c̄,b)` of the A0 parent `c̄` after
`MarkRetAccOn/PopTo_base` has made `c̄` top with `M_BackA0,RetAcc`, and
`LowerStackPreservedExcept`/`SetParentBackA1` ensure no A0-child field is read.

`[falsification]` A1 snapshot aliasing:
```text
Reachable execution uses PosF/UsedF/Sel from popped A0 child d̄ (or mutated
post-A0 state) to build PushChildA(_,_,a,b,1), yielding StepPosBit/PostBudgetFrom
on a state other than the preserved A0 parent snapshot.
```

### FreshChild allocator freshness

`[definition]`
```text
FreshChild(d̄) := CurBase(d̄).
Push requires: FrameLive'(d̄) ∧ Top'(d̄) ∧ Parent'(d̄,c̄) ∧ CurBaseBump.
Pop/Halt-no-push: CurBaseUnchanged.
```

`[open][lemma FreshChild_Fresh_On_IMD]`
On every `I_{M_D}`-reachable push row,
```text
CurBase(d̄) -> ¬FrameLive(d̄) ∧ ∀x̄(FrameLive(x̄) -> x̄!=d̄)
            ∧ ∀x̄(Parent(x̄,·)∨Parent(·,x̄) on active stack -> x̄!=d̄ as aliasing conflict impossible).
```
Equivalently, `CurBase` is a monotone/never-reused allocator over the active
and preserved-relevant cell namespace under the fixed DFS discipline.

`[falsification]` Allocator reuse/alias:
```text
I_{M_D}(E) ∧ push guard D_i(E) ∧ CurBase(E,d̄) ∧ (FrameLive(E,d̄) ∨ FrameEq'-required preserved frame aliases d̄).
```
This would corrupt lower-stack preservation or parent links.

### Parent functional on active non-root frames

`[definition]`
```text
NonRoot(c̄) := FrameLive(c̄) ∧ ∃p̄ Parent(c̄,p̄).
ParentFunctionalActive :=
  ∀c̄(NonRoot(c̄) -> ∃!p̄ Parent(c̄,p̄) ∧ FrameLive(p̄)).
Root(c̄) := FrameLive(c̄) ∧ ¬∃p̄ Parent(c̄,p̄).
```
Push sets `Parent'(d̄,c̄)` for fresh `d̄`; pop sets `FrameInactive'(c̄)` and does
not grant `c̄` new children; preserved frames keep `Parent` by `FrameEq'`.

`[open][lemma Parent_Functional_Active_Preserved]`
`I_{M_D}(E) -> ParentFunctionalActive(E)` is preserved by every matrix row, and
every `NonRoot(c̄)` pop row has the unique DFS parent `p̄` of `c̄` as its
`PopTo_base` target.
