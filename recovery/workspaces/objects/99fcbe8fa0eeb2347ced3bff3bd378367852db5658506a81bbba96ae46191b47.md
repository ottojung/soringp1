## 2. Canonical formula schemas

### 2.1 Frame field equality and inactivity

`[definition]` Let the stored frame-field signature be
```text
Fld(c̄) := ⟨ Mode(c̄), Ret(c̄), Ctrl(c̄),
             UsedF(c̄,·), HasSel(c̄), SelA(c̄,·), SelB(c̄,·),
             HasCur(c̄), CurA(c̄,·), CurB(c̄,·),
             PosF(c̄,·,·), Parent(c̄,·) ⟩
```
where `Mode(c̄)` abbreviates the four mode bits
`M_Eval/M_BackE/M_BackA0/M_BackA1`, `Ret(c̄)` the three return bits, and
`Ctrl(c̄)` the four control bits (or the case's explicit control reading).

```text
FrameFieldsEq'(x̄) :=
    (M_Eval'(x̄)<->M_Eval(x̄)) ∧ (M_BackE'(x̄)<->M_BackE(x̄))
  ∧ (M_BackA0'(x̄)<->M_BackA0(x̄)) ∧ (M_BackA1'(x̄)<->M_BackA1(x̄))
  ∧ (RetNone'(x̄)<->RetNone(x̄)) ∧ (RetAcc'(x̄)<->RetAcc(x̄)) ∧ (RetRej'(x̄)<->RetRej(x̄))
  ∧ (CtrlSort'(x̄)<->CtrlSort(x̄)) ∧ (CtrlAdv'(x̄)<->CtrlAdv(x̄))
  ∧ (CtrlAcc'(x̄)<->CtrlAcc(x̄)) ∧ (CtrlRej'(x̄)<->CtrlRej(x̄))
  ∧ (HasSel'(x̄)<->HasSel(x̄)) ∧ (HasCur'(x̄)<->HasCur(x̄))
  ∧ ∀t(UsedF'(x̄,t)<->UsedF(x̄,t))
  ∧ ∀a(SelA'(x̄,a)<->SelA(x̄,a)) ∧ ∀b(SelB'(x̄,b)<->SelB(x̄,b))
  ∧ ∀a(CurA'(x̄,a)<->CurA(x̄,a)) ∧ ∀b(CurB'(x̄,b)<->CurB(x̄,b))
  ∧ ∀u∀v(PosF'(x̄,u,v)<->PosF(x̄,u,v))
  ∧ ∀p̄(Parent'(x̄,p̄)<->Parent(x̄,p̄)).

FrameEq'(x̄) := FrameFieldsEq'(x̄) ∧ (FrameLive'(x̄) <-> FrameLive(x̄)).
FrameInactive'(x̄) := ¬FrameLive'(x̄).
```

`[deduction]` `FrameInactive'` is a normalization of SYM's `¬FrameLive'`.
`FrameEq'` must **not** be used for popped frames (`FrameLive` becomes false)
and must **not** be used as a blanket statement when a case changes selected
non-marker fields of `p̄`; in such cases use the explicit field clauses.

### 2.2 Lower-stack preservation

`[definition]` (canonical set form)
```text
LowerStackPreservedExcept(S) :=
  ∀x̄( FrameLive(x̄) ∧ ¬S(x̄)  ->  FrameEq'(x̄) ).
```

Specializations:
```text
SYM singleton:      LowerStackPreservedExcept({c̄}).
Pop return:         LowerStackPreservedExcept({p̄,c̄}).
Push (E/A/A1):      LowerStackPreservedExcept({c̄,d̄}).
Halt / NoActiveFrames': global terminal update; no LowerStackPreservedExcept obligation.
```

`[deduction]` SYM's singleton form implies `FrameLive'(z̄)` for preserved live
`z̄!=c̄` because `FrameEq'` preserves `FrameLive`. The case-matrix wrote
`FrameEq'(x̄)∧FrameLive'(x̄)` redundantly; either form is equivalent given the
`FrameEq'` definition above.

### 2.3 `PopTo_base`

`[definition]` Canonical pop schema:
```text
PopTo_base(p̄,c̄) :=
    Top(c̄) ∧ Parent(c̄,p̄) ∧ FrameLive(c̄) ∧ FrameLive(p̄)
  ∧ Top'(p̄) ∧ ¬Top'(c̄) ∧ ∀z̄(Top'(z̄)->z̄=p̄)
  ∧ FrameInactive'(c̄)
  ∧ CurBaseUnchanged
  ∧ LowerStackPreservedExcept({p̄,c̄}).

CurBaseUnchanged := ∃b̄(CurBase(b̄) ∧ CurBase'(b̄)).
```

`[deduction]` This is consistent with SYM `PopTo_base` plus `[SYM-TOP]`'s
already-correct pop `Top` uniqueness (`Top'(p̄) ∧ ∀z̄(Top'(z̄)->z̄=p̄)`), and
with realization/case-matrix intent. The set `{p̄,c̄}` is required because
`MarkRet*On(p̄)` mutates `p̄` return bits; `c̄` becomes inactive.

### 2.4 `MarkRetAccOn` / `MarkRetRejOn`

`[definition]` Primitive return-marker updates (applied only to a designated
frame `p̄` that is a live Back* receiver in the corresponding case):
```text
PreserveNonMarkerFields(p̄) :=
    (M_Eval'(p̄)<->M_Eval(p̄)) ∧ (M_BackE'(p̄)<->M_BackE(p̄))
  ∧ (M_BackA0'(p̄)<->M_BackA0(p̄)) ∧ (M_BackA1'(p̄)<->M_BackA1(p̄))
  ∧ (CtrlSort'(p̄)<->CtrlSort(p̄)) ∧ (CtrlAdv'(p̄)<->CtrlAdv(p̄))
  ∧ (CtrlAcc'(p̄)<->CtrlAcc(p̄)) ∧ (CtrlRej'(p̄)<->CtrlRej(p̄))
  ∧ (HasSel'(p̄)<->HasSel(p̄)) ∧ (HasCur'(p̄)<->HasCur(p̄))
  ∧ ∀t(UsedF'(p̄,t)<->UsedF(p̄,t))
  ∧ ∀a(SelA'(p̄,a)<->SelA(p̄,a)) ∧ ∀b(SelB'(p̄,b)<->SelB(p̄,b))
  ∧ ∀a(CurA'(p̄,a)<->CurA(p̄,a)) ∧ ∀b(CurB'(p̄,b)<->CurB(p̄,b))
  ∧ ∀u∀v(PosF'(p̄,u,v)<->PosF(p̄,u,v))
  ∧ ∀q̄(Parent'(p̄,q̄)<->Parent(p̄,q̄))
  ∧ FrameLive'(p̄).

MarkRetAccOn(p̄) :=
  RetAcc'(p̄) ∧ ¬RetRej'(p̄) ∧ ¬RetNone'(p̄) ∧ PreserveNonMarkerFields(p̄).

MarkRetRejOn(p̄) :=
  RetRej'(p̄) ∧ ¬RetAcc'(p̄) ∧ ¬RetNone'(p̄) ∧ PreserveNonMarkerFields(p̄).
```

`[deduction]` This matches SYM's explicit marker formulas and realization's
`D_eval_acc_ret`/`D_eval_rej_ret`. The `LowerStackPreservedExcept({p̄,c̄})`
clause in `PopTo_base` gives no automatic `FrameEq'(p̄)`; therefore
`MarkRet*On(p̄)` must supply all intended preserved/changed `p̄` fields.

### 2.5 BackE cursor local formulas

`[definition]` (SYM/realization/local semantics)
```text
SuccLex2(x,y,x',y') :=
  Key(x)∧Key(y)∧Key(x')∧Key(y')∧Lex2(x,y,x',y')∧
  ¬∃u∃v(Key(u)∧Key(v)∧Lex2(x,y,u,v)∧Lex2(u,v,x',y')).

NextIncomp_c(a,b;x,y) :=
  Lex2(a,b,x,y) ∧ Incomp_c(x,y) ∧
  ¬∃u∃v(Lex2(a,b,u,v) ∧ Lex2(u,v,x,y) ∧ Incomp_c(u,v)).

NoNextIncomp_c(a,b) :=
  ¬∃x∃y(Lex2(a,b,x,y) ∧ Incomp_c(x,y)).

NextIncompAtCur_c(x,y) :=
  ∃a∃b(CurA(c̄,a)∧CurB(c̄,b)∧NextIncomp_c(a,b;x,y)).

NoNextIncompAtCur_c :=
  ∃a∃b(CurA(c̄,a)∧CurB(c̄,b)∧NoNextIncomp_c(a,b)).
```

`[deduction]` For fixed `a,b` and fixed `PosF(c̄,·,·)`,
`NextIncomp_c(a,b;x,y)` is functional in `(x,y)` when it holds (lex minimum),
and `NoNextIncomp_c(a,b)` is its negated existential complement. Thus
`NextIncompAtCur_c` and `NoNextIncompAtCur_c` are mutually exclusive given
unique `CurA/CurB`.

### 2.6 `SetParentBackE_Advance`

`[definition]` Canonical BackE parent transition for a sort-pick / retry push
from current top `c̄`, after selecting incomparable `(x,y)` by
`NextIncomp_c(CurA,CurB;x,y)`:
```text
SetParentBackE_Advance(c̄,x,y) :=
    FrameLive'(c̄)
  ∧ M_BackE'(c̄) ∧ ¬M_Eval'(c̄) ∧ ¬M_BackA0'(c̄) ∧ ¬M_BackA1'(c̄)
  ∧ RetNone'(c̄) ∧ ¬RetAcc'(c̄) ∧ ¬RetRej'(c̄)
  ∧ CtrlSort'(c̄) ∧ ¬CtrlAdv'(c̄) ∧ ¬CtrlAcc'(c̄) ∧ ¬CtrlRej'(c̄)
  ∧ HasCur'(c̄)
  ∧ (  (∃x'∃y' SuccLex2(x,y,x',y') ∧ CurA'(c̄,x') ∧ CurB'(c̄,y'))
     ∨ (IsLastLex2(x,y) ∧ CurA'(c̄,x) ∧ CurB'(c̄,y)) )
  ∧ ∀a∀a'(CurA'(c̄,a)∧CurA'(c̄,a')->a=a')
  ∧ ∀b∀b'(CurB'(c̄,b)∧CurB'(c̄,b')->b=b')
  ∧ (HasSel'(c̄)<->HasSel(c̄))
  ∧ ∀a(SelA'(c̄,a)<->SelA(c̄,a)) ∧ ∀b(SelB'(c̄,b)<->SelB(c̄,b))
  ∧ ∀t(UsedF'(c̄,t)<->UsedF(c̄,t))
  ∧ ∀u∀v(PosF'(c̄,u,v)<->PosF(c̄,u,v))
  ∧ ∀p̄(Parent'(c̄,p̄)<->Parent(c̄,p̄)).
```

`[open]` **Cursor-at-last normalization.** SYM states `SuccLex2(x,y,·,·)` or
keeps last; the case matrix says “adjusted to last if needed”. The branch
`IsLastLex2(x,y) ∧ CurA'(c̄,x) ∧ CurB'(c̄,y)` is a deterministic
normalization, but it is only safe if no future `NextIncompAtCur_c` can be
required after selecting the last lex pair. Under `I_{M_D}` search discipline,
selecting `(x,y)=last` means no strict successor exists, so the subsequent
BackE reject return can only take `NoNextIncompAtCur_c` (or is otherwise
unreachable). This is a proof obligation, not a free consequence of the symbol
alone.

## 3. Deterministic marker table (case-matrix `Enc`, normalized)

`[definition]` The `PopTo_base+MarkRet*On` combinations are only those where a
child/top `c̄` returns to an already-back parent `p̄`.

| Receiver `Mode(p̄)` before mark | Return from popped `c̄` / case source | Primitive | `Ret'(p̄)` | `Mode'(p̄)` | Immediate next consumer on `p̄` (when it becomes top) |
|---|---|---|---|---|---|
| `M_BackA0` | accept (`D_eval_acc_ret` into A0 parent, or A0-child pop path as encoded) | `PopTo_base(p̄,c̄) ∧ MarkRetAccOn(p̄)` | `RetAcc` | `M_BackA0` | `D_backA0_acc_A1` |
| `M_BackA0` | reject | `PopTo_base(p̄,c̄) ∧ MarkRetRejOn(p̄)` | `RetRej` | `M_BackA0` | `D_backA0_rej_root/ret` |
| `M_BackA1` | accept | `PopTo_base(p̄,c̄) ∧ MarkRetAccOn(p̄)` | `RetAcc` | `M_BackA1` | `D_backA1_acc_root/ret` |
| `M_BackA1` | reject | `PopTo_base(p̄,c̄) ∧ MarkRetRejOn(p̄)` | `RetRej` | `M_BackA1` | `D_backA1_rej_root/ret` |
| `M_BackE` | accept | `PopTo_base(p̄,c̄) ∧ MarkRetAccOn(p̄)` | `RetAcc` | `M_BackE` | `D_backE_acc_root/ret` |
| `M_BackE` | reject | `PopTo_base(p̄,c̄) ∧ MarkRetRejOn(p̄)` | `RetRej` | `M_BackE` | **split:** `D_backE_rej_next` iff `NextIncompAtCur_{p̄}`; else `D_backE_rej_exh_root/ret` iff `NoNextIncompAtCur_{p̄}` |

`[deduction]` **No `M_Eval` receiver.** An `M_Eval` frame is a live evaluation
frame (`RetNone` under `I_{M_D}` coherence) or a non-consuming state; it is not
the Back* marker receiver of `MarkRet*On` in the SYM/MDALT/Enc discipline.
`D_eval_acc_ret/D_eval_rej_ret` pop the current `M_Eval` top `c̄` and mark its
**parent** `p̄`; the parent's mode is read from preserved `p̄` fields and must
be a `Back*` mode for that return to be legal. Any `I_{M_D}`-reachable return
to a non-Back* parent is a falsifier (§6).

## 4. `D_eval_rej_ret -> M_BackE` cursor preservation and NI/NNI split

This is the requested concrete trace. It is a two-step `δ/Δ` interaction under
the canonical schemas above.

### 4.1 Step 1: `D_eval_rej_ret`

`[definition]` (SYM/realization/case-matrix, parent-back mode instantiated as
`M_BackE`):
```text
D_eval_rej_ret[E->BackE] :=
    ¬HaltAcc ∧ ¬HaltRej
  ∧ ∃c̄∃p̄(
        Top(c̄) ∧ FrameLive(c̄) ∧ M_Eval(c̄) ∧ RetNone(c̄)
      ∧ NonRoot(c̄) ∧ Parent(c̄,p̄) ∧ FrameLive(p̄) ∧ M_BackE(p̄)
      ∧ RejectEval_c
      ∧ PopTo_base(p̄,c̄)
      ∧ MarkRetRejOn(p̄)
    ).
```

`[deduction]` **Cursor preservation.** `MarkRetRejOn(p̄)` includes
`PreserveNonMarkerFields(p̄)`, which preserves
`HasCur(p̄), CurA(p̄,·), CurB(p̄,·), HasSel/SelA/SelB, UsedF, PosF, Parent`
and the mode bits; in particular it preserves `M_BackE(p̄)` as `M_BackE'(p̄)`.
`PopTo_base(p̄,c̄)` changes only `Top`, `FrameLive` of `c̄/p̄` as specified,
`CurBase` unchanged, and lower stack outside `{p̄,c̄}`. Therefore the whole
successor `E1` satisfies:
```text
Top(E1)=p̄,  FrameLive(E1,p̄),  ¬FrameLive(E1,c̄),
M_BackE(E1,p̄),  RetRej(E1,p̄),
HasCur(E1,p̄)<->HasCur(E,p̄),
CurA(E1,p̄,·)=CurA(E,p̄,·),  CurB(E1,p̄,·)=CurB(E,p̄,·),
PosF(E1,p̄,·,·)=PosF(E,p̄,·,·),  UsedF(E1,p̄,·)=UsedF(E,p̄,·).
```
No `NextIncomp_c`/`NoNextIncomp_c` recomputation changes the stored cursor; the
NI/NNI test is evaluated in the **next** macro-step over this preserved cursor
and preserved `PosF(p̄,·,·)`.

### 4.2 Step 2: `RetRej + NI/NNI` split on `M_BackE(p̄)`

From `E1`, the unique top is `p̄`, with `M_BackE(p̄) ∧ RetRej(p̄)`. By
`I_{M_D}` cursor coherence, `HasCur(p̄)` with unique `CurA(p̄,a), CurB(p̄,b)`
holds (obligation if a counterexample appears). The NI/NNI partition is:
```text
NI_p  := NextIncompAtCur_p(x,y)
      := ∃a∃b(CurA(p̄,a)∧CurB(p̄,b)∧Lex2(a,b,x,y)∧Incomp_p(x,y)
              ∧ ¬∃u∃v(Lex2(a,b,u,v)∧Lex2(u,v,x,y)∧Incomp_p(u,v))).

NNI_p := NoNextIncompAtCur_p
      := ∃a∃b(CurA(p̄,a)∧CurB(p̄,b)∧¬∃x∃y(Lex2(a,b,x,y)∧Incomp_p(x,y))).
```
They are complementary and `NI_p` is functional in `(x,y)`.

**Branch NI: `D_backE_rej_next`.**
```text
D_backE_rej_next :=
    ¬HaltAcc ∧ ¬HaltRej
  ∧ ∃p̄∃a∃b∃x∃y(
        Top(p̄) ∧ FrameLive(p̄) ∧ M_BackE(p̄) ∧ RetRej(p̄) ∧ CtrlSort(p̄)
      ∧ CurA(p̄,a) ∧ CurB(p̄,b) ∧ NextIncomp_p(a,b;x,y)
      ∧ ∃d̄( FreshChild(d̄) ∧ PushChildE(d̄,p̄,x,y) )
      ∧ SetParentBackE_Advance(p̄,x,y)
      ∧ LowerStackPreservedExcept({p̄,d̄}) )
```
with `[SYM-TOP]` `ChildFrameBase` inside `PushChildE`: `Top'(d̄)`, `¬Top'(p̄)`,
`∀z̄(Top'(z̄)->z̄=d̄)`, `CurBaseBump`.

**Branch NNI, root/non-root:** `D_backE_rej_exh_root` / `D_backE_rej_exh_ret`.
```text
D_backE_rej_exh_root :=
  Top(p̄)∧Root(p̄)∧FrameLive(p̄)∧M_BackE(p̄)∧RetRej(p̄)∧NoNextIncompAtCur_p
  ∧ HaltRej' ∧ ¬HaltAcc' ∧ NoActiveFrames' (or equivalent fixed terminal encoding).

D_backE_rej_exh_ret :=
  Top(p̄)∧NonRoot(p̄)∧FrameLive(p̄)∧M_BackE(p̄)∧RetRej(p̄)∧NoNextIncompAtCur_p
  ∧ Parent(p̄,q̄) ∧ PopTo_base(q̄,p̄) ∧ MarkRetRejOn(q̄).
```

`[deduction]` Thus `D_eval_rej_ret` to an `M_BackE` parent does **not** itself
select NI/NNI; it only installs `RetRej` on the parent while preserving the
cursor/snapshot. The NI/NNI decision is a separate, deterministic BackE
consumption step over the same preserved cursor and `PosF(p̄,·,·)`.

## 5. `D_backE_rej_next` / `SetParentBackE_Advance` / `NoNextIncomp_c` interaction

### 5.1 Required interaction

```text
D_backE_rej_next(E1,E2) requires:
  RetRej(p̄) at top p̄, M_BackE(p̄),
  NI_p(x,y) at current cursor (a,b),
  push child d̄ on selected incomparable (x,y),
  SetParentBackE_Advance(p̄,x,y): parent remains live, M_BackE', RetNone',
  cursor advanced to SuccLex2(x,y,·) or last-pair normalization.

D_backE_rej_exh_*(E1,E2) requires:
  RetRej(p̄) at top p̄, M_BackE(p̄),
  NNI_p at current cursor (a,b),
  no child push; root halt-reject or PopTo_base+MarkRetRejOn to grandparent.
```

### 5.2 Checkable interaction obligations

1. **Totality of NI/NNI on consuming BackE+RetRej tops.** `[open]` For every
   `I_{M_D}`-reachable state where `Top(p̄) ∧ M_BackE(p̄) ∧ RetRej(p̄)` is the
   consuming case, prove `HasCur(p̄)` with unique `CurA/CurB` and hence exactly
   one of `NI_p`/`NNI_p`.
2. **`SuccLex2` advance prevents immediate reselect of `(x,y)`.** `[deduction]`
   If `Cur'(p̄) = SuccLex2(x,y,·)`, then `Lex2(x,y,Cur'(p̄))` and `SuccLex2`
   minimality imply the next `NextIncomp_p` witness, if any, is lex-after
   `(x,y)`. This is the intended no-spurious-retry discipline.
3. **Last-pair normalization safety.** `[open]` If `IsLastLex2(x,y)`, the
   normalization `Cur'(p̄)= (x,y)` must not create a reachable
   `M_BackE∧RetRej∧NI_p` loop that reselects `(x,y)`: either the state is
   unreachable after a last-pair selection or the NI test must be understood as
   search strictly/appropriately after the selected pair in that encoding. A
   clean alternative is to store `Cur'` as a sentinel/no-next state or make
   `NextIncomp` use `Lex2_strict_or_selected-after` consistently with
   `SetParentBackE_Advance`; this is an **encoding detail that must be fixed
   explicitly**.
4. **`SetParentBackE_Advance` preserves snapshot fields.** `[deduction]`
   `UsedF/PosF/HasSel/SelA/SelB/Parent` of `p̄` are preserved, so retry children
   are generated from the same search frame snapshot except cursor advancement.
5. **Composition with `D_eval_rej_ret`.** `[deduction]` Because Step 1 preserves
   `CurA/CurB/PosF/Mode=M_BackE` and sets `RetRej`, Step 2 sees exactly the
   intended NI/NNI partition for that BackE frame.

## 6. Underdetermined symbols / inconsistent field risks

`[open]` The following are the only concrete formula-level risks found by this
cross-check. They are **not** claims of inconsistency in the intended model;
each is a checkable closure obligation or falsifier.

1. **`FrameEq'` over-specificity.** If `FrameEq'` is defined as field+liveness
   equality and also used for a frame whose `FrameLive` changes, or for `p̄`
   under `PopTo_base+MarkRet*On` without excluding `Ret*`, it becomes
   inconsistent. **Fix/obligation:** use `FrameFieldsEq'` for field-only
   preservation and reserve `FrameEq'` for untouched live frames; keep `p̄` in
   `LowerStackPreservedExcept({p̄,c̄})` but supply `MarkRet*On` as its explicit
   update.
2. **`LowerStackPreservedExcept` arity drift.** SYM singleton `c̄` vs.
   case-matrix set `S`. Not semantically harmful if normalized, but a direct
   formula merge is ambiguous. **Fix:** adopt `LowerStackPreservedExcept(S)`.
3. **`M_Eval` as marker receiver.** If any encoding applies `MarkRetAccOn`/
   `MarkRetRejOn` to a frame while keeping or setting `M_Eval` as the active
   pending mode, it conflicts with mode/return coherence (`M_Eval` live eval is
   `RetNone`; Back* parents receive markers). **Fix:** restrict the §3 table to
   Back* receivers; enforce `M_BackE/A0/A1(p̄)` in receiver guards.
4. **BackE last-pair cursor sentinel.** The `IsLastLex2` normalization in
   `SetParentBackE_Advance` can be inconsistent with NI/NNI totality unless the
   selected-pair/after-cursor convention is explicit. **Fix:** define whether
   `NextIncomp_c(a,b;·,·)` searches pairs with `Lex2(a,b,·,·)` (including equal
   start) and how cursor is advanced past the selected pair; prove no
   re-selection of the just-tried pair and no last-pair NI loop.
5. **`RejectEval_c` / sort-exhaust boundary.** SYM root/non-root eval reject
   includes `CtrlSort(c̄)∧¬Total_c∧Budget_c∧NoNextIncomp_c`. This means a sort
   frame can be rejected at eval time when no incomparable exists after cursor.
   The interaction with BackE retry exhaust is equivalent in effect (reject) but
   must be placed in exactly one consuming case on reachable states to preserve
   mutual exclusion. **Obligation:** confirm `I_{M_D}` reachability makes
   `D_eval_rej_ret`/`D_root_rej` sort-exhaust disjoint from
   `D_backE_rej_exh_*` as encoded, or merge the exhaust meaning into one
   canonical case family.
6. **Return to non-Back* parent.** `D_eval_acc_ret/D_eval_rej_ret` composes
   `MarkRet*On(p̄)` preserving mode; if `Parent(c̄,p̄)` points to a frame not in
   `M_BackE/A0/A1`, the next-state mode is underdetermined for the matrix.
   **Falsifier/obligation:** `I_{M_D}` must imply every non-root eval return
   target is the appropriate Back* parent.
7. **`HasSel/Cur` coherence under BackE retries.** `SetParentBackE_Advance`
   preserves `HasSel/SelA/SelB` “harmlessly” in SYM; case-matrix text keeps the
   DFS snapshot discipline. For BackE sort search this is harmless only if no
   later A0/A1 case reads stale selection from a BackE frame. **Obligation:**
   state the intended `CtrlSort` BackE invariant for selection fields.

## 7. Exact checkable closure obligations left

Assuming the formulas in §§2–5 are adopted as the normalized `Enc` schema, the
remaining checkable obligations for `[CKS-AV-POST-HALT/I_M_D-DET-SUCC]` are:

1. **Encoding normalization proof obligation.** Fix one concrete `Enc` where
   `FrameInactive' := ¬FrameLive'`, `LowerStackPreservedExcept(S)` is the set
   form, `FrameFieldsEq'`/`FrameEq'` are used without liveness conflicts, and
   `PopTo_base+MarkRet*On` gives `p̄`'s complete field update.
2. **Marker-receiver reachability.** Prove every `D_eval_acc_ret/D_eval_rej_ret`
   target `p̄` satisfies `M_BackE(p̄)∨M_BackA0(p̄)∨M_BackA1(p̄)` on
   `I_{M_D}`-reachable states.
3. **BackE NI/NNI totality and cursor convention.** Prove consuming
   `M_BackE∧RetRej` tops have unique cursor and exact `NI_p`/`NNI_p`
   complementarity; fix the `SuccLex2`/last-pair/after-selected-pair convention
   so selected pair `(x,y)` is never reselected and no last-pair NI loop occurs.
4. **Sort-exhaust case placement.** Prove mutual exclusion/coverage between
   eval-time sort exhaust (`RejectEval_c` / `NoNextIncomp_c` in `D_eval_*` or
   root reject) and BackE retry exhaust (`D_backE_rej_exh_*`) under the chosen
   canonical matrix.
5. **Full guard matrix on reachable states.** Recheck exhaustivity/mutual
   exclusion over all `I_{M_D}`-reachable `(Mode,Ret,Ctrl,Root/Parent,HasSel,
   HasCur,NI/NNI)` combinations, including `Back*+RetNone` top non-consumption
   or explicit falsifier status.
6. **`I_{M_D}` preservation per case.** For each `D_*` case, prove unique
   `Top'`, `ExactlyOneMode`, functional `Parent/UsedF`, coherent
   `HasSel/SelA/SelB, HasCur/CurA/CurB`, active-path discipline, and
   `[SYM-TOP]` push/pop behavior under the normalized `Enc`.
7. **No-spurious local alignment.** Prove `NextIncomp_c` is the only pair
   selector; `PushChildA` uses `StepPosBit_c/SuccCtr/PostBudgetFrom` with the
   correct side and preserved A0 snapshot for A1; no `PosF/UsedF` mutation
   outside A-child creation; accept/reject only by fixed terminal/propagation
   rules.
