# Obstruction for S(n) / SORT-BOUND-U (billy-dev)

**Date:** 2026-10-31  
**Scope:** unary threshold SORT-BOUND-U = {1^n # 1^k : S(n) <= k}, function S(n).  
**Model:** adaptive comparison trees (minimax game G(n,k)); uniform vs nonuniform distinguished.

## Precise definitions / cost model

- S(n) = min height of deterministic adaptive comparison tree sorting n distinct labelled keys.
- Game G(n,k): state = transitively closed partial order P on n; start empty; while P not total and < k comparisons left, sorter picks incomparable pair {x,y}, adversary answers x<y or y<x, update by transitive closure. Sorter wins iff total order reached within k comparisons. S(n)<=k <-> sorter wins G(n,k).
- Input lengths: N_U = n+k+1 for unary; N_B = Θ(log n) for binary. 
- Upper bounds (established): SORT-BOUND-U in PSPACE (alternating TM on poset states, O(k n^2) time) and SORT-BOUND-B in EXPSPACE. (Improves prior EXPTIME/2-EXPTIME.)

## Concrete obstruction (barrier)

1. **Sparse barrier (unary).** SORT-BOUND-U is sparse (O(N^2) instances of length<=N). By Mahaney's theorem, polynomial-time many-one NP-hardness => P=NP. This rules out the most direct route to NP-hardness for the unary threshold language.
2. **Witness size explosion.** Any correct sorting tree must distinguish all n! permutations; a reduced optimal tree has exactly 2n!-1 nodes and n! leaves. For informative unary instances n! = 2^(Θ(N/log N?)) in terms of relation to N=n+k+1? More directly, input length N_U = Θ(n log n) in the informative window k=Θ(n log n), so tree size 2n!-1 = 2^(Θ(N_U / log N_U)). The obvious nondeterministic "guess the tree" certificate is super-polynomial in input length (and doubly exponential in binary). No polynomial-size succinct certificate is known in either direction.
3. **State space / game complexity.** The minimax game is on poset states (labelled). The memoized DP visits all labelled posets A001035(n)=2^(Θ(n^2)). The budgeted DFS only explores states reachable within k=S(n) comparisons (~2^(O(n log^2 n)) in worst bound) but still exponential; no compact canonical form of optimal strategy is known. Counting/greedy-optimal by linear extensions is #P-hard.
4. **Transfer failure.** NP-completeness of optimal decision-tree construction (arbitrary tests), inapproximability (Laber-Nogueira), and sorting-network verification coNP-completeness do not transfer to fixed pairwise-comparison set + single parameter n (and unary sparsity blocks many-one NP-hardness).

## Necessary conditions for a strong classification

- **For NP membership (SORT-BOUND-U in NP):** There must exist a polynomial-size (in N_U) witness W(n,k) and poly-time verifier V with (S(n)<=k <-> exists W, V(n,k,W)=true), *different* from listing the full comparison tree. Plausible forms: a DAG of optimal comparisons over canonical posets, or a compact strategy description; both would require bounding the number of distinct states on optimal plays to poly(n).
- **For P=NP consequence avoidance / hardness:** Showing many-one NP-hardness of unary SORT-BOUND-U is equivalent in effect to showing P=NP (sparsity). Any hardness claim must use Turing reductions (and would collapse PH to Δ2P by Ogiwara-Watanabe only in stronger forms) — still nontrivial but the barrier is sharp.
- **For lower bounds:** A polynomial certificate for S(n)>k needs a potential stronger than log2(n!) (information bound not tight; exact lower bounds require exhaustive search). No such potential is known.

## Conclusion

The decisive obstruction is the **lack of a succinct certificate** coupled with the **unary sparsity barrier**. 
- Upper side: PSPACE is known (alternation). Moving below PSPACE would require exploiting structure not obvious from general alternation; NP/coNP seem implausible without a poly-size witness.
- Lower side: Showing NP-hardness for unary is blocked by Mahaney (would imply P=NP); showing super-polynomial uniform lower bounds for a problem in PSPACE with no known circuit/lower-bound foothold and this structure is not a standard route.

**Most plausible concrete path:** characterize the "optimal-play" poset graph (states reachable by some height-S(n) strategy). If its size is polynomial in n, NP membership becomes plausible; if exponential and "universal", it argues against succinct certificates. This is a falsifiable/computable structural question.
