## 0. Assumed post-halt frontier (argumentative)

`[inherited assumption]` For this note only, assume the paper-level MDALT BackE-rank fix in `mdalt-halt-back-e-rank-fix.md` is independently audited as sound: `[open:CKS-AV-MDALT-HALT.BACK_E_RANK]` is discharged, so the global well-founded measure `μ(E)=(V(F_0),...,V(F_d))`, `V=(bcost,q,ex,ph)` with `ex=rlex` before `ph`, makes every non-halting `δ_{M_D^alt}^{sch}`/`Δ_{M_D}^{sym,top}` macro-step from an `I_{M_D}`-reachable non-halting state strictly decrease `μ`, while preserving `I_{M_D}`. Hence, under that assumption plus the realization's determinism/totality-on-relevant-states structure, every `I_{M_D}`-reachable computation from `Init_{M_D}^{sym}` is finite and reaches `HaltAcc` or `HaltRej`.

This assumption is **not** re-proved here. If it fails, the chain returns to `[CKS-AV-MDALT-HALT.BACK_E_RANK]`.

## 1. Why this is the next dependency

PACK-REACH (whole-configuration normal form) repairs the tuple-accumulation error and gives the simultaneous PFP acceptance form `Φ_{M_D}^{sim} := WellFormed_w ∧ HaltAcc[PFP_{Rbar}\Psi^{abs}]`, with stages `Rbar^0=∅`, `Rbar^1=Init_{M_D}`, `Rbar^{α+1}=(ψ_1^{abs}(Rbar^α,·),...,ψ_m^{abs}(Rbar^α,·))` and absorbing halting states. Its correctness proof states (PACK-REACH §4): if `Rbar^α` is a non-halting well-formed configuration satisfying `I_{M_D}`, then `Rbar^{α+1}` is the **unique** `Δ_{M_D}`-successor by the deterministic FO operator extracted from the case-closed functional `Δ_{M_D}`. The PACK-REACH residual is exactly this inherited assumption: complete symbol-level closure/correctness of the case-closed `Δ_{M_D}` (mutual exclusion, totality on relevant `I_{M_D}` states, determinism/functionality, invariant preservation, no spurious transitions relative to semantic `M_D^alt`).

After the assumed halting fix, termination of the orbit is no longer the blocker. What remains minimal for *instantiating* `Ψ^{abs}` as the actual computation operator is a single, checkable extraction lemma: on every `I_{M_D}`-reachable state, the case-closed guards are exhaustive and mutually exclusive, and each produces exactly the corresponding successor whole configuration. The delta-d-dfs-stack / MDALT realization audits identify the concrete locus of risk as schematic helper/marker/return-channel/parent-link/frame-boundary encodings (`ParentOf/PopTo_base/MarkRet*On/FreshChild/LowerStackEq'/FrameEq'/return markers/BackE,BackA0,BackA1 wiring`), which affect mutual exclusion and totality on backtrack/return-marker states. `I_{M_D}` preservation and no-spurious transition structure are plausible in the SYM/MDALT realization, but PACK-REACH needs the operator to be a *deterministic FO successor map* on the whole reachable orbit.

The model-bridge/semantic equivalence (`M_D^alt` accepts iff alternating DFS accepts `Init_{M_G/G(n,k)}` iff sorter wins `G(n,k)` iff `S(n)<=k` iff `w∈SORT-BOUND-U`) is a separate project/model assumption already stated in the realization/PACK-REACH/closure map; it is not the next *operator-instantiation* dependency once halting is assumed fixed.

## 2. Single minimal falsifiable closure lemma

### `[open:CKS-AV-POST-HALT/I_M_D-DET-SUCC]` — `I_{M_D}`-reachable deterministic successor extraction

**Objects (fixed).** `[definition]`
- Input structure `A(w)=(W,<,One,Hash)`, `w=1^n#1^k`, `N=n+k+1`, `Cell=W^r` as in the SYM/PACK/MDALT artifacts.
- Configuration component family `Rbar=(R_1,...,R_m)` / DTM encoding `E(Rbar)` with `Top,CurBase,EmptyStack,HaltAcc,HaltRej, M_Eval/M_BackE/M_BackA0/M_BackA1, RetNone/RetAcc/RetRej, CtrlSort/Adv/Acc/Rej, UsedF, HasSel/SelA/SelB, HasCur/CurA/CurB, PosF, Parent, FrameLive` and the fixed frame/layout conventions.
- Symbol-level one-step relation `Δ_{M_D}^{sym,top}(Rbar;Rbar')` / DTM macro-schema `δ_{M_D^alt}^{sch}(E)=E'` (MDALT realization §3.2 with `[SYM-TOP]` push `Top'`-uniqueness), with local semantics `PosF`-closure, `Incomp_c/Total_c/Budget_c/CfgAcc_c/RejectEval_c`, `StepPosBit_c`, `PostBudgetFrom`, `NextIncomp_c/NoNextIncomp_c/SuccLex2`, `SuccCtr`, and the DFS cases `D_halt, D_root_acc/rej, D_eval_acc/rej_ret, D_sort_pick, D_backE_acc_root/ret, D_backE_rej_next, D_backE_rej_exh_root/ret, D_adv_push_A0, D_backA0_rej_root/ret, D_backA0_acc_A1, D_backA1_acc/rej_root/ret`.
- Frame invariant `I_{M_D}` (SYM/realization): well-formed input, unique halt or unique `Top` on non-halting states, `ExactlyOneMode`, `Parent` functional on active non-root frames, unique `UsedF∈Ctr`, coherent `HasSel/SelA/SelB, HasCur/CurA/CurB, Ret*, Ctrl*, PosF` fields, root-to-top active path discipline, and `[SYM-TOP]` push uniqueness.

**Marker/encoding instantiation (must be explicit).** `[definition]` The lemma requires **one fixed** symbol-level/DTM encoding choice for the previously schematic helpers, sufficient to read/write whole configurations:
```text
Enc := ( FreshChild := CurBase with CurBase' = SuccCell(CurBase) on push,
         ParentOf(c̄,p̄) := Parent(c̄,p̄) or the equivalent fixed active-stack link,
         PopTo_base(p̄,c̄) := Top'(p̄) ∧ ¬Top'(c̄) ∧ FrameInactive'(c̄) ∧ lower stack preserved except p̄,
         MarkRetAccOn(p̄) / MarkRetRejOn(p̄) := unique RetAcc/RetRej on p̄ with parent mode transition,
         BackE/BackA0/BackA1/Ret marker representation and Root(c̄) test,
         LowerStackPreservedExcept / FrameEq' / FrameInactive' boundary discipline ).
```
Any other fixed encoding is acceptable only if it makes the same `Δ_{M_D}^{sym,top}`/`δ` macro-case meaning checkable and preserves `I_{M_D}`.

### Lemma statement

`[open]` (to be discharged/falsified). Let `Enc` be fixed as above. For every well-formed `w=1^n#1^k` and every `I_{M_D}`-reachable configuration `E = E(Rbar)`:

1. **Halting or unique case.** Either `HaltAcc(E) ∨ HaltRej(E) ∨ EmptyStack(E)` holds, or exactly one macro-case precondition `Guard_D(E)` among the non-halting `D_*` cases holds at the unique `Top(E)`.
2. **Unique whole-successor.** In the non-halting case, the corresponding `Enc`-update produces exactly one whole configuration `E'` (equivalently `Rbar'`) such that
   ```text
   E --δ_{M_D^alt,Enc}^{sch}--> E'   and   Δ_{M_D,Enc}^{sym,top}(Rbar;Rbar').
   ```
3. **Orbit closure.** `I_{M_D}(E')` holds. No lower active-stack frame is changed except the designated top/pop/parent marker/mode/cursor field updates of that case; no spurious incomparable selection, `PosF` mutation, budget mutation, or accept/reject is introduced outside the fixed local semantics.
4. **FO operator extraction.** Consequently, for the fixed component order `Rbar=(R_1,...,R_m)`, there are FO formulas `ψ_{1,Enc}^{abs},...,ψ_{m,Enc}^{abs}` over `A(w)` and current `Rbar` such that, on `I_{M_D}`-reachable `Rbar`,
   ```text
   Rbar' = (ψ_{1,Enc}^{abs}(Rbar,·),...,ψ_{m,Enc}^{abs}(Rbar,·))
   ```
   is the unique successor/absorbing-halting whole configuration, and therefore the simultaneous PFP orbit of PACK-REACH §4 is the unique deterministic computation orbit:
   ```text
   Rbar^0=∅, Rbar^1=Init_{M_D}, Rbar^{α+1}=Ψ_{Enc}^{abs}(Rbar^α),
   ```
   containing `HaltAcc` iff the `Δ_{M_D,Enc}^{sym,top}`/`δ_{Enc}` computation from `Init_{M_D}^{sym}` reaches `HaltAcc`.

### Proof obligations (all required)

1. **Exhaustivity on `I_{M_D}`-reachable states.** Show the `Guard_D` disjunction covers every non-halting `I_{M_D}`-reachable `E`, using unique `Top`, `ExactlyOneMode`, `Ret*`/`Ctrl*` coherence, `Root/Parent` cases, and the `NextIncomp_c/NoNextIncomp_c` partition for BackE/sort-exhaust states.
2. **Mutual exclusion under `Enc`.** Show no two `Guard_D` preconditions hold simultaneously on an `I_{M_D}`-reachable state, including all `M_BackE/M_BackA0/M_BackA1/RetAcc/RetRej/NextIncomp/NoNextIncomp/root/non-root` combinations under the concrete marker representation.
3. **Unique successor update.** For each case, the primed fields (`Top/CurBase/mode/Ret/Ctrl/UsedF/HasSel/Sel/HasCur/Cur/PosF/Parent/FrameLive` and global halting flags) are functionally determined by `Enc` and the fixed local formulas; no underdetermined child address, parent marker, or frame-boundary write remains.
4. **`I_{M_D}` preservation.** Recheck `[SYM-TOP]` push uniqueness, `ExactlyOneTop/Mode`, functional `Parent/UsedF`, field coherence, and active root-to-top path after every case, with the concrete `Enc` marker/pop discipline.
5. **No-spurious alignment.** The produced successor is exactly the legal DFS-local transition of the fixed `G(n,k)`/`δ` semantics (lex `NextIncomp_c` choice, `StepPosBit_c`/`SuccCtr`/`PostBudgetFrom` on A0/A1, A0 then A1 from the same preserved snapshot, BackE cursor advance by `SuccLex2`, return consumption, terminal accept/reject only by `CfgAcc_c`/`RejectEval_c`/root/exhaust rules). This obligation is inherited/plausible from SYM/MDALT realization but must be consistent with `Enc`.

## 4. Concrete disproof test / smallest constructive step

### Disproof test (falsifiable)

`[falsification]` Construct or explicitly derive a counterexample to `[CKS-AV-POST-HALT/I_M_D-DET-SUCC]`:
1. **Ambiguous case:** an `I_{M_D}`-reachable `E` whose unique `Top` state (mode, `Ctrl`, `Ret`, `HasSel/HasCur`, `NextIncomp_c/NoNextIncomp_c`, `Root/Parent`) satisfies `Guard_{D_i}(E) ∧ Guard_{D_j}(E)` for `i!=j`, or satisfies no non-halting `Guard_D(E)` while being non-halting.
2. **Nondeterministic successor:** a case where `Enc` leaves `Top'/Parent'/child address'/Ret'` or a preserved field underdetermined (e.g., conflicting `PopTo_base`/`MarkRet*` behavior for a return to `BackE` vs. `BackA0`/`BackA1`, or multiple `FreshChild`/`CurBase` successors).
3. **Invariant break:** an `I_{M_D}`-reachable transition producing duplicate `Top`, broken `Parent`, non-unique `UsedF/mode/Ret`, or corrupted `PosF`/cursor coherence.
4. **Spurious local move:** a `Δ_{M_D,Enc}` step that selects a non-`NextIncomp_c` pair, applies a wrong `StepPosBit_c`/`SuccCtr` side, evaluates A1 from a mutated snapshot, or accepts/rejects outside the fixed terminal rules.

A single explicit witness of any kind (1)-(4) falsifies the lemma and blocks PACK-REACH operator instantiation at that point.

### Smallest constructive step

`[deduction]` First fix `Enc` completely on paper (one page): make `Parent(c̄,p̄)` the sole parent link, define `PopTo_base(p̄,c̄)`/`FrameInactive'` as exact component updates, and define `MarkRetAccOn/MarkRetRejOn` as a deterministic table
```text
p̄ in M_BackA0, RetNone  + RetAcc(child pop) -> M_BackA0,RetAcc;
p̄ in M_BackA0, RetNone  + RetRej(child pop) -> M_BackA0,RetRej;
p̄ in M_BackA1, RetNone  + RetAcc(child pop) -> M_BackA1,RetAcc;
p̄ in M_BackA1, RetNone  + RetRej(child pop) -> M_BackA1,RetRej;
p̄ in M_BackE,  RetNone  + RetAcc(child pop) -> M_BackE, RetAcc;
p̄ in M_BackE,  RetNone  + RetRej(child pop) -> M_BackE, RetRej if NextIncomp_c else M_BackE,RetRej (exhaust) as per BackE table,
```
with all other parent fields preserved. Then prove (1)-(2) by a case matrix over `I_{M_D}`-reachable `(Mode,Ctrl,Ret,Root/Parent,HasSel,HasCur,NextIncomp/NoNextIncomp)` combinations, and prove (4) for the same cases. This is the smallest constructive step because it closes the exact locus the audits called schematic without reopening SYM-TOP, the assumed halting measure, PACK one-step packing, or the model bridge.
