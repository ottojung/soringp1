# Joined rank-envelope insertion stage: constructive certificate experiment

Date: 2026-11-21. Worktree base 6a96398. No repository code changed.

## What was built

A Python generator (/tmp/opencode/fj_cert.py) implementing the Ford-Johnson
joined rank-envelope insertion stage as a permutation-framed DAG, plus the
existing checker scripts/check_framed_strategy.py.

- n=3: S(3)=3. Graph has 11 nodes, depth 3. Checker: ACCEPT.
- n=4: S(4)=5. Graph has 47 nodes, depth 5. Checker: ACCEPT.
- n=5: S(5)=7. Graph has 199 nodes, depth 6 along some paths, but
  checker REJECTS (64/120 inputs reach an unsorted leaf).

All edges carry permutations, including non-identity frames (pair swaps,
composite compaction, insertion moves).

## Obstruction at n=5

The FJ insertion stage contains zero-comparison insertions (a loser whose
paired winner is already at the front of the chain). Their slot move is
attached to the preceding comparison edge. That move is positional but its
correctness depends on the value state before that edge, not only on the
outcome prefix. Consequently a node shared by inputs with the same outcome
prefix can require different frames:

- node with comparison [4,2] (0-based slots) has perm_lt
  [0,1,3,4,2] in one value context and [1,2,4,0,3] in another.
  Neither fixed permutation sorts both contexts.

Exact bookkeeping failure: a fixed permutation on a shared edge cannot
simultaneously encode the two different insertion positions forced by the
two different value states that reach that edge. Thus the joined
rank-envelope construction, as implemented, does not yield a valid
polynomial-size framed DAG at n=5.

## Claims (labels)

- Construction for n=3,n=4: experiment (checker-accepted).
- n=5 obstruction: experiment (checker-rejected) + deduction
  (value-dependent frames prevent sharing).
- Polynomial-size generalization: conjecture (still open; this
  experiment does not establish it; the zero-comparison tail suggests a
  barrier to naive sharing).

## Next decisive step

Find an insertion schedule / frame convention in which every insertion
move is determined solely by the outcome prefix (no value-dependent
hypothetical frames), or prove that joined rank-envelope insertion
cannot be encoded as a polynomial-size framed DAG without such moves.
A candidate is to eliminate zero-comparison insertions by restructuring
the insertion order or by absorbing forced losers into compaction with a
uniform frame.
