## 2. Soundness of scoped resumable-transcript analysis

**Mostly sound as stated, with scope boundaries that should remain explicit.**

### What is sound

1. **Model alignment.** The artifact fixes the relevant model: `w=1^n#1^k`, `N=n+k+1`, read-only input, work space excludes input, exact minimax `V(P,d)` / `S(n)<=k` (`docs/problem.md`). This matches the budgeted-DFS decision formulation.

2. **Baseline accounting is consistent.** Citing `2^{O(k log(n+2))}poly(N) <= 2^{O(N log(N+2))}` time and `O((k+n)log(n+2)) <= O(N log(N+2))` bits after trivial `k>=U(n)` handling matches `research-budgeted-dfs.md` §5.3 and §5.2. The transcript/cursor source of the space bound is the same as §5.2 items 1 and 5: path stores comparisons/cursors; reachability is recomputed in reusable workspace.

3. **History dependence is real.** A sorter move must be a pair incomparable in `P(σ_{i-1})`, the closure of the adaptive prefix transcript. This is definitionally correct for the comparison-game state used by the budgeted DFS; legal moves depend on prior answers.

4. **Exact AND/OR resumability is the right bottleneck for the scoped class.** For a chosen incomparable pair, exact evaluation needs both orientations unless short-circuited by an already-determined value; on return, a depth-first/stack-based exact evaluator must resume at the correct ancestor with the correct unexplored branch/candidate. That requires retaining or exactly reconstructing resumable path/cursor state. The artifact correctly states this as an accounting issue for the standard transcript/cursor representation (`O(log n)`/level, `O(t log n)` depth `t`), not as a universal impossibility proof.

5. **Unary worst case is stated carefully enough.** Using `t <= k <= N`, `n <= N` gives `O(N log(N+2))` for the baseline and `Θ(N log N)` for the natural transcript/cursor worst case. This is a representation-size worst case, not a claim that every input forces that exact internal state format.

6. **Correct separation from winning-frontier barrier.** The artifact correctly treats `research-winning-frontier-barrier.md` as an enumeration obstruction only. Avoiding full winning-frontier enumeration does not, by itself, prove low work space; the artifact uses that to motivate the space question rather than to derive a lower bound.

### Scope/caution notes

- **“Selective” is family-scoped, not method-universal.** The artifact is careful here: selective variants “in the usual form” maintain resumable node records/bounds/frontier/path, and no `Ω(N log N)` proof is given for every exact selective variant. This is the right boundary. Proof-number/alpha-beta-like searches can be organized in many ways; the obstruction applies cleanly to realizations that keep resumable path/cursor/proof-state proportional to transcript depth/candidate information. It should not be read as covering every conceivable exact selective architecture without an explicit state accounting.

- **Reachability workspace is not the claimed obstacle.** The note correctly identifies the resumable adaptive transcript/cursor as the bottleneck and allows reachability recomputation in reusable `O(n log n)` workspace. This matches `research-budgeted-dfs.md` §5.2.

- **External catalytic/recompute audit is a dependency, not an internal proof.** The cited external audit supports the same bottleneck narrative, but this independent audit cannot verify its contents from the files read. The artifact’s conclusion does not overclaim from that citation; it restates the scoped obstruction directly.

## 3. Candidate-representation analysis

**Sound as a non-committal map; not a proposal of achieved bounds.**

The table is framed as “*candidate* directions only; none is established as an `o(N log N)` exact uniform algorithm.” Each row gives (a) how it avoids full winning-frontier enumeration and (b) the concrete proof obligation it would still have to satisfy. That is methodologically appropriate for the repository’s “barriers/candidates, not deliverables” posture.

Checks against model fidelity / common failure modes:

- **Reversible/catalytic row:** correctly warns that restoring a catalytic tape in that model is not the same as improving standard TM work space unless counted as standard work space. This prevents a model slip.
- **Succinct resumable transcript/path row:** requires exact decompress/reconstruct/resume under adversarial branch returns, not average-case compression. This addresses the main pitfall for compressing adaptive transcripts.
- **Symbolic state/strategy predicates row:** requires `o(N log N)` peak work space and no hidden expansion to explicit frontier/path objects — important because symbolic methods can hide large intermediate state.
- **Succinct game-graph/proof-DAG row:** requires construction/access without enumerating winning frontier states and exact resumable evaluation; good guardrail against reintroducing frontier/path objects.
- **Low-space tree-evaluation row:** requires preserving exact adaptive move legality and handling a presented/fixed or on-the-fly constructible structure in `o(N log N)` work space; appropriately cautious.

No row is presented as satisfying `SORT-BOUND-U ∈ DSPACE(o(N log N))`, as a time improvement, or as a separation.
