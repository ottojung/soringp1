# Obstruction: root-reachable quotient must be superpolynomial for NP-certificates

**Status:** barrier/note (no Lean). Labels: `[definition]`, `[deduction]`, `[conjecture]`.

## Definitions `[definition]`

- $S(n)$ = minimum height of a deterministic adaptive comparison tree sorting $n$ distinct labelled keys (minimax/game $G(n,k)$).
- A *framed comparison strategy* is a DAG of nodes with a comparison pair and two outgoing framed edges $(next, \pi)$ representing the relabelling $\pi$ applied after adding $x<y$ (cf. `scripts/check_framed_strategy.py`).
- Two states (reachable posets with context) are *root-reachable equivalent* under an equivalence $\equiv$ if they are indistinguishable for the purpose of some property of optimal strategies from root, and $\equiv$ is locally checkable/composable along framed moves.
- A *root-reachable quotient* $\mathcal{Q}_n = \{ [P] : P \text{ reachable on some height-}S(n)\text{ optimal play from }\emptyset_n\}$ is the set of equivalence classes of posets appearing on some optimal play.

## Necessary condition for a polynomial NP certificate `[deduction]`

Suppose for all $n$ there is an equivalence $\equiv_n$ (on posets on $n$ labelled elements, effectively describing states relevant to optimal sorting) such that:
1. $\equiv_n$ is polynomial-time decidable.
2. The transition is a congruence under the framed comparison move (outcome classes determined by class of current state and choice of pair).
3. $|\mathcal{Q}_n / \equiv_n| \le \mathrm{poly}(n)$ (polynomial number of classes appear on any height-$S(n)$ optimal strategy).

Then one can build a polynomial-size certificate for $S(n)\le k$: give the (polynomial) DAG of classes with pair choices and frame maps; verify local congruence, reachability/consistency of frames, that every path reaches a total order within $k$ steps, and totality. This is polynomial-time checkable in $n,k$ (and in unary input length $m=n+k+1$) hence yields $SORT\!-\!BOUND\!-\!U \in NP$.

Conversely, any polynomial NP certificate that works by "canonical state classes" (DAG over canonical forms with local move rules) induces such an equivalence with polynomial classes.

## Obstruction / falsifier `[conjecture]` + `[falsifier]`

**Falsifier (concrete):** There is an infinite family $\{n_i\}$ and for each some height-$S(n_i)$ optimal strategy (or a family of optimal strategies) such that *every* equivalence relation $\equiv$ satisfying (1)-(2) and being "complete enough" to capture optimality produces $\ge 2^{\Omega(n_i^\alpha)}$ classes on these strategies for some fixed $\alpha>0$.

Equivalently, the *optimal-play quotient* has super-polynomial size and is not compressible by any local congruence compatible with framed moves and optimality.

**Why this is a barrier:** without polynomial classes, the DAG-of-classes route fails; combined with Claim C (explicit tree has size $2n!-1$), this points to no polynomial succinct certificate from canonicalization/compression. Also the state graph of *all* reachable posets is $2^{\Theta(n^2)}$ (A001035) — the question is whether optimal play lives on a polynomial subgraph up to equivalence.

## Residual gaps `[open]`

- Need to make (1)-(2) precise (exactly which $\equiv$ count as "locally checkable congruences" for framed strategies).
- The falsifier is asymptotic over all $n$; a single large $n$ counterexample is suggestive but not enough for "for all $n$ no polynomial equivalence".
- Even if quotient is super-polynomial, $SORT\!-\!BOUND\!-\!U$ might still be in $NP$ by some non-DAG/certificate form (e.g. a different witness) — the obstruction is to this canonical class route, not absolute NP non-membership.
- Optimal-play counts vs all-reachable counts need measurement for $n\ge7$ (see certificates note §8) to calibrate.

## Relation to existing results `[deduction]`

- Sparsity (Mahaney) blocks many-one NP-hardness for unary but does not directly force NP membership; it’s a constraint.
- $APTIME=PSPACE$ gives $SORT\!-\!BOUND\!-\!U \in PSPACE$.
- Hyafil–Rivest/Laber–Nogueira/Parberry don’t transfer to $S(n)$ (Claim D). The barrier here is structural (quotient size/compressibility), not a generic decision-tree hardness transfer.
