# Candidate: framed-DAG replay with an explicit frame-store interpreter

**Status:** unreviewed paper-level construction in an isolated worktree. This is an explicit extension of the existing FO(TC) strategy-program model, not a theorem in the current `Ask(original-label, original-label)` model. It does not assert optimal polynomial certificates exist.

## Claim under review

Given a framed strategy DAG accepted by `scripts/check_framed_strategy.py`, of explicit bit length `C` and checked height at most `k`, a deterministic compiler can produce a program in an extended query-program model that sorts every input permutation with at most `k` charged comparisons. The program's rule formulas are in FO(TC) with one global variable bound `v=4` and fixed relational arity at most 4. For any fixed polynomial bound on `C` in `n+k`, compilation and execution have a fixed polynomial ordinary-TM clock.

The essential extension is explicit primitive semantics for `AskSlot` and framed `Goto`; no implicit mutable relation update is attributed to the current draft.

## Static tables and stores

Use a tagged finite domain of size `N' = Theta(n+k+C+1)`, explicitly encoding key labels, slots, certificate instructions/edges, output positions and two outcome tokens. Static relation arities are at most four:

- `Query(q,a,b,bq)`: query-control `q` compares current slots `a,b`; after answer, transfer to branch-control `bq`.
- `Edge(bq,o,e,t)`: at branch-control `bq`, outcome token `o` selects edge `e` and target entry-control `t`.
- `Perm(e,x,w)`: edge `e` maps old slot `x` to new slot `w` (the checker's old-to-new convention).
- `LeafOrder(l,p,x)`: at leaf control `l`, current slot `x` is the `p`th element of the certified increasing slot order.
- Unary predicates mark leaf controls and the final output-position sentinel. Control `Ctl(r)`, answer `Ans(o)`, and output-position `OutPos(p)` are mutable registers. `M(x,i)` is the mutable binary relation saying current slot `x` contains original label `i`; initialize it to identity. `H(i,j)` remains indexed by original labels and records that `i` was returned smaller than `j`. Counter `qcount` counts every call, including repeats.

For each certificate query node allocate one query-control and one branch-control. Every edge target is the child's query-control or leaf-control. The compiler runs the existing polynomial certificate checker first and constructs `LeafOrder` for reachable leaves from their checked total strict order. The interpreter starts only at the certified root and permits only the unique action selected by the current control and static tables; it rejects if there is not exactly one selected action or if any selected control/edge/table entry is malformed. Therefore no execution from the root can enter an unreachable leaf. The claim is only about these root-reachable executions; the checker does not certify unreachable leaves.

## Rule formulas and primitive actions

Fix one global variable-name pool V={v1,v2,v3,v4} for every FO(TC) rule formula. Each displayed formula can be alpha-renamed using only V; the pool is reused from formula to formula, not unioned as if all formulas were one simultaneous scope. The rule evaluator receives the current control state as part of the store; action arguments are the formula's free variables. `Query`, `Edge`, `Perm`, and `LeafOrder` are explicit tables, not oracles. The table-update and query effects below are primitive deterministic steps of the fixed interpreter U, not extra FO(TC) rule formulas; their implementation may use ordinary TM work variables, and their time is explicitly charged.

1. **Select a slot query.**
   `Ctl(r) AND Query(r,a,b,s)`
   with free variables `r,a,b,s` selects primitive action `AskSlot(a,b,s)`.

    **Primitive `AskSlot(a,b,s)` semantics in the extended interpreter U:** reject if either slot lacks a unique M-image or the two images coincide. Read the unique original labels `i,j` with `M(a,i)` and `M(b,j)`. Call the existing comparison oracle exactly once on original labels `(i,j)`. It returns the smaller original label `z`; if `z=i`, insert `H(i,j)`, otherwise insert `H(j,i)`; increment `qcount` exactly once; set the unique answer register to `Ans(LT)` iff `z=i`, otherwise `Ans(GT)`; and set `Ctl(s)`. The primitive is enabled only with a unique selected `AskSlot` action; malformed states reject before the oracle call, while valid calls consume exactly one comparison. Thus the FO formula selects slots, while the fixed interpreter explicitly translates through `M` before the charged query. There is no direct access to the hidden order other than this one oracle call. A deterministic implementation scans the explicit M table and performs one ordinary oracle call; it is not a unit-cost table oracle.

2. **Select the path edge.**
   `Ctl(r) AND Ans(o) AND Edge(r,o,e,t)`
   with free variables `r,o,e,t` selects primitive `Goto(e,t)`.

   **Primitive `Goto(e,t)` semantics in U:** enabled only with a unique selected `Goto` action; atomically replace `M` by `M'` where, for every new slot `w` and label `y`,
   `M'(w,y) iff exists x (Perm(e,x,w) AND M(x,y))`; then set `Ctl(t)` and clear `Ans`. This equation defines the primitive store transition; it is not an additional FO(TC) rule formula. Before the transition, U validates that the selected edge has exactly n distinct old-slot/new-slot pairs, each coordinate is in `[n]`, and both projections are bijections; it rejects duplicate, missing, out-of-range, or nonfunctional entries. It also validates that current `M` is the graph of a bijection. U then computes the new explicit n-by-n bit table by deterministic loops and commits it atomically; malformed state rejects. The transition preserves bijectivity.

3. **Emit the certified leaf order.**
    `Ctl(r) AND OutPos(p) AND LeafOrder(r,p,x) AND M(x,y)`
    with free variables `r,p,x,y` selects primitive `Emit(p,y)`. `Emit` is permitted only at a reachable leaf, with `p` the current next unwritten position and `1<=p<=n`; it writes label `y` once and advances `OutPos`. Initialize `OutPos` to 1 and use `n+1` as the final sentinel. Thus for `n=0`, the initial position already equals the sentinel and the root leaf can immediately halt without an Emit. At the final sentinel, `Ctl(r) AND IsLeaf(r) AND OutPos(p) AND FinalPosition(p)` selects `Halt` (two variables). These guards are mutually exclusive: `LeafOrder` has positions only `1..n`, while `FinalPosition` holds only at `n+1`. The outer verifier still checks that the output is a permutation sorted by the actual input order and that `qcount <= k`.

There is no TC occurrence in these rule bodies; they are FO formulas and therefore belong to FO(TC)_4, using the single reused pool V above. Relation arity is at most four (`Query` and `Edge`). The compiler's acyclic reachability and order computation are ordinary polynomial-time preprocessing, not a claim that TC supplies mutable store updates. The primitive extension is an explicit change to fixed interpreter U; the current draft does not already contain `AskSlot` or the M-changing `Goto` semantics.

## Correctness invariant

For the actual root-to-current-node edge path `P`, let `rho_P` map each current slot to its original label, initially identity. Maintain

`M(a,i) iff i = rho_P(a)`.

It holds at the root. If edge `e` has old-to-new permutation `pi`, `Goto` sets `M_new(pi(a),i) iff M_old(a,i)`, so `rho_{P e}(pi(a)) = rho_P(a)`, equivalently `rho_{P e} = rho_P o pi^{-1}`. This is the inverse-coordinate direction required when the checker moves each old relation slot `a` to new slot `pi(a)` (`_rename`, lines 32–41).

At query node `(a,b)`, `AskSlot` compares exactly the original labels occupying those slots; `LT/GT` therefore selects the same feasible outcome as the certificate. At joins, the runtime store follows the actual incoming path. Independently, the checker intersects incoming guaranteed-order relations; this can only discard facts, so its relation at each reachable node remains true of every actual run reaching that node. At a reachable leaf the checked relation is a strict total order; `LeafOrder` lists that order, and mapping its slots through `M` emits the actual input labels in sorted order. Both claims are universal over every input permutation. Repeated queries remain correct and charged because each `AskSlot` invokes the oracle and increments the counter again.

## Size and clock accounting

Let `C` include the explicit DAG, all edge permutations, and its encoding. The checker/compiler can validate node types, forward edges, query slots, edge permutations, reachability, path budget, partial-order propagation, and leaf totality in polynomial time in `n+C` (for example, a straightforward dense implementation is polynomial in `C` and `n`). Tables have at most polynomially many explicit tuples: `Perm` and `LeafOrder` use at most `O(Cn)` tuples; `M` and `H` can be dense `O(n^2)` tables. The augmented domain has size `N'=Theta(n+k+C+1)`.

A run visits at most `C` DAG nodes. It performs at most one `AskSlot` and one `Goto` per internal node, then at most `n` emits and one halt: at most `2C+n+1` actions and at most `k` charged comparisons. Since the explicit certificate and action tables are included in program encoding, `C` and the table tuple counts are polynomially bounded by `|p|+n`; no succinct relation lookup is used. For a concrete bit-time bound, encode each domain element by a fixed-width `w=ceil(log2(N'+1))` bit string; encode each static relation as a length-prefixed list of fixed-width tuples and each dynamic binary relation as an explicit `n`-by-`n` bit matrix. Let `B=O((Cn+C+n^2)w)` upper-bound the static tables and mutable relations (with a fixed constant number of tables); explicit edge permutations imply `nC=O(C)` for `n>=2`, and `n<2` is a trivial small-domain case, so `B` is polynomial in `n+C`. Include all remaining configuration data explicitly: the control/answer/output-position registers, counter, output buffer, and fixed interpreter scratch/work tapes. The registers and counter use `O(w)` bits each, the output buffer uses `O(nw)`, and the fixed tape algorithms use `O(B)` workspace, so the complete configuration length `B_*` is `O(B)` (increasing its constant if necessary). The interpreter can validate and scan/copy/write this representation in `O(B_*^2)` deterministic bit steps per primitive transition by simple sequential-tape algorithms. To avoid random access, implement a requested matrix-bit update by a sequential scan and full rewrite, also within `O(B_*^2)`; output verification costs `O(B_*^2)`. Query handling reads two `O(w)`-bit labels, calls the one comparison oracle, and updates one `H` bit within this same bound. There are at most `2C+n+1` actions. Every selector formula is a fixed-size FO formula with at most four variables over explicitly tabulated relations, hence can be evaluated by enumerating at most `N'^4` assignments and scanning the encoded tables in `O(B_*)` per atom; this costs `O(N'^4 B_*)` per rule, a deliberately crude explicit bound. Certificate validation and checker propagation admit a fixed polynomial `P_check(n+C)` bit-time by scanning the explicit input and using n-bit row representations. Consequently a full run is bounded by

`T(n,k,C) <= P_check(n+C) + (2C+n+1) * (K N'^4 B_* + K B_*^2) + K B_*^2`

for a fixed implementation-dependent constant `K` (including input parsing, table validation, and output verification). For a selected fixed polynomial certificate bound `C <= (n+k+2)^r`, both `N'` and `B_*` are polynomial in `n+k`, so this displayed expression is at most `(n+k+2)^A` for some fixed integer `A`. Choose fixed action exponent `d` to dominate `2C+n+1`, and fixed machine-clock exponent `c>A`; they depend only on `r` and the fixed interpreter implementation, never on the instance. This is a bit-time polynomial, not a unit-cost table model.

## Scope and unresolved theorem

This construction would show that the explicit mutable-frame extension can replay **any supplied accepted certificate, on root-reachable executions**, with polynomial overhead, provided the extended interpreter implements the deterministic primitives and fixed clock just specified. It does not show that a polynomial-size accepted certificate of height `S(n)` exists for every `n`; that remains the central open #47 completeness question. It gives no unrestricted NP or Sigma2P membership consequence absent that completeness theorem. It also does not silently change the semantics of the existing FO(TC) draft: `AskSlot` and atomic frame-updating `Goto` must be adopted as explicit fixed-interpreter primitives for this conditional compiler lemma to apply.
