# Minimal winning-state bases can be superpolynomial

**Result ([deduction] + [literature]).** A natural exact-search compression
does not admit a polynomial-size basis uniformly over explicit comparison
budgets. There is a fixed explicit valid sorting bound

```text
H(n) = ceil(log2(n!)) + n ceil(log2(n+1))
```

such that, for `t=floor(n/4)` and all sufficiently large `n`, the set of
inclusion-minimal winning posets reachable in exactly `t` comparisons with
remaining budget `H(n)-t` has size at least

```text
n! / ((n-2t)! t!) = 2^((1/4+o(1)) n log2 n).
```

This rules out polynomial-size *relation-inclusion dominance bases* at these
budgets. It is not a lower bound for arbitrary exact evaluators, symbolic
representations, or the exact-optimal budget `S(n)`; `H(n)` deliberately has
superlinear additive slack over the information bound.

**Stronger existential-slack corollary.** Fredman's `O(n)` theorem also gives
the same lower bound at a budget `H_D(n)=ceil(log2(n!))+D n` for some fixed
integer `D`, so the additive slack need only be linear. Choose `D` larger
than Fredman's absolute additive constant and large enough to dominate the
merge-sort excess over `ceil(log2(n!))`; then `H_D(n)` is a valid sorting
upper bound and the displayed family is winning with residual budget
`H_D(n)-t`. The currently cited source statement gives only `O(n)` here, so
this argument does **not** identify a numerical `D`; the explicit `H(n)` in
the main theorem remains the effective, constant-free formulation. This still
does not reach `S(n)`, whose surplus over `ceil(log2(n!))` is `o(n)`.

`[experiment]` Small-sample consistency check of the Fredman premise on this
exact family (exact DP over comparison trees; ad-hoc script, not integrated;
not a proof): for `t=n/4` oriented matchings the maximal slack
`F(P) - log2(e(P))` stayed sublinear — `n=5`: 0.093 total (0.019 per n);
`n=6`: 0.508 total (0.085 per n); at `n=7` the exact DP exceeded a practical
time bound, so no larger sample was obtained.

## Proof

Fix `t` disjoint unordered pairs from `[n]`, and orient each pair in either
direction. Let `P` be the resulting poset: each oriented pair is a two-element
chain, and the other `n-2t` elements are singleton chains. There are

```text
choose(n,2t) (2t)!/(2^t t!) 2^t = n!/((n-2t)! t!)
```

distinct labelled posets. Each is reachable from the antichain in exactly `t`
legal comparisons, by comparing the `t` disjoint pairs. Its strict relation
set contains exactly `t` ordered pairs, and its number of linear extensions
is `e(P)=n!/2^t`.

Let `R[n,t]` be the posets reachable in exactly `t` comparisons and
`W[n,t,r]={P in R[n,t]: F(P)<=r}`. Every `t`-comparison history establishes
at least `t` distinct comparable unordered pairs: a queried pair cannot be
queried again after its outcome makes it comparable. Thus if `Q in R[n,t]`
has its relation set contained in that of one of the constructed `P`, it has
at least `t` comparable pairs and at most `t`; equality forces `Q=P`. So
every constructed state is inclusion-minimal in *any* subset of `R[n,t]`, in
particular in `W[n,t,r]` whenever it is winning. Pairwise incomparability
alone would not imply this; the exact `t`-relation count is essential.

Fredman’s partial-information sorting theorem gives, uniformly for every
finite poset `P`,

```text
F(P) <= log2(e(P)) + c n
```

for some absolute constant `c` (the `O(n)` additive term in M. L. Fredman,
“How good is the information theory bound in sorting?”, *Theoretical
Computer Science* 1(4), 1976, 355–361, DOI 10.1016/0304-3975(76)90078-5).
Consequently the constructed `P` satisfy

```text
F(P) <= log2(n!) - t + c n.
```

For all sufficiently large `n`, `ceil(log2(n+1))>=c`, so
`F(P)<=H(n)-t`. The budget is nonnegative for these `n`.

The function `H` is a valid explicit upper bound on `S(n)`: balanced mergesort
uses at most `n ceil(log2 n)` comparisons, while
`H(n)>=n ceil(log2(n+1))>=n ceil(log2 n)`.

Finally, with `t=floor(n/4)`, Stirling’s formula yields

```text
log2(n!/((n-2t)! t!)) = t log2 n + O(n)
                       = (1/4+o(1)) n log2 n.
```

This proves the stated minimal-basis lower bound.

## Scope and falsification checks

The proof uses only the uniform partial-information guarantee from Fredman;
it does not assume that the strategy is polynomial-time. The choice of `H`
avoids relying on an effective numerical value of Fredman’s hidden constant:
the explicit `n ceil(log2(n+1))` slack eventually exceeds any fixed `c n`.
The construction is also checked by `scripts/minimal_winning_basis.py` and
`tests/test_minimal_winning_basis.py` for small `n`. Those finite checks test
the counting and antichain claims; the all-`n` conclusion comes from the
paper argument and Fredman’s theorem, not from enumeration.

**Consequence.** A compression scheme that stores only inclusion-minimal
winning states at each fixed `(n,t,r)` cannot have a polynomial-size worst-case
basis across all valid explicit budgets. This does not preclude other state
summaries, nor prove a time lower bound for `S(n)` or `SORT-BOUND-U`.
