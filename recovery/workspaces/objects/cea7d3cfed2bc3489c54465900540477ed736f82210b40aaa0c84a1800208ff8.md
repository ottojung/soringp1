## 1. Concrete `Rbar` / `Fld` / `FrameEq'` instantiation

`[definition]` The whole configuration is an interpretation of `Rbar` with
globals and live-frame table `E(Rbar)` as in normalized `Enc` §0 / realization
§1.2, revised by adding `CurExhausted`:

```text
Rbar := (Top,CurBase,EmptyStack,HaltAcc,HaltRej,
         M_Eval,M_BackE,M_BackA0,M_BackA1,
         RetNone,RetAcc,RetRej,
         CtrlSort,CtrlAdv,CtrlAcc,CtrlRej,
         UsedF,HasSel,SelA,SelB,
         HasCur,CurA,CurB,CurExhausted,   -- revised BackE cursor
         PosF,Parent,FrameLive).

Globals := (Top,CurBase,EmptyStack,HaltAcc,HaltRej).
E(Rbar) := [Globals] ⊕ [live-frame table: FrameLive(c̄) fields, incl. PosF(c̄,·,·)].
```

`[definition]` Concrete frame component tuple (includes `CurExhausted`):

```text
Fld(c̄) := ⟨Mode,Ret,Ctrl,UsedF,HasSel,SelA,SelB,
            HasCur,CurA,CurB,CurExhausted,PosF,Parent⟩

```

`[definition]` **Cursor-state coherence** (closes audit §6.1,2). `HasCur` is the
cursor-state presence field; `CurExhausted` distinguishes exhausted vs normal
state; `CurA,CurB` carry a normal witness only in the normal state. A fixed
designated null `SentinelNull := (MinKey,MinKey)` is used as the concrete
exhausted encoding for realizations requiring total `CurA,CurB` fields;
`SentinelNull` is **never** interpreted as `CurNormal` because `CurExhausted`
must hold when it is used and `CurNormal` requires `¬CurExhausted`.

```text
CurNormalState(c̄,a,b) := ¬CurExhausted(c̄) ∧ HasCur(c̄) ∧ CurA(c̄,a) ∧ CurB(c̄,b).
CurNormalState(c̄)     := ∃a∃b CurNormalState(c̄,a,b).

CurExhaustedState(c̄)  := CurExhausted(c̄) ∧ HasCur(c̄)
                        ∧ CurA(c̄,MinKey) ∧ CurB(c̄,MinKey)
                        ∧ ¬CurNormalState(c̄).

CursorCoherent(c̄) :=
      ( CurNormalState(c̄)
        ∧ ∃!a∃!b(CurA(c̄,a)∧CurB(c̄,b))
        ∧ ¬CurExhausted(c̄) )
    ⊕
      ( CurExhaustedState(c̄) ).

-- equivalently: CurExhausted(c̄) xor CurNormalState(c̄),
-- with total HasCur/CurA/CurB and unique witnesses in each case.
```

`[deduction]` `CurExhaustedState` uses `MinKey,MinKey` as a total concrete
encoding only; `CurNormalState` is excluded there by `¬CurExhausted(c̄)`. Thus
no sentinel ordinary pair is consulted as a normal NI witness: NI requires
`¬CurExhausted ∧ CurNormalState`.

`[definition]` Frame-equality / preservation helpers (concrete, include
`CurExhausted`):

```text
FrameFieldsEq'(x̄) := equality of all Fld components for x̄ and x̄',
                     including CurExhausted, with no implicit liveness change.
FrameEq'(x̄)       := FrameFieldsEq'(x̄) ∧ (FrameLive'(x̄) <-> FrameLive(x̄)).
FrameInactive'(x̄) := ¬FrameLive'(x̄).
LowerStackPreservedExcept(S) :=
  ∀x̄(FrameLive(x̄) ∧ ¬S(x̄) -> FrameEq'(x̄)).

PreserveNonMarkerFields(p̄) :=
  FrameLive'(p̄)
  ∧ preserve every Fld component of p̄ except Ret
  ∧ (RetAcc'(p̄)∨RetRej'(p̄)∨RetNone'(p̄) decided only by the row's marker clause).
  -- explicitly preserves Mode,Ctrl,UsedF,HasSel,SelA,SelB,HasCur,CurA,CurB,
  -- CurExhausted,PosF,Parent and FrameLive.

MarkRetAccOn(p̄) :=
  FrameLive'(p̄) ∧ RetAcc'(p̄) ∧ ¬RetRej'(p̄) ∧ ¬RetNone'(p̄)
  ∧ PreserveNonMarkerFields(p̄).

MarkRetRejOn(p̄) :=
  FrameLive'(p̄) ∧ RetRej'(p̄) ∧ ¬RetAcc'(p̄) ∧ ¬RetNone'(p̄)
  ∧ PreserveNonMarkerFields(p̄).
```

`[deduction]` `CurExhausted` is in `Fld` and `FrameFieldsEq'`; therefore
`LowerStackPreservedExcept(S)` preserves it for live frames outside `S`, and
`MarkRet*On`/`PreserveNonMarkerFields` preserve it for `p̄` even when `Ret`
changes.

## 3. `SetParentBackE_Advance` (concrete)

`[definition]` (closes v1/audit IsLastLex2 branch and CurExhausted interaction).
`Lex2,SuccLex2,IsLastLex2,Incomp_c,Total_c,Budget_c,P_c,NextIncomp_c,
NoNextIncomp_c,SuccCtr,StepPosBit_c,PostBudgetFrom,Root,NonRoot,CfgAcc_c,
CfgRej_c` are fixed as in normalized `Enc` §0/§1.5 / realization §1.3.

```text
NextIncomp_c(a,b;x,y) := Lex2(a,b,x,y) ∧ Incomp_c(x,y)
                       ∧ ¬∃u∃v(Lex2(a,b,u,v) ∧ Lex2(u,v,x,y) ∧ Incomp_c(u,v)).
NoNextIncomp_c(a,b)   := ¬∃x∃y(Lex2(a,b,x,y) ∧ Incomp_c(x,y)).

SetParentBackE_Advance(c̄,x,y) :=
    FrameLive'(c̄)
  ∧ M_BackE'(c̄) ∧ ¬M_Eval'(c̄) ∧ ¬M_BackA0'(c̄) ∧ ¬M_BackA1'(c̄)
  ∧ RetNone'(c̄) ∧ ¬RetAcc'(c̄) ∧ ¬RetRej'(c̄)
  ∧ CtrlSort'(c̄) ∧ ¬CtrlAdv'(c̄) ∧ ¬CtrlAcc'(c̄) ∧ ¬CtrlRej'(c̄)
  ∧ HasCur'(c̄)
  ∧ (
        ( ¬IsLastLex2(x,y)
          ∧ ∃x'∃y'(SuccLex2(x,y,x',y') ∧ CurA'(c̄,x') ∧ CurB'(c̄,y'))
          ∧ ∀a∀a'(CurA'(c̄,a)∧CurA'(c̄,a')->a=a')
          ∧ ∀b∀b'(CurB'(c̄,b)∧CurB'(c̄,b')->b=b')
          ∧ ¬CurExhausted'(c̄) )                 -- CurNormalState'
      ∨
        ( IsLastLex2(x,y)
          ∧ CurA'(c̄,MinKey) ∧ CurB'(c̄,MinKey)  -- concrete exhausted encoding
          ∧ CurExhausted'(c̄) )                   -- CurExhaustedState', no normal
    )
  -- preserved non-cursor frame fields of c̄:
  ∧ HasSel'(c̄)<->HasSel(c̄)
  ∧ ∀a(SelA'(c̄,a)<->SelA(c̄,a)) ∧ ∀b(SelB'(c̄,b)<->SelB(c̄,b))
  ∧ ∀t(UsedF'(c̄,t)<->UsedF(c̄,t))
  ∧ ∀u∀v(PosF'(c̄,u,v)<->PosF(c̄,u,v))
  ∧ ∀p̄(Parent'(c̄,p̄)<->Parent(c̄,p̄)).
```

`[deduction]` On `¬IsLastLex2(x,y)`, `SuccLex2` gives a unique strict successor
`(x',y')`; `CurExhausted'` is false and `CurNormalState'(c̄,x',y')` holds. On
`IsLastLex2(x,y)`, `CurExhausted'` is true and the concrete total cursor is
`(MinKey,MinKey)` with `HasCur'`; `CurNormalState'` is false by
`¬CurExhausted'` in its definition, so no normal NI witness is produced.

`[open]` `SuccLex2` must be total on non-last pairs and functional; `IsLastLex2`
must be the exact complement for selected pairs. The realization must encode
`CurExhausted` and the exhausted `CurA/CurB` values as in this component-closure
shape.
