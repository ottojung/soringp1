## 1. Question

For finite posets `A`, `B` on disjoint ground sets, with `A^op` the order dual of `A` and `+` the disjoint (parallel) union, define

    D(A,B) = | F(A^op + B) - F(A + B) |,

where `F(P)` is the exact minimax adaptive comparison-sorting cost from poset state `P`:

    F(P) = 0 if P is total;
    F(P) = 1 + min_{x || y} max(F(P+x<y), F(P+y<x)) otherwise.

Question: is `D(A,B) <= 1` for all finite `A,B`, or can `D` be arbitrarily large?

Consequence: a small universal bound would give a symmetry reduction for disjoint-union states; an unbounded defect would show high sensitivity to component orientation and rule out simple additive decompositions.

## 2. Method

- Exact poset-state minimax solver with memoization over transitively closed successor-bitmask posets.
- Cross-checked against an independent extension-set minimax solver on all ordered pairs with `|A|+|B| <= 5` (246 instances), all unlabelled poset classes through `n = 6` (406 classes), and a 100-pair random sample at total size 6; agreement in every case.
- Poset isomorphism classes via the repository's refined canonical form (`scripts/benchmark_symmetry_quotients.py`: 2-D colour refinement plus lexicographically least encoding over colour-preserving relabellings; complete invariant). Class counts match OEIS A000112.
- Disjoint union encoded with the required block shift: `succ_{A+B}[|A|+i] = succ_B[i] << |A|`. Dual via the repository `dual()`.
- For each total size `n = |A|+|B|`, enumerated all ordered pairs of unlabelled posets `(A,B)` with sizes summing to `n`, formed `A+B` and `A^op+B`, canonicalized both, and looked up exact `F` from `quotient_classes(n)`.

This is finite exhaustive computation only. It is not a proof and not a disproof.

## 4. Constructed examples

No example with `D >= 1` was found through total size 8. Every enumerated ordered pair satisfies

    F(A^op + B) = F(A + B)

exactly. Thus there is no concrete family with defect `1`, `2`, or larger in the checked range, and no witness for an unbounded defect.

For context, a restricted theorem is already known (see `docs/research-parallel-duality.md`): if `B` is self-dual up to relabelling, then `F(A^op+B)=F(A+B)` (defect 0). The checked range extends this equality empirically to non-self-dual `B` as well, but no proof of the general case is claimed.

## 5. Proved vs conjectured

- Proved: the restricted case `B` self-dual (defect 0).
- Finite evidence only: `D = 0` for all 46,481 ordered pairs with `|A|+|B| <= 8`.
- Neither proved nor refuted: a universal bound `D <= 1` (or `D = 0`) for all finite posets; an unbounded defect; or a first witness with `D >= 2`.
- The stop condition for this front asked for either a proved bound or a concrete family with defect at least 2. Neither has been obtained. The computation is an honest boundary result: no counterexample and no theorem.
