## Sharp, falsifiable all-`n` question
For finite posets `A,B` on disjoint ground sets, let `A^op` be the dual, `A+B` the disjoint (parallel) union, and
`F(P)=min_T height(T)` the exact minimax adaptive comparison-sorting cost (model of `docs/problem.md`):
`F(P)=0` if `P` is total, else `F(P)=1 + min_{x,y incomparable in P} max(F(P+(x<y)), F(P+(y<x)))` with transitive closure.
Define the component-reversal defect
`D(A,B)=|F(A^op + B) - F(A + B)|`.

**Question (all finite `A,B`):** is `D(A,B) <= 1` always, or can `D(A,B)` be arbitrarily large? A single pair with `D(A,B) >= 2` is a concrete refutation of the `<=1` bound; an all-`A,B` proof of `D<=c` (or unboundedness) would be a theorem.

## Attempted falsification / proof
- **Literature/prior context (literature/deduction, as reported in front artifacts):** restricted theorem known in prior notes: if `B` is self-dual up to relabelling then `D(A,B)=0`. This does not settle non-self-dual `B`.
- **Exact exhaustive computation (experiment; evidence from `component-reversal-defect-20261111/comment_301.md` and `results_max8.json`, not independently recomputed in this session):**
  - Two exact minimax solvers implemented and cross-checked (`defect_probe.py`): (1) poset-state (transitively-closed successor-bitmask tuples) with memoization; (2) extension-set (frozenset of consistent linear extensions/rank arrays) with memoization.
  - Cross-checks reported: exhaustive all ordered pairs with `|A|+|B| <= 5` (246 pair-instances, both forms) agree; all individual unlabelled poset classes for `n <= 6` (406 classes) agree; random sample of 100 ordered pairs with `|A|+|B|==6` agree; poset-state `F` agrees with precomputed `F` from `quotient_classes` for all `n<=7` classes.
  - Unlabelled poset enumeration via `quotient_classes(n)` / `make_refined_canon(n)` (2-D colour refinement + lex-min canonical form), counts matching OEIS A000112 for `n=0..8` (1,1,2,5,16,63,318,2045,16999). `F` tables for unions obtained by canonicalizing `A+B`, `A^op+B` and lookup.

## Result
- **No counterexample found:** no pair with `D(A,B) >= 1` among all exhaustively checked ordered pairs with `|A|+|B| <= 8`.
- **No theorem proved:** the all-`n` (all finite `A,B`) bound/refutation remains **open**. Finite exhaustive evidence `D=0` for `|A|+|B| <= 8` does **not** imply `D<=1` (or `D=0`) universally, nor boundedness/unboundedness.

## Precise boundary / obstruction
- **Checked boundary:** exhaustive up to total size 8 (46,481 ordered pairs). Unchecked: `|A|+|B| >= 9`.
- **Computational obstacle at next size (as reported):** total size 9 would require `F` for 183,231 unlabelled poset classes and ~400k+ pair evaluations/canonicalizations; not attempted.
- **Conceptual obstacle:** defect `D` compares minimax values of two disjoint-union games differing by reversal of one component. Reversal preserves extension counts/order-theoretic duality in some forms but minimax `F` is not known to be invariant under component reversal inside a parallel union; no all-`n` invariant/recurrence found that controls `|F(A^op+B)-F(A+B)|`. Known exact recurrences handle series/parallel composition only in special cases and do not by themselves yield a uniform defect bound.

## Consequence for evaluating `S(n)` / SORT-BOUND-U
- **No change to known uniform bounds.** A universal small bound like `D(A,B)<=1` for all components, if proved, would be a structural theorem about the minimax game on disjoint unions (potentially useful for state compression/decomposition heuristics in exact evaluation) but would not by itself yield a faster uniform evaluator, a space improvement, NP/coNP membership, or any separation for `SORT-BOUND-U = {1^n#1^k : S(n)<=k}`. Unbounded defect, if witnessed, would be a negative structural fact limiting reversal-based reductions/compressions. Either outcome is currently only a hypothesis/empirical observation; **no established consequence for `S(n)` or SORT-BOUND-U follows from present evidence**.
