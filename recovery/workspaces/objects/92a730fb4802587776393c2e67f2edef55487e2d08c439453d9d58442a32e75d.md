# First forced depth of the information/leaf-count obstruction (falsifiable analysis)

**Date:** 2026-11-17  
**Scope:** research note in `exec-report.md` only (no Lean, no other repo edits).  
**Model:** adaptive worst-case pairwise comparison sorting of `n` distinct labelled keys (`docs/problem.md`).

## 1. Definitions

`[definition]` (standard, from `docs/problem.md`, `docs/research-n12-nontightness.md`)
- `S(n)`: minimum worst-case number of comparisons of any deterministic adaptive comparison tree that sorts every permutation of `n` keys.
- `C(n) := ⌈log₂(n!)⌉`: information-theoretic (leaf-count) lower bound.
- Gap case: `n` with `S(n) > C(n)`.
- State after `c` comparisons: partial order `P` on the `n` keys; `e(P)` is its number of linear extensions. Root: antichain `P₀`, `e(P₀)=n!`.
- A comparison at depth `c` produces children `P+uv`, `P+vu` with `e(P+uv)+e(P+vu)=e(P)`.

`[definition]` (node-level information/leaf-count admissibility for a target height `h`)
- A node/state `P` at comparison depth `c` (after `c` comparisons, with `h-c` comparisons remaining in the budget) **satisfies the leaf-count constraint** iff
  \[
  e(P) \le 2^{h-c}.
  \]
- Equivalently, writing efficiency `E(P)=n!/(2^c e(P))` and `E_{tot}=n!/2^h`, `E(P)\ge E_{tot}` at depth `c` (the "efficiency" pruning condition of Wells/Peczarski/Stober–Weiß is definitionally equivalent to this node-level leaf count; `docs/research-n12-nontightness.md` §4, Stober–Weiß Observation 2.2).

`[definition]` (strategy / tree view)
- A *height-`h` strategy* is a comparison decision tree of height `≤h` (adaptively choosing a pair at each internal node). It *survives the leaf-count constraint to depth `d`* if every node on every root-to-depth-`d` prefix satisfies `e(P) \le 2^{h-c}` at its depth `c`.
- A strategy is *forced to violate the leaf-count constraint at depth `d`* (relative to height `h`) if, at some node reached at depth `< d` while still admissible, no available comparison produces two admissible children for the remaining budget, or more generally if every possible height-`h` continuation from the root reaches an inadmissible node by depth `d`.

`[definition]` (first forced depth; falsifiable quantity)
- For `n` with `S(n)>C(n)`, define
  \[
  d^*(n) := \min\{ d \in \{1,\ldots,C(n)\} : \text{every height-}C(n)\text{ strategy violates the leaf-count constraint at or before depth }d \}.
  \]
  This is well-defined (as an integer) whenever `S(n)>C(n)`, because a height-`C(n)` correct sorting tree would satisfy all leaf-count constraints while having `n!` leaves, but nonexistence of any such correct/surviving tree means every strategy is eventually forced into violation. (Equivalent strategic obstruction: adversary can maintain a position whose remaining information demand exceeds the remaining budget within `d^*(n)` plies.)

`[definition]` (Wells one-sided level view, literature/search object)
- For target `h=C(n)`, let `S_0={P₀}` and let `S_c` be the set of heavier admissible children obtainable from comparisons in `S_{c-1}` under the one-sided Wells exploration; emptiness of some `S_c` certifies nonexistence for cases where one-sided suffices (`docs/research-n12-nontightness.md` §4, Peczarski 2012, Stober–Weiß).

## 2. Falsifiable question and hypothesis

**Question.** For `n` with `S(n)>C(n)`, can `d^*(n)` be characterized or bounded (lower/upper), uniformly or as an explicit function of `n`, in terms of the information/leaf-count constraint or an equivalent strategic obstruction? Is there a *depth-uniform* structural obstruction (a fixed local/prefix condition at some depth depending only on `n,C(n)` that already forces all strategies)?

**Hypothesis H (depth-uniform early obstruction).** There exists a simple function `f(n)` with `f(n)=o(C(n))` (or bounded, or otherwise "early") such that for all sufficiently large gap cases `n`, every height-`C(n)` strategy violates the leaf-count constraint by depth `f(n)` via a uniform local mechanism (e.g. forced perfectly balanced prefix/split constraints independent of strategic choice except a fixed finite pattern).

This is falsifiable: exhibit gap `n` where no uniform early mechanism applies and/or any lower bound on `d^*(n)` must grow in a way incompatible with the proposed `f`; or exhibit a proved uniform `f(n)`.

## 3. Derivation and evidence from known values and literature

### 3.1 Trivial bounds `[deduction]`

- `1 \le d^*(n) \le C(n)` for any gap `n`. Upper bound: after `C(n)` comparisons there is 0 budget left but a non-total state would have `e(P)\ge 2>2^0` impossible for a correct leaf; more directly, nonexistence means violation occurs within the full height.
- At depth `c-1`, a comparison is admissible iff both children satisfy `e(child) \le 2^{C(n)-c}`. Since children partition `e(P)`, the heavier child always has `e(child)\ge ⌈e(P)/2⌉`, so admissibility requires the state not to be too extension-rich relative to remaining budget; however this is necessary-local and not by itself a characterization of `d^*(n)`.

### 3.2 Known gap cases and baseline `[literature]`

From `docs/literature.md`, `docs/research-plan.md`, `docs/research-n12-nontightness.md`:
- `S(n)=C(n)` for `1 ≤ n ≤ 11`.
- `n=12`: `C(12)=29`, `S(12)=30` (Wells 1966/1971). First global gap.
- `n=13,14,15`: information bound missed (Peczarski 2012 §4 discussion; Stober–Weiß context). Exact `S` values not restated as new claims here beyond literature.
- Exact values known for all `n ≤ 22` (Stober–Weiß 2023 settled `S(16)=46`, `S(17)=50`, `S(18)=54`; `n=23` open). `C(16)=45`, so `n=16` is a gap case; similarly for others where `S(n)>⌈log₂ n!⌉` per known tables.
- `S(22)=71` while `C(22)=70` is implied by the slack/ratio table in `docs/research-n12-nontightness.md` (H1: `2^C/22!` small and "no" tight). `[literature/derived from cited table]`
- Asymptotically `S(n)-log₂ n! = O(n/(log n)^{1/5})` (Sergeev), so gaps (when present) are `+O(...)` but existence/pattern for large `n` is delicate.

### 3.3 Evidence on early/local forcing `[deduction + literature + experiment]` (from existing notes)

- **Forced prefix is real but not predictive (H4, n12 note):** for `n=12,h=29`, only `1/2` splits are admissible at depth 1 and the second comparison is forced to pair two free elements (given the all-`1/2` prefix context); chain-free `2/3` and min–max cross-chain `5/6` splits are already inadmissible early. But the same kind of forced second comparison occurs at `n=5,10` which are tight (`S=C`). Therefore an early forced local split condition does **not** imply `d^*(n)` is small in the sense of certifying a global gap, nor does it uniformly separate gap from non-gap cases.
- **Search-certification depth vs strategic obstruction:** `[literature]` Peczarski reports for `n=12` that in Wells' reported one-sided exploration "only the set `S_24` is empty" and one outcome suffices at `n=12` (per extracted text cited in n12 note). `[deduction/caveat]` This is a property of a particular pruned search regime (heavier/admissible one-sided levels), not directly identical to `d^*(n)` over *all* strategies; still, it is strong evidence that for `n=12` no obstruction is found at very shallow depths and that the certified exhaustion occurs deep (on the order of the full budget, 24th one-sided level in that report), consistent with large `d^*(12)$ relative to `C(12)=29`.
- **Not localized by stored search effort:** Stober–Weiß Table 2 for `n=12` (`sortable=no`, ~6190 posets stored, 152 ms, bandwidth 0.05 chosen) describes search effort/pruning thresholds, not a measured small bottleneck window; the obstruction is certified by exhaustive search, not a compact depth-local object (`n12` note §4, §8).
- **Local vs global failures:** local leaf-count/information-bound failures at the poset level appear very early (`n=5`, `e=8`, `m=4` while global `S(5)=7` tight; `L1>L0` witness in `research-one-ply-obstruction.md` at depth-1/local split structure). But local non-tightness does not imply global `S(n)>C(n)` (n12 note H3, §8). Hence any `d^*(n)$ characterization must be strategic/global over the whole antichain-root game, not reducible to existence of some locally bad poset.

### 3.4 Relation to `n ≥ 12` patterns `[literature + deduction]`

- Known pattern: first gap at 12; further misses at 13–15 discussed in literature; exact landscape through 22 known with some gaps and some tight values (e.g. 20 tight per n12 table) — the gap set is not a simple monotone or threshold function of `n` or of scalar slack `2^{C(n)}/n!` (H1 falsified).
- Peczarski’s `n=13` analysis shows strategic/structural non-monotonicity (`P16` sortable in 17 vs predecessors/alternatives not, and fewer extensions can be harder), reinforcing that obstruction depth cannot be read off a single scalar of the current frontier except through full strategic feasibility.
- Sergeev’s asymptotic bound implies `C(n) \le S(n) \le C(n)+o(n)$ in growth terms but gives no effective finite `d^*(n)`.

## 4. Falsification

1. **Falsification of H (depth-uniform early obstruction):** `[deduction from evidence]` Early uniform/local prefix forcing occurs also at tight `n` (5,10) and therefore cannot serve as a uniform witness that `d^*(n)$ is "early" in gap cases; moreover published `n=12` certification evidence points to deep exhaustion (one-sided `S_24` empty) rather than a shallow uniform cutoff. No known theorem gives a uniform `f(n)=o(C(n))$ forcing all strategies at that depth for all gap `n$. Thus H, as stated, is unsupported and is effectively falsified as a *predictive/local* uniform mechanism by current evidence.
2. **What would falsify a "deep obstruction" claim:** a proved shallow certificate for some gap `n` (e.g. a small-depth strategy-elimination argument, or an explicit `d^*(n)$ much smaller than indicated by search) would refute the view that obstruction is inherently deep/global.
3. **Non-falsified (open):** existence of *some* nontrivial upper bound `d^*(n) \le C(n)-g(n)$ or lower bound `d^*(n)\ge g(n)$ as a function of gap structure remains open; current evidence neither proves nor rules out a sharp characterization.

## 5. Assessment: is there a depth-uniform structural obstruction?

`[deduction/conjecture-level assessment]` **No depth-uniform *local* structural obstruction is known, and simple candidates fail.** 
- Uniform split/prefix constraints at very small fixed depths are not specific to gap cases (H4). 
- The leaf-count condition is necessary at every node but its *strategic* violation for all height-`C(n)` trees is certified, in the key known case `n=12`, only by exhaustive/global search reaching deep levels; no compact bottleneck-depth certificate is published.
- A genuinely "structural" obstruction may exist in principle (e.g. an invariant of the rooted minimax game/frontier), but present evidence indicates it is **global and strategic**, not a depth-uniform local rule. Formally: current knowledge supports `d^*(n)$ being determined by the full height-`C(n)` game tree feasibility, with only trivial uniform bounds available.

## 6. Consequence for evaluating `S(n)` / `SORT-BOUND-U`

`[deduction]`
- If a nontrivial, checkable bound or characterization of `d^*(n)$ were found, it could yield: (a) stronger pruning/certificates for the budgeted decision procedure "is $S(n)\le C(n)$?" by early refutation, (b) structural insight into when/why `S(n)=C(n)+1` occurs, potentially narrowing the exact-evaluation search window in those cases. Any such result would matter only insofar as it is proved for the exact adaptive model and measured against the relevant input encoding.
- The absence of a known depth-uniform/local obstruction means we cannot currently shortcut the gap question by a fixed-depth test; exact gap certification remains tied to deep strategic search/exhaustive methods in known difficult cases, consistent with the broader barrier picture (`docs/research-plan.md`, winning-frontier/state explosion considerations).
- No complexity-class separation follows: a comparison/strategy lower bound at height $C(n)$ is about $S(n)$, not about the Turing complexity of computing $S(n)$ or deciding `SORT-BOUND-U` beyond established inclusions (`SORT-BOUND-U ∈ PSPACE`).

## 7. Summary of claim labels

- **Literature:** exact values/bounds and search results for $n=12,13$–$15,16$–$18,≤22$; Wells/Peczarski/Stober–Weiß/Sergeev facts as cited in repo docs.
- **Definition:** $S,C,e,L0,E,d^*$, admissibility, first forced depth.
- **Deduction:** trivial bounds on $d^*$, equivalence of efficiency/leaf-count node condition, interpretation limits (search-level vs all-strategy $d^*$), consequences.
- **Experiment (as reported in existing notes):** forced-prefix computations, small-$n$ exhaustive minimax/local-gap and $L1$ witnesses; not re-run here.
- **Conjecture/assessment:** no known depth-uniform local obstruction; obstruction appears global/strategic; sharp $d^*(n)$ characterization open.

**Bottom line:** for gap $n$, $d^*(n)$ is well-defined but currently has no known nontrivial uniform characterization or depth-uniform structural certificate; evidence from $n=12$ and related cases points to a deep, strategic (not early local/uniform) leaf-count obstruction, while the precise first forced depth remains an open, search-certified phenomenon.
