## 2. Model and defect definitions (`definition`, aligned with `docs/problem.md`)

- For a finite strict partial order `P` on `n` labelled keys, `F(P)` is the minimax worst-case number of further adaptive pairwise comparisons to identify the unknown linear extension (complete the order): `F(P)=0` if `P` is total, else `F(P)=1+min_{x||y} max(F(P∪{x<y})^*, F(P∪{y<x})^*)` with `^*` transitive closure. `S(n)=F(A_n)` where `A_n` is the antichain.
- For posets `A,B` on disjoint ground sets, the **disjoint (parallel) union** `P=A ⊔ B` has `x <_P y` iff `x <_A y` or `x <_B y` (no cross relations). Encoding requires shifting `B`'s labels/masks (`docs/research-parallel-duality.md` § "Encoding invariant").
- Define the **disjoint-union additivity defect** (interaction cost)
  \[
  \delta(A,B) := F(A ⊔ B) - F(A) - F(B).
  \]
  This measures extra comparisons caused by cross-component incomparabilities relative to the components' standalone minimax costs. (It is not the separate component-reversal defect `D(A,B)=|F(A^op ⊔ B)-F(A ⊔ B)|` discussed on #301; that prior "at-least-two" discussion is distinct.)

**Basic deductions (`deduction`):**
- `\delta(A,\emptyset)=\delta(\emptyset,B)=0`.
- `F(A ⊔ B) >= F(A)` and `>= F(B)` by restriction/monotonicity intuition is not immediate as a one-line theorem here without care, but `F(A ⊔ B) >= max(F(A),F(B))` follows because an optimal strategy for `A ⊔ B` induces a strategy for sorting `A` given any fixed linear extension context? more directly, projecting/adversary can force solving each component: an adversary can answer comparisons consistently with some extensions making cross comparisons non-resolving in a way that still leaves A's order unknown except through A-comparisons — formally, `L(A ⊔ B)` corresponds to interleavings and `F` is at least the cost to identify the A-projection in worst case, hence `>=F(A)`. (This is the easy direction of the deterministic direct-sum intuition but parallel union is not a clean product relation; however `F(A ⊔ B) >= F(A)+0` is plausible and supported by all evidence; a full all-n proof of this specific inequality was not re-derived here.)
- Unlike ordinal sum, `\delta` can be positive and large relative to naive separate handling: e.g. singleton ⊔ singleton gives `F=1, F(A)+F(B)=0, \delta=1`; total components inside a larger non-total union give larger `F(A ⊔ B)` than `0`.

## 4. Sharp falsifiable all-n question (identified)

**Q (minimal-size/threshold, all `n`):** For every pair of finite posets `A,B` on disjoint ground sets, let `m(A,B)=min(|A|,|B|)` and `n(A,B)=|A|+|B|`. Is the universal threshold inequality
\[
\forall A,B\,(n(A,B)\ge 3 \implies \delta(A,B) = F(A \sqcup B)-F(A)-F(B) \ge m(A,B)+1)
\]
true for all finite `n(A,B)`?

**Equivalent threshold form:** `T(n):=\min\{\delta(A,B): n(A,B)=n, |A|,|B|\ge1\}` satisfies `T(n) >= 1 + \min_{1\le a\le n/2} a = 2` in the weak sense, but the size-sensitive sharp question is whether the **per-pair** lower bound `m(A,B)+1` is universal. A single explicit finite pair with `n(A,B)>=3` and `\delta(A,B) <= m(A,B)` is a **falsifier**.

**Minimal-size aspect (exact boundary identification):**
- Minimal total size with any defect above separate-component costs in checked data: `n=3` gives `\delta>=2`.
- Minimal universal constant defect over all `n>=3`: cannot be >2 because `(1,2)` achieves `\delta=2 = m+1`.
- Therefore the exact minimal-size/threshold content splits into: (i) global floor `\delta>=2` for `n>=3` (weaker, would be implied by (ii) only when `m>=1` gives 2 but note `m=1` cases give bound 2) — actually (ii) implies `\delta>=2` since `m>=1 => m+1>=2`. Conversely any falsifier of (ii) at `m>=2` could still satisfy `\delta>=2`.
- **Primary sharp question:** universality of the size-sensitive threshold `m(A,B)+1` for all `n`.
- **Secondary minimal-threshold question:** is `\delta(A,B) >= 2` for all `n(A,B)>=3`? (also open all-n from proof perspective, but weaker where `m>=2`).

## 5. Consequence for evaluating `S(n)` / `SORT-BOUND-U` (`deduction`, conditional)

- **If true (all-n):** yields a rigorous structural lower-bound law for every disjoint-union state reachable during adaptive sorting. Since many partial-information states decompose into parallel components in special cases, any exact search or certificate scheme that reasons compositionally over parallel blocks would gain a sound per-split comparison deficit bound `F(A⊔B) >= F(A)+F(B)+m+1`, potentially pruning/certifying branches without enumerating interleavings. This is directly about the minimax game defining `S(n)=F(A_n)` (and states arising from it), not arbitrary unrelated problems.
- **Complexity consequence:** a standalone structural inequality does **not** by itself place `SORT-BOUND-U` in P/NP/PSPACE or prove separations. It could, however, be a lemma in a future improved evaluator or space/certificate argument; conversely, absence of such a theorem is a **blocker** to claiming that decomposition route.
- **If false:** an explicit falsifying family `(A_t,B_t)` with controlled growth of `n` would exhibit unexpectedly efficient interleaving across components, a nontrivial phenomenon for optimal strategy structure and a constraint any proposed compositional/exact recurrence must respect.

## 6. Falsification attempts and status (`experiment`/`deduction`/`blocker`)

- **Finite falsification (done, prior):** exhaustive unlabelled search found **no** counterexample to `\delta >= m+1` for `n<=8` (`experiment`, reported; partially independently confirmed through totals <=6). Tight witnesses exist, so the bound cannot be strengthened to `m+2` uniformly.
- **Small/degenerate cases (`deduction` consistent with data):** components of size 1 give bound 2; chains/antichains in checked splits satisfy it. No analytic counterexample identified in audited repo notes.
- **Why not resolved all-n (precise blocker):**
  1. `F` is the exact minimax value of an adaptive game; interleaving creates cross relations dynamically, so `F(A⊔B)` is not reducible to a static function of `(F(A),F(B),e(A),e(B),m)` by known invariants (cf. non-determination phenomena: `e(P)` does not determine `F`, comparability-graph/value subtleties; `research-n12-nontightness.md`, `research-compression-next.md`).
  2. No decomposition theorem for parallel composition analogous to ordinal-sum additivity is known; direct-sum lower-bound methods for independent relations do not transfer because cross comparisons couple components.
  3. Exhaustive verification scales at least with poset/state growth (A000112/A001035) and pair blow-up; `n=9` already requires ~183k class F-values and large pair counts — feasible only with substantial optimized computation, and still finite.
  4. Therefore: **neither a proof for all relevant `n` nor a counterexample family is established**. The exact all-n status of Q is **open**; current evidence is supportive but finite.

- **Best current resolution:** supported by exhaustive evidence for `|A|+|B|<=8` with tight instances and no violations (`experiment`, prior + partial independent check), but **no all-n proof and no falsifier** (`blocker`).
- **Bridge to central objective:** a positive all-n theorem would be a concrete structural lower-bound lemma for the minimax sorting game underlying `S(n)`; by itself it does not resolve complexity of `SORT-BOUND-U`, but it sharpens the space of valid compositional arguments/search bounds. A negative answer would refute that compositional threshold.
