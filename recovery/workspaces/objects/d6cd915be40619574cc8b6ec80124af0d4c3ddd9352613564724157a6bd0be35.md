## 1. Definitions (permutation-framed DAG certificates)

**Definition 1 (instance and height). [definition]**  
`S(n)` is the minimum worst-case number of adaptive pairwise comparisons to sort `n` distinct labelled keys. A certificate targets a claim `S(n) <= k` (equivalently, sorter wins `G(n,k)`; see `docs/research-certificates-barriers.md`, `docs/problem.md`).

**Definition 2 (explicit permutation-framed comparison DAG). [definition; follows `docs/research-framed-certificate-frontier.md` and `scripts/check_framed_strategy.py`]**  
An explicit certificate is a finite directed acyclic graph `C = (V,E,r)` with a designated root `r`, given in a topological encoding (nodes numbered so all edges go forward), parameterized by `n >= 0` and budget `k >= 0`. Each node is either:
- **query node** `v`: stores a compared pair `(a_v,b_v) ∈ {0,...,n-1}^2`, `a_v != b_v`, and two outgoing outcome edges `e_lt = (v, u_lt, π_lt)` and `e_gt = (v, u_gt, π_gt)`. Outcome `lt` asserts `slot(a_v) < slot(b_v)` before relabelling; `gt` asserts `slot(b_v) < slot(a_v)`. Each `π_*` is a permutation of `n` slots (a frame/relabelling applied after the outcome). Both edges are present even if one is infeasible under the node annotation.
- **leaf node** `v`: terminal, no outgoing query.

**Definition 3 (guaranteed-order semantics and local validity). [definition/deduction]**  
For each node `v`, let `R(v)` be a strict partial order on current slots represented as a transitively closed relation (or equivalent). 
- `R(r)` is empty (antichain). 
- For a query edge from `v` with outcome adding `x < y`, let `R' = TC(R(v) ∪ {(x,y)})` in pre-frame coordinates. The edge is **infeasible** if this is cyclic (or contradicts `R(v)`); otherwise it is **feasible** and contributes `rename(R', π)` to its child, where `rename` transports relations by the slot permutation `π`.
- **Join rule:** for a node `u` with incoming feasible contributed relations `R_1,...,R_d`, `R(u) = ⋂_i R_i` (intersection of guaranteed comparisons). An unreachable/unreached node in the explicit graph may have no feasible incoming contribution.
- **Leaf soundness condition:** every reachable leaf must guarantee a total strict order on all `n` slots.
- **Depth/budget condition:** every root-to-reachable-node path length (number of query edges) is `<= k`; equivalently `depth(u) <= k` for all reachable `u`.

`check_framed_strategy.py` implements this semantics (bitset closure/intersection, explicit infeasible-branch skipping when contradicted by `R(v)`, forward-edge/topology checks, permutation validity, total-order check at reachable leaves, max depth `<= budget`). [experiment/implementation]

**Definition 4 (size parameters). [definition]**  
Let `|V|`, `|E| <= 2|V_q|` be node/edge counts (`V_q` query nodes), `d_in(v)` in-degree, `w` a width parameter if a levelization/frontier is specified, and `n` the number of keys. The explicit encoding size is `poly(|V|, n, log k)` bits (pairs, next indices, permutations). The unary decision input length relevant to `SORT-BOUND-U` is `N = n + k + 1`.

**Definition 5 (restricted forms considered). [definition]**
- **Tree form:** `d_in(r)=0` and `d_in(v)<=1` for `v != r` (no merges/joins). 
- **Bounded in-degree DAG:** `d_in(v) <= Δ` for fixed/all-`n` `Δ` (general DAG allows joins; Δ>=2 permits intersection). 
- **Bounded width:** all-`n` bound on simultaneously "live" states under a chosen traversal/schedule (a compression constraint; exact notion must be fixed to be formal). 
- **Local frame constraints:** frames/permutations restricted to local operations, e.g. identity, compared-pair transposition (compare-exchange), or other uniformly local relabellings depending only on edge/local state.

## 2. Soundness checking vs completeness/existence

**Distinction (central). [deduction]**

| Aspect | Question | Object quantified | Status for framed DAGs |
|---|---|---|---|
| **Soundness checking** | Given an explicit `C,n,k`, does `C` validly certify `S(n) <= k`? | fixed certificate instance | Locally/checkably decidable in time polynomial in explicit graph size and `n` under Definition 3 (`docs/research-framed-certificate-frontier.md` §1; checker). |
| **Completeness / existence** | For true instances `(1^n#1^k)` with `k >= S(n)` (especially `k=S(n)`), is there some valid `C` of size polynomial in `n` (hence in `N` on the informative window)? | existence of a short certificate | **Open in general for optimal height `S(n)`**. Polynomial-size all-`n` DAGs exist for some non-optimal strategies (bubble, merge-sort construction), but exact-optimal all-`n` completeness is unresolved (`docs/research-framed-certificate-frontier.md` §1,§2,§5). |

A sound checker alone does **not** imply `SORT-BOUND-U ∈ NP`; NP membership would require an existentially quantified, polynomial-size, polynomial-time-verifiable witness for every yes-instance (at the relevant budget). Conversely, failure to find a small certificate is not a proof of nonexistence. [deduction]

## 3. Verification complexity bounds (soundness), in `|V|, |E|, n`

**Theorem 1 (local soundness verification is polynomial in explicit size). [paper theorem claim in repo; supported by implementation/experiment]**  
*Claim:* There is a deterministic algorithm that, given an explicit permutation-framed DAG certificate `C` over `n` elements with budget `k`, decides validity of Definition 3 in time polynomial in `|V| + |E| + n` (and space polynomial in the same, under explicit storage). If `C` is accepted, then every permutation of `n` distinct keys is sorted within `k` comparisons along some feasible root-to-leaf path consistent with outcomes, so `C` is a sound witness for `S(n) <= k`.

*Argument (proof sketch, from `docs/research-framed-certificate-frontier.md` §1 and checker logic):* process nodes in topological/forward order. For each query edge perform: contradiction/feasibility test against `R(v)` (`O(1)`/bitset or `O(n^2)`), if feasible copy/update relation (`O(n^2)`), transitive closure (`O(n^3)` by Floyd–Warshall/bitset closure), apply permutation/rename (`O(n^2)`), and intersect into child (`O(n^2)`). Each edge is handled once in forward order; leaves check totality by testing all pairs (`O(n^2)`). Depths update by max over incoming feasible edges (`O(1)` per edge) and compare to `k`. All operations are local to explicit edges/nodes and the `n x n` relation state. Intersection preserves only comparisons justified on every feasible incoming path, so no unjustified order is introduced; feasible real executions remain represented. Therefore acceptance implies correctness and height `<= k`. [deduction, grounded in cited repo construction/checker]

*Concrete checker upper bound (implementation-level). [deduction from code]* `scripts/check_framed_strategy.py` uses dense bitsets/rows of length `n`: `_closure` is `O(n^3)` bit operations, `_rename` `O(n^2)`, feasibility/intersection/leaf-totality checks `O(n^2)`. With `|E| <= 2|V_q|`, total time is `O(|V_q| * n^3 + |V| * n^2) = O(|V| * n^3)` in that direct implementation model, hence polynomial in explicit size. [experiment/implementation]

**Corollary 1a (relation to `SORT-BOUND-U`). [deduction]**  
If for all `n` there exists a valid framed DAG certificate of height `S(n)` with `|V|,|E| <= poly(n)` and polynomial-bit encoding, then (since `n <= N` and verification is polynomial in `|V|,n`) `SORT-BOUND-U ∈ NP` by taking the certificate as NP witness for yes-instances. The converse is not implied. No such all-`n` polynomial-size completeness theorem at `S(n)` is known. [deduction/open; `docs/research-framed-certificate-frontier.md` §1]

**Proposition 1b (not an NP witness by explicit tree size). [deduction/experiment; `docs/research-certificates-barriers.md` Claim C]**  
Any correct comparison *tree* distinguishing all `n!` permutations has at least `n!` reachable leaves and at least `2*n! - 1` nodes (reduced optimal trees achieve equality, observed for `n<=6`). On informative unary instances (`m = n+k+1 = Θ(n log n)`), `n! = 2^{Θ(m)}`; thus explicit tree certificates are exponential in unary input length (and do not by themselves yield NP membership), though verifiable in time polynomial in their own size. [deduction/experiment]

## 4. Natural restricted forms: polynomial-size existence vs obstructions

### 4.1 Tree / bounded in-degree `Δ <= 1` (no joins)

**Theorem 2 (tree-form obstruction, all `n`). [deduction/literature in repo]**  
*Statement:* Any sound tree-form certificate (no intersection/merge of distinct feasible histories; non-root in-degree <= 1) that correctly sorts all `n` permutations must have `>= n!` leaves and `>= 2*n! - 1` nodes, hence cannot be polynomial-size in `n` (or in unary `N`) for all `n`.

*Proof:* In a deterministic rooted tree each input permutation follows exactly one root-to-leaf path. Correctness requires different permutations not to be certified by the same total-order outcome unless distinguished, so at least `n!` leaves are necessary; a full binary decision structure with `L` leaves has `2L-1` nodes. Therefore size is `Ω(n!)`, super-polynomial and exponential in `Θ(n log n)`. ∎ [deduction; `docs/research-certificates-barriers.md` Claim C]

*Implication:* restrictions that forbid joins (in-degree <= 1) cannot yield succinct all-`n` certificates; any poly-size framed certificate route must exploit DAG sharing/joins. [deduction]

### 4.2 Local frame constraints (compare-exchange / identity style)

**Proposition 3 (local frames are compatible with poly-size but non-optimal all-`n` certificates). [paper construction in repo; experiment via generator]**  
*Statement:* Under a strong local frame constraint where frames are identity or adjacent-slot transpositions induced by compare-exchange (as in bubble-sort passes), there exists an explicit all-`n` sound certificate of size/depth `Θ(n^2)`: `triangular_bubble_certificate(n)` has `n(n-1)/2` query nodes and one leaf and is accepted by the checker (e.g. generator produces valid certs). [experiment/implementation + definition of generator]

*Proof sketch:* each step compares adjacent slots and branches to permuted-but-equivalent successor states that realize the exchange on the `gt` branch; sequential composition over all bubble passes yields a sorted total order at the end in `n(n-1)/2` comparisons. ∎ (sound as a fixed strategy encoding). [deduction/experiment]

*Obstruction/limit (optimality, not size):* polynomial size under local/simple frames does **not** imply optimal height. Merge-based all-`n` polynomial DAGs (balanced merges) achieve `O(n log n)` path length but not `S(n)` for large powers of two; standard FJ/rank-envelope constructions target `F_FJ(n) >= S(n)` (equality not for all `n`) and require careful frame/boundary audit. Thus local/simple frames admit poly-size *upper-bound* witnesses for some algorithms but provide no known all-`n` poly-size witness at exact `S(n)`. [paper construction/open; `docs/research-framed-certificate-frontier.md` §2,§3]

### 4.3 Bounded in-degree `Δ >= 2` and bounded width (DAG compression)

**Observation 4 (joins help, but worst-case compression is unproved). [deduction/open]**  
Allowing `d_in >= 2` enables intersection/merging of histories (the mechanism behind merge-sort and rank-envelope DAG sharing) and is necessary to beat the `n!` tree barrier. However:
- A DAG over reachable partial-order states can in worst case require `2^{Θ(n²)}` distinct states (labelled posets/A001035 scale), so unrestricted-by-semantics compression is not guaranteed polynomial. [literature/experiment context; `docs/research-certificates-barriers.md` §5]
- Optimal-play state counts vs all reachable states remain an open discriminating measurement (`docs/research-certificates-barriers.md` §8). No theorem here establishes a polynomial bound for bounded `Δ` or bounded width at height `S(n)`.
- Entropy/forgetting identities give necessary conditions for near-information-bound compression under an auxiliary walk, not a polynomial-size existence proof and not a poly-time counting verifier (`docs/research-framed-certificate-frontier.md` §4). [paper identity]

**Status:** for natural DAG restrictions beyond "tree", **no proved all-`n` polynomial-size completeness at `S(n)` and no proved universal super-polynomial obstruction specific to bounded-width/bounded-degree framed DAGs** is established in consulted materials; the question is open. Any claim of obstruction must quantify over all valid encodings/joins consistent with `S(n)`, which current results do not do. [open]

## 5. Implications for `SORT-BOUND-U` in NP / coNP (no separation claims)

**NP (upper-bound certificates, yes-instances). [deduction]**
- *Sufficient route (open):* poly-size, poly-time-checkable framed DAG certificates for all `n` at budget `S(n)` (or for each yes-instance) would place `SORT-BOUND-U ∈ NP` (Corollary 1a). This is a potential **upper-bound** result, consistent with `SORT-BOUND-U ∈ PSPACE`. [deduction]
- *Known partials:* sound local verification is efficient in explicit size; poly-size certificates exist for some algorithms/bounds (e.g. bubble `O(n^2)`, merge-sort construction `O(n^2)` nodes / `O(n log n)` depth) but these certify `S(n) <= k` only for non-optimal `k` in general, so they do not settle NP membership for the exact threshold language except on instances where those bounds suffice. [paper construction/experiment]
- *Barriers to naive NP witness:* explicit trees are exponentially large; no succinct optimal certificate is known. [deduction/open]

**coNP (lower-bound certificates, no-instances, i.e. `S(n) > k`). [deduction/open]**
- A coNP certificate for `SORT-BOUND-U` would be a poly-size, poly-time-checkable witness that no height-`k` adaptive strategy exists. The game characterization is alternation-heavy (sorter ∃ moves, adversary ∀ outcomes); known lower bounds in hard regimes (e.g. around information bound/non-tight cases like `n=12`) come from exhaustive/adversarial searches, and no succinct general lower-bound witness is identified in consulted notes. [deduction/literature context; `docs/research-certificates-barriers.md`]
- Framed DAGs as defined are direct **upper-bound/strategy** witnesses; obtaining coNP via them would require an additional dual/complementation argument not provided. [open]

**No separation claims. [deduction per `AGENTS.md`/`problem.md`]**  
`SORT-BOUND-U ∈ PSPACE`; proving `∉ NP` would imply `NP != PSPACE` and proving `∉ P` would imply `P != PSPACE` (open). Sparsity gives only the Mahaney barrier for many-one NP-hardness (P=NP consequence), not membership/separation. This report makes no containment/separation claim beyond cited/derived upper bounds and open status. [deduction]
