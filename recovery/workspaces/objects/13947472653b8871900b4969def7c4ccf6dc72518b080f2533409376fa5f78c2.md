# Obstruction/barrier for final theorems about S(n)/SORT-BOUND-U

This is a precise obstruction (barrier) with proof sketches, falsifiers, and gaps. Labels: [definition], [literature], [deduction], [experiment], [conjecture], [open].

## Problem statement recap
- S(n) = minimum height of a deterministic adaptive comparison tree sorting n distinct labelled keys. [definition]
- SORT-BOUND-U = { 1^n # 1^k : S(n) <= k } (unary), N = n+k+1 input length. [definition]
- SORT-BOUND-B = { bin(n) # bin(k) : S(n) <= k } (binary). [definition]
- Game G(n,k): state = transitively closed poset P on n; sorter picks incomparable pair, adversary answers both directions (transitively closed); sorter wins if total order within k. S(n)<=k iff sorter wins G(n,k). [deduction]
- Established bounds (this repo): SORT-BOUND-U in EXPTIME (memoized DP 2^{O(n^2)} time in numeric n), improved by budgeted DFS/transcript to 2^{O(n log^2 n)} time and O(n log^2 n) space in numeric n; SORT-BOUND-B gives 2^{2^{O(m)}} time. [deduction]

## Strongest defensible upper bounds (claims)
**Claim A (PSPACE/EXPSPACE).** [deduction] Model G(n,k) as an alternating Turing machine: existential (sorter chooses pair), universal (adversary branches), state = n×n transitive closure (O(n^2) space). Time O(k n^2)=O(m^3) for unary (m=n+k+1) => ATM in ATIME(poly(m))=APTIME=PSPACE; for binary, n<=2^{Θ(m)}, k<=O(n log n)=>ATM in ATIME(2^{Θ(m)}) subset DSPACE(2^{O(m)})=EXPSPACE. By binary search, S_unary in FPSPACE, S_binary in FEXPSPACE. These improve EXPTIME/2-EXPTIME.

**Claim B (sparsity barrier, unary only).** [literature]+[deduction] SORT-BOUND-U is sparse (<=O(m^2) strings of length<=m). Mahaney: sparse NP-hard under poly-time many-one reductions => P=NP. SORT-BOUND-B is dense (guaranteed yes pairs give 2^{Ω(m)} strings of length<m for large m), so barrier does not apply.

**Claim C (no obvious poly witness / tree size).** [deduction]+[experiment] Correct sorting tree has >= n! reachable leaves, reduced optimal tree has exactly 2n!-1 nodes. For unary input length m=Θ(n log n), n!=2^{Θ(m)} (super-polynomial). For binary m=Θ(log n), n!=2^{2^{Θ(m)}} (doubly exponential). Verifying an explicit tree is poly in tree size (not input). Standard tree witness gives naive NEXP/N2EXP verifier at best; different succinct witness not ruled out.

**Claim D (no transfer).** [deduction] Hyafil–Rivest/Laber–Nogueira (arbitrary tests) and Parberry (fixed networks, coNP) do not transfer to S(n) (fixed pairwise tests, adaptive choice; unary sparsity blocks naive NP-hardness reduction; alternation gives game).

**Claim E (counting barrier).** [literature]+[deduction] Greedy (min over pairs of max extension count) needs #P-complete linear extension counts (Brightwell–Winkler); barrier to that specific algorithm, not a hardness theorem for S(n).

## The central obstruction (precise)
**Obstruction O1 (absence of succinct canonical witness).** [conjecture/open] To get below PSPACE (e.g. NP/coNP or P) for SORT-BOUND-U we need a polynomial-size, polynomial-time-checkable certificate for (S(n)<=k) or (S(n)>k). Known candidates fail or are large:
- Explicit reduced tree: size 2n!-1 = 2^{Θ(m)} in unary input (super-polynomial). [deduction]
- DAG over all labelled posets: worst case 2^{Θ(n^2)} states (A001035) in general; question is whether optimal play uses only polynomially many. [open, falsifiable]
- Program/strategy description: universal over n! inputs, checkability unclear. [open]
- Potential functions: only information-theoretic log2(n!) known, not tight (fails at n>=12). [literature]+[open]

Also note: SORT-BOUND-U in P/poly trivially (tally) so circuit lower bounds cannot separate from P; uniform super-polynomial lower bound needs a method not known for natural PSPACE problems. [literature]+[deduction]

## Falsifiers (concrete)
1. **F1 (poly-size optimal DAG).** Find for some family/n or show that the set of posets reachable on some height-S(n) optimal strategy has size poly(n). Falsifies O1 for upper bound (would give polynomial witness/certificate). [open/experiment]
2. **F2 (succinct lower-bound witness).** Exhibit a polynomial-time verifiable certificate for S(n)>k using a new potential (stronger than log2(n!)) or combinatorial invariant for some cases where information bound is slack. [open]
3. **F3 (nontrivial uniform algorithm).** Give a uniform algorithm computing S(n) (or deciding SORT-BOUND-U) better than 2^{O(n log^2 n)} time / O(n log^2 n) space with correctness+cost proof; if polynomial, that’s a huge result but would need to avoid Mahaney-like issues? Or just an improvement. [open]
4. **F4 (reduction showing transfer).** Find an encoding-preserving reduction from some NP-complete problem to SORT-BOUND-U (would imply P=NP by Claim B — extremely strong constraint; likely false). [conjecture extremely unlikely]
5. **F5 (characterization).** Show S(n) depends only on some function of poset that is polynomially computable/countable and gives optimal strategy (would relate to #P but maybe yield structure) — Brightwell–Winkler says greedy needs #P; maybe no closed form. [open]

## Residual gaps (do not guess)
- Is there any polynomial-size certificate for S(n)<=k? Unknown. [open]
- Are there poset families on optimal paths polynomial in number? Unknown (A001035 is all posets; optimal-play set unmeasured). [open]
- Can information-theoretic bound be extended to a polynomial witness in the slack regime? Unknown. [open]
- Is SORT-BOUND-U in NP union coNP? Unknown; PSPACE is the strongest safe upper bound from alternation/game. [open]
- For binary encoding, no sparsity barrier; PSPACE class not the same constraint — but still no known hardness/certificate. [open]

## Conclusion
The main obstruction is **O1: no known succinct canonical witness** for optimal comparison strategies. The sparsity barrier (B) rules out routine many-one NP-hardness for the unary language (would need P=NP). The alternation/game gives **PSPACE/EXPSPACE** as the defensible upper bounds (A). Circuit lower bounds are inapplicable (tally). Achievable frontiers: faster uniform evaluators/space (e.g. better than current 2^{O(n log^2 n)}), barrier theorems ruling out families, or structural theorems about optimal-play poset classes; all must produce concrete deliverables (proof/barrier/falsifier) or precise blockers. No evidence here suggests a polynomial-time solution or NP-membership is obvious.
