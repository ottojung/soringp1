## 3. Model and formula checks

- `C(13)=ceil(log2 13!)=33` is correct (`13!=6,227,020,800`, `log2` gives 33).
- Depth parameterization: states in level `S_c` have `c` comparisons made; children tested for admissibility are at depth `d=c+1` with cap `2^(C-d)=2^(33-c-1)`. Script uses `cap = 1 << (C - depth - 1)` and analyzes `depth -> depth+1`; this matches the Wells definition in the artifact and `docs/research-n12-nontightness.md` §4.
- Admissibility requires **both** children `e <= cap` — correct for Wells forward admissibility.
- Heavier child is `max(e1,e2)` and the corresponding poset is kept (`c1` when `e1>=e2`, else `c2`). Tie handling is documented as order-dependent before quotient; quotient removes labelling/isomorphism ambiguity for the reported classes.
- `e(P)` uses `one_ply_obstruction.linear_extensions`, an order-ideal/downset DP (`dp[S]` counts linear extensions consistent with chosen ideal `S`). For an ideal, maximal elements in `S` are exactly elements of `S` with no successor inside `S`; recurrence `dp[S]=sum dp[S\{x}]` over such `x` is standard and consistent with existing repo code. Complexity `O(2^n)` per state is acceptable at `n=13`.
- `L0` is `ceil_log2(e)` via `(e-1).bit_length()` for positive integers — correct.

## 4. Quotient check

- Quotient is by labelled-poset isomorphism implemented as graph isomorphism of the transitive-closure successor DAG (`succ_to_dag` emits edges `i -> j` for all successors in `succ[i]`; `succ` is maintained transitively closed by `add_relation`).
- Isomorphism preserves number of linear extensions, incomparability count, admissibility of moves, and heavier-child extension counts; therefore quotienting representatives is sound for this one-sided heavier-child level construction. The artifact states this deduction.
- `networkx.DiGraphMatcher.is_isomorphic` is a general isomorphism routine (can be expensive worst-case) but gives an exact graph-isomorphism test, not a hash heuristic. This is appropriate for the small completed level sizes (max 928 heavier states / 62 classes at depth 6).
- Counts reported as “orbit classes / total heavier states” are clear and consistent.
