# Exponent `2^{O(n log n)}` without frontier enumeration: obstruction for natural exact compression/aggregation classes

**Status:** research note (local). Every claim is labelled **[definition]**, **[literature]**, **[deduction]**, **[open]**, or **[conjecture]**. No Lean file, no PR, no complexity-class separation, and no NP/coNP/hardness claim is made. This addresses the falsifiable question: can `S(n)<=k` be evaluated exactly and uniformly in `2^{O(n log n)}` (or `2^{O(n)}`) time while provably avoiding transcript/winning-frontier enumeration (respecting the `2^{(1/4-o(1))n log^2 n}` winning-frontier barrier), or is there a concrete obstruction for natural compression/quotient/duality/state-aggregation routes?

**Conclusion (this note).** **[open]** No exact uniform `2^{O(n log n)}` or `2^{O(n)}` evaluator for the root-antichain minimax value `S(n)` is established here. **[deduction]** However, the existing winning-frontier theorem and the measured/derived compression facts yield a **concrete obstruction** (option B) for a precisely stated natural class: *exact frontier-distinguishing state-aggregation methods* — methods that, in order to decide the root-antichain minimax game exactly at the relevant budget, must treat as distinct all nonisomorphic winning states on some common reachable depth of that budget. For such methods, the worst-case state/time complexity cannot cross below `2^{Omega(n log^2 n)}` in numeric `n`. Known quotient/duality/move-orbit/comparability relaxations either do not form such a complete winning-frontier distinguisher while remaining exact, or do not reduce the exponent of that frontier/count.

## 0. Fixed model and baseline

**[definition]** `S(n)` is the minimum worst-case number of adaptive pairwise comparisons to sort `n` distinct labelled keys (root antichain). `F(P)` is the minimax remaining comparison count from transitively closed poset `P`; `F(∅)=S(n)` (`S_eq_adv_univ`, `docs/problem.md`, `docs/upper-bound.md`). The unary decision input is `1^n#1^k`, length `N=n+k+1`.

**[literature/deduction from repo]** The budgeted transcript DFS decides `S(n)<=k` by the exact game recurrence in deterministic `2^{O(n log^2 n)}` time / `O(n log^2 n)` bits (numeric `n`), and in `2^{O(N log(N+2))}` time / `O(N log(N+2))` work-tape bits for the unary decision problem (`docs/research-budgeted-dfs.md` §5.2–§5.3). It is a backtracking search over the game tree: it stores a transcript/path, not a materialized frontier of all states. Therefore it **avoids enumerating a winning-frontier/state set as an output or table**, but its worst-case node count is still the `2^{O(d log n)} = 2^{O(n log^2 n)}` search bound (depth `d<=U(n)=O(n log n)`, branching `<=n(n-1)`), not `2^{O(n log n)}`.

**[literature, `docs/research-winning-frontier-barrier.md`]** For infinitely many `n=2^(2r)`, at information budget `k=ceil(log2(n!))` and for the exact-optimal budget `k=S(n)=C(n)+d(n)` with `d(n)=o(n)` (Sergeev, asymptotic, no effective finite threshold), there is a common reachable depth `t<=k` with at least

`W(n) >= 2^{(1/4-o(1)) n (log2 n)^2}`

pairwise **nonisomorphic** `n`-vertex partial orders `P` such that `P` is reachable from the root antichain by exactly `t` legal comparison outcomes and `F(P) <= k-t`. A finite witness has `n=224` and `>2^39` such states. This is **not** a general time lower bound for computing `S(n)`; a selective/symbolic method need not list every state.

## 1. Why frontier enumeration is not forced, but exponent reduction is open

**[deduction]** The winning-frontier barrier rules out any method whose correctness argument requires **outputting/listing all** reachable winning partial orders at the relevant budget, even up to isomorphism: that output has size `2^{Omega(n log^2 n)}`. The budgeted transcript DFS does not do this; it explores branches and backtracks. Thus “avoiding frontier enumeration” is compatible with exact evaluation.

**[open]** The falsifiable target `2^{O(n log n)}` or `2^{O(n)}` exact uniform time for root-antichain `S(n)` is not achieved by the methods documented in this repository. The gap is the extra `log n` factor in the DFS exponent, coming from depth/branching `O(n log n) * log n` in the worst-case tree bound. No sound method here removes that factor while remaining exact on the full minimax game.

## 2. Natural class C (frontier-distinguishing exact state aggregation)

**[definition]** Fix root size `n` and a budget `k` with `S(n) <= k <= U(n)`. Call an exact uniform method a *frontier-distinguishing state-aggregation method at `(n,k)`* if there exist a reachable depth `t=t(n,k)<=k` and a family `W'(n,k)` of states at depth `t`, reachable from the antichain, each winning with remaining budget (`F(P)<=k-t` for `P in W'(n,k)`), such that:

1. **Exactness over the winning frontier.** The method’s decision/cost for the root game at budget `k` is sound only if it assigns the correct win/remaining-budget status to every state in `W'(n,k)` (or to a representation that is injective on their relevant exact minimax classes).
2. **Distinguishing representation.** Distinct members of `W'(n,k)` that are not identified by a *sound exact* equivalence used by the method occupy distinct represented states/keys/objects during the method. Equivalently, the method does not merge two elements of `W'(n,k)` unless the merge preserves the exact minimax transition/value needed for the root decision.
3. **Work lower bound per represented state.** The method performs at least one unit of representation/processing work per distinct represented state in the worst case (a standard RAM/TM bookkeeping lower bound on enumerating/distinguishing a set; this does not assume listing as external output, only that distinct states are materialized/distinguished).

This class includes: explicit winning-frontier enumeration; memoized exact DP tables that retain every distinct winning class encountered at the critical depth; canonical quotient tables that keep all nonisomorphic winning states; and any aggregation that is injective on a large exact winning frontier. It excludes methods that *selectively* prove win/loss without distinguishing all winning states (e.g. selective DFS/search that returns on a sufficient move, proof-number style selection, or symbolic reasoning) — those may still be expensive, but they are not forced by this frontier-size argument alone.

**[definition]** *Natural compression/quotient/duality/state-aggregation routes* (the routes named in the question) are exact identifications of states or moves: key relabelling `S_n`, order duality, `Aut(P)` move orbits, coarse invariants used as states, decomposition/series-parallel merges, comparability relaxations, and similar state aggregations that preserve the root-antichain minimax answer.

## 3. Obstruction theorem for class C

**Theorem (obstruction for frontier-distinguishing exact aggregation). [deduction from literature]**
Let `k(n)=S(n)` (or any budget in the range covered by the winning-frontier theorem, including `k(n)=ceil(log2(n!))` where the construction applies). For the infinitely many `n=2^(2r)` given by the winning-frontier construction, every frontier-distinguishing state-aggregation method in class C has worst-case represented-state count and time

`T_C(n) >= 2^{(1/4-o(1)) n (log2 n)^2} = 2^{Omega(n log^2 n)}`.

*Proof.* By the winning-frontier theorem (`docs/research-winning-frontier-barrier.md` §3.1), for these `n` and `k(n)=S(n)=C(n)+o(n)` there is a depth `t` and a set of at least `W(n) >= 2^{(1/4-o(1)) n (log2 n)^2}` pairwise nonisomorphic partial orders, each reachable at `t` and winning with budget `k(n)-t`. Take `W'(n,k)=` this set. Its members are distinct exact states (different posets, not merely different labels in the same class — the theorem already quotients by isomorphism). By C(1)–C(2), any sound exact merge used by a method in C cannot identify two of these nonisomorphic winning states unless it preserves the exact minimax behavior needed; in particular, a method that is merely a compression/aggregation table over states must represent each as distinct unless it proves an exact equivalence. The theorem supplies `W(n)` distinct nonisomorphic winning states, so the represented distinct count is `>=W(n)`. By C(3), time/work is `>=W(n)`. Therefore `T_C(n)=2^{Omega(n log^2 n)}`. ∎

**[deduction, scope]** The lower-order `o(1)` depends on the asymptotic Sergeev bound; no effective finite threshold is claimed. The result is an obstruction to the *stated class C*, not to all exact algorithms, and not to `S(n)` computation in general.

## 4. Why the named natural compression routes do not cross this barrier

The following are the concrete routes investigated in the repository; each is evaluated against class C and the `2^{Omega(n log^2 n)}` target.

| Route | Exact? | Effect on exponent / frontier | Status |
|---|---|---:|---|
| Key relabelling `S_n` | yes (**[deduction]**) | quotient by `n! = 2^{Theta(n log n)}`; reachable/class counts remain `2^{Theta(n^2)}` in total, and a large winning frontier can still contain `2^{Omega(n log^2 n)}` nonisomorphic classes (the theorem is already up to isomorphism) | no crossing below `2^{Omega(n log^2 n)}` for C (**[deduction]**) |
| Order duality `Z_2` / `S_n x Z_2` | yes (**[deduction]**) | constant-factor class reduction only | no exponent gain (**[experiment/deduction]**, `docs/research-compression-next.md`) |
| `Aut(P)` move orbits | yes as move reduction (**[deduction]**) | shrinks transitions per state (~30% measured small `n`), not the number of distinct winning states/classes | no exponent gain for C (**[experiment/deduction]**) |
| Linear-extension count / leaf entropy | **falsified** as exact state (**[experiment]**) | cannot determine `F`; fails at `n=5` witness | not a sound exact aggregation (**[deduction]**) |
| Comparability graph | **falsified** as exact DP state (**[experiment]**) | `F` not comparability-invariant at `n=7`; transition ill-defined at `n=5` | not a sound exact aggregation (**[deduction]**) |
| Degree/colour cheap surrogates | **falsified** / unproven (**[experiment]**) | degree-based move identification unsound at `n=6`; colour-pair signature only checked `n<=6` | not established sound (**[open]**) |
| Series/ordinal decomposition | exact where applicable, but not shrinking globally (**[deduction/experiment]**) | `F` not additive over components; does not remove the hard antichain-root/large-frontier regime | no general exponent gain (**[open/deduction]**) |
| Balanced-greedy restricted tree class | **falsified** as optimal (**[experiment]**) | returns `20` for `S(9)=19` | not exact (**[deduction]**) |
| Full winning-frontier enumeration | exact in effect but prohibitive | lists all winning states | ruled out at `2^{Omega(n log^2 n)}` output/state size (**[literature/deduction]**) |

**[deduction]** The common failure mode is: either the compression is sound but gives only constant/polylog/subexponential-in-the-wrong-place factors (so it cannot move a `2^{Theta(n log^2 n)}` frontier below `2^{Omega(n log^2 n)}`), or it is not sound as an exact root-antichain minimax state. No repository result supplies a sound aggregation that provably collapses all nonisomorphic winning-frontier states needed for the exact root decision into `2^{o(n log^2 n)}` represented classes.

## 5. Precise boundary and what is not claimed

**[deduction]** This note establishes option **(B)** only for class C: *exact frontier-distinguishing state-aggregation/compression methods*. It does **not** prove:

- that every exact uniform algorithm for `S(n)` must take `2^{Omega(n log^2 n)}` time;
- that `2^{O(n log n)}` or `2^{O(n)}` is impossible;
- that selective DFS, symbolic minimax, proof-number search, succinct DAG certificates, bidirectional selective search, or unknown structural recurrences are blocked;
- any P/NP/PSPACE separation, lower bound for a standard TM class beyond C, or hardness.

**[open]** A positive result would need either (i) an exact selective/symbolic method with a proved `2^{O(n log n)}` worst-case bound that never distinguishes all winning-frontier states, or (ii) a new sound equivalence/representation that provably compresses the *decision-relevant* winning frontier below `2^{Omega(n log^2 n)}` while preserving root-antichain exactness. A stronger negative result would need to show that every exact uniform evaluator, not only class C, implicitly distinguishes `2^{Omega(n log^2 n)}` information in the worst case.
