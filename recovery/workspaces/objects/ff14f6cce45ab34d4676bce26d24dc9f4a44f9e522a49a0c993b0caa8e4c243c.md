# Selective DFS, state merging, and proof-number value sharing for exact `S(n)`: sound criteria and obstructions

**Status:** research note (local). Every claim is labelled **[definition]**, **[literature]**, **[deduction]**, **[experiment]**, **[open]**, or **[conjecture]**. No Lean file, no PR, no complexity-class separation, and no NP/coNP/hardness claim is made. Scope is the uniform adaptive comparison model; all asymptotics are in numeric `n` unless input length is stated.

**Question.** Can exact evaluation of `S(n)` / the game `G(n,k)` (`S(n) <= k`) be improved toward `2^{O(n log n)}` or `2^{O(n)}` time by selective DFS, state merging, or proof-number / minimax value sharing? Required outcome: either a **sound merge criterion** with an explicit certificate/argument, or a **precise obstruction** showing that merges preserving exact `S(n)`/`G(n,k)` value force `2^{Omega(n log^2 n)}` states or cannot be checked cheaply.

**Conclusion.** **[open]** No `2^{O(n log n)}` or `2^{O(n)}` exact uniform evaluator is established. **[deduction]** A sound merge criterion exists only in restricted, already-known exact-symmetry forms (label relabelling and duality), which do not remove the `n log^2 n`-scale obstacle. For general exact value sharing on the minimax game, *cheap sufficient merge tests* that are both sound and strong enough to collapse the decision-relevant winning frontier are not supplied by the repository evidence; exact value equality is a minimax predicate whose direct verification is as hard as the subgames being merged. Moreover, the winning-frontier theorem gives a `2^{Omega(n log^2 n)}` family of pairwise nonisomorphic reachable winning states at the same depth and exact/near-exact budget: any merge/value-sharing scheme that is injective on those exact decision-relevant states, or that must represent them distinctly to preserve `G(n,k)`, inherits that size obstruction. This is an obstruction for the stated merge/value-sharing class, not a general time lower bound for all exact algorithms.

## 0. Model

**[definition]** `S(n)` is the minimum worst-case number of adaptive pairwise comparisons to sort `n` distinct labelled keys. A state is a transitively closed strict partial order `P` on `n` labels; `F(P)` is the minimax remaining comparisons from `P`, with `F(total)=0` and
`F(P)=1 + min_{(i,j) incomparable} max(F(closure(P,i<j)), F(closure(P,j<i)))`.
`S(n)=F(∅)` (`S_eq_adv_univ`, `docs/problem.md`, `docs/research-budgeted-dfs.md`).

**[definition]** The threshold game is `G(n,k): S(n)<=k`. Budget form: `CanSort(P,d)` is true iff `F(P)<=d`. Monotonicity: `CanSort(P,d)=>CanSort(P,d+1)`. Budgeted DFS stores only a transcript/path and decides `CanSort` in `2^{O(d log n)} poly(n)` time and `O((d+n)log(n+2))` work bits; with `d<=U(n)=O(n log n)` this is `2^{O(n log^2 n)}` time / `O(n log^2 n)` bits for the numeric function and `2^{O(N log(N+2))}` / `O(N log(N+2))` for the unary decision input length `N=n+k+1` (`docs/research-budgeted-dfs.md`).

**[definition]** *Selective DFS* explores a subset of moves/branches using move ordering or proof/disproof guidance but must preserve the exact minimax answer: an OR node is won if some move wins against both adversary answers; an AND/adversary outcome is lost if any answer is lost. *State merging/value sharing* reuses the exact answer/value of a previously solved state for a later state deemed equivalent, or stores values by a key that identifies equivalent states.

## 1. What a sound merge criterion means

**[definition]** A *merge criterion* is a predicate/key `M(P,Q)` (or `M(P,Q,d)` in budget form) used to replace evaluation of `Q` by a stored result for `P`.

- **Function-value sound:** `M(P,Q)=>F(P)=F(Q)`.
- **Budget sound at `d`:** `M(P,Q,d)=>(F(P)<=d iff F(Q)<=d)`.
- **Game-sufficient soundness:** for the fixed root query `G(n,k)`, replacing `Q` by `P` under `M` never changes the root answer. This is weaker than global value equality but depends on the root context; a local criterion that is only contextually sound needs an explicit context certificate.
- **Exact certificate:** a sound merge should be accompanied by an explicit argument/object establishing the implication (isomorphism map, duality map, decomposition equality, or proof that the two subgames are equivalent). A heuristic key without such an implication is not sound.

**[deduction]** Unsound merges are easy to produce and dangerous: the minimax value is sensitive to global linear-extension/refinement structure, not to simple local summaries. `F` is not determined by linear-extension count `e(P)` (`docs/research-n12-nontightness.md`, `docs/research-hardness-boundaries.md`), not comparability-graph invariant (`n=7` falsification, `docs/research-compression-next.md`), and transition structure can be ill-defined on comparability-only representatives (`n=5` falsification, `docs/research-compression-next.md`). Degree-based move identification is unsound at `n=6` (`docs/research-compression-next.md`). Therefore candidate merge keys based on these summaries fail the certificate requirement.

## 2. Sound criteria that are available

| Criterion | Soundness | Certificate/argument | Exponent effect | Evidence |
|---|---|---|---|---|
| Label relabelling `P ~= Q` under `S_n` | **function-value sound** | poset isomorphism transports comparisons/outcomes and the full game tree | quotient by `n!=2^{Theta(n log n)}` in labelled count; total nonisomorphic posets still `2^{Theta(n^2)}` and does not by itself remove the winning-frontier scale | **[deduction/literature in repo]** `docs/research-state-compression.md` |
| Order duality `P ~= Q^{op}` under `Z_2` (or `S_n x Z_2` classes) | **function-value sound** for the symmetric minimax value used | reversing all relations maps legal comparisons/outcomes bijectively | constant factor only | **[deduction/experiment]** `docs/research-compression-next.md` |
| Identical transcript-induced closure in the same root search (transposition in the explicit closure state) | **sound by equality** | identical state object/value | can save repeated subtrees when the same closure recurs; requires storing/canonicalizing states, losing transcript-only space unless carefully designed | **[deduction]** follows from state equality |
| Proven structural decomposition equalities, where valid | **casewise sound** only with proof | explicit theorem/certificate for that decomposition | not globally shrinking the hard antichain-root/winning-frontier regime; ordinal-sum exactness alone does not shrink the state space | **[deduction/experiment]** `docs/research-series-decomposition.md` |

**[deduction]** These are real sound merge/value-sharing criteria, but they are not new exponential breakthroughs. Relabelling+duality are cheap to express conceptually; implementing canonical keys has nonzero cost and, crucially, the winning-frontier barrier is already stated up to isomorphism. Thus even perfect isomorphism merging cannot compress a frontier that contains `2^{Omega(n log^2 n)}` pairwise nonisomorphic winning states into `2^{o(n log^2 n)}` classes.

## 3. Selective DFS and proof-number/value sharing: exactness constraints

**[definition]** Proof-number / best-first minimax selection (e.g. proof-number search style ordering) can change traversal order and may solve easy instances quickly, but exactness of `G(n,k)` requires: a proved win returns a move whose *both* adversary outcomes are wins within the remaining budget; a proved loss establishes that *every* move has some losing adversary outcome.

**[deduction]** Selective DFS is sound as an *evaluation order* only when it does not drop branches whose absence is uncertified. It can avoid exploring the whole worst-case tree on favorable instances, but the worst-case exact decision still quantifies over move choices and adversary answers. Value sharing stores results of solved subgames by exact key. The DFS exponent in `docs/research-budgeted-dfs.md` comes from worst-case reachable depth/branching, not from materializing a frontier; selection/sharing may reduce nodes in practice but the repository gives no proved worst-case `2^{O(n log n)}` bound for any exact selective/value-sharing variant.

**[open]** A worst-case bound below `2^{O(n log^2 n)}` for exact selective DFS or proof-number search on the root-antichain `G(n,k)` is not proved here. Any such claim would need an explicit node-count or represented-state bound, not empirical pruning ratios.

## 4. Obstruction: exact merge/value sharing over the winning frontier

**[literature]** The winning-frontier theorem (`docs/research-winning-frontier-barrier.md`) gives: for infinitely many `n=2^(2r)`, with `k=C(n)=ceil(log2(n!))` and also with `k=S(n)=C(n)+o(n)` (Sergeev, asymptotic, no effective finite threshold), there exists a common reachable depth `t<=k` and at least
`W(n) >= 2^{(1/4-o(1)) n (log2 n)^2}`
pairwise nonisomorphic `n`-vertex partial orders `P`, each reachable from the antichain by exactly `t` legal outcomes and satisfying `F(P)<=k-t`. A checked finite witness has `n=224`, `>2^39` such states.

**[definition]** Call a merge/value-sharing method *decision-frontier injective at `(n,k,t)`* if, for the winning set `W'(n,k,t)` above, no two distinct members are merged into one represented exact value/state unless their merge is certified sound for the root decision at budget `k`, and in particular no pairwise nonisomorphic members that are not certified equivalent are given the same represented key.

**[deduction, obstruction A: size]** For the relevant `(n,k,t)` from the winning-frontier theorem, `|W'(n,k,t)| >= 2^{Omega(n log^2 n)}`. Therefore any decision-frontier injective merge/value-sharing method represents `>=2^{Omega(n log^2 n)}` distinct exact decision-relevant states in the worst case. This is not a general time lower bound for selective search, because selective search may avoid representing most of these states; it is a lower bound on methods whose correctness/caching scheme distinguishes that frontier (including memo tables that retain all winning classes at that depth and proof systems that must cache distinct values for them).

## 5. Obstruction: cheap checking of general exact merges

**[definition]** "Cannot be checked cheaply" is used here in a precise algorithmic sense relative to the merge task, not as a complexity-class separation:
1. **Subgame-hardness:** deciding `F(P)=F(Q)` (or the budget equivalence needed to merge) is an exact minimax predicate over the adaptive comparison subgames from `P,Q`; a direct certificate is a proof of equal minimax value, which is at least as strong as solving/relating those subgames.
2. **Witness cost:** a proposed general merge key must either be proved sound by an explicit structural certificate (isomorphism, duality, decomposition theorem) or be validated by exact evaluation; without such a certificate, the key is heuristic.
3. **Strong-but-cheap barrier:** cheap summaries known to be insufficient (`e(P)`, comparability graph, degree/colour surrogates as exact state keys) cannot certify exact merges; sound exact certificates known to be cheap (relabeling/duality) do not collapse the nonisomorphic winning frontier.

**[deduction]** Consequently, for a merge criterion `M` intended to be both (i) sound for exact `F` or `G(n,k)` and (ii) broadly applicable beyond relabelling/duality/decompositions already proved, the criterion faces a dichotomy:
- if `M` is justified only by a cheap local summary, current evidence makes it unsound or unproved;
- if `M` is justified exactly, the justification is an equivalence/value certificate whose general verification inherits minimax/subgame difficulty.

This is not a proof that no cheap sound criterion exists; it is a precise obstruction to the natural routes: **no cheap, general, sound merge criterion stronger than known exact symmetries is established, and exact value equality itself is the hard predicate being optimized**. **[open]**

## 6. Proof-number/value-sharing specific note

**[deduction]** In AND/OR (minimax) form, value sharing is most directly sound when states are identical or in a proved-equivalent class. Proof-number guidance uses bounds `(proof, disproof)` to choose moves; sharing these bounds across non-identical states is sound only if the bound transfer is justified (e.g. same exact state key, monotonicity, domination theorem). Monotone budget propagation is sound (`d` wins => larger budget wins), but it does not merge distinct posets at the same budget except through an explicit equivalence. A domination relation `P <= Q` implying `F(P)<=F(Q)` or `F(Q)<=F(P)` would be valuable, but such a general cheap domination certificate preserving the exact root-antichain minimax value is not established here and would need careful proof against the falsified scalar/comparability surrogates. **[open]**

## 7. Net assessment

- **Sound merge criterion with certificate/argument:** yes, restricted — isomorphism/duality and state equality; proved structural decompositions only where separately certified. **[deduction]**
- **Sound general merge criterion for exact `F/G(n,k)` with cheap check and frontier-shrinking power:** not found; natural cheap summaries are falsified/insufficient, and exact value equality is minimax-hard to certify in general. **[open/deduction]**
- **Obstruction to merge/value-sharing classes that distinguish the winning frontier:** size `2^{Omega(n log^2 n)}` by the nonisomorphic winning-frontier theorem, including at the exact optimum `S(n)` asymptotically. **[literature/deduction]**
- **General time lower bound for all selective/symbolic exact algorithms:** not claimed. **[deduction]**

## 8. Falsifiable next checks

1. Exhibit a cheap, explicit domination/equivalence certificate `M(P,Q)` and prove `M(P,Q)=>F(P)=F(Q)` or the needed budget implication; then measure whether induced classes are `2^{o(n log^2 n)}` on the winning-frontier construction. **[open]**
2. Prove a worst-case node/state bound for an exact selective DFS or proof-number solver on `G(n,k)` below `2^{O(n log^2 n)}`; a proof must count all visited/represented states, not sampled runs. **[open]**
3. Try to falsify obstruction A by constructing a sound merge that identifies many nonisomorphic winning-frontier states from `research-winning-frontier-barrier.md` under a certified exact equivalence; the barrier already modded out `S_n`, so any success must use structure beyond relabelling. **[open]**
