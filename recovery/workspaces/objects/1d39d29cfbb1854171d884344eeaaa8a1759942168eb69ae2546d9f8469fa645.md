# Finite check / obstruction computation for `S(13) > C(13)=33`

**Status:** research note + reproducible finite computations. **Not a proof
that `S(13)>33`.** No separation claim. Labels follow `AGENTS.md`:
`[definition]`, `[literature]`, `[deduction]`, `[experiment]`.

Companion artifacts: `scripts/s13_finite_check.py`,
`tests/test_s13_finite_check.py`.

## 1. Target (falsifiable)

`[definition]` (model: `docs/problem.md`) `S(n)` is the minimum worst-case
number of adaptive pairwise comparisons needed to sort `n` distinct labelled
keys. A state is the transitively closed partial order (poset) `P` induced by
comparisons made so far; `e(P)` is its number of linear extensions.
`S(n)=F(∅_n)` where `F(P)` is the minimax remaining-comparison value.

`[deduction]`
- `13! = 6,227,020,800` (33 bits).
- `C(13) = ceil(log2(13!)) = 33`.
- Global information bound: `S(13) >= 33`.

**Question.** Is `S(13) <= 33`? Equivalently, does a height-33 adaptive
comparison decision tree sort every permutation of 13 keys?

`[literature, unverified here]` Kasai et al. (1994) and Peczarski (*New
results in minimum-comparison sorting*, Algorithmica 40, 2004, 133–145; as
cited in `docs/research-certificates-barriers.md`) report `S(13)=34`; OEIS
A036604 lists this value. **This note does not verify that literature result
and makes no claim that `S(13)>33`.** The purpose is to state checkable finite
computations that would refute or support `S(13)<=33` under explicit
assumptions.

## 2. Exact assumptions

A1. **Model.** Adaptive, worst-case, pairwise comparisons of `n=13` distinct
labelled keys (no ties). `[definition]`

A2. **State encoding.** A reachable state is a transitively closed strict
partial order `P` on `{0..12}`. `e(P)` is the exact number of linear
extensions. `[definition]`

A3. **Admissibility / Wells heavier-child test.** If a state `P` is reached
after `c` comparisons in a height-`C` tree (`C=33`), then `e(P) <= 2^(C-c)`.
Define the Wells admissible heavier-child levels (`docs/research-n12-nontightness.md` §4):
- `S_0 = {∅}`.
- `S_c = {` heavier child of every admissible comparison `(u,v)` of some
  `P ∈ S_{c-1}}`, where `(u,v)` is admissible at level `c` iff both children
  satisfy `e(child) <= 2^(C-c)`.
`[deduction]` If any `S_c = ∅`, then no height-`C` sorting tree exists, hence
`S(13) > C`. (If a height-`C` tree existed, its heavier-child path would keep
`S_c` non-empty.) The converse is not claimed by this computation alone: a
non-empty `S_c` at finite checked depth is **inconclusive**.

A4. **Resource bounds are not evidence.** Node-cap, time-cap, or state-cap
exhaustion is **inconclusive** and never supports `S(13)<=33` or `S(13)>33`.

A5. **Exact local arithmetic.** `e(P)` is computed exactly by the standard
downset/minimal-element DP for small states used by `one_ply_obstruction.py`
(`O(2^n)` space, `O(2^n n^2)` time in the bitmask implementation) or by
order-ideal enumeration; for `n=13` the downset table has 8192 entries and is
exact for the local checks performed. No floating point is used in
admissibility tests.

## 3. Finite computations performed (reproducible)

### 3.1 Controls `[experiment]`

`python3 scripts/s13_finite_check.py --controls` confirms the exact minimax
engine on small known values: `S(4)=5`, `S(5)=7`.

### 3.2 Depth-1 one-ply / symmetry analysis `[experiment, deduction]`

From the antichain `A=∅_{13}`:
- `C=33`, depth-1 admissibility cap `2^(33-1)=4,294,967,296`.
- Every first comparison `(i,j)` is in one `S_{13}` orbit. Its children are
  isomorphic to `P1={0<1}` with `e(P1)=13!/2=3,113,510,400 <= 2^32`.
- `L0(P1)=32`, so the depth-1 one-ply value is `1+32=33`: **the first
  comparison is not ruled out by one-ply information**. All 78 first moves are
  admissible and produce one heavier-child orbit class `S_1 = {[P1]}`.
- `[deduction]` This matches the forced balanced-prefix phenomenon: the global
  slack `13!/2^33≈0.7249` is below 1/1? (note 2^33 > 13!, so depth 0 is fine;
  depth 1 requires children <= 2^32 and `13!/2` fits).

### 3.3 Depth-2 Wells heavier-child classes `[experiment, deduction]`

From `P1={0<1}`, `Aut(P1)=Sym({2..12})` gives exactly 3 incomparable-pair
orbit classes (77 moves total):

| class (representative) | mult | `e` of children | heavier `e` | cap `2^(31)` | admissible |
|---|---:|---:|---:|---:|:---:|
| `V`: `{0<1,0<2}` | 11 | `(2,075,673,600, 1,037,836,800)` = `(13!/3,13!/6)` | `13!/3` | `2,147,483,648` | yes |
| `Λ`: `{0<1,2<1}` | 11 | `(13!/6,13!/3)` | `13!/3` | `2,147,483,648` | yes |
| disjoint: `{0<1,2<3}` | 55 | `(13!/4,13!/4)` | `13!/4` | `2,147,483,648` | yes |

All 77 depth-2 moves from the `P1` class are admissible. The script's shallow
symmetry signature merges the 77 heavier children into 3 classes with
`e ∈ {13!/4, 13!/3}` and `L0=31`. **`S_2` is non-empty (3 orbit classes).**

### 3.4 Interpretation `[deduction]`

Depths 0–2 do **not** produce a Wells obstruction: the information/admissibility
constraint alone does not kill the search in the first two plies. This is
**inconclusive**: it does not suggest `S(13)<=33`; it only shows any finite
Wells obstruction, if it exists at budget 33, lies at depth `>= 3` and requires
exploring the expansion of those 3 classes under the depth-3 cap `2^30`.

For comparison, `S(12)>29` was proved by exhaustive search (Wells; Stober–Weiss
report `sortable=no` for `n=12`, `C=29`), and `n=13,14,15,16` required
inspecting second children in that framework (`docs/research-n12-nontightness.md`).
The present computation is much shallower.

## 4. Capped witness search (optional, inconclusive) `[experiment]`

`python3 scripts/s13_finite_check.py --witness-search --node-cap 200000` runs a
capped budgeted decision search for `CanSort(antichain_{13}, 33)` with the
extension-count prune `e(P) > 2^d => False`. 

- **`True`** would mean a height-33 strategy exists (a finite witness, in
  principle checkable by emitting the decision tree) and would refute the
  literature value under assumptions A1–A3. This is not expected.
- **`False` with no cap hit** would mean this exact search found no height-33
  strategy; before claiming `S(13)>33`, completeness, exactness, and move
  coverage must be audited (the script as written is a DFS decision procedure,
  not a complete emitted certificate).
- **Node-cap / `None`** is **inconclusive**.

The full `n=13` witness/refutation game tree is astronomically larger than what
this capped search can explore; do not interpret cap exhaustion.

## 5. Minimal next finite witness / obstruction computation

The smallest **checkable finite obstruction** to run next (if feasible) is:

1. **Extend Wells levels exactly**: compute `S_3, S_4, ...` for `n=13, C=33`
   with **exact poset canonical labeling / congruence quotienting** (so states
   are compared up to graph isomorphism of the labelled poset congruence, as in
   Peczarski/Stober–Weiss style searches), not the shallow signature used here.
   - State: transitively closed poset / congruence class.
   - Move: incomparable pair `(u,v)`.
   - Admissibility at level `c`: `e(P+uv) <= 2^(33-c)` and `e(P+vu) <= 2^(33-c)`.
   - Keep heavier child (or inspect both children where required by the chosen
     complete criterion; for `n>=13` Wells' one-sided form may be insufficient
     as a complete refutation strategy—follow the Stober–Weiss/Peczarski
     bidirectional or full-child discipline and cite it).
   - **Success certificate**: first empty level `S_c=∅` under a sound complete
     criterion, with the level data/checkpoint reproducible.
   - **Resource bound**: must be run with explicit time/memory caps; report
     largest completed `c`, number of congruence classes, and frontier size.

2. **If aiming to refute `S(13)>33`** (unexpected): emit an explicit height-33
   decision strategy as a checkable certificate (tree or DAG with comparison
   nodes and both outcomes), and verify every leaf is a total order and every
   path has length <= 33. This is a finite verifier but likely infeasible to
   *find*.

3. **Independent verification target**: reproduce or audit the published
   `S(13)=34` computation (Kasai et al. 1994 / Peczarski 2004) by running a
   modern congruence-quotiented solver under the exact same adaptive model and
   documenting parameters. This is the most decision-relevant finite
   computation, but it requires a serious implementation or an existing solver.

## 7. Conclusion

`[experiment,deduction]` Under assumptions A1–A3, the exact finite checks show:
`C(13)=33`, the antichain has one admissible first-move orbit to `P1` with
`e=13!/2`, and all 77 depth-2 moves from `P1` remain admissible, giving three
Wells heavier-child orbit classes at depth 2 with `e∈{13!/4,13!/3}`. **No
obstruction is found at depths <=2; the result is inconclusive.** The
literature-reported value `S(13)=34` is recorded but **not verified** here. No
claim `S(13)>33` is made. The minimal next finite step is a congruence-quotiented
extension of Wells/Stober–Weiss-style admissible search beyond depth 2 with
explicit resource reporting, or an audited reproduction of the published
`n=13` computation.
