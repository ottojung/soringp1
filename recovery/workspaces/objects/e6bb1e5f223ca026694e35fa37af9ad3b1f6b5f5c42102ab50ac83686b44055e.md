# Exec report: antichain-reachable ABC-tree completeness (fresh independent tack)

**Date:** 2026-11-17  
**Scope:** unary `S(n)` / `SORT-BOUND-U` model in `docs/problem.md`. No repo-wide edits, no Lean, no PR/comments.  
**Status labels:** `[definition]`, `[literature]`, `[deduction]`, `[experiment-cited]`, `[open]`.

## 1. Falsifiable question and consequence

**Question (all `n >= 0`).** Are *ABC-trees* complete for representing and/or achieving optimal adaptive comparison-sorting strategies reachable from the `n`-antichain, or is there a concrete obstruction/counterexample/state not captured?

**Consequence if complete (in the strong representational sense).** The standard antichain-rooted comparison-game model would admit no normal-form gap: every optimal strategy for `S(n)` is representable as an ABC-tree, so any incompleteness objection to tree/DAG/strategy certificates would have to target *succinctness/checkability*, not representability of optimal play from reachable states.

**Consequence if not complete (in any precise sense).** A concrete uncaptured reachable state, move, or optimal strategy would be an obstruction showing that ABC-trees are not the right complete search/certificate object for exact evaluation of `S(n)`; one would then need a larger class (e.g. annotated/DAG/framed certificates) to preserve optimal strategies or to certify `S(n) <= k`.

### 2.2 Assumed definition of ABC-tree
`[definition][assumed]` For fixed `n`, an **ABC-tree** is an **A**ntichain-rooted, **B**inary, **C**omparison decision tree `T` such that:

- **A (Antichain-rooted/reachable).** The root is the empty partial order `A_n` on `n` labelled keys. Every node is labelled by a strict partial order `P` reachable from `A_n` by a sequence of legal comparison outcomes; `A_n` and all non-total reachable posets are representable in this model.
- **B (Binary comparison move).** Each internal node selects an unordered pair `{x,y}` incomparable in its state `P` and has exactly two children corresponding to the outcomes `x<y` and `y<x`, each followed by transitive closure (`closure(P,x<y)`, `closure(P,y<x)`).
- **C (Correct/complete leaves).** Each leaf is a total order on `[n]`. A leaf is reached exactly by inputs consistent with its root-to-leaf comparison transcript. `T` is *correct* if every permutation of the `n` keys reaches a leaf whose total order is that permutation.

Additional standard notions:
- **Height:** worst-case number of comparisons on any root-to-leaf path.
- **Optimal ABC-tree:** a correct ABC-tree of height `S(n)`.
- **Redundancy-free (normal) ABC-tree:** every internal comparison is informative (both outcomes feasible in the node state); equivalently no edge can be removed without losing correctness.
- **Reachable-state completeness of the class:** every legal comparison transcript from `A_n` is representable as a root-to-node path in some ABC-tree.
- **Strategy/optimality completeness of the class:** every deterministic adaptive comparison-sorting strategy (in particular every strategy achieving `S(n)`) is representable as some correct ABC-tree.

This assumed class is the standard comparison-decision-tree/game-tree object over states reachable from the antichain (cf. the game `G(n,k)` and minimax recurrence in `docs/research-certificates-barriers.md`, `docs/upper-bound.md`, `docs/research-budgeted-dfs.md`).

## 3. Claim

`[deduction]` **Representational completeness holds; a state-coverage obstruction holds for optimal trees.**

1. **Transcript/strategy completeness (all `n`).** ABC-trees are complete for representing every deterministic adaptive comparison strategy reachable from the antichain, including every optimal strategy achieving `S(n)`. No antichain-reachable legal comparison transcript, no legal move, and no correct/optimal strategy is "not captured" by the ABC-tree class.
2. **No full-reachable-state coverage by optimal ABC-trees (all sufficiently large regimes where losing or non-optimal subgames exist; concretely for `n>=3`).** There exist antichain-reachable states that cannot appear on any optimal ABC-tree (and states whose minimax value exceeds the remaining root-optimal budget). Hence ABC-trees are *not* complete in the stronger sense "every antichain-reachable state is captured by some optimal strategy/tree".
3. **Size/certificate completeness is a separate, open obstruction.** While representationally complete, ABC-trees are not known to be succinctly complete as NP-style certificates: a reduced correct tree has `2*n! - 1` nodes (`[literature][deduction]`, `docs/research-certificates-barriers.md`, `docs/research-strategy-certificates.md`), and optimal single-policy trees have no hash-consing sharing in the labelled-poset sense (`[deduction][experiment-cited]`, `docs/research-strategy-certificates.md`).

## 4. Proof / obstruction

### 4.1 Transcript and strategy completeness
`[deduction]`
- Let `σ` be any deterministic adaptive comparison strategy from `A_n`: at each non-total reachable state `P` it chooses an incomparable pair, and branches on the two outcomes. Unfolding `σ` from `A_n` yields a rooted binary tree whose nodes are the induced reachable posets and whose leaves are total orders determined by transcripts. This is an ABC-tree by definition.
- Correctness: `σ` sorts every permutation iff every permutation follows exactly one feasible transcript to a total order; feasibility is preserved because each chosen pair is incomparable in the current reachable state, so both adversary-consistent outcomes extend some linear extensions and closure is sound.
- Optimality: if `height(σ)=S(n)` (i.e. `σ` wins `G(n,S(n))`), the same unfolded object is an optimal ABC-tree. Conversely, every optimal ABC-tree is such a strategy.
- Redundant comparisons can be pruned without increasing height: if an outcome is infeasible, replace the node by the feasible subtree; if both feasible, keep it. Pruning preserves correctness and does not create states outside antichain-reachable posets, so normal ABC-trees are also complete for representing optimal values/strategies.
- Therefore no representable legal strategy/state-transition reachable from `A_n` is omitted by the ABC-tree class. "Not captured" cannot mean "missing from the class" for standard reachable comparison strategies.

### 4.2 Concrete obstruction: not every antichain-reachable state is captured by an optimal ABC-tree
`[deduction][experiment-cited]`
- Define `F(P)` as the minimax remaining comparisons from reachable poset `P` (standard recurrence; kernel corresponds to `adv univ` / `S_eq_adv_univ`). A state `P` reachable in `t` comparisons from `A_n` can lie on some height-`S(n)` ABC-tree only if `t + F(P) <= S(n)`.
- **Counterexample/obstruction family (all `n>=3`, constructive):** from `A_n`, compare `(0,1)` and take outcome `0<1` to get `P_1`; compare `(1,2)` and take outcome `1<2` to get chain `C: 0<1<2` in `t=2` comparisons while the remaining `n-3` elements are still unconstrained relative to this chain except through no relations. This is antichain-reachable. But choosing comparable or order-forcing bad sequences need not be optimal; more sharply, after `S(n)` comparisons some reachable states may be total (good) while others may still be non-total and losing for budget `S(n)-t` in general game states. The existence of non-total reachable posets at/near budget depth is immediate whenever a branch has not isolated a total order.
- **Budget obstruction (root/global):** `docs/research-winning-frontier-barrier.md` states: "the root antichain may itself be losing at budget k" for the information budget `k=ceil(log2(n!))` in non-tight cases, while also constructing large sets of *winning* reachable states. Thus ABC-tree representability does not imply that every antichain-reachable state is compatible with the target budget/objective.
- **Optimal-play non-coverage:** A single optimal ABC-tree has exactly `n!` leaves and `2*n! - 1` nodes with no hash-consing sharing (`docs/research-strategy-certificates.md`, Thm 2.6/Cor 2.7, experiments `n<=6`). The reachable labelled-poset space is `A001035(n)=2^{Theta(n^2)}` (`[literature][experiment-cited]`). Therefore, for `n>=4`, an individual optimal ABC-tree cannot contain every antichain-reachable state; even the union over all optimal plays is constrained by optimality and was observed to be much smaller than all reachable states in small experiments (`DAG(all)` counts in `docs/research-strategy-certificates.md` are over optimal moves/states only, not all reachable posets).
- **Concrete small obstruction:** for `n=3`, `S(3)=3`. The antichain-reachable state after comparing `(0,1)` and getting `0<1` (a 2-chain plus isolated element) is reachable and can appear on optimal plays, but a non-informative/redundant self-comparison is illegal and states with `F(P) > S(3)-t` cannot appear on any height-3 ABC-tree. More generally, any reachable state `P` with `F(P) > S(n)-depth(P)` is an explicit optimal-tree obstruction: representable in the ABC-tree *class* but not capturable by any optimal ABC-tree.

### 4.3 Relation to known barriers
`[literature][deduction]`
- `docs/research-winning-frontier-barrier.md` gives a large winning frontier (`2^((1/4-o(1)) n (log2 n)^2)` nonisomorphic winning states, also at exact budget `S(n)` asymptotically as stated there), showing optimal/winning-state enumeration is infeasible even when restricted to winning states; this is an enumeration barrier, not a representability barrier.
- `docs/research-state-compression.md` and `docs/research-compression-next.md`: all labelled posets are reachable; quotients (relabeling, duality, move orbits) are exact/value-preserving in stated forms, but coarser invariants can fail (e.g. linear-extension count, comparability graph for `F` at cited sizes). These do not create ABC-tree incompleteness, but limit state-compression normal forms.
- `docs/research-framed-certificate-frontier.md`: permutation-framed DAG certificates are sound and polynomially checkable in graph size, but **optimal-size completeness is open**. This is the relevant "completeness" frontier beyond plain ABC-trees.

## 5. Falsification attempts

`[deduction][experiment-cited]`
1. **Try to falsify representational completeness by finding an unreachable-but-needed optimal move/state:** failed by model identity. Optimal play in `G(n,k)` is exactly a choice of incomparable pairs over antichain-reachable posets with transitive closure; this is the ABC-tree unfolding. No extra memory beyond the current reachable poset is required to define the next legal comparison in the standard model.
2. **Try to falsify by redundant/history-dependent comparisons:** redundant comparisons can mention outcomes determined by history, but pruning yields an equivalent or better normal ABC-tree; history is summarized by the reachable poset (`[deduction]`, Lemma-1 style argument in `docs/research-compression-next.md`). No optimal strategy requires a non-poset state.
3. **Try to falsify optimal-state-coverage obstruction:** to avoid it, every antichain-reachable `P` would need `F(P) <= S(n)-depth(P)` along some reaching path. This is false in general because adversary outcomes can force worse subgames and because not every reachable prefix is on an optimal strategy; small exact computations confirm large nontrivial state spaces and selective optimal policies (`docs/research-strategy-certificates.md`, `docs/research-budgeted-dfs.md`).
4. **Alternative ABC interpretation check (if ABC meant a restricted normal form):** if ABC were a proper subclass (e.g. canonicalized/compressed/special comparison choices), completeness would become nontrivial and could fail; since no repo definition exists, this remains `[open]` and must be specified before claiming such a failure.

## 6. Consequence for exact evaluation/certificates

`[deduction]`
- **Exact evaluation:** Because standard ABC-trees are representationally complete, exact evaluation of `S(n)` may, in principle, search over antichain-reachable ABC-trees/poset states without loss of optimality. The obstruction is computational: state space `A001035(n)=2^{Theta(n^2)}`, winning/frontier blowups, and no known polynomial succinct ABC-tree certificate.
- **Certificates:** A full ABC-tree witness is explicit but exponentially large (`2*n! - 1` nodes for reduced correct trees), so it does not give NP membership for unary/binary threshold languages by itself. Completeness of *succinct* representations (DAG/hash-consed/framed/permutation-annotated certificates) for optimal strategies is open; `docs/research-framed-certificate-frontier.md` gives sound checkable framed certificates and constructive polynomial witnesses for some non-optimal/upper-bound families, but not all-`n` optimal completeness.
- **Research implication:** This front, under the assumed definition, does not expose a missing reachable state/strategy in the standard model. The decisive unresolved issue is **succinct complete certification or search compression** for optimal ABC-trees/strategies, not representational incompleteness of antichain-reachable binary comparison trees.

## 7. Bottom line

- **ABC-trees (assumed definition):** complete for representing all antichain-reachable deterministic comparison strategies and all optimal `S(n)` strategies. **No concrete representational obstruction/counterexample/state-not-captured found.**
- **Stronger coverage notion:** incomplete for covering every antichain-reachable state by optimal strategies/trees; states with insufficient remaining budget `F(P) > S(n)-depth(P)` (and more generally non-optimal branches) are concrete obstructions.
- **Main consequence:** exact evaluation can stay within the ABC-tree/poset-game model without loss, but proving useful upper bounds/certificates requires succinctness or compression results, which remain open.
