# FO(TC) policy descriptions and worst-case-depth certificates (antichain root)

## Question addressed

Determine whether uniform FO(TC) policy descriptions admit a polynomially checkable proof of worst-case comparison depth at the antichain root, rather than just polynomial evaluation on a single input order.

**Operational interpretation used here (definition/conjecture boundary stated explicitly).**
- A *policy description* for fixed `n` is a uniform description that, given the current comparison transcript/state, selects the next comparison (and/or recognizes terminal outcomes) for the sorting game rooted at the antichain; equivalently it encodes an adaptive comparison strategy for `S(n)`.
- *FO(TC)* is taken in the standard descriptive-complexity sense: first-order logic extended with a transitive-closure operator, interpreted over finite relational structures with a suitable encoding of the current game state (and, in the ordered setting relevant to captures, an order on the universe) (literature; see below).
- *Polynomial evaluation on a single input order* means: for one concrete permutation/input order, the policy can be executed along that single root-to-leaf path within time polynomial in the relevant input/encoding length (a path property).
- *Polynomially checkable proof of worst-case comparison depth at the antichain root* means: a certificate/witness whose validity establishes a global bound `depth(policy, antichain_n) <= k` for **all** adversary outcomes/input orders and which is verifiable in deterministic polynomial time in the certificate/input length (an all-path property), as required for NP-style membership of `SORT-BOUND-U`.

The decisive consequence (as stated in the front): a sound, complete, and polynomial-size proof-carrying FO(TC) normal form for optimal/all-`n` policies would establish `SORT-BOUND-U ∈ NP`; mere single-input executability does not.

## Main findings

### 1. Single-input evaluation is a path property; worst-case depth is a global game property (deduction)

- **Definition/deduction.** An adaptive comparison policy induces, for each input permutation, exactly one root-to-leaf execution path whose length is the number of comparisons on that input. Evaluating the policy on a *single* input order inspects only that path (plus the local next-move computation). Establishing `S(n) <= k` or certifying a policy's worst-case depth requires a guarantee over **all** `n!` permutations / both adversary branches at every internal choice, i.e. the full minimax value of game `G(n,k)` rooted at the antichain (docs: `research-certificates-barriers.md` Claim A, model).
- **Deduction.** Therefore polynomial-time executability on individual inputs is, by itself, logically weaker than possession of a polynomial-time checkable worst-case-depth proof: a correct-but-slow-to-verify global invariant is compatible with fast per-input stepping, while an NP-style certificate must compress the all-path guarantee.

### 2. Explicit strategy witnesses are exponential; succinct framed witnesses are sound/checkable but completeness is open (literature/deduction, repo-established)

- **Literature/deduction (repo).** A reduced explicit comparison tree has `2*n! - 1` nodes/leaves accounting (Claim C, `research-certificates-barriers.md`), so it is not a polynomial certificate in the unary input length on informative instances. The memoized poset/game view is exponential in the state space in general (`2^{Θ(n²)}` labelled posets appear), though optimal play may visit far fewer states — this is unresolved.
- **Paper construction / implemented soundness checker (repo frontier, not independently audited here).** `research-framed-certificate-frontier.md` describes a permutation-framed DAG grammar: if a polynomial-size graph of height `S(n)` exists for every `n`, then `SORT-BOUND-U ∈ NP`; soundness is locally checkable in time polynomial in the explicit graph. Polynomial framed DAGs are constructed at paper level for balanced merge sort and (plausibly, pending frame audit) the Ford–Johnson upper-bound schedule, but these do **not** attain exact `S(n)` for all `n` (merge sort exceeds `log2(n!)` by linear margin on large powers of two; Ford–Johnson gives the known upper bound `F_FJ(n)`, not `S(n)`).
- **Deduction.** Hence "polynomially checkable proof of worst-case depth" is *formally available in principle* conditional on an all-`n` polynomial-size complete certificate family (e.g. optimal framed DAGs/policies), but such completeness is exactly open. Execution of any given policy on one order provides no such global certificate.

### 3. Descriptive-complexity placement: PSPACE/FO(PFP) is known at the language level; FO(TC) or FO(LFP) policy/certificate normal forms would be genuine upper-bound results (literature/deduction)

- **Literature/deduction (repo + standard descriptive complexity).** `SORT-BOUND-U ∈ PSPACE` is established by the alternating/game argument (`research-certificates-barriers.md` Claim A; `problem.md`). By Immerman's capture theorem on ordered finite structures, PSPACE corresponds to FO(PFP), so an FO(PFP)-definable presentation of `SORT-BOUND-U` is consistent with the known upper bound (as noted in `research-plan.md`, "Descriptive complexity"). This is a language/definability fact, not by itself a succinct *policy* certificate.
- **Literature.** On ordered structures, FO(TC) captures NL and FO(LFP) captures P (Immerman–Vardi/Immerman). NL ⊆ P ⊆ NP ⊆ PSPACE are standard inclusions.
- **Deduction (conditional implication).** If there existed, for all `n`, an FO(TC)-expressible (or FO(LFP)-expressible) policy description together with a **sound, complete, polynomial-time verifiable** proof object for its antichain-root worst-case depth `<= k` (a proof-carrying normal form), that would place the corresponding threshold recognition/certification within NP (indeed within P-verifiable witness frameworks) and would constitute a new upper bound `SORT-BOUND-U ∈ NP` in the strong certificate sense asked for. No such normal form is known. Conversely, FO(TC)-expressibility of a *single-input* next-move/evaluation relation does not imply FO(TC)- or P-checkability of the universal worst-case-depth property.

### 4. No theorem-level answer obtained; falsifier not constructed (inconclusive)

- **Inconclusive.** I did not find (in consulted docs/literature recalled here) and did not prove: (a) an all-`n` theorem that FO(TC)-uniform policies admit polynomially checkable worst-case-depth proofs, nor (b) an explicit FO(TC)-expressible policy family whose worst-case budget is provably hard to check under standard assumptions while remaining policy-expressible, nor (c) an unconditional expressive-completeness failure for FO(TC) policies over the antichain sorting game.
- **Deduction (barriers to naive hardness claims).** A proposed many-one NP-hardness of `SORT-BOUND-U` would imply `P=NP` by Mahaney because the language is sparse (Claim B). Parberry-style coNP-hardness concerns fixed-network correctness verification, a different model from adaptive antichain-root policies (Claim D); it does not transfer directly. These block easy routes to the "hard to check" falsifier but do not rule out all certificate-complexity obstructions.

## Precise obstacles

1. **All-path/global quantification gap.** Worst-case depth at the antichain root quantifies over all comparison outcomes/permutations (a minimax/alternating property). Turning local FO(TC)-definable next-move rules into a polynomial-time verifiable global depth bound requires either a succinct invariant that closes over all branches or an explicit polynomial-size unfolded proof; neither is known in general for optimal `S(n)`.
2. **Optimal-size completeness of succinct representations.** Framed/permutation-labeled DAG certificates are sound and locally checkable when given, but all-`n` polynomial-size completeness at height `S(n)` is open (`research-framed-certificate-frontier.md`, `research-plan.md`). Known polynomial constructions (merge sort, Ford–Johnson envelope) certify upper bounds, not exact optimality for all `n`.
3. **Expressive power vs. existence of optimal strategies.** It is unclear whether *some* optimal (or near-optimal) root policy for every `n` is definable uniformly in a low descriptive class such as FO(TC)/FO(LFP), and separately unclear whether such definability would yield a checkable depth proof rather than only a step relation. `research-plan.md` warns not to infer a smaller-class definition from a compact informal recursion.
4. **Model/encoding sensitivity.** FO(TC)/FO(LFP)/FO(PFP) captures are usually stated on ordered finite structures of the input; mapping the sorting game state (posets/transcripts at the antichain root, parameter `n` in unary) to that setting must be made explicit to state a theorem. Without a fixed encoding, "FO(TC) policy description" is under-specified.
5. **No known tight global potential.** Lower-bound/worst-case certification beyond the information bound lacks a succinct potential in the hard regime (Claim C table / §8 of `research-certificates-barriers.md`), obstructing both positive NP/coNP certificates and structured hardness witnesses.

## Falsification attempts

- **Attempt F1 (transfer generic hardness to checking).** Tried to instantiate the falsifier via Parberry's coNP-completeness of sorting-network verification. *Outcome:* rejected as non-transferable — fixed comparator networks with universal correctness differ from adaptive policies with existential move choice at the antichain root (Claim D, literature). Not a falsifier.
- **Attempt F2 (NP-hardness of the threshold language as "hard to check").** Considered hardness of `SORT-BOUND-U` as evidence that depth proofs are hard. *Outcome:* blocked as a direct many-one route by sparsity/Mahaney (Claim B); and in any case language hardness is distinct from hardness of verifying a given FO(TC) policy certificate. Not a falsifier.
- **Attempt F3 (exhibit explicit FO(TC)-expressible but depth-hard policy).** Sought a concrete candidate in repo docs/scripts (merge-insertion/greedy/known constructions). *Outcome:* existing constructive families discussed are either heuristic/experimental or certify known upper bounds; no formal FO(TC) syntax/semantics and no proof of worst-case-depth verification hardness were available. No explicit falsifying instance constructed. **Inconclusive.**
- **Attempt F4 (completeness via known polynomial framed policies).** Tested the positive direction against stated constructions: merge sort and Ford–Johnson framed DAGs give polynomial sound witnesses for their *own* bounds but not for `S(n)` for all `n` (Sergeev/optimality gap). *Outcome:* fails to witness all-`n` optimal completeness; positive claim remains open. **Inconclusive/negative for these candidates.**

## Conclusion (labeled)

- **Literature/deduction:** Single-input FO(TC) (or otherwise uniform) policy evaluation is not, by itself, a polynomially checkable proof of antichain-root worst-case comparison depth; worst-case depth is an all-path minimax property.
- **Literature/deduction (conditional):** A sound, complete, polynomial-size proof-carrying FO(TC) (or similarly checkable) normal form for all-`n` optimal policies would imply `SORT-BOUND-U ∈ NP`; this is the meaningful "yes" target.
- **Inconclusive:** Whether such a normal form exists, or whether there is an explicit FO(TC)-expressible policy whose worst-case depth is hard to certify / whose all-`n` completeness fails, remains open based on consulted evidence. No theorem completion is claimed.

## Concrete next decisive question

Fix a precise encoding of antichain-root sorting states as ordered finite structures and a formal FO(TC) policy schema (next-comparison relation). Then answer the following all-`n`, falsifiable question:

> **Q:** Is there a polynomial-time verifier `V(1^n,1^k,w)` and, for every `n`, a witness `w_n` of size `|w_n| <= poly(n+k)` such that `V` accepts iff `w_n` encodes a *sound* adaptive policy of worst-case depth `<= k` from the antichain on `n` elements, with completeness at `k = S(n)`? Equivalently in this framing: does some uniform (candidate: FO(TC)/FO(LFP)-describable) policy family admit proof-carrying worst-case-depth certificates of optimal height for all `n`?

**Why decisive:** a positive answer gives `SORT-BOUND-U ∈ NP` (a genuine upper bound); a rigorous negative answer restricted to a well-specified certificate/policy class (with a proof that no sound complete family of that class exists at `S(n)` for infinitely many/all relevant `n`) would be a strong barrier theorem. **Discriminating experiment/paper step:** attempt to (i) formally specify and audit an FO(TC)-definable framed-certificate verifier for the merge/Ford–Johnson/Sergeev-style constructions and measure exact depth gaps vs `S(n)` on known values, and/or (ii) prove an incompleteness/barrier for bounded-logic or bounded-state FO(TC) policy classes against the winning-frontier/state-explosion phenomena. Either outcome must be tied back to `S(n)` (not generic partial orders).
