# Sergeev asymptotic bound: effectivization for exact-evaluation search window

**Scope.** Analysis only. No repository-wide edits, no Lean, no PR/comments. All claims are labeled (**definition**, **literature**, **deduction**, **conjecture**, **obstruction**).

## 1. Falsifiable question

**Definition / question.** Can an effective or explicit finite version of Sergeev's asymptotic bound
\[
S(n)-\log_2(n!) = O\!\left(\frac{n}{(\log n)^{1/5}}\right)
\]
be extracted or sharpened so as to narrow the threshold/search window \([C(n), U_{\mathrm{eff}}(n)]\) for exact evaluation of \(S(n)\) / `SORT-BOUND-U`, with a concrete computable \(U_{\mathrm{eff}}(n)\) and justified constants/asymptotics? If not, what is a precise obstruction to effectivization?

Here \(C(n)=\lceil \log_2(n!) \rceil\) is the information lower bound (**literature/definition**, standard), and an "effective/computable finite" upper bound means a function \(U_{\mathrm{eff}}:\mathbb{N}\to\mathbb{N}\) given by an explicit formula or algorithm (computable for each \(n\) from finite data) together with a justification that \(S(n)\le U_{\mathrm{eff}}(n)\) for all \(n\) in the stated domain (**definition**).

## 2. Claim (summary)

- **Literature.** Sergeev proves the asymptotic existence of comparison-sorting algorithms with excess \(o(n)\), specifically \(O(n/(\log n)^{1/5})\) over \(\log_2(n!)\), via group-insertion methods (ECCC TR20-096, 2020, Thm. 3 p.29; journal version DOI 10.1134/S0965542521020111, as recorded in `docs/research-sergeev-asymptotic.md` and `docs/literature.md`).
- **Deduction (from available sources in this workspace).** The cited asymptotic statement alone does **not** yield a concrete finite \(U_{\mathrm{eff}}(n)\): no explicit constants \(c,n_0\), no finite base-case rule, and no fully explicit parameter schedule valid for all \(n\) are provided by the repository's recorded theorem statement.
- **Obstruction (precise, source-limited).** Effectivization is blocked, relative to the information currently available here, by the *asymptotic/non-explicit-constant form* of the main bound and by the absence (in the cited statement) of an audited finite instantiation of all intermediate choices in the group-insertion construction. A complete effective bound would require extracting explicit constants and all threshold/parameter selections for every \(n\) (or for all \(n\ge n_0\) plus finitely many verified base cases) from the full proof; this extraction is not performed in-repo and cannot be certified from the abstract-level statement alone.
- **Deduction (consequence).** Therefore, no Sergeev-derived narrowing of \([C(n),U_{\mathrm{eff}}(n)]\) beyond already-explicit finite bounds (e.g. Ford–Johnson/merge-insertion and other elementary upper bounds recorded in the project) can be justified here. The question is **unresolved in the effective direction** given available evidence: asymptotic sharpening is known in principle, but an explicit computable finite \(U_{\mathrm{eff}}(n)\) with justified constants is **not extracted**.

(PDF body was not text-extractable in this environment; analysis below distinguishes metadata/abstract-level facts from proof internals.)

### 3.2 Model fidelity (definition/literature context)

- **Definition.** \(S(n)\) is the adaptive worst-case comparison complexity (decision-tree height) for sorting \(n\) distinct labelled keys (`docs/problem.md`).
- **Deduction.** A sorting-algorithm comparison bound \(A(n)\) implies \(S(n)\le \lceil A(n)\rceil\) (or \(\lfloor A(n)\rfloor\) as appropriate to the count) when the algorithm is a correct deterministic adaptive comparison procedure for all inputs of size \(n\). Sergeev's result is an upper bound on \(S(n)\) in this sense (**literature**, per repo description).

## 4. Derivation: what an effective finite \(U_{\mathrm{eff}}(n)\) requires

**Deduction.** To narrow \([C(n),U_{\mathrm{eff}}(n)]\) with a Sergeev-based *effective* bound, one of the following concrete deliverables is needed:

1. **Uniform explicit form:** constants \(c>0\), \(n_0\in\mathbb{N}\), and a proved inequality
   \[
   S(n) \le U_{\mathrm{eff}}(n) := \lceil \log_2(n!) + g(n) \rceil, \qquad g(n)\le c\,\frac{n}{(\log n)^{1/5}} \text{ for all } n\ge n_0,
   \]
   together with a finite, verified table/bound for \(n < n_0\).
2. **Piecewise explicit computable form:** an explicit algorithm/recurrence producing \(U_{\mathrm{eff}}(n)\) for every \(n\ge 1\), with a complete proof that each branch/parameter choice used by the underlying sorting procedure is valid at that \(n\).
3. **Strengthened finite bound:** any explicit \(U_{\mathrm{eff}}(n)\le FJ(n)\) (Ford–Johnson) on a justified infinite range, or a computable bound improving the best currently certified window for exact evaluation.

**Deduction.** Big-O notation alone gives: \(\exists c,n_0\,\forall n\ge n_0\) but does not exhibit \(c,n_0\) nor certify small \(n\). Hence an asymptotic theorem is not, by itself, a finite computable \(U_{\mathrm{eff}}\).

## 5. Effective bound status

- **No concrete \(U_{\mathrm{eff}}(n)\) extracted (deduction from available evidence).** From the materials accessible in this workspace (repository docs and ECCC abstract/metadata), I cannot produce explicit \(c,n_0\) or a complete finite parameterization justified by the proof.
- **Not a disproof of effectivization (deduction).** Absence of extraction here does not imply the proof is inherently non-constructive in principle; Sergeev's method is described as an algorithmic/group-insertion construction (**literature**). The gap is between an *asymptotic existence/analysis* statement and a *fully explicit finite instantiation*.
- **Comparison baseline (literature/project baseline).** Ford–Johnson/merge-insertion gives an explicit finite upper bound \(FJ(n)\) for all \(n\) (standard; referenced in repo docs as the explicit finite bound). Any Sergeev-derived \(U_{\mathrm{eff}}(n)\) would be meaningful for window-narrowing only if made explicit and, for relevant \(n\), competitive with or better than such certified bounds (or useful in a regime where \(FJ(n)-C(n)\) is large).

## 6. Precise obstruction(s) to effectivization

1. **Non-explicit asymptotic constants (obstruction, proof-form).** The headline result is stated with \(O(\cdot)\); turning it into a theorem "for all \(n\ge n_0\), \(S(n)\le \ldots\)" requires identifying every hidden constant in every intermediate estimate and tracking their composition. **Deduction:** without those values, \(U_{\mathrm{eff}}(n)\) is undefined.
2. **Parameter/regime selection (obstruction, likely; conjectural without full proof text).** Group-insertion/asymptotic sorting analyses typically choose block/group sizes or auxiliary parameters as functions optimized for large \(n\) (sometimes via floors/ceilings and regime splits). **Conjecture (methodological):** a finite \(U_{\mathrm{eff}}(n)\) needs a globally valid, explicit schedule and proofs that side conditions hold at each finite \(n\), not only eventually.
3. **Certification burden (deduction).** Even if the construction is algorithmic, an "effective bound" claim for the SoringP1 contract must be justified, not merely asserted: one must supply the explicit inequality chain or a mechanically checkable derivation. **Obstruction:** this is substantial proof-engineering work beyond the cited asymptotic statement.
4. **Falsification/limit of usefulness (deduction).** An explicit asymptotic-form bound with very large constants or very large \(n_0\) may be mathematically effective yet *not* narrow \([C(n),U_{\mathrm{eff}}(n)]\) for any \(n\) where exact \(S(n)\) is currently unknown or computationally relevant. Thus "effective" does not automatically imply "practically sharpening."

## 7. Algorithmic consequence for exact evaluation / `SORT-BOUND-U`

- **Deduction.** Exact evaluation or threshold decision can be organized as search/verification over budgets \(k\in [C(n), U(n)]\). Shrinking \(U(n)\) reduces the number of candidate thresholds/budgets that must be considered; however, the dominant project-side cost in known exact methods is the exponential state/game exploration (e.g. \(2^{O(n^2)}\), \(2^{O(n\log^2 n)}\) families recorded in `docs/research-plan.md`), not merely the arithmetic width \(U(n)-C(n)\).
- **Deduction (current state).** Because no explicit Sergeev-derived \(U_{\mathrm{eff}}(n)\) is extracted here, there is **no justified algorithmic improvement** to the search window from this source at present. The safe explicit upper endpoints remain those already established/recorded (e.g. Ford–Johnson, elementary \(n(n-1)/2\), project upper-bound frameworks) depending on the required certification level.
- **Conditional consequence (deduction).** If future work extracted a certified explicit \(U_{\mathrm{eff}}(n)\) with \(U_{\mathrm{eff}}(n) < FJ(n)\) on some range, it would tighten upper-budget pruning/search for those \(n\); if also asymptotically \(U_{\mathrm{eff}}(n)-C(n)=o(n)\) with explicit constants, it would improve asymptotic window knowledge but would not by itself change the exponential-time character of known exact evaluators.

## 9. Bottom line

**Deduction (answer to the falsifiable question, given available evidence):** an explicit, finite, computable Sergeev-derived \(U_{\mathrm{eff}}(n)\) narrowing \([C(n),U_{\mathrm{eff}}(n)]\) is **not extracted** from the sources available in this workspace. The asymptotic improvement \(S(n)-\log_2(n!)=O(n/(\log n)^{1/5})\) is **literature-known** but, as stated, insufficiently explicit for a certified finite window bound. The principal obstruction is **effectivization work**: making all asymptotic constants and all finite parameter choices explicit and universally justified (or explicitly delimited with verified base cases). Any future claim of narrowing must supply that explicit \(U_{\mathrm{eff}}(n)\) and a proof valid for the stated \(n\).
