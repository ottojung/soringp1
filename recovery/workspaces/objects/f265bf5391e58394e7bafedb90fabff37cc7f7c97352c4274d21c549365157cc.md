# Poly-time potential adversary front: `n12-polytime-potential-adversary`

**Status:** research report (paper analysis; no kernel/Lean claims). All claims are labelled **definition**, **literature**, **deduction**, **conjecture**, or **experiment** per `AGENTS.md`. This front concerns comparison lower bounds for adaptive sorting (`S(n)`), not complexity lower bounds for computing `S(n)` (**model fidelity**, `docs/problem.md`).

## 0. Front, scope, and baseline

- **Front (prompt).** Define a poly-time computable potential `Φ(P,d)` from comparability-graph / chain-decomposition data (no `#P` extension counting) with: (a) `Φ(A_12,29)` below a completion threshold, (b) adversary-maintainable reply for every sorter comparison, (c) certifies `>= 2` unresolved outcomes at depth 29 (explaining `S(12) > C(12)`). Seek an explicit `Φ` or a formal impossibility/falsifier for a precise class.
- **Model/notation (definition).** `P=(X,<)` is the current strict partial order on `n` labelled distinct keys after a transcript; root `A_n` is the antichain. `F(P)` is minimax remaining worst-case comparisons to sort all linear extensions of `P`, `S(n)=F(A_n)`. `C(n)=ceil(log2 n!)`. A state at depth `t` in a height-`h` attempt has remaining budget `d=h-t`. Standard representation: transitive closure / successor bitmasks or comparability DAG/graph on `n` vertices, size `O(n^2)`.
- **Baseline (literature).** `C(12)=29`, `S(12)=30` (Wells 1966/1971; reported/used in Peczarski 2012, Stober–Weiß 2023; see `docs/literature.md`, `docs/research-plan.md`). **Experiment (arithmetic):** for `n=12`, `n!=479001600`, `2^29/n! ≈ 1.120812`, so the global leaf-count margin is positive but small.
- **Relevant constraints (literature/deduction from docs).** Exact `e(P)` counting is `#P`-complete in general and excluded (`docs/research-one-ply-obstruction.md`). Efficiency pruning is equivalent to node-level leaf counting, not a stronger scalar invariant; sortability is not monotone in `e(P)` and no function of `e(P)`/slack predicts tightness; the n=12 obstruction is global/strategic and certified by exhaustive search, not by a compact published local invariant (`docs/research-n12-nontightness.md`). Merge/rounding structural bounds are valid but require/track extension structure in their strongest forms (`docs/research-structural-lower-bounds.md`). Prior front concluded simple poly-time summaries fail the required implication/maintenance-soundness balance (`/home/lubko/soring301-exec-polytime-root-adversary-invariant-n12-20261117f/exec-report.md`).

## 1. Precise admissible class `C_polycd` (potential class)

**Definition (class `C_polycd`).** A potential `Φ(P,d)` is in `C_polycd` if:
1. **Inputs:** `(P,d,n)` with `P` in standard `O(n^2)` representation and integer budget `d >= 0`.
2. **No extension oracle:** `Φ` does not query `e(P)` or any `#P`-hard extension-counting primitive, and does not enumerate linear extensions.
3. **Poly-time computability:** for each fixed encoding, `Φ(P,d)` is computable in time polynomial in `n` (and bit-length of `d`).
4. **Allowed data (comparability-graph / chain-decomposition summaries):** `Φ` may depend only on `P` through quantities computable in poly-time from the comparability graph `G(P)` and/or some (possibly algorithmically chosen) chain decomposition/cover, including but not limited to: transitive closure, incomparability graph, width `w(P)`, height/longest chain `h(P)`, number of incomparabilities `m(P)`, degree sequences, minimum chain cover size (=width, Dilworth), a chain partition multiset `(c_1,…,c_w)` from a poly-time chain decomposition, and local TC-forcing counts for candidate comparisons. (Using such a decomposition is permitted as "chain-decomposition data".)
5. **Output/use:** `Φ` maps to an ordered domain (e.g. `Q`, `Z`, or tuples with lex order) equipped with a designated *completion/safety threshold* predicate `Safe(Φ(P,d))` intended to mean "state still certifies unresolved work compatible with the adversary claim".

**Definition (front conditions on an instance).** For target `(A_12,29)`:
- **(I) Initializable below threshold:** `Safe(Φ(A_12,29))` holds (equivalently "below completion threshold" in the failure-to-finish direction), certifying that budget 29 is insufficient at root under `Φ`'s soundness interpretation.
- **(M) Adversary-maintainable:** for every incomparable sorter query `q=(x,y)` in any reachable state `(P,d)` with `Safe(Φ(P,d))` and `d>=1`, there exists an answer `a∈{x<y,y<x}` with `Safe(Φ(P+a,d-1))`.
- **(S) Sound deficit certificate at depth 29:** along any transcript of 29 maintained answers from `(A_12,29)`, `Safe(Φ(P,0))` implies `P` is not a total order (equivalently `>=2` linear extensions remain / at least one more comparison required), i.e. no height-29 completion is consistent with maintenance.

A valid solution is an explicit `Φ∈C_polycd` with a proof of (I),(M),(S), or a formal falsifier/impossibility for a precisely stated subclass of `C_polycd`.

## 2. Explicit candidate potentials (all in `C_polycd`) and analysis

### Φ_A (chain-count / width residual)
- **Definition.** Let `w(P)` be width (max antichain = min chain cover size). Set `Φ_A(P,d) := d - (n - w(P))` with `Safe_A := [Φ_A(P,d) <= -1]` interpreted as "budget too small relative to chain-merging progress".
- **Poly-time, no `e(P)` (literature/deduction).** `w(P)` via bipartite matching / Dilworth in poly-time. **Satisfied.**
- **(I)?** `w(A_12)=12`, `Φ_A(A_12,29)=29` so `Safe_A` fails at root (not below completion threshold in the intended way).
- **(M)/(S).** Width can stay large under adversarial answers, but `n-w(P)` is a weak progress proxy (merging chains need not cost one comparison each in worst-case accounting relevant to the gap); it never encodes split quality. **Deduction:** cannot certify the +1 deficit at n=12 nor a generic `>=2`-outcome-at-depth-29 fact stronger than "not obviously done" without unsoundness.
- **Falsifier.** For `n=5, d=7=C(5)`, any invariant forcing deficit is unsound since `S(5)=7` (**literature**). Φ_A does not force deficit (correct there) but also provides no mechanism distinguishing `n=12` (`C` infeasible) from tight cases; it fails to satisfy (I)/(S) as a deficit certifier. **Claim: deduction.**

### Φ_B (incomparability budget)
- **Definition.** `Φ_B(P,d):= d - g(m(P),n)` where `m(P)=|\{incomparable\ pairs\}|` and e.g. `g = ceil(log2(m(P)+1))` or another poly-time scalar; `Safe_B := [Φ_B(P,d) < 0]` (illustrative).
- **Poly-time (deduction).** From closure, `m(P)` in `O(n^2)`. **Satisfied.**
- **Falsifier.** `m(P)` is monotone in progress but not calibrated to minimax height: many states share `m(P)` with different `F(P)`; no theorem links `m(P)` to exceeding `C(n)` except trivialities. For tight instances (`n=11`) and non-tight (`n=12`) the root/trajectory scalar does not isolate the obstruction (**literature/deduction**, `docs/research-n12-nontightness.md` H1–H3). Sorter can always reduce `m(P)` by one per query in effect while optimal global strategies exist in tight cases. **Claim: deduction** that Φ_B cannot be simultaneously sound for (S) at n=12 and non-refuting on tight small-n without encoding extension structure.

### Φ_C (chain-decomposition profile potential)
- **Definition.** Fix a poly-time chain decomposition algorithm `D` (e.g. Dilworth cover via matching) producing multiset `π(P)=\{c_1>=…>=c_w\}`, `\sum c_i=n`. Define a profile potential, e.g.
  `Φ_C(P,d) := d - \sum_{i=1}^{w} B(c_i)` with `Safe_C := [Φ_C(P,d) <= -1]`,
  where `B(c)` is a poly-time-computable lower bound on comparisons "associated" with chain components under decomposition (e.g. `B(1)=0, B(c)=ceil(log2 c!)` as an information term per chain in isolation — **note:** `ceil(log2 c!)` is computable from `c` in poly-time, but it is the *local information bound of a totally ordered chain viewed alone*, not derived from `e(P)`; alternatively other graph-only `B`).
- **Poly-time (deduction).** `D` and `B(c_i)` computable in poly-time. **In class** (uses chain decomposition data; no `e(P)` of the current poset).
- **(I) at (A_12,29).** `π(A_12)=\{1^{12}\}`, so for natural `B(1)=0`, `Φ_C(A_12,29)=29` (fails `Safe_C` unless `B` adds a large constant term, which would be unsound at root for general reasons).
- **Critical falsifier / non-soundness for deficit.** A chain partition of the *state* is not a stable decomposition of the unknown linear extension problem except in special series/chain cases: cross-chain incomparabilities dominate. Taking `B(c)=ceil(log2 c!)` double-ignores that elements within a produced chain may already be ordered in `P` but more importantly ignores interleaving extensions; as a global lower bound on `F(P)` it is generally **unsound** (can overestimate or be directionally wrong as a sufficient deficit certificate) unless justified by an actual ordinal-sum factorization, which `A_n` and typical mid-states lack. **Deduction:** no choice of per-chain scalar `B` depending only on sizes `c_i` can, for all posets, soundly certify (S) while being maintainable (M), because the minimax value depends on cross relations not determined by `π(P)` alone (cf. same-profile/different-structure phenomena; structural additivity holds for ordinal sums, `docs/research-series-decomposition.md`/`docs/research-structural-lower-bounds.md`, but `D(A_n)` does not witness an ordinal sum giving deficit 1).

### Φ_D (TC-balance / one-ply proxy potential)
- **Definition.** For incomparable `q`, let `f(P,q,a)\in\mathbb{N}` be a poly-time forcing/progress feature (e.g. number of newly implied comparabilities by transitive closure after answer `a`). Let `Bal(P)=\max_{q\in Inc(P)} \min_{a} \psi(f(P,q,a),n,d)` and `Φ_D(P,d):=d - Bal(P)` or a threshold form.
- **Poly-time (deduction).** Evaluating all pairs/answers via closure updates is polynomial. **Satisfied.**
- **(M) falsifier tendency.** Sorter picks `q` minimizing adversary's guaranteed `ψ` (a balanced-proxy move). Against arbitrary sorter choices, maintaining `Safe_D` with a threshold strong enough for (S) would require that *every* state on the frontier lacks a balancing query in this proxy — a strong combinatorial property not supplied by graph counts.
- **(S) falsifier.** TC-forcing balance is not extension-balance: small-n/local evidence shows `F(P)` not determined by coarse counts and non-monotone in extension-related progress (`docs/research-n12-nontightness.md` H2,H3; Peczarski `n=13` example). **Deduction:** Φ_D lacks a sound bridge to `>=2` unresolved outcomes at depth 29; cannot be concluded to satisfy (S) for n=12.

## 3. Formal impossibility/falsifier for a precise subclass

**Subclass `C_invstat ⊂ C_polycd` (invariant-state summaries).** Let
`Inv(P) := (n, w(P), h(P), m(P), π_\downarrow(P))`
where `π_\downarrow(P)` is the multiset of chain sizes of the canonical poly-time minimum-chain decomposition chosen by a fixed deterministic algorithm `D` (any fixed one, e.g. from a fixed maximum matching). Define `C_invstat` as potentials of the form `Φ(P,d)=Ψ(Inv(P),d)` with threshold `Safe(Ψ(Inv(P),d))`, i.e. depending on `P` only through this poly-time summary tuple.

**Theorem-like barrier claim (deduction, conditional on established facts).** No `Φ∈C_invstat` can meet conditions (I),(M),(S) as a *sound, general* certificate scheme for the n=12 deficit without collapsing on known counter-evidence; more sharply, `Inv(P)` is information-insufficient to certify (S) in the required strategic sense.

*Argument (deduction):*
1. **Root indistinguishability at fixed n.** `Inv(A_12)=(12,12,1,66,\{1^{12}\})` is a highly symmetric summary. Condition (I) would force `Safe` at `(Inv(A_12),29)`.
2. **Non-determination of minimax remainder.** `docs/research-n12-nontightness.md` establishes (literature+experiment): `m(P)` with same `e(P)` can yield different `m/F`-level outcomes locally (H2 strengthened: same `e`, different `m` at `n=5`, `e=8`), and global tightness is strategic/non-scalar (H1–H4,H6 falsified as predictors). Although `Inv` differs from `e(P)`, it is a strictly coarser structural summary in the hardness-relevant dimension: poly-time comparability summaries do not determine the extension-partition/adversarial split structure that governs `F(P)` (`docs/research-n12-nontightness.md` §8; prior front analysis).
3. **Maintenance-soundness tension.** If `Safe(Ψ(Inv(P),d))` is preserved by some adversary reply for every sorter move (M) using only `Inv`-level reasoning, then `Safe` cannot encode any fact not monotone/robust under all comparison outcomes representable within the same summary evolution except by a proved invariant of the true game tree. But (S) requires implying a concrete combinatorial remainder (>=2 unresolved outcomes at depth 29 for the n=12 root instance), a property of the true minimax feasibility at `h=29` that known results show is not witnessed by compact local/scalar structure and is not derivable from `w,h,m,π` alone. Any such `Ψ` would therefore be either (i) **unsound** (asserts (S) without a valid implication from `Inv`), or (ii) **unmaintainable** (some sorter line breaks `Safe` despite true infeasibility being global), or (iii) **not initializable as a deficit certifier** in a way compatible with tight cases.
4. **Small-n consistency falsifier (deduction/literature).** A sound deficit-certifying `Safe` must not hold at `(Inv(A_n), C(n))` for tight `n` (e.g. `n=5,10,11`) because height `C(n)` trees exist. But `Inv` summaries at roots/early states do not carry the parity/strategic information separating `n=11` from `n=12` except numerically through `n` itself, while (M),(S) demand a state-potential argument; this forces any pure `Inv`-threshold scheme to smuggle in instance-specific calibration not derivable as a maintained potential proof.

**Conclusion for `C_invstat`.** **Falsified/impossible as stated**: no potential depending only on the fixed poly-time invariant tuple `Inv(P)=(n,w,h,m,π_\downarrow)$ can be exhibited as satisfying (I),(M),(S) with a valid soundness argument; the class is too coarse to bridge to the global strategic obstruction at n=12. **Claim type: deduction** from literature/experimental facts in docs; **not** a machine-checked metatheorem and **not** a proof that all of `C_polycd` is impossible.

## 4. Small-n evidence / counterstrategy notes

- **Tight controls (literature):** `S(5)=7=C(5)`, `S(10)=22=C(10)`, `S(11)=26=C(11)`. Any `Φ` claiming a deficit at budget `C(n)` for these roots is unsound. This constrains threshold design for (I)/(S).
- **Local-global separation (literature/experiment, `docs/research-n12-nontightness.md`):** local info-bound failures appear at `n=5` (`e=8,m=4`) while global `S(5)` is tight; non-monotonicity at `n=6` (`e=13` harder than `e=14`). Therefore potentials mimicking local slack/shape without global strategic content are unreliable.
- **n=12 numeric slack (experiment, arithmetic):** `2^29/12! ≈ 1.1208` > 1, so leaf count alone does not certify (S); a successful Φ must encode a strictly stronger-than-counting maintained obstruction — precisely what no known compact invariant provides.
- **Sorter counterstrategy schema against proxy/balance Φ (deduction):** for Φ whose maintenance depends on adversary exploiting an "imbalanced" poly-time feature (Φ_D-like), sorter strategy "query a pair minimizing `max_a gain(P,q,a)` over allowed Φ-progress" attacks (M) directly. Effectiveness is instance-dependent but constitutes the required falsification attempt: absent a lemma guaranteeing no such balancing query exists on all reachable states, (M) is unproved.

## 5. Obstacles

1. **Expressiveness gap:** excluded `e(P)` carries split information central to `F(P)`; admitted graph/chain summaries are poly-time but (by current evidence) too coarse to capture the strategic n=12 obstruction.
2. **Soundness of (S):** certifying ">=2 unresolved outcomes at depth 29" for the *actual* n=12 game requires linking Φ to all linear extensions consistent with transcripts — exactly the global property known only via exhaustive search.
3. **Uniform maintenance (M):** adversary reply must exist for *every* sorter comparison; poly-time local proxies can be balanced by sorter moves unless a strong structural theorem holds.
4. **Tight/non-tight discrimination:** Φ must be safe-infeasible at `(A_12,29)` but unsafe/non-certifying at `(A_11,26)`, `(A_10,22)`, etc., under a uniform principle, which no chain/profile scalar in `C_invstat` provides.

## 6. Next decisive question

**Decisive question.** Is there any `Φ∈C_polycd \ C_invstat` — e.g. a potential computed from the *full* comparability graph via a poly-time SDP/flow/spectral or iterative refinement procedure, not reducible to the tuple `(n,w,h,m,π_\downarrow)` — for which one can prove a *reply lemma* (M) and a *soundness lemma* (S) specialized to `n=12, d=29` (a single-instance potential certificate)?

- **Positive resolution (would advance front):** exhibit explicit `Φ`, algorithm, and a checkable proof/certificate that on the congruence-quotiented (or symmetry-reduced) game tree for `n=12,h=29` every sorter move admits a Φ-safe reply and every leaf at depth 29 has Φ-safe => non-total. This is finite but must avoid extension counting and be verifiable.
- **Negative/falsifier resolution:** produce, for a precisely defined broader subclass (e.g. all Φ depending on comparability graph up to poly-time computable graph parameters of bounded description, or all Φ with convex/linear maintenance), either a sorter strategy on the n=12 search space breaking (M), or a proof that (I)+(M) implies ¬(S) (potential cannot remain below threshold while still certifying >=2 outcomes at depth 29). This would sharpen the present `C_invstat` barrier into a publishable no-go.

**Priority rationale (deduction):** given `C_invstat` insufficiency, only instance-sensitive or non-scalar graph-computed Φ with a finite n=12 verification path can plausibly satisfy (a)-(c); determining existence there is the concrete next falsifiable step.
