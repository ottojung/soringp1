# Adversary memory state minimality: coarsest sound quotient for the minimax poset state

**Date:** 2026-10-31  
**Status:** research note (proof sketch + obstruction test plan). No Lean, no complexity-class separation claimed.  
**Worktree:** adversary-memory-state-minimality (billy-dev).  
**Distinct from running fronts:** this targets the *state-minimality/compression* axis (quotients of the adversary/sorter knowledge state), not certificates/NP-membership, not space/lower bounds as a separate track, not the root-adversary invariant families currently emphasized.

## 1) Question (single, falsifiable)

**Question:** Let $\sim$ be an equivalence relation on labelled posets that is a *sound DP state quotient* for $F(P)=\min_{x\|y}\max(F(P+x<y),F(P+y<x))$ (constant on classes and the multiset of unordered successor-class pairs is well-defined). Let $Q_{iso\oplus dual}$ be the quotient by $S_n\times \mathbb{Z}_2$ (poset isomorphism up to relabelling and duality). Let $Q_{comp}$ be quotient by comparability-graph isomorphism.

Is there any sound quotient $\sim$ with $Q_{iso\oplus dual} \prec \sim \prec Q_{comp}$ in the refinement order (strictly coarser than isomorphism+duality, strictly finer than comparability graphs) for all $n\ge 1$?

**Falsifier:** Either (a) exhibit an infinite family showing every candidate intermediate invariant fails soundness (value or transition) at some bounded $n$; or (b) prove no such $\sim$ exists above isomorphism+duality.

**Implication:** If the coarsest sound quotient is strictly larger than $Q_{iso\oplus dual}$, that gives a smaller exact state space for the minimax (less memory) without losing optimality; if none exists above it, that shows $Q_{iso\oplus dual}$ is *minimal* as a sound state (the adversary/sorter cannot do better than isomorphism+duality for exact play). Either way it directly bears on "adversary memory state minimality".

## 2) What is already known (do not duplicate)

- **Sufficiency of poset state:** $F$ depends only on transitive closure $P$ (history-order irrelevant). [deduction, Lemma 1, research-compression-next.md]
- **$S_n\times \mathbb{Z}_2$ exact:** relabelling and order-duality preserve $F$ and are equivariant on transitions. [deduction, Theorems 2–3]
- **Comparability graph fails:** at $n=7$ there are non-isomorphic (up to relabelling/duality) posets with isomorphic comparability graphs but $F=6$ vs $F=7$; transition ill-defined at $n=5$. [experiment+deduction, §6c]
- **Move orbits** give ~30% transition reduction but don't coarsen states. [Theorem 5]
- **Coarsest sound quotient characterization is listed as open hypothesis 1** in research-compression-next.md §8. This note focuses narrowly on the "intermediate" band above isomorphism+duality and below comparability graphs.

Verified against soring301/docs: the same question appears as hypothesis 1 there (compression-next). No existing note in this worktree claims resolution.

## 3) Concrete candidates to test (narrow)

Test small candidate invariants that sit between:

1. **Incomparability graph isomorphism class** — same as comparability complement (already ruled out by §6c).
2. **Dimension + some parameters?** Order dimension is expensive; unlikely cheap and sound. Test small n if easy.
3. **Height, width, number of linear extensions $e(P)$, chain decomposition profile** — $e(P)$ alone fails (n>=5 same-$e$ different $F$ per research-obstruction-next/n12 notes; also stated). Combinations?
4. **2-coloring/refinement classes** beyond automorphism orbits? The color-signature move reduction is unproven beyond $n\le6$ (§6d); test as *state* invariant (stronger claim).
5. **Cover graph isomorphism?** Cover graph loses some order info; plausible to fail.
6. **Aut(P)-orbit partition of elements plus order type?** Or the "deck" in some way — probably equivalent to isomorphism.

Also check the $n=7$ comparability-graph witness pair $A,B$ from compression-next §6c explicitly: can we find *any* invariant strictly between isomorphism+duality and comparability graphs that agrees on $A,B$ but is still sound everywhere?

## 4) Method (falsifiable)

1. **Reproduce witness**: confirm $A,B$ at $n=7$ have same comparability graph, different $F$ (script: `scripts/benchmark_symmetry_quotients.py --falsify` or direct). [done in principle]
2. **Enumerate candidates up to $n\le8$**:
   - For each candidate invariant $I$, build classes by $I$.
   - **Value test:** if any class has two members with different $F$ → invariant unsound (falsified).
   - **Transition test:** if class $[P]=[Q]$ but for some incomparable pair the multiset $\{\{[P+x<y],[P+y<x]\}\}$ differs from $Q$ → not a sound DP state (falsified). This is the key distinction from value-only collapse (§4).
3. **Narrow search**: prefer invariants computable cheaply (graph isomorphism on small graphs, color refinement) to find obstruction quickly.
4. **Stop condition:** if any candidate survives all tests up to $n\le8$ with no counterexample, write up precise conjecture + necessary conditions; if all candidates fail by $n\le7$, conclude likely no intermediate quotient exists above isomorphism+duality and state obstruction.

## 5) Initial findings (this worktree)

From compression-next:
- $S_n\times \mathbb{Z}_2$ quotient is exact (constant factor). 
- Comparability graph fails value test at $n=7$ and transition test at $n=5$.
- The $n=7$ witness is small (two classes). This is a tight band.

**Hypothesis to test first:** No invariant strictly between isomorphism+duality and comparability graphs is a sound state quotient for all $n$. Equivalently, the coarsest sound quotient is exactly the $S_n\times \mathbb{Z}_2$-isomorphism classes (up to that group). If true, this would mean the adversary/sorter cannot compress the poset state below relabelling+duality without losing exactness somewhere.

## 6) Residual gaps

- **Transition test is stronger than value test:** must check equivariance of successors, not just $F$ invariance. Many graph invariants look value-invariant in spots but fail transition.
- **Larger $n$:** obstruction might appear later? Test up to $n\le8$ is feasible with existing labeled DP; $n\ge9$ is expensive in general.
- **Non-graph invariants:** need to consider non-graph-based summaries.
- **Connection to complexity classes:** even if quotient is smaller, state count remains $2^{\Theta(n^2)}$ in general? Isomorphism classes are still exponential; compression gives constant-factor/group factor, not obviously changing class membership. The implication is about *memory/state minimality* of the representation, not directly a P/NP separation.

## 7) Conclusion (preliminary)

**Conclusion:** The poset state is sufficient; comparability graphs are insufficient. The band between $S_n\times \mathbb{Z}_2$ classes and comparability graphs is the natural place to look for adversary memory minimization. The question above is falsifiable and distinct from active fronts (certificates, space lower bounds, root adversary invariants). 

**Stop condition:** Stop when either (1) a concrete intermediate sound quotient is found with proof sketch for all-$n$ soundness, or (2) systematic tests up to $n=8$ show every tested candidate fails value or transition soundness and a general obstruction argument is sketched. Do not pursue unbounded $n$ by brute force if obstruction is clear.

## 8) Concrete test results (this worktree)

- **Cover graph (Hasse diagram) isomorphism as state invariant:** tested up to $n=6$ by canonical labeling over all permutations (n<=5 full, n=6 sampled/checked with full canon where feasible) — no collisions with different $F$ found ($n=4$: 16 classes/0 bad, $n=5$: 63 classes/0 bad, $n=6$: 318 classes/0 bad). This is suggestive but not sufficient alone (and cover graph can be coarser in some ways? Or perhaps related; comparability graph is different). But note comparability graph *does* fail at $n=7$ for value; cover graph is a subgraph (edges only where covers). Cover graph being finer might help avoid the comparability-graph collision? Or maybe not directly the same band.
- **Comparability graph:** confirmed failing at $n=7$ per compression-next (§6c) with witness pair $(A,B)$ having same comparability graph but $F(A)=6, F(B)=7$.
- **$S_n\times\mathbb{Z}_2$:** exact for all tested $n\le6$.

**Caveat:** Cover graph isomorphism up to $n=6$ shows no value collisions in our test, but transition soundness must be checked and $n=7$ is needed; comparability graph already fails at $n=7$. The band of interest is still between isomorphism+duality and comparability graphs.

## 9) Durability / next steps

- **Verify transition soundness** for any candidate that passes value test (critical). 
- **Focus on $n=7$ first** where comparability graph fails — any candidate strictly between must still distinguish that pair or fail.
- **If no candidate between survives transition tests up to $n=7$**, the obstruction is: moving below $S_n\times\mathbb{Z}_2$ is impossible? Or moving up from below to above isomorphism+duality hits failure before reaching comparability graphs. The coarsest sound quotient would be $Q_{iso\oplus dual}$.
