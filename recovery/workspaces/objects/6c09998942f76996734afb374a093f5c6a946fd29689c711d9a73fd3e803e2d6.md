# Space–recompute audit for exact unary evaluation of `S(n) <= k`

**Status:** research note (audit). Labels: `[definition]`, `[literature]`,
`[deduction]`, `[open]`. No Lean, no complexity-class separation, no lower
bound, and no optimality claim is made.

**Question audited.** Can exact evaluation of the unary threshold language
`SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }` be achieved in `o(N log N)` work
space, where `N = n + k + 1` is the actual unary input length, by
recomputation, implicit state, or catalytic-style techniques in a standard
uniform deterministic Turing-machine model, while preserving correctness and an
explicit time bound, thereby improving on the known `O(N log(N+2))`-bit work
space of the budgeted DFS?

**Outcome: (B) precise obstruction, no improved algorithm found.** The known
`O(N log(N+2))` work-space / `2^{O(N log(N+2))}` time bound for
`SORT-BOUND-U` (budgeted minimax DFS, `docs/research-budgeted-dfs.md` §5.2–5.3)
is not improved here. The obstruction is tied to the adaptive minimax
game/tree evaluation: exact DFS evaluation requires resumable access to a
depth-`k` comparison transcript over a history-dependent move set, and the
natural transcript/cursor state has `Θ(N log N)` bits in the worst case.
Standard recomputation and catalytic-space techniques do not remove this
bottleneck for this on-the-fly adaptive game tree; a genuine `o(N log N)`
algorithm would need a new representation of resumable adaptive game-tree
evaluation, which is left `[open]`.

---

## 1. Fixed model and baseline `[definition]`+`[literature]`

Input is `w = 1^n # 1^k`, `N = |w| = n + k + 1`. The machine is a standard
uniform deterministic multi-tape Turing machine with a read-only input tape;
**work space** counts only work-tape cells/bits, not the input. Correctness
means the machine accepts iff `S(n) <= k` in the exact adaptive comparison-sort
model of `docs/problem.md` (minimax height of a deterministic decision tree over
all permutations of `n` distinct labelled keys).

Baseline (`docs/research-budgeted-dfs.md` Proposition, §5.3): after the
`k >= U(n)` trivial-accept precheck, run the exact recurrence
`CanSort(empty_n, k)` by depth-first backtracking. It has depth `d = k`, at
most `n(n-1)` recursive candidates per non-total state, `poly(N)` time per
call, and (transcript-only implementation, §5.2) work space
`O((d+n) log(n+2)) = O((k+n) log(n+2)) <= O(N log(N+2))` bits. Total time is
`2^{O(k log(n+2))} poly(N) <= 2^{O(N log(N+2))}`. This is uniform,
deterministic, read-only on the input, and exact.

The target under audit is work space `o(N log N)` with the same exact
semantics and an explicit time bound.

---

## 2. What the baseline stores `[deduction]`

The minimax decision is
```
V(P,0) = IsTotal(P),
V(P,d) = OR_{(x,y) incomparable in P} [ V(P+x<y, d-1) AND V(P+y<x, d-1) ],
S(n) <= k  iff  V(empty_n, k).
```
`CanSort` evaluates this by DFS. Two kinds of information are needed at a node
on the current path:

1. **The current game state `P`.** In the transcript-only form, `P = P(σ)` is
   the transitive closure of the ordered comparison transcript
   `σ = ((a_1,b_1),..., (a_t,b_t))`, `a_s < b_s`, `t <= k`. Comparability is
   recomputed by reachability in the digraph `([n], σ)` using
   `O(n log n)` bits of temporary workspace (§5.2 item 2), which can be reused.

2. **The resumable search cursor.** For backtracking, after returning from a
   child the evaluator must know which candidate pair was tried at this depth
   and which adversary branch (first/second) remains, so it can continue the
   `OR` over incomparable pairs / the `AND` over the two answers without
   re-exploring completed subtrees in the wrong order or losing correctness.
   The cursor is `O(log(n^2)) = O(log n)` bits per frame.

The stack therefore holds `t` transcript edges plus `t` cursors, total
`O(t log n) <= O(k log n) <= O(N log N)` bits, plus one reusable reachability
workspace `O(n log n)`. This gives the `O((k+n)log n)` accounting. The
`k log n` term is the **path state**: which comparisons were made, in order,
along the current adaptive line of play.

---

## 3. Obstruction: history-dependent adaptive move sets `[deduction]`

The bottleneck is not merely tree depth; it is the interaction of depth with a
**history-dependent move set**.

- **Adaptive legality.** A candidate move at depth `i` is a pair
  `(x_i,y_i)` that is *incomparable in `P(σ_{i-1})`*. The set of legal moves
  is a function of the entire prefix transcript `σ_{i-1}`. Therefore the
  `OR`-branching is not a fixed-width formula over a static input: it is a game
  tree whose available edges are discovered from the current poset.

- **Adversarial answers.** For each chosen pair, both orientations
  `x_i<y_i` and `y_i<x_i` must be winning for the sorter (the `AND`). The
  answer chosen changes `P` and hence changes all future legal moves. The
  evaluator cannot treat the two adversary branches as independent of the
  stored path except through the induced poset.

- **Resumable enumeration.** The DFS explores candidate pairs in a deterministic
  order. To resume at depth `i` after the first adversary branch (or after a
  failed candidate pair) returns, the evaluator must restore or reconstruct
  `P(σ_{i-1})` and the cursor position. Reconstructing `P` from `σ_{i-1}` is
  cheap given `σ_{i-1}` (reachability, polynomial time, reusable space), but it
  presupposes access to `σ_{i-1}`.

Consequently, any exact backtracking evaluator that maintains the standard
resumable DFS invariant has, at peak, a representation of the current path
prefix sufficient to recover both the current poset and the next untried
move/branch at every depth. In the transcript representation this is
`Θ(t log n)` bits at depth `t`; in the worst case `t = k = Θ(N)` and
`n = Θ(N)`, giving `Θ(N log N)` bits.

This is a **structural bottleneck of the representation/evaluation strategy**,
not a proof that no other representation exists. A sub-`N log N` algorithm
would have to avoid storing or implicitly reconstructing an equivalent resumable
path description.

## 4. Why recomputation does not remove the bottleneck `[deduction]`

Recomputation trades time for space by regenerating intermediate values instead
of storing them. Here the relevant intermediate value is the current transcript
prefix / cursor stack.

- **Recomputing the poset from the transcript is already used.** The baseline
  does *not* store `n x n` closure matrices; it stores the transcript and
  recomputes reachability. This is the standard recomputation that yields
  `O(N log N)` instead of `O(N^3 log N)` (§5.1–5.2 of the budgeted DFS note).
  The remaining stored object is the transcript itself.

- **Recomputing the transcript from `(n,k)` alone is insufficient for
  backtracking.** The transcript is the history of the particular DFS path
  currently being explored. After a subtree returns, the evaluator must resume
  at a specific ancestor with a specific cursor. Regenerating the whole search
  from the root without remembering the resume point would repeat completed
  work; remembering only a compressed checkpoint still requires enough
  information to identify that checkpoint among the adaptive game-tree paths.
  For a history-dependent game with `Θ(n^2)` candidate moves per level and
  depth `Θ(N)`, the deterministic path description has `Θ(N log N)` information
  in the general case.

- **Implicit-state enumeration of posets does not give a resumable game-tree
  DFS.** One may enumerate states implicitly, but the minimax recurrence is
  evaluated over *comparison paths* (a strategy is a decision tree). The
  budgeted DFS is already the space-efficient alternative to memoizing all
  `2^{Θ(n^2)}` posets; it stores a path rather than the state table. Further
  compression must compress the path, not replace path DFS by state memoization.

Thus recomputation, as used so far, explains the `O(N log N)` bound; it does
not by itself produce `o(N log N)`.

## 5. Why catalytic/standard implicit techniques do not apply directly `[deduction]`+`[literature]`

- **Catalytic space** (Buhrman et al.) augments work space with a much larger
  catalytic tape whose arbitrary initial contents must be restored. A catalytic
  simulation can reduce *clean* work space for some computations, but applying it
  here would require representing the adaptive minimax DFS (including
  backtrackable path/cursor state and reachability workspace) so that all
  temporary modifications to the catalytic tape are reversible across every
  branch return. The game tree is discovered on-the-fly, has AND/OR alternation
  tied to the minimax value, and has history-dependent branching; no known
  catalytic simulation gives `o(N log N)` work space for this exact task. This
  note does **not** prove catalytic methods cannot work; it records the absence
  of a concrete simulation.

- **Tree-evaluation / formula-evaluation space improvements** (e.g. Cook–Mertz
  for bounded-degree tree evaluation, and related composition results) target
  evaluating a *presented* bounded-degree tree/formula or use structural
  properties of that presentation. The sorting minimax object is not a presented
  bounded-degree formula on the input tape: it is an implicit adaptive game
  tree whose legal moves depend on the current poset. Reducing it to a small
  presented tree would amount to solving the compression problem.

- **Reachability-style space results** (Savitch, Reingold for undirected
  reachability, etc.) concern graph reachability with particular access models.
  They do not directly supply a resumable DFS stack for an implicit,
  history-dependent AND/OR game with value-preserving backtracking.

The common gap is: known low-space techniques either assume a fixed/presented
structure, a reversible/catalytic-safe update discipline not yet exhibited for
this game, or a non-resumable reachability question rather than exact minimax
path evaluation.

## 6. Candidate routes and their status `[deduction]`+`[open]`

| Route | Idea | Status against `o(N log N)` |
|---|---|---|
| Transcript + reachability recomputation | Store only comparisons, recompute closure | Baseline; gives `O(N log N)` `[deduction]` |
| Matrix-per-frame | Store closure matrices | Worse: `O(N^3 log N)` `[deduction]` |
| Checkpoint/restart recomputation | Store sparse checkpoints, replay | Still needs resumable checkpoint identity/cursor; no `o(N log N)` scheme exhibited `[open]` |
| Poset canonicalization without path | Replace path by canonical state | Canonical state is a poset/state description; exact minimax still needs backtrackable exploration, and canonicalization cost/state identity is nontrivial `[open]` |
| Catalytic simulation of DFS | Use full catalytic tape, restore on return | No concrete reversible simulation for this adaptive AND/OR game found `[open]` |
| Tree-evaluation composition | Apply Cook–Mertz-style evaluation | Requires a presented/fixed bounded-degree tree or an equivalent compressed presentation not known `[open]` |
| Succinct encoding of resumable transcripts | Compress `σ` below `k log n` | Would need a proof that all resumable states reached by exact DFS lie in a compressible family; no such bound known `[open]` |

No row yields a proved `o(N log N)` uniform deterministic algorithm with
explicit correctness and time.

## 7. Precise obstruction statement `[deduction]`

**Obstruction (resumable adaptive-transcript bottleneck).** For exact
evaluation of `V(empty_n,k)` by deterministic depth-first minimax search over
the comparison game:

1. A legal sorter move at depth `i` is an incomparable pair of `P(σ_{i-1})`, so
   move legality depends on the full prefix transcript.
2. Correct backtracking requires restoring, after every child return, the pair
   of current poset and untried move/branch at that depth (a resumable cursor).
3. In the standard transcript representation this resumable path state has size
   `O(t log n)` bits at depth `t`, and `Θ(k log n)` in the worst case.
4. With the unary decision input `1^n # 1^k`, `N=n+k+1`, the relevant worst
   case gives `Θ(N log N)` bits, matching the known upper bound up to the
   suppressed `log(N+2)` normalization used in the baseline note.

Therefore improving below `O(N log N)` work space by recomputation/implicit
state/catalytic-style techniques requires a **new exact resumable
representation or evaluation protocol** for the history-dependent minimax game
tree: one that either compresses resumable adaptive transcripts below
information-theoretic path size on all relevant instances, or evaluates the
AND/OR minimax value without maintaining equivalent resumable path/cursor state.
No such representation/protocol is established here.

This is **not** an unconditional space lower bound for `SORT-BOUND-U`: the
language could in principle be decided by an algorithm that is not a resumable
DFS over the natural comparison transcript, or by an unexhibited catalytic/low-
space simulation. The obstruction is concrete and tied to the minimax
game/tree evaluation strategy that yields the current best explicit bound.

---

## 8. Falsification / sanity checks `[deduction]`

- The obstruction does not apply to storing full closure matrices: that route is
  already dominated (more space). Avoiding matrix storage is necessary but not
  sufficient for `o(N log N)`.
- It does not claim `Ω(N log N)` is necessary for the language, only that the
  transcript/cursor path state of the direct minimax DFS is `Θ(N log N)` in the
  worst case.
- It is compatible with the known upper bounds: `SORT-BOUND-U` remains in
  `DSPACE(O(N log(N+2)))` and `PSPACE`; no class separation follows.
- It respects model fidelity: unary encoding, actual input length `N`, uniform
  deterministic TM, work space excludes read-only input.

---

## 9. Conclusion `[deduction]`+`[open]`

**(B)** No `o(N log N)` work-space algorithm for exact unary evaluation of
`S(n) <= k` was found under recomputation, implicit-state, or catalytic-style
techniques in the standard uniform TM model. The concrete obstruction is the
resumable adaptive-transcript bottleneck of exact minimax DFS: history-
dependent move legality and AND/OR backtracking require resumable path/cursor
state of worst-case size `Θ(N log N)` under the standard transcript
representation, and no known technique exhibited here compresses or eliminates
this state while preserving exactness and an explicit time bound.

**Next decisive obstacle `[open]`.** Either (i) exhibit an exact resumable
representation/simulation of the adaptive comparison game whose work space is
`o(N log N)` (with correctness proof and explicit time), e.g. by a reversible
catalytic simulation or a succinct path scheme valid for all minimax-relevant
transcripts; or (ii) prove a model-appropriate lower bound showing that exact
uniform evaluation of this history-dependent minimax game requires
`Ω(N log N)` work space under stated access/recomputation restrictions. Route
(ii) would be strong and must be distinguished carefully from an unconditional
language lower bound.
