## 1. Fixed objects and local move semantics

### 1.1 Input, signature, cells

`[definition]` (SYM §1.1). Input `w = 1^n # 1^k`, `N=|w|=n+k+1`,
`A(w)=(W,<,One,Hash)`, `W={1,...,N}`.  FO-definable: `Succ,Min,Max,HashPos,
WellFormed_w,Malformed,Key,Ctr,Zero,MaxK,SuccCtr,HasBudget,KeyNe,Lex2,SuccLex2,
IsLastLex2,MinKey`.

`[definition]` (SYM §1.2). `r:=4`, `Cell:=W^r`, `|Cell|=N^r`.  `ZeroCell`,
`SuccCell`, `<_lex` are FO/DTM-definable from `<`.  `CurBase` is a unique
`Cell`-valued allocator register; `FreshChild(d̄):=CurBase(d̄)`; a push sets
`CurBase'(b̄')` to the `SuccCell` successor of `CurBase(b̄)`.

### 1.2 Configuration family and encoded DTM state

`[definition]` (SYM §1.3, with `[SYM-TOP]` understood).  The fixed
component-relation family `Rbar` is
```text
Top(c̄), CurBase(b̄), EmptyStack, HaltAcc, HaltRej,
M_Eval(c̄), M_BackE(c̄), M_BackA0(c̄), M_BackA1(c̄),
RetNone(c̄), RetAcc(c̄), RetRej(c̄),
CtrlSort(c̄), CtrlAdv(c̄), CtrlAcc(c̄), CtrlRej(c̄),
UsedF(c̄,t), HasSel(c̄), SelA(c̄,a), SelB(c̄,b),
HasCur(c̄), CurA(c̄,a), CurB(c̄,b),
PosF(c̄,u,v), Parent(c̄,p̄), FrameLive(c̄).
```
All arities and the count `m` are fixed, independent of `n,k`.

`[definition]` A **DTM-encoded configuration** `E(Rbar)` is a finite work-tape
encoding of the current interpretation of these components over `A(w)`:
```text
E(Rbar) := [ globals: Top,CurBase,EmptyStack,HaltAcc,HaltRej ]
           ⊕ [ live-frame table: for FrameLive(c̄), fields of c̄ ]
```
where frame `c̄` stores mode, return marker, control, `UsedF` (one `Ctr`
value), `HasSel/SelA/SelB`, `HasCur/CurA/CurB`, `Parent` link (or root mark),
and `PosF(c̄,·,·)` as an `n×n` bit table over `Key×Key` in the fixed order of
`A(w)`.  This stores **current-frame** `PosF` only, not names for all
`A001035(n)=2^{Θ(n^2)}` labelled posets.  `[falsification]` No `PACK-REPR` /
no global valid-`Pos` tuple-coding is introduced.

The input tape is read-only `w`.  A fixed finite control state of `M_D^alt`
records the macro-dispatch phase (halt check, classify top, return handling,
existential search, universal A0/A1, accept/reject write), and a fixed finite
set of tape-head/offset registers (implemented by bounded counters/marks on the
polynomial work tape under (P1)) addresses the current `Top`, `Parent`,
`CurBase`, and field offsets.

### 1.3 Local semantic formulas (fixed)

`[definition]` (SYM §2).  For a live frame `c̄`:
```text
P_c(u,v)      := PosF(c̄,u,v).
Incomp_c(x,y) := KeyNe(x,y) ∧ ¬P_c(x,y) ∧ ¬P_c(y,x).
Total_c       := ∀x∀y(KeyNe(x,y) -> P_c(x,y) ∨ P_c(y,x)).
Budget_c      := ∃t(UsedF(c̄,t) ∧ HasBudget(t)).
CfgAcc_c      := CtrlAcc(c̄) ∨ Total_c.
CfgRej_c      := CtrlRej(c̄).

StepPosBit_c(x,y;u,v) := P_c(u,v) ∨ ((u=x ∨ P_c(u,x)) ∧ (v=y ∨ P_c(y,v))).

PostBudgetFrom(Pnew,t';Acc,Sort,Rej) :=
   (TotalOf(Pnew) ∧ Acc∧¬Sort∧¬Rej)
 ∨ (¬TotalOf(Pnew) ∧ HasBudget(t') ∧ Sort∧¬Acc∧¬Rej)
 ∨ (¬TotalOf(Pnew) ∧ ¬HasBudget(t') ∧ Rej∧¬Acc∧¬Sort),
where TotalOf(Pnew):=∀x∀y(KeyNe(x,y)->Pnew(x,y)∨Pnew(y,x)).
```
Local move preconditions:
```text
YieldE_c(a,b)  := CtrlSort(c̄) ∧ ¬Total_c ∧ Budget_c ∧ Incomp_c(a,b).
YieldA_c(a,b)  := CtrlAdv(c̄)  ∧ HasSel(c̄) ∧ SelA(c̄,a)∧SelB(c̄,b) ∧ Incomp_c(a,b).
RejectEval_c   := CfgRej_c ∨ (CtrlSort(c̄)∧¬Total_c∧¬Budget_c)
                ∨ (CtrlSort(c̄)∧¬Total_c∧Budget_c∧NoNextIncomp_c).
```

`[literature,deduction]` **Incremental TC.** If `P_c` is the transitive closure
of a strict partial order and `Incomp_c(x,y)`, then `StepPosBit_c(x,y;·,·)` is
the closure of `P_c ∪ {(x,y)}` and a strict partial order (SYM §2; standard).

### 1.4 `G(n,k)` local move semantics (fixed)

`[definition]` (project model: `docs/problem.md`, `research-certificates-barriers.md`
game `G(n,k)`, CKS-AV; fixed here).  A `G(n,k)` state is
`s=(P,used,ctrl,sel)` with strict partial-order closure `P` on `n` keys,
`used∈{0,...,k}` (`Ctr`), `ctrl∈{Sort,Adv,Acc,Rej}`, and optional selected
incomparable pair `sel`.
```text
Init_{G(n,k)}: P=∅, used=0, ctrl=Acc if n<=1 else Sort, sel=⊥.
Sort terminal:    Total(P) -> Acc.
Sort reject:      ¬Total(P) ∧ used=k -> Rej.
Sort move:        ¬Total(P) ∧ used<k, choose incomparable (a,b): sel=(a,b), ctrl=Adv.
Adv moves:        from sel=(a,b), adversary gives (a,b) or (b,a);
                  P' = TC(P ∪ {answer}), used' = used+1,
                  ctrl' = Acc if Total(P') else Sort if used'<k else Rej.
```
Sorter wins `G(n,k)` iff some strategy forces `Acc` against all adversary
answers.  Alternating DFS evaluation of `G(n,k)` is the deterministic DFS
realization with existential `Sort` nodes, universal `Adv` outcomes evaluated in
fixed order `(a,b)` then `(b,a)`, lex-next search over incomparables for `Sort`
backtracking, and the terminals above.

## 2. `Init` realization

### 2.1 Symbol-level initial formula

`[definition]` (SYM §5).  `Init_{M_D}^{sym}(Rbar)` is
```text
WellFormed_w ∧ ¬HaltAcc∧¬HaltRej∧¬EmptyStack
∧ ∃c̄(Top(c̄)∧ZeroCell(c̄)∧FrameLive(c̄)∧∀d̄(FrameLive(d̄)->d̄=c̄)
      ∧ M_Eval(c̄)∧RetNone(c̄)
      ∧ ∃h(Zero(h)∧UsedF(c̄,h))∧ unique UsedF
      ∧ ( (¬∃x∃y KeyNe(x,y) -> CtrlAcc(c̄))
        ∨ ( ∃x∃y KeyNe(x,y) -> CtrlSort(c̄)) )
      ∧ ¬HasSel(c̄)∧HasCur(c̄)∧CurA/CurB=MinKey
      ∧ ∀u∀v ¬PosF(c̄,u,v) ∧ ¬∃p̄ Parent(c̄,p̄))
∧ ∃b̄(CurBase(b̄)∧SuccCell(ZeroCell,b̄)∧ unique CurBase).
```

### 2.2 DTM initialization

`[definition]` `δ_{M_D^alt}^{sch}` has a unique initial control phase `q_init`
from the standard DTM start configuration on input `w`:
```text
q_init:
  if Malformed(A(w)) then write HaltRej, enter q_halt_rej;
  else create root live frame at ZeroCell;
       set Top=ZeroCell, CurBase=SuccCell(ZeroCell), EmptyStack=false;
       clear HaltAcc/HaltRej;
       root.M := M_Eval, root.Ret := RetNone;
       root.Used := Zero(Ctr);
       root.PosF := empty over Key×Key;
       root.HasSel := false; root.HasCur := true; root.Cur := (MinKey,MinKey);
       root.Parent := none;
       if no KeyNe pair exists then root.Ctrl := CtrlAcc else root.Ctrl := CtrlSort;
       enter q_loop.
```
All reads/writes are over fixed FO-definable predicates/fields in `A(w)` and
the frame encoding (P1).

`[deduction]` For well-formed `w`, the encoding produced by `q_init` satisfies
`Init_{M_D}^{sym}(Rbar)` and is unique.

## 3. Explicit fixed deterministic `δ_{M_D^alt}` transition schema

### 3.1 Deterministic dispatch principle

`[definition]` `δ_{M_D^alt}^{sch}` is a fixed finite-state DTM control with a
polynomial work tape encoding `E(Rbar)`.  In control phase `q_loop` it
performs:
1. **Halt test:** if `HaltAcc` or `HaltRej`, stay in absorbing halt.
2. **Top read:** read unique `Top(c̄)`, `FrameLive(c̄)`, `Root(c̄)`,
   `M_Eval/M_BackE/M_BackA0/M_BackA1`, and `Ctrl/Ret/UsedF/HasSel/SelA,B/
   HasCur/CurA,B/PosF` fields of `c̄`.
3. **Case test:** evaluate the preconditions of the mutually exclusive
   `Δ_{M_D}^{sym,top}` disjuncts in a fixed deterministic priority equal to the
   mathematical partition below.
4. **Macro-update:** execute the corresponding finite field update on
   `E(Rbar)` (copying unchanged lower-stack frame blocks, creating one fresh
   child block at `CurBase` on pushes, or popping the top block on returns).
5. **Re-enter `q_loop`** (or a halt state).

(P1) licenses compilation of each FO-definable test/update in steps 2--4 into
deterministic DTM moves over the fixed encoding; the schema below fixes *which*
test/update is performed, so no semantic choice is left open.

### 3.2 Schema cases (equivalent to `Δ_{M_D}^{sym,top}`)

Let `c̄` be the current `Top`.  `Δ_{M_D}^{sym,top}` is the SYM case split with
`[SYM-TOP]`:
```text
Δ_halt, Δ_root_acc, Δ_root_rej,
Δ_eval_acc_ret, Δ_eval_rej_ret, Δ_sort_pick_push,
Δ_backE_acc_root, Δ_backE_acc_ret, Δ_backE_rej_next, Δ_backE_rej_exhaust_root, Δ_backE_rej_exhaust_ret,
Δ_adv_push_A0,
Δ_backA0_rej_root, Δ_backA0_rej_ret, Δ_backA0_acc_push_A1,
Δ_backA1_acc_root, Δ_backA1_acc_ret, Δ_backA1_rej_root, Δ_backA1_rej_ret.
```

The deterministic schema `δ_{M_D^alt}^{sch}(E(Rbar)) = E(Rbar')` is:

| DTM macro-case | Precondition (FO test on encoded top `c̄`) | Deterministic update |
|---|---|---|
| `D_halt` | `HaltAcc∨HaltRej` | identity; absorbing halt state. |
| `D_root_acc` | `M_Eval(c̄)∧Root(c̄)∧CfgAcc_c` | `HaltAcc:=1, HaltRej:=0, EmptyStack:=1`, clear live frames. |

### 3.3 Determinism of the schema

`[deduction]` The precondition partition is exactly the `Δ_{M_D}^{sym,top}`
partition: unique `Top(c̄)` by `I_{M_D}.4`; exactly one mode by
`ExactlyOneMode`; `Root`/`¬Root`; `CfgAcc_c` vs `RejectEval_c` vs sort-pick vs
adversary-push for `M_Eval`; `RetAcc/RetRej` and `NextIncomp/NoNextIncomp` and

state, exactly one DTM macro-case applies and its update is a single-valued
function.  This is the same argument as SYM §§7.2,7.4 together with `[SYM-TOP]`.

## 4. Equivalence to `Δ_{M_D}^{sym,top}` steps

**Theorem 4.1 (schema equivalence).** `[deduction]` Let `Rbar` satisfy
`I_{M_D}(Rbar)` and let `E(Rbar)` be its DTM encoding.  Then
```text
E(Rbar) --δ_{M_D^alt}^{sch}--> E(Rbar')
  iff
Δ_{M_D}^{sym,top}(Rbar;Rbar').
```

*Proof.*  (⇒) By §3.2 every macro-case `D_*` reads exactly the precondition of
the corresponding SYM-top disjunct on `c̄=Top` and performs exactly its primed
updates: `PopTo_base/MarkRet*` for returns; `PushChildE`/`PushChildA` with
`ChildFrameBase` including `[SYM-TOP]` for pushes; `SetParentBack*` and
`SuccLex2` cursor advance; global halting/empty/no-active-frame updates for
root terminal cases; and `LowerStackPreservedExcept(c̄)` by copying unchanged
frame blocks.  Therefore the produced `Rbar'` satisfies that unique disjunct.
(⇐) Conversely, by SYM mutual exclusion and totality on relevant `I_{M_D}`
states (§7.2--7.3, preserved by `[SYM-TOP]`), exactly one
`Δ_{M_D}^{sym,top}` disjunct holds; `D_*` is selected by the same precondition
and produces the same unique primed interpretation (SYM determinism §7.4,
`[SYM-TOP]` §4.2).  The DTM macro-step compilation (P1) preserves the
mathematical read/write effect.  ∎

**Corollary 4.2 (invariant preservation).** `[deduction]` If `I_{M_D}(Rbar)` and
`E(Rbar) --δ_{M_D^alt}^{sch}--> E(Rbar')`, then `I_{M_D}(Rbar')`.

*Proof.* By Theorem 4.1 and SYM §7.5 plus `[SYM-TOP]` §4.1,4.3.  The push
`Top`-uniqueness clause is present, so `ExactlyOneTop` is preserved in push
cases; all other invariants are preserved as in SYM.  ∎

**Corollary 4.3 (no spurious transitions).** `[deduction]` Relative to the fixed
`G(n,k)` local move semantics of §1.4 and the DFS discipline, every
`δ_{M_D^alt}^{sch}` step is a legal alternating-DFS evaluator step: it selects
an incomparable pair only by `NextIncomp_c`, applies adversary outcomes only as
`StepPosBit_c(a,b)/(b,a)` with `SuccCtr`, uses `PostBudgetFrom` for terminals,
propagates/short-circuits universal returns in order A0 then A1, backtracks
existential search by advanced lex cursor, and halts only on the explicit
accept/reject conditions.

*Proof.* Theorem 4.1 and SYM §7.6 / `[SYM-TOP]` §4.5.  ∎

## 5. Halting and space bound

**Theorem 5.1 (space).** `[deduction]` For well-formed `w=1^n # 1^k`,
`N=n+k+1`, `M_D^alt` under `δ_{M_D^alt}^{sch}` uses `O(N^3)` work-tape cells
(and polynomially bounded DTM control/offset state under P1), hence space
polynomial in `N`.

*Proof.* A current frame stores: fixed mode/return/control flags (`O(1)`),
`UsedF` as one `Ctr` value (`O(log N)`), `HasSel/SelA/SelB/HasCur/CurA/CurB`
(`O(log N)`), `Parent` as one `Cell` value (`O(r log N)=O(log N)`), and
`PosF(c̄,·,·)` as `|Key|^2 = n^2 <= N^2` bits.  Thus one frame is `O(N^2)`.

The active stack depth is `<= 2k+1 <= 2N+1`: every `PushChildA` (A0 or A1)
applies `SuccCtr` to the child's `UsedF`; `UsedF` ranges over `Ctr` of size
`k+1`; a universal comparison requires A0 (and possibly A1) children whose used
counts increase; existential `PushChildE` children copy `UsedF` but lead to a
`CtrlAdv` frame whose A0/A1 children consume budget.  Consequently no
`I_{M_D}`-reachable active path contains more than `k+1` budget-consuming
universal outcomes total, and the DFS discipline keeps at most one active
root-to-top path with bounded local backtrack frames, giving `O(k)=O(N)` live
frames.

Globals (`Top,CurBase,HaltAcc,HaltRej,EmptyStack`) are `O(log N)`.  Therefore
total space is `O(N) * O(N^2) = O(N^3)`.  `[falsification]` This is a
uniform polynomial-space bound in the actual unary input length `N`; it is not
a claim about exponential-time enumeration of all posets and does not use
A001035 indexing.  ∎

**Theorem 5.2 (halting).** `[deduction]` On every well-formed input `w` and
every `I_{M_D}`-reachable configuration, `δ_{M_D^alt}^{sch}` reaches a halting
configuration (`HaltAcc` or `HaltRej`) in finitely many steps.

*Proof.* Use a lexicographic progress measure on `I_{M_D}`-reachable
non-halting configurations:
```text
μ(E(Rbar)) = (Brem,  Sphase,  Cphase) in ω × ω × ω,
```
defined as follows.

- `Brem = k - val(UsedF of active DFS budget frontier)`: a nonnegative integer
  bounded by `k`, measuring remaining budget potential.  `PushChildA` sets the
  child's `UsedF` to `SuccCtr` of the parent snapshot, so every A0/A1 push on a
  path strictly consumes one budget unit.  Budget-exhausted non-total eval states
  take `D_eval_*rej` or root reject, not pushes.

- `Sphase`: for the active sort-search frontier, a finite tuple combining
  (active stack depth profile bounded by `2k+1`) and, for the current top
  existential search frame, the lex position of `CurA,CurB` in `Key×Key`
  (`N^2` possible positions).  `D_sort_pick` and `D_backE_rej_next` advance the
  cursor by `SuccLex2` past the selected pair (or to last) before/while setting
  `M_BackE`; `D_backE_rej_exh_*` resolves when `NoNextIncomp_c`.  `HasCur` and
  cursor uniqueness are in `I_{M_D}`.

- `Cphase`: a fixed finite phase order on `(M_Eval/M_BackE/M_BackA0/M_BackA1,
  RetNone/RetAcc/RetRej, root/non-root terminal disposition)` ensuring that
  return markers are consumed, `BackA0+RetAcc` leads to A1 push or `BackA1`
  return, and eval terminal states lead to return/halt rather than
  self-loops.

Every non-halting case decreases `μ`: halt cases are excluded; eval
accept/reject pop/halt decrease stack/phase without creating unbounded work;
`D_sort_pick/D_backE_rej_next` push a child but advance the existential cursor
and/or enter a backtrack phase that must return; `D_adv_push_A0` and
`D_backA0_acc_A1` decrease `Brem` for the pushed child; backtrack return cases
pop and consume return markers; exhaustion cases halt or pop.  Since
`Key×Key`, `Ctr`, stack depth, and control/return modes are finite, `μ` is a
well-founded progress witness.  Therefore no infinite `δ_{M_D^alt}^{sch}`
computation exists from an `I_{M_D}`-reachable state.  ∎

## 6. Acceptance iff alternating DFS accepts initial `M_G/G(n,k)` state

### 6.1 Frame-state projection

`[definition]` For a live frame `c̄` with `P_c=PosF(c̄,·,·)`, `t_c=val(UsedF(c̄))`,
and `G`-relevant control, define its projected `G(n,k)` state:
```text
GState(c̄) :=
  (P_c, t_c, Acc)            if CfgAcc_c or (CtrlAcc(c̄));
  (P_c, t_c, Rej)            if CfgRej_c and not CfgAcc_c;
  (P_c, t_c, Sort, ⊥)        if CtrlSort(c̄) and not Total_c and not CfgRej_c;
  (P_c, t_c, Adv, (a,b))     if CtrlAdv(c̄) and HasSel(c̄), SelA(c̄,a),SelB(c̄,b);
  (P_c, t_c, Sort/Adv, ...)  as determined by stored control/selection for Back* parents.
```
For `Init_{M_D}^{sym}`, `GState(root)=Init_{G(n,k)}`.

`[definition]` Let `ADF_{G(n,k)}(s)` be the Boolean result of alternating DFS
evaluation of `G(n,k)` from state `s` under the fixed semantics of §1.4:
existential `Sort` choices try incomparables in lex-next DFS order and return
true if some child returns true; universal `Adv` returns true iff the A0 child
`(a,b)` and A1 child `(b,a)` both return true; terminals return `Acc=true`,
`Rej=false`.

### 6.2 Local semantic agreement

`[deduction]` (from §1.3, incremental TC, and `PushChildA/E` definitions).
- `Init`: root is antichain, `Used=Zero`, `Sort`/`Acc` by `n`.
- `YieldE_c(a,b)` means `Sort`, `¬Total_c`, `Budget_c`, `Incomp_c(a,b)` —
  exactly a legal `G(n,k)` sort move selecting incomparable `(a,b)`.
- `ChildA0` gives `P' = StepPosBit_c(a,b;·,·) = TC(P_c ∪ {(a,b)})`, `Used'=
  SuccCtr(UsedF_c)`, with `PostBudgetFrom` selecting `Acc/Sort/Rej`; `ChildA1`
  gives `TC(P_c ∪ {(b,a)})` with the same `Used'` from the same parent snapshot.
  These are exactly the two adversary outcomes of §1.4.
- `Total_c`, `CfgAcc_c`, `RejectEval_c`, and `PostBudgetFrom` agree with the
  `G(n,k)` terminals.

### 6.3 Acceptance equivalence theorem

**Theorem 6.1.** `[deduction]` For well-formed `w=1^n # 1^k`,
```text
M_D^alt accepts w
  iff
alternating DFS evaluation accepts the initial M_G/G(n,k) state.
```

*Proof.* Let `Comp(w)` be the unique halting `δ_{M_D^alt}^{sch}` computation
from `Init_{M_D}^{sym}` (Theorems 4.1, 5.2, Corollary 4.2).  Prove by
induction on the well-founded DFS return structure of `Comp(w)` (Theorem 5.2)
that for every reachable evaluation of a frame/projection `s=GState(c̄)` the
eventual return value produced at that DFS node is `ADF_{G(n,k)}(s)`.

**Terminals.** If `CfgAcc_c`/`CtrlAcc(c̄)` or `Total_c` resolves to accept,
`δ` returns/halt-accepts only in the SYM accept cases (`D_root_acc`,
`D_eval_acc_ret`, `D_backE_acc_*`, `D_backA1_acc_*` as appropriate), matching
`ADF` terminal true.  If `RejectEval_c` (`CtrlRej`, no budget on non-total sort
state, or `NoNextIncomp_c` after exhausted search) or `PostBudgetFrom` gives
reject, `δ` returns/halt-rejects in the corresponding reject cases, matching
`ADF` terminal false.  No other accept/reject is possible by Corollary 4.3.

**Existential `Sort` node.** Suppose `c̄` is evaluated with
`CtrlSort(c̄)∧¬Total_c∧Budget_c`.  `δ` uses `HasCur/CurA,CurB` and
`NextIncomp_c` to try incomparables in lex order: `D_sort_pick` or
`D_backE_rej_next` pushes `ChildE(d̄,c̄,x,y)`, making the parent `M_BackE` with
advanced cursor and the child a `CtrlAdv` node with selected `(x,y)`.  If the
child DFS returns accept, `D_backE_acc_*` propagates accept.  If it returns
reject, the parent remains `M_BackE,RetRej` and the next `D_backE_rej_next`
continues from the advanced cursor, or `D_backE_rej_exh_*` rejects when
`NoNextIncomp_c`.  Because `NextIncomp_c` enumerates exactly current
incomparables in fixed lex order and the cursor advances monotonically over
finite `Key×Key`, this is precisely `ADF` existential DFS over legal sort moves.
By induction hypothesis on child returns, the node returns true iff some legal
incomparable choice leads to an accepting adversarial evaluation.

**Universal `Adv` node.** Suppose `c̄` (or pushed child) is `CtrlAdv` with
selected incomparable `(a,b)`.  `D_adv_push_A0` pushes A0:
`P' = TC(P_c∪{(a,b)}), used'=SuccCtr(used)` (from the parent snapshot), resolved
by `PostBudgetFrom`.  On A0 reject, `D_backA0_rej_*` short-circuits reject.  On
A0 accept, `D_backA0_acc_A1` pushes A1 from the **same preserved parent snapshot**
`Sel/PosF/UsedF`: `P'' = TC(P_c∪{(b,a)}), used'=SuccCtr(used)`.  On A1 return,
`D_backA1_acc_*`/`D_backA1_rej_*` return that value.  This is exactly `ADF`
universal evaluation of outcomes `(a,b)` then `(b,a)` in fixed order.  By local
semantic agreement and induction hypothesis, the node returns true iff both
adversary outcomes return true.

**Root.** The initial frame is `Init_{G(n,k)}`.  `M_D^alt` accepts iff the
computation reaches `HaltAcc`, which occurs only by root accept or propagated
accept to root.  By the induction, that is equivalent to
`ADF_{G(n,k)}(Init_{G(n,k)})=true`.  ∎
