## 1. Falsifiable finite task

`[definition]` (model: `docs/problem.md`) `S(n)` is the minimum worst-case number of adaptive pairwise comparisons to sort `n` distinct labelled keys (no ties). A state is a transitively closed strict partial order `P`; `e(P)` is the exact number of linear extensions.

`[deduction]` `13! = 6,227,020,800`, `C(13)=ceil(log2 13!)=33`, so the global information bound gives `S(13) >= 33`. The Wells/admissibility test for target height `C=33` asks whether every admissible comparison path can be killed by the extension-count constraint.

**Test performed (one-sided Wells heavier-child levels, congruence-quotiented):**
- `S_0 = {∅_{13}}`.
- For states in `S_c` (after `c` comparisons), a move `(u,v)` is *admissible at level `c+1`* iff **both** children satisfy `e(child) <= 2^(C-c-1)`.
- `S_{c+1}` contains the **heavier child** (`max(e)`) of every admissible move from every `P ∈ S_c`, quotiented by **poset isomorphism** of the transitive-closed successor DAG.
- `[deduction]` Soundness (as in `docs/research-n12-nontightness.md` §4, Wells/Peczarski/Stober–Weiss heavier-child argument): if any `S_c = ∅` under a complete enumeration, no height-`C` sorting tree exists, hence `S(13)>33`. A complete empty level would be a finite obstruction candidate subject to audit.

`[literature context, not audited here]` For `n=12` Wells' one-sided exploration already empties a level; for `n>=13` the published search discipline may require inspecting second children / bidirectional or complete-child handling (as summarized in `docs/research-n12-nontightness.md`). **Therefore a non-empty one-sided level is inconclusive, and this computation alone cannot certify `S(13)>33` even if it found a suspicious state.** Resource exhaustion is also inconclusive.

## 2. Exact assumptions and resource caps

- **Model:** adaptive, worst-case, pairwise comparisons, 13 distinct labelled keys, no ties. `[definition]`
- **State:** transitive-closed successor bitmask poset on `{0..12}`. `[definition]`
- **`e(P)`:** exact order-ideal DP over `2^13=8192` ideals, integer arithmetic (`one_ply_obstruction.linear_extensions`). `[experiment]`
- **Admissibility:** children at depth `d=c+1` must satisfy `e <= 2^(33-d)`. `[definition]`
- **Quotient:** `networkx.algorithms.isomorphism.DiGraphMatcher.is_isomorphic` on the transitive DAG. `[experiment]` This is a congruence quotient by labelled-poset isomorphism; orbit counts/classes are reported up to this quotient.
- **Completeness of each reported level:** every incomparable pair of every representative of `S_c` was tested (all moves tested counts shown). Since poset isomorphism preserves incomparability, `e` of outcomes, admissibility, and heavier-child class, representatives suffice for the one-sided heavier-child level definition. `[deduction]`
- **Resource caps used:** `--max-depth 5 --time-cap 120` s for the depth-5 run (completed in 47.226 s); depth-4 JSON run used `--time-cap 600` s (22.441 s). `--max-state-expansions` available for explicit state caps. No cap was hit in the reported completed levels. `[experiment]`
- **Interpretation rule:** node/time/state/depth-cap exhaustion or a non-empty completed level => **INCONCLUSIVE**. Never evidence for or against `S(13)<=33` / `S(13)>33` except a complete audited empty level under a sound discipline.
