## 2. Row-group audit

### 2.1 Terminals / absorbing (1,2,3,8,11,13,16,18)
All primed explicitly (globals + `Terminal_ClearFrames`). Row 1 absorbing identity. Root accept/reject set globals mutually exclusive. **v2:** row 11 uses `NNI_c` including `CurExhausted` (consumed). No obvious closure gap in schema; partition must hold under `I_M_D`.

### 2.2 Pops / returns (4,5,9,12,14,17,19), `S={p,c}`
`p` excluded from `FrameEq'`, receives `MarkRetAccOn/RejOn` with `PreserveNonMarkerFields`. Critical: row 5 must preserve BackE cursor components including `CurExhausted` (v2) so rows 10–12 can consume. 
- **4,9,17:** acc markers to Back* receivers.
- **5,12,14,19:** rej markers; row 12 is `NNI_c` path (exhaustion) in v2.
**Falsifiers:** `MarkerReceiver_Is_BackStar` (eval return to non-Back*), `No_Eval_RetMarker_Top`, cursor corruption before consumer. v2 strengthens preservation to include `CurExhausted`.

### 2.3 Pushes (6,7,10,15), `S={c,d}`
All use `ChildFrameBase` + `[SYM-TOP]` (`Top'(d),¬Top'(c)`, unique top, `CurBaseBump`, `FreshChild(d)`).
- **6 (eval-sort):** requires `NI_c = ¬CurExhausted ∧ CurNormalState ∧ ∃x,y NextIncomp` from current cursor; calls `SetParentBackE_Advance(c,x,y)` and `PushChildE(d,c,x,y)`. **v2:** if last pair, advances to `CurExhaustedState'` (no reselect). 
- **7 (adv A0):** uses selected pair, `PushChildA(d,c,a,b,0)`, sets `StepPosBit_c(a,b)`, `SuccCtr`, `PostBudgetFrom`, parent becomes `M_BackA0` preserving snapshot.
- **10 (BackE rej next):** same as 6 but guard `M_BackE∧RetRej∧NI_c` (cannot fire on `CurExhausted`).
- **15 (BackA0 acc A1):** uses preserved `PosF/UsedF/SelA/SelB` of BackA0 parent, `PushChildA(d,c,a,b,1)` with reversed side, parent becomes `M_BackA1`. **Critical:** snapshot must come from parent `c`, not popped A0 child.

**Falsifiers:** freshness/alias (`FreshChild_Fresh_On_IMD`), cursor/witness issues (non-minimal/ambiguous), A1 snapshot alias (`A1_Snapshot_From_Parent`), reselect on exhausted/last pair (fixed by v2).

### 2.4 Eval-focused (2–7)
- **Partition:** `M_Eval∧Root -> CfgAcc_c xor RejectEval_c`; non-root same. **Fix 1:** `RejectEval_c` includes `NoNextIncompAtCur_c` (now `NNI_c` in v2) => rows 3 or 5.
- **CtrlSort exhaustivity:** `Guard_pre := Top∧M_Eval∧CtrlSort∧RetNone ∧ ¬Total_c ∧ Budget_c -> (CfgAcc_c ∨ RejectEval_c ∨ NI_c)`, pairwise disjoint. Row 6 is `NI_c`-only; with v2 `NI_c` requires `¬CurExhausted ∧ CurNormalState`.
- **No eval return-marker on top:** `No_Eval_RetMarker_Top`.
- **Push legality:** witness incomparable/lex-minimal, children get correct `PosF/UsedF/ctrl/ret/mode/parent`.

## 3. v2 vs v1: what changed, remaining gaps

**v2 addresses (schema-level):**
1. Adds `CurExhausted` to `Rbar/Fld/FrameFieldsEq'`, defines `CursorCoherent` (`CurExhausted xor CurNormalState`) with total `HasCur/CurA/CurB` and concrete exhausted encoding `(MinKey,MinKey,CurExhausted)`.
2. Initializes `CurExhausted` in `Init_{M_D}^{sym}` and in all child constructors (`PushChildE/A` set `¬CurExhausted'`).
3. Rewrites `SetParentBackE_Advance`: `¬IsLastLex2 => SuccLex2 => CurNormalState' ∧ ¬CurExhausted'`; `IsLastLex2 => CurExhaustedState'`. Eliminates sentinel ambiguity (last pair produces exhausted state).
4. Extends `PreserveNonMarkerFields`/`MarkRet*On` to preserve `CurExhausted`.
5. Rewrites `NI_c/NNI_c`: `NI_c := ¬CurExhausted ∧ CurNormalState ∧ ∃x,y NextIncomp`; `NNI_c := CurExhausted ∨ (¬CurExhausted ∧ CurNormalState ∧ NoNextIncomp)`. Rows 10 requires `NI_c` (cannot fire on exhausted), rows 11–12 consume `NNI_c` including `CurExhausted`.
6. Gives per-row `CurExhausted'` priming for all 19 rows (table §5) — no row leaves it underdetermined.

**Remaining open (per v1/v2):**
- `BackE_Cursor_Preservation` under `I_M_D` reachability (row 5 must preserve cursor including `CurExhausted` until consumer).
- `BackE_NI_NNI_Total_Complement`: reachable `BackE_RetRej_Top` gives `CursorCoherent` and `NI_c xor NNI_c` with unique NI witness.
- `BackE_AfterSelected_NoReselect`: schema prevents reselect (last => exhausted, non-last => successor), but needs proof under reachability.
- `MarkerReceiver_Is_BackStar`, `No_Eval_RetMarker_Top`, `No_BackStar_RetNone_Consuming_Top`.
- `A1_Snapshot_From_Parent`, `FreshChild_Fresh_On_IMD`, `Parent_Functional_Active_Preserved`.
- `CtrlSort_Exhaustive_On_IMD` adapted to v2 `NI_c/NNI_c`.
- Full `I_M_D` preservation induction over all 19 rows + `ExactlyOneMode/Top/UsedF` coherence.
- `Enc_Component_Closure` cursor coherence + realization alignment (v2 narrows but does not discharge).
- DET-SUCC discharge not provided.
