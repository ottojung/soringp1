# FO(TC), bounded-width branching programs, and the minimax sorting strategy

**Status:** research note (paper-level, literature + deduction). Not Lean-checked.
No NP-hardness, separation, or P vs NP claim. All items labeled
`[literature]`, `[deduction]`, `[conjecture]`, `[open]`.

**Model:** adaptive comparison sorting of `n` distinct labeled keys, `S(n)=`
minimum worst-case height of a correct decision tree (`docs/problem.md`).
Game `G(n,k)`: states are transitively closed partial orders `P` on `n`
elements; sorter moves by picking an incomparable pair, adversary branches on
`x<y/y<x`; sorter wins iff reaches a total order within `k` comparisons
(`docs/research-certificates-barriers.md` §0). 
`SORT-BOUND-U = {1^n # 1^k : S(n) ≤ k}` (unary), `SORT-BOUND-B` binary.

## 1. Candidate formalisms

`[definition]` **FO(TC)_v (fixed variables).** First-order logic with transitive
closure where every subformula uses at most `v` distinct variable names, `v`
fixed; arity bounded by `v`. On finite ordered structures FO(TC) captures NL
`[literature, Immerman]`. With bounded variables and combined evaluation over
domain `N = O(n+k)` this is polytime in `(|phi|, N)` (direct induction)
`[deduction, docs/research-fo-tc-combined.md Lemma A]`.

`[definition]` **Strategy/query programs.** A finite program that, given the
current knowledge structure (history of comparisons + closure), produces the
next query `Ask(i,j)` or halts with output, charging all steps; run under a
uniform polynomial clock on input `n,k` and all permutations
`[definition, docs/research-fo-tc-combined.md]`. If rules are given by
FO(TC)_v formulas, this is a FO(TC)_v strategy program.

`[definition]` **Bounded-width branching programs (strategy programs).**
A branching program that reads comparison outcomes (or the input order)
and maintains state in a set of size `w` (fixed width), making transitions
depending only on current state and current input bit/outcome; equivalent in
power to width-`w` finite automata with output/branching. Barrington’s
theorem relates bounded width over non-solvable groups to NC^1
`[literature, Barrington]`. Interpreted as a strategy, fixed width means
fixed memory/state space for the decision policy.

## 2. What the formalisms can do

- **Standard sorts as programs:** insertion sort / merge sort have fixed
  schemas implementable as strategy programs with `O(n log n)` queries and
  `O(n log n)` control actions (polynomial size in description of `n`);
  FO(TC)_v can express the needed local comparisons/ordering tests
  `[deduction, docs/research-fo-tc-combined.md §Elementary strategy examples]`.
- **FO(TC)_v evaluation is cheap:** polytime per formula evaluation over
  size `N` domains; with polynomially many rule applications total gives
  uniform polytime interpreters. The representable subclass is in `Sigma_2^P`
  if one guesses the program `p` and universally verifies over all `n!`
  orders under uniform clock (soundness yes; completeness open)
  `[deduction, docs/research-fo-tc-combined.md]`.
- **Descriptive complexity:** FO(TC) on ordered structures ⊆ NL ⊆ PSPACE
  `[literature, Immerman]`. Fixed-variable fragments are more restrictive than
  full FO(TC).

## 3. Barriers from state complexity (the key obstruction)

**[deduction]** The minimax strategy graph is the DAG/game graph on poset
states `P` with transitions by comparisons. Two independent barriers show this
graph is not “small” or “compressible” by memoization/recurrence compilers:

1. **Winning frontier (all-n / exact budget).** For infinitely many
   `n=2^{2r}` with `k=C(n)+o(n)` (and in particular at exact optimal budget
   `k=S(n)$ by Sergeev’s bound giving sublinear surplus), there are
   `>= 2^{(1/4-o(1)) n (log_2 n)^2}` pairwise nonisomorphic posets `P` reachable
   at the same comparison depth `t=k-B` that are all winning (can finish within
   remaining budget `B=k-t$). A finite witness with `n=224` already gives
   `> 2^{39}$ nonisomorphic winning states
   `[deduction/experiment, docs/research-winning-frontier-barrier.md]`.
   This is an enumeration/barrier to any method that must “handle” states
   separately; it is not a time lower bound for computing `S(n)$ by selective
   search but a property of the strategy graph state space.

2. **Recurrence/compiler barriers.** Exact minimax recurrence needs
   `e(P)$ (linear extensions) — `#P$-complete to count
   `[literature, Brightwell–Winkler]`; table compilers over all reachable
   posets hit `2^{Theta(n^2)}$ states in general
   `[deduction, docs/research-certificates-barriers.md §5, research-hardness-boundaries.md]`.
   Explicit tree compilers produce `Omega(n!)$ nodes
   `[deduction, docs/research-fo-tc-combined.md Lemma B1]`.

**[deduction]** **Width/variable invariants.**
- A bounded-width branching program has fixed width `w =>` at most `2^w$ states
  distinguishable at any level; it is a finite-state transducer over the
  comparison sequence. The winning frontier requires exponentially many
  different states at the same depth that are all reachable and winning but
  (in general) not equivalent for optimal play — a fixed finite state machine
  cannot assign different optimal next moves to exponentially many
  non-equivalent states without either (a) merging and making suboptimal
  moves on some, or (b) being unable to represent the strategy at all. More
  directly, the strategy graph restricted to that frontier has pathwidth/width
  exponential in `n log n$ (up to factors), exceeding any fixed `w$.
- FO(TC)_v has at most `v$ variables =>` the “type” of any tuple is described
  by a formula over `v$ variables from a finite set of quantifier-rank bounded
  formulas (Ehrenfeucht–Fraisse / finite variable logics). The number of
  `v$-types is finite (for fixed `v$). A strategy defined by fixed FO(TC)_v
  rules is a function of the current `v$-type (and bounded history) of the
  knowledge structure. The posets in the independent-edge winning frontier
  form exponentially many non-isomorphic structures that are pairwise
  indistinguishable by any fixed first-order sentence of bounded quantifier
  rank / by bounded-variable logics in a way that preserves optimal
  comparison choices? Or more directly, they realize exponentially many
  different “advice” needs while having bounded “local” type complexity —
  a fixed set of `v$-types cannot index exponentially many different optimal
  moves. This is analogous to pebble games: bounded pebbles cannot
  distinguish certain structures, and to a bounded-state strategy being unable
  to win on all members of a large family.

**Conclusion on capturability (deduction):** Fixed-width bounded branching
programs and fixed-variable FO(TC)_v strategy programs do **not** capture
the all-n minimax optimal sorting strategy. The obstruction is unbounded
arity/width of the strategy graph’s state space (the winning frontier)
relative to fixed finite memory/variable budget. To capture optimal play on
all members of that frontier one would need either unbounded width/variables
or a representation that effectively enumerates/encodes exponentially many
states (super-polynomial resources). General exponential decision trees
capture it by definition but are not compressed.

## 4. Can FO(TC) evaluation of S(n) be placed in a uniform class below PSPACE?

`[deduction]` **Upper side (fragment):** FO(TC)_v strategy programs are
uniformly polytime evaluable; guessing such a program and verifying against
all orders gives a `Sigma_2^P$ predicate for the “there exists a poly-size
fragment strategy of depth <= k” property (sound). This places that
*representable subclass* of `SORT-BOUND-U$ in `Sigma_2^P$ (conditional on
the fragment being exactly those programs) — still above NP in the
polynomial hierarchy, and the class depends on the fragment.

`[deduction]` **Lower/obstruction side:** 
- **No NP membership known.** Explicit tree witnesses are exponential in
  input length (n! is doubly exponential in binary input length, superpolynomial
  in unary) so naive nondeterministic certificates fail; no succinct
  polynomial certificate is known for either direction
  `[deduction, docs/research-certificates-barriers.md §4, research-decision-encoding.md §4]`.
- **Unary sparse => Mahaney barrier to many-one NP-hardness.** `SORT-BOUND-U$
  is sparse; NP-hardness under polynomial-time many-one reductions would
  imply `P=NP$ `[literature, Mahaney; deduction, research-hardness-boundaries.md §4]`.
- **PSPACE upper bound holds.** The game `G(n,k)$ is solvable by an
  alternating TM in time polynomial in `n,k$ (unary) giving `SORT-BOUND-U ∈ PSPACE$,
  and in time exponential in binary input length giving `SORT-BOUND-B ∈ EXPSPACE$
  `[deduction, research-certificates-barriers.md Claim A]`. Binary is not sparse
  so Mahaney doesn’t apply.

**Answer:** FO(TC) evaluation of the *strategy* is polytime for fixed
formulas, but placing the *function/value* `S(n)$ (or `SORT-BOUND-U$) in a
uniform class below PSPACE is blocked by the strategy-graph state complexity
barrier above. The natural FO(TC)/bounded-width compression is not complete
for optimal strategies due to the winning frontier; without completeness you
don’t get a better upper bound than the game/ATM PSPACE bound from this
route. A uniform FO(TC)-computable strategy for all `n$ of size polynomial
in `n+S(n)$ would be a strong form of completeness (putting that
subclass in `Sigma_2^P$) — but all-n completeness is the open question and
is falsified in principle by the width/invariant barrier unless the winning
frontier posets are “capturable” despite non-isomorphism (which bounded
memory cannot do). No primary source establishes FO(TC)_v completeness for
all `n$; the barrier suggests it is false.

Also note: “FO(TC) ⊆ L” in some forms is not a standard fact for all
FO(TC)-definable functions without ordering/structure restrictions; and
relating to NC^1 via bounded-width branching programs is directly contradicted
by the exponential width requirement from the winning frontier.

## 5. Falsifiers and disproof directions

**Falsifier 1 (width/arity obstruction, preferred):** Show there exists a family
of posets `{P_{n,i}}$ from the winning frontier (or constructively) such that
every fixed FO(TC)_v (or every bounded-width branching program of fixed width
`w$) makes a suboptimal next comparison on some member of the family while
some adaptive strategy makes an optimal next comparison on all members,
for all sufficiently large `n$. Proof idea: use Ehrenfeucht–Fraisse games /
pebble games to show `v$-types cannot distinguish the “column”/“edge”
configurations that force different optimal moves in that rectangular
construction; or use the fact that number of types is constant in `n$ while
number of relevant configurations is exponential. This would be a clean
all-n invariant/barrier separating them.

**Falsifier 2 (direct invariant):** Identify a property `Phi(P)$ preserved by
all FO(TC)_v-definable strategies and violated by some optimal minimax
strategy on some poset in the winning frontier for large `n$ (e.g. a
locality/regularity invariant). State `Phi$ precisely and give a
counterexample.

**Converse (upper bound):** Construct a uniform FO(TC)_v program (fixed
`v$, polynomial size in `n+S(n)$) computing the optimal next comparison for
all posets on `n$ elements and all `n>=1$, with a proof of correctness and
a check that it fits the `Sigma_2^P$ verification model. The barrier above
suggests this is false for the exact minimax strategy; a correct
construction would need to overcome the winning frontier by some global
invariant that happens to be FO(TC)-definable (seems unlikely given
current understanding).

## 6. Relation to certificate size and classes

- **Certificate size:** If the strategy cannot be compressed below
  exponential size by bounded-width/FO(TC) means, the only polynomial-size
  certificates would need to come from a different form (not a compressed
  strategy graph) — none is known. The tree witness is exponential; the
  winning frontier shows the “state graph” is large.
- **Complexity classes:** FO(TC)_v ∈ P (uniform evaluation). Strategy
  programs don’t directly give NP membership of `SORT-BOUND-U$ without a
  succinct proof; they give `Sigma_2^P$ if complete and guessed+verified.
  Below PSPACE seems ruled out by the state-complexity/winning-frontier
  barrier for compression to fixed width/variables; the game already gives
  PSPACE. NC^1/L would require even more compression (bounded width +
  very small depth) and is incompatible with needing to distinguish
  exponentially many states in the frontier unless there is a deep
  symmetry argument that fails for all-n optimal strategies.

## 8. Verdict (concrete)

**Obstruction (strongest):** The minimax comparison strategy graph has
exponentially many nonisomorphic winning states at the same depth (the
winning frontier), present even at exact optimal budget `S(n)`. Fixed-width
branching programs and fixed-variable FO(TC)_v cannot distinguish this many
states and cannot assign correct optimal moves to all of them; any such
fixed-compression strategy is either suboptimal on some frontier member or
requires super-polynomial size to simulate unbounded memory. Therefore
FO(TC)_v (fixed `v$) does **not** capture the all-n minimax optimal strategy
without super-polynomial resources, and bounded-width branching programs do
not either. This blocks the naive route to placing `S(n)$ evaluation below
PSPACE via FO(TC)/bounded-width compression — the game-theoretic PSPACE
upper bound from alternation remains the natural uniform upper bound, and
no polynomial certificate is apparent.
