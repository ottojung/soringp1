## 1. Invariant strengthening required for obligations (1)-(2)

`[definition]` **Strengthening `I^{+}_{M_D}`.** Let `I^{+}_{M_D}(E)` be
`I_{M_D}(E)` together with the DFS stack-shape conjuncts
```text
(LiveBackParent)
  ∀c̄∀p̄( FrameLive(E,c̄) ∧ FrameLive(E,p̄) ∧ Parent(E,c̄,p̄)
         -> M_BackE(E,p̄) ∨ M_BackA0(E,p̄) ∨ M_BackA1(E,p̄) ).

(TopBackMarker)
  ∀c̄( Top(E,c̄) ∧ (M_BackE(E,c̄)∨M_BackA0(E,c̄)∨M_BackA1(E,c̄))
       -> RetAcc(E,c̄) ∨ RetRej(E,c̄) ).
```

`[inherited assumption]` The proof sketches below also use the intended
DFS/`I_{M_D}` consequences already named as open in normalized Enc §4.2:

## 2. `MarkerReceiver_Is_BackStar`

**Lemma 2.1 (`MarkerReceiver_Is_BackStar`, conditional proof sketch).**
`[deduction]` Let `E` be `I^{+}_{M_D}$-reachable (hence `I_{M_D}$-reachable) and
let `D_eval_acc_ret(E,c̄,p̄)` or `D_eval_rej_ret(E,c̄,p̄)` fire:
```text
Top(E,c̄) ∧ M_Eval(E,c̄) ∧ NonRoot(E,c̄) ∧ (CfgAcc_c(E) ∨ RejectEval_c(E))
∧ Parent(E,c̄,p̄).
```
By base `I_{M_D}$, `Top(E,c̄) ∧ FrameLive(E,c̄)`. By `NonRoot/Parent` and
functional parent/active-path discipline `[inherited assumption]`,
`FrameLive(E,p̄)`. By `LiveBackParent`,
```text
Parent(E,c̄,p̄) -> M_BackE(E,p̄) ∨ M_BackA0(E,p̄) ∨ M_BackA1(E,p̄).
```
Rows 4 and 5 perform `PopTo_base(p̄,c̄) ∧ MarkRetAccOn(p̄)` or
`MarkRetRejOn(p̄)`. `MarkRet*On(p̄)` preserves `Mode` and `FrameLive'(p̄)`, so
`Mode'(p̄)` remains Back* and the marker is applied to a matrix-consumable
Back* frame.

**Verdict (obligation 1).** `[deduction]` **Proved as a proof sketch on
`I^{+}_{M_D}$-reachable states**, not discharged on base `I_{M_D}$ alone
without stating `LiveBackParent`. The strengthening is precise and preserved by
the proof sketch in Lemma 1.1.

**Falsification shape.** `[falsification]`
```text
I_{M_D}(E) ∧ D_eval_{acc,rej}_ret(E,c̄,p̄) ∧ M_Eval(E,p̄).
```
A transition by row 4/5 would then set `Top'(p̄)`, preserve `M_Eval'(p̄)`, and
set `RetAcc'(p̄)`/`RetRej'(p̄)`, yielding the Eval+RetMarker top of obligation
(2). No explicit `I_{M_D}$-reachable witness of this shape was found from the
normalized matrix: every matrix path that creates a live `Parent(E,c̄,p̄)` with
an `M_Eval` child `c̄` (rows 6,7,10,15) sets `p̄` to Back* in the same step, and
no row restores a live parent to `M_Eval`. The falsifier is therefore
inconsistent with `LiveBackParent`; a genuine reachable witness would have to
violate `LiveBackParent` (or the freshness/parent-discipline assumptions).

## 3. `No_Eval_RetMarker_Top`

**Lemma 3.1 (`No_Eval_RetMarker_Top`, conditional proof sketch).** `[deduction]`
We show no `I^{+}_{M_D}$-reachable state has
```text
Top(E,c̄) ∧ M_Eval(E,c̄) ∧ (RetAcc(E,c̄) ∨ RetRej(E,c̄)).
```
`Init_{M_D}^{sym}` has `M_Eval(root),RetNone(root)`. For a step `E --D_i--> E'`:
- **Direct `M_Eval` assignments**: `PushChildE`/`PushChildA` set
  `M_Eval'(d̄) ∧ RetNone'(d̄)`; no row sets `M_Eval'` together with
  `RetAcc'`/`RetRej'`.
- **`RetAcc`/`RetRej` assignments**: `MarkRetAccOn(p̄)`/`MarkRetRejOn(p̄)` set a
  return marker but preserve `Mode` of `p̄`. They occur in rows 4,5,9,12,14,17,19.
  In rows 4,5, the pre-state gives `Parent(E,c̄,p̄)` with `M_Eval(E,c̄)$ top child;
  `LiveBackParent` implies `Back*(E,p̄)$, hence `Mode'(p̄)$ is Back* and not
  `M_Eval`. In rows 9,12 the consumed child is `M_BackE$; in row 14 `M_BackA0$;
  in rows 17,19 `M_BackA1$; their parent `p̄` is live with
  `Parent(E,c̄,p̄)$ in the pre-state, so `LiveBackParent` gives `Back*(E,p̄)$
  and preserved Back* `Mode'(p̄)$.
- **Back*-setting rows** 6,7,10,15 set Back* modes with `RetNone'$ on the modified
  frame and do not make that frame `Top'$.
- **Preservation**: `FrameEq'`/`LowerStackPreservedExcept` and `MarkRet*On`
  preserve mode/ret of untouched frames; no other row mutates an untouched live
  frame's `M_Eval,Ret` into the forbidden combination.

Therefore `M_Eval ∧ (RetAcc∨RetRej)$ is not created on any frame, in particular
not on `Top$.

**Verdict (obligation 2).** `[deduction]` **Proved as a proof sketch on
`I^{+}_{M_D}$-reachable states**, using `LiveBackParent`. Base `I_{M_D}$ states
the shape as a lemma but not the `LiveBackParent` conjunct; without that
strengthening the row-local argument is incomplete because rows 4/5 do not
syntactically guard `¬M_Eval(p̄)$.

**Falsification shape.** `[falsification]`
```text
I_{M_D}(E*) ∧ Top(E*,c̄) ∧ M_Eval(E*,c̄) ∧ (RetAcc(E*,c̄)∨RetRej(E*,c̄)).
```
Under the normalized 19-row matrix, this requires either a direct assignment
(none exists) or `MarkRet*On(c̄)$ applied while `c̄$ is/preserves `M_Eval$. The
only candidate producers are pop rows 4,5,9,12,14,17,19, all excluded on
`I^{+}_{M_D}$ by `LiveBackParent$ as in Lemma 3.1. No explicit
`I_{M_D}$-reachable transition trace producing this shape was found.

## 4. `No_BackStar_RetNone_Consuming_Top`

**Lemma 4.1 (`No_BackStar_RetNone_Consuming_Top`, proof sketch).** `[deduction]`
We prove the stronger reachability statement: no `I_{M_D}$-reachable state
satisfies
```text
Bad(E,c̄) := Top(E,c̄) ∧ (M_BackE(E,c̄)∨M_BackA0(E,c̄)∨M_BackA1(E,c̄)) ∧ RetNone(E,c̄).
```
`Init_{M_D}^{sym}$ has only `M_Eval$ as `Top$, so `¬Bad$. Assume `¬∃c̄ Bad(E,c̄)$
and `E --D_i--> E'$.

- **Row 1** (halt): no non-halting Back* `Top'$.
- **Rows 2,3,8,11,13,16,18**: terminal/global halt conventions; no consuming
  non-halting `Top'$ of the bad form.
- **Push rows 6,7,10,15**: `Globals_push(c̄,d̄)$ gives unique `Top'(d̄)$ and
  `¬Top'(c̄)$. The child `d̄$ is `M_Eval'(d̄)∧RetNone'(d̄)$
  (`PushChildE`/`PushChildA$), so `Bad(E',d̄)$ is false. The frame `c̄$ becomes
  Back* with `RetNone'$ (`SetParentBackE_Advance`/`SetParentBackA0`/
  `SetParentBackA1$) but is not `Top'$.
- **Pop rows 4,5,9,12,14,17,19**: `Globals_pop(p̄,c̄)$ gives unique `Top'(p̄)$
  and `FrameInactive'(c̄)$. Every such row applies `MarkRetAccOn(p̄)$ or
  `MarkRetRejOn(p̄)$, hence `RetAcc'(p̄)∨RetRej'(p̄)$ and `¬RetNone'(p̄)$.
  Therefore `Bad(E',p̄)$ is false regardless of `Mode'(p̄)$.
- **Other frames**: only `{c̄,d̄}$ or `{p̄,c̄}$ are modified; `Top'$ is unique and
  is the modified top-designated frame in every non-halt row.

Thus `Bad$ is unreachable. Consequently no `I_{M_D}$-reachable state *requires* a
return-consuming matrix row from `Top(c̄)∧Back*(c̄)∧RetNone(c̄)$, because no
such state is reachable at all.

**Verdict (obligation 3).** `[deduction]` **Proved as a proof sketch on
`I_{M_D}$-reachable states** (base `I_{M_D}$ is sufficient together with the
normalized matrix's row-local `Top'$ and `Ret'$ assignments). No invariant
strengthening is needed beyond the matrix discipline and the base `Top'$
uniqueness/non-halt conventions already in `I_{M_D}$.

**Matrix completeness remark.** `[deduction]` The normalized 19-row matrix has no
row consuming `Top(c̄)∧Back*(c̄)∧RetNone(c̄)$: BackE rows are 8-12 (RetAcc/RetRej),
BackA0 rows 13-15 (RetAcc/RetRej), BackA1 rows 16-19 (RetAcc/RetRej). This is
consistent with Lemma 4.1: the case is neither needed nor consumable on the
reachable orbit. A refined invariant asserting `Top∧Back* -> RetAcc∨RetRej$ is
exactly `TopBackMarker$ (`I^{+}_{M_D}$); it strengthens `I_{M_D}$ but is not
required to refute reachability of the bad top state.

**Falsification shape.** `[falsification]`
```text
I_{M_D}(E*) ∧ Top(E*,c̄) ∧ (M_BackE∨M_BackA0∨M_BackA1)(E*,c̄) ∧ RetNone(E*,c̄)
∧ (no D_i consumes E* ∨ two D_i consume E*).
```
The reachability part `I_{M_D}(E*)∧Top(E*,c̄)∧Back*(E*,c̄)∧RetNone(E*,c̄)$ is
refuted by Lemma 4.1: every row that creates a Back* `RetNone'$ frame removes
`Top'$ from it (push rows), and every row that creates `Top'$ on a frame sets
`RetAcc'/RetRej'$ (pop rows) or creates an `M_Eval'$ child (push rows). No
explicit transition trace to this shape exists under the normalized matrix.
