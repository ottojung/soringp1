# FO(LFP) definability of SORT-BOUND-U on ordered unary structures

**Agent:** billy-dev (research exec, worktree at HEAD)  
**Question/front:** `folfp-definability-sortboundu`  
**Date:** 2026-11-18

## 1. Question

Can

> `SORT-BOUND-U = { 1^n # 1^k : S(n) ≤ k }`

be defined by an `FO(LFP)` (first-order logic with least fixed point) sentence on ordered finite structures encoding the unary input `1^n#1^k`?

**Consequence (stated in task, literature context).** On ordered finite structures, `FO(LFP)` captures `P` (Immerman 1986; Vardi 1982) `[literature]`. Therefore an explicit, correct `FO(LFP)` definition of `SORT-BOUND-U` would place `SORT-BOUND-U ∈ P` (equivalently `S_unary ∈ FP`, by `problem.md`), a new uniform polynomial-time upper bound for the unary threshold problem. A rigorous proof that no `FO(LFP)` sentence defines `SORT-BOUND-U` on the intended ordered structures would imply `SORT-BOUND-U ∉ P`; combined with the established `SORT-BOUND-U ∈ PSPACE` this would imply `P ≠ PSPACE` (`problem.md`, "Realistic outcomes") `[deduction]`. The task asks not to infer membership from a compact informal recurrence.

## 2. Definitions and model

### 2.1 Sorting-number language (fixed)

`[definition]` (from `docs/problem.md`). `S(n)` is the minimum worst-case height of a deterministic adaptive comparison decision tree correctly sorting every permutation of `n` distinct labelled keys. `SORT-BOUND-U = { 1^n # 1^k : S(n) ≤ k }` with parameters encoded in unary; input length `N = n + k + 1`. The active question is uniform in `(n,k)` (all `n,k`).

### 2.2 Ordered finite structure for the unary encoding

`[definition]` (standard string/word structure for descriptive complexity). For an input `w = 1^n # 1^k`, let

- universe `U = {1, ..., N}` with `N = n+k+1`;
- `<` a total linear order on `U` (the position order);
- unary relations `One ⊆ U`, `Hash ⊆ U` with `Hash = {n+1}` and `One = U \ Hash` (equivalently, the symbol at position `i`).

Write `𝔄_{n,k} = (U, <, One, Hash)`. The vocabulary is `τ = {<, One, Hash}` with `<` binary. The two blocks are first-order definable:
`Left(x) := ∃y (Hash(y) ∧ x < y)` defines an initial segment of size `n`, and `Right(x) := ∃y (Hash(y) ∧ y < x)` one of size `k`; `|Left| = n`, `|Right| = k`. Because `<` orders `Left`, the `n` abstract input keys of the sorting problem can be canonically identified with the elements of `Left` as a linearly ordered `n`-element domain available to formulas (this supplies the order required by Immerman–Vardi). The unknown permutation to be sorted is not encoded in `𝔄_{n,k}`; it is universally quantified by the correctness condition defining `S(n)`.

Alternative equivalent ordered encodings (e.g. separate unary predicates for the blocks, or a structure whose universe is the disjoint union of the blocks with induced order) are interdefinable in first-order logic with `<` and do not change `FO(LFP)` definability up to standard translations; the analysis below is stated against `𝔄_{n,k}` but hinges only on having an ordered structure of size `Θ(N)` from which `n,k` and an ordered `n`-element domain are definable.

### 2.3 FO(LFP): syntax, semantics, range

`[literature]` (standard; e.g. Ebbinghaus–Flum, *Finite Model Theory*; Libkin, *Elements of Finite Model Theory*; Immerman, *Descriptive Complexity*). `FO(LFP)` extends first-order logic by least fixed-point operators. If `φ(R, x̄)` is a formula of vocabulary `τ ∪ {R}` in which the `r`-ary relation variable `R` occurs only positively, it induces a monotone operator on `r`-ary relations over the universe `U`:
`T_φ(S) = { ā ∈ U^r : (𝔄, S) ⊨ φ[ā] }`.
The least fixed point `lfp_R, x̄ φ` denotes `⋃_{i≥0} T_φ^i(∅)` (by Knaster–Tarski/Kleene on finite structures). A sentence of `FO(LFP)` has a truth value on each finite `τ`-structure.

- **Quantification/range.** First-order variables range over elements of `U` (size `N`). Second-order content is only through fixed-point relations `R ⊆ U^r` of fixed arities `r` determined by the formula.
- **Stages/complexity.** Because `|U^r| = N^r`, the inflationary sequence reaches the least fixed point in at most `N^r + 1` stages for each fixed `r`. On a fixed sentence, evaluation is polynomial in `|U|` (hence polynomial in `N`). Conversely, every polynomial-time decidable class of ordered finite structures is definable in `FO(LFP)` (Immerman 1986; Vardi 1982) `[literature]`.
- **What LFP can/cannot range over directly.** `FO(LFP)` can define and iterate over polynomial-arity relations on the input domain, compare tuples in the given order, and (on ordered structures, via the Immerman–Vardi framework) simulate polynomial-time computation including arithmetic on the numeric domain `{1,…,N}`. It cannot introduce variables ranging over subsets/relations not representable as fixed-arity tuples over `U`, nor perform a fixed point whose natural state is exponentially larger than every polynomial power of `N` unless that state is compressed into polynomial-arity relations over `U`.

### 2.4 Game/minimax characterization of S(n) ≤ k

`[deduction]` (from `docs/problem.md`, `docs/research-certificates-barriers.md` Claim A). `S(n) ≤ k` iff the sorter wins the finite game `G(n,k)`:
- state: a transitively closed strict partial order `P` on `n` labelled elements;
- initial state: the empty order on `Left`;
- move: sorter picks an incomparable pair `{x,y}`; adversary answers `x<y` or `y<x`; update to transitive closure;
- sorter wins if a total order is reached within `k` comparisons.

Equivalently the minimax recurrence is
- `W(P,0) := Total(P)`;
- `W(P,t+1) := Total(P) ∨ ∃{x,y} incomparable in P . W(tc(P∪{x<y}), t) ∧ W(tc(P∪{y<x}), t)`.

`S(n) ≤ k` iff `W(∅, k)` holds for the empty order on `n` elements.

## 3. Analysis

### 3.1 Equivalence to a complexity upper bound (capture theorem)

`[literature]` + `[deduction]`.

- `FO(LFP) = P` on ordered finite structures (Immerman–Vardi). Hence `SORT-BOUND-U` is `FO(LFP)`-definable on `𝔄_{n,k}` iff `SORT-BOUND-U ∈ P`.
- `SORT-BOUND-U ∈ P ⇔ S_unary ∈ FP` (`problem.md`). 
- `SORT-BOUND-U ∈ PSPACE` is established (`research-certificates-barriers.md`, Claim A: decide `G(n,k)` by an alternating TM in time `O(k n^2)=O(N^3)` on unary input, and `APTIME = PSPACE` by Chandra–Kozen–Stockmeyer 1981 `[literature]`).
- `FO(PFP) = PSPACE` on ordered finite structures (Abiteboul–Vianu 1991; Vardi 1982 context) `[literature]`. Therefore, at the level of capture theorems, the known upper bound is consistent with existence of an `FO(PFP)` definition on ordered unary structures but does **not** imply an `FO(LFP)` definition. Conversely, `FO(LFP)` definability would strictly strengthen the known bound from `PSPACE` to `P`.

**Implication:** the definability question is not a purely syntactic/formalization question given current knowledge; it is equivalent to an open uniform upper-bound question. A definitive negative answer is out of reach without separating `P` from `PSPACE`; a definitive positive answer requires a new polynomial-time decision procedure (or an independently verified explicit formula whose correctness proof would amount to one).

### 3.2 What an LFP definition would need to represent

`[deduction]`.

A correct definition must capture, for all `n,k`, the minimax truth value `W(∅,k)` of game `G(n,k)`. Any direct logical rendering of the known characterizations must account for:

1. **The element domain.** The `n` keys are representable as `Left ⊆ U`, `|Left|=n ≤ N` (polynomial). An individual pair `(x,y)` is a tuple in `U^2`.
2. **A partial-order state.** A strict partial order `P` on `Left` is a binary relation `P ⊆ Left^2` satisfying irreflexivity, transitivity, asymmetry — first-order definable as a property of a relation. A single state is thus representable as an `n×n`/binary relation over the input domain.
3. **Comparison outcomes and closure.** Adding `x<y` and taking transitive closure `tc(P∪{x<y})` is definable from `P` by `FO(LFP)`/`FO(TC)` on the ordered `n`-element domain (reachability/transitive closure is a least fixed point) `[literature]`.
4. **Budget / height.** The horizon `k` is given by `|Right|` and the path length is ≤ `k ≤ N`; numeric comparison and iteration up to polynomially many steps are expressible in `FO(LFP)` on ordered structures `[literature]`.
5. **The minimax quantifier pattern over reachable states.** Correctness requires: there exists a sorter move such that for both adversary outcomes the resulting state is winning with one fewer comparison. This is an alternation (∃∀) repeated along plays. Moreover, after `t` comparisons there may be many different reachable posets depending on adversary answers along different histories.

Item (5) is the crux: the known exact methods quantify/evaluate over families of poset states whose cardinality is not polynomially bounded in `N` in general.

### 3.3 Known exact evaluation methods vs FO(LFP)

`[deduction]` from `docs/upper-bound.md`, `docs/research-budgeted-dfs.md`, `docs/research-certificates-barriers.md`, `docs/research-winning-frontier-barrier.md`.

| Method | Core state/iteration | Resource character | Direct FO(LFP) status |
|---|---|---|---|
| Memoized poset DP (`upper-bound.md`) | table over labelled posets on `n` elements (`2^{Θ(n^2)}` states, OEIS A001035 reachability for small `n`) | time `2^{O(n^2)}` in numeric `n` | No direct translation: LFP can maintain only fixed-arity relations over `U` (`N^{O(1)}` tuples total per relation); it cannot tabulate values for exponentially many poset states without a polynomial compression scheme. |
| Game/ATM characterization (Claim A) | current poset `O(n^2)` space, `k` alternating rounds | `ATIME(poly(N)) = PSPACE` (unary) | Natural logical counterpart is `FO(PFP)`/alternating fixed-point evaluation capturing `PSPACE`, not `FO(LFP)`. The universal adversary branch is explicit alternation, whereas `FO(LFP)` captures deterministic polynomial time. |
| Budgeted transcript DFS (`research-budgeted-dfs.md`) | transcripts/current state, no full poset table | `2^{O(N log N)}` time, `O(N log N)` bits space | Time-superpolynomial (so not a P procedure) and again adversarial/game-structured; does not yield an `FO(LFP)` definition. |
| Winning-frontier enumeration | all nonisomorphic winning states at a depth | `2^{(1/4-o(1)) n log^2 n}` states even at budget `S(n)` (`research-winning-frontier-barrier.md`) | Rules out methods that materialize the winning frontier; any LFP definition simulating such enumeration would be impossible, but this is a barrier to that method class, not to all LFP definitions. |

### 3.4 Attempted explicit/schematic construction and where it fails

`[deduction]` (falsification attempt on natural direct constructions).

**Attempt C1 (state-as-relation, value-by-fixpoint over states).** Identify keys with `Left`. Let a binary relation variable `P(x,y)` encode a poset on `Left`. Try to define a relation `Win(P-or-code, t)` by least fixed point over stages `t=0..k` using the minimax recurrence in §2.4. *Obstacle:* `Win` would need one truth value per `(poset state, budget)` pair; there is no single fixed-arity relation over `U` whose tuples range over all poset states. Encoding "for all poset relations P ..." inside `FO` quantifies `P` only if `P` is a free second-order variable not available in `FO(LFP)` sentences on `𝔄_{n,k}`; `FO(LFP)` allows LFP of first-order formulas in the expanded vocabulary, not quantification over arbitrary exponentially many relations as data values.

**Attempt C2 (strategy/certificate quantification).** Existentially quantify a winning strategy object and universally verify it. A strategy is a function from comparison histories/outcomes to next comparisons (a tree/DAG object); explicit trees have `2·n!−1` nodes (`research-certificates-barriers.md`, Claim C), far larger than any polynomial in `N`. Representing such an object as a constant-arity relation over `U^r` for fixed `r` is not generally possible. (This is also why `NP` membership is open: no succinct certificate is known.)

**Attempt C3 (unfold k alternation layers in FO).** Since `k ≤ N`, write `W(∅,k)` as a formula with `k` nested `∃pair ∀outcome` blocks. *Obstacle:* the formula size/depth would depend on `k` (on the input), not be a single fixed `FO`/`FO(LFP)` sentence uniform over all `n,k`; and each layer must update/maintain the current poset state through closure, which again branches over histories.

**Attempt C4 (use Immerman–Vardi existence non-constructively).** By capture, some `FO(LFP)` sentence exists iff a polynomial-time TM decides the property. *Status:* not a construction; it reduces definability to `SORT-BOUND-U ∈ P`, which is open. No polynomial-time algorithm is known (`problem.md`), and known methods are superpolynomial or polynomial-space/game-based.

None of C1–C4 yields an explicit, correct `FO(LFP)` definition valid for all `n,k`; C4 isolates the exact missing ingredient.

### 3.5 Structural barriers for natural definability attempts

`[deduction]`, consistent with known complexity facts.

1. **Capture/meta-barrier (unconditional).** Because `FO(LFP)=P` on ordered structures, any proof that `SORT-BOUND-U` is *not* `FO(LFP)`-definable would prove `P ≠ PSPACE` (via the known `PSPACE` upper bound). Such a separation is beyond currently reachable methods and out of scope as an unconditional target (`problem.md`). Therefore no absolute non-definability theorem is claimed.
2. **State-explosion barrier for direct state-tabulation formulas.** The direct minimax/DP semantics ranges over partial orders on `n` elements: `2^{Θ(n^2)}` labelled states in general. An `FO(LFP)` definition computes by iterating monotone operators on fixed-arity relations over an `N`-element universe, with at most `N^{O(1)}` stages/tuples per relation. Hence any definition that correctly decides `S(n) ≤ k` by explicitly enumerating, indexing, or storing win/lose information for all (or a frontier of) poset states in separate tuples/stages would require a polynomial-size compression of that state space into `U^{O(1)}`. No such compression is known; the winning-frontier barrier gives `2^{(1/4-o(1)) n log^2 n}` nonisomorphic winning states even at budget `S(n)` (`[literature]`-as-reported-in-repo/paper theorem in `research-winning-frontier-barrier.md`), so frontier-enumerating strategies are excluded. This bars a natural class of "tabulate the recurrence" LFP attempts, though not hypothetical highly compressed representations.
3. **Alternation barrier for the direct game translation.** The exact characterization is an alternating game (`∃` sorter, `∀` adversary) of polynomial horizon on a polynomial-space state description, yielding `APTIME/PSPACE` (Claim A). The descriptive-complexity translation of this form aligns with `FO(PFP)`/`PSPACE` capture on ordered structures, not with `FO(LFP)`/`P`. Removing alternation/determinizing the game evaluation within polynomial time would itself be an algorithmic breakthrough equivalent to the positive answer.
4. **No help from standard complexity barriers against P.** `SORT-BOUND-U` is sparse/tally-like in relevant senses? (it is a tally-threshold language; `problem.md` notes it is trivially in `P/poly` and sparse-set many-one NP-hardness would imply `P=NP`). None of these imply non-membership in `P` or non-definability in `FO(LFP)`; they only limit other routes (circuit lower bounds, routine NP-hardness). Thus there is no known "easy" structural barrier forcing `SORT-BOUND-U ∉ P`.

## 4. Result

**Inconclusive (open), with a classified barrier analysis.**

- **Construction:** No explicit or fully specified schematic `FO(LFP)` sentence defining `SORT-BOUND-U` on `𝔄_{n,k}` for all `n,k` was found. Non-constructively, such a sentence exists iff `SORT-BOUND-U ∈ P` (Immerman–Vardi), which is open `[literature]+[deduction]`.
- **Barrier/falsification:** (i) An unconditional proof of non-definability would imply `P ≠ PSPACE`, so it is out of reach under known complexity facts `[deduction]`. (ii) Direct "tabulate poset states / minimax recurrence" and "encode a strategy/certificate" LFP attempts are blocked by the exponential poset/strategy/winning-frontier state objects versus the polynomial-arity, polynomial-stage nature of `FO(LFP)` over size-`N` inputs `[deduction]`. (iii) The direct alternating-game formulation maps to `FO(PFP)`/`PSPACE`, and no polynomial-time determinization is known `[literature]+[deduction]`.
- **Natural-class refutation achieved:** direct definability attempts that explicitly materialize poset-DP states, winning frontiers, or comparison-tree strategies as LFP-definable polynomial-size objects over `𝔄_{n,k}` are falsified/infeasible given current structural bounds; this does not rule out all possible `FO(LFP)` definitions.

## 6. Exact implication for SORT-BOUND-U

- `SORT-BOUND-U` is `FO(LFP)`-definable on ordered finite structures encoding `1^n#1^k` (as in §2.2) **if and only if** `SORT-BOUND-U ∈ P`, **if and only if** `S_unary ∈ FP` `[literature]+[deduction]`.
- Known: `SORT-BOUND-U ∈ PSPACE` `[deduction/literature]`, hence consistent with `FO(PFP)`-definability on ordered structures but not known to be in `FO(LFP)` `[literature]`.
- A correct explicit `FO(LFP)` definition would be a new polynomial-time upper bound for the unary threshold problem. A proof of non-definability would imply `P ≠ PSPACE` and is therefore beyond currently known techniques consistent with the project's stated frontier. The concrete obstacle for known evaluation methods is representing/adjudicating the exponentially large adversarial poset-game state space within polynomial-arity, polynomial-stage least fixed points over the length-`N` input structure.
