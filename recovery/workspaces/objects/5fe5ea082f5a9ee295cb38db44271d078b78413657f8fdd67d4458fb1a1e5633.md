# Exec report: dfs-backtrack-configuration-lowerbound

## Scope and claim discipline

- **Front (new, falsifiable).** Intrinsic "backtrack configuration" complexity of the exact budgeted DFS for `CanSort`: prove a realizable family forcing `Ω(t log n)` mutable bits for exact undo/resume at depths `t <= c*S(n)`, or exhibit an explicit representation supporting exact undo/resume in `o(t log n)` bits with stated time cost. `[definition, task]`
- **Model / encoding.** Adaptive comparison decision trees on `n` distinct labelled keys; game `G(n,k)` / recurrence `CanSort(P,d)` / transcript-induced poset `P(σ)` as in `docs/problem.md`, `docs/research-certificates-barriers.md` §0, `docs/research-budgeted-dfs.md` §2–3,5. Active encoding is unary: decision input `1^n#1^k`, `N=n+k+1`, `d=k`; function regime uses `d=Θ(S(n))=Θ(n log n)`. Work space means mutable Turing-machine work tape; the read-only input is excluded. `[definition]`
- **Baseline.** The transcript-only pure DFS is a correct backtracking evaluator using a stored comparison path plus control and recomputation workspace: `O((d+n)log(n+2))` bits with BFS reachability (`docs/research-budgeted-dfs.md` §5.2) and `O(d log n + log^2 n)` bits with logspace reachability (prior report `/home/lubko/soring301-exec-compress-exact-space-evaluator-20261117e/exec-report.md`). At `d=Θ(S(n))` both are `O(n log^2 n)` bits. This is an upper bound only; `SORT-BOUND-U ∈ PSPACE` is already known and no class separation is claimed. `[literature/deduction, repository docs]`
- **No overclaim.** This report does **not** exhibit an `o(t log n)`-bit exact undo/resume representation, does **not** prove a universal `Ω(t log n)` lower bound for every possible exact evaluator of `S(n)`, and does **not** separate complexity classes. The positive result is a formal lower bound for an intrinsic *resumable backtrack-configuration* notion on an explicit realizable family (Theorem 1); limitations outside its hypotheses are stated. `[deduction/open]`

## Formal model: backtrack configuration and exact undo/resume

`[definition]` Fix `n>=2` and a deterministic pure budgeted DFS evaluator `A` for `CanSort` on the empty initial order, with budget `d >= 1` (the decision call may use `d=k`; the function-relevant regime is `d>=S(n)`). At any moment of its execution, `A` has a **configuration** `C = (W, R)` where `W \in {0,1}^*` is the mutable work-tape contents (including any stack/path/control representation, but excluding the read-only input and excluding recomputation scratch whose value is not required to persist across the resume event under consideration) and `R` is the read-only finite control / head state.

`[definition]` A **realizable depth-`t` execution point** (`t <= d`) is a point reached by `A` after exactly `t` comparison actions along some root-to-current path consistent with the rules of `G(n,d)`: from a non-total poset the sorter selects an incomparable pair, the adversary selects one of its two orientations, and the transcript prefix is a valid strict partial-order transcript. A configuration is **resumable at depth `t`** if, from that point, `A` can correctly complete the DFS evaluation required by `CanSort` for the original call, including, upon returning from any descendant, restoring the exact parent execution context needed to (i) try the opposite adversary orientation for the same selected pair when that branch is required, and (ii) continue the sorter's scan/selection policy over remaining untried legal moves at that parent when required.

`[definition]` For a set `F` of realizable depth-`t` execution points, let `M_A(F,t)` be the maximum number of mutable bits of `W` used by `A` over points in `F`. Define the intrinsic backtrack-configuration complexity on `F` as
`B(F,t) = inf_A M_A(F,t)` over all correct deterministic exact undo/resume evaluators `A` for the budgeted comparison DFS semantics.

This model isolates *persistent path/control* information from transient recomputation workspace: an algorithm may recompute reachability from a stored transcript, but if it discards information necessary to identify which parent branch/action must be resumed, it is not an exact undo/resume evaluator. `[definition/deduction]`

## Theorem 1: a realizable family forcing `Ω(t log n)` persistent resume bits

**Theorem 1 (`[deduction]`).** Fix constants `0 < c < 1/4` and `n >= 8`. Let `t` be any integer with `1 <= t <= c*n`. There is an explicit realizable family `F_{n,t}` of depth-`t` execution points for budgeted DFS on the antichain over `n` labelled keys such that
`B(F_{n,t}, t) >= t * log2(n^2/4) = Ω(t log n)`.
In particular, since `S(n) >= ⌈log2(n!)⌉ = Ω(n log n)`, for every fixed `c' > 0` and all sufficiently large `n` there is some $c>0$ with `c*n <= c'*S(n)` and hence a realizable family at depths `t <= c'*S(n)` (indeed for all `t` in that initial range) forcing `Ω(t log n)` mutable bits for exact undo/resume.

*Proof.*

1. **Realizable long-prefix family.** Let the root state be the antichain `P_0`. Consider any ordered sequence of `t` vertex-disjoint unordered pairs
   `e_1={u1,v1}, ..., e_t={ut,vt}` with all endpoints distinct (possible because `2t <= 2c*n < n/2 <= n-2` for large enough range; explicitly feasible when `t <= n/2`). Let `σ` be any transcript obtained by, for each step `s<=t`, selecting `e_s` as the sorter's comparison and selecting an arbitrary orientation `(us,vs)` or `(vs,us)` as the adversary answer. Because the pairs are disjoint, adding an orientation of `e_s` never creates a comparability between endpoints of any different `e_r` (`r!=s`) except none: no transitivity path can pass through distinct disjoint new edges before others are added, and endpoints were previously incomparable. Therefore every `e_{s+1}` remains an incomparable pair in `P(\sigma_s)` for all `s < t`, and every such `σ` is a realizable depth-`t` transcript prefix of `G(n,d)` for any `d>=t`. `[deduction]`

2. **Frame-resume distinguishability.** Fix any correct exact undo/resume DFS evaluator `A`. For any realizable point with transcript prefix `σ_{s-1}` and selected pair `e_s`, if the recursive evaluation of the first adversary orientation returns `False` (which is a possible outcome in the game), correctness of DFS requires `A` to resume at depth `s-1` and invoke evaluation of the opposite orientation of the **same** pair `e_s` before trying any different sorter pair. Hence the resumable configuration stored at the moment control is inside/returning to that first branch must distinguish `e_s` from every other incomparable pair that could have been the selected pair at depth `s-1` in some realizable point of the family, whenever those alternatives require different mandatory resume actions. `[deduction]`

3. **Per-level counting.** At step `s`, after `s-1` disjoint comparisons, at least `n-2(s-1)` vertices are untouched and every pair among them is still incomparable. Thus the number of available disjoint choices consistent with extending some family prefix is at least
   `C(n-2(s-1),2) >= C(n-2t,2) >= C(n - n/2,2) = C(⌈n/2⌉,2) >= n^2/16` for `c<1/4` and $n>=8$.
   More tightly, using the actual untouched count at each level, the family of ordered selected-pair sequences realizable by this construction has size
   `Π_{s=0}^{t-1} C(n-2s,2) >= (C(n-2t+2,2))^t >= (n^2/16)^t` for the stated range. For each selected pair there are also two adversary orientations realizable; orientations must be resumable as branch identity in the standard DFS control, but even counting only the selected-pair identity gives the bound below. `[deduction]`

4. **Information bound.** Different selected-pair sequences in item 3 require different resume behavior at the first level where they differ (a different opposite-orientation sibling, hence a different mandatory recursive call on some legal return outcome). Therefore no single mutable configuration value can serve as a correct resumable state for two such execution points; the map from family points to resumable configurations of `A` is injective on this distinction. By pigeonhole principle,
   `2^{M_A(F_{n,t},t)} >= (n^2/16)^t`, so `M_A(F_{n,t},t) >= t*log2(n^2/16) = Ω(t log n)`.
   Taking `inf_A` yields `B(F_{n,t},t)=Ω(t log n)`. ∎ `[deduction]`

**Accounting note.** The bound counts persistent mutable bits required to identify the resumable branch/action history (or equivalent information). It does not count transient reachability workspace, which may be recomputed; and it does not claim optimal constants. `[deduction]`

## Why this does not settle the full `t <= c*S(n)` regime

`[deduction/open]` Theorem 1 is a proved intrinsic lower bound on an explicit realizable family, but it is strongest at depths where many incomparable pairs remain (the disjoint-pair antichain-prefix regime). Extending an `Ω(t log n)` lower bound to all `t` up to `Θ(S(n))` for *all* correct uniform simulators faces obstacles:

- **Realizability/comparability constraints.** After many comparisons, transitive closure can make most pairs comparable, so the per-step choice alphabet may drop far below `n^2`; a global `Ω(log n)` per remaining step must be argued against the actual game-constrained poset evolution, not unconstrained sequences. `[open]`
- **Representation freedom.** An evaluator need not store the literal pair `(i,j)` if it stores equivalent information. A universal lower bound must quantify over all encodings that preserve exact undo/resume (including possible implicit cursor recomputation, canonical path codes, or non-chronological but resumable representations). `[open]`
- **State vs control.** The minimax value depends on `(P(σ),d)`, but resumability additionally depends on unexplored siblings/scan state. Simple counting of posets (A001035, `2^{Θ(n^2)}` overall) or of whole search trees (`2^{O(d log n)}` nodes) does not directly lower-bound persistent *path* bits because DFS stores one path and can recompute state (`docs/research-certificates-barriers.md` §5, prior report §B). `[deduction/open]`
- **No `o(t log n)` construction found.** Candidate compressions were examined against the resume obligation: closure/canonical poset storage loses chronological last action and/or costs `Θ(n^2)` bits; transitive-reduction/path codes must still recover the exact resumable action; control recomputation may reduce cursor fields but not obviously the undo/action history; catalytic/reversible schemes give no explicit ordinary-workspace `o(t log n)` construction here. No correct simulation with proved `o(t log n)` mutable bits and stated time cost is exhibited. `[open]`

- **Falsification attempt (stronger universal lower bound).** Attempted to extend Theorem 1 to arbitrary `t<=c*S(n)` by global counting over all transcripts/posets/nodes: each argument fails for the reasons above (comparability collapse, representation freedom, path-vs-state/tree confusion). No universal theorem obtained. `[deduction/open]`
- **Falsification attempt (upper bound).** Sought an explicit representation with exact undo/resume in `o(t log n)` bits: no closure-only, compressed-history, recomputed-control, catalytic, or reversible scheme yielded a proved correct construction. Falsification of the easy compression routes succeeded; existence of a non-obvious scheme remains open. `[deduction/open]`

## Findings

1. **`[deduction]` (proved, realizable-family lower bound).** There is an explicit realizable family of depth-`t` execution points (disjoint comparisons from the antichain, any `t <= c*n`) on which every correct deterministic exact undo/resume budgeted-DFS evaluator must store `Ω(t log n)` persistent mutable bits (`B(F_{n,t},t)=Ω(t log n)`), by an injective resume-behavior/counting argument on mandatory opposite-branch resumption.
2. **`[deduction]` (intrinsic control/path content).** Exact undo/resume requires persistent information sufficient to restore the selected action and unexplored sibling/control context at each active level; transient recomputation workspace (BFS/logspace reachability) is separable and does not remove this obligation.
3. **`[deduction/open]` (frontier not closed).** Theorem 1 does not by itself force `Ω(t log n)` at every depth up to `Θ(S(n))` for all representations, because late-depth choice alphabets and representation freedom require a stronger realizable incompressibility argument. No `o(t log n)`-bit exact undo/resume representation with stated time cost was found.
4. **`[deduction]` (status).** Known correct simulations remain at `Θ(d log n)` persistent path/control bits (plus recomputation workspace) for depth `d`; improving below this for the decisive `d=Θ(S(n))` regime would require either a new resumable representation or a deeper game-constrained lower bound extending Theorem 1.

## Obstacles

- **Deep realizable family.** Construct, for `t = Θ(S(n))`, a family of DFS execution points whose mandatory resume continuations form a large injective (or high-entropy) set under all correct encodings, despite transitive-closure constraints reducing available incomparable pairs. `[open]`
- **Representation-universal argument.** Prove a lower bound over all resumable encodings (not just literal transcripts/cursors), e.g. via an information/communication invariant preserved by undo/resume. `[open]`
- **Or an explicit counterexample.** Exhibit a concrete exact undo/resume data structure storing `o(t log n)` mutable bits on all realizable depth-`t<=c*S(n)` states, with a correctness proof and time accounting for updates/recomputation. `[open]`

## Next decisive question

Can Theorem 1's disjoint-pair/resume-distinguishability argument be lifted to a realizable family reaching `t = Θ(S(n))` — for example by tracking the entropy of mandatory (pair, branch-phase, scan-state) resumptions along actual `CanSort` executions where many pairs remain incomparable for `Ω(n log n)` steps — thereby proving `B(F,t)=Ω(t log n)` throughout the decisive regime, or else can one design an explicit resumable encoding (compressed cursor/history with certified undo) achieving `o(t log n)` bits on that regime with stated time overhead? `[open]`
