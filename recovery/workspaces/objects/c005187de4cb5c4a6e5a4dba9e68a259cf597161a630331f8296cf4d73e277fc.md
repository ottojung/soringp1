# Independent audit: MDALT whole-configuration rank

**Verdict (paper audit, not theorem completion).** The proposed order is
well-founded *if* the stated frame bounds and finite component domains hold.
The BackE retry cycle's key arithmetic repair is sound: putting `ex` before
`ph` makes the phase reset harmless when the cursor rank strictly falls.
However, the inherited argument does **not** establish the requested
all-reachable-transition claim from definitions alone. Several indispensable
facts are declared as local deductions/assumptions rather than derived from
the concrete transition semantics and invariant; in particular the complete
reachable-state frame table and `I_{M_D}` preservation. Thus this is a
conditional rank proof, not an independently closed proof, and I found no
concrete reachable counterexample trace in these artifacts.

## Evidence and proof obligations

Primary target: [`mdalt-halt-back-e-rank-fix.md`](../mdalt-halt-back-e-rank-fix-20261105/docs/mdalt-halt-back-e-rank-fix.md), §§2–6. The realization schema is
[`fopfp-cks-av-mdalt-dtm-realization.md`](../fopfp-cks-av-mdalt-dtm-realization-20261105/docs/fopfp-cks-av-mdalt-dtm-realization.md), especially §§1–5. The dependent successor case matrix explicitly labels the rank claim inherited, not reproved: [`cks-av-det-succ-enc-case-matrix.md`](../cks-av-det-succ-enc-case-matrix-20261105/docs/cks-av-det-succ-enc-case-matrix.md) §§0, 6.

1. **Order well-foundedness — conditional pass.** The rank note defines
   `V=(bcost,q,ex,ph)` in a finite product (`bcost∈0..k`, `q∈0..2`,
   `ex∈0..n²+1`, `ph∈0..6`) and bounds path depth by `2k+1` (§§2–3).
   Finite products and bounded finite sequences are well-founded under the
   stated lexicographic order. This proves the order claim only once these
   domains, and that every rank is defined on the active path, are justified.
2. **Cursor decrease — arithmetic pass; semantic premise open.** If the chosen
   pair is at/after the cursor and `SuccLex2` stores its strict successor, then
   `idx` rises and `rlex=L-idx` strictly falls (rank note §2). This excludes
   exhaustion as a successful choice. The realization defines `NextIncomp`
   and `SuccLex2` (§1.3), but the rank argument still needs the actual update
   to preserve a well-formed cursor and the stated cursor order on every
   reachable BackE retry.
3. **BackE cycle — conditional pass.** The three transitions listed in rank
   note §5 decrease respectively by `ex`, `ph` at fixed `ex`, and `ex` again.
   The advertised repair works, including the `4→5` phase rise on the last
   transition. This relies on the exact `NextIncomp`/`SuccLex2` premises above
   and the return marker leaving the parent's cursor unchanged.
4. **Pushes — conditional pass.** The table compares the old top frame before
   considering its new child, which is correct for root-to-top lex order.
   A-push decreases `bcost` on the existing parent (or its phase/`q` as listed);
   E-push decreases its existential rank. This requires that precisely those
   parent fields change and lower frames remain fixed. The encoding templates
   in the case matrix assert those updates, while the realization gives
   schema-level macros; a field-by-field derivation for the actual compiled
   DTM is not supplied here.
5. **Pop/return — conditional pass.** Removing the top and marking its parent
   makes the parent the first possibly changed index. The table's decreases
   are plausible for the listed BackA/BackE return phases. They require a
   unique active parent, preserved lower prefix, and exhaustive marker/mode
   combinations. The matrix itself names `Back* + RetNone` at a consuming top
   as a falsifier (§5), rather than proving that such a reachable state cannot
   occur.
6. **Completeness and invariant — not independently discharged.** Rank note
   §3 calls its frame table complete, but its completeness argument appeals to
   `I_{M_D}` coherence and the `D_*` partition. The cited realization §4
   provides a schema/equivalence argument; the rank note §6 inherits invariant
   preservation from the realization/SYM/SYM-TOP chain. The matrix §3.4
   explicitly leaves `BackE/BackA0/BackA1 ∧ RetNone` at unique top as a
   reachability-preservation obligation/falsifier. These are exactly the
   obligations needed to know every reachable state has a rank row and a
   non-halting successor. They are not consequences of lexicographic
   well-foundedness.

## Conclusion

No counterexample trace follows merely from the described push/pop or BackE
phase behavior; under the stated local facts, the rank comparisons cover the
listed non-halting cases. But the falsifiable question as phrased—whether the
order is defined on *all actual reachable configurations* and every actual
non-halting transition strictly decreases it—remains conditional on closure,
frame-table completeness, and fidelity of the concrete macro-updates. The
case-matrix artifact explicitly assumes the rank fix, so it is not independent
corroboration. Closing the claim needs a derivation of those invariant and
transition obligations from the fixed realization (especially exclusion of a
Back* `RetNone` top and exact parent/cursor preservation), not another
well-foundedness argument.

This verdict concerns termination of the specified fixed run under those
conditions only. It gives no uniform time/space bound and implies no
`DET-SUCC` or complexity classification.
