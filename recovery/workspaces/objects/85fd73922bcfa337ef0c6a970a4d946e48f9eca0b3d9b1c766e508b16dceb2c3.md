## 0. Scope, model, and question

**[definition / model — literature + repo contract]** For `n >= 0`, `S(n)` is the minimum worst-case number of pairwise comparisons of a deterministic adaptive comparison decision tree that sorts every permutation of `n` distinct labelled keys (`docs/problem.md`). A state after a comparison history is the transitive closure `P` of observed outcomes, a strict partial order on `[n]` (poset sufficiency: `docs/research-compression-next.md` Lemma 1; Lean correspondence `S_eq_adv_univ`). The minimax value is

`F(P)=0` if `P` is total, else `F(P)=1 + min_{x‖y in P} max(F(P+x<y), F(P+y<x))`, and `S(n)=F(∅)`.

**[definition — this report]** Let `T` be a **height-`S(n)` optimal comparison strategy** (an optimal deterministic policy): at every non-total reachable state `P` it fixes one incomparable pair `(x,y)` with `1+max(F(P+x<y),F(P+y<x))=S(n)-depth(P)`, and has two outcome edges to the successor states. The **directed strategy state graph** `G_dir(T)` is the directed graph whose nodes and edges are one of:

- **(H) history/tree form:** nodes are reachable play prefixes (equivalently, one node instance per visit/path); edges are the two comparison outcomes. For a single deterministic strategy this is an out-arborescence (a rooted decision tree).
- **(L) labelled-poset DAG form:** nodes are the distinct labelled poset states `P` reachable in `T`, identified by equality of `P` (hash-consing by labelled state); directed edges `(P -> P+x<y)` and `(P -> P+y<x)`.
- **(C) canonical optimal-play form:** nodes are equivalence classes of reachable states under a chosen equivalence (e.g. relabelling `S_n`, or `S_n × Z_2` duality, as in `docs/research-compression-next.md`) with a representative per class; outcome edges map to the class of the successor. (This is the quotient analogue of a single optimal play, when such a quotient policy is well-defined; see caveats.)

Let `G(T)` denote the underlying simple undirected graph used for width parameters. **Treewidth** `tw`, **pathwidth** `pw`, and **branchwidth** `bw` are the standard graph parameters on `G(T)` (Robertson–Seymour / standard definitions).

**Question (all `n`, falsifiable).** For optimal strategies `T` achieving height `S(n)`, are `tw(G(T))`, `pw(G(T))`, `bw(G(T))` bounded, polynomially bounded, or provably unbounded in `n`? Compute/bound for small `n` where feasible, give an all-`n` argument or obstruction, and relate bounded width to compact (polynomial-size) certificates/evaluators.

**Evidence labels used:** `[definition]`, `[literature]`, `[deduction]`, `[experiment]`, `[conjecture]`, `[open]`.

## 2. All-`n` structural arguments

### 2.1 History/tree form (H): bounded treewidth, unbounded pathwidth

**[deduction]** A single deterministic comparison strategy is a function from reachable histories/states-on-path to one comparison; each non-leaf yields exactly two outcome children and every node except the root has exactly one parent. Hence `G_dir(T)` in form **(H)** is a rooted full (proper) binary out-tree on its reachable play nodes, and `G(T)` is a tree. For any tree on >=2 vertices, `tw(G(T)) = 1` and `bw(G(T)) = 2` (branchwidth of a nontrivial tree is 2). Therefore **treewidth and branchwidth are bounded (constant) for all `n` and all optimal strategies** in interpretation (H).

**[deduction]** Pathwidth is unbounded as `n -> ∞`. Any optimal strategy has height exactly `S(n)`. A rooted path of `S(n)` comparison edges is a subgraph/ minor-path structure realizable along some root-to-leaf branch, and more generally the pathwidth of a rooted tree is >= 0 and satisfies `pw(T) >= h'`-type? Careful: for a simple path of length `h`, `pw=h`? no, path of `m` vertices has pathwidth 1. The correct relation is: `pw` of a tree is at least `Omega(log L)` in number of leaves and for a complete binary tree of height `h`, `pw = ceil(h/2)` [literature fact: pathwidth of complete binary trees; e.g. follows from standard tree pathwidth characterizations / Scheffler-type recurrences]. An optimal comparison *decision* tree of height `S(n)` sorting all `n!` inputs is a reduced binary tree with `n!` leaves and height `S(n)`; in particular it contains, in the rooted-tree pathwidth sense, large width substructure: the experiment shows `pw = S(n)-1` for `n=3,4,5` for the chosen optimal policy (a highly unbalanced-in-shape? no, height equals `S(n)` on the deepest branch while many leaves appear shallower, which yields large `p2+1`). 

A safe all-`n` bound/obstruction in form (H): `pw(G(T)) <= S(n)` is immediate since the graph has a path/tree decomposition guided by height at most `S(n)` in simple forms? (a path decomposition can follow a DFS in order with bags of ancestors — for a tree, `pw <= h` holds for rooted depth `h` via the standard vertex-separation/path decomposition giving width <= height). Also `pw(G(T)) >= 1` for `n>=2`. Combining with `S(n) = Θ(n log n)` [literature, information-theoretic lower/upper bounds; `docs/problem.md`], we get `pw(G(T))` is **unbounded but polynomially bounded in `n`** (indeed `O(n log n)`, and for the sampled optimal policies `Θ(S(n))`). The exact coefficient/asymptotic of `pw` depends on strategy shape, but boundedness fails while polynomial boundedness in numeric `n` (hence in unary input length `N>=n`) holds.

**[deduction]** Node/edge size in (H): `V = 2*n! - 1`, `E = 2*n! - 2` for any reduced single optimal decision tree (`n!` leaves) — **superexponential/exponential-factorial in `n`**, not polynomial (cf. `docs/research-strategy-certificates.md` Thm 2.1, `docs/research-encoding-consequences.md`).

### 2.2 Labelled-poset DAG form (L), single optimal policy

**[deduction]** In a **reduced** deterministic comparison tree, any comparison on the path from ancestor `u` to descendant `v` is informative, so the linear-extension sets satisfy `L(P_v) ⊂ L(P_u)` strictly; nodes in different subtrees have disjoint extension sets. Hence distinct tree nodes have distinct labelled poset states (`docs/research-strategy-certificates.md` Thm 2.6). Therefore, for a **single** optimal policy, hash-consing by labelled-poset equality merges no nodes: form **(L)** is identical (as a graph) to form **(H)**.

**Conclusion (L, single policy).** For all `n`, `tw=1`, `bw=2` (bounded), `pw` unbounded but `O(S(n))=O(n log n)` (polynomially bounded in `n`), and size `2*n! - 1` (not polynomial). This is consistent with `[experiment]` for `n <= 5`.

### 2.3 Canonical / quotient optimal-play form (C) and all-optimal graphs

**[deduction + literature context]** Quotienting states by relabelling `S_n` (and/or duality) is exact for values (`docs/research-compression-next.md` Lemmas 2, Thm 3) and can compress node counts substantially (e.g. single-policy quotient classes `1,2,4,7,11,27` for `n=1..6` in `docs/research-strategy-certificates.md` Table 2; all-optimal quotients also far below labelled DAGs). However:
- A **single-policy quotient graph** identifies isomorphic but not identical labelled posets; different tree nodes may map to the same canonical class, so the underlying undirected graph can become a DAG (not necessarily a tree). Thus `tw` need not be 1 a priori. I did **not** compute `tw/pw` of these quotient DAGs for `n>=4` here (feasible in principle for the very small quotients up to `n<=6`, but not executed as a width computation in this run).
- The **all-optimal** labelled DAG has large sharing and superpolynomial/exponential observed growth (`DAG(all)=19,181,1551,65551` for `n=3..6`; `docs/research-strategy-certificates.md` Obs. 2.4) but remains a DAG of comparisons; its width parameters are `[open]` from this note.
- **[deduction]** Regardless of width, quotient or DAG size is the binding issue for compactness: no polynomial-size all-`n` optimal certificate is known, and `DAG(all)`/quotient growth evidence is inconclusive but not polynomially established (`docs/research-strategy-certificates.md` §6–7).

**[conjecture/open]** For canonical quotient graphs (C), `tw/pw/bw` may grow with `n`, but establishing “provably unbounded” would require an explicit all-`n` minor/obstruction argument on those specific quotient graphs; none is provided here.

## 4. Relation to compact (polynomial-size) certificates/evaluators

**[deduction]** *Bounded width ≠ compactness.* In forms (H)/(L) the width is minimal (`tw=1`) yet the representation has `Θ(n!)` nodes, so it is not a compact (polynomial-size, in `n` or in unary input length `N=n+k+1`) certificate or evaluator. Thus low treewidth/pathwidth of the **execution/state tree itself** does not imply existence of a succinct certificate.

**[deduction]** *Compactness is primarily a size (and verifiability) condition.* A polynomial-size strategy DAG/certificate with a polynomial-time verifier would be relevant to unary `NP` membership of `SORT-BOUND-U` (`docs/research-framed-certificate-frontier.md` §1, `docs/research-strategy-certificates.md` Thm 1.1, Remark 1.3): soundness/checkability is polynomial in explicit graph size, but **no all-`n` polynomial-size completeness at exact budget `S(n)` is known**. Size, not treewidth of the per-play tree, is the bottleneck in that route.

**[deduction]** *Where width can matter (conditional).* If one had a **polynomial-size** certificate/evaluator graph `D_n` (e.g. a framed/merged DAG encoding many plays) whose underlying undirected graph had **bounded treewidth** (or bounded pathwidth), then many graph predicates/evaluations admit linear-time dynamic programming in `|D_n|` for fixed width (Courcelle/MSO-style results) and path decompositions support space-efficient evaluation. Conversely, large/unbounded width in such a compact `D_n` would indicate more global sharing/entanglement. However, this is conditional: (i) existence of polynomial-size `D_n` for optimal `S(n)` is `[open]`; (ii) I give no all-`n` width bound for candidate framed/merged certificate DAGs here.

**[deduction]** *Evaluators vs strategy graphs.* Computing/evaluating `S(n)` exactly need not materialize a full strategy graph: memoized/DFS minimax over posets, budgeted DFS, or symbolic methods can be viewed as evaluators with different state graphs. The winning-frontier barrier (`docs/research-winning-frontier-barrier.md`) rules out methods that must enumerate the full winning frontier (a different object), but does not constrain width of a hypothetical compact evaluator except through what it must represent.

## 5. Obstructions, limits, and open points

- **[deduction]** “Provably unbounded pathwidth” in (H)/(L) follows from growth of `S(n)=Ω(n log n)` together with decision-tree structure (height/shape), while polynomial boundedness `O(n log n)` holds; this is an all-`n` structural fact, not a computational hardness result.
- **[open]** Width parameters of **canonical quotient** single-policy DAGs and of **all-optimal** DAGs/certificates at exact `S(n)` for all `n`.
- **[open]** Existence of any polynomial-size optimal strategy certificate/evaluator for all `n` (hence any width question on such a compact object is downstream). Relation to unary `SORT-BOUND-U ∈ NP?` remains open (`docs/research-framed-certificate-frontier.md`).
- **Falsification tried:** possibility that hash-consing a single optimal policy yields a non-tree (enabling larger/smaller widths) — **falsified in general for reduced single policies** by distinct-poset argument (Thm 2.6 logic) and by `[experiment]` `E=V-1` for `n<=5`.

## 6. Bottom line

- **Bounded:** `tw(G(T))=1`, `bw(G(T))=2` for the state graph of any height-`S(n)` optimal comparison strategy in the natural single-strategy history/labelled-state readings (it is a tree). **[deduction/experiment]**
- **Unbounded but polynomially bounded:** `pw(G(T))` is unbounded in `n` but `O(S(n))=O(n log n)` (polynomial in numeric `n` and in unary input length). **[deduction/experiment]**
- **Compact certificates:** bounded width of this strategy tree does **not** yield polynomial-size certificates/evaluators (the tree has `2*n!-1` nodes). Compactness hinges on polynomial graph size (open for exact optimal strategies); bounded treewidth/pathwidth would only become an additional useful structural property if such compact representations existed. **[deduction/open]**
