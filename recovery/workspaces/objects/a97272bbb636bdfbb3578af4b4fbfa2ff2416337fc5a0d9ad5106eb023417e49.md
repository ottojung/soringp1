# Rank-envelope framed-certificate frontier: completeness on small `n` (exec report)

**Front:** `rank-envelope-framed-completeness-n7`  
**Status:** research report (definitions, experiments for `n <= 6`, deductions, feasibility note for `n=7`). Not Lean-checked. No claim of NP membership, hardness, or an all-`n` completeness/separation theorem.

## Question and consequence

Prior report `soring301-exec-framed-certificate-bounded-completeness-smalln-20261117f` showed the fixed-width framed class `W(w)` is trivially incomplete at the root antichain (`width(R_root)=n`) and measured semantic optimal-policy parameters for `n <= 6`. This run addresses the posed next step:

> define a nontrivial checkable framed class `C(n)` (e.g. rank-envelope grammar with parameter `r(n)`, or controlled-forgetting joins) excluding the trivial root-width obstruction, test optimal-height realizability for `n <= 6` and `n=7` if feasible with measured parameters, seek a first incompleteness witness or a rigorous lower bound forcing superpolynomial growth.

**Consequence (if resolved positively/negatively):** a natural, verifier-checkable framed/certificate grammar that is complete at height `S(n)` with polynomially bounded parameters for all `n` would be evidence toward succinct witnesses for `SORT-BOUND-U`; a concrete optimal-height incompleteness witness for such a class, or a forced superpolynomial parameter growth, would be a barrier for that certificate route. Neither outcome by itself settles NP membership of `SORT-BOUND-U` (see `docs/research-framed-certificate-frontier.md`, `docs/research-strategy-certificates.md`, `docs/problem.md`).

## Model and baseline (fixed)

- **[definition/literature]** Deterministic adaptive comparison sorting of `n` distinct labelled keys; `S(n)` is the minimax worst-case comparison height (`docs/problem.md`, `docs/research-strategy-certificates.md` §0). Known values used: `S(1..6)=0,1,3,5,7,10`; `S(7)=13` is literature-known (`docs/problem.md`).
- **[definition/tooling]** Framed/permutation-DAG certificates with propagated guaranteed strict partial orders `R_v`, transitive closure, slot relabelling, and intersection at joins are as in `scripts/check_framed_strategy.py` and `docs/research-framed-certificate-frontier.md`. Soundness of that grammar is polynomial-time checkable in explicit size; completeness at optimal height `S(n)` is open.
- **[experiment]** For `n <= 6`, exhaustive minimax values `F(P)` over all reachable labelled posets and the set of all optimal-reachable states were computed by the standard recurrence (same model as `scripts/strategy_dag_probe.py` / `scripts/state_compression.py`), using bitmask successor-matrix states and transitive-closure updates. Policy realizability questions were decided by memoized AND/OR search over optimal moves (proposer chooses an optimal comparison, adversary chooses outcome, property must hold on all reached states).
- **[experiment/feasibility]** `n=7` was **not** completed. A full reachable-poset minimax run over `A001035(7)=6,129,859` labelled states was started in pure Python (same approach that takes ~2.13s / 130,023 states for `n=6`) and exceeded a 120s budget without completing; completing `n=7` here likely requires an optimized/compiled implementation, stronger pruning, or a quotient/memory-bounded method. No `n=7` optimal-realizability measurement is claimed.

## Nontrivial checkable classes excluding root-width obstruction

### Class A: active-width framed certificates `AW(w)` (controlled-activity envelope)

**[definition, checkable]** For a guaranteed strict partial order `R_v` on `n` slots, let
- `A(R_v) ⊆ [n]` be the *active* elements: those comparable to at least one other element in `R_v` (incident to some strict relation), and
- `aw(R_v) = width(R_v |_{A(R_v)})` be the width (maximum antichain size, Dilworth width) of the induced subposet on active elements, with `aw(empty)=0`.

A framed certificate/policy state is in `AW(w)` if `aw(R_v) <= w`.

**Root obstruction excluded by construction:** `R_root` is empty, so `A(R_root)=∅` and `aw(R_root)=0 <= w` for any `w >= 0`. The parameter is therefore not forced to `n` by the initial antichain; it measures antichain complexity only among elements already placed into comparisons/relations (an "active envelope").

**Checkability:** from an explicit `R_v` (or successor matrix), compute `A(R_v)` and exact width of the induced subposet; for small `n` exact by subset antichain test, in general by standard comparability/chain-cover algorithms. Polynomial in explicit certificate size.

**Optimal realizability question:** does some height-`S(n)` strategy keep every reached state in `AW(w(n))`?

### Class B: pendant rank-window envelope `PRE` (strict rank-envelope grammar)

**[definition, checkable]** A state/guarantee `R_v` is in `PRE` if there exist a *backbone chain* `B ⊆ [n]` (totally ordered by `R_v`) and pendant set `P = [n] \ B` such that:
1. **No pendant-pendant relations:** for all distinct `p,q ∈ P`, `p,q` are incomparable in `R_v`.
2. **Rank-window constraints to backbone:** for each `p ∈ P`, its relations to elements of `B` are consistent with some insertion interval in the chain order of `B` (equivalently, the set of backbone elements incomparable to `p` forms a contiguous rank window; elements below/above that window are below/above `p`, as forced by transitivity for comparisons against a chain).
3. No other relations are required except those implied.

Parameters measured when a decomposition exists: `r(R_v)=|P|` (pending count) and `win(R_v)` = maximum number of backbone elements incomparable to any single pendant (window width in backbone elements).

**Rank-envelope motivation:** this formalizes a backbone-plus-pending-insertion envelope in the spirit of `docs/research-framed-certificate-frontier.md` §3 (rank windows / pending insertions), restricted to states where pending elements remain mutually unconstrained except through the backbone. It is a **strict** grammar (stronger than general interval constraints allowing pendant-pendant orderings).

**Root obstruction excluded by construction:** for the root antichain, take any singleton backbone `B={b}` and `P=[n]\{b}`: all pendants are pairwise incomparable and each has a valid window against `B` (incomparable to `b`), so `R_root ∈ PRE` with small window parameter (e.g. `win=1` in the tested decomposition choice). Thus membership is not ruled out by the empty initial guarantee; difficulty comes from maintaining the envelope under optimal comparisons.

**Checkability:** for given `R_v,n`, test existence of such `(B,P)` by enumerating candidate backbone subsets/chains and verifying conditions 1-2 (exact and easy for `n <= 6`; exponential in `n` in worst case but explicit and finite). An explicit framed certificate could carry `(B,P,windows,perm)` annotations making local checks polynomial in annotation size.

**Optimal realizability question:** can some height-`S(n)` strategy keep every reached state in `PRE` (and with what parameter profile)?

## Findings and claim types

1. **[deduction] `AW(w)` removes the trivial root-width obstruction by construction.** Because `aw(R_root)=0`, incompleteness of `AW(w)` for large `n` cannot follow from the empty root antichain alone (unlike `W(w)` where `width(R_root)=n`). Any limitation must arise from relations created along optimal play.
2. **[experiment] `AW(w)` is optimal-height realizable with small width on `n <= 6`.** Minimal policy widths are `0,1,2,2,3,3` for `n=1..6`. At `n=6`, the union of all optimal-reachable states reaches `aw=4` but there exists an optimal policy confined to `AW(3)`, showing policy choice matters and the nontrivial class can be strictly easier than the all-optimal envelope.
3. **[experiment] `AW(w)` parameter growth evidence is limited (no asymptotic bound).** Measured policy widths grow slowly on `n<=6` but this range is far too small to distinguish constant/`O(log n)`/`O(n^α)`/superpolynomial behavior. **No** rigorous lower bound forcing superpolynomial growth of `w(n)` for `AW` was obtained; **no** polynomial upper bound is established.
4. **[deduction] `PRE` is a nontrivial, root-admissible, checkable rank-envelope grammar.** The root is in `PRE` by explicit decomposition, so failure (if any) is structural, not the root-width artifact.
5. **[experiment] First policy-level incompleteness witness for strict `PRE` at `n=5`.** For `n<=4`, some optimal-height strategy remains inside `PRE`; for `n=5` and `n=6`, **no** optimal-height strategy can keep all reached states in `PRE` (every optimal move choice can be met by outcomes forcing exit from the class at some reached state). This is a concrete small-`n` incompleteness/obstruction for this strict pendant rank-window envelope grammar as an optimal-certificate class.
6. **[experiment] The `PRE` obstruction is semantic and appears early.** Non-member optimal-reachable posets already exist at `n=4` (e.g. two disjoint comparable pairs), but become unavoidable for optimal policies at `n=5`. The obstruction corresponds to optimal play creating relations among elements that would need to remain simultaneous mutually-unconstrained pendants of a single backbone.
7. **[open] Relaxed/controlled-forgetting rank-envelope grammars.** A more permissive envelope (allowing controlled pendant-pendant relations, bounded weakening/intersection loss at joins, or multiple envelopes with certified merge rules as in frontier §3-§4) may remain complete where strict `PRE` fails; this was **not** formalized or tested here. Such relaxation is the natural next refinement to exclude the observed obstruction without reintroducing the root-width triviality.

No result above implies `SORT-BOUND-U ∈ NP`, `SORT-BOUND-U ∉ NP`, or any separation.

## n=7 feasibility (measured)

- **[literature]** `S(7)=13`.
- **[experiment/feasibility]** Exhaustive labelled-poset minimax/value enumeration for `n=7` (`6,129,859` states) did not finish within 120s in the pure-Python prototype used for `n<=6`. Estimated scaling from `n=6` (130,023 states, ~2.13s) suggests ~100s+ in optimized low-level code under favorable memory locality, but Python object/dict overhead and memory pressure make completion uncertain in this environment; no result obtained.
- **[deduction]** Therefore optimal-height `AW`/`PRE` realizability and parameter measurements for `n=7` remain **open in this run**. Feasible next step: implement a compact integer-array/bitset DP (or reuse/extend a compiled evaluator) and, if needed, restrict to optimal-reachable states on-the-fly or quotient by relabelling to test `AW(w)` / envelope membership at `n=7`.

## Obstacles

- **Strict envelope fragility:** simple, globally-checkable rank-envelope forms (pendants independent except via one backbone) can be broken by locally optimal comparisons that relate pending elements; completeness likely requires a richer join/forgetting grammar with sound local checks (frontier §1, §4).
- **State explosion at `n>=7`:** full reachable labelled-poset analysis crosses from 1.3e5 (`n=6`) to 6.1e6 (`n=7`) states and grows rapidly thereafter; policy/realizability tests need efficient representations.
- **Expressivity vs verifiability:** allowing intersection/weakening joins can compress DAGs but any admitted forgetting must preserve soundness (`lambda`/information-loss discipline, frontier §4) and remain polynomial-time checkable.
- **Class design bias:** incompleteness of strict `PRE` is a barrier for that grammar, not for all rank-envelope-framed certificates.

## Next decisive question

Can a **relaxed, verifier-checkable rank-envelope/controlled-forgetting grammar** `RE(n,t)` (e.g. a backbone with bounded window parameters allowing certified pendant-pendant relations or a bounded number/amount of intersection-weakened joins, with explicit local annotations) be defined so that it (a) excludes the root-width obstruction by construction, (b) remains optimal-height realizable for `n<=6` where strict `PRE` already fails (`n=5,6`), and (c) is testable at `n=7` with measured parameter growth under an efficient/quotiented evaluator? A concrete discriminating experiment is: specify the minimal relaxation needed to repair the `n=5` `PRE` policy obstruction, implement its membership/check on optimal-reachable states for `n<=6`, and determine whether the required relaxation parameter stays bounded or forces growth consistent with a superpolynomial barrier at `n=7`.
