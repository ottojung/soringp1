# Exec report: succinct canonical state / non-path control for exact `S(n)` evaluation

**Task (falsifiable question).** Can exact evaluation of `S(n)` or `SORT-BOUND-U` avoid storing an explicit comparison transcript path by using a succinct canonical state representation (symmetry quotients, DAG/state compression, implicit reachability) in a non-DFS or alternative exact algorithm, achieving `o(N log N)` space with a stated correct time bound? Provide a concrete scheme with correctness/space/time analysis, or a precise obstruction/barrier showing why canonical/succinct state control cannot beat path storage for all relevant instances.

## 1. Problem and baseline (context)

- **[definition]** `S(n)` is the minimum worst-case number of adaptive pairwise comparisons to sort `n` distinct labelled keys; `SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }` has actual unary input length `N = n + k + 1` (`docs/problem.md`, `AGENTS.md`).
- **[definition]** Exact evaluation is the minimax/alternating game on transitively closed strict partial orders: from state `P`, sorter picks an incomparable pair, adversary answers, state becomes `closure(P ∪ {answer})`; `S(n) <= k` iff sorter wins within `k` comparisons (`docs/budgeted-dfs.md` §1,3; `S_eq_adv_univ` correspondence noted in `AGENTS.md`/`problem.md`).
- **[paper proof, recorded]** Budgeted transcript-only DFS decides `SORT-BOUND-U` in deterministic time `2^{O(N log(N+2))}` and work space `O(N log(N+2))` bits by storing the current comparison transcript `σ` (one pair per frame, depth `d=k <= N`), a cursor, and one reachability workspace `O(n log n)`; comparability is recomputed on demand from `σ` on a read-only view of the path (`docs/research-budgeted-dfs.md` §5.2–5.3). This *is* an explicit comparison-transcript path representation.
- **[literature/deduction, recorded]** `SORT-BOUND-U ∈ PSPACE` (game/APTIME characterization) and sparsity/circuit barriers apply (`docs/problem.md`); the active frontier includes smaller space/time upper bounds and barriers (`AGENTS.md`, `docs/research-plan.md`).

**Target inequality.** The question asks for `o(N log N)` work space (sublinear in the baseline `O(N log N)` bit bound for the unary threshold decision procedure) while retaining an exact, uniform algorithm with a stated correct time bound.

## 2. What "succinct canonical state" can and cannot buy (deductions from recorded results)

### 2.1 Exact symmetry quotients are value/move reductions, not a per-path storage reduction below the transcript

- **[paper proof/deduction, recorded]** Relabelling `S_n` and order duality give exact state/value symmetries (`F(πP)=F(P)`, `F(P^op)=F(P)`), and `Aut(P)` orbits give an exact move reduction (Theorem 5) (`docs/research-compression-next.md`). Module reversal is **not** an exact symmetry of `F` in general (fails at `n=7`, prime quotients) though interval modules are sound (`docs/research-orientation-modules.md`).
- **[deduction]** A symmetry quotient helps by identifying states *across* the search (fewer stored/visited classes) or by pruning moves, but it does not by itself eliminate the need to represent the *current* game position along a single exploration branch. A canonical representative of a labelled poset is still a description of an `n`-element poset: a naive explicit form is an `n×n` relation/closure (`Θ(n^2)` bits, worse than `O(N log N)` whenever `n^2 / (N log N)` is large) or a graph encoding of comparable size in the dense worst case. Therefore, replacing "transcript" by "explicit canonical state object" does **not** yield `o(N log N)` space in general for relevant instances (in particular when `n` is comparable to `N`, e.g. moderate `k`).
- **[deduction]** Conversely, the transcript `σ` is already a *succinct generator*: `t <= d <= k` comparisons, each `O(log n)` bits, total `O(d log n)` bits, from which the full closure is recoverable by reachability in polynomial time per query. Any method that, at a node, must support (i) testing whether the induced order is total, (ii) enumerating/testing incomparable pairs, and (iii) producing both adversary successors, must have access to information equivalent to the current strict partial order (the sufficient statistic, Lemma 1 in `docs/research-compression-next.md`). There is no general guarantee that this sufficient statistic has a representation of `o(d log n)` bits uniformly over all reachable paths of length `d = Θ(N)`; in particular, paths can encode `Θ(N log N)` bits of comparison choices at that scale.

### 2.2 Non-DFS / frontier / "DAG/state compression" alternatives hit the winning-frontier barrier

- **[paper proof, recorded]** For infinitely many `n`, at a common depth `t <= k` (including `k = S(n)` up to the recorded asymptotic extension), there are at least `2^{(1/4-o(1)) n (log n)^2}` pairwise **nonisomorphic** reachable *winning* partial orders `P` with `F(P) <= k-t` (`docs/research-winning-frontier-barrier.md`). A finite witness has `n=224`, `> 2^39` nonisomorphic winning states at one depth.
- **[deduction]** Any exact algorithm whose control strategy stores, materializes, or explicitly indexes a *frontier* of simultaneously live winning states/classes at such a depth (e.g. BFS/level-synchronous expansion over states, explicit DAG/state-graph memoization of the reachable winning subgame, or any "keep all states at depth t" compression scheme) requires at least one bit/token per represented state up to its representation, hence `2^{Ω(n (log n)^2)}` space in the worst documented instances—astronomically larger than `O(N log N)`, and exponential in numeric `n`. This is an **enumeration/frontier-storage barrier**, not a time lower bound (`docs/research-winning-frontier-barrier.md`, "What this theorem excludes (and does not)").
- **[deduction]** "DAG/state compression" that merges identical *states* (not just paths) therefore cannot achieve `o(N log N)` space on these instances unless it avoids retaining the full live frontier; but avoiding the full live frontier while exploring a general minimax DAG by non-path methods requires either recomputation (see 2.4) or a path-like stack discipline.

### 2.3 Implicit reachability / game-tree recomputation trades space down poorly in time (and not below baseline here)

- **[deduction]** A Savitch-style (or generic divide-and-conquer over configuration graphs) evaluation of a game/search tree of size `T = 2^{O(N log N)}` nodes/depth parameterized appropriately would target space on the order of `(log T)^2 = O((N log N)^2)` in the usual reachability form, or otherwise incur large recomputation overheads; this is **worse** than `O(N log N)` space, not `o(N log N)`. No project result establishes a sub-`O(N log N)` implicit-reachability scheme for this minimax game.
- **[deduction]** Depth-first path storage is the standard way to evaluate an AND/OR (minimax) tree in space proportional to depth times state/token size; the transcript form achieves `O(d log n)` for the path tokenization, which is already near the information in the chosen move sequence.

### 2.4 Encoding/instance caveat (all relevant instances)

- **[deduction]** "All relevant instances" of `SORT-BOUND-U` include cases with `n = Θ(N), k = Θ(N)`, where `O(N log N) = O(n log n)` and `n^2`-bit state objects are not `o(N log N)`. It also includes small-`k` regimes where `d=k` is the controlling depth (`docs/research-budgeted-dfs.md` §5.3), but a uniform scheme must meet the bound across the family. Any proposed canonical/succinct-state replacement must be analyzed against this full unary regime.

## 3. Concrete "alternative" scheme considered (and why it fails the target)

**Scheme S (canonical-state DFS, non-transcript state).** Run the same exact minimax DFS/backtracking control (to avoid frontier explosion), but store at each frame a canonical isomorphism-class representative of the current poset (under `S_n`, duality, or a stronger sound quotient, when available) instead of the raw transcript; recompute legal moves/successors from that canonical state.

- **Correctness:** **[deduction, conditional]** Correct **only if** the quotient is a sound DP state quotient with a well-defined equivariant transition (states *and* moves); relabelling/duality satisfy this, but comparability-graph/MDT/module-reversal quotients fail in general (`docs/research-compression-next.md` §4,6c; `docs/research-orientation-modules.md`), so an "aggressive" canonicalization can be unsound.
- **Time:** **[deduction]** Canonicalization and/or automorphism/orbit computation adds overhead (e.g. `O(n!)` naive automorphisms noted in `docs/research-compression-next.md` §7; practical canonical labeling is nontrivial) on top of `2^{O(N log N)}` node exploration in the worst case; no stated asymptotic time improvement follows from recorded results.
- **Space:** **[deduction]** Still one state per depth level: `O(d)` frames × (bits to represent a canonical poset/class key plus workspace). In general a canonical labelled/unlabelled poset key is `Ω(n)` to `Θ(n^2)` bits in explicit forms, so total `Ω(d * f(n))` which is **not** `o(N log N)` uniformly (and can be far larger when `f(n)=Θ(n^2)`). Hence Scheme S does **not** achieve the target `o(N log N)` space.

**Conclusion on Scheme S:** **[deduction]** no concrete canonical-state variant identified here meets `o(N log N)` space with correctness for all relevant instances.

## 4. Overall assessment (answer to the falsifiable question)

- **Concrete `o(N log N)`-space scheme:** **[open / not found]** No concrete scheme was identified in the cited project results, nor derived here, that (a) avoids storing an explicit comparison transcript path, (b) is exact and uniform for `S(n)` / `SORT-BOUND-U`, (c) achieves `o(N log N)` work space on all relevant unary instances, and (d) comes with a stated correct time bound. The closest recorded exact upper bound remains transcript-path DFS at `O(N log(N+2))` space (`docs/research-budgeted-dfs.md`).
- **Precise obstruction/barrier (why the obvious routes fail):** **[deduction from recorded paper proofs/deductions]**
  1. **Frontier explosion blocks non-path state retention:** any method that keeps the live winning/state frontier (BFS/DAG memo of frontier states) incurs `2^{Ω(n (log n)^2)}` states in documented instances, far exceeding polynomial/`o(N log N)` space (`docs/research-winning-frontier-barrier.md`).
  2. **Per-node representation does not beat transcript in general:** the current partial order is the sufficient statistic; an explicit or canonical state encoding is `Ω(d log n)` to `Θ(n^2)` bits in general regimes, while the transcript is already a `O(d log n)`-bit generator with on-demand reachability—so substituting a "succinct canonical state object" for the path does not yield a uniform `o(N log N)` guarantee (`docs/research-budgeted-dfs.md` §5.2, `docs/research-compression-next.md`).
  3. **Implicit/recomputation alternatives are space-worse here:** generic implicit reachability over the exponentially large game graph gives bounds like `O((N log N)^2)` or heavy time blowups, not `o(N log N)`.
  4. **Soundness constraint:** many tempting compressions/quotients (comparability graph, MDT, general module reversal) are not sound DP states for `F`, limiting admissible canonicalization (`docs/research-compression-next.md`, `docs/research-orientation-modules.md`).

**Net conclusion:** **[deduction]** Within the analyzed space of alternatives (symmetry/canonical quotients, DAG/frontier storage, implicit reachability, non-DFS state retention), there is a **barrier/obstruction package**: frontier-retaining methods are ruled out on space by the winning-frontier barrier, and path-avoiding per-state substitutions do not improve the `O(N log N)` transcript-path accounting on all relevant instances (and can worsen it or break correctness). This does **not** constitute a proof that *no conceivable* algorithm can achieve `o(N log N)` space—only that no such scheme is established and the recorded structural barriers block the natural succinct-state/non-path routes. **[open]** Whether `SORT-BOUND-U` is decidable in `o(N log N)` bits (e.g. `O(N)` or polylogarithmic) remains open, consistent with `docs/research-plan.md` and `docs/research-budgeted-dfs.md` §13.
