## 1. Problem statement and `S(8)` baseline

We study explicit, checkable permutation-framed strategy DAG certificates for deterministic adaptive comparison sorting of `n` distinct labelled keys, as specified by:

- [`docs/problem.md`](docs/problem.md): `S(n)` is the optimal worst-case adaptive comparison count; active target is unary `SORT-BOUND-U = {1^n#1^k : S(n) <= k}`.
- [`docs/research-framed-certificate-frontier.md`](docs/research-framed-certificate-frontier.md): framed certificate grammar, soundness of the local checker, and open question whether every true instance has a polynomial-size certificate at exact budget `S(n)`.
- [`scripts/check_framed_strategy.py`](scripts/check_framed_strategy.py): executable soundness/depth checker (propagates guaranteed strict partial orders, intersects incoming branches, checks feasible outcomes/permutations, computes longest reachable path).

**Question (this front):** Does there exist an explicit, checkable permutation-framed strategy DAG certificate of exact height `S(8)=16` for `n=8`, and what is its concrete size/depth/profile compared to polynomial envelopes (e.g. `O(n^2)` nodes, `O(n log n)` path length)?

**Baselines (literature / repo-stated, not re-proved here):**
- `docs/problem.md` states the sorting-number literature knows `S(7)=13`, `S(8)=16`, `S(12)=30`.
- Information-theoretic lower bound: `ceil(log2(8!)) = ceil(log2(40320)) = 16`, so any correct certificate of height 16 for `n=8` is exact-optimal in height.
- Ford–Johnson / merge-insertion upper bound `F_FJ(n)=∑_{j=1}^{n} ceil(log2(3j/4))` gives `F_FJ(8)=16` (computed locally; see Methods). This matches `S(8)` **(arithmetic fact + literature baseline; not by itself a constructed framed DAG witness)**.
- Polynomial envelopes named in the question: `O(n^2)` nodes and `O(n log n)` path length; for `n=8`, `n^2=64`, `n log2 n = 24`.

**Not produced/verified in this run.** No file in this worktree is a checker-accepted framed certificate with `n=8` and depth `<=16`.
