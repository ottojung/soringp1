### 1. Definitions
- Finite posets `A,B` on disjoint ground sets. `A^op` is the dual (all relations reversed). `+` denotes disjoint (parallel) union: internal relations of `A` and `B` preserved, every cross pair incomparable.
- `F(P)` = exact minimax adaptive comparison-sorting cost (minimum height decision tree / minimax value over poset states):
  - `F(P)=0` if `P` is total;
  - `F(P)=1 + min_{x,y incomparable in P} max(F(P+(x<y)), F(P+(y<x)))` otherwise,
  where successors are transitively closed. Model consistent with `docs/problem.md`/`docs/upper-bound.md` and repo scripts (`scripts/benchmark_symmetry_quotients.py`, `scripts/parallel_module_probe.py`, `scripts/budgeted_pruning_experiments.py`).
- Defect `D(A,B)=|F(A^op + B) - F(A + B)|`.
- Question: is `D(A,B) <= 1` for all finite `A,B`, or can it be arbitrarily large?

### 2. Method (computational, exact only)
- **Two exact solvers implemented and cross-checked** (`defect_probe.py`):
  1. **Poset-state minimax with memoization**: states are transitively-closed successor-bitmask tuples (bit `j` of `succ[i]` iff `i<j`), DFS minimax over incomparable pairs with memo table per query.
  2. **Extension-set minimax with memoization**: state is the frozenset of all linear extensions consistent with the current poset (rank arrays), each comparison splits extensions by relative order of the queried pair; minimax over extension states.
- **Cross-check agreement**:
  - Exhaustive over all ordered pairs `(A,B)` with `|A|+|B| <= 5`: **246 pair-instances** (both `F(A+B)` and `F(A^op+B)` forms) — solvers agree on every case.
  - All individual unlabelled poset classes for `n <= 6` (1+1+2+5+16+63+318 = 406 classes): solvers agree.
  - Random sample of **100 ordered pairs** with `|A|+|B| == 6` (both forms): solvers agree.
  - Additional sanity: poset-state solver agrees with precomputed `F` from `quotient_classes` for all `n<=7` classes.
- **Enumeration (unlabelled posets, exhaustive)**: used `quotient_classes(n)` / `make_refined_canon(n)` from `/home/lubko/soring301/scripts/benchmark_symmetry_quotients.py` (2-D colour refinement + lex-min canonical form over colour-preserving relabellings; complete isomorphism invariant). Class counts match OEIS A000112: n=0..8 → 1,1,2,5,16,63,318,2045,16999. (`genposetg` available at `/home/lubko/soring-scratch/antichain-abc/nauty2_8_8/genposetg` for poset generation; class enumeration/F tables obtained via quotient machinery as above.)
- **Exact computation of D**: for each total `n=|A|+|B|`, enumerated all ordered pairs of unlabelled posets `(A,B)` with sizes summing to `n` (`sum_{a+b=n} A000112(a)*A000112(b)` pairs). Computed `F` for all unlabelled posets of size `n` via iso-quotient DP (`quotient_classes(n)`) to obtain exact `F` table keyed by canonical rep; then for each pair formed `A+B` and `A^op+B`, canonicalized, and looked up exact `F` values. `F(A^op)` dual computed by `dual()`; disjoint union by block-shift encoding (`disjoint_union(A,B)=A ++ [m<<|A| for m in B]`), matching `parallel_module_probe.py`.

### 4. Boundary / limits (honest)
- **Exact boundary fully covered (exhaustive):** all ordered pairs `(A,B)` of unlabelled posets with `|A|+|B| <= 8` (46,481 pairs total across totals 0..8; 19,368 distinct union canonical reps encountered across nonempty totals).
- **Not covered:** `|A|+|B| >= 9` not computed (n=9 would require 183,231 unlabelled poset classes / F values and substantially more canonicalization work; not attempted here as “cheap”). No claim for n=9,10.
- **No theorem:** `max D=0` on all `n <= 8` is finite exhaustive evidence only; it does **not** imply `D(A,B) <= 1` (or `D=0`) for all finite `A,B`, nor that `D` is bounded/unbounded in general. Either outcome (a universal bound, including 0 or 1, or an unbounded defect / a first `D>=2` witness at larger size) remains open by this computation.
- This is a computational boundary report, not a proof and not a disproof.
