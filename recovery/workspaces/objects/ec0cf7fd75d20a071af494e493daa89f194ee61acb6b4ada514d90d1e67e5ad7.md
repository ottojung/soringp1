## 1. Fixed signature and ordered input structure (obligation i)

`[definition]` Input word `w=1^n # 1^k`, length `N=n+k+1`.
```text
A(w) = (W, <, One, Hash),   W={1,...,N},   Hash={n+1},   One=W\{n+1}.
```
`<` is the standard linear order. `Succ(x,y)`, `Min(x)`, `Max(x)` are FO-definable from `<`.

FO parameters/guards (AC-independent):
```text
HashPos(h)      := Hash(h) ∧ ∀z(Hash(z)->z=h).
WellFormed_w    := ∃h HashPos(h) ∧ ∀h(HashPos(h)->∀x(One(x)<->x!=h)).
Malformed       := ¬WellFormed_w.

Key(x)          := ∃h(HashPos(h) ∧ x < h).                 -- {1,...,n}
Ctr(t)          := ∃h(HashPos(h) ∧ (t=h ∨ h < t)).         -- {0,...,k}, 0 = hash
Zero(t)         := HashPos(t).
MaxK(t)         := Ctr(t) ∧ ¬∃s(Ctr(s) ∧ t < s).
SuccCtr(t,s)    := Ctr(t) ∧ Ctr(s) ∧ t < s ∧ ¬∃z(Ctr(z) ∧ t < z ∧ z < s).
HasBudget(t)    := ∃s SuccCtr(t,s).
KeyNe(x,y)      := Key(x) ∧ Key(y) ∧ x!=y.
Lex2(x,y,x',y') := x < x' ∨ (x=x' ∧ y < y').               -- lex on Key pairs
```
`[deduction]` `|Key|=n`, `|Ctr|=k+1`. The Ctr zero is the hash position and is never read as a `Key`.

`[definition]` Target sentence shape:
```text
Φ_SORTU := WellFormed_w ∧ Φ_accept.
```
Malformed inputs are rejected.

## 2. Fixed `M_G/G(n,k)` state signature (obligation i, continued)

`[definition]` Fixed-arity state signature `N_G$ over `A(w)`:
```text
Pos(u,v)   arity 2 : strict partial-order edge u < v on Key
Used(t)    arity 1 : comparisons-used marker on Ctr (exactly one element)
Sel(a,b)   arity 2 : selected sorter pair during adversary phase
Ctrl(q)    arity 1 : finite control tag
```
A semantic `N_G$ configuration is `C=(Pos,Used,Sel,Ctrl)` as relations over `W`. The signature is fixed, independent of `n,k`.

`[definition]` Finite control (any fixed FO-definable 4-tag scheme). Using the first four positions in `<` when they exist, with FO tags:
```text
QSort(Ctrl) := ∃q(Ctrl(q) ∧ Min(q)).
QAdv(Ctrl)  := ∃q∃p(Ctrl(q) ∧ Min(p) ∧ Succ(p,q)).
QAcc(Ctrl)  := ∃q∃p∃r(Ctrl(q) ∧ Min(p) ∧ Succ(p,r) ∧ Succ(r,q)).
QRej(Ctrl)  := ExactlyOneCtrl(Ctrl) ∧ ¬QSort(Ctrl) ∧ ¬QAdv(Ctrl) ∧ ¬QAcc(Ctrl).
ExactlyOneCtrl(Ctrl) := ∃q Ctrl(q) ∧ ∀q∀r((Ctrl(q)∧Ctrl(r))->q=r).
```
(Equivalent fixed encodings are acceptable; only FO definability and uniqueness matter.)

## 3. Explicit local FO formulas (obligations i–ii, move semantics)

All formulas are first-order over `A(w)` and displayed `N_G` relations.

### 3.1 Validity, order, and budget predicates
```text
ValidPos(Pos) := ∀u∀v(Pos(u,v)->(Key(u)∧Key(v)))
               ∧ ∀x ¬Pos(x,x)
               ∧ ∀x∀y∀z((Pos(x,y)∧Pos(y,z))->Pos(x,z)).

Incomparable(Pos,x,y) := Key(x)∧Key(y)∧x!=y ∧ ¬Pos(x,y) ∧ ¬Pos(y,x).
Total(Pos) := ∀x∀y((Key(x)∧Key(y)∧x!=y)->(Pos(x,y)∨Pos(y,x))).

ExactlyOneUsed(Used) := ∃t(Used(t)∧Ctr(t)) ∧ ∀t∀s((Used(t)∧Used(s))->t=s).
NoSel(Sel) := ¬∃a∃b Sel(a,b).
OneSel(Sel):= ∃a∃b(Sel(a,b)∧Key(a)∧Key(b)∧∀x∀y(Sel(x,y)->(x=a∧y=b))).

ValidConfig(Pos,Used,Sel,Ctrl) :=
  ValidPos(Pos) ∧ ExactlyOneUsed(Used) ∧ ExactlyOneCtrl(Ctrl)
  ∧ (QSort(Ctrl)->NoSel(Sel))
  ∧ (QAdv(Ctrl) ->OneSel(Sel))
  ∧ (QAcc(Ctrl) ->Total(Pos)).
```

### 3.2 `Init` and terminal predicates (obligation ii)
```text
Init(Pos,Used,Sel,Ctrl) :=
    (∀u∀v ¬Pos(u,v))                                 -- antichain
  ∧ (∃t(Used(t)∧Zero(t)) ∧ ∀t∀s((Used(t)∧Used(s))->t=s))
  ∧ NoSel(Sel)
  ∧ ((Total(Pos) ∧ QAcc(Ctrl)) ∨ (¬Total(Pos) ∧ QSort(Ctrl))).

ConfigAcc(Pos,Used,Sel,Ctrl) := QAcc(Ctrl) ∨ Total(Pos).
ConfigRej(Pos,Used,Sel,Ctrl) := QRej(Ctrl).
```
`[deduction]` `Total(Pos)` is true at the empty poset only when `n<=1`; `Init` selects `QAcc` in that case and `QSort` otherwise.

### 3.3 `StepPos` and incremental transitive closure (obligation ii)
```text
StepPos(Pos,x,y;u,v) := Pos(u,v) ∨ ((u=x ∨ Pos(u,x)) ∧ (v=y ∨ Pos(y,v))).
```
`[deduction]` **Incremental TC lemma.** If `ValidPos(Pos)` and `Incomparable(Pos,x,y)`, let `Pos'(u,v) :⇔ StepPos(Pos,x,y;u,v)`. Then `Pos' = TC(Pos ∪ {(x,y)})` as a strict partial order and `ValidPos(Pos')` holds.

*Proof.* Soundness: every added edge has a path `u=x or u<_{Pos}x`, `x->y`, `y=v or y<_{Pos}v`, so it is forced by `Pos ∪ {(x,y)}`. Completeness: any path in `Pos ∪ {(x,y)}` uses the new edge at most once, since using it twice would require a path `y <_{Pos} ... <_{Pos} x`, contradicting `Incomparable(Pos,x,y)` and irreflexivity/transitivity of `Pos`; a single use factors through `x->y`, giving `StepPos`. Irreflexivity: `Pos'(x,x)` would imply `Pos(x,x)` or `Pos(y,x)` or equalities forcing `x=y`, all impossible under the assumptions. Transitivity: if `Pos'(u,v)` and `Pos'(v,w)`, case analysis on whether each comes from old `Pos` or a path through `x->y`, using transitivity of `Pos`, yields `Pos'(u,w)`. Domain restriction is immediate. ∎

### 3.4 `PostBudget` (obligation ii)
```text
PostBudget(Pos',Used',Ctrl') :=
    (Total(Pos') ∧ QAcc(Ctrl') ∧ ¬QSort(Ctrl') ∧ ¬QAdv(Ctrl') ∧ ¬QRej(Ctrl'))
  ∨ (¬Total(Pos') ∧ (∃s(Used'(s)∧HasBudget(s)))
       ∧ QSort(Ctrl') ∧ ¬QAdv(Ctrl') ∧ ¬QAcc(Ctrl') ∧ ¬QRej(Ctrl'))
  ∨ (¬Total(Pos') ∧ ¬(∃s(Used'(s)∧HasBudget(s)))
       ∧ QRej(Ctrl') ∧ ¬QSort(Ctrl') ∧ ¬QAdv(Ctrl') ∧ ¬QAcc(Ctrl')).
```
`[deduction]` **Budget lemma.** `PostBudget` accepts a total state (including the state reached after the `k`-th comparison), continues only while `HasBudget` holds for the used marker, and rejects a non-total exhausted state. Combined with `YieldE`/`YieldA0,1` below, every completed comparison consumes exactly one `SuccCtr` step and no accepting run uses more than `k` comparisons.

### 3.5 `YieldE`, `YieldA0`, `YieldA1` (obligation ii)
```text
YieldE(Pos,Used,Sel,Ctrl; Pos',Used',Sel',Ctrl') :=
    QSort(Ctrl) ∧ ¬Total(Pos)
  ∧ (∃t(Used(t)∧HasBudget(t)))
  ∧ (∃a∃b(Sel'(a,b) ∧ Incomparable(Pos,a,b)
           ∧ ∀x∀y(Sel'(x,y)->(x=a∧y=b))))
  ∧ (∀u∀v(Pos'(u,v)<->Pos(u,v)))
  ∧ (∀t(Used'(t)<->Used(t)))
  ∧ QAdv(Ctrl').

YieldA0(Pos,Used,Sel,Ctrl; Pos',Used',Sel',Ctrl') :=
    QAdv(Ctrl)
  ∧ (∃a∃b(Sel(a,b) ∧ Incomparable(Pos,a,b)))
  ∧ (∀u∀v(Pos'(u,v)<->StepPos(Pos,a,b;u,v)))
  ∧ (∃t∃s(Used(t)∧SuccCtr(t,s)∧Used'(s) ∧ ∀r(Used'(r)->r=s)))
  ∧ NoSel(Sel')
  ∧ PostBudget(Pos',Used',Ctrl').

YieldA1(Pos,Used,Sel,Ctrl; Pos',Used',Sel',Ctrl') :=
    QAdv(Ctrl)
  ∧ (∃a∃b(Sel(a,b) ∧ Incomparable(Pos,a,b)))
  ∧ (∀u∀v(Pos'(u,v)<->StepPos(Pos,b,a;u,v)))
  ∧ (∃t∃s(Used(t)∧SuccCtr(t,s)∧Used'(s) ∧ ∀r(Used'(r)->r=s)))
  ∧ NoSel(Sel')
  ∧ PostBudget(Pos',Used',Ctrl').
```

## 4. Move preservation and reflection (obligation iii)

`[deduction]` **Preservation.** If `ValidConfig(C)` and `YieldE(C,C')` (respectively `YieldA0/YieldA1`), then `ValidConfig(C')` follows: `ValidPos` is preserved by `YieldE` (unchanged) and by `YieldA0/YieldA1` (incremental TC lemma); `ExactlyOneUsed` is preserved (unchanged / advanced by `SuccCtr`); control/selection invariants are enforced by the formulas; `QAcc` only under `PostBudget` with `Total(Pos')`.

`[deduction]` **Reflection to `G(n,k)`.** Define the semantic map `γ(C)=(P_C,u_C,phase_C,sel_C)` where `P_C={ (u,v)∈Key^2 : Pos(u,v) }`, `u_C$ is the unique `Used` counter, and `phase_C,sel_C` are read from `Ctrl,Sel`. Then: `Init(C)` gives the `G(n,k)` initial state (antichain, 0 used, sorter phase, no selection, or immediate accept at `n<=1`); `YieldE(C,C')` iff sorter legally selects an incomparable pair with remaining budget and moves to the corresponding adversary state; `YieldA0(C,C0),YieldA1(C,C1)` iff the adversary answers `(a,b)` or `(b,a)` for the selected pair, applies transitive closure, consumes one comparison, and resolves to accept/continue/reject by budget and totality. Conversely, every legal `G(n,k)` move has a corresponding semantic `N_G$ step satisfying the `Yield*` formula.

`[falsification targets]` Boundary cases: `n<=1`; `k=0`; exact exhaustion (`Used'=MaxK` makes `HasBudget` false); `Total` reached exactly at `MaxK`; `Zero=Hash` not a key; selected pair must be incomparable in the *current* `Pos`.

## 5. Alternating acceptance fixed point and `S(n)<=k` (obligation iv–v)

### 5.1 Semantic alternating operator (CKS game/alternation view)
`[definition]` For semantic `N_G$ configurations, let
```text
C ∈ T(Accept) iff
    ConfigAcc(C)
  ∨ (QSort(C) ∧ ∃C'(YieldE(C,C') ∧ C' ∈ Accept))
  ∨ (QAdv(C)  ∧ ∃C0,C1(YieldA0(C,C0) ∧ YieldA1(C,C1)
                         ∧ C0 ∈ Accept ∧ C1 ∈ Accept)).
```
`[deduction]` `T` is monotone in `Accept`. Every legal play decreases budget across universal phases, so plays have length `<=2k+1`. Hence the least fixed point `LFP(T)` exists and
```text
C ∈ LFP(T)  iff  M_G has an accepting alternating computation from C
            iff  γ(C) is a sorter-winning position in G(n,k).
```

### 5.2 Equivalence to `S(n)<=k` (obligation v)
`[deduction,literature]` Let `C0` be the unique semantic initial configuration with `Init(C0)`. By §§3–4, `C0 ∈ LFP(T)` iff the sorter has a winning strategy in `G(n,k)`. By the fixed comparison-sorting game characterization used in `docs/problem.md` and `docs/research-certificates-barriers.md`, sorter wins `G(n,k)` iff there is a correct adaptive comparison decision tree of height `<=k` iff `S(n)<=k`. Therefore
```text
S(n)<=k  iff  C0 ∈ LFP(T).
```

## 6. Global FO(PFP)/IFP instantiation (obligation iv, syntactic)

### 6.1 Why direct tuple-coded alternating acceptance is not used
`[falsification,literature]` The naive global form `ACC(s̄,z̄)` with `z̄∈W^r` naming whole configurations fails as a total coding of all valid `Pos` states: `A001035(n)=2^{Θ(n^2)}$ labelled posets exceed `|W|^r=(n+k+1)^r` for every fixed `r` at large `n` (OEIS A001035; Kleitman–Rothschild). This note does not use that total tuple-coding; `Pos` remains a relation variable/content in the DTM tape encoding below.

### 6.2 CKS/alternation layer
`[literature,deduction]` For well-formed `w$, `N=n+k+1$, `n<=N`, `k<=N$. An alternating procedure evaluating `G(n,k)` uses `O(k)$ alternation/comparison phases and polynomial local work in `n$ (`StepPos`, legality, totality, budget are polynomial in `n$), hence `SORT-BOUND-U` is accepted in alternating polynomial time on the unary input scale: `ATIME(poly(N))`. By Chandra–Kozen–Stockmeyer, `APTIME = PSPACE`.

### 6.3 Explicit deterministic PSPACE evaluator `M_D^alt`
`[definition]` `M_D^alt` is a deterministic Turing machine over `A(w)$ (or its standard string encoding) that evaluates alternating acceptance of `M_G` by depth-first search. Its state is a stack of frames:
```text
frame := (Pos,Used,Sel,Ctrl, mode, cursor)
```
where `(Pos,Used,Sel,Ctrl)` is an `N_G$ configuration, `mode ∈ {EVAL, BACK-E, BACK-A0, BACK-A1, RET}`, and `cursor$ enumerates existential pair choices in lex order on `Key×Key$ when needed.

High-level deterministic transitions (all tests/updates use the local FO formulas):
1. **Initialize:** push `C0$ with `Init(C0)$, mode `EVAL`.
2. **EVAL, accepting:** if `ConfigAcc(C)$ then return accept to parent.
3. **EVAL, rejecting:** if `ConfigRej(C)$ or (`QSort(C) ∧ ¬Total(Pos) ∧ ¬HasBudget(Used)$) then return reject.
4. **EVAL, existential `QSort`:** enumerate `(a,b)∈Key×Key$ in lex order with `Incomparable(Pos,a,b)$; for the next such pair, form `C'$ by `YieldE(C,C')$ and push `C'$ in `EVAL`; if a child returns accept, return accept; if none remain, return reject.
5. **EVAL, universal `QAdv`:** form `C0,C1$ by `YieldA0/YieldA1(C,·)$; evaluate `C0$ first; if reject return reject; else evaluate `C1$ and return its result.

`[deduction]` **Correctness of `M_D^alt`.** By induction on the finite game rank (or on remaining budget/height of the alternating computation): a returned accept/reject for frame `C$ matches `C∈LFP(T)$. Therefore `M_D^alt` accepts `w$ iff `C0∈LFP(T)$ iff `M_G$ accepts iff `S(n)<=k$.

`[deduction]` **Space bound.** Each frame stores `Pos$ (`n^2$ bits), `Used$ (`O(log k)$), `Sel$ (`O(log n)$), `Ctrl$/mode (`O(1)$), cursor (`O(log n)$), total `O(n^2 + log N)=O(N^2)$. Stack depth is at most `2k+1=O(N)$ because each comparison phase consumes budget. Thus `M_D^alt$ uses `O(N^3)$ space, polynomial in the unary input length `N$.

### 6.4 Vardi/AV FO(PFP) capture instantiation
`[literature]` Vardi (1982), Immerman (1986), Abiteboul–Vianu (1991), and standard finite-model-theory treatments (Ebbinghaus–Flum; Libkin; Immerman book) establish FO(PFP)=PSPACE (and FO(IFP)/FO(LFP)+inflationary/partial fixed-point equivalents on ordered structures in the standard presentations) on ordered finite structures. The capture direction constructs, for a polynomial-space DTM, fixed-arity relations encoding tape cells/head/state over `W^r$ and an FO(PFP) formula whose partial fixed point simulates the DTM until halting.

`[definition,deduction]` Applying this standard construction to the explicit `M_D^alt$ of §6.3 yields an FO(PFP) sentence `Φ_{M_D}$ over the ordered word/signature structure for `A(w)$ with the property:
```text
A(w) |= Φ_{M_D}   iff   M_D^alt accepts w.
```
Combined with §6.3 and §5.2:
```text
A(w) |= WellFormed_w ∧ Φ_{M_D}   iff   w ∈ SORT-BOUND-U.
```

### 6.5 Why this avoids the A001035 total-coding falsifier
`[deduction]` The tape encoding of `M_D^alt$ stores *the current frame's* `Pos$ relation as tape content (a binary array on `Key×Key$ inside a frame), not a global name `z̄∈W^r$ for every possible `Pos$ in the configuration space. The DTM simulation therefore needs fixed-arity access to tape cells, not injective tuple codes for all `A001035(n)$ valid posets. The A001035 falsifier blocks total configuration-name packing (`[open:PACK-REPR]`), not storage of one current `O(N^2)$ configuration on a polynomial-space tape.
