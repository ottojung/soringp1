# Framed-DAG witness attempt for `n=12` (front: `framed-dag-witness-n12-exact`)

## 1. Problem statement and `S(12)` baseline

**Question (falsifiable, independent).** Does there exist an explicit, checkable permutation-framed strategy DAG certificate of **exact height `S(12)=30`** for `n=12` (noting `C(12)=29` but `S(12)=30`), and what is its concrete size/depth/profile compared to polynomial envelopes (e.g. `O(n^2)` nodes, `O(n log n)` path length)?

**Model / certificate format.** Distinct labelled keys, deterministic adaptive comparison sorting. A framed strategy DAG is as in `docs/research-framed-certificate-frontier.md` and `scripts/check_framed_strategy.py`: acyclic graph, each comparison node has `compare=[a,b]`, outcome edges `lt` (`a<b`) and `gt` (`b<a`) with `next` and slot permutation `perm`; the checker propagates/intersects guaranteed strict partial orders, rejects cycles, unsound frames, non-sorting leaves, and depths above `budget`. Acceptance is **soundness of that explicit certificate** (checker-verified), not an all-`n` completeness theorem.

**Baseline (literature / stated in repo docs).**
- Information lower bound: `C(12) = ceil(log2(12!)) = 29` (verified by computation below). `12! = 479001600`, `log2(12!) ≈ 28.835455`.
- Exact sorting number: `S(12) = 30` (literature: Wells; reported in Peczarski 2012 and indexed e.g. OEIS A036604; listed as known in `docs/problem.md`, `docs/literature.md`, `AGENTS.md` context). **Not re-proved here.**
- **Gap:** `S(12) - C(12) = 1`. The instance is nontight: no comparison strategy can sort every permutation of 12 keys in 29 comparisons, while 30 are sufficient in the optimal model.

**Related bounds for `n=12` (computed):**
- Ford–Johnson / merge-insertion bound `F_FJ(n)=∑_{j=1}^{n} ceil(log2(3j/4))`: `F_FJ(12)=30` (matches `S(12)`; **value equality only**, not by itself a framed-certificate construction).
- Standard merge-sort worst-case comparisons `M(12)=33` (`M` defined by balanced split recurrence `M(n)=M(⌊n/2⌋)+M(⌈n/2⌉)+n-1`, `M(1)=0`).
- Bubble/network-style triangular path: `n(n-1)/2 = 66` comparisons for `n=12`.

### 3.3 Documented obstruction / evidence (falsifiable)

1. **Search/exhaustive optimal-policy DAG is infeasible at `n=12`.** Exact optimal strategy discovery for `n=12` is historically hard (the information-bound gap at 12/29–30 was a known case; larger exact values up to 22 required large pruned searches per `docs/literature.md`, e.g. Stober–Weiß report 89–115h on 48-thread/768GB for `n=16..18`). A minimax/optimal-policy DAG enumeration as in `strategy_dag_probe.py` is only run here up to `n=5` (table below); scaling to `n=12` is not attempted as it is computationally out of reach for this environment/turn.
2. **No existing generator for an exact-height framed cert.** `scripts/check_framed_strategy.py` provides a soundness checker and `triangular_bubble_certificate` only; there is no implemented Ford–Johnson/merge-sort framed-certificate generator in `scripts/`. `docs/research-framed-certificate-frontier.md` marks merge-sort/FJ framed constructions as paper constructions with pending independent implementation/audit.
3. **Tree vs. framed DAG size pressure.** An unshared decision tree realizing 30 comparisons in the worst case can be exponentially large in the relevant sense (up to `2^30` leaves in the worst branching picture, though structured), so an explicit witness must exploit sharing/joins/permutation framing; constructing correct frames and join invariants for FJ at `n=12` is a nontrivial implementation task not completed here. Therefore the existence of an explicit, checkable height-30 framed DAG for `n=12` remains **open/unwitnessed** in this worktree.
4. **Complexity caveat (from frontier/literature).** Even if some polynomial-size framed DAG existed for every true unary instance at height `S(n)`, that would imply `SORT-BOUND-U ∈ NP`; sparsity/Mahaney is only a barrier to routine NP-hardness claims, not a proof of nonexistence of such certificates. No such completeness theorem is known.
