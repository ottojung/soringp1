## 1. C4 format under test `[definition]`

Following the refuter-certificate note (C4): a C4 refuter/adversary DAG for
`G(n,k)` has root `(antichain_n, k)` and, for each internal node
`(P, b)`, a **total refuter rule** covering **every** incomparable pair
`m = (i,j)` with an adversary answer `a_m ∈ {(i<j),(j<i)}` and an edge to
`(tc(P + a_m), b-1)`. A terminal is a non-total state with `b = 0` (sorter
lost). Sharing is sound only when states/budgets are identical under an
explicit equality/canonicalization rule; dominance rules are not assumed sound
unless proved.

`[deduction]` If a verifier accepts such a DAG, every legal sorter move at
every reachable refuter state has a certified adversary answer and all
branches end within budget without a total order, so the adversary wins
`G(n,k)` and `S(n) > k`.

## 2. Explicit verifier (implemented) `[experiment]`

A local verifier was implemented for labelled C4 DAGs (successor-bitmask
partial orders, transitive-closure recomputation on each edge). Checks:

1. root is `((0,...,0), k)` on `n` elements;
2. for terminal nodes: state non-total and `budget == 0`;
3. for internal nodes: rule keys are exactly `Inc(P)` (total move coverage);
4. for each rule entry: answer is one of the two orientations of the move,
   `tc(P + answer)` equals the stored child state, child exists, and
   `child.budget == parent.budget - 1`;
5. no terminal total state (would mean sorter wins on that branch).

The verifier is polynomial in `|D| * poly(n)` (TC/state checks per edge). It
is **not** a compressed `G(12,29)` verifier instance; it is the explicit
checker used for the small concrete instances below.

## 4. Bounded-fragment obstructions for `G(12,29)` `[deduction, experiment]`

The measurements support the following precise, reproducible obstructions to
obtaining a *short* C4 witness for `G(12,29)` by direct compression of the
explicit refuter DAG/search:

### 4.1 Total move coverage is structurally expensive `[definition, deduction]`

C4 requires a rule over **all** incomparable pairs at every internal node.
At the `G(12,29)` root (antichain), `|Inc(P_0)| = C(12,2) = 66`. Thus the
root alone needs 66 certified answers/child edges before any compression can
help. Raw search traces that explore only selected moves are not C4 certificates.

### 4.2 Verifier/DAG blowup on bounded fragments `[experiment]`

The explicit labelled C4 DAG grows from 8 nodes (`n=3`) to 1,146 nodes and
3,995 rule entries (`n=5`), and aborts after 30,003 nodes on the bounded
`n=6,k=9` build while the underlying adversary-win state space already has
58,806 memo states. This is direct evidence that *uncompressed* total-coverage
C4 materialization blows up rapidly with `n,k`; it does **not** rule out a
clever compressed representation, but any such representation must supply both
the compression and an explicit compressed verifier.

### 4.3 State canonicalization is nontrivial at `n=12` `[deduction, experiment]`

Sound sharing by relabelling requires canonical keys/equality proofs. Naive
full-`S_n` canonicalization enumerates `n!` permutations per state:
`12! = 479,001,600`, so a naive full relabelling canonicalizer per state is
infeasible. A color-refinement/pruned canonicalizer can reduce cost in
practice, but for C4 it must preserve the total-coverage semantics on the
chosen representative or include an explicit isomorphism/quotient soundness
argument. The failed canonical attempt above shows this step is easy to get
wrong; it is an obstruction to a *verified* compressed C4 witness, not merely a
performance detail.

### 4.4 Dominance is not a free C4 compression `[deduction]`

A dominance rule (e.g., replacing a state by an “easier/harder” one, or using
`e(P)`/budget heuristics) is unsound unless accompanied by an explicit proof
rule checked by the verifier. `[literature, deduction]` Prior notes record that
information/efficiency conditions are node-level necessary conditions and that
sortability is not monotone in simple scalar invariants; therefore dominance
cannot be assumed in a C4 verifier.

### 4.5 Strategic obstruction remains `[literature, open]`

`C(12)=29`, so `S(12)>29` is a strategic/non-scalar gap: node-level leaf-count
bounds do not by themselves yield a short refuter witness. Known proofs of
`S(12)>29` are exhaustive/structured computer searches (Wells; later
Peczarski/Stober–Weiß context in repo notes). This test does not produce a
short C4 instance for `G(12,29)` and does not prove none exists.

## 5. Conclusion

**(a) Achieved on reduced subgames:** a machine-checkable C4 refuter DAG format
with an explicit verifier was implemented and accepted on concrete small
instances `G(3,2)`, `G(4,4)`, and `G(5,6)`, with measured sizes.

**(b) Obstruction on bounded fragments toward `G(12,29)`:** the first failing
compression steps for direct explicit C4 materialization are

- **total move coverage** (66 root moves at `n=12`, and all `Inc(P)` at every
  internal node),
- **verifier/DAG blowup** (1,146 nodes / 3,995 rule entries at `n=5,k=6`;
  >30,000 nodes before completion at `n=6,k=9`, with 58,806 adversary-win memo
  states measured),
- **state canonicalization** (naive full `S_n` canonicalization is `12!` per
  state at `n=12`; canonical representative handling must be proved sound), and
- **dominance** (not verifier-sound without explicit proof rules).

No compressed C4 witness for `G(12,29)` is produced here. No complexity
separation is claimed. The result is a concrete negative/obstruction report for
uncompressed C4 materialization, plus small verified C4 instances demonstrating
the format and verifier.
