## 1. Fixed problem objects

`[definition]` `SORT-BOUND-U = {1^n # 1^k : S(n) <= k}` (`docs/problem.md`). Input length `N=n+k+1`.

`[definition]` `G(n,k)`: states are transitively closed strict partial orders `P` on `n` labelled keys; initial state is the empty order; budget `k`. Sorter picks an incomparable pair; adversary chooses `x<y` or `y<x`; state becomes `TC(P ∪ {answer})`; budget decreases by 1. Sorter wins iff a total order is reached within `k` comparisons. `S(n)<=k` iff sorter wins `G(n,k)`.

`[literature,deduction]` `SORT-BOUND-U ∈ PSPACE` by the alternating `G(n,k)` computation (Claim A, `research-certificates-barriers.md`; APTIME=PSPACE, Chandra–Kozen–Stockmeyer 1981). FO(PFP) captures PSPACE on ordered finite structures (Vardi 1982; Abiteboul–Vianu 1991), so FO(PFP)-definability holds in principle.

## 2. Ordered word structure and FO parameters

`[definition]` Intended structure for `w=1^n#1^k`:
```text
A(w) = (W, <, One, Hash),   W={1,...,N}, N=n+k+1,
Hash={n+1}, One=W\{n+1}.
```

`[definition]` FO well-formedness and parameters:
```text
HashPos(h)       := Hash(h) ∧ ∀z(Hash(z)->z=h).
WellFormed_w     := ∃h HashPos(h) ∧ ∀h(HashPos(h)->∀x(One(x)<->x!=h)).
Malformed        := ¬WellFormed_w.

Key(x)           := ∃h(HashPos(h) ∧ x < h).
Ctr(t)           := ∃h(HashPos(h) ∧ (t=h ∨ h < t)).          -- {0,...,k}
Zero(t)          := HashPos(t).
MaxK(t)          := Ctr(t) ∧ ¬∃s(Ctr(s) ∧ t < s).
SuccCtr(t,s)     := Ctr(t) ∧ Ctr(s) ∧ t < s ∧ ¬∃z(Ctr(z) ∧ t < z ∧ z < s).
HasBudget(t)     := ∃s SuccCtr(t,s).
```

`[deduction]` `|Key|=n`, `|Ctr|=k+1`, `|W|=N`. `Zero` is 0 comparisons used; `SuccCtr` increments comparisons by 1; `MaxK` is `k`. All are FO on `A(w)` and independent of any acceptance fixed-point variable.

`[definition]` Final form:
```text
Φ_SORTU := Malformed ? reject : Φ_game.
```
Formally `Φ_SORTU := WellFormed_w ∧ Φ_game` (malformed rejected).

## 3. Explicit configuration encoding (AC-independent)

The blocker was decoding arbitrary poset content from a fixed tuple. The encoding here uses a binary relation for the poset:

`[definition]` A complete game/ATM configuration is represented by relations
```text
Pos(u,v)        -- current transitive-closure edge u < v, arity 2
Time(t)         -- comparisons used, arity 1, exactly one Ctr element
Mode(m1,m2,m3)  -- finite control mode, arity 3 over a fixed tag encoding
Pair(a,b)       -- selected sorter pair, arity 2 (or null)
```
with domain restrictions `Pos ⊆ Key×Key`, `Time ⊆ Ctr`, `Pair ⊆ Key×Key`. ATM-specific finite states are folded into `Mode`.

`[deduction]` `Pos` is a binary relation over `W` and can represent any subset of `Key×Key`, including all `2^{Θ(n^2)}` relevant strict partial orders, without decoding from a fixed `W^r` control tuple. The counting blocker does not apply to relation-valued configuration components.

`[definition]` AC-independent state decode/helpers (FO, no acceptance variable):
```text
PValid(Pos) :=
  (∀u∀v (Pos(u,v) -> (Key(u)∧Key(v))))
  ∧ (∀x ¬Pos(x,x))
  ∧ (∀x∀y∀z ((Pos(x,y)∧Pos(y,z))->Pos(x,z))).

Incomparable(Pos,x,y) :=
  Key(x)∧Key(y)∧x!=y ∧ ¬Pos(x,y) ∧ ¬Pos(y,x).

Total(Pos) := ∀x∀y ((Key(x)∧Key(y)∧x!=y)->(Pos(x,y)∨Pos(y,x))).

ExactlyOneTime(Time) :=
  ∃t(Time(t)∧Ctr(t)) ∧ ∀t∀s((Time(t)∧Time(s))->t=s).

NullPair(Pair) := ¬∃a∃b Pair(a,b).
HasPair(Pair)  := ∃a∃b (Pair(a,b)∧Key(a)∧Key(b)∧∀x∀y(Pair(x,y)->(x=a∧y=b))).
```

`[definition]` Fixed finite mode tags (FO on `W`, AC-independent), using order-min/non-min bits:
```text
IsMin(x):=∀y(x=y∨x<y).  NotMin(x):=¬IsMin(x).
MS(m̄)  := NotMin(m1)∧IsMin(m2)∧IsMin(m3).      -- sorter/existential
MA(m̄)  := IsMin(m1)∧NotMin(m2)∧IsMin(m3).      -- adversary/universal
MAcc(m̄):= NotMin(m1)∧NotMin(m2)∧IsMin(m3).     -- accept
MRej(m̄):= NotMin(m1)∧IsMin(m2)∧NotMin(m3).     -- reject
ExactlyOneMode(m̄):= MS(m̄)∨MA(m̄)∨MAcc(m̄)∨MRej(m̄) with pairwise exclusion by table.
```
(For degenerate tiny `W`, equivalent finite tags may be used; intended inputs have `N>=2`.)

## 4. Explicit transition formulas (legal `G(n,k)`, TC, budget `<=k`)

All formulas below are FO in the displayed relations and `A(w)$ parameters; they do **not** mention `AC`.

`[definition]` Initial configuration:
```text
Init(Pos,Time,Mode,Pair) :=
    (∀u∀v ¬Pos(u,v))
  ∧ ∃t(Time(t)∧Zero(t))
  ∧ (∃m̄ (Mode(m̄)∧MS(m̄)))          -- or MAcc if already total; n<=1 edge case
  ∧ NullPair(Pair)
  ∧ (Total(Pos) -> ∃m̄(Mode(m̄)∧MAcc(m̄))).
```
More explicitly, for general `n`:
```text
Init(Pos,Time,Mode,Pair) :=
  (∀u∀v ¬Pos(u,v)) ∧ ∃t(Time(t)∧Zero(t)) ∧ NullPair(Pair)
  ∧ ((Total(Pos) ∧ ∃m̄(Mode(m̄)∧MAcc(m̄)))
     ∨ (¬Total(Pos) ∧ ∃m̄(Mode(m̄)∧MS(m̄)))).
```

`[definition]` Accepting configuration:
```text
Acc(Pos,Time,Mode,Pair) := Total(Pos) ∨ ∃m̄(Mode(m̄)∧MAcc(m̄)).
```

`[definition]` Incremental transitive closure after adding `x < y` to a valid strict partial order `Pos` where `(x,y)` was incomparable:
```text
StepPos(Pos,x,y; u,v) :=
    Pos(u,v)
  ∨ ((u=x ∨ Pos(u,x)) ∧ (y=v ∨ Pos(y,v))).
```
`[deduction]` `StepPos` is FO. It adds the edge and all implied transitive edges; when `Pos` is transitively closed and `x,y` incomparable, the result is the transitive closure of `Pos ∪ {(x,y)}`.

`[definition]` Existential sorter move (select incomparable pair, keep poset/time):
```text
YieldE(Pos,Time,Mode,Pair; Pos',Time',Mode',Pair') :=
    ∃m̄(Mode(m̄)∧MS(m̄)) ∧ ¬Total(Pos) ∧ ∃t(Time(t)∧HasBudget(t))
  ∧ ∃a∃b (Pair'(a,b) ∧ Incomparable(Pos,a,b) ∧ ∀x∀y(Pair'(x,y)->(x=a∧y=b)))
  ∧ (∀u∀v (Pos'(u,v)<->Pos(u,v)))
  ∧ (∀t (Time'(t)<->Time(t)))
  ∧ ∃m̄(Mode'(m̄)∧MA(m̄)).
```

`[definition]` Universal adversary outcome 0: answer `a<b`.
```text
YieldA0(Pos,Time,Mode,Pair; Pos',Time',Mode',Pair') :=
    ∃m̄(Mode(m̄)∧MA(m̄))
  ∧ ∃a∃b (Pair(a,b) ∧ Incomparable(Pos,a,b))
  ∧ (∀u∀v (Pos'(u,v) <-> StepPos(Pos,a,b;u,v)))
  ∧ ∃t∃s (Time(t)∧SuccCtr(t,s)∧Time'(s))
  ∧ NullPair(Pair')
  ∧ ((Total(Pos') ∧ ∃m̄(Mode'(m̄)∧MAcc(m̄)))
     ∨ (¬Total(Pos') ∧ ∃s(Time'(s)∧HasBudget(s)) ∧ ∃m̄(Mode'(m̄)∧MS(m̄)))
     ∨ (¬Total(Pos') ∧ ∃s(Time'(s)∧MaxK(s)) ∧ ∃m̄(Mode'(m̄)∧MRej(m̄)))).
```

`[definition]` Universal adversary outcome 1: answer `b<a`.
```text
YieldA1(Pos,Time,Mode,Pair; Pos',Time',Mode',Pair') :=
    ∃m̄(Mode(m̄)∧MA(m̄))
  ∧ ∃a∃b (Pair(a,b) ∧ Incomparable(Pos,a,b))
  ∧ (∀u∀v (Pos'(u,v) <-> StepPos(Pos,b,a;u,v)))
  ∧ ∃t∃s (Time(t)∧SuccCtr(t,s)∧Time'(s))
  ∧ NullPair(Pair')
  ∧ ((Total(Pos') ∧ ∃m̄(Mode'(m̄)∧MAcc(m̄)))
     ∨ (¬Total(Pos') ∧ ∃s(Time'(s)∧HasBudget(s)) ∧ ∃m̄(Mode'(m̄)∧MS(m̄)))
     ∨ (¬Total(Pos') ∧ ∃s(Time'(s)∧MaxK(s)) ∧ ∃m̄(Mode'(m̄)∧MRej(m̄)))).
```

`[deduction]` **Budget `<=k`.** Time is a `Ctr` value in `{0,...,k}`. `YieldE` requires `HasBudget(t)`, so a comparison is selected only when `t<=k-1`. `YieldA0/A1` use `SuccCtr(t,s)`, so exactly one comparison is consumed and `s<=k`. Acceptance is possible at any time a total order is reached (including exactly at `k` by the `Total(Pos')`/`MAcc` branch). Exhausting budget on a non-total state gives `MRej`. No move exceeds `k` comparisons.

`[falsification target]` Edge cases: `n<=1` initial totality; `k=0`; reaching totality exactly at `MaxK`; `NullPair` inertness (never used to satisfy `Incomparable`); preservation of `PValid` after `StepPos`; selected pair must remain incomparable in the pre-adversary state.

## 5. ATM/config interpretation over `A(w)`

`[definition]` The explicit ATM `M_G` for input `A(w)`:
- **Tape/state content.** A configuration is `(Pos,Time,Mode,Pair)` as in §3. Space `O(n^2)+O(log k)+O(1)=O(N^2)` bits, representable by fixed-arity relations over `W`.
- **Initial.** `Init(Pos,Time,Mode,Pair)`.
- **Existential configurations** (`MS`): accept if `Acc`; reject if not total and no budget; otherwise existentially choose legal `YieldE` successor.
- **Universal configurations** (`MA`): require both `YieldA0` and `YieldA1` successors to be accepting.
- **Accepting/rejecting sinks** (`MAcc`/`MRej`).
- **Transition legality.** For every reachable non-sink step, exactly the `G(n,k)` rules apply: incomparable pair selection, two adversary outcomes, incremental TC update, budget increment.

`[deduction]` `M_G` is an explicit alternating polynomial-space computation over `A(w)` whose accepting runs correspond bijectively (by the decoded state components) to sorter-winning strategies in `G(n,k)`. Therefore `M_G` accepts `A(w)` iff `S(n)<=k` iff `w ∈ SORT-BOUND-U`, on well-formed inputs.

## 6. PFP/IFP acceptance form (AC-independent, no class overclaim)

`[definition]` The intended alternating acceptance operator (schematic over configuration relations/components) is:
```text
ψ_accept(AC; Pos,Time,Mode,Pair) :=
    Acc(Pos,Time,Mode,Pair)
  ∨ (∃m̄(Mode(m̄)∧MS(m̄)) ∧ ∃Pos'∃Time'∃Mode'∃Pair'
       (YieldE(Pos,Time,Mode,Pair;Pos',Time',Mode',Pair')
        ∧ AC(Pos',Time',Mode',Pair')))
  ∨ (∃m̄(Mode(m̄)∧MA(m̄))
       ∧ ∃Pos1,Time1,Mode1,Pair1 ∃Pos2,Time2,Mode2,Pair2
         (YieldA0(Pos,Time,Mode,Pair;Pos1,Time1,Mode1,Pair1)
          ∧ YieldA1(Pos,Time,Mode,Pair;Pos2,Time2,Mode2,Pair2)
          ∧ AC(Pos1,Time1,Mode1,Pair1)
          ∧ AC(Pos2,Time2,Mode2,Pair2))).
```

`[deduction]` **Syntactic positivity / AC-independence.** `AC` occurs only positively. All decoding and transition formulas (`Acc, YieldE, YieldA0, YieldA1, Pos/Time/Mode/Pair` tests, `StepPos`, `Incomparable`, `Total`, budget predicates) are FO over `A(w)` and do **not** mention `AC`. Thus, once a complete configuration representation is fixed, the acceptance operator is semantically monotone in `AC`.

`[definition]` **PFP/IFP form (conditional/global).**
```text
Φ_game := ∃Pos,Time,Mode,Pair (Init(Pos,Time,Mode,Pair) ∧
           [PFP_{AC,...} ψ_accept(AC,...)](Pos,Time,Mode,Pair)),
```
under a standard encoding that makes configuration components available to the FO(PFP) simulation (see §7).

For a fixed finite `G(n,k)` game structure with AC-independent transitions, the positive acceptance operator also has an LFP/IFP:
```text
Win := [LFP/IFP_{AC,...} ψ_accept(AC,...)].
```
Because each universal adversary step consumes one comparison, reachable alternations/ranks are bounded by `O(k)` and the game fixed point stabilizes in finitely many stages on reachable states.

`[deduction]` **No overclaim.** This positivity/LFP form does not imply `SORT-BOUND-U ∈ P`, FO(LFP) on the bare ordered word, or NP/coNP membership. The complexity consequence used is only the established PSPACE/FO(PFP)-in-principle fact; the global PFP simulation remains the non-discharged step.

## 7. Global closure status and precise residual blocker

`[literature]` Vardi/Abiteboul–Vianu: FO(PFP) captures PSPACE on ordered finite structures. The standard proof gives, for every PSPACE (or alternating polynomial-time) machine/acceptance condition, an FO(PFP) definition by encoding configurations and iterating the transition/acceptance computation.

`[deduction]` What is discharged here:
1. Explicit ordered input structure `A(w)` and FO parameters `Key/Ctr/Zero/SuccCtr/MaxK`.
2. Explicit AC-independent configuration decoding for the game/ATM state: `Pos, Time, Mode, Pair` with validity/totality/incomparability helpers.
3. Explicit FO local transitions: `Init, Acc, StepPos, YieldE, YieldA0, YieldA1`, with legal `G(n,k)` moves, incremental TC, and budget `<=k`.
4. Explicit equivalence target: `M_G` accepts `A(w)` iff `S(n)<=k`.
5. Explicit AC-independent, syntactically positive acceptance operator.

`[open]` **Precise residual blocker (global, not local).** To obtain a fully discharged formula-level closure from scratch, one must instantiate the standard FO(PFP) PSPACE/ATM simulation for `M_G`:
- encode the full `M_G` configuration space in the exact normal form expected by the chosen FO(PFP) simulation proof (including any stage/time/cell indexing used by that proof);
- write the complete PFP/IFP fixed-point sentence(s) over `A(w)` whose stages compute accepting configurations/reachability;
- prove the simulation lemma: the fixed point holds for the initial encoded configuration iff `M_G` has an accepting alternating computation iff `S(n)<=k`.

This note reduces closure of `SORT-BOUND-U` by path (iii) to that standard instantiation and supplies all game-specific/local ingredients. It does **not** reproduce the entire AV/Vardi global simulation proof specialized to `M_G`.

`[deduction]` **Why this is not the old blocker.** The old fixed-tuple blocker concerned representing arbitrary `Pos` as data decoded from `d̄∈W^r`. Here `Pos` is an explicit binary relation component; `StepPos`, legality, and budget are explicit FO formulas independent of `AC`. The remaining gap is global fixed-point simulation/normal-form instantiation, not missing local game semantics.
