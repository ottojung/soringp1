# Descriptive encodings of the unary sorting threshold

**Status:** paper deduction; not Lean-checked. This note records a
resource-faithful game encoding and an explicit falsification of the proposed
network-depth bridge.
The input is `1^n#1^k`, of length `N=n+k+1`; `S(n)` is adaptive worst-case
comparison-tree height on `n` distinct labelled keys.

## Ordered-structure encoding

Represent an input of length `N` as an ordered finite structure whose domain
is the `N` string positions, with `<` and unary predicates for `1` and `#`.
The delimiter position `d` is first-order definable as the unique `#` position;
the key universe is the initial segment before `d`, and the budget is the
final segment after `d`. Thus both `n` and `k` are represented by domain
cardinalities, not binary numerals. Malformed strings are rejected in FO.

There is a direct finite-game evaluation on this structure. A game state is an
`n×n` ternary relation for the current partial order plus a counter `t≤k`.
At each position, existentially choose an incomparable pair `(x,y)`, then
universally choose one of the two orientations, close transitively, and
increment `t`. The existential player wins iff the state becomes total by
round `k`. The inductive invariant is exact: a state is winning with `r`
rounds left iff there is a correct adaptive comparison tree of height at most
`r` sorting every linear extension of that state. At the empty relation this
is precisely `S(n)≤k`.

The state relation has `O(n²)` bits, the counter `O(log(k+1))` bits, and each
transition can be computed in polynomial time in `N`. There are at most
`k≤N` rounds. Consequently this is an alternating polynomial-time computation
on the actual unary input, and hence a PSPACE decision procedure. By the
ordered-structure capture theorems, the language has an FO(PFP) definition;
the formula obtained through the generic capture theorem is not claimed to be
a useful short explicit formula. This recovers the existing PSPACE bound, not
a new complexity improvement.

The FO(PFP) statement here is a capture-theorem consequence, not a printed
formula. The machine-level game transition is explicit: encode a configuration
by the `n×n` relation, a stage counter, and the finite control; from a
nonterminal configuration, existentially choose an incomparable pair,
universally require both oriented successor configurations to be winning,
and compute each successor's transitive closure. A terminal configuration is
accepting exactly when its relation is total. This uses polynomially many
configuration bits and at most `k` rounds. The deterministic polynomial-space
decision procedure can use depth-first evaluation of this alternating game;
the standard ordered-structure FO(PFP) capture applies to that evaluator.
The game choices are semantically solved by the evaluator, not asserted to
be one first-order existential witness.

## Why ESO certificates and FO(LFP) are not obtained by writing the game

An ESO sentence on ordered structures captures NP, and FO(LFP) captures P.
The game semantics above has the quantifier pattern “there exists a move, for
both outcomes there exists a next move, for both outcomes ...”, with up to
`k=Θ(N)` alternating rounds. It is not one existential choice of a
polynomial-size relation followed by a first-order check unless that relation
succinctly specifies a complete winning strategy with a sound polynomial-time
verifier. Expanding the strategy as a tree has `n!` reachable leaves, which
is super-polynomial in informative unary input length; the existence of a
polynomial-size adaptive DAG strategy remains open. Conversely FO(LFP)
definability would imply uniform P, and ESO definability would imply NP, both
unproved for this language. These are exact consequences of the capture
theorems, not formulas we have supplied.

## Comparator networks do not bridge to `S(n)`

A comparator network is a fixed sequence of comparators (or fixed layers); it
does not select its next comparison based on earlier outcomes. If it sorts,
then its comparisons can be read as an adaptive tree that ignores outcomes,
so `S(n)` is at most the network's total comparator count. In particular a
depth-`d`, width-`w` network gives only `S(n)≤wd`, not `S(n)≤d`; network depth
counts parallel layers, while `S(n)` counts sequential comparisons along a
path.

There is no general cost-preserving bridge from network depth to `S(n)`:
depth counts parallel layers, whereas an adaptive comparison tree counts
individual comparisons on a path. A depth-`d`, width-`w` network only implies
`S(n)≤wd` by sequentializing all its comparators; no implication `S(n)≤d`
follows without a separate width/count argument or construction of a tree
using at most `d` comparisons on each path. The standard zero-one principle
establishes network correctness, not such an adaptive bound. This falsifies
the proposed inference, not the possibility of a stronger theorem for a
particular network family.

For a concrete cost counterexample, take the standard odd-even
transposition network on four wires: successively compare adjacent wires in
alternating parity layers until the wires are sorted. It has comparator
count 6 (comparisons `(1,2),(3,4),(2,3),(1,2),(3,4),(2,3)`) arranged in
four layers, and sorts all 24 input permutations. Yet `S(4)=5` (the exact
small value documented in `research-plan.md`), so a depth-4 witness cannot
imply `S(4)≤4`. This is the explicit falsification: its depth is smaller
than the true adaptive optimum. The generic network-to-tree conversion is
by its 6-comparator size, not its depth.

The useful bridge is the converse, correctly costed: every adaptive tree of
height `k` is a data-dependent comparator program with at most `k`
comparisons per execution. Its branching program may have exponentially many
nodes; replacing it with a fixed network is not generally size-preserving.

## Consequence and evidence

**Deduction:** an explicit finite-game encoding gives a transparent
FO(PFP)/PSPACE characterization, while an FO(LFP) or ESO definition would
be a genuine P or NP upper bound respectively. Neither follows merely from
the compact recurrence or a comparator-network witness. The unresolved
obligation is exactly a uniform polynomial evaluator (for FO(LFP)) or a
polynomial-size, polynomial-time-checkable adaptive strategy certificate
(for ESO); existing framed-DAG soundness does not prove all-`n`
completeness.

**Literature:** Immerman–Vardi, “Relational queries computable in polynomial
first-order spectra and polynomial-time recognizable sets,” in *Complexity
of Computation* (1974), 43–73; Chandra–Kozen–Stockmeyer, “Alternation,” *J.
ACM* 28(1) (1981), 114–133. For sorting networks versus adaptive trees,
see the model distinction and Parberry's fixed-network verification result
in `research-certificates-barriers.md`; that complexity result does not
transfer to `S(n)`.

**Correction / limitation:** no numerical separation example is needed for
the bridge refutation: the general, proved conversion sequentializes a
network and costs its size, not its depth. The exact general bridge is
`S(n)≤size(network)`; any stronger relation requires proof and is not used
here.
