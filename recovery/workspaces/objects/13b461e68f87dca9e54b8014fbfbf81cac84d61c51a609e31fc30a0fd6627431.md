## 1. Fixed signature, address space, and `Δ_{M_D}` family

### 1.1 Ordered input structure

`[definition]` Input `w=1^n # 1^k`, `N=|w|=n+k+1`,
```text
A(w) = (W,<,One,Hash),   W={1,...,N}.
```
FO-definable predicates/relations over `A(w)` are fixed as in the delta-d
artifacts: `Succ, Min, Max, HashPos, WellFormed_w, Malformed, Key, Ctr, Zero,
MaxK, SuccCtr, HasBudget, KeyNe, Lex2`.  `Key` has size `n`, `Ctr` has size
`k+1` with zero at the hash position.

### 1.2 Cell/address space and configuration family

`[definition]` Fix `r:=4` and `Cell := W^r`, `|Cell|=N^r`.  Lex order and fixed
successor/offset relations on `Cell` are FO-definable from `<`.  This is the
standard polynomial-space addressing margin `[literature]`; it does not name all
`Pos` states.

`[definition]` Let
```text
Rbar = (R_1,...,R_m)
```
be the fixed finite family of configuration relations of
delta-d-dfs-stack §2.  Every `R_i` has fixed arity `a_i` over `W` and is
independent of `n,k`.  The family includes, in particular:
```text
Top              arity r
EmptyStack       arity 0
HaltAcc          arity 0
HaltRej          arity 0
M_Eval,...,M_RetRej   arity r      (frame modes)
CtrlSort,...,CtrlRej  arity r      (control tags)
UsedF             arity r+1
HasSel            arity r
SelA,SelB         arity r+1
HasCur            arity r
CurA,CurB         arity r+1
PosF              arity r+2        (current closure bit at frame c̄ for (u,v))
Parent            arity 2r
```
plus any fixed finite auxiliary frame/stack relations used by the final
normal-form realization of the delta-d artifact (all fixed arity).  Let
```text
A := max_i a_i = 2r = 8.
```
This maximum is fixed (currently attained by `Parent`).  If auxiliary fixed
relations of larger fixed arity are added, `A` is increased to that fixed
maximum; the construction is unchanged.

`[falsification]` `PosF(c̄,u,v)` stores the current transitive-closure bit of the
active frame `c̄` for `Key` pair `(u,v)`.  No relation ranges over all
`A001035(n)=2^{Θ(n^2)}` labelled posets and no tuple name in `W^q` is used as a
global code for an arbitrary valid `Pos` state.

### 1.3 Case-closed transition

`[definition,literature-context]` `Δ_{M_D}(Rbar;Rbar')` is the case-closed FO
formula of delta-d-dfs-stack §5, a finite disjunction of mutually exclusive
deterministic cases:
```text
Δ_halt, Δ_root_acc, Δ_root_rej, Δ_eval_acc_ret, Δ_eval_rej_ret,
Δ_sort_pick_push, Δ_sort_exhaust_rej, Δ_backE_acc_ret, Δ_backE_rej_next,
Δ_adv_push_A0, Δ_backA0_rej_ret, Δ_backA0_acc_push_A1, Δ_backA1_ret.
```
`Init_{M_D}(Rbar)` is the FO initial-configuration formula of delta-d-dfs-stack
§3.  The frame/stack invariant is `I_{M_D}(Rbar)` (§6 there).  Delta-d proves
paper-level: determinism/functionality, totality on non-halting well-formed
states satisfying `I_{M_D}`, invariant preservation, and absence of spurious
transitions relative to the semantic DFS evaluator `M_D^alt`.

## 2. Explicit single configuration relation with FO projections/updates

### 2.1 Small-input guard

`[definition]` The packing uses `m` distinct tag values, where `m=|Rbar|` is
fixed.  Let
```text
Large_m := ∃x_1 ... ∃x_m (Min(x_1) ∧ Succ(x_1,x_2) ∧ ... ∧ Succ(x_{m-1},x_m)).
```
`Large_m` is FO over fixed `A(w)`.  For the finitely many `A(w)` with
`¬Large_m` (i.e. `N < m`), membership of `w` in `SORT-BOUND-U` is a fixed
finite table, because `N=n+k+1<m` bounds both `n` and `k`; define
```text
Φ_small := \/_{(n,k): n+k+1<m, S(n)<=k} Shape_{n,k},
```
where `Shape_{n,k}` is the FO sentence stating that `A(w)` is exactly the
well-formed word with `n` ones before hash and `k` ones after hash.  (The truth
values `S(n)<=k` in this finite table are fixed mathematical facts; the table
has size `< m^2`.)

`[definition]` The final sentence is
```text
Φ_{M_D} := (¬Large_m ∧ Φ_small) ∨ (Large_m ∧ Φ_pack).
```
It remains to define the fixed sentence `Φ_pack` under `Large_m`.

### 2.2 Tag constants

`[definition]` Assume `Large_m`.  For `i=1,...,m`, define
```text
Tag_i(t) := ∃x_1 ... ∃x_i (
   Min(x_1) ∧ Succ(x_1,x_2) ∧ ... ∧ Succ(x_{i-1},x_i) ∧ t=x_i).
```
Each `Tag_i` is FO, and under `Large_m` the tags `c_1,...,c_m` are unique and
pairwise distinct.  The map `i ↦ R_i` is a fixed metatheoretic assignment.

### 2.3 Packed configuration relation

`[definition]` Let `Cnf` be a single relation symbol of fixed arity
```text
1 + A = 1 + 2r = 9.
```
An intended tuple is written `(t, y_1,...,y_A)`.  The tag `t` selects a
component relation; `y_1,...,y_{a_i}` carry the arguments of `R_i`; remaining
coordinates are canonical padding.

Define canonical padding by `Min`:
```text
Pad_{i}(y_{a_i+1},...,y_A) := Min(y_{a_i+1}) ∧ ... ∧ Min(y_A).
```
(Any fixed FO-definable padding works; projections ignore padding.)

### 2.4 FO projections and encoding

`[definition]` For each component `R_i` define the FO projection/decode
```text
Decode_i(y_1,...,y_{a_i}, Cnf) :=
   ∃t ∃z_{a_i+1}...∃z_A (Tag_i(t) ∧ Cnf(t,y_1,...,y_{a_i},z_{a_i+1},...,z_A)).
```
Define the encode/update into component `i` by
```text
Encode_i(t,y_1,...,y_A) := Tag_i(t) ∧ Pad_i(y_{a_i+1},...,y_A).
```
When a component update asserts `R_i(y_1,...,y_{a_i})`, its packed form asserts
```text
Encode_i(t,\bar y) ∧ Cnf_i-body(y_1,...,y_{a_i})  [or sets Cnf accordingly]
```
as made explicit in `Step^#` below.

`[definition]` The decode of a packed configuration `Cnf` is the simultaneous
family
```text
decode(Cnf) := (R_1^Cnf,...,R_m^Cnf),   R_i^Cnf(\bar x) :⇔ Decode_i(\bar x,Cnf).
```
A packed configuration is **canonically encoded** if every tuple with tag `c_i`
has padding `Min` in positions `a_i+1,...,A`, and no semantic information is
stored outside those positions:
```text
Canonical(Cnf) := ∀t∀\bar y (Cnf(t,\bar y) ->
   \/_{i=1}^{m} (Tag_i(t) ∧ Pad_i(y_{a_i+1},...,y_A))).
```
Canonical encoding is not needed for correctness of decode; it is maintained by
`Init^#` and `Step^#`.

## 3. FO translation of `Δ_{M_D}` and exact operator correspondence

### 3.1 Systematic decode/encode translation

`[definition]` Let `Θ(Rbar;Rbar')` be any FO formula over the current component
relations `R_1,...,R_m` and next-step component relations `R_1',...,R_m'`.
Define its packed translation `Θ^#(c,c')` as follows, where `c$ and `c'$
range over packed-configuration objects represented by relation variables
`Cnf, Cnf'$ (or, in reachability form, by individual packed tuples in the fixed
single-relation encoding below): replace every atom
```text
R_i(z_1,...,z_{a_i})      by   Decode_i(z_1,...,z_{a_i}, Cnf),
R_i'(z_1,...,z_{a_i})     by   Decode_i(z_1,...,z_{a_i}, Cnf').
```
Boolean connectives and first-order quantifiers over `W` are preserved.
This is a purely syntactic FO translation because the family and arities are
fixed.

`[definition]` The packed initial and transition formulas are
```text
Init^#(Cnf)            := Init_{M_D}^#(Cnf),
Step^#(Cnf;Cnf')       := Δ_{M_D}^#(Cnf;Cnf').
```
Equivalently, at the level of the simultaneous family,
```text
Init^#(Cnf)      iff  Init_{M_D}(decode(Cnf)),
Step^#(Cnf;Cnf') iff  Δ_{M_D}(decode(Cnf); decode(Cnf')).
```

### 3.2 Exact correspondence lemma

`[deduction]` **Lemma 3.2 (exact packed/operator correspondence).** For all
interpretations of `Cnf,Cnf'$ as relations of arity `1+A` over `A(w)$ with
`Large_m`:
1. `Init^#(Cnf) iff Init_{M_D}(decode(Cnf))`.
2. `Step^#(Cnf;Cnf') iff Δ_{M_D}(decode(Cnf);decode(Cnf'))`.
3. Consequently the one-step operator on simultaneous configurations induced by
   `Δ_{M_D}`,
   ```text
   F_Δ(Rbar)=Rbar'  :⇔  Δ_{M_D}(Rbar;Rbar') as a functional update,
   ```
   and the packed one-step relation
   ```text
   F_#(Cnf,Cnf')    :⇔  Step^#(Cnf;Cnf')
   ```
   are exactly the same operator up to decode/encode:
   ```text
   F_#(Cnf,Cnf')  iff  F_Δ(decode(Cnf)) = decode(Cnf')
   ```
   whenever `Cnf'` is the (canonical) packed encoding of that update.

*Proof.* (1),(2) are immediate by structural induction on the FO formula being
translated: atomic `R_i`/`R_i'$ cases hold by definition of `Decode_i`; Boolean
and first-order cases are preserved. (3) follows from (2) and the fact that
`decode` is surjective onto all simultaneous interpretations of the fixed family
(every `Rbar` has a packed encoding, e.g. canonical encoding
`Cnf_{Rbar}(t,\bar y) :⇔ \/i (Tag_i(t)∧R_i(y_1,..,y_{a_i})∧Pad_i)$) and that
`Δ_{M_D}` is functional/deterministic on the intended well-formed configurations
(delta-d-dfs-stack §6).  Therefore the packed one-step operator is exactly the
operator induced by the case-closed `Δ_{M_D}`. ∎

### 3.3 No-spurious/correctness inheritance

`[deduction]` By Lemma 3.2 and delta-d-dfs-stack §6:
```text
I_{M_D}(decode(Cnf)) ∧ ¬HaltAcc^Cnf ∧ ¬HaltRej^Cnf
  => ∃!Cnf' in canonical form : Step^#(Cnf;Cnf') ∧ I_{M_D}(decode(Cnf')),
```
and every `Step^#`-successor corresponds to exactly one legal `Δ_{M_D}` case and
hence to exactly one legal semantic DFS transition of `M_D^alt`.  No spurious
transition is introduced by packing, because `Step^#` has no atoms except
decoded `Δ_{M_D}` atoms.

This discharges the requested proof obligation for `[open:CKS-AV-Δ_D/PACK]`.

## 4. Fixed syntactic FO(IFP) sentence `Φ_{M_D}` over `A(w)`

### 4.1 Reachability fixed point

`[definition]` On ordered `A(w)` with `Large_m`, define the inflationary
reachability operator over the single packed configuration relation `S$ of
arity `1+A$:
```text
ψ_reach(t,\bar y, S) :=
    Init^#_{tuple}(t,\bar y)
  ∨ ∃s∃\bar z ( S(s,\bar z) ∧ Step^#_{tuple}(s,\bar z; t,\bar y) ).
```
Here `Init^#_{tuple}$ and `Step^#_{tuple}$ are the tuple-level packed forms:
they assert that the unique packed configuration encoded by a `Cnf$-style
single relation containing exactly the relevant tagged tuples for the source/target
is an initial configuration, respectively a `Δ_{M_D}$ step.  Concretely, use the
standard finite encoding of a configuration by its bounded finite family of
component relations through the single relation `Cnf$: set
```text
Cnf_S(u,\bar v) :⇔ S(u,\bar v)
```
and read/write components by `Decode_i$ / canonical tagged tuples.  Since
`S` appears only positively in `ψ_reach$, the operator is inflationary.

`[definition]` The packed acceptance subformula is
```text
Φ_pack :=
  ∃t∃\bar y (
    [IFP_{S,t\bar y} ψ_reach](t,\bar y)
    ∧ Tag_{HaltAcc}(t) ∧ Min(y_1) ∧ ... ∧ Min(y_A)
  ).
```
Thus a well-formed, large enough input is accepted iff the inflationary fixed
point of one-step `Δ_{M_D}` reachability from the packed initial configuration
contains the `HaltAcc` component.

### 4.2 The fixed sentence

`[definition]` The final fixed syntactic sentence over the fixed signature
`A(w)=(W,<,One,Hash)$ is
```text
Φ_{M_D} := (¬Large_m ∧ Φ_small) ∨ (Large_m ∧ Φ_pack).
```
It has fixed quantifier/IFP structure, fixed finite tag set, fixed component
family, fixed arities, and no dependence on `n,k$ except through the input
structure `A(w)$.

### 4.3 FO(IFP)/FO(PFP) normal form

`[literature]` On ordered finite structures, FO(IFP)=FO(PFP)=PSPACE
(Vardi 1982; Immerman 1986; Abiteboul–Vianu 1991/1995).  Therefore `Φ_{M_D}$ is
in the standard FO(IFP) normal form and has an equivalent FO(PFP) presentation
on ordered `A(w)$.  The PFP presentation may be taken as the partial fixed point
of the same first-order operator or, equivalently for deterministic halting
configuration graphs, the PFP/IFP reachability form in the chosen capture
presentation.  This note cites the equivalence only as standard literature and
uses the explicit `ψ_reach/Step^#` construction for all project-specific
content.

## 5. End-to-end proof

`[deduction,literature]` Assume `w$ is an input word and `A(w)=(W,<,One,Hash)$
its structure.

**Malformed/small.** If `Malformed$, `Φ_{M_D}$ is false on the intended branch?
`Φ_small$ is only over well-formed finite shapes with `N<m`; `Φ_pack$ is guarded
by `Large_m$ but `Init_{M_D}$ requires `WellFormed_w$ inside the CKS/AV
construction.  To make malformed rejection explicit, one may add `WellFormed_w ∧`
to both branches; this does not affect the target language, which is defined on
well-formed unary threshold encodings.

**Main chain (`WellFormed_w$).**
1. `A(w) |= Φ_{M_D}$ iff the packed `HaltAcc$ configuration is reachable by
   the IFP of `ψ_reach$ from `Init^#_{tuple}$ (definition of `Φ_{M_D}$, IFP
   semantics).
2. `ψ_reach$ adds exactly `Init^#_{tuple}$ and `Step^#_{tuple}$ successors of
   already reached packed configurations (FO definition; `S$ positive), so its
   IFP is the reflexive-transitive/iterated closure of `Step^#` from `Init^#`
   in the standard finite reachability sense `[literature]`.
3. By Lemma 3.2, packed initial/successor steps are exactly decoded
   `Init_{M_D}`/`Δ_{M_D}` steps.  Therefore (1) iff some `Δ_{M_D}` path reaches
   `HaltAcc$ from `Init_{M_D}$.
4. By delta-d-dfs-stack §6 (functional, total on non-halting well-formed states,
   invariant-preserving, no spurious transitions), `Δ_{M_D}` induces exactly the
   legal transitions of the deterministic DFS stack evaluator `M_D^alt$.
   `M_D^alt$ halts on well-formed inputs by the finite budget/DFS discipline
   established in the prior CKS/AV artifacts `[literature-context]`.  Hence (3)
   iff `M_D^alt$ accepts `w$.
5. By the prior CKS/AV/tape-formulas chain
   (`fopfp-altpack-chandra-kozen-encoding.md`, `fopfp-cks-av-tape-formulas.md`,
   delta-d-dfs-stack §7): `M_D^alt$ accepts `w$ iff the alternating DFS
   evaluation accepts the initial `M_G/G(n,k)$ state iff sorter wins `G(n,k)$
   `[literature, project model]`.
6. By the comparison-game characterization of the sorting number
   (`docs/problem.md`, `docs/research-certificates-barriers.md`): sorter wins
   `G(n,k)$ iff `S(n)<=k$ `[definition/literature]`.
7. By definition of the unary threshold language,
   `S(n)<=k$ iff `w = 1^n # 1^k ∈ SORT-BOUND-U$.

Combining (1)--(7):
```text
A(w) |= Φ_{M_D}
  iff M_D^alt accepts w
  iff sorter wins G(n,k)
  iff S(n) <= k
  iff w ∈ SORT-BOUND-U.
```
Project-specific steps are (3) Lemma 3.2, (4) `Δ_{M_D}$ correctness and
`M_D^alt$ semantics, (5) CKS/AV alternating-evaluator equivalence, and (6) the
fixed `G(n,k)/S(n)$ model.  Standard theorems used only where necessary are
FO(IFP)/FO(PFP)=PSPACE on ordered structures, finite IFP reachability
semantics, and the cited Chandra–Kozen–Stockmeyer / Vardi / Immerman /
Abiteboul–Vianu capture context. ∎

## 6. A001035 / `PACK-REPR` avoidance and non-claims

`[deduction,falsification]` The construction uses:
```text
|Cnf-packing domain contribution| = N  (elements of W, tags/values),
arity = 1 + 2r = 9 fixed,
|Cell|^q = N^{O(1)} address space for frame references,
```
but never a name for an arbitrary member of the `A001035(n)=2^{Θ(n^2)}$ labelled
posets.  `PosF$ remains a current-frame relation over `Key×Key`; `StepPosBit$
computes local closure updates; `Step^#` translates the same `Δ_{M_D}$ updates.
Packing/simultaneous relation tags index finitely many fixed component relations,
not global `Pos$ states.  Therefore no `PACK-REPR$ total tuple-coding is
introduced.

**Non-claims.** No `P$, no `FO(LFP)$ on the bare ordered word, no `NP$, no
`coNP$, no binary-encoding workstream, no separation claim, no `SORT-BOUND-B$
claim, and no Lean formalization claim.  The result is a paper-level discharge of
`[open:CKS-AV-Δ_D/PACK]$ and a fixed syntactic FO(IFP)/FO(PFP) sentence with an
end-to-end proof conditional only on the cited standard descriptive-complexity
semantics and the inherited paper-level correctness of the explicit
`Δ_{M_D}/M_D^alt/G(n,k)$ artifacts.

## 7. Final assessment

`[open:CKS-AV-Δ_D/PACK]` is discharged by an explicit single fixed-arity
configuration relation with FO tag projections/updates: `Cnf$ has fixed arity
`1+A$, `Decode_i/Encode_i$ give FO projections/updates, and `Step^# = Δ_{M_D}^#$
is exactly the packed operator induced by the case-closed `Δ_{M_D}$ (Lemma 3.2,
Section 3.3).  The fixed syntactic sentence `Φ_{M_D}$ (Section 4) over fixed
`A(w)$ has the required end-to-end equivalence (Section 5).  No A001035/PACK-REPR
and no prohibited complexity claim is made.
