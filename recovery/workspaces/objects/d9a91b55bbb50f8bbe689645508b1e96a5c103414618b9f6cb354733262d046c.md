# Annotation diversity versus the majority entropy identity

**Limited result (illustration, not a root-complexity result).**
The annotation-majority identity in §4 of
[`research-framed-certificate-frontier.md`](research-framed-certificate-frontier.md)
has no annotation-count term. The following elementary sorting tree
illustrates that annotations can change while forgetting loss is zero. It is
not a counterexample to polynomial certificate size, and makes no claim about
height `S(n)`.

## Explicit family

For each `n >= 2`, use the ordinary binary insertion decision tree sorting
`n` labelled keys. Its comparisons successively insert key `j` into the
already sorted keys `1,...,j-1` by balanced binary search. Expand it as a
tree, so no joins or annotation ambiguity are needed. Annotate each node with
the exact transitive closure `P` of the comparisons made on its path. This is
a sound height-`B(n)` framed certificate, where
`B(n)=sum_{j=2}^n ceil(log2 j)`.

At any query, the two feasible outcomes partition the extensions of `P` into
their exact child posets. Route the majority outcome (ties either way). Its
probability `q` is at least `1/2`; the child annotation is exactly the
comparison closure, so `e(Q)=m_b` and `lambda=0`. On this path, telescoping
gives

`sum log2(2q_b) = D - log2(n!) <= B(n)-log2(n!) = O(n)`.

Along any complete path there are at least `n-1` distinct stage-boundary
annotations: each insertion stage adds comparisons involving its new key,
which the earlier stage's closure cannot contain. The unfolded tree can have
up to `n!` leaves, so this observation alone gives no useful size bound; no
superpolynomial annotation lower bound is asserted.

This is not a superpolynomial-diversity family and does not establish a
polynomial-size certificate: the unfolded decision tree can be exponential.
It only illustrates that the numerical identity does not itself track
annotation count; any diversity theorem needs an additional combinatorial
argument. It also does not show that this tree's annotations are unavoidable
in another certificate for the same sorting task.

## Exact-optimum obstruction to the intended bridge

For the exact antichain-root optimum, the same identity gives only
`O(n/(log n)^(1/5))` total majority-path budget using Sergeev's
`S(n) <= log2(n!)+O(n/(log n)^(1/5))`; it still contains no diversity
statistic. However, the insertion-tree family above has budget `B(n)`, not
`S(n)`: its linear additive overhead is not `o(n)`, and no argument makes
its majority paths unavoidable in every optimal sorter. Hence it is not a
counterfamily to polynomial certificates at height `S(n)`.

The claim defensibly established is the limited logical one: **the identity
alone implies no bound on annotation diversity**. It neither proves a
superpolynomial number of annotations is necessary nor yields an upper bound
on certificate size. The general family of optimal root sorters could
nevertheless admit polynomial DAGs for reasons absent from this identity.

## Falsification checks and next obstacle

This uses exact-history annotations, so `lambda=0` by construction and
respects the identity's auxiliary majority walk; it does not confuse that
walk with a uniform input permutation. Annotation changes are caused by
retaining new comparison information, which is not charged as forgetting.
The construction is an adaptive decision tree, not a sorting network.

**Next decisive obstacle:** obtain a diversity-sensitive invariant that is
both (i) forced on at least one path of *every* height-`S(n)` antichain-root
strategy (or applies to a specified optimal construction), and (ii) converts
that diversity into a lower bound on the size of every sound framed DAG,
including forgetful joins and slot relabellings. The entropy/forgetting
identity supplies neither implication. Without such a bridge, stop: this
generic certificate observation says nothing new about exact evaluation of
`S(n)` or unary `SORT-BOUND-U`.

**Sources/model:** The entropy identity and its auxiliary-walk caveat are the
paper derivation in §4 of the linked repository frontier note. Sergeev,
*On the asymptotic complexity of sorting*, ECCC TR20-096 (2020), supplies the
near-information upper bound, not an exact-optimum annotation theorem.
No external claim about arbitrary-poset minimax complexity is used.
