## 1. Fixed model and target

`[definition]` `S(n)` is the minimum worst-case height of a deterministic adaptive comparison decision tree sorting `n` distinct labelled keys. Active unary threshold language:
`SORT-BOUND-U = {1^n # 1^k : S(n) <= k}` with input length `N=n+k+1`. A NO instance is `(1^n,1^k)` with `S(n)>k`.

`[literature]` `S(12)=30`, hence `S(12)>29` is a NO instance for `G(12,29)` (Wells 1965/1971; later confirmations summarized in `docs/literature.md`, `docs/research-n12-nontightness.md`, Stober–Weiß arXiv:2206.05597 Table 2).

`[definition]` `G(n,k)` is the comparison game: state `P` a transitively closed partial order on `[n]`; root antichain; while `P` not total and `<k` comparisons used, sorter chooses incomparable pair `q`; adversary answers `q^+` or `q^-` if consistent; `P := TC(P+answer)`. Sorter wins iff total in `<=k`. Then
`S(n)<=k  iff  sorter wins G(n,k)`, and `S(n)>k iff adversary/refuter wins G(n,k)`. `[deduction]`

## 2. Distinguish the yes framed-DAG grammar from the dual refuter grammar

### 2.1 Yes framed-DAG grammar (existing, checker-verified)

`[definition, code: scripts/check_framed_strategy.py]` A yes certificate for `S(n)<=k` is a topologically numbered DAG `(V,E,root=0)` with nodes
- `compare(a,b)` plus outgoing edges `lt,gt` to forward nodes, each with a full-slot permutation `perm in S_n`; `lt` means `a<b` before relabelling, `gt` means `b<a`; both edges are present even if one outcome is infeasible; or
- `leaf`.

The checker propagates guaranteed strict partial orders `R(v) ⊆ [n]^2` as transitively closed acyclic relations (bitmask rows). `R(root)` is empty. For an edge `v --(outcome,perm)-> w`, let `R' = TC(R(v) ∪ {outcome(a,b)})`; if cyclic, the branch is impossible and contributes nothing; else contribute `rename(R',perm)`. `R(w)` is the intersection of all feasible incoming contributions, or `None` if unreachable. A leaf is accepted only if `R(leaf)` is total. Longest reachable path depth must be `<= budget`.

This is an existential-over-sorter, universal-over-outcomes object: the DAG commits to the sorter query at compare nodes and must accept all feasible adversary outcomes.

### 2.2 Dual explicit refuter grammar (exact, natural class)

`[definition]` An **explicit total refuter certificate** for `S(n)>k` in game form is `C=(n,k,V,root,\sigma,\delta)`:
- `V` finite node set, `root in V`, each node has `state(v)=(P_v,d_v)` where `P_v` is a closed acyclic strict partial order on `[n]` (or an equivalent canonical invariant) and `d_v in {0,...,k}` is used depth.
- Root obligation: `P_root = \emptyset` (antichain), `d_root=0`.
- Move coverage: if `d_v < k`, let `Inc(P_v)={(a,b): a<b, incomparable in P_v}`. For **every** `q=(a,b) in Inc(P_v)`, `C` supplies exactly one refuter answer `b_{v,q} in {lt,gt}` and a successor `w=\delta(v,q) in V` such that `P_w = TC(P_v ∪ outcome(q,b_{v,q}))` is acyclic and `d_w=d_v+1`.
- Terminal refutation: if `d_v == k`, `v` is marked `refuted` and `P_v` is **not** total.
- (Optional compression) `C` may be hash-consed/DAG-shared on `(P,d)`; sharing is allowed only when the same invariant is reached.

This is universal-over-sorter, existential-over-refuter: the certificate must answer every legal sorter comparison but may choose the refuter outcome.

### 2.3 Crucial distinction

`[deduction]` The yes grammar proves `∃Σ ∀A : play(Σ,A) total in <=k`. The dual refuter grammar proves `∀Σ ∃A_C : play(Σ,A_C) not total in <=k`, where `A_C` is the adversary induced by `C`. They are not the same object with signs flipped: the quantifier carried by node coverage is opposite. A checked refuter checker must enforce **total coverage over incomparable sorter pairs** at certified states; an unfolded yes checker enforces correctness over all feasible outcome branches of fixed sorter queries. The repository currently has the former's dual only in yes form (`check_framed_strategy.py` has no refuter format).

## 3. Verifier cost model and obligations

### 3.1 Cost model

`[definition]` Measure verification time and certificate bit-length as functions of explicit certificate size `|C|` and the unary instance parameters `n,k,N=n+k+1`. A **succinct coNP/refuter certificate class** for `SORT-BOUND-U` would be a family of certificates `C_{n,k}` for all NO instances with `|C_{n,k}| <= poly(N)` and a deterministic verifier `V(1^n,1^k,C_{n,k})` running in `poly(N+|C_{n,k}|)=poly(N)`.

### 3.2 Obligations

A verifier for the grammar in §2.2 must check:

- `V-state`: `P_root` antichain/closed; every `P_v` closed and acyclic; depths in range.
- `V-answer-feasibility`: for each provided answer, `outcome(q,b_{v,q})` consistent with `P_v` and `TC(P_v ∪ outcome(q,b_{v,q}))` acyclic.
- `V-successor`: `delta(v,q)` points to a node with the claimed `(TC(P_v ∪ outcome), d_v+1)`.
- `V-coverage` (the refuter obligation): for every certified nonterminal node `v`, **every** `q in Inc(P_v)` has a provided answer. Since `|Inc(P_v)| <= n(n-1)/2 <= poly(N)`, this is local polytime *per certified node*.
- `V-refute`: every certified node with `d_v=k` is marked refuted and `P_v` not total.

`[deduction]` **Soundness:** by induction on depth, for any sorter strategy `Σ`, following `C` from root yields a legal play whose state after `d` steps is some certified `P_v` with `d_v=d`; at `k` it is non-total. Hence adversary wins `G(n,k)`, so `S(n)>k`.

`[deduction]` **Completeness (semantic, non-succinct).** If `S(n)>k`, the adversary has a winning strategy; its explicit total strategy graph/state table is a valid certificate in this grammar. Semantic completeness does not imply succinctness.

`[deduction]` **Verifier cost.** Let `m` be the number of certified nodes and `e` the number of certified `(v,q)` responses. Each closure/acyclicity/totality test is `O(n^3)` (Floyd–Warshall bit-matrix) or `O(n^2 * α)` in simple forms, and `|Inc(P_v)|=O(n^2)`. Thus explicit verification is
`T(V)=O((m+e) * n^3)=poly(|C|,n)=poly(|C|,N)` in the *explicit* representation. The open issue is not the per-node formula but whether a sound complete class can keep `|C|` polynomial in `N`.

## 4. Concrete checked obstruction/combinatorial facts in that grammar

`[experiment]` A local exact dual-grammar checker (bitmask closed posets, total coverage over incomparable pairs, hash-consed states by `(P,d)`) was run for small no-instances at the information-bound-adjacent budget (known: `S(3)=3,S(4)=5,S(5)=7`).

| instance | `S(n)>k`? | explicit dual-refuter cert checked? | hash-consed `(P,d)` states in minimal-state winning refuter DAG |
|---|---:|---:|---:|
| `G(3,2)` | yes | yes | 8 |
| `G(3,3)` | no | n/a | — |
| `G(4,4)` | yes | yes | 115 |
| `G(4,5)` | no | n/a | — |
| `G(5,6)` | yes | yes | 1146 |
| `G(5,7)` | no | n/a | — |

These are concrete, checked positive examples in the exact dual grammar for tiny `n`, and they calibrate that even the minimal hash-consed winning-refuter state count is already much larger than `n!`-style informal intuition would suggest at tiny scale (e.g. `1146` states for `n=5,k=6`, where `5!=120`). The experiment does **not** extrapolate to `G(12,29)` and does **not** prove a lower bound.

`[deduction]` **Concrete grammar obstruction for `G(12,29)` (explicit total refuter).** To certify `S(12)>29` in §2.2, every certified nonterminal node must provide a feasible answer for every incomparable pair the sorter may ask. A valid refuter is therefore a total adversary response system over all sorter strategies of height `<=29`. Combined with §5, no explicit total certificate in this grammar is known or plausibly small: the unfolded strategy/tree is at least `2*12!-1` nodes in the worst explicit realization (`research-certificates-barriers.md` Claim C gives the reduced sorting-tree size scale; the dual strategy object is the same universal quantifier burden over plays), and the local state universe includes labelled-poset states on 12 elements (`A001035(12)=414864951055853499`, literature/calibration). The checked small cases do not supply a `G(12,29)` certificate; available methods in the SoringP1 #301 inputs produced none (`s12k30-refuter-dag-size.md`).

## 5. Sharpened obstructions for natural refuter certificate classes

### 5.1 Explicit total refuter DAG / state table
**Class:** §2.2, all certified `(P,d)` or `(transcript)` states listed, `V-coverage` explicit.
**Obstruction:** `[literature]+[deduction]` verification is local-poly per state but `|C|` is controlled by the number of states forced by universal sorter coverage. Full labelled-poset state space is `2^{Θ(n^2)}` (Kleitman–Rothschild; OEIS A001035 calibration in `research-certificates-barriers.md` §5). Winning-frontier states cannot all be listed on the yes/winning side by the `2^{(1/4-o(1))n (log n)^2}` frontier barrier (`research-winning-frontier-barrier.md`); refuter/losing-frontier compression is dual and has no known polynomial bound. This is decisive against *explicit total enumeration*, not against all succinct proofs.

### 5.2 Finite adversary-memory machines
**Class:** explicit transducer/DAG with memory states and transitions on all sorter moves.
**Obstruction:** `[deduction]+[open]` natural sufficient memory is the current order-theoretic state/history invariant; no polynomial memory bound is known. Compressing memory while preserving `V-coverage` and `V-refute` for all continuations is equivalent in force to finding the missing succinct object below. Counting/greedy selection routes face Brightwell–Winkler `#P`-completeness for linear extensions (`[literature]`), which blocks that specific algorithmic route, not all certificates.

### 5.3 Raw alternation / game-value certificate
**Class:** use the alternating acceptance of `G(n,k)` itself as the NO witness.
**Obstruction:** `[literature]+[deduction]` `APTIME=PSPACE` gives the upper bound (Chandra–Kozen–Stockmeyer, J. ACM 1981) because the unary horizon gives polynomial rounds but alternation remains. A coNP certificate needs a one-sided existential witness with deterministic polytime verification; raw alternation does not provide it.

### 5.4 Encoding shortcuts
**Class:** sparsity/density/Mahaney invoked as a membership or separation shortcut.
**Obstruction (one-sided):** `[literature]+[deduction]` `SORT-BOUND-U` is sparse, so many-one NP-hardness would imply `P=NP` (Mahaney), and it cannot be many-one EXPTIME-hard; this constrains hardness proofs only. It gives no obstruction to `coNP` membership and no separation.

### 5.5 Search traces and root-local bad states
**Class:** exhaustive-search logs, pruned traces, single bad reachable posets, local slack/`e(P)` examples.
**Obstruction:** `[literature]+[deduction]` published `S(12)>29` arguments are exhaustive/poset-pruning computations, excluded as short certificates; a bad reachable poset is not a refuter unless forceable against every height-`k` root sorter strategy (`research-framed-certificate-frontier.md` §5). Local `e(P)` non-tightness/slack facts (`research-n12-nontightness.md`) are evidence, not a complete `G(12,29)` refuter.

## 6. Minimal missing mathematical object (falsifiable target)

The obstruction is sharpest when stated as a missing object rather than as a blanket impossibility claim.

**Missing object M.** For the family of NO instances `(1^n,1^k)` with `S(n)>k`, a **selective refuter invariant** consisting of:
1. a polynomial-size representation `I_{n,k}` (symbolic/DAG/invariant program/annotated proof object);
2. a polynomial-time local checker establishing (a) the root antichain satisfies `I`, (b) for every state satisfying `I` and every incomparable sorter query `q` there is a refuter-feasible answer whose successor satisfies `I`, and (c) any state satisfying `I` at depth `k` is non-total;
3. soundness of `I` as an adversary-winning inductive invariant for `G(n,k)`.

This is stronger in structure than raw alternation and weaker in explicitness than the full §2.2 state table: it would replace `V-coverage` over an explicitly listed state set by `V-coverage` over all states satisfying a compact invariant.

**Precise falsifier for a proposed M-candidate:** give a NO instance `(n,k)` and either
- a sorter query from an `I`-state with no `I`-preserving feasible refuter answer (breaks inductive coverage), or
- an `I`-state at depth `k` that is total (breaks refutation), or
- an explicit family where any sound `I` satisfying (b),(c) has super-polynomial representation/verifier cost under the candidate grammar.

**What would count as success (not achieved):** a uniform `I` for all `n,k`, or even a nontrivial infinite family including hard cases near `k=⌈log2(n!)⌉`, with a complete polytime checker. That would establish the corresponding certificate-class membership claim; this note does not make it.

## 7. Bottom line

For `S(12)>29` / `G(12,29)`, the natural dual to the yes framed-DAG grammar is an explicit total refuter strategy/DAG whose verifier is polynomial **per certified state** but whose core obligation is universal coverage over all sorter moves. A small checked dual grammar works on tiny instances (`G(3,2),G(4,4),G(5,6)`), but no concrete checked succinct refuter for `G(12,29)` is produced, and known explicit/exhaustive representations are not short certificates. The sharp obstruction is: **no known polynomial, polytime-checkable selective refuter invariant replaces explicit universal state/strategy enumeration**. This is a precise missing-object barrier and class-specific obstruction, not a proof that `SORT-BOUND-U ∉ coNP`.
