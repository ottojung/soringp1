## 5) Concrete expressibility obstacles (identified) **[obs]**

1. **Alternation / PSPACE nature (strong obstacle for H1).** `CanSort` is ∃ move ∀ adversary ∃ move ... of depth k (minimax). `SORT-BOUND-U ∈ PSPACE` by alternating TM in polynomial time/space (curator: `research-certificates-barriers.md` Claim A / budgeted DFS notes) **[lit/std in docs]**. FO(LFP) captures P on ordered structures (Immerman–Vardi) **[lit/std]**; FO(PFP) captures PSPACE **[lit/std]**. So an *explicit* definition in FO(LFP) would imply `SORT-BOUND-U ∈ P` (ordered uniform setting) => would have huge consequences? Or more carefully: if you can write an FO(LFP) sentence over the standard ordered encoding, then the model-checking/definability gives a P algorithm => `SORT-BOUND-U ∈ P` in the usual complexity sense (via standard encodings). Given `SORT-BOUND-U ∈ PSPACE` is proved in that model, H1 means P=PSPACE — almost certainly false. Therefore **H1 is not expected to be true**; any attempt is fighting a complexity barrier.
2. **Input-dependent depth k (unary):** k is given as unary string length after `#`. You can reference positions/times up to k by the order on that suffix, but writing a fixed-point of exactly k alternation levels in a fixed FO(LFP) formula is awkward; FO(LFP) gives unbounded (to fixed point) induction, not a bounded-depth alternation game of parameterized depth except by encoding carefully. Possibly encodable via a staged fixed point indexed by time steps — but needs care.
3. **Exponential poset-state space:** labelled posets count is `2^{Θ(n^2)}` (Kleitman–Rothschild etc., cited in curator docs) **[lit/std]**. No way to have these as first-order elements of a poly-size structure. Memoization/table over all posets is impossible in FO over input structure. Transcript/DFS explores paths but state identity is by poset equality (relation E) — representing and comparing/branching over all encountered posets is the hard part.
4. **Strategy representation (for ESO):** adaptive strategy is positional in poset state but there are exponentially many possible states; guessing a global strategy relation is not the same as guessing one poset/witness. The “certificate” is more like a strategy DAG (curator notes discuss framed certificates) — not obviously a single existential second-order relation of polynomial arity over `D_n`.
5. **No known succinct witness:** curator `research-certificates-barriers.md` argues explicit trees are exponential (≥2n!−1 nodes) and no polynomial succinct certificate is known; ESO would mean NP membership => some polynomial witness exists — open **[obs/open from docs]**.

- **n=0,1:** `1^0#1^0? Or strings "1*#1*"`. `S(0)` (empty) trivial 0 => `1^0#1^0` should be in language? Or `#` forms: depends on encoding, but values 0. Easy.
- **n=2:** `S(2)=1`. So `1^2#1^0? no, k>=0 integer; S(2)<=0? no false, S(2)<=1 true. So inputs `1^2#1^1 ∈ SORT-BOUND-U`, `1^2#1^0 ∉`.

- **n=4:** `S(4)=5`.

- **n=12 (boundary hard case mentioned):** `S(12)=30`, info bound `⌈log2 12!⌉=⌈log2 479001600⌉=29`, so `S(12)=29+1`. Thus `1^12#1^29 ∉ SORT-BOUND-U`, `1^12#1^30 ∈ SORT-BOUND-U`. This is a known “information bound not tight” example (Wells). Any proposed definition/formula must give NO for k=29, YES for k=30 at n=12. Also note the gap is +1 (small). This is a good test case for any explicit recurrence/characterization.

**What a correct FO(LFP)/ESO definition must satisfy (sanity):** on the ordered string structure of `1^12#1^29` it is false; of `1^12#1^30` true. Also it must be uniform in n,k (a single formula). No obvious small-formula obstacle from these numeric values alone, but the *combinatorial* existence of a depth-30 strategy (not depth-29) is the content (the Ford–Johnson/merge-insertion family gives strategies; the lower bound is the hard part, shown by adversary/search in literature). 

**Falsification attempt on “naive FO(LFP) by unrolling k levels”?** Suppose someone tries to write: “exists move1 forall reply1 ... exists move_k forall reply_k (reached total)”. If written as a fixed FO formula with k alternations inside, formula size depends on k — but formula must be fixed (independent of input) for FO(LFP). So cannot be a fixed FO formula when k varies; you might try to encode levels by unary suffix positions (use LFP to step through k positions) — doable in form? Maybe, but still the state-space/strategy-encoding problem remains (how to quantify over poset relations/states across steps inside FO(LFP) on this structure?). No concrete counterexample to “some encoding exists”, but a strong methodological obstacle: standard descriptive complexity uses fixed vocabularies/formulas over the input structure.

**No contradiction found on small n values** from the numbers; the obstacles are structural (complexity/representation), not small-case counterexamples.
