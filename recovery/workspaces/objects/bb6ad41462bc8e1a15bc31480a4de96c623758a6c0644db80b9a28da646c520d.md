# Framed DAG witness for exact `S(5)=7` (exec report)

## 1. Problem statement and `S(5)` baseline

- **Task/front:** `framed-dag-witness-n5-exact` (falsifiable, independent). Construct or derive an explicit, checkable permutation-framed strategy DAG certificate of exact height `S(5)=7` for `n=5` (budget 7), or document the smallest certified budget/obstruction; verify with the soundness checker when possible; report exact node/edge/depth/profile and structural observations.
- **Model/certificate:** deterministic adaptive comparison sorting of distinct labelled elements; framed strategy DAG format and soundness as in [`docs/research-framed-certificate-frontier.md`](docs/research-framed-certificate-frontier.md) and checked by [`scripts/check_framed_strategy.py`](scripts/check_framed_strategy.py) (acyclic DAG, forward edges, comparison nodes with outcome-specific slot permutations, relation propagation + intersection at joins, total order at leaves, depth ≤ budget). The checker is a **soundness** check of an explicit certificate; it does not assert completeness/optimality in general.
- **Baseline:** `S(5)=7` is the known exact sorting number for `n=5` (e.g. [`docs/problem.md`](docs/problem.md), [`scripts/strategy_dag_probe.py`](scripts/strategy_dag_probe.py) `KNOWN`, literature table in `docs/research-plan.md` context). Information bound `ceil(log2(5!))=7` is tight here.

## 2. Methods, tools, and commands

**Tools/docs consulted:** `scripts/check_framed_strategy.py`, `scripts/strategy_dag_probe.py`, `docs/research-framed-certificate-frontier.md`, `docs/problem.md`, `tests/test_framed_strategy.py`.

**Method (construction):** computed the exact minimax value `F(P)` over labelled successor-bitmask poset states for `n=5` (same state/closure model as `scripts/strategy_dag_probe.py`: `extend` by transitive closure, `incomparable_pairs`, total when all pairs comparable). Selected **one** optimal policy by choosing the first incomparable pair `(i,j)` (lexicographic over `i<j`) with `1 + max(F(P+i<j), F(P+j<i)) == F(P)` at each state. Serialized to the framed-certificate JSON schema with **identity slot permutations** on every arc (`perm = [0,1,2,3,4]`) and nodes indexed in construction order (forward/topological). States were hash-consed by identical labelled `succ` tuples during generation (attempted DAG sharing); no duplicate states occurred for this chosen policy, so the result is a rooted tree.

**Commands executed (representative):**

```bash

python3 scripts/strategy_dag_probe.py --max-n 5

# generate + verify exact-height witness (construction logic as above)

# comparison envelope (non-optimal height, polynomial-size path example)
python3 scripts/check_framed_strategy.py --bubble 5

# derived measurements
# -> produced witness_n5_h7_framed_stats.json
```

(Generation was performed via an inline Python script in `/tmp` importing `minimax_values, extend, incomparable_pairs, is_total` from `scripts/strategy_dag_probe.py`; the resulting durable artifacts are saved in this worktree.)

## 3. Concrete results / witness

**Produced artifacts:**
- [`witness_n5_h7_framed.json`](witness_n5_h7_framed.json): explicit permutation-framed strategy DAG certificate, `n=5`, `budget=7`.
- [`witness_n5_h7_framed_stats.json`](witness_n5_h7_framed_stats.json): machine-derived size/profile summary.

**Certified witness (checked):** exact height/depth **7** at budget **7** for `n=5`.

| Metric | Value |
|---|---:|
| `n` | 5 |
| budget | 7 |
| max depth (accepted) | 7 |
| total nodes | 239 |
| compare (internal) nodes | 119 |
| leaf nodes | 120 |
| directed edges | 238 |
| graph shape | tree (`edges = nodes-1`, rooted at 0) |
| slot permutations | identity on all arcs |

**Depth histogram (nodes at distance from root):** `{0:1, 1:2, 2:4, 3:8, 4:16, 5:32, 6:64, 7:112}` (112 nodes at depth 7: 120 leaves total reached across feasible optimal paths in this certificate structure).

**Structural observations (evidence from this witness + probe):**
- This exact-height certificate is an **explicit optimal-policy tree** in labelled slot space, not a compressed multi-parent DAG: hash-consing by labelled poset state yielded **no merges** (239 nodes), consistent with `strategy_dag_probe.py` for one optimal policy at `n=5` (`unshared(1)=239`, `DAG(1)=239`, `DAG(all)=1551`, union over all optimal strategies).
- The **symmetry quotient** (S_n-canonical poset classes) for one optimal policy is much smaller (`quotient(1)=11`, `quotient(all)=19` per `strategy_dag_probe.py`), indicating substantial relabelling redundancy in the labelled view; exploiting it inside a *sound framed* certificate would require non-identity frame/meet design (not done here).
- **Polynomial-envelope comparison (size vs height):** the sound bubble witness is very small but non-optimal in height (`n=5`: 11 nodes, depth 10, quadratic construction `n(n-1)/2` comparisons). Existing all-n framed constructions discussed in `docs/research-framed-certificate-frontier.md` target polynomial node counts at larger (merge/Ford–Johnson) heights (e.g. O(n²) nodes, path lengths O(n log n) or FJ bound), and do **not** establish exact optimal height `S(n)` in general. Thus, at `n=5` we have a checked exact-height-7 framed witness with 239 nodes; no polynomial-size-at-exact-height claim follows from this single instance.

## 4. Verification performed

- **Primary soundness check:** `python3 scripts/check_framed_strategy.py witness_n5_h7_framed.json` → **`ACCEPT: n=5, depth=7, nodes=239`** (exit success). The verifier confirms local feasibility/closure/frame validity, forward acyclicity constraints, relation intersection, total-order leaves on reachable outcomes, and depth ≤ budget.
- **Sanity/control:** `python3 scripts/check_framed_strategy.py --bubble 5` → **`ACCEPT: n=5, depth=10, nodes=11`** (confirms checker/environment on a known polynomial non-optimal witness).
- **Consistency:** construction uses the same minimax/closure primitives as `scripts/strategy_dag_probe.py`, which reports `S(5)=7` and matching single-policy DAG size (239) for `n=5`.
- **Not performed / not claimed:** no Lean formalization; no claim that this witness is unique, minimal in nodes among height-7 framed certificates, or representative of an all-`n` polynomial-size exact-height scheme.
