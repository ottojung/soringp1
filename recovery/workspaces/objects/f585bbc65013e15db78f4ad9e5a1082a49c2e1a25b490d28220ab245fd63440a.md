## Concrete gaps (what blocks discharge)

1. **[open:PACK] / fixed-arity Code/Decode.** No definition of `Code(C; z̄) : W^p \to$ config codes for fixed `p$ (packing `Pos/Used/Sel/Ctrl` into tuple(s)/a fixed-arity relation), no decoding formulas, no encoding/decoding lemmas, no proof of faithfulness. The schematic `PosCode` note remains unresolved.
2. **Obligation (2): initial code correctness.** Need `InitCode` to uniquely encode `Init(C_0)$ and to be FO-definable from `A(w)$ given `Code/Decode`.
3. **Obligation (3): transition faithfulness.** Need `YieldECode ⇔ YieldE`, `YieldA0Code ⇔ YieldA0`, `YieldA1Code ⇔ YieldA1` under `Code/Decode` (preservation/reflection), covering TC/budget/legal-move conditions.
4. **Obligation (4): alternating PFP soundness/completeness.** Need stage correspondence for `ψ_ACC$ (each PFP stage = one backward acceptance step of `T$), finite rank bound of `G(n,k)$ covered by chosen stage arity `r$ (sufficient since `k <= N(n-1)/2 = O(N^2)$ but game phases `<= 2k+O(1)=O(N^2)$; need explicit stage bound argument), and least fixed-point convergence to `LFP(T)$.
5. **End-to-end equivalence proof.** No completed proof that `A(w)|=Φ_game ⇔ M_G$ accepts ⇔ sorter wins `G(n,k)$ ⇔ `S(n)<=k$.

## Precise minimal residual step

**Discharge `[open:PACK]` and prove (2)-(4):**
- Choose one standard global normal form (e.g. stage-indexed ATM acceptance PFP over fixed-arity configuration codes, or simultaneous tuple encoding) consistent with §5.2.
- Define fixed-arity `Code(C; \bar z)$ with explicit decoding `DecodePos/DecodeUsed/DecodeSel/DecodeCtrl` over `A(w)$; prove coding lemma (faithfulness, unique decoding).
- Write global operator as single FO formula `ψ_ACC$ in that normal form using only those decodings/codings.
- Prove simulation lemma obligations (2)-(4) for the chosen normal form using §4 local formulas as semantic truth conditions.
- (Optionally) justify stage bound for alternating game rank `O(k)$.

No local `G(n,k)` rule is missing; the gap is purely global coding + the alternating PFP correspondence proof.
