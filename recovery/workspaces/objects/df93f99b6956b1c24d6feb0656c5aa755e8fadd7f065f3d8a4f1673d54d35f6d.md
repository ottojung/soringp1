# Exact-height permutation-framed DAGs: soundness, completeness gap, and obstacles

**Status (2026-11-05, local research note).** Paper-level analysis; not
Lean-checked. Labels: `[definition]`, `[deduction]`, `[literature]`,
`[experiment]` (from cited repo notes/scripts), `[open]`. No unconditional
complexity separation, no NP-hardness, and no NP membership claim.

**Task.** Assess the falsifiable question: is there a polynomial-size, all-`n`,
sound **and complete** permutation-framed DAG/certificate class at exact height
`S(n)` (an NP-style witness system for yes instances of
`SORT-BOUND-U = {1^n#1^k : S(n) <= k}`)? If not known, give a precise
soundness/completeness obstacle and a falsifiable test.

This note does **not** repeat the known framed soundness result or
winning-frontier enumeration barrier except as fixed inputs; see
[`research-framed-certificate-frontier.md`](research-framed-certificate-frontier.md),
[`research-certificates-barriers.md`](research-certificates-barriers.md),
[`research-strategy-certificates.md`](research-strategy-certificates.md),
[`research-winning-frontier-barrier.md`](research-winning-frontier-barrier.md),
and [`scripts/check_framed_strategy.py`](../scripts/check_framed_strategy.py).

## 0. Fixed inputs

`[definition]` `S(n)` is the minimum worst-case height of a deterministic
adaptive comparison decision tree sorting every permutation of `n` distinct
labelled keys. `SORT-BOUND-U` has unary `n,k`; informative yes instances have
input length `N = n+k+1 = Θ(n log n)` and `k >= C(n)=⌈log₂ n!⌉`.
`[literature]` Exact values are known for `n <= 22`; `S(12)=30 > C(12)=29`
(Wells); `S(n)-log₂ n! = o(n)` (Sergeev). `[deduction]` `SORT-BOUND-U ∈ PSPACE`
(game formulation), and a reduced explicit sorting tree has `2n!-1` nodes, so
it is not a polynomial certificate in `N`.

## 1. The permutation-framed poset-guarantee class (PGF)

`[definition]` A **PGF certificate** is an acyclic comparison DAG with root 0.
Each non-leaf node `v` names a comparison `(a,b)` on current slots and two
outcome edges `lt` (`a<b`) / `gt` (`b<a`) to forward nodes, each carrying an
explicit permutation frame `π_v,out : [n] -> [n]`. Each node `v` has an implicit
annotation `R(v)` = a transitively closed strict partial order (or ⊥ for
impossible), computed by:

- `R(0)=∅` (antichain).
- For an outcome edge `v --(out,π)--> u` with feasible `R(v)`, let
  `R'(v,out)=TC(R(v) ∪ {smaller<larger})`; if contradictory, the branch is ⊥;
  otherwise `E(v,u,out)=rename(R'(v,out),π)`.
- `R(u)=⊥` if all incoming branches are ⊥, else
  `R(u)= ⋂ {E(v,u,out) : feasible incoming edge}` (bitwise meet on successor
  relations, followed by closure consistency in the abstract sense used here).

A leaf is accepting only if `R(leaf)` is a total order. The certificate is
**sound at budget `k`** if every reachable accepting path has length `<= k` and
every feasible real input permutation is sorted by some execution.

`[deduction]` PGF is exactly the class whose local checks are implemented by
`check_framed_strategy.py`: feasibility/closure/permutation validity, total
leaves, and max depth `<= budget`, in time polynomial in explicit graph size and
`n`. The meet is a sound over-approximation: intersecting guaranteed relations
never asserts a comparison not justified on every feasible incoming history.

## 2. Known positive boundary (not repeated as a new result)

`[literature]/[paper construction, audit pending]` (from
`research-framed-certificate-frontier.md`):

- Soundness and polynomial checking for explicit PGF graphs.
- A quadratic-node bubble-sort PGF witness for all `n` at budget `n(n-1)/2`.
- A polynomial-node balanced merge-sort PGF construction at path length
  `O(n log n)` (comparison count, not exact optimal except special cases).
- A plausible polynomial PGF for the Ford–Johnson upper bound `F_FJ(n)`
  (lifted rank-envelope/insert frames; full recursive frame audit pending).

`[experiment]` `F_FJ(n)=∑_{j=1}^n ⌈log₂(3j/4)⌉` equals the known exact values of
`S(n)` for all `1 <= n <= 22` where `S(n)` is published in this repo's notes.
This is **not** evidence of all-`n` exact optimality of Ford–Johnson:
`F_FJ(n)=log₂(n!)+Θ(n)` while `S(n)=log₂(n!)+o(n)` `[literature, Sergeev]`, so
a complete all-`n` PGF system cannot be obtained by proving FJ exact.

**Completeness status.** `[open]` No theorem is known that every yes instance
`1^n#1^{S(n)}` has a polynomial-size PGF certificate, and no theorem is known
that some yes instance lacks one. NP membership of `SORT-BOUND-U` via PGF (or
any other succinct certificate) remains open.

## 3. Precise obstacle O1: meet-induced incompleteness of naive optimal encodings

This is a **soundness/completeness obstruction for naive encodings**, not a
proof that no PGF exists.

`[deduction]` **O1 (poset-meet information loss).** Let `T` be any correct
deterministic adaptive comparison strategy (tree or DAG of histories). Define a
PGF-like compression by identifying history nodes and setting
`R_join = ⋂ R_in`. This compression is **sound** only as a certificate checker
on states it accepts, but it can become **incomplete for the original strategy**:
if a comparison after a join is justified only by the disjunction
`⋁_h R_h` of incoming path guarantees and not by their intersection, then the
compressed node has `R_join` too weak to certify the next comparison/leaf, and
the checker must reject even though `T` is correct.

Equivalently, PGF node annotations form a meet-semilattice of single partial
orders under intersection; they cannot represent disjunctive path knowledge
except by duplicating nodes (un-sharing). This is the formal content behind the
frontier warning: an arbitrary correct comparator network need not be accepted
if outcomes are joined immediately. `[deduction, frontier]`

**Consequence.** A polynomial-size PGF for exact height `S(n)` cannot be
obtained by merely hash-consing or quotienting an optimal comparison tree by
equality/isomorphism of *raw histories* unless the chosen join/renaming scheme
also makes every post-join guarantee certifiable from a single intersected poset.
The obstacle is therefore **representation of disjunctive residual knowledge**,
not raw tree size alone.

## 4. Obstacle O2: single-policy trees have no identical-poset sharing

`[deduction]` (from `research-strategy-certificates.md`, Thm 2.6/Cor. 2.7). In a
reduced deterministic comparison **tree**, distinct reachable nodes have distinct
labelled poset states, because distinct nodes have different permutation sets
(disjoint in different subtrees, strictly nested ancestor/descendant). Hence
hash-consing by identical labelled posets saves zero nodes in a single optimal
policy: `DAG_labelled(1)=2n!-1`.

PGF is stronger than labelled-poset hash-consing because it may rename slots by
`π` and identify states only up to the *certificate's* chosen frames; this is
quotient/strategy-sharing, not graph isomorphism solving. `[deduction]` But O2
shows the trivial compression route is unavailable; any poly PGF at `S(n)` must
use nontrivial frame choices and/or a strategy whose post-join guarantees remain
single-poset certifiable.

## 5. Obstacle O3: what the winning-frontier barrier does and does not give

`[deduction]` The winning-frontier theorem gives
`2^{(1/4-o(1))n log² n}` nonisomorphic reachable winning states at a common
depth, even at budget `S(n)` by Sergeev's `S(n)-C(n)=o(n)`. It rules out any
method that **enumerates** the full winning frontier. It does **not** rule out a
poly-size PGF: a PGF may represent one selected optimal strategy and may join
many histories, provided the meets preserve enough guarantees. Therefore O3 is a
barrier to frontier enumeration, not a completeness obstruction for PGF.

## 6. Exact-height tension (falsifiable)

`[open, falsifiable target]` **H-exact-PGF:** For every `n`, some PGF of size
`poly(N)=poly(n log n)` accepts `1^n#1^{S(n)}`.

`[deduction]` Known constructive PGFs cover *upper bounds* (bubble `n(n-1)/2`,
merge-sort `O(n log n)` comparisons, plausibly FJ `F_FJ(n)`); they witness
`SORT-BOUND-U` yes instances at those budgets but do not settle H-exact-PGF
because exact optimality at all `n` is not supplied. The first informative exact
stress points from literature values are:

| n | C(n)=⌈log₂ n!⌉ | S(n) | F_FJ(n) | gap S-C | note |
|---:|---:|---:|---:|---:|---|
| 12 | 29 | 30 | 30 | 1 | info bound not tight (Wells) |
| 13 | 33 | 34 | 34 | 1 | non-monotone poset phenomena known |
| 16 | 45 | 46 | 46 | 1 | first refutation of old conjecture context |
| 20 | 62 | 62 | 62 | 0 | info bound tight |
| 22 | 70 | 71 | 71 | 1 | largest fully settled in cited notes |

`[deduction]` These rows show no separation between `S(n)` and `F_FJ(n)` on
known values, so they cannot falsify H-exact-PGF; they only identify where an
exact-optimal PGF, if FJ frames are fully audited, would also be an exact
`S(n)` certificate on current knowledge. Asymptotically FJ cannot witness
H-exact-PGF.

## 7. A concrete falsification/obstruction program

To turn O1 from a warning into a decisive result, one of the following
falsifiable outcomes is needed:

1. **Completeness obstruction (class-specific).** Exhibit an infinite family
   `(n_i,k_i=S(n_i))` and prove that every sound PGF of height `<=k_i` has size
   `>= 2^{Ω(f(N_i))}` for super-polynomial `f`, by showing that any sufficient
   set of join-stable single-poset guarantees must split on exponentially many
   disjunctive optimal histories. This would refute H-exact-PGF for PGF.
2. **Representation theorem (positive).** Give an all-`n` construction of a
   `poly(N)`-size, sound PGF at height `S(n)`, or at least at
   `log₂(n!)+o(n)`. This would prove `SORT-BOUND-U ∈ NP` (and, combined with
   `S_unary ∈ FP` equivalence to the threshold, place exact evaluation in NP via
   the usual search-to-decision view under a suitable certificate convention;
   the direct claim to record is NP membership of the threshold language).
3. **Finite distinguisher.** For a known exact case, either (a) produce and
   independently check a PGF at height `S(n)` smaller/more structured than a
   tree, or (b) prove no PGF at height `S(n)` exists below some explicit size for
   that `n` by exhaustive/constraint search over the PGF grammar. Case (a) does
   not prove all-`n` completeness; case (b) would be a finite incompleteness/no-go
   for that budget and size.

**New falsifiable test (local, decisive relative to PGF class).** `[deduction]`
Fix `n` with known `S(n)` and enumerate/constraint-solve for a **minimum-size
sound PGF** at budget `S(n)` under a normalized frame convention (e.g. canonical
slot relabelling of total/partial orders, bounded node count). Compare its size
to `2n!-1` and to any poly-in-`N` target. A verified finite PGF at `S(n)` for a
nontrivial `n` (especially `n=12`, where the information bound is not tight)
would refute the claim "PGF cannot represent exact-optimal play except as a
tree"; a certified lower bound against all PGFs up to a meaningful size would
make O1 quantitative. This test is not carried out here.

## 8. Answer to the falsifiable question

`[deduction]` **No polynomial-size, all-`n`, sound and complete PGF certificate
class at exact height `S(n)` is currently known.** The existing evidence is:

- **Soundness:** yes, for explicit PGF graphs (poly-time checkable).
- **Completeness for non-optimal/all upper bounds:** constructive families exist
  at bubble/FJ/merge heights, but FJ is not proved exact for all `n` and is
  asymptotically too large to witness exact `S(n)`.
- **Exact-height completeness:** open.

The precise obstacle is **not** Parberry's network-verification hardness, not the
winning-frontier enumeration count, and not the mere `2n!-1` tree size by
itself. It is **O1: single-poset meet annotations cannot express post-join
disjunctive guarantees without node splitting**, combined with **O2: a
single-policy optimal strategy has no identical-labelled-poset sharing**. A
positive all-`n` exact result would require a representation theorem showing
that some optimal strategy's residual knowledge is compressible into polynomially
many join-stable poset frames; a negative result would require proving that such
compression forces super-polynomial splitting at exact height `S(n)`.

Until O1 is resolved by theorem 7.1 or 7.2, PGF gives no NP certificate for
`SORT-BOUND-U` and no proved obstruction to one; the question is a sharp open
frontier, not a closed complexity classification.
