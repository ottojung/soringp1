Experiment 3: Polynomial bound test
----------------------------------------------------------------------

Polynomial bound test: log2(nodes) vs n
If log2(nodes) ~ c*n, DAG is exponential. If ~ c*log(n), polynomial.

----------------------------------------------------------------------
Experiment 4: Verifier complexity
----------------------------------------------------------------------

A polynomial-in-DAG-size verifier would:
  1. Check each node is a valid poset (transitive closure).
  2. Check each edge (pair, yes_child, no_child) is valid.
  3. Check the DAG has no cycles (topological order).
  4. Check the root reaches a total order within k steps.

This is O(DAG_size * n^2) = poly(DAG_size, n).
BUT: this only verifies a GIVEN DAG. It does NOT prove S(n) <= k
without a polynomial-size DAG existing.

----------------------------------------------------------------------
Experiment 5: Concrete no-go for naive polynomial certificates
----------------------------------------------------------------------

If a polynomial-size DAG certificate existed for S(n) <= k,
then SORT-BOUND-U would be in NP (unary encoding).

But SORT-BOUND-U is sparse (Lemma 3.1 of research-encoding-consequences.md).
By Mahaney's theorem, a sparse set is not NP-hard under many-one
reductions unless P = NP.

This is a CONDITIONAL barrier, not a proof that no poly DAG exists.
It shows: IF a poly-size DAG certificate exists AND SORT-BOUND-U is
NP-hard, THEN P = NP. So the naive route to NP-hardness is blocked.

The DAG approach does NOT claim NP membership without a size bound.
