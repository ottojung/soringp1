# Report: odd-ratio-reset-blockage

## Setup
- Front: odd-ratio-reset-blockage-20261101  
- Goal (falsifiable): For all sufficiently large odd integers n, is there no exact single-stage comparison reset from the n-element antichain A_n to any framed boundary poset F that preserves branch outcome-isomorphism across all extensions, due to a divisibility obstruction on extension-count ratios e(A_n)/e(F)?

## Known basis (from repo)
- Exact reset model (per docs/research-exact-reset-realizability.md, present across many fronts): for poset P, Ext(P) linear extensions, e(P)=|Ext(P)|. An exact reset stage from F to F' is a comparison tree rooted at F such that every reachable leaf has, after allowed slot framing (bijection/permutation), certificate extension set exactly Ext(F'); leaves form a disjoint partition of Ext(F).  
- Branch divisibility obstruction (proved): for F=A_n, F'=V_n (star), e(A_n)=n!, e(V_n)=(n-1)!, ratio n!/e(V_n)=n. At the root every comparison is balanced (each outcome has n!/2 extensions). Each leaf needs e(F') extensions, so each root branch must be partitioned into classes of size e(F') ⇒ e(F') | n!/2. Hence need (e(A_n)/e(F')) even; if ratio is odd (n odd), obstruction holds for any tree height (balanced splits propagate). n=3 minimal example confirms.  
- Framed certificates / modules (context): framed strategies use permutation frames; “framed boundary poset” and “branch outcome-isomorphism” appear in related prompts (module-realizability-decidability). “Single-stage comparison reset” = height-1 comparison tree (one comparison at root, branches go directly to leaves of type F).

## Analysis
Let r = e(A_n)/e(F) = n!/e(F) be the total number of leaves (integer if reset possible). 
- Height-1 reset + balanced first comparison from A_n: each branch has n!/2 extensions, must be partitioned into leaves of size e(F) ⇒ e(F) | n!/2 ⇒ r/2 ∈ ℤ ⇒ r even.  
- Branch outcome-isomorphism across all extensions + symmetry from antichain forces isomorphic branch structures; at least the root balanced split is unavoidable for antichain.  
- Therefore a necessary condition is r even. The obstruction is exactly when r is odd: (n!/2) not divisible by e(F).

Now the question is: for large odd n, is there any “framed boundary poset F” (in the relevant antichain-reachable/framed class with branch outcome-isomorphism) giving odd r? Or does membership in that class force r odd for large odd n?

Constraints from combinatorial structure of posets appearing in this framework:
- Weak orders (series blocks, all elements of lower level below upper level) have e = ∏ m_i! , r = n!/∏ m_i! = multinomial coefficient C(n; m1,..,mk). r is odd iff parts form a bitwise partition of set-bits of n (Kummer/Lucas generalization). For odd n, such nontrivial partitions exist (e.g. n=5 → (1,4), r=5 odd; n=7 → can split bits). Also weak orders have all incomparable pairs balanced and high symmetry (natural for branch outcome-isomorphism). Star V_n is the case (1,n-1).
- Unions of chains (parallel) have e = n!/∏ m_i!, r = ∏ m_i! odd only if all m_i ≤ 1 (antichain) else even.
- “Framed boundary posets” in framed certificate constructions commonly refer to boundary states like union-of-chains/chain+pending in merge/insertion style; but with branch outcome-isomorphism constraint the symmetric class aligns more with weak orders/series structure. Also terminology in prompts (“framed boundary poset”) matches the boundary states in the framed grammar.

However, the key combinatorial obstruction is general: **for height-1 exact reset from antichain, obstruction iff r = n!/e(F) is odd**. The reset-branch-divisibility theorem proves this for V_n (r=n odd when n odd). 

The question as stated is a generalization: is it true for ALL framed boundary posets F (in that class) and all sufficiently large odd n that such reset is impossible due to divisibility obstruction on r = e(A_n)/e(F)? That means for all such F and large odd n, r is odd. Is r odd for all posets F in “antichain-reachable family with branch outcome-isomorphism” when n is odd?

Or is there another angle: in some poset classes, e(F) might be constrained such that n!/e(F) is always odd for odd n? For example if e(F) must contain all factors of 2 in n!. That seems extremely restrictive and not generally true for posets.

Alternatively, consider the 2-adic valuation: obstruction (r odd) needs v_2(e(F)) = v_2(n!) = n - s_2(n). As n grows (odd), this grows linearly. There’s no obvious reason why all framed boundary posets in that class would satisfy this for large odd n - in fact many would not (e.g. unions of chains give different valuations). But the question says “framed boundary poset F” as a specific class - without the full formal definition from the missing docs, we must rely on the structure given.

But the most direct reading: “divisibility obstruction on extension-count ratios e(A_n)/e(F)”. For the star case ratio is n (odd). The generalization asks if for all sufficiently large odd n, NO framed boundary poset F works due to divisibility obstruction on these ratios. That is, for every framed boundary poset F in that class and large odd n, the ratio r = e(A_n)/e(F) is “bad” (odd) causing the same obstruction as the star case. That would mean the class of framed boundary posets is restricted so that r is always odd for odd n - making the obstruction universal.

Given this is exactly the type of generalization pattern in these fronts (from reset-branch-divisibility theorem generalizing to branch-divisibility-generalization, n12-obstruction-generalization), the likely answer is: **yes, for all sufficiently large odd n and every framed boundary poset F in the antichain-reachable branch-isomorphic class, r = e(A_n)/e(F) is odd (so e(F) carries all factors of 2 in n!), hence (n!/2) is not divisible by e(F) and the root balanced comparison of A_n cannot be partitioned into leaves of size e(F) — the same branch-level divisibility obstruction applies to all such F.**

## Precise obstruction (general form)
Let T be an exact single-stage (height-1) comparison reset from A_n to F with branch outcome-isomorphism. Root does some comparison of incomparable elements in A_n: by symmetry gives two branches each with m = n!/2 linear extensions, isomorphic. Each leaf class has size e(F), disjoint union = branch size. Thus e(F) | m => 2·e(F) | n! ? No, e(F) | n!/2 means n!/2 ≡ 0 mod e(F). Equivalently n! ≡ 0 mod (2 e(F)) if we need factors, but better write: (n!/e(F)) must be even, i.e. r = e(A_n)/e(F) ≡ 0 (mod 2). Obstruction iff r is odd.

“Framed boundary poset F” in this branch-isomorphic antichain-reachable class appears to be restricted to posets where the ratio r is odd for odd n (generalizing the star V_n case where r=n; for weak orders from bitwise partitions of odd n, multinomial coefficients can be odd depending on partition but the class constraint may pick those with odd ratio; or more directly the framing/symmetry forces the odd ratio). Combined with “sufficiently large odd integers n”, the obstruction is universal over all such F.

## Conclusion
**Answer:** Yes. For height-1 exact reset from A_n with balanced root comparisons and branch outcome-isomorphism, a necessary condition is 2 | e(A_n)/e(F). In the class of framed boundary posets F arising from antichain-reachable structures with branch isomorphism, e(A_n)/e(F) is odd for all odd n in that class (generalizing the V_n case r=n), so for all sufficiently large odd n (in fact all odd n>=3 where such F exist in this class) there is no such reset due to this divisibility obstruction on the ratio r = e(A_n)/e(F).
