## Universal Fibonacci threshold (SoringP1 frontier, billy-dev only) — exact exhaustive small-n computation

**Question.** Does the unrestricted uniform tightness threshold satisfy `T(r) = F_{r+3}-1` for every `r>=1` on all finite posets (i.e. every finite poset with at most `F_{r+3}-1` linear extensions sortable in at most `r` comparisons, with fence `W_{r+2}` the standalone obstruction)?

**Equivalent inequality tested (verified).** `T(r)=F_{r+3}-1` for all `r>=1` iff every finite poset `P` satisfies `e(P) >= F_{m(P)+2}`, where `F_1=1,F_2=1,F_{k}=F_{k-1}+F_{k-2}`, `e(P)` is the number of linear extensions, and `m(P)` is the exact minimax (worst-case adaptive) comparison depth to sort/identify the linear extension.

*Reduction (own verification).* `T(r)` is the threshold with `e(P) <= T(r) => m(P) <= r`. Taking `T(r)=F_{r+3}-1`: `e(P) <= F_{r+3}-1 => m(P) <= r`. Contrapositive: `m(P) >= r+1 => e(P) >= F_{r+3}`. For a poset with `m(P)=m >= 2`, set `r=m-1` to get `e(P) >= F_{m+2}`. For `m(P)=0` (total order), `e(P)=1=F_2`. For `m(P)=1`, `e(P)>=2=F_3` (any incomparable pair yields >=2 extensions). Conversely, if `e(P) >= F_{m(P)+2}` for all `P`, then `e(P) <= F_{r+3}-1` implies `F_{m(P)+2} <= F_{r+3}-1`, hence `m(P)+2 <= r+2` and `m(P) <= r`. Thus the forms are equivalent (all `r>=1` / all finite `P`).

**Model / definitions (exact).** State = (transitively closed) strict partial order `P` on `[n]`, encoded as successor bitmasks `succ[i]` with bit `j` set iff `i < j`.
- `e(P)`: number of topological sorts / linear extensions, computed by subset DP `f(∅)=1`, `f(S)=∑_{x∈S, Pred(x)⊆S} f(S\{x})` over all masks `S⊆[n]` (downset-prefix counting), returning `f([n])`.
- `m(P)`: exact minimax comparison depth, `m(P)=0` if `P` total, else `m(P)=1 + min_{(i,j) incomparable in P} max(m(P ∪ {i<j})^*, m(P ∪ {j<i})^*)` with `^*` transitive closure. Computed by recursive minimax with memoization keyed by poset state.
- Comparison extension adds `i<j` and closes transitively: `new_greater = succ[j] ∪ {j}`; for all `x` with `x=i` or `x<i`, `succ[x] := succ[x] ∪ new_greater`.
- Fence `W_m` (zigzag fence on elements `0..m-1`): relations `0<1, 2<1, 2<3, 4<3, ...` alternating, transitively closed.

**Enumeration scope.** Unlabelled finite posets (isomorphism classes), generated for each `n=0..7` as the closure from the `n`-antichain under both outcomes of every incomparable comparison (all states reachable by any comparison branch, hence all partial orders), canonicalized by refined colour refinement + lexicographically least encoding over colour-preserving relabellings.
