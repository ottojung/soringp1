## 0. Baseline `[literature/deduction]`

For function evaluation `d=Theta(S(n))`, both are `O(n log^2 n)` bits `[deduction, docs/research-budgeted-dfs.md]`.

## 1. Class definitions `[definition]`

- **`C_path` (transcript/path-storing exhaustive DFS).** Uniform deterministic algorithms that decide/evaluate by exhaustive depth-first exploration of the comparison game and, at every reached node of transcript depth `t`, store an explicit representation sufficient to identify the ordered sequence of the `t` comparison outcomes on the current root-to-node path and to resume the deterministic enumeration of the sorter's candidate moves at every ancestor after backtracking. Reachability/comparability may be recomputed in separate workspace.
- **`C_state` (state-storing / canonical-state / checkpoint-resumable).** Uniform deterministic algorithms whose persistent configuration contains a representation of the current partial order `P` (or a canonical name for it) from which all legal moves and the minimax value `F(P)` are recoverable, possibly together with pending control but *not* relying on an explicit comparison path/transcript.
- **Checkpointing.** A special case of either class: selected configurations are stored and non-stored ancestors are regenerated; a checkpoint that can resume must contain either path information (hence `C_path`) or a resumable state (hence `C_state`).
- **Oracle/advice.** An algorithm may be given an external string purportedly naming the current state or path; for a uniform deterministic exact evaluator, that string is part of the mutable/auxiliary information and is subject to the same counting bounds (and would be nonuniform advice if fixed in advance).

## 2. Barrier for `C_path` (established) `[deduction]`

**Theorem P (path-storage barrier).** Every algorithm in `C_path` uses `Omega(S(n) log n)=Omega(n log^2 n)` bits of work space on infinitely many `n`, in particular for all sufficiently large `n` on successful runs reaching depth `S(n)`.

*Argument.* A successful evaluation has a root-to-leaf path of depth `S(n)=Theta(n log n)`. Each level must encode/resume a move/outcome from an alphabet of size `Theta(n^2)` (at least `Omega(log n)` bits) to avoid repeating or skipping branches after backtracking. Hence `Omega(S(n) log n)` persistent bits. The time constraint sub-`2^{O(n^2)}` is satisfied by the known transcript-only DFS and is orthogonal. ∎

*Falsifier.* Exhibit any `C_path` algorithm and an infinite family of `n` on which it uses `o(n log^2 n)` bits while correctly deciding/evaluating in sub-`2^{O(n^2)}` time.

## 3. Barrier for `C_state` (new, counting) `[deduction]`

**Theorem S (winning-frontier state-count barrier).** There are infinitely many `n` (namely `n=s^2` with `s=2^r`) such that the set of pairwise nonisomorphic n-vertex partial orders that are (i) reachable from the n-antichain by exactly `t` legal comparisons and (ii) winning with remaining budget `S(n)-t` has size at least `2^{(1/4-o(1)) n (log_2 n)^2}`. Consequently, any algorithm in `C_state` must use `Omega(n log^2 n)` bits of work space for at least one such state.

*Source.* `docs/research-winning-frontier-barrier.md` (independent-edge construction; exact finite witnesses `n=224`, `>2^39` states, and `n=256`, `>2^148` states; tests `tests/test_winning_frontier_barrier.py` pass). The construction specializes to budget `k=S(n)` because Sergeev gives `S(n)=log_2(n!)+o(n)`, so the surplus is sublinear `[literature/deduction]`.

*Argument.* A `C_state` algorithm's persistent configuration must distinguish the current partial order among the legal states it can be in; otherwise it cannot enumerate the correct legal moves or compute `F(P)`. The family above has `2^{Omega(n log^2 n)}` pairwise nonisomorphic (hence mutually distinguishable) members, so any injective encoding of the family requires `Omega(n log^2 n)` bits. This is an information-theoretic lower bound on the size of a resumable state representation, not on time. ∎

*Scope note.* This does **not** rule out algorithms that neither store a path nor a state (e.g. a closed-form or implicit enumeration that never materializes the current poset). It rules out state-storing/checkpoint-resumable paradigms whose correctness depends on knowing `P`.

*Falsifier.* Exhibit a `C_state` algorithm using `o(n log^2 n)` bits, or prove that the winning-frontier family can be represented/identified in `o(n log^2 n)` bits despite its cardinality (e.g. by a non-injective but resumable encoding).

## 4. Combined obstruction for path-or-state paradigms `[deduction]`

**Theorem C (combined).** For infinitely many `n`, any uniform deterministic exact evaluator of `S(n)`/`SORT-BOUND-U` whose persistent mutable configuration is either (a) an explicit comparison path/transcript (`C_path`) or (b) a resumable representation of the current partial order (`C_state`) requires `Omega(n log^2 n)` bits. Checkpointing cannot escape this: every checkpoint that can resume must be of type (a) or (b), so at least one checkpoint costs `Omega(n log^2 n)` bits; with `o(n log^2 n)` bits total, no checkpoint can be resumable and regeneration would have to be path/state reconstruction, which is exactly the obstructed class. Oracle/advice strings naming the current state or path are subject to the same `Omega(n log^2 n)` information bound.

*What this does not prove.* It does not prove an unconditional `Omega(n log^2 n)` lower bound for *all* uniform deterministic algorithms in a standard Turing model, because an algorithm might avoid both storing a path and storing a state (for example by a structural/closed-form evaluation or by an implicit representation not captured by (a)/(b)). No such algorithm is known.
