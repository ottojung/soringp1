# Succinct coNP/refuter certificates for `S(n) > k` — format analysis and obstructions

**Status:** research note (paper analysis; no new computation, no Lean). Labels: `[definition]`, `[literature]`, `[deduction]`, `[open]`, `[conjecture]`. This note is local work product for SoringP1 #301 (billy-dev) and does not change `main`, Lean, or the research board.

**Model (fixed).** `[definition]` `S(n)` is the minimum height of a deterministic adaptive comparison decision tree that sorts every permutation of `n` distinct labelled keys. The active decision language is unary

`SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }`,

with actual input length `N = n+k+1`. A **NO instance** is therefore `(1^n,1^k)` with `S(n) > k`. A succinct polytime-verifiable coNP/refuter certificate for NO instances, uniform in `n,k`, would mean that `SORT-BOUND-U ∈ coNP` under standard witness verification measured in `N`.

**Relevant established context.** `[literature]+[deduction]` `SORT-BOUND-U ∈ PSPACE` via the comparison game / alternating formulation (Chandra–Kozen–Stockmeyer `APTIME=PSPACE`; see `docs/research-certificates-barriers.md`, Claim A). `[literature]+[deduction]` The unary language is sparse, so ordinary many-one NP-hardness would imply `P=NP` (Mahaney); it is not many-one EXPTIME-hard (`docs/research-hardness-boundaries.md`, `docs/research-encoding-consequences.md`). `[deduction]` An explicit sorting-tree witness is not a polynomial NP certificate on informative unary inputs because a reduced correct tree has `2*n! - 1` nodes while `N=Θ(n log n)` there (`docs/research-certificates-barriers.md`, Claim C). `[open]` Neither `SORT-BOUND-U ∈ NP` nor `SORT-BOUND-U ∈ coNP` is known.

## Question

Is there a succinct, polynomial-time verifiable coNP/refuter certificate for NO instances `S(n) > k`, uniform in `n,k` (dual to the YES framed-DAG certificate frontier), or is there a decisive obstruction for natural certificate classes: winning-frontier/adversary-memory certificates, alternation/strategy certificates, and encoding-related classes?

## Answer summary

**(A) No concrete uniform succinct coNP/refuter certificate is established here.** A candidate certificate format can be stated (an explicit adversary/refuter strategy against all height-`k` sorter strategies), but the natural verifier is not polynomial-time in the input length; it is itself an alternating/game verification. 

**(B) Precise obstructions (for stated natural classes).** 
1. **Winning-frontier / explicit-state refuter enumeration:** enumerating all winning/reachable states or all height-`k` sorter strategy outcomes is not a succinct certificate class; it hits the exponential/DAG state explosion and, on the winning side, the `2^{(1/4-o(1)) n (log n)^2}` nonisomorphic winning-frontier barrier (`docs/research-winning-frontier-barrier.md`). This rules out explicit-frontier refuter certificates, not all coNP certificates.
2. **Finite adversary-memory strategies with polynomial explicit memory graph:** no polynomial bound on the number of memory states needed by an optimal refuter is known; the natural memory is a partial-order/state object and the reachable/winning poset space is exponential (`2^{Θ(n^2)}` in general; A001035 calibration in `docs/research-certificates-barriers.md`, §5). Thus explicit finite-state adversary certificates are not known succinct.
3. **Alternation-as-certificate:** the YES/NO game has polynomially many rounds in unary input length but existential/universal alternation remains. A coNP certificate would need a *one-sided* polynomial witness whose verification avoids universal quantification over all sorter moves; the PSPACE upper bound supplies alternating computation, not such a witness.
4. **Encoding barrier (one direction only):** sparsity/Mahaney blocks many-one NP-hardness of `SORT-BOUND-U` (and is irrelevant to binary density) but gives **no obstruction** to membership in coNP (or NP). It only constrains hardness proofs.

No claim is made that `SORT-BOUND-U ∉ coNP`; that remains `[open]`.

## (A) Candidate certificate format (not proved succinct/verifiable)

### A1. Semantic refuter object

`[definition]+[deduction]` Let `G(n,k)` be the comparison game: sorter chooses incomparable pairs, adversary answers `x<y` or `y<x`, state is a transitively closed partial order, sorter wins if a total order is reached within `k` comparisons. Then

`S(n) > k`  iff  adversary has a winning strategy in `G(n,k)`.

A **refuter certificate** is therefore naturally an adversary strategy `A`:
- input to `A` at step `i ≤ k`: history `(q_1,b_1,...,q_{i-1},b_{i-1},q_i)` or current state `(P_{i-1},q_i)` where `q_i` is an incomparable pair chosen by the sorter and `P_{i-1}` is the current poset;
- output: `b_i ∈ {q_i^+, q_i^-}` (an outcome consistent with `P_{i-1}`);
- winning condition: for every sorter strategy `Σ` of height `≤ k`, the play `Σ || A` reaches step `k` with a non-total poset.

### A2. Proposed explicit encoding

`[definition]` A concrete (but not known succinct) encoding is a **refuter DAG/decision graph**:
- nodes indexed by reachable game states `(P,d)` or by transcript prefixes, where `d` is depth;
- for every node and every legal sorter move `q` incomparable in `P`, an edge labeled `(q -> b, P')` where `P' = TC(P+b)`;
- root `(antichain_n,0)`;
- every node at depth `k` is marked `non-total`.

Soundness/completeness at the semantic level are immediate if the graph is total over all sorter moves:
- **Completeness (semantic):** if `S(n)>k`, some adversary strategy exists; its strategy graph witnesses NO.
- **Soundness (semantic):** if every legal sorter move at every reachable certified node has a certified refuter answer and depth-`k` nodes are non-total, no height-`k` sorter strategy wins.

### A3. Verifier and why it is not polynomial-time

A verifier would need to check:
1. `V1` (well-formed state): root is antichain, depths increase, outcomes are consistent with poset/transitive closure.
2. `V2` (totality over sorter moves): for every certified state `(P,d)` with `d<k` and `P` not total, **for every incomparable pair** `q` in `P`, the certificate provides a legal answer. There are up to `O(n^2)` pairs per state.
3. `V3` (NO condition): all certified depth-`k` states (or all leaves reachable under all sorter moves through depth `k`) are non-total.

The semantic proof is a universal statement over sorter strategies. In the explicit graph form, `V2` is locally checkable per state but the number of states may be exponential. In a compressed/program form, checking `V2` becomes: for the represented refuter program, does it answer every legal sorter move and force non-totality within `k`? That is a strategy-validity/game question, not known to be in deterministic polynomial time. 

`[deduction]` Therefore this candidate gives **soundness/completeness as a strategy object**, but **not** a known polytime verifier in input length `N` unless the representation is proved polynomial and `V2/V3` are proved polynomially checkable. It does **not** establish `SORT-BOUND-U ∈ coNP`.

## (B) Precise obstructions for stated natural classes

### B1. Winning-frontier / explicit-state refuter certificates

**Class.** Certificates that explicitly enumerate, hash, or list refuter/winning-frontier states: e.g. all posets at some depth, all winning states, all transcript outcomes, or a table mapping every relevant `(P,q)` pair.

**Obstruction.** `[literature]+[deduction]`
- The memoized/poset DP state space is the number of labelled posets, `2^{Θ(n^2)}` (Kleitman–Rothschild; A001035 calibration in `docs/research-certificates-barriers.md`, §5), so full-state enumeration is exponential in numeric `n` and super-polynomial in unary `N=Θ(n log n)` on informative instances.
- The winning-frontier barrier proves a stronger obstruction on the *winning* side: for infinitely many `n`, at common depth `t` and budget `k=⌈log₂(n!)⌉` (and, by the sublinear-surplus extension, at exact `k=S(n)` using Sergeev's `S(n)-C(n)=o(n)`), there are at least `2^{(1/4-o(1)) n (log n)^2}` pairwise nonisomorphic winning states with `F(P) <= k-t` (`docs/research-winning-frontier-barrier.md`). Consequently any certificate/verifier that must output or inspect the full winning frontier is ruled out.
- An explicit reduced comparison tree has `2*n! - 1` nodes (`docs/research-certificates-barriers.md`, Claim C), exponential in `N`.

**Evidence/citations.** Kleitman–Rothschild (Trans. AMS 205, 1975); OEIS A001035; `docs/research-certificates-barriers.md` §5/Claim C; `docs/research-winning-frontier-barrier.md`; Sergeev, *On the asymptotic complexity of sorting*, ECCC TR20-096 (2020), for `S(n)-log₂(n!)=o(n)`.

**Scope of obstruction.** Decisive for *explicit-frontier/enumeration* certificate classes. It does **not** rule out selective, symbolic, or otherwise compressed coNP witnesses whose validity can be checked without enumerating states.

### B2. Finite adversary-memory certificates

**Class.** Refuter strategies represented as explicit finite-state transducers/mealy machines/DAGs whose states are adversary memory states and whose transitions cover sorter moves.

**Obstruction.** `[deduction]+[open]` The natural sufficient memory is the current partial order (or an equivalent transcript invariant), because the legal adversary answers and future refuter value depend on the order-theoretic state. No theorem is known bounding optimal adversary memory by `poly(N)`. Known size lower bounds for *all* reachable or *all* winning states are exponential (`B1`), and the certificate must be total over sorter moves from every certified state it can reach. Therefore:
- if memory states are arbitrary labelled posets/states, the explicit machine can have `2^{Θ(n^2)}` states;
- if memory is compressed, the compression must preserve universal totality over all incomparable pairs and all induced continuations; proving that such compression exists for all `n,k` is exactly the succinct-certificate problem.

**Evidence/citations.** `docs/research-certificates-barriers.md` (poset state space, absence of succinct canonical optimal-play object); `docs/research-winning-frontier-barrier.md` (winning states cannot all be listed); Brightwell–Winkler (STOC 1991, counting linear extensions #P-complete) is a barrier for the greedy/counting route, not a direct memory lower bound.

**Scope.** A strong practical/structural obstruction to *explicit finite-memory* refuters; not a proof that no polynomial adversary-memory representation exists.

### B3. Alternation / universal strategy verification

**Class.** Certificates whose verification is "run the refuter against every sorter strategy" or, dually, use the raw alternating acceptance condition as the witness.

**Obstruction.** `[literature]+[deduction]` `G(n,k)` is an alternating game. In the unary encoding, the horizon gives polynomially many moves but still alternates: sorter existential, adversary universal in the original game value; a NO certificate needs the adversary to win against **all** sorter choices. `APTIME=PSPACE` (Chandra–Kozen–Stockmeyer, J. ACM 1981) explains membership in PSPACE, but a coNP certificate requires collapsing this two-sided alternation into an existential witness with deterministic polynomial verification. No such collapse is known for `SORT-BOUND-U`.

**Evidence/citations.** Chandra–Kozen–Stockmeyer, *Alternation*, J. ACM 28(1):114–133, 1981, doi:10.1145/322234.322243; `docs/research-certificates-barriers.md` Claim A.

**Scope.** Decisive against using raw alternation as a coNP certificate. It is not evidence against all possible succinct invariants that might imply adversary victory.

### B4. Encoding-related classes

**Class.** Arguments that attempt to use unary sparsity, binary density, or the mere existence of a small threshold window to force/prohibit coNP/refuter certificates.

**Obstruction/limit.** `[literature]+[deduction]`
- **Unary sparsity:** Mahaney's theorem blocks many-one NP-hardness of sparse sets unless `P=NP`; Ogiwara–Watanabe gives a Turing-collapse consequence. This constrains *hardness* routes, not membership. It does not show `SORT-BOUND-U ∈ coNP` and does not show `SORT-BOUND-U ∉ coNP`.
- **Binary density:** `SORT-BOUND-B` is not sparse, so Mahaney does not apply; this note's unary obstruction claims do not transfer automatically to binary.
- **Small numeric window:** `k` is informative only in a window of width `O(n)` in numeric `n` (`problem.md`), but a certificate must still be uniform and polytime-checkable in the encoded input and must justify the global value `S(n)>k`, not merely a local comparison count.

**Evidence/citations.** Mahaney, JCSS 25(2):130–143, 1982; Ogiwara–Watanabe, SICOMP 20(3):471–483, 1991; `docs/problem.md`; `docs/research-certificates-barriers.md` Claim B.

**Scope.** Rules out using encoding/sparsity as a decisive obstruction to coNP membership.

## Conclusion

For `SORT-BOUND-U`, a succinct polytime-verifiable coNP/refuter certificate for `S(n)>k` would be an adversary strategy (or equivalent invariant) that is universal over all height-`k` sorter plays yet checkable in `poly(N)`. The natural semantic refuter exists iff `S(n)>k`, but known explicit representations either enumerate exponential state/frontier objects or leave universal strategy validity unverified. The decisive obstructions established here are class-specific: explicit winning-frontier/enumeration certificates, raw alternation-as-certificate, and encoding-based hardness shortcuts do not yield a uniform succinct coNP certificate. Finite adversary-memory certificates are obstructed by the absence of any polynomial memory bound and by exponential state/frontier growth, but this is not a separation proof.

**Falsifiable next test (not performed).** Measure optimal refuter-memory / losing-frontier state counts for small `n,k` near the information bound (dual of the optimal-play state count suggested in `docs/research-certificates-barriers.md`, §8): if refuter play can be confined to polynomially many states, a compressed coNP-certificate route remains plausible; if it scales with the full poset/winning-frontier explosion, that strengthens the adversary-memory obstruction evidence. Either outcome is evidence, not a complexity-class proof.
