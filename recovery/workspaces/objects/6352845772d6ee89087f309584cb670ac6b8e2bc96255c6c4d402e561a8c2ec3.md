## PGF/obstruction summary `[definition]/[deduction]`
A permutation-framed PGF certificate (checker format) is an acyclic comparison DAG with root state `R(0)=∅`. A feasible comparison outcome extends `R(v)` by `smaller<larger`, takes transitive closure, applies the edge permutation; a join node gets `R(u)=⋂` of feasible incoming renamed guarantees. Leaves must be total orders; max path depth `<= k`. This is sound and locally checkable in polynomial time in explicit graph size and `n` (`check_framed_strategy.py`). It is **not** known complete at exact height `S(n)`.

- **O1 (meet-induced incompleteness).** The meet of single posets cannot represent disjunctive incoming guarantees: if downstream correctness needs a fact present on one branch but contradicted/absent on another, `R_join` may be too weak and the checker rejects even when an unjoined strategy is correct. This is a representation/naive-encoding obstacle, not a proof that no PGF exists.
- **O2 (single-policy tree sharing).** In a reduced deterministic comparison tree, distinct nodes have distinct labelled poset states, so identical-labelled-poset hash-consing saves nothing for one policy. PGF is stronger because frames can normalize/rename; O2 only rules out the trivial compression route.
- **O3 (frontier barrier, not used as a completeness proof).** Winning-frontier enumeration is ruled out by state counts, but a selected strategy may still be small.

### 1. Accepted joined fragment (disjunctive behavior exposed, but meet preserved by frames)
`accepted_join_n3`, `n=3,k=3`: root compares `(0,1)`; `lt` uses identity, `gt` uses swap `(1,0,2)`. Both edges target node 1, so histories with opposite raw outcomes **join** after frame normalization into the identical state `{slot0 < slot1}`. The checker accepts:
```
ACCEPT depth=3 nodes=6
```
Interpretation `[deduction]`: joins/disjunctive control-flow are representable in PGF **when** frames make the meet preserve sufficient guarantees. This is a positive local existence for frame-normalized joins, not a certificate for `S(n)`.

### 2. Rejected O1 fragment (same join class, meet loses 0v1)
`o1_reject_n3`, `n=3,k=3`: same topological join shape but `gt` keeps identity frame, so branch states carry `0<1` vs `1<0`. Join nodes receive meet that drops the 0v1 relation. A leaf reached after that join is rejected:
```
REJECT leaf 3 does not sort 0,1
```
Interpretation `[deduction]`: the checker correctly rejects an unsound/incomplete-by-meet join. The failure is local and structural (O1), independent of budget except reachability.

### 3. O1 fragment instantiated at the hard case `(n,k)=(12,30)`
`o1_reject_n12_budget30`, `n=12,k=30`: first comparison `(0,1)` produces `0<1` or `1<0`; second compares `(2,3)` on both branches and joins the `2<3` outcomes with identity frames. Meet is `{2<3}` and cannot certify `0,1`.
```
REJECT leaf 3 does not sort 0,1
```
Interpretation `[deduction]`: O1 is **active at the hard-case parameters** as a concrete local constraint — any framed join that discards the `0v1` disjunction before a total leaf is certifiable is rejected by existing checker logic at `(12,30)`. This does **not** prove that no other exact-height-30 PGF exists for `n=12`; it proves that this concrete framed-join subclass (identity/no-normalizing frames at that join point, or any join whose meet loses an unresolved required pair) cannot be completed to an accepted certificate.

## Finite search/constraint argument (bounded scope) `[experiment]/[deduction]`

### Tiny exact sanity
Exact poset-minimax sanity values from the script: `S(3)=3`, can sort at 3, cannot at 2; `S(4)=5`, can sort at 5, cannot at 4. (Implementation note: the memoized helper returns the minimax height and the script reports the standard values.)

### Why an exhaustive global framed-join search at `(12,30)` was not performed
An exact decision tree for `n=12` has `12! = 479,001,600` leaves and `2*12!-1` nodes; optimal/exact-height strategies are not represented here, and the search space over PGF graphs with arbitrary joins, frames, and node identities at budget 30 is astronomically larger than any finite enumeration feasible in this environment. Therefore no claim is made from an exhaustive global search over all PGF certificates at `(12,30)`.

### Bounded class-specific constraint (reproducible)
The following finite class is ruled out by the checker as a **local completion mechanism**:
> **C_id-loss (identity-frame disjunction-losing join):** a PGF execution reaches two feasible histories whose guaranteed posets disagree on some pair `(p,q)` and agree/are incomparable on other recorded facts used to justify a join, the join is taken with frames/permutations that do not make `(p,q)` uniformly certifiable in the meet, and the joined subgraph later requires a total leaf or comparison justified only by that lost pair. 

For C_id-loss, `R_join[p][q]=R_join[q][p]=0` at the join, so the existing checker must reject every completing leaf in that joined region that still needs `(p,q)` ordered. `o1_reject_n12_budget30` is a concrete instance at `(12,30)`. This is a finite, reproducible constraint argument on a named class; it is **not** a bound on all framed joins, because frame normalization (as in `accepted_join_n3`) can sometimes make meets equal/strong enough.

### O2 finite evidence (tiny n, not n=12)
Global labelled-poset reachability over all feasible comparisons/outcomes shows reachable-state collisions (`n=3`: 19 states, 24 collision-events; `n=4`: 219 states, 826 collision-events), but O2 states the opposite for a **single deterministic policy tree**: distinct nodes of one reduced policy cannot share identical labelled poset states. This confirms the distinction used in the obstruction note; it gives no information about `n=12` exact strategies.

## Scope and limits
- **Established here:** existing checker accepts a sound frame-normalized joined fragment; rejects O1 join fragments that lose required disjunctive guarantees, including a concrete fragment at `(n=12,k=30)`. This validates O1 as a local, machine-checkable obstruction mechanism.
- **Not established:** no exact-height-30 PGF for `n=12` was constructed (and `S(12)=30` optimal strategies are not available as small explicit objects here). No exhaustive/global search proved that all PGF classes fail at `(12,30)`. No lower bound on exact-height PGF size for `n=12`. No NP/coNP claim.
- **Falsifiability:** O1 for a proposed joined fragment is falsified by running `check_framed_strategy.py` on that fragment; C_id-loss is falsified for a specific fragment if the checker accepts. A positive exact-height-30 PGF for `n=12` would falsify any stronger global nonexistence claim (none made). A certified exhaustive/constraint proof over a normalized bounded PGF grammar at `(12,30,S(12)-1 or S(12),size<=B)` would make the bounded search decisive; not done.

## Conclusion `[deduction]`
For the hard case `(n,k)=(12,30)`, O1 is concretely instantiated: the existing PGF checker rejects a framed join whose meet loses a required comparison fact (`o1_reject_n12_budget30`). Frame normalization can create accepted joins (`accepted_join_n3`), so the obstruction is **class-sensitive** (meets must preserve/normalize post-join guarantees), not an immediate global impossibility proof. O2 remains a policy-level non-sharing fact that rules out trivial identical-state compression of a single optimal tree; it was not turned into an `n=12` exact-height size lower bound. The exact question “is there any poly/explicit-size sound PGF of height `S(12)=30`?” remains open and is not settled by this finite falsify test.
