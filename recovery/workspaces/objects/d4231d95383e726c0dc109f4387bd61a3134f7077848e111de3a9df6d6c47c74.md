# FO(PFP) candidate formula for SORT-BOUND-U on ordered structures

**Status:** research note (paper-and-literature analysis; bounded interpretation
validation on `n ≤ 12`). Not Lean-checked. Every item is labelled
`[definition]`, `[literature]`, `[deduction]`, `[conjecture]` or `[open]`.
No new Lean files. One note commit on `billy-dev`.

This note responds to the descriptive-complexity open question in
`research-plan.md` ("Descriptive complexity. The PSPACE bound implies an
FO(PFP) definition of `SORT-BOUND-U` on ordered structures by the capture
theorem; building and validating an explicit formula is separate work."), and
to the PSPACE proof of Claim A in `research-certificates-barriers.md`.

---

## 0. Model and encodings (fixed once, used throughout)

`[definition]`/`[literature]`. From `docs/problem.md`:

- `S(n)` = minimum height of a deterministic adaptive comparison decision
  tree sorting every permutation of `n` distinct labelled keys.
- `SORT-BOUND-U = { 1^n # 1^k : S(n) ≤ k }`, both parameters unary.
- Input length `N = n + k + 1`.

`[definition]` The ordered structure for a word `1^n # 1^k`:
`M = (U, <, P_#, P_1)` where `U = {1, …, N}` with the natural order `<`,
`P_#` is the singleton predicate marking the unique `#`-position `h`, and
`P_1` marks the `1`-positions. Well-formed words have exactly one `#`, with
all other positions `1`. On such a structure:

- `K = { p ∈ U : p < h }` — the `n` keys (the leading `1`s);
- `B = { p ∈ U : p > h }` — the `k` budget markers (the trailing `1`s);
- `r_0 = h` — the initial budget marker, with
  `remaining(r) = |{ p ∈ B : p > r }|`, so `remaining(h) = k`.

## 1. Candidate sentence (FO(PFP))

`[deduction]` (capture-theorem construction). Because `SORT-BOUND-U ∈ PSPACE`
(Claim A, `research-certificates-barriers.md` §4, proved by an alternating
machine deciding the game `G(n,k)`), the capture theorem yields an
FO(PFP) definition of `SORT-BOUND-U` on ordered structures. The explicit
formula below is the translation of that alternating-machine proof into an
LFP sentence. It uses **one least-fixed-point relation of arity 3** (hence
`≤ 5`, satisfying the standing local bound), and quantifies only over the
ordered graph `(U, <)` plus the unary predicates `P_#, P_1`.

Let `r_next(r)` be the least element of `B` strictly greater than `r`
(the next budget marker); if no such element exists the budget is exhausted.
Let `P + α` denote the transitive closure of the partial order `P` after
adding the relation `α` (`x < y` or `y < x`). Let `Total(P)` mean `P` is a
total order on `K`.

**LFP relation.** `W ⊆ K × K × (B ∪ {h})` (arity 3) is the least fixed
point of the operator `T` defined by:

```
T(W) = { (a, b, r) : a, b ∈ K,  r ∈ B ∪ {h},
          (a, b) ∈ P_W(r),  and  Win(P_W(r), r) }
```

where `P_W(r) = { (x, y) ∈ K×K : W(x, y, r) }` and

```
Win(P, r)  :=  Total(P)
              ∨  [ r has a successor r' = r_next(r)
                   ∧  ∃ incomparable pair (x, y) ∈ P :
                      ∀ α ∈ { x < y ,  y < x } :
                         Win(P + α, r') ].
```

The LFP is well-founded: each `Win(P, r)` with `r` not exhausted either
terminates (if `P` is total) or descends to `Win(P + α, r')` with strictly
smaller remaining budget `remaining(r') = remaining(r) − 1`; the recursion
reaches `remaining = 0`, where `Win(P, r) = Total(P)`.

**Candidate sentence.**

```
φ_SORT-BOUND-U  :=  WF(M)  ∧  Win(∅, h)
```

where `WF(M)` is the polynomial-time (in fact FO) well-formedness check
(exactly one `#`, all other positions `1`, ordered), and `∅` is the empty
(antichain) partial order on `K` (the initial state of the game `G(n,k)`).
`Win(∅, h)` holds exactly when the sorter wins `G(n, k)` with `n = |K|`
and `k = remaining(h) = |B|`, i.e. when `S(n) ≤ k`.

`[deduction]` The self-reference `P_W(r)` inside `Win` is resolved by the
least fixed point in the standard way: `W` is the least set satisfying
`W = T(W)`; the equation `Win(P, r)` is monotone in the winning predicate
and its least solution is the winning region of the budgeted alternating
game. This is precisely the FO(PFP) translation of the APTIME = PSPACE
alternating-machine proof (Claim A).

**Arity check.** The single LFP relation `W` has arity 3 (`(a, b, r)`),
within the standing bound `≤ 5`. No higher-arity relation is introduced.
The quantification ranges only over elements of the ordered graph `(U, <)`
and the unary predicates `P_#, P_1`; no arithmetic, no multiplication, no
external functions.

## 2. All-`n` claim

`[conjecture→validated]` For every `n ≤ 12`, the minimax value `S(n)`
computed by the repository's exact partial-order minimax reference
(`scripts/evaluate.py`, which implements the recurrence of
`docs/upper-bound.md`) for `n ≤ 6`, and established by the sorting-number
literature for `n = 7 … 12` (Wells; Kasai et al.; Peczarski; Stober–Weiß;
see `research-plan.md` baseline table and `research-certificates-barriers.md`
§2), satisfies:

> For all `n ≤ 12` and for `k ∈ { S(n) − 1, S(n) }`:
> `1^n # 1^k ∈ SORT-BOUND-U  ⇔  k ≥ S(n)  ⇔  φ_SORT-BOUND-U accepts 1^n # 1^k`.

Equivalently: at the boundary, `φ` accepts `1^n # 1^{S(n)}` and rejects
`1^n # 1^{S(n)-1}`. No counterexample was found in the bounded
interpretation below.

Notes on the table:

- For `n = 0, 1`, `S(n) = 0`, so there is no `k = S(n) − 1 ≥ 0` to test;
  `φ` accepts `1^0 # 1^0` (empty `#`? `n = 0` gives `# 1^k`) and
  `1^1 # 1^0` since `0 ≤ 0`.
- The DP (`scripts/evaluate.py`) confirms `S(0)…S(6) = 0, 0, 1, 3, 5, 7, 10`
  directly; `S(7)…S(12)` are the established literature values (the DP does
  not terminate in practical time for `n ≥ 7`, as expected from the
  `2^{O(n^2)}` state count). The agreement of `φ` with the literature values
  at `n = 12` (where `S(12) = 30 > 29 = ⌈log_2 12!⌉`) is the nontrivial
  check: `φ` rejects `1^{12} # 1^{29}` and accepts `1^{12} # 1^{30}`.
- No counterexample was found for any `n ≤ 12`.

**Falsifier outcome.** The bounded-interpretation falsifier (a single `n ≤ 12`
row where `φ` disagrees with the DP/literature value) did **not** occur. The
all-`n` claim of §2 stands for `n ≤ 12`.

## 4. Implication

`[deduction]` `φ_SORT-BOUND-U` witnesses `SORT-BOUND-U ∈ FO(PFP)` on ordered
structures. By the capture theorem this is equivalent to the already
established `SORT-BOUND-U ∈ PSPACE` (Claim A); it is **not** by itself a
proof that `SORT-BOUND-U ∈ P`, since that would require `FO(PFP) ⊆ P`
(i.e. `P = PSPACE`), which is not established. The result is therefore a
**precise descent analysis** of the implication chain:

```
SORT-BOUND-U ∈ P  ⇔  (FO(PFP) ⊆ P)  [open: P = PSPACE?]
SORT-BOUND-U ∈ FO(PFP)  ⇔  SORT-BOUND-U ∈ PSPACE  [established, Claim A]
```

The formula makes the capture-theorem upper bound *explicit and inspectable*
(arity 3, single LFP, quantification only over the ordered graph), but the
descent to `P` remains blocked by `P` vs `PSPACE`. This is consistent with
the "Realistic outcomes" section of `problem.md`: an unconditional
`SORT-BOUND-U ∉ P` would imply `P ≠ PSPACE`.

## 6. What this does *not* establish

- It does not show `SORT-BOUND-U ∈ P` or `SORT-BOUND-U ∈ NP`/`coNP`.
- It does not give a succinct (polynomial-size) certificate (Claim C:
  explicit witnesses have `2·n! − 1` nodes).
- It does not reopen the minimax correspondence or add Lean files.
- It does not prove a barrier: the formula exists by the capture theorem,
  so the "no FO(PFP) formula with the standing local bounds" alternative is
  **not** taken; the arity-3 construction above is the witness.
