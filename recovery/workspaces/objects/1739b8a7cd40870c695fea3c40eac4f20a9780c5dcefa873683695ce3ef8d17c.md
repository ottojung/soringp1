# Beyond permutation-framed poset-meet certificates: FO(TC)/FO/ESO-style and nonframed polynomial-checkable formats at exact height S(n)

**Status (2026-11-05, local research note).** Paper-level analysis; not
Lean-checked. Uses local unverified artifact
`../exact-s12-height-dag-obstruction-20261105/docs/exact-s12-height-dag-obstruction.md`
as framing context only; claims here are labelled independently.
Labels: `[definition]`, `[literature]`, `[deduction]`, `[open]`,
`[falsifiable]`. No unconditional separation, no NP-hardness, no NP
membership, and no new complexity-class placement is claimed.

## 0. Falsifiable question

`[definition]` Fix the unary threshold language
`SORT-BOUND-U = {1^n # 1^k : S(n) <= k}`, where `S(n)` is the minimum
worst-case height of a deterministic adaptive comparison decision tree
sorting every permutation of `n` distinct labelled keys. Informative
yes instances have `k >= C(n)=ceil(log2 n!)`, so input length
`N = n+k+1 = Theta(n log n)`.

**Question.** Beyond the permutation-framed poset-meet class PGF, whose
naive optimal encodings face meet/disjunction obstacles O1/O2
(`[deduction]`, local height-DAG note; see also
`research-framed-certificate-frontier.md` and
`research-strategy-certificates.md`), is there an exact height-`S(n)`
certificate/program format that is

1. **sound**: a polynomial-time verifier accepts only true yes instances
   of `SORT-BOUND-U`;
2. **complete for all `n`** at the exact optimum: every `1^n#1^{S(n)}`
   has such a certificate of size `poly(N)` (or a verifier that checks a
   `poly(N)`-size object/program in `poly(N)` time under a fixed
   convention); and
3. drawn from a **nonframed** or logic/program-based family such as
   FO(TC), FO, ESO, branching-program/DAG annotations not restricted to
   single-poset meet plus slot permutations, or another polynomial-checkable
   witness system?

Equivalently: can dropping the PGF frame/meet discipline remove O1/O2
without recreating an exponential object, or is there a precise
obstruction (e.g. forced encoding of disjunctive path knowledge,
superpolynomial state explosion, verifier/correctness gap, or a logic
expressiveness mismatch)?

**Consequences if positive.** `[deduction]` A sound, complete, `poly(N)`
certificate with a deterministic polynomial verifier for the threshold
language would place `SORT-BOUND-U` in `NP`. This would be a genuine
upper-bound result below the known `PSPACE` membership; it would not by
itself separate classes, since `SORT-BOUND-U` is a tally language and
`NP != PSPACE` is open in general but this instance is already in
`PSPACE` (`problem.md`, `research-certificates-barriers.md`).

**Consequences if negative (class-specific).** `[deduction]` A proof that
*some fixed nonframed certificate class* has no all-`n` exact complete
`poly(N)` system would be a barrier theorem for that class, not a proof
that `SORT-BOUND-U ∉ NP`.

## 1. Fixed background (not re-argued)

`[literature]/[deduction]`
- `ceil(log2 n!) <= S(n) <= O(n log n)`; exact values known for
  `n <= 22`; `S(12)=30 > C(12)=29` (Wells); `S(n)-log2 n! = o(n)`
  (Sergeev). See `literature.md`, `problem.md`.
- `SORT-BOUND-U ∈ PSPACE` by the comparison game; a full explicit
  sorting tree has `2n!-1` nodes after reduction, so it is not a
  `poly(N)` certificate (`research-certificates-barriers.md`).
- Full winning-frontier enumeration is ruled out by
  `2^{(1/4-o(1))n log^2 n}` nonisomorphic winning states at one depth,
  even near/at `S(n)` in the relevant regime
  (`research-winning-frontier-barrier.md`). This bars frontier-enumerating
  methods, not every succinct representation of one selected strategy.
- PGF soundness is polynomial-time checkable for explicit graphs; naive
  poset-meet compression of an optimal strategy can be incomplete because
  a single meet cannot represent disjunctive path guarantees without node
  splitting (O1), and a reduced single-policy tree has no identical
  labelled-poset sharing (O2) (`research-strategy-certificates.md`,
  `scripts/check_framed_strategy.py`, local height-DAG note).

## 2. Nonframed certificate classes to distinguish

The phrase "FO(TC)/FO/ESO-style or other polynomial-checkable nonframed
certificate/program format" conflates several models. They must be kept
separate.

### 2.1 Explicit nonframed comparison DAG with arbitrary sound annotations

`[definition]` Let a **general annotated comparison DAG** be a finite DAG
whose nodes carry comparison queries and whose edges carry outcome
conditions, with an annotation function `A(v)` from some formal language
(over `n`, slot/order relations, path constraints, arithmetic, etc.) and
a local soundness rule: `A(root)` over-approximates all inputs, outgoing
edges preserve feasible inputs under outcomes, joins preserve only
knowledge valid on every feasible incoming history, and leaves imply a
total order. "Nonframed" means we do not require `A(v)` to be a single
renamed strict partial order under PGF's meet rule.

`[deduction]` This strictly enlarges PGF as a *representation language*:
PGF is the special case where `A(v)` is one transitively closed partial
order and joins are meet. Therefore O1 does **not** by itself rule out a
general annotated DAG. The cost is moved to the verifier: the certificate
format must fix (a) the syntax/semantics of `A(v)`, (b) local entailment
checks for edge soundness, (c) join correctness, and (d) total-order
termination. A format is polynomial-checkable only if every local check
is in `P` in the explicit certificate size and `n`.

### 2.2 Deterministic finite-control program/strategy

`[definition]` A **program certificate** is a deterministic procedure
`Pi_n` (or a uniform program plus `n`-dependent data within the
certificate) that, given comparison outcomes, selects the next pair or a
terminal total order in at most `k` comparisons on every input
permutation.

`[deduction]` The verifier/correctness gap is severe: checking that
`Pi_n` sorts *one* input is easy, but soundness requires correctness for
all `n!` permutations. A universal checker over all inputs is
exponential; a local invariant proof is exactly what PGF/general annotated
DAGs attempt to provide. Thus "program" is not automatically a
polynomial-checkable certificate unless accompanied by polynomial
invariants/proof obligations discharged by the verifier.

### 2.3 FO, FO(TC), FO(LFP), FO(PFP) as languages

`[definition]/[literature]` These are first-order logics over finite
relational structures, possibly ordered:
- `FO`: first-order formulas.
- `FO(TC)`: FO plus transitive closure; on ordered structures captures
  `NL` (Immerman–Szelepcsényi context for closure; standard descriptive
  complexity capture is `FO(TC)=NL` on ordered structures).
- `FO(LFP)`: FO plus least fixed point; captures `P` on ordered
  structures (Immerman–Vardi).
- `FO(PFP)`: FO plus partial fixed point; captures `PSPACE` on ordered
  structures (Abiteboul–Vianu, Vardi).
- `ESO` (existential second-order): captures `NP` on finite structures
  (Fagin).

`[deduction]` These are *expressiveness/capture* results for properties
of a finite input structure. Applying them to `SORT-BOUND-U` requires
fixing the structure encoding of the unary input `1^n#1^k` and asking
whether the yes/no property is definable in the logic. They do **not**
automatically supply a short NP witness string in the usual certificate
sense except through the `NP = ESO` correspondence: an ESO sentence has
the form `exists R1..Rm phi(R1,..,Rm, input)` with first-order `phi`, so
a polynomial-size witness over the input universe can be read as
relations `R1..Rm` whose correctness is checked by evaluating `phi`.

### 2.4 Nondeterministic branching programs / certificate systems

`[definition]/[literature]` A general NP verifier is a polynomial-time
Turing machine `V(x,w)`; equivalently (up to polynomial conventions) a
polynomial-size circuit/verifier family or an ESO property. "Nonframed"
here just means not restricted to PGF's local semantics.

`[deduction]` Therefore the broadest nonframed polynomial-checkable
certificate question is simply: is `SORT-BOUND-U ∈ NP`? Restricting to a
named format (FO(TC), branching program, DAG annotation language) is
useful only if it identifies a tractable sufficient condition or a
class-specific obstruction.

## 3. Descriptive-complexity status relevant to this question

`[literature]/[deduction]` From `research-plan.md` and the capture
theorems:
- `SORT-BOUND-U ∈ PSPACE` implies there exists an `FO(PFP)` definition of
  the language on ordered structures encoding the input. This is an
  existence/capture consequence of the known upper bound, not a new
  combinatorial sorting certificate.
- An explicit, natural `FO(PFP)` formula mirroring the minimax game would
  still be a *definition/verifier of the property by fixed-point
  iteration*, not evidence of `NP` membership. `FO(PFP)` can express
  polynomial-space computations; it does not collapse to polynomial-size
  existential witnesses.
- An `FO(LFP)` definition would mean `SORT-BOUND-U ∈ P`; an `ESO`
  definition would mean `SORT-BOUND-U ∈ NP`. Neither is known.
- `FO(TC)` captures `NL` on ordered structures. Since an `NL` definition
  would place the language far below the current `PSPACE` upper bound and
  is not suggested by the alternation depth of the comparison game, a
  direct `FO(TC)` definition of exact `SORT-BOUND-U` is unsupported. This
  is an expressiveness caution, not a proof of impossibility: capture is
  over ordered structures and the exact encoding details matter.

`[deduction]` **Non-test:** Do not infer a small logic class from a
compact informal recurrence. The comparison game has up to `k = O(n log n)`
adaptive rounds and universal/adversarial branching; the PSPACE proof
uses alternation/game evaluation, which aligns with `FO(PFP)`/APTIME
intuition, not with `FO(TC)`.

## 4. Does "nonframed" remove O1/O2?

### O1 (poset-meet cannot represent disjunction)

`[deduction]` O1 is specific to **single-conjunctive meet annotations**:
`R(u)=∩ R_in` forgets every comparison that is not common to all incoming
histories. A nonframed format can avoid O1 only by changing the
annotation/join semantics, e.g.:
- store a set/formula/DNF of possible partial-order states (disjunctive);
- store a stronger invariant implied on all paths but richer than raw
  transitive closure of common edges;
- avoid joins (tree/DAG unfolding) so no meet is needed;
- use path-indexed or history-compressed witnesses accepted by a verifier.

But each escape has a cost:
- **Tree unfolding** gives `2n!-1` nodes (O2/Theorem 2.6 in strategy
  certificates): complete, sound in effect, exponentially large.
- **Disjunctive annotations** risk state explosion: the number of
  reachable posets is `2^{Theta(n^2)}` in total, and the winning-frontier
  lower bound shows even strategy-relevant states can be
  `2^{Omega(n log^2 n)}` at fixed depth. A certificate that materializes
  or implicitly distinguishes superpolynomially many cases is not a
  `poly(N)` witness.
- **Richer invariants** must still be locally checkable in `P`. An
  invariant strong enough to certify every next comparison after a join
  but compact enough to be polynomial is exactly the missing object; no
  such invariant is known.

### O2 (single-policy tree has no identical labelled-poset sharing)

`[deduction]` O2 is stronger in one way and weaker in another after
dropping frames. For a *deterministic reduced tree*, distinct nodes have
distinct permutation/poset information, so identical-state hash-consing
saves nothing. Nonframed DAGs may still hash-cons equal *abstract states*
under a coarser equivalence, but the verifier must prove that the chosen
equivalence preserves optimal next-move correctness for all histories
mapped to that state. This is the same completeness burden in a new
guise: state quotienting is sound only with a proof/invariant that the
quotient is behaviorally adequate at exact height `S(n)`.

## 5. Verifier/correctness gap (new test target)

The central nonframed difficulty is not merely "can we write the object?"
but "can a polynomial verifier establish global correctness?".

`[deduction]` **Verifier/correctness gap.** For a proposed nonframed
format `F`, define:
- `Check_F(n,k,w)=1` if witness `w` is syntactically valid and every
  local rule of `F` holds.
- `Sound_F`: `Check_F(n,k,w)=1 => S(n)<=k`.
- `Complete_F`: `S(n)<=k => exists w, |w|<=poly(N), Check_F(n,k,w)=1`.

Known explicit trees give `Sound+Complete` in the strong object sense but
fail the size bound. PGF gives polynomial local checking on accepted
objects but no all-`n` exact completeness proof. Any FO(TC)/ESO-style
proposal must supply both the local `Check_F` semantics and an argument
that local checks imply global sorting correctness over all `n!`
permutations.

`[falsifiable]` **Test VCG-1 (format audit).** For any candidate
nonframed format, produce: (i) a formal verifier; (ii) a soundness proof
from local rules to `S(n)<=k`; (iii) either a completeness construction
for all `n` at `k=S(n)` or an explicit family where every sound `F`
-witness has superpolynomial size. Absent (ii)–(iii), the format is not a
certificate system for `SORT-BOUND-U`.

`[falsifiable]` **Test VCG-2 (unfolding lower bound).** Take a known
exact/near-exact strategy family (merge-sort is not exact-optimal at the
needed points; FJ is optimal on all known `n<=22` but asymptotically not
exact; no all-`n` optimal family is explicitly certified). Measure the
minimum size of a *sound complete verifier-accepted* nonframed DAG when
joins are allowed only if the verifier can prove post-join adequacy using
a chosen invariant language. This distinguishes "DAG exists as a graph"
from "DAG is checkable as a certificate".

## 6. Disjunctive path knowledge and superpolynomial risk

`[deduction]` **Disjunction pressure.** After `t` comparisons there are
up to `2^t` transcripts; distinct transcripts can induce distinct residual
constraints relevant to optimality. Exact height `S(n)=log2(n!)+O(n)`
(in the worst currently possible informative regime? note: `S(n)` can be
only slightly above the information bound, and Sergeev gives
`S(n)-log2 n!=o(n)`) means the tree is near the information-theoretic
branching limit. Compression at exact height has almost no slack: a join
that discards a constraint useful only on a small but adversarially
relevant branch can force one extra comparison, moving height above
`S(n)`. This is sharper than upper-bound PGFs (bubble/merge/FJ at larger
budgets), where slack can absorb weaker annotations.

`[literature]/[deduction]` The winning-frontier barrier gives
superpolynomially many nonisomorphic winning states under the relevant
conditions; it does not count only states on *one* optimal policy, but it
shows the ambient game graph contains enormous winning diversity. A
complete exact-height nonframed certificate must therefore either:
1. select one optimal policy and prove all joins safe by a compact
   invariant (representation theorem), or
2. include enough disjunctive/path information to cover all adversary
   continuations (risking superpolynomial size), or
3. use a nonconstructive proof object whose checking is not known to be
   polynomial.

`[open]` No theorem currently forces (2) for all nonframed formats, and
no theorem establishes (1).

## 7. Finite stress points (exact S(n))

`[literature]` Known values relevant to exact-height testing:
`n=12: S(12)=30, C(12)=29` (information bound not tight);
`n=13: 34/33`; `n=16: 46/45`; `n=20: 62/62`; `n=22: 71/70`.
`n<=11` and `20,21` have tight information bound in the cited tables.
Values for `n>=23` are open.

`[falsifiable]` **Test X-12 (nonframed, finite).** Target `n=12,k=30`.
Find a nonframed, locally polynomial-checkable certificate accepted by an
independent verifier at height 30, substantially smaller or structurally
different from an explicit reduced strategy tree, and not relying on PGF
single-poset meet. Success would not prove all-`n` completeness but would
refute "exact non-tight cases require near-tree certificates in every
reasonable nonframed local-check format". Failure under a resource-bounded
search is evidence only about the searched subclass.

## 8. Precise obstruction statement

`[deduction]` **Obstruction N1 (exact-height local adequacy).** Let `F`
be any polynomial-time locally checkable DAG/certificate format whose
accepted object claims `S(n)<=k` by local edge/join/leaf rules. At exact
height `k=S(n)`, every accepted join/quotient must preserve all
adversary-relevant distinctions: if some feasible history class merged at
node `u` requires a different comparison choice or reaches a terminal
only after `S(n)+1` in the represented strategy unless split, local
soundness forces either node splitting, a stronger annotation, or
rejection. Therefore an all-`n` `poly(N)` completeness theorem for `F`
requires a uniform proof that the exact-optimal game admits a
join-stable invariant system in the annotation language of `F` with
polynomially many reachable certified states.

This is stronger pressure than at non-optimal upper bounds because the
budget slack is zero. N1 is an **adequacy/representation obstruction**; it
is not a known superpolynomial lower bound for general NP verifiers.

`[deduction]` **Obstruction N2 (logic-vs-certificate mismatch).**
`FO(PFP)` definability follows from `PSPACE` membership but supplies no
short existential witness; `ESO` would supply NP witnesses but is exactly
the open target. `FO(TC)`/`NL`-level definability is unsupported by the
game's alternation structure. Thus descriptive-logic names alone do not
resolve the nonframed certificate question.

## 9. Bottom line

`[deduction]`
- No sound, complete, all-`n`, exact height-`S(n)`, polynomial-checkable
  **nonframed** certificate/program format is currently known for
  `SORT-BOUND-U`.
- Dropping PGF frames/poset-meet removes O1 as stated, but replaces it by
  the general local-adequacy problem N1: exact-height joins must preserve
  adversarially relevant disjunctive knowledge, and proving polynomial
  join-stable adequacy for all `n` is open.
- The verifier/correctness gap blocks treating arbitrary strategy
  programs as certificates; nonframed formats need fixed local semantics
  and a global soundness theorem.
- The winning-frontier barrier prevents frontier enumeration and signals
  large winning-state diversity, but does not prove a lower bound against
  all succinct nonframed certificates.
- Descriptive complexity gives `FO(PFP)` existence from `PSPACE` and makes
  `ESO` equivalent to the desired NP-certificate outcome; neither settles
  exact-height succinctness.
- The sharpest next falsifiable moves are VCG-1/VCG-2 (format audit and
  checked unfolding under explicit invariants) and X-12 (a concrete
  nonframed exact-height-30 certificate attempt for `n=12`, independently
  verifiable). A positive all-`n` representation theorem for any fixed
  nonframed class would imply `SORT-BOUND-U ∈ NP`; a superpolynomial
  lower bound for such a class would be a barrier, not a separation of
  standard complexity classes.
