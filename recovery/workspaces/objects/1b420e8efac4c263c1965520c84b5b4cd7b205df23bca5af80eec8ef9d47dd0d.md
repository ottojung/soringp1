# Framed DAG (join/intersection) completeness: analysis

## Models
- Framed DAG (per check_framed_strategy.py): nodes have fixed comparison pairs; edges carry permutations; at joins, guaranteed relations are intersected (forgetful). Each node’s comparison must be valid for all paths reaching it; impossible branches skipped. Merging is by intersection of guaranteed relations after permutation, not by exact poset equality.
- Strategy DAG (hash-consed): nodes = exact poset states P; merging iff identical P; comparisons chosen per state. Distinct model from framed.

## Evidence for obstruction
- Root-prefix sibling obstruction (packets): R_h(P)=max(d+F(P), max_i i+F(Q_i^sibling)) depends on sibling branches Q_i from transcript history h. Example n=5 C2 ordinal A3: d+F(P)=S(5) but min_h R_h > S(5) so not viable on any root-optimal strategy despite local viability. Framed nodes store only guaranteed relations R (intersection) with no sibling history; merging by R cannot preserve sibling constraints.
- Conditional compression / local minimax: packet states reorganizing height-S(n) decision tree into framed DAG with locally minimax states and no increase in distinct framed nodes fails at n=6 by naive local repairs; fixed comparisons per framed node require local minimax for all merged cases while intersection merging is lossy.
- Grammar restrictions: framed grammar rejects arbitrary comparator networks on immediate join (loses disjunctive correlations); issue #47 notes this as a restriction. Soundness holds but completeness is open.
- Entropy/forgetting identity (framed-certificate-frontier §4): forgetful joins create loss; near-information-bound certificates allow only o(n) aggregate loss in that walk but counting e(P) is hard; this is a necessary condition, not obviously satisfiable for all optimal root strategies under framed merge constraints.

## Structural obstruction (all-n)
The framed (DAG+join/intersection) grammar cannot in general preserve:
1. Sibling constraints required for root-optimality from antichain (lost on intersection merge / no sibling state)
2. The ability to have different optimal comparisons for cases that become merged into same framed node but need different moves (fixed comparison + locally minimax requirement conflicts with lossy merge)
3. Disjunctive correlations that some optimal strategies/certificates require

Thus there is a structural obstruction to polynomial-size exact completeness for the antichain root in the framed grammar; other proof systems (e.g. different DAG representations not requiring intersection-merge with fixed node comparisons / not losing sibling constraints the same way) need not be blocked. This separates framed-certificate completeness from NP membership in form without contradicting sparsity/Mahaney (unary SORT-BOUND-U sparse).

## Falsifier status
- Transformation from any sound polynomial verifier for SORT-BOUND-U to equivalent polynomial framed DAG: unclear how to encode sibling constraints / satisfy locally minimax under intersection merges without blowing up size or being impossible for root-optimal families.
- Obstruction family: root-prefix sibling obstruction gives a concrete pattern (posets viable locally but not on any root-optimal strategy due to siblings); combined with lossy framed merging suggests infinite families where framed-join soundness forces exponential DAG size or prevents exact completeness. The n=6 conditional compression counterexample is finite evidence consistent with obstruction.

## Limits
- Exact all-n obstruction theorem not yet fully formalized; n=5/n=6 are finite witnesses suggesting the pattern.
- Cannot rule out some other framed normalization; obstruction is structural given the merge rules.
- Does not contradict existing polynomial constructions for non-optimal sorts (bubble/merge) or bounds.
