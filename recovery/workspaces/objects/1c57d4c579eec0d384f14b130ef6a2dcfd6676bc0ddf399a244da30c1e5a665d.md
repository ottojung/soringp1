# Framed DAG witness attempt for n=16 (SoringP1 / framed-dag-witness-n16-exact)

## 1. Problem and baseline

- **Task/front:** Construct or derive an explicit, checkable permutation-framed strategy DAG certificate of exact height `S(16)=46` for `n=16` (or best certifiable budget), verify with checker if possible, and report exact node/edge/depth counts and structural observations; or provide a precise falsifiable obstruction/evidence.
- **Model/certificate format:** Deterministic adaptive comparison sorting of `n` distinct labelled keys. Framed strategy DAG as in `docs/research-framed-certificate-frontier.md` and `scripts/check_framed_strategy.py`: topologically numbered nodes, root 0, each query node has `compare [a,b]` and edges `lt` (`a<b`) / `gt` (`b<a`) with `next` and slot permutation `perm`; leaves assert a total order; checker propagates/intersects guaranteed partial orders and accepts iff all reachable leaves sort and max depth ≤ `budget`. Sound and polynomial-time in explicit graph size (not an all-`n` completeness claim).
- **Baseline for n=16 (literature):** `S(16)=46`, `⌈log2(16!)⌉=45` (Stober & Weiß, arXiv:2206.05597 / ALENEX 2023; see `docs/literature.md`, `docs/research-framed-certificate-frontier.md`).
- **Related constructive upper bounds:** Ford–Johnson/merge-insertion `M(n)=∑_{i=1}^{n} ⌈log2(3i/4)⌉` gives `M(16)=46`; standard balanced merge sort worst case `n log2 n - n + 1 = 49` for `n=16`.

## 3. Results

### 3.1 Constructed and verified framed witness (best certifiable budget achieved here)

**Artifact:** `artifacts/bubble_n16_framed.json` (triangular bubble / compare-exchange path, generated by `triangular_bubble_certificate(16)`).

- **Checker result:** `ACCEPT: n=16, depth=120, nodes=121` (verified by `check_framed_strategy.py`).
- **Exact counts:** `n=16`, `budget=120`, `nodes=121` (120 comparison nodes + 1 leaf), `depth=120`.
- **Edges/profile:** 120 query nodes × 2 outcomes = **240 directed edges** total. Each node emits `lt`/`gt` to `next = v+1` with identity or adjacent-swap permutation (a compare-exchange frame), so the certificate is a **single path/DAG of depth 120** (maximal sharing in this linear form: 1 node per comparison level, no branching in node count). Structural observation: this is the quadratic-size all-`n` sound framed witness noted in `docs/research-framed-certificate-frontier.md` (§1, issue #47 reference), but far from optimal (`120 >> 46`).

**Edge accounting (from format):** for node `v<120`, `lt.next=v+1`, `gt.next=v+1`; for leaf `v=120`, none. Total edges = 240.

### 3.2 Exact-height target (S(16)=46): no explicit framed witness constructed

- **Attempted:** searched repository for existing n=16 framed/strategy witnesses or certificates (`find` for `*n16*/*witness*/*certificate*` patterns; inspected scripts/docs) — **none found**.
- **Constructive attempt status:** no explicit permutation-framed strategy DAG certificate of height `46` for `n=16` was constructed or derived in this run. No checkable artifact at budget 46 was produced.
- **Best budget context:** `M(16)=46 == S(16)` (Ford–Johnson bound equals the known optimum at 16) and `⌈log2(16!)⌉=45`; merge-sort worst case is 49. `docs/research-framed-certificate-frontier.md` (§3) states a plausible all-`n` polynomial framed certificate for the *standard Ford–Johnson upper bound* subject to checking the complete recursive frame construction and odd case — this would target budget 46 for n=16 but **an explicit, audited n=16 framed DAG instance is not implemented here**.
- **Falsifiable obstruction/evidence (why exact witness not achieved):**
  1. **Optimal strategy origin/size:** `S(16)=46` is established by a large computer search (Stober & Weiß 2022), not by a small explicit strategy object in this repo. A single optimal comparison *tree* has `n!` leaves (`16!`) and `2·16!-1` nodes, so an unshared framed witness is infeasible to materialize/check explicitly.
  2. **Sharing/representation gap:** Hash-consed poset-state DAGs can be much smaller than trees for unions of strategies, but `scripts/strategy_dag_probe.py` (poset states, not framed certificates) shows rapid growth; for n≤6, single-policy DAG equals the tree (`2n!-1`, no hash-consing gain) while all-optimal DAG grows quickly (e.g. n=6: 65551 nodes, quotient 134) — see `artifacts/strategy_dag_probe_max5.txt` and `docs/research-strategy-certificates.md`. No evidence here of a polynomial-size, explicitly constructible framed certificate at exact optimum for n=16.
  3. **No available generator for optimal/FJ framed DAG:** repository provides `check_framed_strategy.py` and only a bubble witness generator; merge-sort/FJ framed constructions are described on paper but not implemented/audited as certificate emitters, so derivation of a correct height-46 framed instance was not completed.
