Order-ideal-dp-state-doubling analysis
=======================================

Attempt to parse the front:
- "poset DP over order ideals used to compute F(P)=S(P)" - could mean (a) the linear-extensions-style DP (states = order ideals of poset P) applied to compute F(P), or (b) DP over posets/states called "order ideals" by terminology, or (c) just garbled terminology referring to the standard poset DP.

Known facts (from repo):
1. Linear extensions counting: uses order ideal (down-set) DP over subsets forming order ideals of P; states for fixed P are N(P) = number of order ideals of P, with N(P) <= 2^n and N(P)=2^n iff P is antichain, decreasing when adding relations.
2. Minimax sorting DP (F(P)): states are partial orders P (transitively closed). Total labelled = A001035(n)=2^(Theta(n^2)). Unlabelled quotient A000112(n)=2^(Theta(n^2)) still (Kleitman–Rothschild). All reachable by some comparison sequences; quotienting preserves optimum. Symmetry compression doesn't change exponent.
3. Winning frontier barrier: at fixed depth there are 2^((1/4-o(1)) n (log n)^2) winning states - large frontier but exponent in n log^2 n vs n^2.
4. "Reachable from the antichain under optimal play": in minimax game, sorter moves to minimize worst case, adversary adversarially; "optimal play" paths form the minimax strategy tree. The full value DP explores broadly (needs both adversary branches), but which states appear only under optimal-play paths vs all paths?

Falsifiability attempt:
- If "order ideals" means order ideals of current posets P (interpretation matching linear-extensions DP structure): then N(P) <= 2^n and decreases as we add relations from antichain, so cannot grow as 2^(Omega(n^2)). This would directly DISPROVE the claim. Also basis says "DP over all subsets is exponential but the 'down-set' (order ideal) formulation gives states as order ideals of the current poset" - suggesting moving TO order-ideal formulation reduces state count; going the other way would be bad.
- If "order ideals" means the states themselves (partial orders/classes) and the terminology is misused: then question is about state count in poset DP being 2^(Omega(n^2)) under optimal play even with quotients. State compression shows total quotient is 2^(Theta(n^2)) and appears reachable; Kleitman–Rothschild gives the asymptotic. But "under optimal play" restriction is critical - if restricted to minimax optimal paths, perhaps much smaller? Or perhaps still large. Unclear without more analysis.

Conclusion (honest limits):
The terminology is ambiguous. The most decisive reading is: if the DP formulation uses order ideals OF the current poset P as states, then N(P) is non-increasing from antichain and bounded by 2^n, so the claim of 2^(Omega(n^2)) growth is false by monotonicity. That would be a clean disproof of that specific formulation. However "reachable from the antichain under optimal play" is odd if states are N(P) of growing/shrinking P. Alternatively if interpreted as the standard poset DP states, the "order ideals" terminology is likely mistaken; the Kleitman–Rothschild structure makes 2^(Theta(n^2)) natural for the full state graph but restricting to optimal-play paths is a different (open) question.

No repository changes made (no substantive new theorem/counterexample ready without further work). No Lean changes.
