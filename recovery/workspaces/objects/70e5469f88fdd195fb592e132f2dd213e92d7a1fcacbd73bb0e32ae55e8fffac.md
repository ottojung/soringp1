## 2. Statement of Lemma A and its status

**Lemma A (e-form, as recorded in the T(6) report).** For every finite poset
`P` with `e(P) <= F_{r+3} - 2`, there exists a comparison of two incomparable
elements whose both outcomes satisfy `e <= F_{r+2} - 2` (so the induction
hypothesis `T(r-1)` applies to both children).

**Status: FALSE as stated.** It is a sufficient condition, not a necessary one,
and it already fails at small `r`.

Counterexample 1 (`r = 2`). Poset on 3 elements with one relation `0 < 2`
(`up = (4,0,0)`): `e = 3 = F_5 - 2`, `m = 2`. The child threshold is
`F_4 - 2 = 1`; since `e = 3 > 2`, no comparison can have both children
`<= 1`. Balance fails (trivially by counting), yet `T(2)` holds.

Counterexample 2 (`r = 4`, the first nontrivial one). Poset on 5 elements with
`up = (28, 16, 16, 0, 0)` (transitively closed): `e = 11 = F_7 - 2`,
`m = 4`. Child threshold `F_6 - 2 = 6`. The five incomparable splits are
`8/3, 7/4, 8/3, 7/4, 8/3`; none has both sides `<= 6`. Balance fails, yet
`T(4)` holds (`m = 4 <= 4`), and the child with `e = 8` still has `m = 3`.

So Lemma A (e-form) cannot be used as the induction step. This is an
obstruction to that *proof route*, not a refutation of `T(r)`.

## 3. Exact verification for `r <= 6`

Using the paper generation of cores (Lemmas 1–5 of `research-core-threshold.md`)
and `core_threshold_census.py`, I enumerated all cores with
`e <= F_{r+3} - 2` and tested the balance property (existence of a comparison
with both children `e <= F_{r+2} - 2`). Counts and failures:

| r | E = F_{r+3}-2 | cores with e <= E | balance failures |
|---|---|---|---|
| 1 | 1 | 0 (vacuous) | 0 |
| 2 | 3 | 3 | 1 |
| 3 | 6 | 11 | 0 |
| 4 | 11 | 43 | 1 |
| 5 | 19 | 205 | 0 |
| 6 | 32 | 982 | 0 |

`T(r) = F_{r+3} - 1` is verified for `r <= 6` (and in fact for `r <= 8` by
the core census: `T(6)=33`, `T(7)=54`, `T(8)=88`). Thus the all-r statement
is not refuted in this range; only the e-form balancing lemma fails.

## 4. Structured-family search for `r = 7+`

For `r = 7`, the full core census gives `4362` cores with `e <= 53`; **all**
satisfy the balance property (0 failures). I additionally tested structured
families that could in principle escape the core census (ordinal sums, disjoint
unions of chains/antichains/staircases, and staircase posets with one added
relation), for sizes up to `n = 8`:

- Disjoint unions of chains (partitions of `n <= 7`): no balance failure,
  no `T(7)` violation.
- Ordinal sums and disjoint unions of chains/antichains/staircases (`n <= 8`):
  no balance failure, no `T(7)` violation.
- Staircase `W_n` plus one added relation (`n = 5..8`): no balance failure,
  no `T(7)` violation (and `W_n` itself is balanced for `n <= 8`).

So no structured family violates balance at `r = 7`, and no family violates
`T(7)`. For `r >= 8`, the core census already verifies `T(8) = 88`; balance
for `r = 8` was not completed (enumeration cost), but no counterexample to
`T(r)` is known.

## 5. Proof attempt via Kahn–Saks balance

Kahn–Saks balancing gives, for any poset, a comparison whose two children have
sizes in the range roughly `[3/11, 8/11]` of `e(P)` (best guaranteed split
factor about `8/11`). To close the Fibonacci induction one would need

    (8/11) * (F_{r+3} - 2) <= F_{r+2} - 2.

For `r = 7` the LHS is about `38.5` against `32`; asymptotically
`F_{r+3}/F_{r+2} -> phi ~ 1.618`, and `(8/11)*phi ~ 1.18 > 1`. Hence the
Kahn–Saks constant is too weak: the guaranteed child bound exceeds the
Fibonacci threshold at every large `r`. This is a precise obstruction to the
Kahn–Saks route to Lemma A. A successful proof would need either a sharper
split constant (closer to `1/2`) or a structural argument exploiting the
poset shape, not just extension counts.

## 6. Honest limits and conclusion

- Lemma A (e-form) is **false**; it is not a valid proof route.
- `T(r) = F_{r+3} - 1` is **verified for `r <= 8`** (core census, conditional
  on implementation faithfulness) and **not refuted** for any `r`.
- The all-`r` statement remains **open**. A counterexample to `T(r)` would need
  at least 15 elements (Gupta's GPC verification through 14 elements), so the
  search space is finite but growing.
- No complexity-class consequence follows: `T(r)` bounds are statements about
  the minimax game on partial orders, not about `S(n)` at the antichain root.

**Bottom line:** the all-r Fibonacci threshold is neither proved nor refuted.
The e-form balancing lemma is dead; the theorem survives all finite tests
through `r = 8`. The next decisive obstacle is a correct balancing statement
(perhaps in terms of `m` rather than `e`, or with adjusted constants) or a
genuine counterexample.
