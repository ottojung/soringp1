# Finding: space lower bound for budgeted DFS on SORT-BOUND-U

**Front:** space-reduction-budgeted-dfs  
**Status:** investigated (no repo/Lean changes)  

## Summary
For the transcript/DFS family (current approach) used in the budgeted DFS for SORT-BOUND-U, achieving $o(N\log N)$ workspace is obstructed by (a) the path stack requiring $\Omega(d\log n)=\Omega(N\log N)$ bits when depth $d=\Theta(N)$ and pair indices require $\Omega(\log n)$ bits, and (b) on-demand reachability requiring $\Omega(n\log n)=\Omega(N\log N)$ workspace. More directly, the pair-cursor over $\binom{n}{2}$ incomparable pairs means each DFS frame needs $\Omega(\log n)$ bits just for navigation; with depth up to $k=\Theta(N)$ and $n=\Theta(N)$ in worst nontrivial decision instances this gives $\Omega(N\log N)$ stack space. Reachability recomputation adds another $\Omega(n\log n)$ term. These are unavoidable features of this evaluation strategy.

## Evidence
- Transcript DFS: §5.2 of `docs/research-budgeted-dfs.md` accounts for stack as $O(d\log n)$ (pair $(a_s,b_s)$ needs $2\lceil\log_2(n+1)\rceil$ bits, cursor over $\binom{n}{2}$ pairs needs $\lceil\log_2(\binom{n}{2}+1)\rceil$ bits, depth $d+1$ frames) plus one reachability workspace $O(n\log n)$ (visited bitvector $n$ bits + stack/queue up to $n$ labels). For decision instances where $d=k$ can be $\Theta(N)$ and $n$ can be $\Theta(N)$ (e.g. inputs where $n,k$ are comparable), this is $O(N\log N)$.
- Existing prior finding in ledger for `linear-space-unary-decision`: "The transcript-DFS family cannot achieve O(N) bits: its path stack has depth k ≤ N levels, and each level must store a cursor over binom(n,2)=Ω(n²) candidate pairs, requiring Ω(log n)=Ω(log N) bits per level, giving Ω(N log N) bits total. The reachability workspace adds another Ω(N log N)-bit term. Hence the established O(N log(N+2)) bound is the best this algorithm family yields; only a fundamentally different traversal/symbolic method could close the gap."
- `scripts/transcript_dfs.py` implements exactly this structure (shared transcript list + cursor over pairs with on-demand reachability) and tests confirm space-accounting behavior.
- For the general poset DP view, symmetry compression reduces state counts but doesn't change asymptotic exponent structure in a way that helps this DFS space accounting; canonical root-replay attempts give time blowup without obvious space win (per `compress-exact-space-evaluator` finding).

## Obstruction to O(N)/polylog N
Any correct DFS that (1) explores branches by trying incomparable pairs in some fixed order and must remember which pairs remain to try at each level (to do backtracking correctly), and (2) tests comparability on-the-fly via reachability over the current transcript/poset without storing a full $n\times n$ closure matrix per frame, will need $\Omega(\log \binom{n}{2})=\Omega(\log n)$ bits for the cursor and $\Omega(n\log n)$ for reachability workspace; with depth $\Omega(N)$ this forces $\Omega(N\log N)$ total. Storing the full path transcript is necessary for correctness of backtracking in the pure DFS (and to reconstruct poset state). Root-replay/canonicalization avoids storing explicit path but requires recomputing from root at each step with time blowup (and still needs to encode the decision path/canonical rank). 

## Conclusion
For the budgeted DFS/traversal family used here, $O(N\log N)$ is the natural bound and $O(N)$ (and certainly polylog $N$) appears infeasible without changing the model (memoization storing exponential states, or a completely different symbolic/structural method). This supports the falsifier in the sense that sublinear space relative to naive expectations is obstructed for this family; achieving better than $O(N\log N)$ would require a fundamentally different algorithm, not just space compression of the existing DFS structures.
