## 1. Fixed signature, addressing, and configuration family

### 1.1 Ordered input structure

`[definition]` Input `w = 1^n # 1^k`, `N = |w| = n+k+1`,
```text
A(w) = (W,<,One,Hash),   W={1,...,N}.
```
FO-definable fixed predicates/relations over `A(w)` `[literature, definition]`:
`Succ, Min, Max, HashPos, WellFormed_w, Malformed, Key, Ctr, Zero, MaxK,
SuccCtr, HasBudget, KeyNe`, and lex order on pairs
```text
Key(x)   := ∃h(HashPos(h) ∧ x < h),                       |Key|=n,
Ctr(t)   := ∃h(HashPos(h) ∧ (t=h ∨ h < t)),                |Ctr|=k+1,
Zero(t)  := HashPos(t),
SuccCtr(t,s):= Ctr(t) ∧ Ctr(s) ∧ Succ(t,s),
HasBudget(t):= ∃s SuccCtr(t,s),
KeyNe(x,y):= Key(x)∧Key(y)∧x!=y,
Lex2(a,b,x,y):= Key(a)∧Key(b)∧Key(x)∧Key(y)∧(a<x ∨ (a=x ∧ b<y)).
```

### 1.2 Cell space and monotone frame allocator

`[definition]` Fix `r:=4`, `Cell := W^r`, `|Cell|=N^r`. Lex order `<_lex` and
successor `SuccCell(c̄,d̄)` on `Cell` are FO-definable from `<`. Fixed constant
cell values are FO-definable by fixed `SuccCell`-chains from `MinCell`.

The DFS stack uses one active top frame base and `Parent` links. To make
`FreshChild` symbol-level and deterministic without variable multiplication,
the realization uses a **monotone frame allocator**:
```text
CurBase(b̄)   arity r, global: base address reserved for the next push.
```
`FreshChild` returns `CurBase`; after a push, `CurBase` advances by one
`Cell`-successor. The stack depth is bounded by `2k+1 <= 3N` on intended
computations (one universal comparison consumes one `Used` budget step on each
accepted adversary branch; existential search uses backtrack frames along the
active DFS path). Since `|Cell|=N^4`, monotone allocation never exhausts
`Cell` on intended inputs. No address reuse is required for correctness.

`[falsification]` This is not a global name for all `Pos` states and not an
A001035-indexed encoding. `CurBase`/frame bases are polynomially many workspace
addresses in `W^r`; `PosF` stores only the current frame's closure bits.

### 1.3 Fixed configuration-relation family

`[definition]` The fixed family `Rbar=(R_1,...,R_m)` has fixed arities,
independent of `n,k`:
```text
Top(c̄)                       arity r
CurBase(b̄)                   arity r
EmptyStack                     arity 0
HaltAcc, HaltRej               arity 0

M_Eval(c̄), M_BackE(c̄), M_BackA0(c̄), M_BackA1(c̄)   arity r  (exactly one
                                                        when frame active)

RetNone(c̄), RetAcc(c̄), RetRej(c̄)                 arity r  (child return
                                                        marker, relevant on
                                                        Back* frames)

CtrlSort(c̄), CtrlAdv(c̄), CtrlAcc(c̄), CtrlRej(c̄)  arity r  (frame control)

UsedF(c̄,t)                   arity r+1   (exactly one Ctr value t)
HasSel(c̄)                    arity r
SelA(c̄,a), SelB(c̄,b)        arity r+1   (meaningful when HasSel)
HasCur(c̄)                    arity r
CurA(c̄,a), CurB(c̄,b)        arity r+1   (lex cursor in Key×Key)
PosF(c̄,u,v)                  arity r+2   (current closure bit for Key pair)
Parent(c̄,p̄)                  arity 2r    (stack link: p̄ below c̄)
FrameLive(c̄)                 arity r     (frame c̄ is active in stack/workspace)
```
All are relations over `W`; `m` and `A=max_i a_i=2r` are fixed. This realization
makes parent/return/cursor metadata explicit as relations (no hidden TM tape
conventions). An equivalent fixed packed single-relation realization is obtained
by the PACK §2 tag/`Decode_i`/`Encode_i` translation (`1+A` arity), which is
left unchanged.

## 2. Local semantic FO formulas

`[definition]` For a frame base `c̄`:
```text
P_c(u,v)      := PosF(c̄,u,v).
Incomp_c(x,y) := KeyNe(x,y) ∧ ¬P_c(x,y) ∧ ¬P_c(y,x).
Total_c       := ∀x∀y(KeyNe(x,y) -> P_c(x,y) ∨ P_c(y,x)).
Budget_c      := ∃t(UsedF(c̄,t) ∧ HasBudget(t)).
CfgAcc_c      := CtrlAcc(c̄) ∨ Total_c.
CfgRej_c      := CtrlRej(c̄).

StepPosBit_c(x,y;u,v) :=
  P_c(u,v) ∨ ((u=x ∨ P_c(u,x)) ∧ (v=y ∨ P_c(y,v))).

PostBudgetNew_c(t'; Acc,Sort,Rej) :=
   (Total_c'after? not used directly)  -- use PostBudgetFrom:
PostBudgetFrom(Pnew, t'; Acc,Sort,Rej) :=
   (TotalOf(Pnew) ∧ Acc ∧ ¬Sort ∧ ¬Rej)
 ∨ (¬TotalOf(Pnew) ∧ HasBudget(t') ∧ Sort ∧ ¬Acc ∧ ¬Rej)
 ∨ (¬TotalOf(Pnew) ∧ ¬HasBudget(t') ∧ Rej ∧ ¬Acc ∧ ¬Sort),
where TotalOf(Pnew):=∀x∀y(KeyNe(x,y)->Pnew(x,y)∨Pnew(y,x)).
```
`Pnew` is supplied as the FO body `StepPosBit_c(a,b;u,v)` or
`StepPosBit_c(b,a;u,v)` in the relevant push cases.

`[literature,deduction]` **Incremental TC lemma.** If `P_c` is the transitive
closure of a strict partial order and `Incomp_c(x,y)`, then
`StepPosBit_c(x,y;·,·)` is the closure of `P_c ∪ {(x,y)}` and a strict partial
order (standard; CKS-AV/tape-formulas/delta-d-dfs-stack).

## 4. Frame content update templates

`[definition]` `CopyFrame(c̄,d̄)` copies all content relations indexed by `c̄`
to `d̄` in the primed state (mode/control/ret/used/sel/cur/pos/parent preserved
for copied values as specified). `ClearLive(c̄)` is implied by `¬FrameLive'(c̄)`
and the invariant (dead frames irrelevant). `ChildFrameBase(d̄,c̄)` sets
```text
FrameLive'(d̄) ∧ Parent'(d̄,c̄) ∧ Top'(d̄)
∧ ∃b̄(CurBase(b̄)∧d̄=b̄) ∧ ∃b̄∃b̄'(CurBase(b̄)∧SuccCell(b̄,b̄')∧CurBase'(b̄')).
```

`PushChildE(d̄,c̄,x,y)`:
```text
ChildFrameBase(d̄,c̄)
∧ M_Eval'(d̄)∧¬M_BackE'(d̄)∧¬M_BackA0'(d̄)∧¬M_BackA1'(d̄)
∧ RetNone'(d̄)∧¬RetAcc'(d̄)∧¬RetRej'(d̄)
∧ CtrlAdv'(d̄)∧¬CtrlSort'(d̄)∧¬CtrlAcc'(d̄)∧¬CtrlRej'(d̄)
∧ (∀u∀v (PosF'(d̄,u,v)<->PosF(c̄,u,v)))
∧ (∀t (UsedF'(d̄,t)<->UsedF(c̄,t)))
∧ HasSel'(d̄)∧SelA'(d̄,x)∧SelB'(d̄,y)∧∀a(a!=x -> ¬SelA'(d̄,a))∧∀b(b!=y -> ¬SelB'(d̄,b))
∧ HasCur'(d̄)∧∃m(MinKey(m)∧CurA'(d̄,m)∧CurB'(d̄,m)).
```

`PushChildA(d̄,c̄,a,b,side)` where `side=0` uses `(a,b)`, `side=1` uses
`(b,a)`:
```text
ChildFrameBase(d̄,c̄)
∧ M_Eval'(d̄)∧¬M_BackE'(d̄)∧¬M_BackA0'(d̄)∧¬M_BackA1'(d̄)
∧ RetNone'(d̄)∧¬RetAcc'(d̄)∧¬RetRej'(d̄)
∧ (∀u∀v (PosF'(d̄,u,v) <-> Pside_c(a,b;u,v)))
∧ (∀s (UsedF'(d̄,s) <-> ∃t(UsedF(c̄,t)∧SuccCtr(t,s))))
∧ ¬HasSel'(d̄)∧∀x¬SelA'(d̄,x)∧∀y¬SelB'(d̄,y)
∧ HasCur'(d̄)∧∃m(MinKey(m)∧CurA'(d̄,m)∧CurB'(d̄,m))
∧ PostBudgetFrom(Pside_c(a,b;·,·), t'; CtrlAcc'(d̄),CtrlSort'(d̄),CtrlRej'(d̄))
  with t' the unique SuccCtr successor of UsedF(c̄,t).
```
`Pside_c` is `StepPosBit_c(a,b;u,v)` for side 0 and `StepPosBit_c(b,a;u,v)`
for side 1.

## 5. `Init_{M_D}^{sym}`

```text
Init_{M_D}^{sym}(Rbar) :=
```

## 6. Complete case-closed `Δ_{M_D}^{sym}`

`[definition]`
```text
Δ_{M_D}^{sym}(Rbar;Rbar') :=
   Δ_halt
 ∨ Δ_root_acc
 ∨ Δ_root_rej
 ∨ Δ_eval_acc_ret
 ∨ Δ_eval_rej_ret
 ∨ Δ_sort_pick_push
 ∨ Δ_backE_acc_root
 ∨ Δ_backE_acc_ret
 ∨ Δ_backE_rej_next
 ∨ Δ_backE_rej_exhaust_root
 ∨ Δ_backE_rej_exhaust_ret
 ∨ Δ_adv_push_A0
 ∨ Δ_backA0_rej_root
 ∨ Δ_backA0_rej_ret
 ∨ Δ_backA0_acc_push_A1
 ∨ Δ_backA1_acc_root
 ∨ Δ_backA1_acc_ret
 ∨ Δ_backA1_rej_root
 ∨ Δ_backA1_rej_ret.
```
Every case includes `¬HaltAcc ∧ ¬HaltRej` (except `Δ_halt`) and `WellFormed_w`
implicitly via `I_{M_D}` on the source; we include `WellFormed_w` in
`I_{M_D}`.

### 6.1 Halt
```text
Δ_halt := (HaltAcc ∨ HaltRej) ∧ Rbar'=Rbar.
```

### 6.2 Root accept/reject from evaluating top frame
```text
Δ_root_acc :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄(Top(c̄)∧Root(c̄)∧FrameLive(c̄)∧M_Eval(c̄)∧CfgAcc_c)
  ∧ HaltAcc'∧¬HaltRej'∧EmptyStack'∧NoActiveFrames'∧CurBase'=CurBase.

Δ_root_rej :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄(Top(c̄)∧Root(c̄)∧FrameLive(c̄)∧M_Eval(c̄)
     ∧ (CfgRej_c ∨ (CtrlSort(c̄)∧¬Total_c∧¬Budget_c) ∨ (CtrlSort(c̄)∧¬Total_c∧Budget_c∧NoNextIncomp_c)))
  ∧ HaltRej'∧¬HaltAcc'∧EmptyStack'∧NoActiveFrames'∧CurBase'=CurBase.
```

### 6.3 Non-root evaluating accept/reject return (pop with marker)
```text
Δ_eval_acc_ret :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄∃p̄(Top(c̄)∧¬Root(c̄)∧FrameLive(c̄)∧M_Eval(c̄)∧CfgAcc_c∧ParentOf(c̄,p̄)∧FrameLive(p̄))
  ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack'
  ∧ Top'(p̄)∧∀z̄(Top'(z̄)->z̄=p̄)∧¬FrameLive'(c̄)∧CurBase'=CurBase
  ∧ LowerStackPreservedExcept(c̄) ∧ FrameLive'(p̄)
  ∧ MarkRetAccOn(p̄)  -- sets RetAcc'(p̄), clears RetRej/RetNone, preserves p̄ mode/control/sel/cur/pos/used.

Δ_eval_rej_ret := symmetric with reject condition and MarkRetRejOn(p̄),
  reject condition = CfgRej_c ∨ (CtrlSort(c̄)∧¬Total_c∧¬Budget_c)
                  ∨ (CtrlSort(c̄)∧¬Total_c∧Budget_c∧NoNextIncomp_c).
```
`MarkRetAccOn(p̄)` abbreviates: preserve all `p̄` frame fields except
`RetAcc'(p̄)∧¬RetRej'(p̄)∧¬RetNone'(p̄)`.

### 6.4 Existential sort pick and push
```text
Δ_sort_pick_push :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄∃a∃b∃x∃y(
     Top(c̄)∧FrameLive(c̄)∧M_Eval(c̄)∧CtrlSort(c̄)∧¬Total_c∧Budget_c
     ∧ CurA(c̄,a)∧CurB(c̄,b) ∧ NextIncomp_c(a,b;x,y))
  ∧ ∃d̄( FreshChild(d̄) ∧ PushChildE(d̄,c̄,x,y) )
  ∧ SetParentBackE_Advance(c̄,x,y)
  ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack'∧LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).
```
`SetParentBackE_Advance(c̄,x,y)` sets `M_BackE'`/`RetNone'`/`CtrlSort'` on
`c̄`, preserves `PosF/UsedF/Sel/HasSel` of `c̄` (no selection needed, but
preserved harmlessly) and sets cursor to `SuccLex2(x,y,·,·)` or keeps last.
It does **not** make `c̄` top; `PushChildE` makes `d̄` top.

### 6.5 BackE: consume child return
```text
Δ_backE_acc_root :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄(Top(c̄)∧Root(c̄)∧FrameLive(c̄)∧M_BackE(c̄)∧RetAcc(c̄))
  ∧ HaltAcc'∧¬HaltRej'∧EmptyStack'∧NoActiveFrames'∧CurBase'=CurBase.

Δ_backE_acc_ret :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄∃p̄(Top(c̄)∧¬Root(c̄)∧FrameLive(c̄)∧M_BackE(c̄)∧RetAcc(c̄)∧ParentOf(c̄,p̄))
  ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack' ∧ PopTo(p̄) with MarkRetAccOn(p̄)
  ∧ LowerStackPreservedExcept(c̄).

Δ_backE_rej_next :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄(Top(c̄)∧FrameLive(c̄)∧M_BackE(c̄)∧RetRej(c̄)∧CtrlSort(c̄)
     ∧ ∃a∃b∃x∃y(CurA(c̄,a)∧CurB(c̄,b)∧NextIncomp_c(a,b;x,y)))
  ∧ ∃d̄(FreshChild(d̄)∧PushChildE(d̄,c̄,x,y))
  ∧ SetParentBackE_Advance(c̄,x,y)
  ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack'∧LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).

Δ_backE_rej_exhaust_root :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄(Top(c̄)∧Root(c̄)∧FrameLive(c̄)∧M_BackE(c̄)∧RetRej(c̄)∧NoNextIncomp_c)
  ∧ HaltRej'∧¬HaltAcc'∧EmptyStack'∧NoActiveFrames'∧CurBase'=CurBase.

Δ_backE_rej_exhaust_ret :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄∃p̄(Top(c̄)∧¬Root(c̄)∧FrameLive(c̄)∧M_BackE(c̄)∧RetRej(c̄)∧NoNextIncomp_c∧ParentOf(c̄,p̄))
  ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack' ∧ PopTo(p̄) with MarkRetRejOn(p̄)
  ∧ LowerStackPreservedExcept(c̄).
```

### 6.6 Universal adversary: push A0
```text
Δ_adv_push_A0 :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄∃a∃b(Top(c̄)∧FrameLive(c̄)∧M_Eval(c̄)∧CtrlAdv(c̄)
     ∧ HasSel(c̄)∧SelA(c̄,a)∧SelB(c̄,b)∧Incomp_c(a,b))

  ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack'∧LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).
```

### 6.7 BackA0: reject short-circuit or push A1
```text
Δ_backA0_rej_root :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄(Top(c̄)∧Root(c̄)∧FrameLive(c̄)∧M_BackA0(c̄)∧RetRej(c̄))
  ∧ HaltRej'∧¬HaltAcc'∧EmptyStack'∧NoActiveFrames'∧CurBase'=CurBase.

Δ_backA0_rej_ret :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄∃p̄(Top(c̄)∧¬Root(c̄)∧FrameLive(c̄)∧M_BackA0(c̄)∧RetRej(c̄)∧ParentOf(c̄,p̄))

Δ_backA0_acc_push_A1 :=

     ∧ HasSel(c̄)∧SelA(c̄,a)∧SelB(c̄,b))
  ∧ ∃d̄(FreshChild(d̄)∧PushChildA(d̄,c̄,a,b,1))

  ∧ ¬HaltAcc'∧¬HaltRej'∧¬EmptyStack'∧LowerStackPreservedExcept(c̄)∧FrameLive'(c̄).
```

### 6.8 BackA1: return child result
```text
Δ_backA1_acc_root :=
  ¬HaltAcc∧¬HaltRej ∧ ∃c̄(Top(c̄)∧Root(c̄)∧FrameLive(c̄)∧M_BackA1(c̄)∧RetAcc(c̄))

Δ_backA1_rej_root := BackA1+RetRej+Root -> HaltRej', empty.
Δ_backA1_rej_ret  := BackA1+RetRej+non-root -> PopTo(p̄), MarkRetRejOn(p̄).
```

## 7. Proofs for the resulting formulas

### 7.1 Invariant `I_{M_D}`

`[definition]` `I_{M_D}(Rbar)` is the conjunction:
1. `WellFormed_w`.
2. At most one global halt: `¬(HaltAcc ∧ HaltRej)`.
3. If halted (`HaltAcc∨HaltRej`): `EmptyStack ∧ NoActiveFrames`.
4. If not halted and not `EmptyStack`-initially ill-formed in the relevant
   domain: `ExactlyOneTop ∧ ∃c̄(Top(c̄)∧FrameLive(c̄))`.
5. For every `FrameLive(c̄)`: `ExactlyOneMode(c̄) ∧ ExactlyOneRet(c̄)`;
   exactly one `Ctrl*`; exactly one `UsedF(c̄,t)` with `Ctr(t)`;
   `HasCur(c̄)` with unique `CurA,CurB` in `Key`; if `HasSel(c̄)` then unique
   `SelA,SelB` in `Key`; and `PosF(c̄,·,·)` is a transitive closure of a strict
   partial order on `Key` (in particular irreflexive, asymmetric, transitive).
6. Mode/control coherence for live frames:
   `M_Eval(c̄)` has `RetNone(c̄)` and `CtrlSort∨CtrlAdv∨CtrlAcc∨CtrlRej`;
   `CtrlAdv(c̄)` implies `HasSel(c̄) ∧ Incomp_c(SelA,SelB)`;
   `M_BackE(c̄)` implies `CtrlSort(c̄)` and preserves a valid search cursor;
   `M_BackA0(c̄)∨M_BackA1(c̄)` implies `CtrlAdv(c̄) ∧ HasSel(c̄)` and
   `PosF/UsedF` are the pre-universal-outcome snapshot needed for `A1`.
7. Stack discipline: `Top(c̄)∧¬Root(c̄)` implies `∃!p̄ Parent(c̄,p̄) ∧
   FrameLive(p̄)`; `Parent` links live frames into a well-founded chain ending
   at `Root`; `Top` is a leaf of that active-stack view.
8. `CurBase` is unique; for live non-top frames, allocator monotonicity is not
   required after pop, but `CurBase` is at or beyond every allocated base (an
   auxiliary monotonicity fact used for absence of collision; it follows from
   pushes only advancing `CurBase` and pops not decreasing it).

`[deduction]` **Init.** `Init_{M_D}^{sym}` establishes `I_{M_D}`: single root
live frame, antichain `PosF` (empty, hence a strict partial order closure),
`Used=Zero`, `CtrlSort`/`CtrlAcc` as required, no selection/parent issues,
unique `CurBase` as successor of root.

### 7.2 Mutual exclusion

`[deduction]` For any `Rbar` satisfying `I_{M_D}` and `¬HaltAcc∧¬HaltRej`, at
most one `Δ` case applies:

- `Δ_halt` is excluded by `¬HaltAcc∧¬HaltRej`.
- All other cases require a unique `Top(c̄)` (by `I_{M_D}.4`). Fix that `c̄`.
- They partition first by `M_Eval/M_BackE/M_BackA0/M_BackA1` (`I_{M_D}.5`).
- `M_Eval` partition: `Root(c̄)∧CfgAcc_c` -> `Δ_root_acc`;
  `Root(c̄)∧RejectEval_c` -> `Δ_root_rej` (reject condition is
  `CfgRej_c ∨ budget-exhausted-non-total ∨ no-next-incomp-while-searching`);
  `¬Root(c̄)∧CfgAcc_c` -> `Δ_eval_acc_ret`;
  `¬Root(c̄)∧RejectEval_c` -> `Δ_eval_rej_ret`;
  `CtrlSort(c̄)∧¬Total_c∧Budget_c∧HasNextIncomp_c` -> `Δ_sort_pick_push`;
  `CtrlAdv(c̄)∧HasSel(c̄)∧Incomp_c(Sel)` -> `Δ_adv_push_A0`.
  These are mutually exclusive: root vs non-root; accept vs reject-eval vs
  search-progress vs adversary-push. `CfgAcc_c` (`CtrlAcc∨Total`) is disjoint
  from `CtrlSort∧¬Total∧...` and from `CtrlAdv` (`I_{M_D}.6` makes controls
  coherent); `RejectEval_c` for sort includes no-next-incomp and no-budget,
  disjoint from `HasNextIncomp_c ∧ Budget_c`. `CtrlAdv` precondition gives
  incomparable selected pair; it does not co-occur with `CtrlSort` accept/reject
  search in the same frame state.
- `M_BackE` partition: `RetAcc ∧ Root` -> `Δ_backE_acc_root`;
  `RetAcc ∧ ¬Root` -> `Δ_backE_acc_ret`;
  `RetRej ∧ HasNextIncomp_c` -> `Δ_backE_rej_next`;
  `RetRej ∧ NoNextIncomp_c ∧ Root` -> `Δ_backE_rej_exhaust_root`;
  `RetRej ∧ NoNextIncomp_c ∧ ¬Root` -> `Δ_backE_rej_exhaust_ret`.
  (`RetAcc` vs `RetRej` by `I_{M_D}.5`; next-incomp vs no-next-incomp disjoint;
  root vs non-root.)
- `M_BackA0` partition: `RetRej∧Root`, `RetRej∧¬Root`, `RetAcc` (push A1) are
  disjoint. (`RetAcc` branch requires `HasSel`, preserved by `I_{M_D}.6`.)
- `M_BackA1` partition: `RetAcc/Rej` × `Root/¬Root`, disjoint.

Thus no two cases apply to the same `Rbar`.

### 7.3 Totality on relevant non-halting well-formed states

`[deduction]` Let `I_{M_D}(Rbar)` and `¬HaltAcc∧¬HaltRej`. By `I_{M_D}.4` let
`c̄=Top(c̄)` be live. By `I_{M_D}.5` it has exactly one mode and coherent
control/return fields.

- `M_Eval, CtrlAcc ∨ Total_c`: `CfgAcc_c`, so root/non-root accept case applies.
- `M_Eval, CtrlRej`: reject-eval case applies.
- `M_Eval, CtrlSort, ¬Total_c, ¬Budget_c`: reject-eval case applies.
- `M_Eval, CtrlSort, ¬Total_c, Budget_c`: with unique cursor `CurA,CurB`,
  either `∃x∃y NextIncomp_c(CurA,CurB;x,y)` giving `Δ_sort_pick_push`, or
  `NoNextIncomp_c` giving reject-eval. (`Key×Key` is finite linearly ordered by
  `Lex2`, so the search from cursor is total.)
- `M_Eval, CtrlAdv`: by `I_{M_D}.6`, `HasSel` and selected pair is incomparable
  in `P_c`, so `Δ_adv_push_A0` applies.
- `M_BackE, RetAcc`: root/non-root acc case.
- `M_BackE, RetRej`: cursor gives next-incomp or exhaust; root/non-root gives a
  case.
- `M_BackA0, RetRej`: root/non-root rej.
- `M_BackA0, RetAcc`: `I_{M_D}.6` preserves `HasSel`, so `Δ_backA0_acc_push_A1`.
- `M_BackA1, RetAcc/Rej`: root/non-root return.

All combinations are covered; `RetNone` on a `M_Back*` top frame is excluded
by `I_{M_D}` progression (a pushed child becomes top; parent becomes `M_Back*`
with `RetNone` only while child is live above it, so top cannot be that
parent).

### 7.4 Determinism / functionality

`[deduction]` By §7.2 at most one case applies. In the applicable case:
- `Top` is unique; `Root` is a predicate on that unique top.
- `ParentOf(c̄,p̄)` is functional on the active stack by `I_{M_D}.7`.
- `FreshChild(d̄)` is `CurBase(d̄)` with unique `CurBase` (`I_{M_D}.8`).
- `NextIncomp_c(a,b;x,y)` is unique by the lex-minimality clause.
- `SuccLex2` is functional on the finite linearly ordered `Key×Key`.
- `SuccCtr` is functional on `Ctr`.
- `StepPosBit_c` and `PostBudgetFrom` are FO functions of current frame
  relations and the selected side.
- `PushChild*` sets all primed components for the new child deterministically;
  `LowerStackPreservedExcept(c̄)` and mark/pop helpers determine all other
  primed components (unchanged or uniquely updated).
Therefore `Δ_{M_D}^{sym}(Rbar;Rbar') ∧ Δ_{M_D}^{sym}(Rbar;Rbar'')` implies
`Rbar'=Rbar''` as interpretations.

### 7.5 Preservation of `I_{M_D}`

`[deduction]` Assume `I_{M_D}(Rbar)` and `Δ_{M_D}^{sym}(Rbar;Rbar')`.

- `Δ_halt`: preserves.
- Root halt cases: set halt, empty stack, no live frames; `I_{M_D}.2--4,3`.
- Pop-return cases: remove only top `c̄`, make unique parent `p̄` top, preserve
  lower stack and `p̄` contents except deterministic `RetAcc/RetRej` marker.
  Parent remains live with same mode-control coherence except return marker
  consumed next; `Parent` chain remains well-founded.
- `Δ_sort_pick_push` / `Δ_backE_rej_next`: create fresh child at unique
  `CurBase`, set `Parent(child,c̄)`, make child top/live, advance `CurBase` by
  one. Child gets copied `PosF/UsedF` (valid by `I_{M_D}`), valid `CtrlAdv`,
  incomparable selected pair `x,y` from `NextIncomp_c` (hence `Incomp_c(x,y)`),
  `RetNone`, `M_Eval`, cursor reset. Parent becomes `M_BackE,CtrlSort,RetNone`
  with advanced cursor; its `PosF/UsedF` unchanged (valid). `CurBase`
  monotonicity/uniqueness preserved.
- `Δ_adv_push_A0`: child gets `PosF' = StepPosBit_c(a,b;·,·)` and
  `UsedF' = SuccCtr(UsedF)`. By `I_{M_D}.6` selected pair is incomparable and
  `P_c` is a strict partial-order closure; incremental TC lemma gives `PosF'`
  a strict partial-order closure. `SuccCtr` gives unique `UsedF'`. `PostBudget`
  gives exactly one of `CtrlAcc/CtrlSort/CtrlRej`. Parent becomes `M_BackA0`
  preserving `Sel/PosF/UsedF/Cur` as required.
- `Δ_backA0_acc_push_A1`: uses preserved `Sel(a,b)` and snapshot `PosF/UsedF`
  on parent; pushes `A1` with `StepPosBit_c(b,a;·,·)` and `SuccCtr(UsedF)`,
  same closure/budget argument.
- In all non-halt cases, `HaltAcc/HaltRej` remain false and `EmptyStack` false.

Thus `I_{M_D}(Rbar')` holds.

### 7.6 No spurious transitions relative to semantic `M_D^alt`

`[deduction]` The semantic DFS evaluator `M_D^alt` is specified by the
