## 1. Merge/soundness criteria

**What the artifact claims (defs §1, table §2, conclusion §7).** It defines function-value soundness `M(P,Q)=>F(P)=F(Q)`, budget soundness, weaker game-sufficient/contextual soundness, and requires an explicit certificate/argument for sound merges. It lists relabelling `P ~= Q`, duality `P ~= Q^{op}` (for the symmetric minimax value), identical transcript-induced closure/state equality, and separately certified structural decompositions as sound/restricted.

**Assessment.** This framing is appropriate.

- **Relabelling/duality/state equality:** `[deduction/literature in repo]` as labeled. Poset isomorphism and order reversal are standard symmetries of the comparison game; state equality is trivially sound. These are valid *local* merge/value-sharing criteria.
- **Certificate requirement:** Correctly blocks heuristic keys. The cited repo falsifications (linear-extension count `e(P)`, comparability graph, degree/colour surrogates, degree-based move identification) support the claim that simple summaries are not exact certificates. I did not re-audit those external-to-this-artifact falsification docs here; the artifact labels them as repo evidence/experiment/deduction, which is acceptable if those docs stand.
- **Tightening needed:** “Exact certificate” is used informally for several kinds of justification (isomorphism map, duality map, decomposition theorem, proof). This is fine as research prose, but it should not be read as a formal proof-certificate system or as implying cheap machine-checkability. The artifact mostly avoids that confusion, but §5 item (2) could be read as “validated by exact evaluation is a certificate”; better to say “validated by solving the relevant subgames exactly” (not a cheap certificate).
- **Budget/contextual soundness:** Including a budget form and a weaker game-sufficient notion is sensible for `G(n,k)`, but the artifact correctly warns that contextual soundness needs an explicit context certificate. No contextual merge is actually proposed.

**No overclaim found:** it does not claim relabelling/duality give an exponential breakthrough; §2 explicitly notes the winning-frontier barrier is already up to isomorphism.

## 2. Cheap-check / obstruction claims

**What the artifact claims (§5, §7).** For general exact merges beyond known symmetries, it presents a dichotomy: cheap local summaries are unsound/unproved by current evidence, while exact justification is an equivalence/value certificate whose general verification inherits minimax/subgame difficulty. It labels this an obstruction, not a proof of impossibility (`[open/deduction]`).

**Assessment.** This is a **reasonable, scoped obstruction statement**, provided it is not promoted to a lower bound or separation.

- **Good:** §5 defines “cannot be checked cheaply” relative to the merge task (subgame-hardness, witness cost, strong-but-cheap barrier), explicitly *not* as a complexity-class separation. That matches `AGENTS.md`/`problem.md` guidance (no P!=PSPACE/NP!=PSPACE claims; `SORT-BOUND-U ∈ PSPACE`).
- **Good:** It distinguishes “no cheap sound criterion established” from “no cheap sound criterion exists”. This preserves falsifiability (§8 proposes exhibiting a cheap domination/equivalence certificate).
- **Caution:** “As hard as the subgames being merged” (§5.1, §7 phrasing) is directionally plausible but informal. Exact value equality `F(P)=F(Q)` is a strong predicate; one could imagine special certified relations not obtained by independently solving both subgames. The artifact’s actual claim is weaker and acceptable: direct verification is an exact minimax/value certificate and no general cheap route is supplied. The audit recommends keeping the wording at “inherits minimax/subgame difficulty in general / no cheap general verification established,” not “equivalent to solving.”
- **Caution:** Proof-number bound sharing (§6) is correctly treated as needing justification; monotone budget propagation is correctly sound. The note about a hypothetical domination relation is appropriately marked `[open]` and warns against falsified surrogates.

## 3. Use of the `2^{Omega(n log^2 n)}` winning frontier

**What the artifact claims (§4, §7).** It cites the winning-frontier theorem for infinitely many `n=2^(2r)`, `k=C(n)` and also `k=S(n)=C(n)+o(n)` (Sergeev, asymptotic, no effective finite threshold), giving a common reachable depth `t<=k` and `W(n) >= 2^{(1/4-o(1)) n (log2 n)^2}` pairwise nonisomorphic reachable winning states with `F(P)<=k-t`. It defines “decision-frontier injective” merge/value-sharing and concludes such methods represent `>=2^{Omega(n log^2 n)}` distinct decision-relevant states in the worst case. It states this is **not** a general time lower bound.

**Assessment.** The frontier use is **sound for the stated class**.

- **Source match:** The numbers/form match `research-winning-frontier-barrier.md` §§1–3.1 (independent-edge construction, `n=s=L=2^r`, `m=nr-O(n)+o(n)`, `M=Θ(n^(3/2))`, `log2[binom(M,m)/n!] = (1/4-o(1)) n (log2 n)^2`). The theorem states states are reachable in exactly `t` legal outcomes and satisfy `F(P)<=k-t`; up to isomorphism is explicit.
- **Exact-optimum extension:** The artifact correctly attributes the `S(n)` extension to Sergeev asymptotically and notes no effective finite threshold. This matches the frontier doc §3.1 (uses `S(n)=log2(n!)+O(n/(log n)^(1/5))`, ECCC TR20-096, asymptotic). Good scope hygiene.
- **Finite witness:** “`n=224`, `>2^39` such states” is inherited from the frontier doc §4, which reports exact integer arithmetic and a certified inequality via `tests/test_winning_frontier_barrier.py` in that context. The audit artifact does not independently recheck the test; it should be read as a claim supported by the cited frontier note/test, not as a new computation in this audit.
- **Class restriction is clear:** “decision-frontier injective” is a defined method class. The obstruction is on methods that distinguish/retain that frontier, including memo tables/proof caches that must represent those classes. This avoids the common error of turning a frontier-size theorem into a universal algorithmic lower bound.
- **Selective search caveat:** Repeated and explicit (`§4`: “selective search may avoid representing most of these states”; `§7`: “general time lower bound for all selective/symbolic exact algorithms: not claimed”). This is correct and necessary.
- **Minor wording point:** The class is “decision-frontier injective at `(n,k,t)`” and the conclusion applies to “relevant `(n,k,t)` from the winning-frontier theorem.” Since that theorem gives such `t` for infinitely many `n`, the `2^{Omega(n log^2 n)}` worst-case obstruction is properly asymptotic/existence-based. The artifact states this adequately.
