## Falsification attempt

No explicit `I_{M_D}`-reachable falsifying trace was found. The strongest attempted counterexample would require a reachable transition mutating `HasSel/SelA/SelB/PosF/UsedF/Cur` of the live BackA0 parent while that parent is outside the transition's changed set, or an allocator alias making the nominal fresh child equal to an existing live/popped frame. The normalized `LowerStackPreservedExcept(S)` discipline blocks the former; allocator freshness/no-reuse is separately identified as an open structural obligation and no realizing trace is supplied for the latter. A row-15 read of a popped child would contradict its explicit schema read source rather than arise from the given row.

Universal propagation likewise has no schema-level overlapping consumer: `RetAcc` versus `RetRej`, and root versus non-root, select the stated branches. This alone does not prove every reachable return has an enabled consuming row or that the marked receiver is the intended active DFS parent. Those are genuine remaining invariant/realization obligations, not a counterexample trace.

## Verdict

**Supported / no explicit `I_{M_D}`-reachable witness.** In the audited schema, row 15 reads the preserved BackA0 parent snapshot rather than the popped A0 child; A0/A1 pushes use the specified opposite sides and the same parent counter basis; and rows 13–19 implement the stated universal accept/reject propagation. This is not a complete `I_{M_D}` preservation proof: `BackA0_Snapshot`, allocator freshness/no-alias, active-parent/receiver correctness, and complete coverage of consuming return states remain open. **No DET-SUCC discharge.**
