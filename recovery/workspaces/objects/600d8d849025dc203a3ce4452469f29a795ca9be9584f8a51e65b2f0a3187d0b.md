## 1. CKS/alternating acceptance instantiation

**Status: semantic instantiation explicit; syntactic sentence not discharged.**

The artifact instantiates the Chandra–Kozen–Stockmeyer alternating-computation layer in two forms:

1. **Semantic game/alternation operator (§5.1).** It defines the monotone operator `T` over semantic `N_G` configurations:
   - `ConfigAcc(C)` accepts;
   - `QSort(C)` accepts if some `YieldE(C,C')` successor is accepted (existential);
   - `QAdv(C)` accepts if both `YieldA0(C,C0)` and `YieldA1(C,C1)` successors are accepted (universal).
   It argues monotonicity, finite rank from budget consumption (`<= 2k+1` phases), existence of `LFP(T)`, and equivalence to an accepting alternating computation / sorter win in `G(n,k)`. This is the right CKS-style alternating acceptance semantics for the fixed comparison game.

2. **CKS complexity/capture bridge (§6.2, §6.4).** It uses `SORT-BOUND-U` on well-formed unary input length `N=n+k+1` as an `ATIME(poly(N))`/`APTIME`-scale alternating procedure, cites `APTIME=PSPACE` (Chandra–Kozen–Stockmeyer), and then appeals to Vardi/Immerman/Abiteboul–Vianu capture of PSPACE on ordered structures for FO(PFP)/FO(IFP). The intermediate `M_D^alt` (§6.3) makes the DTM side concrete rather than leaving it as an existence-only appeal.

**Audit notes.**
- The semantic `T` is correctly presented as a configuration-level operator, not as a discharged FO(LFP)/FO(PFP) sentence on the bare word. §5.2 and §7 keep that distinction.
- The `ATIME(poly(N))` claim in §6.2 is plausible given `O(k)=O(N)` phases and polynomial local work in `n<=N` for the explicit formulas; it is not a machine-formalized proof in the artifact. This is acceptable as a paper-level bridge, but it should not be read as a kernel-checked complexity claim.
- The artifact’s title/goal is satisfied at the instantiation level: CKS alternating acceptance is concretely instantiated for `M_G/G(n,k)` over ordered `A(w)`, with the syntactic formula expansion isolated.

## 2. Explicit `M_G` local formulas

**Status: explicit and substantially complete as a local semantic specification.**

The artifact gives fixed first-order formulas over `A(w)=(W,<,One,Hash)` and the fixed `N_G` relations `Pos,Used,Sel,Ctrl`:

| Component | Where | Assessment |
|---|---|---|
| Fixed signature / guards | §1 | Explicit: `HashPos, WellFormed_w, Malformed, Key, Ctr, Zero, MaxK, SuccCtr, HasBudget, KeyNe, Lex2`, `Φ_SORTU := WellFormed_w ∧ Φ_accept`. |
| Fixed state signature `N_G` | §2 | Explicit arities 2/1/2/1 for `Pos,Used,Sel,Ctrl`; semantic configuration `C=(Pos,Used,Sel,Ctrl)`. |
| Finite control encoding | §2 | Explicit FO-definable 4-tag scheme using `<`/`Succ`; uniqueness required. Equivalent fixed encodings acceptable. |
| Validity predicates | §3.1 | `ValidPos` includes domain restriction, irreflexivity, transitivity (strict partial order). `Incomparable`, `Total`, `ExactlyOneUsed`, `NoSel`, `OneSel`, `ValidConfig` are explicit. |
| `Init` | §3.2 | Antichain `Pos`, `Used=Zero`, `NoSel`, and `QAcc` iff `Total(Pos)` else `QSort`. Handles `n<=1` boundary. |
| `ConfigAcc/ConfigRej` | §3.2 | `ConfigAcc := QAcc ∨ Total(Pos)`; `ConfigRej := QRej`. |
| `StepPos` (incremental TC) | §3.3 | Explicit formula `Pos(u,v) ∨ ((u=x∨Pos(u,x)) ∧ (v=y∨Pos(y,v)))` with an **incremental TC lemma proof sketch** (soundness, completeness via single-use of new edge, irreflexivity, transitivity). |
| `PostBudget` | §3.4 | Three-way split: total -> `QAcc`; non-total + remaining budget -> `QSort`; non-total + exhausted -> `QRej`, with mutual exclusion of control tags. |
| `YieldE` | §3.5 | Existential sorter move: `QSort`, non-total, `HasBudget`, selects exactly one incomparable pair into `Sel'`, preserves `Pos/Used`, sets `QAdv`. |
| `YieldA0/YieldA1` | §3.5 | Universal adversary outcomes for selected pair `(a,b)`: apply `StepPos` with `(a,b)` or `(b,a)`, advance `Used` by exactly one `SuccCtr`, clear `Sel`, apply `PostBudget`. |

**Audit notes / falsification points.**
- The local TC lemma is the most mathematically sensitive local claim. The sketch is directionally correct and cites the standard incomparability/single-edge-use argument; a full formal proof should still check all endpoint combinations and the fact that `Pos` is already transitively closed. This is an ordinary proof obligation, not a hidden representation gap.
- `ConfigAcc := QAcc ∨ Total(Pos)` is permissive (accepts total states even if control is not `QAcc`); `Init` and `PostBudget` set control consistently, and `ValidConfig` requires `QAcc -> Total(Pos)`. The combination is reasonable but should be used consistently in the DTM evaluator/transition semantics.
- `YieldE` preserves `Pos` and `Used` while moving to `QAdv`; `YieldA0/1` consume budget and clear `Sel`. This matches the intended `G(n,k)` phase structure.
- The control encoding in §2 is schematic enough to permit equivalent fixed FO encodings; only definability and uniqueness matter. A symbol-level expansion under `[open:CKS-AV-FORMULA]` would need to fix one encoding.
- No local formula decodes arbitrary `Pos` from a fixed tuple name `d̄∈W^r`; all formulas quantify over `Key` elements or treat `Pos` as a relation. This is the right design.

## 3. DTM/AV capture route

**Status: explicit bridge provided; standard capture not fully expanded.**

The artifact’s route (b)-style/global bridge is concrete:

1. **Existence/capture context (§6.2, §6.4).** Uses CKS `APTIME=PSPACE` and standard Vardi/Immerman/Abiteboul–Vianu FO(PFP)/FO(IFP) capture of PSPACE on ordered structures, with standard references.

2. **Explicit DTM `M_D^alt` (§6.3).** Defines a deterministic DFS alternating evaluator with frame `(Pos,Used,Sel,Ctrl,mode,cursor)`. Transitions are specified in terms of the local formulas:
   - initialize from `Init`;
   - accept on `ConfigAcc`;
   - reject on `ConfigRej` or exhausted non-total sorter state;
   - existential `QSort`: enumerate lex-incomparable pairs and recurse via `YieldE`;
   - universal `QAdv`: evaluate `YieldA0` then `YieldA1`, accept only if both accept.
   It gives correctness by induction on finite game rank and a space bound: `O(n^2+log N)` per frame, depth `<=2k+1`, total `O(N^3)`.

3. **Target sentence/correspondence (§6.4).** Claims application of the standard Vardi/AV construction to `M_D^alt` yields `Φ_{M_D}` with `A(w)|=Φ_{M_D}` iff `M_D^alt` accepts, hence iff `M_G` accepts iff `S(n)<=k`, and final `A(w)|=WellFormed_w ∧ Φ_{M_D}` iff `w ∈ SORT-BOUND-U`.

**Audit notes.**
- This is stronger than an uninstantiated “FO(PFP)=PSPACE implies some sentence exists” because it supplies the specific polynomial-space evaluator `M_D^alt` whose moves come from the explicit local formulas. The DTM/AV theorem is still used as a standard construction, but its target machine is now concrete.
- The DTM frame stores the *current* `Pos` as `n^2` bits/content. That is legitimate for a PSPACE machine and avoids the tuple-name packing problem (§6.5).
- The DFS evaluator’s treatment of alternation is standard (AND/OR evaluation): existential node accepts if any child accepts; universal node accepts if both children accept. The artifact should be read as a semantic machine description; a full tape-level Turing transition function is not written.
- The space bound is plausible and conservative enough; exact constants/polynomial degree are not critical.
- A complete discharge would still need the symbol-level tape encoding of frames, the FO definition of `M_D^alt`’s one-step transition, and the fixed-point halting/acceptance proof for that encoding. The artifact correctly assigns this to `[open:CKS-AV-FORMULA]`.

## 4. A001035 / `PACK-REPR` avoidance

**Status: correctly avoided at the relevant point.**

The artifact addresses the old tuple-coding falsifier directly:

- §0 states the local alternating layer avoids total tuple-coding of all `Pos` by keeping `Pos` as a binary relation over `Key`, not as a code name in `W^r`.
- §6.1 restates the naive-global-form failure: `ACC(s̄,z̄)` with `z̄∈W^r` naming whole configurations fails for all valid `Pos` states because `A001035(n)=2^{Θ(n^2)}` labelled posets exceed `|W|^r=(n+k+1)^r` for every fixed `r` (OEIS A001035; Kleitman–Rothschild). It states this note does not use that total tuple-coding.
- §6.5 explains why the `M_D^alt` tape encoding avoids the falsifier: it stores the current frame’s `Pos` relation as tape content (a binary array in a frame), not a global name for every possible `Pos`. The Vardi/AV simulation needs fixed-arity access to tape cells, not injective tuple codes for all `A001035(n)` posets.

**Audit assessment.** This is the right distinction. `PACK-REPR` (total tuple naming of all valid configurations/posets) is falsified by counting; representing one current relation-valued state in a polynomial-space DTM configuration or as fixed-arity state relations is not. The artifact does not smuggle back a claim that every valid `Pos` has a unique `W^r` name. It also does not claim a restricted polynomial-capacity domain `D_{n,k}`; it explicitly bypasses that route.

Residual caution: a final symbol-level FO(PFP) expansion must still ensure that every quantified/encoded object is a domain tuple/cell index in the chosen normal form. The artifact has identified the right place for that check (`[open:CKS-AV-FORMULA]`), but the check is not yet performed.

## 5. `[open:CKS-AV-FORMULA]` isolation

**Status: precise and appropriately narrow.**

The artifact isolates one residual:

> **[open:CKS-AV-FORMULA] (formula expansion).** Give the explicit symbol-level FO(PFP) (or FO(IFP)) sentence obtained by applying the standard Vardi/Immerman/Abiteboul–Vianu DTM-capture construction to the concrete PSPACE DTM `M_D^alt` of §6.3 over the fixed ordered signature of §1, including: (i) fixed tape-cell/head/state relations and arity `r>=4`; (ii) FO definition of the initial tape encoding `Init_{M_D}`; (iii) FO one-step transition `Δ_{M_D}` expressing DFS stack operations and evaluation of `YieldE/YieldA0/YieldA1/ConfigAcc/PostBudget` on the encoded current `N_G` frame; (iv) the FO(PFP) halting/acceptance fixed point; (v) the equivalence proof `A(w)|=Φ_{M_D} iff M_D^alt accepts w iff M_G accepts A(w) iff S(n)<=k`.

**Audit assessment.** This isolation is useful and mostly accurate:
- It is narrower than `PACK-REPR` and `ALT-PACK` because it assumes the local formulas and the explicit `M_D^alt` are the semantic source, and it does not require total poset tuple-coding or a restricted polynomial domain.
- It is honest that the expansion is “routine-in-principle but lengthy”; routine-in-principle is not the same as discharged.
- It identifies the right deliverables for a symbol-level closure: tape layout/arity, initial configuration, one-step transition, fixed point, and equivalence proof.
- The arity hint `r>=4` is a reasonable implementation-level suggestion, not a theorem; the final proof would need to fix the actual arity and encoding.

Possible sharpening (not a contradiction): the artifact could also state that the one-step transition must be proved FO-expressible *from the fixed signature* and that the DFS stack discipline must be faithfully encoded (push/pop/cursor/frame boundaries), since that is the main nonlocal detail inside `M_D^alt`. §6.3 gives the semantic evaluator; `[open:CKS-AV-FORMULA]` already mentions DFS stack operations, which covers this.

## 7. Overclaim check

**No prohibited overclaim found.**

- **No `P` claim.** The artifact does not claim `SORT-BOUND-U ∈ P` or polynomial-time computability of `S`.
- **No `FO(LFP)`-on-bare-word claim.** The acceptance operator is described as a semantic alternating LFP and as a route to FO(PFP)/FO(IFP) capture via PSPACE; it does not assert FO(LFP) definability on the bare ordered word input.
- **No `NP` or `coNP` claim.** The note contains no membership or hardness claim for `NP` or `coNP`.
- **No discharged fixed-sentence overclaim.** §0 and §7 explicitly state that the symbol-level FO(PFP)/IFP sentence is not expanded and name `[open:CKS-AV-FORMULA]` as the exact residual. §6.4 describes a sentence `Φ_{M_D}` obtained by applying a standard construction, which is an existence/instantiation route, not a displayed discharged formula in this note.
- **Scope discipline.** The artifact stays on unary `SORT-BOUND-U` over ordered `A(w)` and does not open a binary workstream or claim a separation from `P`.

Minor wording caution: phrases like “syntactic schema discharged via `M_D^alt`+Vardi/AV” (§7 table) could be over-read. The surrounding text prevents this by calling the symbol-level expansion open; future summaries should keep the qualifier “schema/route, not expanded sentence”.
