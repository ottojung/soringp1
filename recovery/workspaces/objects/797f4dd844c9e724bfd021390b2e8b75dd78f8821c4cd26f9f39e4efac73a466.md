# Ford–Johnson recurrence: all-n upper bound and closed-form identification

## Status and scope

This note proves that the particular merge-insertion implementation described
below sorts every n-key input using at most

```
M(n) = sum_{j=1}^n ceil(log2(3j/4))
```

comparisons. It proves an **upper bound** for this strategy only. It does not
prove that the strategy attains this count as its exact worst-case height, and
it makes no claim that `S(n)=M(n)` or about the complexity of computing S(n).
No primary-source pinpoint for the recurrence was accessed in this audit; the
proof is given from the implementation conventions.

## 1. Definitions

Let `J_0=0`, `J_1=1`, and `J_r=J_{r-1}+2J_{r-2}` for `r>=2`. Put

```
q(j) = min { r>=1 : J_r >= j }
d(j) = ceil(log2(3j/4))
B(n) = sum_{j=1}^n d(j),   B(0)=0.
```

The schedule starts with `{1}` and then, for r=3,4,..., visits the block
`{J_r,J_r-1,...,J_{r-1}+1}` in descending order, truncating at the final
pending index K. Thus the blocks are `{1}`, `{3,2}`, `{5,4}`, `{11,...,6}`,
etc.; there is no block for r=2 because `J_2=J_1=1`.

In `fj_sort`, let `k=floor(n/2)`. It spends k comparisons orienting disjoint
pairs, recursively sorts the k winners, then inserts each loser before its
paired winner by binary search. If n is odd, the unpaired straggler is the
last pending index `K=k+1` and is inserted by full-chain binary search;
otherwise `K=k`. Binary search over m chain elements has at most
`ceil(log2(m+1))` comparisons.

## 2. The implemented strategy has an all-n recurrence upper bound

Define `U(0)=U(1)=0` and, for n>=2,

```
U(n) = U(floor(n/2)) + floor(n/2)
       + sum_{j=1}^{ceil(n/2)} (q(j)-1).                 (R)
```

Then every run of the implementation on n distinct keys uses at most U(n)
comparisons.

**Proof.** The closed form
`J_r=(2^r-(-1)^r)/3` follows by checking the initial values and the recurrence.
It gives

```
J_r+J_{r-1}=2^(r-1)  (r>=1).                            (1)
```

For pending index j in block r>=3, the number `b_j` of scheduled entries
strictly before j is

```
b_j = J_{r-1} + min(J_r,K) - j.
```

Indeed, all previous blocks contribute indices `1,...,J_{r-1}`, and within
the current descending block the entries before j are exactly
`min(J_r,K),...,j+1`. The code assigns each loser the pending key
`pos_in_sorted[winner]+1`, not its original pair number. Consequently, the
paired winner for schedule index j has zero-based rank exactly j−1 in the
initial sorted-winner chain, regardless of original pair order. Each
previously scheduled item is one earlier loser insertion, and each can shift
that winner's rank right by at most one. There are exactly b_j such earlier
items, so the binary-search interval size m (the number of chain elements
before the paired winner) obeys `m<=j−1+b_j`. Therefore

```
m+1 <= j+b_j
     = J_{r-1}+min(J_r,K)
     <= J_{r-1}+J_r
     = 2^(r-1),
```

and the insertion costs at most `r−1=q(j)−1` comparisons. For j=1, the
interval is empty and the same bound is zero.

If n=2k+1>=3, set K=k+1 and r=q(K). The truncated block visits K first;
exactly `J_{r-1}` indices from completed blocks precede it. Thus, just before
the straggler insertion, the chain length is `L=k+J_{r-1}`. Since `K<=J_r`,

```
L+1 = K+J_{r-1} <= J_r+J_{r-1} = 2^(r-1),
```

so full-chain binary search costs at most `r−1=q(K)−1`. Pairing costs k,
recursion costs at most U(k), and the regular pending indices together with
the possible straggler contribute at most the sum in (R). This proves (R) by
induction. ∎

## 3. Exact integer threshold lemma for odd indices

For every integer m>=1,

```
d(2m-1) = q(m)-1.                                     (2)
```

For m=1, both sides are zero. For m>=2, let r=q(m), so
`J_{r-1}<m<=J_r` and r>=3. The closed form for J gives

```
3(2m-1) >= 6J_{r-1}+3 = 2^r + 2(-1)^r + 3 > 2^r,
3(2m-1) <= 6J_r-3     = 2^(r+1) - 2(-1)^r - 3 <= 2^(r+1).
```

Dividing by 4 gives `2^(r-2) < 3(2m-1)/4 <= 2^(r-1)`, which is exactly
`ceil(log2(3(2m-1)/4))=r-1`.

Also, directly from the definition of d,

```
d(2m)=d(m)+1.                                         (3)
```

## 4. The even-step identity by first differences

Let

```
D(k)=sum_{j=1}^k(q(j)-1).
```

Then `D(k+1)-D(k)=q(k+1)-1`. We prove for all k>=1 that

```
B(2k)-B(k)-k = D(k).                                 (4)
```

At k=1, `B(2)=1`, `B(1)=0`, and `D(1)=q(1)-1=0`, so (4) holds. For m=k+1,
the difference between the left-minus-right expressions at k+1 and k is

```
d(2k+1)+d(2k+2)-d(k+1)-1 - (q(k+1)-1)
 = d(2m-1)+d(2m)-d(m)-q(m)
 = (q(m)-1)+(d(m)+1)-d(m)-q(m)
 = 0,
```

using (2) and (3). This proves (4) by induction. Notice the proof uses the
odd threshold identity as an all-integer lemma; no numerical fit or parity
case table is being substituted for the induction.

## 5. Identification of U with the displayed sum

For even n=2k, (4) is exactly

```
B(2k)=B(k)+k+sum_{j=1}^k(q(j)-1).
```

For odd n=2k+1>=3, use (4), (2), and `D(k+1)=D(k)+q(k+1)-1`:

```
B(2k+1)
 = B(2k)+d(2k+1)
 = B(k)+k+D(k)+q(k+1)-1
 = B(k)+k+D(k+1).
```

Thus B obeys recurrence (R) for even and odd n, with `B(0)=B(1)=0`. By
induction, `U(n)=B(n)` for every n>=0. Combining this with Section 2 proves
the stated all-n Ford–Johnson **upper bound**.

It checks the Jacobsthal closed form, (1), (2), (3), (4), and equality of the
