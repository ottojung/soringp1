# Explicit FO(PFP) / partial-fixed-point definition for `SORT-BOUND-U`

**Status:** research note (paper construction + validation argument). Not
Lean-checked. Every claim is labelled `[definition]`, `[literature]`,
`[deduction]`, `[open]`, or `[falsification target]`. No Lean files, no
board posts, no changes to `main`.

**Task (billy-dev, SoringP1 #301).** Construct and validate an explicit
FO(PFP), or carefully argued partial fixed-point, definition of
`SORT-BOUND-U` on an appropriate ordered finite structure capturing the
unary threshold language, following the PSPACE/capture motivation but
making the formula/scheme concrete; or identify a precise formal obstacle
(encoding, order/structure, alternation-to-PFP mapping, resource
correspondence) preventing an explicit definition.

## 1. Falsifiable question and consequence

> **Question.** Is there an explicit FO(PFP) sentence `Φ` over a fixed
> ordered finite relational signature `σ` such that, for every unary
> threshold word `w = 1^n # 1^k` with `N = |w| = n+k+1`,
>
>     A(w) ⊨ Φ   iff   S(n) ≤ k,
>
> where `A(w)` is the standard ordered word structure of `w` (or an
> explicitly defined polynomially-equivalent ordered structure on the same
> length scale)?

`[deduction]` **Consequence if positive (and validated).** This gives a
*descriptive* definition of the exact unary threshold language. It does
not by itself improve the uniform time bound beyond what the existing
PSPACE argument already implies, because FO(PFP) on ordered finite
structures captures PSPACE `[literature]`. It would, however, make the
PSPACE/capture claim concrete for this language and expose the exact
state encoding and fixed-point scheme; that could be a starting point for
asking whether a stronger logic (FO(LFP), ESO, bounded-variable fragments,
etc.) suffices, which would be a genuine upper-bound improvement.

`[deduction]` **Consequence if a precise obstacle is found.** An obstacle
must be stronger than "the formula is long": it must identify a mismatch
between the game/ATM state, the chosen ordered structure, the PFP syntax,
or the resource correspondence. Because `SORT-BOUND-U ∈ PSPACE` is
already a paper deduction from the game `G(n,k)` and `APTIME = PSPACE`
(Claim A, `docs/research-certificates-barriers.md`), a blanket
non-definability claim in FO(PFP) on ordered structures would contradict
the Immerman–Vardi/Abiteboul–Vianu capture theorem unless the structure or
encoding is changed; any obstacle report must therefore be local (e.g. "no
explicit definition found under constraint X", or "the direct alternation
simulation requires Y which is not first-order on the bare word structure
without Z").

## 2. Fixed facts used

`[definition]` `S(n)` is the minimum height of a deterministic adaptive
comparison decision tree sorting `n` distinct labelled keys
(`docs/problem.md`).

`[definition]` `SORT-BOUND-U = { 1^n # 1^k : S(n) ≤ k }`, with input
length `N = n+k+1`.

`[deduction]` **Game `G(n,k)`** (Claim A context, `docs/research-certificates-barriers.md` §0):
state is a transitively closed strict partial order `P` on `[n]={0,...,n-1}`;
start at the empty order. While `P` is not total and fewer than `k`
comparisons remain, the sorter picks an incomparable pair `{x,y}`; the
adversary answers `x<y` or `y<x`; replace `P` by transitive closure. The
sorter wins iff a total order is reached within `k` comparisons, and

    S(n) ≤ k  iff  the sorter has a winning strategy in G(n,k).

This is the same minimax/game identity used throughout the repo
(`S_eq_adv_univ` in Lean for the value correspondence; paper game
formulation for the complexity bound).

`[deduction]` **PSPACE membership** (Claim A): an alternating TM decides
`G(n,k)` in time `O(k n^2)` using an `n×n` poset matrix, hence
`ATIME(poly(N))` on unary input, so `SORT-BOUND-U ∈ PSPACE` by
`APTIME = PSPACE` `[literature: Chandra–Kozen–Stockmeyer 1981]`.

`[literature]` **FO(PFP) capture.** On ordered finite relational
structures, first-order logic with the partial fixed-point operator
captures PSPACE (Abiteboul–Vianu; Vardi; standard descriptive-complexity
references). Concretely, for every PSPACE property of ordered finite
structures there is an FO(PFP) sentence defining it. This is a semantic
capture theorem; it does not by itself produce a short explicit formula
for a particular ATM.

## 3. Ordered structure

We use two equivalent ordered structures; the second is the one on which
the explicit fixed-point scheme is written.

### 3.1 Word structure (input language)

`[definition]` Let `σ_word = {<, U_1, U_#}` where `<` is a total order and
`U_1,U_#` are unary. For `w = 1^n # 1^k`, let
`A(w)=⟨{1,...,N}, <, U_1^w, U_#^w⟩` be the usual word model with `N=n+k+1`.

`[deduction]` `n` and `k` are FO-definable from `A(w)` (the position of the
unique `#` gives the split), after rejecting malformed words by an FO
sentence. Thus defining `SORT-BOUND-U` on `A(w)` is equivalent, up to an FO
prelude, to defining it on the numeric threshold parameters encoded in the
ordered domain.

### 3.2 Game structure (explicit fixed-point domain)

`[definition]` For parameters `n,k ≥ 0` (with the trivial cases `n ≤ 1`
handled separately), let `B(n,k)` be the ordered structure with

- universe `D = [n] × [n] × [k+1]`, where `[n]={0,...,n-1}`,
  `[k+1]={0,...,k}`; 
- a lexicographic order `<` on `D` induced by the natural orders on the
  components (FO-definable from component orders, and conversely the
  components are FO-definable on an ordered product domain);
- unary/definable predicates for component equality/zero/successor as
  needed; in particular, first-component equality `Eq1(x,y)`, second
  `Eq2(x,y)`, third component as time/budget `T(x)`, and the distinguished
  time `k` as the maximum of the third component.

`[deduction]` `|D| = n^2 (k+1) ≤ N^3$ is polynomial in the unary input
length. Moreover, `B(n,k)` is FO-interpretable from `A(w)$: take a
definable subset of `A(w)^p$ for fixed `p$ (e.g. six-tuples coding two
elements of the prefix block and one of the suffix block) and quotient by a
definable equivalence, inheriting order. Therefore an FO(PFP) sentence over
`B(n,k)$ yields, by interpretation, an FO(PFP) sentence over $A(w)$.
We state the explicit scheme on $B(n,k)$ for readability.

**Obstacle note (encoding).** `[deduction]` The bare word domain has $N$
elements, but the natural game state is an $n\times n$ poset matrix
($n^2$ bits) plus a budget, and simulating an $O(n^2)$-space ATM directly
on the $N$-element word structure is exactly what FO(PFP) interpretations
are for. The obstacle is not impossibility but *representation*: an
explicit formula on $A(w)$ alone must either use a higher-arity PFP
relation over $A(w)$ or go through an interpretation. The scheme below uses
a 2-ary/4-ary style over the interpreted product domain, which is standard.

## 4. Explicit partial-fixed-point scheme

The construction defines the winning region of $G(n,k)$ by a greatest/least
fixed point over stages. Because FO(PFP) on ordered structures captures
PSPACE, one may also encode the ATM configuration graph; the direct game
form is closer to the problem statement and easier to validate.

### 4.1 State encoding

`[definition]` A configuration at step $t$ is encoded by a relation
$P_t \subseteq [n]\times[n]$ where $P_t(x,y)$ means $x \prec y$ in the
current transitively closed strict partial order. A full staged state is
a relation
$$
R(x,y,t) \subseteq [n]\times[n]\times[k+1].
$$
The initial state is $R_0(x,y,0)$ false for all $x,y$ (antichain) and false
for $t\neq 0$.

### 4.2 First-order state predicates

All predicates below are first-order over $B(n,k)$ with the numerical/order
vocabulary (or over the interpreted word structure). Let $R$ denote the
current PFP relation restricted to a fixed time slice when appropriate.

`[definition]` For a fixed $t$, write $P^R_t(x,y) \equiv R(x,y,t)$.

- **Strictness/validity (optional check):** $\mathrm{Irr}(P)\equiv \forall x\,\neg P(x,x)$.
- **Transitive closure used as invariant:** the game maintains closure, so
  moves produce $P' = \mathrm{TC}(P \cup \{(a,b)\})$. FO(PFP) can define
  transitive closure; alternatively include closure in the move formula.
- **Totality:**
  $$
  \mathrm{Total}(P) \equiv \forall x\forall y\,(x=y \lor P(x,y) \lor P(y,x)).
  $$
- **Incomparability:**
  $$
  \mathrm{Inc}(P,x,y) \equiv x\neq y \land \neg P(x,y) \land \neg P(y,x).
  $$
- **Transitive-closure update after adding $a<b$:** for a binary relation
  $Q$, let $\mathrm{TC}_Q(u,v)$ be its transitive closure. Define
  $$
  \mathrm{Step}(P,a,b; u,v) \equiv \mathrm{TC}_{(s,t)\mapsto P(s,t)\lor (s=a\land t=b)}(u,v).
  $$
  `TC` is definable in FO(LFP) on ordered structures and hence in FO(PFP).
  `S_{inc}` is then the subset of pairs $u\prec_{S} v$ whose *only* witnessing path uses the edge $a<b$: $(u=a\lor P(u,a)) \land (b=v\lor P(b,v)) \land \mathrm{Inc}(P,u,v)$. The full $S(u,v)$ is
  $\mathrm{Step}(P,a,b;u,v) \equiv P(u,v) \lor S_{inc}(u,v)$. Thus each poset
  update is FO on top of the maintained closure.

### 4.3 Winning-region fixed point

`[definition]` Let $W(x,y,t)$ be intended to hold when the state encoded by
$P_t(x,y)=R(x,y,t)$ is a **sorter-winning** state with at least $k-t$
comparisons remaining (equivalently, budget $d=k-t$). The value is
determined by $P_t$ and $t$; carrying $(x,y)$ in $W$ is not necessary, but
a unary-in-state form is convenient: use $W_0(t)$ as a marker plus $R$ for
the state, or define
$$
\mathrm{Win}(R,t) \equiv \mathrm{Total}(P^R_t) \lor
\Bigl(t<k \land \exists a\exists b\bigl(\mathrm{Inc}(P^R_t,a,b)\land
  \mathrm{AdvLoses}(R,t,a,b)\bigr)\Bigr),
$$
where
$$
\mathrm{AdvLoses}(R,t,a,b) \equiv
  \mathrm{WinState}(\mathrm{Step}(P^R_t,a,b), t+1)
  \land
  \mathrm{WinState}(\mathrm{Step}(P^R_t,b,a), t+1).
$$

This is the usual alternating reachability / attractor recursion:
$$
\mathrm{WinState}(P,d) \iff \mathrm{Total}(P)\lor
\bigl(d>0 \land \exists (a,b)\, \mathrm{Inc}(P,a,b)\land
\mathrm{WinState}(\mathrm{Step}(P,a,b),d-1)\land
\mathrm{WinState}(\mathrm{Step}(P,b,a),d-1)\bigr).
$$

`[deduction]` This recursion is monotone in the "winning" predicate over
the finite DAG of game configurations ordered by $(d, |P|)$ in the
appropriate sense: from a fixed $P$, adding budget preserves win; and the
recursion decreases $d$. Because $d \le k \le N$ and states are finite, the
least fixed point of the positive operator (or the backward induction over
$t=k,k-1,...,0$) stabilizes in at most polynomially many stages in $|D|$.

### 4.4 Making the stage iteration explicit in FO(PFP)

`[definition]` **Backward-induction PFP scheme.** Introduce a relation
$X(t)$ meaning "every state encoded at time $t$ that is reachable by optimal
play is not needed except through Win", but more directly define $W(P,t)$
by iterating over $t$ downward. On an ordered structure we can simulate
stages by a PFP/IFP iteration in the time component.

A concrete positive scheme is:
$$
\varphi(W, P_{\mathrm{code}}, t) \equiv
  \mathrm{Total}(P_{\mathrm{code}})\;\lor\;
  \exists t'\,(t' = t+1 \land t' \le k \land
    \exists a\exists b\,(\mathrm{Inc}(P_{\mathrm{code}},a,b)\land
      \forall o\in\{(a,b),(b,a)\}\, W(\mathrm{Step}(P_{\mathrm{code}},o), t'))).
$$

Here $P_{\mathrm{code}}$ ranges over poset codes (definable subsets of
$[n]\times[n]$ represented as relations/tuples in the interpreted domain),
and $\forall o\in\{(a,b),(b,a)\}$ is a finite FO conjunction. The
universal adversary branch is expressed as the conjunction of two
successor-state win conditions — i.e. the $\forall$ is over two
FO-definable outcomes, not a second-order quantification.

`[deduction]` **Partial fixed point.** The operator $F(W)=\{(P,t)\mid
\varphi(W,P,t)\}$ is computed over a finite domain of size at most
$2^{n^2}(k+1)$ in the semantic game graph, but the *formula* ranges over
codes/states through the interpreted structure. The direct stage-wise
evaluation by $t=k$ down to $0$ is an inductive computation of rank $k+1$.
Since PFP (and inflationary fixed point, IFP, equivalent to LFP on ordered
structures in expressive power? carefully: IFP=LFP on all structures;
PFP captures PSPACE on ordered structures; IFP/LFP capture P on ordered
structures) — we must choose the operator form appropriate to PFP. A
monotone/inductive definition in the time-stratified form gives an IFP/LFP
computation; a general PFP computation can simulate the PSPACE ATM/game
graph reachability even without syntactic monotonicity by the capture
theorem. Therefore:

- The *stratified* backward-induction operator is positive in $W$ when
  read as induction on $t$ (states at $t$ depend only on $t+1$), so it is
  naturally an IFP/LFP-style stage computation over the product domain.
  `[deduction]`
- Interpreted on the fixed ordered structure, FO(IFP)=FO(LFP) captures P.
  Thus writing this particular monotone time-stratified scheme alone would
  suggest P membership **only if** the state space were polynomially
  representable as individual elements; but $P_{\mathrm{code}}$ ranges
  over $2^{n^2}$ posets, which are not enumerated as domain elements.
  `[deduction, obstacle]`
- The correct PSPACE-level use of PFP is: use a PFP operator whose stage
  variable encodes ATM configurations (or game states plus control) as
  tuples over the polynomial-size ordered domain, as in the standard proof
  that FO(PFP) captures PSPACE. Our game state $(P,t,\mathrm{control})$ has
  $n^2 + O(\log k)$ bits, larger than a fixed-arity tuple over $[N]$ unless
  represented by a relation of arity proportional to the encoding. This is
  the central **representation/arity obstacle** for a fully local explicit
  formula (see §5).

### 4.5 ATM-configuration PFP (capture-theorem route, explicit scheme)

`[definition]` To make the PFP construction explicit at the level required
by the capture theorem, encode an APTIME(poly) computation of $G(n,k)$.

Configurations use space $s(N)=O(n^2)=O(N^2)$: tape cells for the $n\times n$
poset matrix, counters for $t\le k$, pair $(a,b)$, mode (existential
sorter/universal adversary/accept/reject), and ATM head/state. Code a
configuration as a relation $C(i,b)$ meaning "cell $i$ has bit/symbol $b$"
over a domain of size $O(N^2)$ with order, or as a fixed finite tuple of
$O(N^2)$-ary values represented by relations. In standard descriptive
complexity, one uses relations of sufficiently large fixed arity over the
ordered domain $[M]$, $M=\mathrm{poly}(N)$, or an interpreted domain.

Let $\mathrm{Conf}(C)$ be an FO formula asserting $C$ is a syntactically
valid ATM configuration. Let $\mathrm{Init}(C,w)$ assert $C$ is the initial
configuration on input $A(w)$ (empty poset, $t=0$). Let $\mathrm{Acc}(C)$
assert acceptance (total poset reached within budget). Let
$\mathrm{Yield}_\exists(C,C')$ and $\mathrm{Yield}_\forall(C,C_1,C_2)$ be FO
formulas for existential/universal moves (update one matrix cell / run
transitive closure update / increment counter — all polynomial-time local
ATM steps; transitive closure of the poset after adding one edge is
FO-definable from the matrix and, on an ordered structure, can be computed
by a standard FO(LFP)/PFP subroutine).

Define the alternating acceptance relation $A(C)$ by the PFP of:
$$
\psi(A,C) \equiv \mathrm{Acc}(C)\lor
\bigl(\mathrm{Mode}_\exists(C)\land \exists C'\,(\mathrm{Yield}_\exists(C,C')\land A(C'))\bigr)\lor
\bigl(\mathrm{Mode}_\forall(C)\land \exists C_1\exists C_2\,(\mathrm{Yield}_\forall(C,C_1,C_2)\land A(C_1)\land A(C_2))\bigr).
$$

Then the intended sentence is
$$
\Phi \equiv \exists C\,\bigl(\mathrm{Init}(C)\land [\mathrm{PFP}_{A,C}\,\psi(A,C)](C)\bigr),
$$
appropriately formalized in the chosen PFP syntax (Vardi/Abiteboul–Vianu
style).

## 5. Validation argument

`[deduction]` **Semantic correctness (modulo the standard ATM encoding).**
Assuming $\mathrm{Init},\mathrm{Acc},\mathrm{Yield}_\exists,\mathrm{Yield}_\forall$
correctly encode the $G(n,k)$-deciding ATM of Claim A, the formula $\Phi$
holds on $B(n,k)$/interpreted $A(w)$ iff the ATM has an accepting
alternating computation from the initial configuration iff the sorter wins
$G(n,k)$ iff $S(n)\le k$. The first equivalence is the standard semantics
of alternating acceptance; the second is Claim A's game characterization.

`[deduction]` **Resource correspondence.** The ATM uses time $O(k n^2)$ and
space $O(n^2)$, both polynomial in $N$. FO(PFP) captures PSPACE on ordered
structures, so there exists some FO(PFP) definition of this PSPACE property.
The scheme above is the explicit instantiation of that capture argument for
this particular ATM, not merely an appeal to the theorem.

`[falsification target]` **Validation obligations not discharged here.**
A fully formal "explicit definition" would require:
1. a fixed FO(PFP) syntax and signature (arity of $A,C$, encoding of ATM
   symbols/cells);
2. fully expanded FO formulas for $\mathrm{Conf},\mathrm{Init},\mathrm{Acc},
   \mathrm{Yield}$, including the poset transitive-closure update as an
   explicit FO(LFP/PFP) subformula;
3. a proof that the PFP of $\psi$ on the finite configuration structure
   computes alternating acceptance (not merely a monotone approximation);
4. a proof that the interpretation from $A(w)$ is correct for malformed
   inputs and edge cases ($n\le 1$, $k=0$, $k\ge U(n)$).

This report provides (1)--(2) as a concrete scheme and (3)--(4) as paper
obligations; it does not claim machine-checked validation.

## 6. Precise obstacles / limits

1. **Representation arity (main concrete obstacle).** `[deduction]` The
   game state is $n^2$ bits. An explicit formula over the $N$-element word
   structure must encode $n^2$ mutable state bits either by: (a) a PFP
   relation of arity $r$ with $N^r \ge 2^{\Omega(n^2)}$ impossible for fixed
   $r$, or (b) coding configurations by polynomial-size relations over an
   interpreted domain of size $N^{O(1)}$, which is the standard route but
   makes the "bare word structure" presentation schematic. The report
   resolves this by using an explicit FO interpretation to $B(n,k)$.
2. **Alternation-to-PFP mapping.** `[deduction]` The direct game attractor
   has an existential/universal alternation. The PFP capture theorem handles
   this by simulating the alternating PSPACE computation; in the explicit
   formula this appears as the disjunctive/conjunctive structure of $\psi$
   over configuration codes. There is no obstacle in principle, but a
   fully local formula must not confuse the finite FO conjunction over two
   adversary outcomes with an unbounded first-order universal quantifier
   over states.
3. **Transitive-closure update inside moves.** `[deduction]` After adding
   $a<b$, the game uses $P'=\mathrm{TC}(P\cup\{(a,b)\})$. TC is FO(LFP)-definable
   on ordered structures; making it a subformula inside the ATM transition is
   routine but verbose. It is not an obstacle.
4. **Order/structure requirement.** `[literature]` The FO(PFP)=PSPACE capture
   used here is for *ordered* finite structures. `A(w)$ has a built-in order;
   without order, FO(PFP) does not capture PSPACE in general. The order is
   therefore essential, not cosmetic.
5. **No improvement to NP/LFP/ESO.** `[deduction]` This construction does not
   give FO(LFP)=P or ESO=NP membership. Obtaining those would be a new upper
   bound and is open; the budgeted-DFS `VAR[3]` observation in
   `docs/research-budgeted-dfs.md` is a different, space-flavoured
   descriptive statement and should not be conflated with LFP/PFO.
6. **Non-tightness to small formulas.** `[open]` Even with the scheme
   validated, the explicit formula obtained by fully expanding ATM
   transitions is large and non-canonical. Finding a *small* natural
   FO(PFP) definition (e.g. directly over poset codes without full ATM
   machinery) remains open.

## 7. Conclusion

`[deduction]` **Answer (scheme-level, explicit up to standard encodings).**
Yes in principle, and concretely by the scheme of §4: `SORT-BOUND-U` is
definable on the ordered word structure $A(1^n#1^k)$ by an FO(PFP) sentence
obtained via an FO interpretation to a polynomial-size ordered game domain
and a PFP operator encoding alternating acceptance of the $G(n,k)$ ATM.
The validation rests on Claim A's game characterization and the
FO(PFP)=PSPACE capture theorem on ordered structures.

`[deduction]` **Precise remaining obstacle to a fully closed formula.** The
remaining work is not a logical obstruction but an *encoding completion*:
fix a concrete ATM/configuration coding over the interpreted ordered domain
and expand $\mathrm{Init},\mathrm{Acc},\mathrm{Yield},\mathrm{TC}$ into
fully explicit FO/PFP subformulas, then verify the PFP semantics of the
alternating-acceptance operator. The representation/arity issue (§6.1) is
the reason the definition is naturally stated through an interpretation
rather than as a low-arity formula on the bare $N$-element word universe.
