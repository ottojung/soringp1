## 3. C1/C2 — row 15 snapshot source and preservation

`[open][lemma A1_Snapshot_From_Parent_v2]`
Let `E` be `I_{M_D}`-reachable (BackE-v2 `Fld`/cursor discipline where stated)
and let row 15 consume `c̄` with
`D_backA0_acc_A1(E,c̄,d̄,a,b)`. Then:
1. Row 15's A1 child `d̄` is constructed only from
   `PosF(E,c̄), UsedF(E,c̄), HasSel(E,c̄), SelA(E,c̄,a), SelB(E,c̄,b)`,
   `a,b`, `d̄=CurBase(E)`, and fixed formulas `StepPosBit_c((b,a);·,·)`,
   `SuccCtr`, `PostBudgetFrom`, `MinKey`.
2. Row 15 reads no field of any `x̄` with `FrameInactive(E,x̄)`; in particular
   it reads no field of the popped A0 child `d0` that produced `RetAcc(c̄)`.
3. `PosF(E,c̄),UsedF(E,c̄),HasSel(E,c̄),SelA(E,c̄,a),SelB(E,c̄,b),
   HasCur(E,c̄),CurA(E,c̄),CurB(E,c̄),CurExhausted(E,c̄)` equal the snapshot
   installed/preserved by row 7 `SetParentBackA0(c̄)` and preserved by every
   intervening transition until `Top(E,c̄)∧M_BackA0(E,c̄)∧RetAcc(E,c̄)`.

`[deduction]` (C1 schema). Row 15's guard has only `c̄,a,b` fields of live `c̄`;
updates are `SetParentBackA1(c̄)` and `PushChildA(d̄,c̄,a,b,1)`.
`PushChildA` writes only `d̄` fields and reads `UsedF(c̄,·)` and side/formulas;
`StepPosBit_c(side;u,v)` uses `side=(b,a)` and the selected pair/orientation
formula, not an A0-child frame address. No inactive frame variable occurs.
Thus (1),(2) hold by schema.

## 5. C4 — universal accept/reject propagation

`[open][lemma Universal_Adv_Propagation_A0A1]`
For an `I_{M_D}`-reachable adversary split at `(a,b)` on `c̄` (row 7), the
A0/A1 return discipline is:
1. **A0 reject propagates, no A1.** `M_BackA0(c̄)∧RetRej(c̄)∧Top(c̄)` is
   consumed only by row 13 (root: `Globals_root_halt_rej`) or row 14
   (non-root: `MarkRetRejOn(p̄)`, pop to parent). Row 15 cannot fire because it
   requires `RetAcc(c̄)`.
2. **A0 accept => A1.** `M_BackA0(c̄)∧RetAcc(c̄)∧Top(c̄)∧HasSel/SelA/SelB`
   is consumed by row 15, which sets `M_BackA1'(c̄),RetNone'(c̄)`, preserves
   the snapshot, and pushes A1 child with side `(b,a)`. Rows 13/14 cannot fire.
3. **A1 accept propagates.** `M_BackA1(c̄)∧RetAcc(c̄)∧Top(c̄)` is consumed
   only by row 16 (root: `Globals_root_halt_acc`) or row 17 (non-root:
   `MarkRetAccOn(p̄)`). This means both A0 and A1 subtrees accepted.
4. **A1 reject propagates.** `M_BackA1(c̄)∧RetRej(c̄)∧Top(c̄)` is consumed
   only by row 18 (root: `Globals_root_halt_rej`) or row 19 (non-root:
   `MarkRetRejOn(p̄)`).

`[deduction]` (schema). The guards partition the consuming cases:
`M_BackA0∧RetRej` => {13 root,14 non-root}; `M_BackA0∧RetAcc` => 15 (and
requires `HasSel/SelA/SelB`, supplied by row 7/BackA0 snapshot); `M_BackA1∧RetAcc`
=> {16,17}; `M_BackA1∧RetRej` => {18,19}. `ExactlyOneMode` and exclusive `Ret`
states under `I_{M_D}` prevent overlap; `Root`/`NonRoot+Parent` and
`MarkRet*On` make root/non-root propagation explicit.

`[open]` A complete proof must discharge: `I_{M_D}` preservation of
`ExactlyOneMode`/coherent `Ret`; `HasSel/SelA/SelB` present on reachable row-15
states (BackA0 snapshot); no `BackA*+RetNone` consuming gap except as a
refined invariant (normalized Enc §4.1 `No_BackStar_RetNone_Consuming_Top`);
`MarkerReceiver_Is_BackStar` so `MarkRet*On(p̄)` reaches a consuming Back*
or terminal-compatible receiver; `Parent_Functional_Active_Preserved` for row
14/17/19 targets.

```text
I_{M_D}(E) ∧ Top(E,c̄) ∧ M_BackA0(E,c̄) ∧ RetAcc(E,c̄)
```

Impossible by schema because row 15 requires `RetAcc(c̄)` and rows 13/14 require
`RetRej(c̄)`.

`[falsification-shape F_A1_wrong_prop]` **A1 return mispropagated.**

and `MarkRet*On` definitions under the stated schema.

```text
I_{M_D}(E) ∧ D_{backA0_rej_ret,backA1_acc_ret,backA1_rej_ret}(E,c̄,p̄)
∧ ( ¬Parent(E,c̄,p̄) as DFS-active parent
```

This is the normalized Enc §4.1/§4.2 dependency
(`Parent_Functional_Active_Preserved`, `MarkerReceiver_Is_BackStar`), not a
row-15-specific failure.
