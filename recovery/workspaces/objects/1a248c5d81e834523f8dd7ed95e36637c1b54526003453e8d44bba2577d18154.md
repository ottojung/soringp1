## Question
For an optimal adaptive comparison strategy of height `S(n)` on `n` keys, what is a provable all-`n` lower bound on the number of nodes/edges in any sound, complete framed permutation certificate / comparison DAG that certifies `S(n) <= k` (polynomial-time verifiable in the representation)? Either (a) prove a superpolynomial or exponential lower bound (in `n`, or relate to `n!`, or `2^{Ω(n log n)}` etc.) for every such certificate system or for a clearly stated natural class, or (b) construct/exhibit a polynomial-size framed DAG/certificate family for all `n` at height `S(n)` (or show why known constructions fail and what exact obstruction remains). Distinguish explicit tree (`2n!-1` leaves/nodes scale), quotient/DAG sharing, framed vs unframed, and completeness at optimal height.

## Definitions / model fixed (from repo docs)
- `[definition][literature]` `S(n)`: minimum worst-case comparisons of a deterministic adaptive comparison decision tree correctly sorting every permutation of `n` distinct labelled keys (`docs/problem.md`). `SORT-BOUND-U = {1^n#1^k : S(n) <= k}`.
- `[definition][paper, repo]` Framed permutation certificate (`docs/research-framed-certificate-frontier.md`, `scripts/check_framed_strategy.py`): acyclic DAG of comparison instructions on `n` slots. Each arc gives comparison outcome and a permutation of current slots. Root guaranteed strict order `R` empty. Outgoing arc extends `R` by outcome, takes transitive closure, applies permutation. Join intersects guaranteed relations of all feasible incoming arcs. Terminal requires resulting `R` to be a total order on slots. Longest execution path `<= k`. Sound and checkable in time polynomial in explicit graph length and `n` (local feasibility, permutation, closure/intersection, DAG depth).
- `[deduction]` A sound complete certificate for a correct height-`k` sorting strategy is a witness that every real input order follows some feasible path to a terminal total-order guarantee within `k` comparisons. This is an upper-bound/correctness witness for `S(n) <= k`; it is not a lower-bound certificate for `S(n) > k`.

## Findings

### F1. Trivial all-`n` path/depth lower bound (every sound certificate, any representation)
- `[literature][deduction]` Information-theoretic/adversary lower bound: `S(n) >= C(n)=ceil(log2(n!)) = n log2 n - n/log 2 + O(log n) = Θ(n log n)`.
- `[deduction]` Therefore any sound certificate certifying `S(n) <= k` must satisfy `k >= S(n) >= C(n)`, so its longest feasible path has `>= C(n)` comparison edges and `>= C(n)+1` nodes on that path. This is an `Ω(n log n)` **path-length** lower bound, not a superpolynomial **total DAG size** lower bound.

### F2. Exponential lower bound for the natural class of unshared framed decision trees (no joins)
- `[deduction]` **Claim (unshared-tree class).** Let `D` be any sound, complete framed certificate whose reachable comparison/terminal structure is a rooted tree (equivalently: no feasible join identifies distinct histories; each reachable non-root node has exactly one feasible incoming arc/path). Then `D` has at least `n!` terminal nodes, at least `n!-1` internal comparison nodes, and at least `2n!-1` nodes / `2n!-2` edges in total. This is `2^{Θ(n log n)}`.
- `[paper argument]` For `n` distinct labelled keys there are `n!` possible input linear orders. In a deterministic comparison strategy, each input order induces a unique sequence of comparison outcomes along feasible arcs, hence a unique root-to-terminal path in any unshared tree representation. Soundness/completeness require every input order to be sorted correctly, so every input reaches some terminal whose guarantee is consistent with that execution. Distinct input orders cannot be certified as identical unresolved executions in a correct sorting strategy; in the unshared framed decision-tree case they correspond to distinct paths/terminals in the usual decision-tree accounting, giving `>= n!` terminals and `2n!-1` nodes for a full/reduced comparison tree. This matches explicit adaptive comparison trees and the repo's `DAG(1)=unshared(1)=2n!-1` observations for `n<=6` (`docs/research-strategy-certificates.md`, Thm 2.1/2.6, Obs 2.5; `docs/research-certificates-barriers.md` Claim C). *Model note:* this lower bound is for the **unshared tree** class, not for framed DAGs that exploit joins/intersection.

### F3. Framed DAG sharing / joins: polynomial-size certificates exist at non-optimal heights, so no universal superpolynomial lower bound follows from F2
- `[paper construction, repo; audit pending]` `docs/research-framed-certificate-frontier.md` §2: adaptive merge sort admits an all-`n` framed DAG with `O(n^2)` comparison nodes and `O(n log n)` path length (balanced merges), using slot permutations and joins of completed merge states; identity `sum pq = n(n-1)/2`.
- `[paper construction, repo; audit pending]` §3: rank-envelope joins give a plausible `O(n^2)`-query framed certificate for the standard Ford–Johnson upper bound `F_FJ(n)=sum_{j=1}^n ceil(log2(3j/4))`, subject to independent frame/boundary review.
- `[experiment/example, repo tool]` `scripts/check_framed_strategy.py --bubble N` produces/verifies a polynomial-size framed witness of depth `N(N-1)/2`.
- `[deduction]` Consequently, a general superpolynomial/exponential lower bound for **every** sound complete framed permutation certificate DAG (without restricting height/class) is false; joins and slot framing can compress the certificate far below `n!` nodes at some correct heights.

### F4. Optimal height `S(n)`: no proved polynomial-size family and no proved universal superpolynomial lower bound (open)
- `[open]` For height exactly `S(n)`, the repo docs state: "No such all-n polynomial-size completeness theorem is known" (`research-framed-certificate-frontier.md`), and membership in NP/coNP remains open (`research-plan.md`, `research-strategy-certificates.md`, `research-certificates-barriers.md`).
- `[deduction]` A polynomial-size, polynomial-time-checkable framed certificate family at height `S(n)` for all `n` would imply `SORT-BOUND-U ∈ NP` (repo frontier/checker claim). Therefore proving such a family is exactly an NP-certificate upper-bound route, not merely a representation trick.
- `[deduction]` Conversely, proving a superpolynomial lower bound on total nodes/edges for **every** sound complete framed DAG at height `S(n)` would rule out this specific framed-certificate route to `SORT-BOUND-U ∈ NP`. It would **not** by itself prove `SORT-BOUND-U ∉ NP` in general, and it would **not** prove any complexity-class separation.

### F5. Why known polynomial framed constructions fail at optimal height (exact obstruction)
- `[paper deduction, repo]` Merge-sort framed DAG is polynomial but has comparison deficit at exact optimum for large powers of two: independent complete sorting of equal halves followed by optimal equal-chain merge uses `n log2(n)-n+1` comparisons, exceeding `log2(n!)` by `(log2(e)-1)n + O(log n)`; Sergeev gives `S(n)=log2(n!)+o(n)` (`research-framed-certificate-frontier.md` §2, citing Sergeev). DAG sharing cannot repair a comparison-count deficit of the architecture.
- `[paper deduction, repo; audit pending]` Ford–Johnson rank-envelope embedding targets `F_FJ(n)`, which is an upper bound and not equal to `S(n)` for every `n`; exact recursive frame/boundary accounting remains to be independently audited (`§3`).
- `[open][barrier context]` Sergeev's near-optimal group-insertion construction stores pending keys in coupled interval containers. A polynomial-state framed rank-envelope/nested-subroutine grammar with sound joins and `o(n)` surplus is unspecified; short local insertion routines do not automatically yield polynomial global control states (`§5.2`). The winning-frontier barrier shows `2^{(1/4-o(1)) n log^2 n}` nonisomorphic winning states at one depth including budget `S(n)` (`docs/research-winning-frontier-barrier.md`), so any polynomial framed certificate at optimal height must avoid explicit enumeration of winning states/transcripts and exploit a stronger global invariant/frame than raw state enumeration (`[deduction]`, compatibility constraint, not a DAG-size proof).

### F6. Framed vs unframed / quotient distinction
- `[deduction]` **Unframed labelled-poset/strategy DAGs** (nodes = labelled posets/states, hash-consed) can share identical states but a single optimal policy may still be a tree: `DAG(1)=2n!-1` for `n<=6` (`research-strategy-certificates.md`). `S_n`-quotient can compress representatives but quotient certificate size/count at optimal height is open (`§3, §6` there).
- `[deduction]` **Framed permutation certificates** track slot permutations and guaranteed relations over slots, enabling joins across histories whose slot guarantees intersect to a reusable invariant (e.g. merge prefix + two ordered queues). This is a different compression mechanism than labelled-poset identity/quotient and is the reason F3 is possible while F2 holds for unshared trees.
- `[deduction]` Completeness at optimal height requires both (i) height `S(n)` and (ii) a sound, complete, explicitly checkable framed DAG for all `n`. Known constructions satisfy fragments (poly size at larger height, or near-optimal comparison counts without proved poly framed global states), but no construction is known to satisfy all requirements simultaneously.

## Answer to posed alternatives
- **(a) Superpolynomial/exponential lower bound for every sound complete framed permutation certificate/DAG certifying `S(n)<=k`?** **No such general all-`n` lower bound is proved here, and none is currently justified by repo evidence for the unrestricted framed-DAG class.** For the clearly stated natural class of **unshared framed decision trees** (no joins), size is `>= 2n!-1 = 2^{Θ(n log n)}` for all `n>=1` (F2). For join-enabled framed DAGs, polynomial-size certificates exist at non-optimal heights (F3), so only height-restricted/optimal-height lower bounds remain meaningful.
- **(b) Polynomial-size framed DAG/certificate family for all `n` at height `S(n)`?** **Not constructed/exhibited.** Open (F4).
- **Obstruction:** known polynomial framed families are either too tall (merge sort) or not proved exact/fully framed at all `n` (Ford–Johnson embedding), while near-optimal Sergeev strategies lack a proved polynomial global framed state/join grammar; winning-frontier state explosion bars raw state enumeration at budget `S(n)` (F5).

## Falsifiers
- A concrete all-`n` polynomial-size sound complete framed DAG family with longest path `<= S(n)` (or `<= k` at the exact threshold) and a verifier-checked encoding would falsify any purported universal superpolynomial lower bound for optimal-height framed certificates and would establish the NP-certificate route for `SORT-BOUND-U`.
- A concrete infinite family `n_i` and a proof that every sound complete framed certificate of height `<= S(n_i)` has `>= n_i^{ω(1)}` (or `2^{Ω(n_i log n_i)}` etc.) nodes/edges would establish a superpolynomial optimal-height lower bound for that class and rule out framed-certificate NP membership via that representation.

## Bottom line
The strongest provable all-`n` lower bound identified here is **class-dependent**: `Ω(n log n)` path length for every sound certificate, and `2n!-1 = 2^{Θ(n log n)}` nodes for every **unshared framed decision tree**. For **join-enabled framed DAG certificates at optimal height `S(n)`**, neither a polynomial-size all-`n` construction nor a superpolynomial all-`n` node/edge lower bound is established; the exact obstruction is the lack of a globally polynomial, sound joinable framed state grammar for an `S(n)`-height (Sergeev-compatible/optimal) strategy.
