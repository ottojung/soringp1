## Single minimal failing lemma/proof gap

> **[open:CKS-AV-MDALT-HALT] (complete well-founded halting/progress proof for `δ_{M_D^alt}^{sch}`).**  
> Theorem 5.2 claims that on every well-formed input `w=1^n # 1^k` and every `I_{M_D}`-reachable configuration, `δ_{M_D^alt}^{sch}` reaches `HaltAcc` or `HaltRej` in finitely many steps, using `μ(E(Rbar))=(Brem,Sphase,Cphase) ∈ ω×ω×ω`. As written this is not a discharged proof because:
> 1. **`Brem` is not well-defined as a global component.** It is described as `k - val(UsedF of active DFS budget frontier)`. The current top frame need not be the budget-consuming frontier in the intended sense across all modes: after an existential push `D_sort_pick/D_backE_rej_next`, the parent becomes `M_BackE` with unchanged `UsedF` while the child becomes `CtrlAdv/M_Eval`; after `D_adv_push_A0`/`D_backA0_acc_A1`, the pushed child has `SuccCtr(used_parent)`. The proof states “every A0/A1 push ... decreases `Brem` for the pushed child”, but `μ` is assigned to the whole encoded configuration, not to the pushed child alone. A complete proof must define the relevant measure on the whole active DFS configuration (e.g. a finite multiset/vector over the bounded active stack path, or a lexicographic ranking by remaining universal-comparison potential and backtrack obligations).
> 2. **`Sphase` is not a single explicit finite component for all top modes.** It is described as “a finite tuple combining (active stack depth profile bounded by `2k+1`) and, for the current top existential search frame, the lex position of `CurA,CurB` in `Key×Key`”. When the top is `M_Eval/CtrlAdv`, `M_BackA0`, or `M_BackA1`, the “current top existential search frame” is generally a lower waiting frame, not the top; when several `M_BackE` frames may exist in the broader design, the relevant cursor is not globally unique from the informal description. The proof must specify which cursor(s)/depth obligations are ranked in each control mode.
> 3. **`Cphase` is not fully specified.** It is given as “a fixed finite phase order on `(M_Eval/M_BackE/M_BackA0/M_BackA1, RetNone/RetAcc/RetRej, root/non-root terminal disposition)` ensuring ...” without the complete order and without a case-by-case check that each non-halting macro-case strictly decreases `(Brem,Sphase,Cphase)` lexicographically while preserving `I_{M_D}`.
>
> **Required discharge.** Give an explicit well-founded measure `μ` on `I_{M_D}`-reachable encoded configurations (or an equivalent finite-descent argument over the fixed finite control alphabet plus bounded counters/stack state) and prove, for every `D_*` non-halting macro-case in §3.2, that if `I_{M_D}(Rbar)`, `¬HaltAcc∧¬HaltRej`, and `E(Rbar)--δ_{M_D^alt}^{sch}-->E(Rbar')`, then `μ(E(Rbar')) < μ(E(Rbar))`. The argument may use: `UsedF` ranges over `Ctr` of size `k+1`; only `PushChildA` (A0/A1) applies `SuccCtr`; `PushChildE` copies `UsedF`; `NextIncomp_c`/`SuccLex2` advance monotonically over finite `Key×Key`; `I_{M_D}` gives unique top/parent/cursor/mode/ret coherence; BackA0+RetAcc produces A1 from the same parent snapshot and BackA1 returns; return-pop removes the top frame and consumes `RetAcc/RetRej`; budget-exhausted/non-total and exhausted existential search take reject/halt/exhaust cases rather than pushes. The measure/proof must not rely on A001035/`PACK-REPR` or on hidden DFS semantics.

This is a proof-level gap in Theorem 5.2 only. It does not identify a contradictory transition in `δ_{M_D^alt}^{sch}`, and it does not reopen the SYM/SYM-TOP symbol-level case split or PACK/PACK-REACH normal forms except insofar as the final “halts and decides” consequence is not fully proved.
