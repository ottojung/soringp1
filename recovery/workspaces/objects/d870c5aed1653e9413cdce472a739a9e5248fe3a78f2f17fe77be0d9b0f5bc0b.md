# Exec report: FO(TC) / fixed-point strategy programs for `SORT-BOUND-U`

**Issue context:** `JTsW4AnxTLzN18IBQibXea-fervor` (descriptive-complexity / strategy-program angle).  
**Scope:** paper-level analysis only. No repository-wide edits, no Lean, no PR/comments.

## Falsifiable question

Can exact optimal, or exact-threshold-deciding, sorting strategies for `S(n)` / `SORT-BOUND-U` be expressed or compiled as FO(TC) (or related fixed-point logic) *strategy programs* over an appropriate ordered finite structure, yielding an explicit definability/upper-bound result; or is there a precise obstruction (alternation, strategy dependence, reachability-vs-universality) preventing this?

## Definitions and encoding (model fidelity)

- **Language (unary, active).** `SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }` over alphabet `{1,#}`. Input length is `N = n + k + 1` (`docs/problem.md`). Resources are measured in `N`.
- **Sorting model.** `S(n)` is the minimax height of deterministic adaptive comparison decision trees correctly sorting `n` distinct labelled keys (all permutations possible at root). Threshold truth means: there exists a prover/comparison strategy such that for every adversary-consistent outcome sequence of length `<= k`, the induced partial order becomes total (`docs/problem.md`, `S_eq_adv_univ` correspondence noted in `docs/research-plan.md`).
- **Ordered structure for the input.** A canonical choice is the word structure
  \[
  \mathcal{A}_{n,k} = (\{0,\ldots,N-1\}, <, U, H)
  \]
  where `<` is the standard linear order on positions, `U(i)` means position `i` carries `1`, and `H(i)` means position `i` is `#`. From `<,U,H` FO can define the segments of lengths `n` and `k` and arithmetic predicates needed on an ordered domain of size `N`.
- **State/game structure (for “strategy over states”).** A comparison state can be represented as `(P,b)` where `P ⊆ [n]^2` is (the transitive reduction/closure encoding of) a strict partial order consistent with some linear extension and `b <= k` is remaining budget. A faithful finite structure for states is `\mathcal{S}_{n,k}` with universe encoding elements/positions `1..n` and budget `0..k` (polynomial in `N` for representing one state/value tuple, but the reachable state *space* is exponential in numeric `n`), equipped with `<` and relations `Prec_P(x,y)`, `Budget(b)`, etc. A move is an incomparable pair `(x,y)`; outcomes extend `P` by `x<y` or `y<x` if consistent.
- **“Strategy program” (precise reading used here).** A *uniform strategy program* for the threshold game is an FO(TC), FO(LFP), or FO(PFP) formula/program over an appropriate ordered structure that defines, from the encoded input (and, if state-based, the current encoded state), either (a) a next comparison `(x,y)` as a definable function/relation, or (b) the Boolean value `Win(n,k)` = “`S(n) <= k`”. On ordered finite structures, by Immerman–Vardi/Sazonov–Vardi correspondences, FO(TC) corresponds to NL, FO(LFP) to P, and FO(PFP) to PSPACE (literature; standard descriptive complexity). This is the relevant “definability/upper-bound” sense for `SORT-BOUND-U`.

## Claim

**Claim (deduction/literature + obstruction, not kernel-checked).**
1. **FO(PFP) upper bound (definability in principle):** because `SORT-BOUND-U ∈ PSPACE` is established (`docs/problem.md`, `docs/research-plan.md`), the capture of PSPACE by FO(PFP) on ordered finite structures implies there exists an FO(PFP) sentence over `\mathcal{A}_{n,k}` defining `SORT-BOUND-U`. However, `docs/research-plan.md` correctly notes that building and validating an explicit formula is separate work; a compact informal recursion is not by itself an FO(LFP)/smaller-class definition.
2. **FO(TC) strategy programs do not yield an exact all-`n` threshold/optimal strategy by reachability alone (precise obstruction):** the exact predicate has the natural alternating form
   \[
   Win(P,b) \iff (b=0 \land Total(P)) \lor \exists (x,y)\,Move(P,x,y)\,\forall o\in\{<,>\}\,(Cons(P,x,y,o)\rightarrow Win(P\cup\{(x,y,o)\}^*, b-1)).
   \]
   The outer quantifier is prover choice but the inner quantifier ranges over *all* adversary-consistent outcomes; correctness requires universality/strategy dependence on the adversary branch, not mere existence of a path. FO(TC) expresses transitive closure / reachability (NL on ordered structures), which captures existential path properties, but does not capture this universal branching game semantics. Therefore an FO(TC) “follow some path” policy is insufficient as a proof of `S(n) <= k`; a sound proof-carrying compilation would additionally need a polynomially checkable witness that every adversary outcome stays within budget (cf. `docs/research-frontier.json` note: execution alone does not give NP/worst-case depth proof).
3. **No new upper bound obtained:** absent a proof that the minimax alternation collapses to FO(TC)/FO(LFP)/ESO-definable form for the antichain-root family `S(n)`, this route gives no membership in NL, P, or NP and no improved evaluator. This is consistent with the project barriers (exponentially many states/strategies, no succinct certificate known, sparsity blocks many-one hardness arguments but does not help membership).

## Construction/argument sketch

- **Why alternation is essential (deduction).** A comparison strategy is winning at budget `k` iff *every* root-consistent permutation follows some root-to-leaf path of length `<= k` in that strategy. Equivalently in state form, after each chosen comparison both feasible outcomes must remain winning with budget `k-1`. Any logic/compiler that only certifies an FO(TC)-definable next-move rule on a single observed outcome sequence establishes per-run behavior, not the universal worst case over the adversary. Hence “FO(TC)-expressible policy” ≠ “FO(TC)-definable proof that height `<= k`”.
- **Why FO(PFP) is the matching descriptive class given current knowledge (literature/deduction).** `SORT-BOUND-U ∈ PSPACE` (budgeted DFS / alternating polynomial-space characterization, `docs/research-budgeted-dfs.md`, `docs/research-certificates-barriers.md`) places the language in the class captured by FO(PFP) on ordered inputs. This yields existence of a defining fixed-point formula in principle but does not by itself produce an explicit, audited formula or any smaller-class collapse.
- **Relation to framed certificates.** A polynomial-size permutation-framed DAG with local soundness and a polynomial-time verifier would be an NP/explicit-certificate object (`docs/research-framed-certificate-frontier.md`), but optimal-size all-`n` completeness is open. Such a DAG is a different artifact from an FO(TC) formula over the length-`N` input structure; compiling an optimal strategy into either form remains open.

## Falsification attempts / what would change the claim

1. **Would falsify obstruction (major result):** exhibit, for all `n,k` with `N=n+k+1`, an explicit FO(TC) (or FO(LFP)) formula/program over `\mathcal{A}_{n,k}` or a polynomial-size ordered state structure that defines `Win(n,k)` and is proven equivalent to `S(n)<=k`, with a correspondence argument to adaptive comparison sorting. By capture theorems this would imply `SORT-BOUND-U ∈ NL` (or `∈ P`), a genuine upper-bound breakthrough.
2. **ESO/NP route:** give a uniform existential second-order definition (or equivalently a polynomial-size, polynomial-time-checkable witness schema) complete at exact budget `S(n)` for all `n`. Would imply `SORT-BOUND-U ∈ NP`.
3. **Weaker but useful:** a sound, complete, polynomially checkable “proof-carrying” normal form for some restricted FO(TC)-described policy class, with an explicit argument that it covers optimal root strategies for all `n` (currently unsupported; frontier open).
4. **Sanity check against known values:** any proposed explicit strategy program must reproduce known exact thresholds (`S(1)..S(12)` table in `docs/research-plan.md`, literature values) and respect `N=n+k+1` resource accounting; failure is a direct refutation of that proposal.

## Consequence for the project

- **Consequence:** the FO(TC)-strategy-program question, as stated, runs into a structural **alternation/strategy-dependence obstruction** rather than a direct reachability compilation: proving worst-case budget requires certifying all adversary-consistent branches. No explicit FO(TC) (or stronger-but-below-PFP) definability/upper bound for exact `SORT-BOUND-U` is currently justified.
- **Consistent frontier:** (i) make the FO(PFP) definition explicit (separate, nontrivial formalization task; expected given PSPACE but not automatic), (ii) pursue succinct certificates/ESO-NP completeness at exact `S(n)` (open, per framed-certificate frontier), or (iii) prove a barrier showing optimal strategies are not definable in a given weaker logic/program class on the relevant structures. Any of these must state consequences for evaluating `S(n)` and include a falsification attempt.

- **Deduction (from established project results):** FO(PFP) definability in principle from `SORT-BOUND-U ∈ PSPACE`; alternation/universal-adversary obstruction to reachability-only FO(TC) strategy certification.
