# Proof attempt — Lemma A split on a single optimal branch

**Status:** attempt only; no all-`n` theorem obtained. Finite check `n<=7`
(summary.md) found no counterexample, but does not prove the statement.

## Statement

Let `P` be a finite poset and `m = m(P)` its exact minimax sorting depth
(`m = 0` iff `P` is a total order). For an incomparable pair `(a,b)` write
`P^{a<b}`, `P^{b<a}` for the two children. The question is whether there is an
**optimal** comparison, i.e. one with

    max(m(P^{a<b}), m(P^{b<a})) = m - 1,

such that additionally

    min(m(P^{a<b}), m(P^{b<a})) >= m - 2.

Equivalently, among the comparisons achieving the minimum in the minimax
recurrence, one has child depths `{m-2, m-1}` (never `{<=m-3, m-1}`).

## Easy facts

1. For any comparison, `m <= 1 + max(child depths)`, so **some** comparison has
   `max = m-1` (that is what optimal means). This is by definition of the
   minimax recurrence.
2. If a comparison has `max = m-1`, then the worse child has depth exactly
   `m-1`. Hence the only nontrivial content is the lower bound on the better
   child.
3. Monotonicity: if `P ⊆ Q` (Q has all relations of P and possibly more), then
   `m(Q) <= m(P)`. Adding a known comparison can only help the sorter.

## Natural attempt: push a grandchild comparison to the root

Let `(a,b)` be an optimal root of an optimal strategy tree for `P`. Let

    D = P^{a<b},  S = P^{b<a},  m(D) = m-1,  m(S) = s <= m-1.

If `s >= m-2`, we are done. Assume the split is unbalanced: `s <= m-3`.

Take the root `(c,d)` of the deep child `D` in the same optimal tree. It is
legal in `P` (it is incomparable in `D`, hence in `P`). Let
`D1 = D^{c<d}`, `D2 = D^{d<c}`; since the tree is optimal for `D`,
`max(m(D1), m(D2)) = m-2` and both are `<= m-2`.

Now compare `(c,d)` first in `P`.

*Upper bounds.* With `S1 = S^{c<d}`, we have `S ⊆ S1`?? No: `S1 = P^{b<a,c<d}`
extends `S` by `c<d`, so `m(S1) <= s <= m-3`. Also `m(D1) <= m-2`. From
`P^{c<d}`, compare `(a,b)`: the `a<b` branch lands in `D1` (depth `<= m-2`) and
the `b<a` branch lands in `S1` (depth `<= m-3`). Hence

    m(P^{c<d}) <= 1 + max(m-2, m-3) = m-1,

and symmetrically `m(P^{d<c}) <= m-1`. So `(c,d)` **is** an optimal comparison
for `P` (its max is exactly `m-1`, since `m` is the minimum).

*Lower bounds.* Since `P^{a<b,c<d} = D1` is more constrained than `P^{c<d}`,
monotonicity gives `m(P^{c<d}) >= m(D1)`, and similarly for the other side.

## Precise obstruction

The lower bounds above are only `m(D1), m(D2) >= m-3` in general (an optimal
comparison inside `D` of depth `m-1` guarantees only that the **larger** child
has depth `m-2`; the other may be `m-3`). After pushing `(c,d)` to the root of
`P` we therefore know

    m(P^{c<d}), m(P^{d<c}) in [m-3, m-1],   max = m-1.

This yields an optimal comparison whose better child is `>= m-3`, which is
**one step short** of the required `>= m-2`. Equivalently, the construction can
produce child depths `{m-1, m-3}` (unbalanced) rather than `{m-1, m-2}`.

Trying to close the gap by induction fails for the same reason: applying the
desired statement to `D` (depth `m-1`) gives a comparison whose children in `D`
have depths `{m-2, m-3}`, and after pushing up the weaker side still has only
the lower bound `m-3`. To make the induction close one would need the stronger
auxiliary statement

    every `P` with `m(P) >= 2` has an optimal comparison whose two children
    BOTH have depth exactly `m(P)-1`,

which is false already at small `m` (e.g. at `m=2` the children of an optimal
comparison are `{1,0}`), or some other way to rule out the `{m-1, m-3}` case.

## What the finite data says

For `n<=7` every poset with `m>=2` has an optimal comparison with child depths
`{m-2, m-1}` or `{m-1, m-1}`; no `{m-1, <=m-3}` case occurs. For `n<=6` the
best achievable `min(child depths)` among optimal comparisons was always
`m-2` or `m-1`. This is evidence against a small counterexample, but gives no
all-`n` implication. In particular, the threshold induction in
`research-core-threshold.md` only needs the weaker statement "some comparison
has both children `>= m-2`"; that weaker statement would already be implied by
the property tested here, so a search for a counterexample to the stronger
version is a sound way to probe it.

## Next decisive step

Search `n=8` (or structurally constrained infinite families) for a poset whose
every optimal first comparison is `{m-1, m-3}`. The push-to-root argument shows
any such counterexample must have the following property: for the deep child
`D` of every optimal root, every optimal comparison of `D` that can be pushed
up is itself unbalanced ` {m-2, m-3} ` in `D`. That is a concrete finite
structure to look for, and is where a proof would have to break down.
