## Question

For the unary threshold language
`SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }`,
does its complement
`coSORT-U = { 1^n # 1^k : S(n) > k }`
admit polynomial-size (in `N = n+k+1`), polynomial-time verifiable certificates for all `n,k`? Equivalently, is there a succinct, statically checkable adversary/refutation object proving that no adaptive comparison strategy of height `<= k` sorts the `n`-element antichain, placing `SORT-BOUND-U` in `coNP`?

**Consequence if yes (would-be, not established):** `SORT-BOUND-U ∈ coNP`, a genuine uniform upper-bound classification below `PSPACE` for the unary threshold language, dual in form to the open NP/framed-DAG YES-certificate question.

## Definitions

**[definition] Input and language.** Fix `n >= 0`, `k >= 0`. Let
`S(n)` be the minimum worst-case height of a deterministic adaptive comparison decision tree that correctly sorts every permutation of `n` distinct labelled keys (`docs/problem.md`). A valid unary instance is
`x = 1^n # 1^k` with input length `N = |x| = n + k + 1`.
`x ∈ SORT-BOUND-U ⇔ S(n) <= k`.
`x ∈ coSORT-U ⇔ S(n) > k`.
Malformed strings are outside the languages by convention; well-formedness is checkable in `O(N)`.

**[definition] Static certificate / verifier (coNP form).** `coSORT-U ∈ coNP` iff there exist a polynomial `p` and a deterministic polynomial-time Turing machine `V` such that for every valid input `x`,
`x ∈ coSORT-U ⇔ ∃w ∈ {0,1}^*, |w| <= p(|x|) ∧ V(x,w)=1`.
Soundness: if `V(x,w)=1` then `S(n)>k`. Completeness (all-`n`): if `S(n)>k` then some such `w` exists. Verification time/space are measured in `N`.

**[definition] Game characterization.** Let `G(n,k)` be the finite perfect-information game (`docs/research-certificates-barriers.md`, Claim A form): state is a transitively closed partial order `P` on `[n]`, initial state is the antichain `A_n`; while `P` is not total and fewer than `k` comparisons have been made, the sorter chooses an incomparable pair and the adversary chooses one of its two orientations; `P` becomes the transitive closure. Sorter wins iff a total order is reached within `k` comparisons. Then
`[deduction] S(n) <= k ⇔` sorter has a winning strategy in `G(n,k)`; by determinacy of finite games,
`S(n) > k ⇔` adversary has a winning strategy in `G(n,k)` (for every sorter strategy of length `<=k`, some consistent play ends in a non-total poset after `k` comparisons).

**[definition] What is *not* the same as a static certificate.**
- *Interactive protocols (IP/AM):* a prover and verifier exchange messages. `APTIME=PSPACE` and `IP=PSPACE` imply the underlying decision problem (and its complement) have interactive proofs in principle, but this is not a single static `w` checked by a deterministic poly-time verifier; it does not imply `coNP`.
- *Exponential explicit strategies/game trees:* an object whose size is `2^{Ω(N)}` (or `2^{Ω(n log n)}`) is not a polynomial-size certificate in `N`.
- *YES certificates (NP side):* a sound, poly-checkable explicit strategy/DAG witnessing `S(n)<=k` is the dual existential object; polynomial-size existence/completeness for all `n` at optimal budgets is open (`docs/research-framed-certificate-frontier.md`, `docs/research-strategy-certificates.md`).

## Baseline from repository (literature/deduction already recorded)

- **[literature]+[deduction]** `SORT-BOUND-U ∈ PSPACE` and `S_unary ∈ FPSPACE` via the alternating/game formulation and `APTIME=PSPACE` (`docs/research-certificates-barriers.md` Claim A; reflected in `docs/problem.md`). Since `PSPACE` is closed under complement, `coSORT-U ∈ PSPACE` as a decision problem, but this is not a `coNP` certificate result.
- **[deduction]+[experiment]** An explicit reduced sorting tree has `2·n!−1` nodes (`docs/research-certificates-barriers.md` Claim C, `docs/research-strategy-certificates.md`); for informative unary instances this is exponential in `N` and not a polynomial NO/YES certificate by itself.
- **[literature]+[deduction]** `SORT-BOUND-U` is sparse, so many-one NP-hardness or coNP-hardness of the unary language would imply `P=NP` (Mahaney/Fortune consequences; `docs/research-encoding-consequences.md`, `docs/research-hardness-boundaries.md`). Sparsity does **not** rule out membership in `NP` or `coNP`.
- **[deduction/open]** Neither `SORT-BOUND-U ∈ NP` nor `SORT-BOUND-U ∈ coNP` is known; no succinct certificate is known in either direction (`docs/problem.md`, `docs/research-plan.md`, certificates docs). The framed-certificate frontier studies YES-side DAGs; exact optimal-size completeness is open.

## Analysis

### 1. Sound, poly-checkable partial NO certificates exist (not complete)

**[paper proof, elementary] Information-theoretic certificate for the sub-information regime.**
*Certificate `w`:* the pair `(n,k)` (or empty beyond the instance). *Verifier:* check `k < ⌈log2(n!)⌉`.
*Soundness:* every comparison tree of height `k` has at most `2^k` leaves, while a correct sorter must distinguish all `n!` permutations, so `S(n) >= ⌈log2(n!)⌉ > k`.
*Checkability:* `n!` can be computed exactly by iterative integer multiplication in time polynomial in its bit-length `Θ(n log n) = O(N log N)` and compared with `2^k`; alternatively one can compare logs/bit-lengths by standard integer arithmetic, all polynomial in `N`.
*Completeness scope:* complete exactly for instances with `k < ⌈log2(n!)⌉` (in particular all instances where the information lower bound alone refutes budget `k`). It is **not** complete for the gap regime `⌈log2(n!)⌉ <= k < S(n)` (e.g. `n=12, k=29`, since `⌈log2(12!)⌉=29` and `S(12)=30` by literature), which any all-`n` coNP system must certify.

**[deduction] Trivial edge cases.** `k >= n(n-1)/2` is never in `coSORT-U` (insertion/selection-style upper bound gives `S(n) <= n(n-1)/2`); `n <= 1` gives `S(n)=0`. These do not provide NO certificates but delimit the informative window.

### 2. Explicit adversary-strategy objects are not succinct in general

**[deduction] Quantifier/shape obstacle for tree/DAG encodings of adversary play.** A winning strategy for the adversary in `G(n,k)` can be described as: for every sorter move at every reachable game position, prescribe an outcome such that after `k` plies no total order is reached regardless of sorter choices. In the extensive form, sorter nodes retain all legal comparison choices (universal over sorter moves) while adversary nodes may select one outcome per presented move; thus a fully explicit strategy object must, in general, branch over sorter choices at each level. The number of incomparable pairs at the antichain is `n(n-1)/2 = O(N^2)`, and while branches may merge by reaching identical posets, no argument is known showing that the adversary-winning frontier/strategy graph is polynomially bounded for all NO instances. This is the dual of the YES-side obstacle: a single optimal sorter policy is a tree of size `2n!−1` (`docs/research-strategy-certificates.md`), and the all-optimal/strategy union is not known to compress to polynomial size. A static coNP certificate would therefore need a representation fundamentally different from explicit game-tree enumeration.

**[deduction] Local reachable-poset hardness is insufficient.** Exhibiting a reachable poset `P` with remaining minimax value `F(P) > k-d` after `d` comparisons is a sound refutation of *that line of play* but not a root certificate unless one also proves the sorter is forced into `P` against some adversary strategy from `A_n`. This is the root-quantifier distinction noted in prior work (cf. `docs/research-frontier.json`: `quantified-root-adversary-proof` targets antichain-forcing invariants for numerical lower bounds, not a general per-instance coNP certificate family). Without a global forcing argument, local gadgets are not complete NO certificates for `(n,k)`.

### 3. Potential/invariant certificates: sound form, no known all-`n` poly-checkable system

**[paper proof] A sufficient invariant condition (certificate schema).** Suppose a witness supplies (a representation of) a function `Φ` on partial orders of `[n]` such that a verifier can check in polynomial time in `N` and `|Φ|`:
- (I1) `Φ(A_n) >= k+1` (or `>k` over integers),
- (I2) `Φ(T) <= 0` for every total order `T`,
- (I3) for every non-total poset `P` and every incomparable pair `{x,y}` in `P`, `max(Φ(tc(P∪{x<y})), Φ(tc(P∪{y<x}))) >= Φ(P)-1`.

Then `S(n)>k`.
*Proof:* by induction on depth `d<=k`, adversary can maintain a reachable state `P_d` after `d` comparisons with `Φ(P_d) >= Φ(A_n)-d >= k+1-d`. For `d=k`, `Φ(P_k)>=1`, so by (I2) `P_k` is not total. Hence no height-`k` sorter strategy wins. ∎

**[deduction] Barrier for this schema.** The schema is sound but only as useful as the checkability of (I2),(I3). Naively (I3) quantifies over posets and pairs (exponentially many); (I2) over total orders. To be a polynomial static certificate, `Φ` must be encoded so that these global properties follow from a polynomial-time proof/check (e.g. a compositional/inductive definition with local lemmas). No such `Φ` complete for all NO instances `(n,k)` is known. The information lower bound is the special case `Φ(P)=⌈log2 e(P)⌉` in effect? Not directly as a one-step invariant in this additive form except in ideal cases; and `e(P)` counting is `#P`-complete in general (`[literature]` Brightwell–Winkler), which obstructs one natural route to evaluating/comparing such potentials, though it does not by itself forbid a differently represented proof.

### 4. Distinction from sorting-network verification (important non-transfer)

**[literature]+[deduction]** Parberry's results show coNP-completeness/NP-completeness phenomena for verification/correctness of *arbitrary fixed comparator networks* (a given oblivious network: `∀` inputs correctness; a NO witness for correctness is a single bad input, which is succinct and poly-checkable for a fixed network). The present problem is different: `coSORT-U` asks whether *all* adaptive strategies of height `<=k` fail from the antichain root. A counterexample input to one particular strategy does not refute the existence of some other strategy unless lifted to a universal adversary argument. Therefore fixed-network counterexample certificates do not transfer to `coSORT-U`, and conversely no implication to/from Parberry's hardness is claimed.

### 5. Known gap-regime lower bounds and certificate size

**[literature]** Exact values with `S(n) > ⌈log2(n!)⌉` are known only in limited ranges (e.g. `S(12)=30`, `S(16)=46` etc.; `docs/literature.md`, OEIS A036604). Published determinations in/near the gap have relied on substantial search/case analysis (e.g. Stober–Weiß 2023 report large exhaustive bidirectional searches for `n=16,17,18`). **[deduction]** A completed exhaustive search transcript can be viewed as a proof object, but there is no known uniform argument that such objects compress to size polynomial in `N=n+k+1` for all `n,k`; treating them as evidence against succinctness would be an empirical/heuristic observation, not a theorem.

## Attempted refutation / falsification

- **Attempted construction (nontrivial family):** information-theoretic certificates were constructed and verified above for all instances with `k < ⌈log2(n!)⌉` (sound, complete on that subfamily). I found no construction extending to the full gap regime `⌈log2(n!)⌉ <= k < S(n)` for all `n`.
- **Attempted structural barrier proof:** no unconditional proof was found that every sound, complete certificate system for `coSORT-U` requires superpolynomial size. Such a proof would separate `coNP` from `PSPACE` on this language only in a very strong sense? Not directly as stated, but establishing `SORT-BOUND-U ∉ coNP` unconditionally is far beyond known methods here and would be a major separation claim; I do not claim it.
- **Concrete discriminant:** the first classical gap point in terms of need beyond pure counting is `n=12,k=29` (`S(12)=30 > 29 = ⌈log2(12!)⌉`), where the partial information-theoretic certificate fails; this is a concrete falsification point for any proposed all-`n` system that relies only on permutation-counting.

## Result

**Inconclusive (open).**

- No polynomial-size, polynomial-time verifiable static certificate family for `coSORT-U` (all `n,k`) was constructed.
- No theorem was proved placing `SORT-BOUND-U` in `coNP`, and no unconditional superpolynomial-size/refutation barrier was proved.
- A rigorous partial positive result holds: the complement is certified in polynomial time on the complete subfamily `k < ⌈log2(n!)⌉` by exact counting.

## Limits and what would change the picture

- This is not a separation result. A coNP upper bound remains consistent with known barriers recorded here (sparsity bars hardness, not membership).
- A decisive positive result would be an explicit certificate system with: (1) a precise object format, (2) a polynomial-time verifier, (3) a proof of soundness, and (4) a proof of completeness for all `n,k`, with size bounded by `poly(N)`.
- A decisive negative result for a *restricted* family would need a formal definition of that family and a superpolynomial lower bound or verification-hardness theorem for it (careful not to confuse with unconditional `SORT-BOUND-U ∉ coNP`).
- Any future claim must handle the gap regime where `⌈log2(n!)⌉ <= k < S(n)`; pure permutation counting is insufficient there.

## Exact implication for `S(n)` / `SORT-BOUND-U`

- **Established here:** no change to the known complexity classification. `SORT-BOUND-U` remains in `PSPACE`; membership in `NP`, `coNP`, or `P` remains open.
- **Hypothetical implication (not achieved):** a sound, complete, polynomial-size, polynomial-time verifiable adversary-certificate system for all `n,k` would imply `coSORT-U ∈ NP`, hence `SORT-BOUND-U ∈ coNP`.
- **No lower-bound/separation implication:** failure to find such a certificate here is not evidence of `SORT-BOUND-U ∉ coNP`.
