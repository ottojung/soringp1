# FO(PFP) formula for SORT-BOUND-U: structure, correctness, test, falsification

## FRONT: Explicit FO(PFP) formula (on ordered structures encoding poset/unary input)

### Input structure
For $w = 1^n \# 1^k \in \{1,\#\}^*$, let $\mathcal{A}_w = (D, <, P_1, P_\#)$ with $D=\{0,\ldots,N-1\}$, $N=n+k+1$, $<$ natural order, $P_1(x)\!\iff w_x='1'$, $P_\#(x)\!\iff w_x='#'$. Define
- $h = \min\{x : P_\#(x)\}$, $K = \{u\in D : P_1(u)\land u < h\}$ ($|K|=n$, keys), $B=\{v : P_1(v)\land h<v\}$ ($|B|=k$, budget markers).
- Budget levels $\beta(0),\ldots,\beta(k)$ ordered via $B\cup\{h\}$, FO-definable.

### Poset encoding
Let $R \subseteq D^2$ encode a strict partial order on $K$: $R(u,v)\implies u,v\in K, u\neq v$. 
- $\mathrm{Total}(R) \equiv \forall u,v\!\in K\,(u\neq v \to R(u,v)\lor R(v,u))$.
- $\mathrm{Incmp}_R(u,v)\equiv u,v\!\in K,u\neq v,\neg R(u,v),\neg R(v,u)$.
- $\mathrm{AddCl}(R,u,v;R')$: $R'$ is the transitive closure of $R \cup \{(u,v)\}$, definable by LFP/TC (positive).

### Game (correct by minimax / kernel-checked $S=\mathrm{adv\ univ}$)
Game $G(n,k)$: state = transitively closed poset $P$ on $n$ labeled elements (start empty). While $P$ not total and budget left: sorter picks incomparable pair $(\exists)$; adversary chooses direction $(\forall)$ extending $P$ (only allowed if incomparable; maintains consistency); update to closure, budget--. Sorter wins iff reach total order within $k$ comparisons. $S(n)\le k \iff$ sorter wins $G(n,k)$.

### FO(PFP) definition (explicit structure)
**Element-quantified game form (conceptual):** Let $W(R,b)$ be defined by PFP with positive operator
$$
\varphi(W,R,b)\equiv \mathrm{Total}(R)\lor \!\left(\exists b'\,\mathrm{Next}(b,b')\land \exists u,v\,\mathrm{Incmp}_R(u,v)\land \forall d\!\in\!\{L,R\}\,\exists R'\,\mathrm{AddDir}(R,u,v,d;R')\land W(R',b')\right),
$$
base/terminal cases as above. Issue: $W$ must be over domain elements/tuples (fixed arity), but $R$ is a relation parameter. 

**Correct full form (ATM/configuration encoding, standard):** Encode machine configurations $C$ as tuples $\bar c \in D^m$ (fixed arity, independent of $n,k$) representing $(q,\text{head positions},T)$ where tape relation $T \subseteq D^d\times\Sigma$ stores the poset matrix $R$ on $K^2$ (using $O(n^2)$ cells, addressed by tuples from $D^2$) plus input/workspace. Define $W(C,\tau)$ by PFP over positive $\varphi$ capturing alternating moves:
- if $R(C)$ total → accept (true).
- if no budget/level left → false.
- if existential state (sorter): $\exists C'\,(C\vdash_\exists C') \land W(C',\tau)$ where $C'$ results from picking some incomparable pair $(u,v)$ in $R(C)$.
- if universal state (adversary): $\forall C'\,(C\vdash_\forall C') \to W(C',\tau')$ with branches for both directions producing $R_1=\mathrm{Cl}(R\cup\{u<v\}), R_2=\mathrm{Cl}(R\cup\{v<u\})$ and $\tau'$ decreased.

Transitions $\vdash_\exists,\vdash_\forall$ are FO-definable. Budget/alternation tracked by elements of $B$ or encoded in configuration/iteration level. Let $C_{init}(n,k)$ be initial configuration (empty $R$, budget $k$, existential). Then $\exists$ fixed FO(PFP) sentence $\psi$ with $\mathcal{A}_{1^n\#1^k}\models \psi \iff \text{sorter wins }G(n,k)\iff S(n)\le k \iff 1^n\#1^k \in \text{SORT-BOUND-U}$.

### Correctness argument (mapping)
1. Game equivalence: $S(n)=\min_T \max_{\pi\in S_n}\text{depth}_T(\pi)=\mathrm{val}(G(n,\cdot))$ by minimax over poset lattice (established in repo; kernel-checked $S_{eq\_adv\_univ}$). ✓
2. ATM: $G(n,k)$ is decidable by alternating TM in time $O(k n^2)=O(N^3)$, space $O(n^2)=O(N^2)$, alternation depth $O(k)$ polynomial in unary $N=n+k+1$, so in $\mathrm{APTIME}$.
3. Descriptive capture: on ordered finite structures, $\mathrm{APTIME}=\mathrm{PSPACE}=\mathrm{FO}(\mathrm{PFP})$ (Grädel/Immerman). ✓
4. Encoding: standard TM/configuration encoding into tuples over ordered domain gives fixed-arity FO(PFP) formula. ✓

### Complexity/size sketch
- Input length $N=n+k+1$, domain $|D|=N$. Tape needs $O(n^2)$ cells → tuple arity $d\ge 2$ ($|D^d|\ge N^2$). Configuration tuples arity $m = d + O(1)$ fixed.
- Alternation depth $O(k)\le O(N)$; ATM time/space polynomial in $N$.
- Formula size fixed (independent of $n,k$), depends only on fixed game/TM. Data complexity PSPACE, matching $\text{SORT-BOUND-U}\in\text{PSPACE}$.
- Note: $n^2$ exponential in $\log n$ but the tuple encoding uses the domain elements to index polynomially many cells (up to $N^d$). The PFP reaches fixed point over all tuples in that space (size exponential in fixed $d\log N$, but the number of configurations is $\exp(O(N^2\log N))$ in naive counting? Or more tightly, with $O(N^2)$ tape cells over fixed alphabet and fixed states, total configurations ~ $|Q||\Gamma|^{O(N^2)}$ which is exponential in $N^2$; but we can only define relations over tuples of fixed arity over domain of size $N$ - total tuples of arity $m$ are $N^m$ polynomial in $N$ if $m$ fixed. That means we must encode the exponential configuration space using the relational/tuple encoding in a different way - or use larger tuple arity. For space $S(N)=O(N^2)$, we need address space $|D|^d \ge S(N)$ so $d\ge 2$ fixed; we encode tape as a relation $T \subseteq D^d \times \Sigma$ (arity $d+1$). The full configuration is described by $(q, \bar h, T)$ - still relations over tuples; the fixed point is over a relation of fixed arity that can represent "accepting" states in this relational encoding. The iteration count is bounded by the number of possible values of the defined relation: if defined over tuples of arity $p$, at most $N^p$ possible tuples total, so fixed point reached within $N^p + 1 \le \mathrm{poly}(N)$ iterations. That matches LFP/PFP data complexity giving polynomial iteration bound on the tuple space of fixed arity - which is exactly how we simulate polynomial-space computations on an $N$-sized domain: we use relations to represent the exponential structure.

## FALSIFIER: tests, collapse to FO(LFP)/P, soundness/compositionality

### Test on small $n/k$ (by game logic, matches known values)
- $(n,k)=(0,0)$ or $(1,*)$: $S(0)=S(1)=0 \le k$ for $k\ge0$ → accept. Base case total/empty trivial.
- $(n,k)=(2,0)$: $S(2)=1>0$ → reject. Budget 0, not total → false. ✓
- $(n,k)=(2,1)$: can win in 1 comparison → accept. ✓
- $(n,k)=(3,2)$: $S(3)=3>2$ → reject. ✓
- $(n,k)=(3,3)$: accept. ✓
- $(n,k)=(6,9)$: $S(6)=10>9$ → reject; $(6,10)$ → accept. All consistent with kernel-checked values.

### Does it collapse to FO(LFP)/P?
- FO(LFP)=P, FO(PFP)=PSPACE on ordered structures.
- Game is alternating $\exists\forall$ per round, polynomial depth, states = partial orders on $n$ elements (succinct). ATM simulation is correct.
- Barriers from repo/board:
  - $\text{SORT-BOUND-U}\in \text{PSPACE}$ established; showing $\notin P$ would imply $P\neq PSPACE$.
  - Sparse + P/poly closure arguments rule out many-one PSPACE-hardness under plausible assumptions ($\text{PSPACE}\nsubseteq \text{P/poly}$); also Mahaney-like constraints apply to unary (sparse).
  - Adversary has **global consistency constraints** (must keep relation a partial order extendible to a total order; moves only on incomparable pairs) - unlike free alternating games where adversary can assign arbitrarily. This restriction is structural to the poset model.
- However: the ATM encoding above still correctly models the restricted game (adversary choices are exactly orientations of incomparable pairs). The fixed-point is well-defined. Restriction does not obviously make it polynomial-time decidable. No proof of collapse to LFP exists; conversely no proof it’s outside P. The formula structure is the PFP/PSPACE one by construction - collapse to LFP would mean $P=\text{PSPACE}$ in general for this problem, which is not a theorem. So **the proposed structure does not obviously collapse to FO(LFP)/P; any such collapse would be a major complexity separation consequence, not an obvious identity of the formula.**

### Soundness/compositionality issues checked
- Transitive closure: adding direction to incomparable pair + closure is correct (preserves partial order, adds all consequences). ✓
- Adversary freedom: only incomparable pairs allowed; both directions allowed if incomparable (each extendible to some total order). This matches worst-case adversary. ✓
- Budget counting: must decrement once per full round $(\exists$ pair, $\forall$ branches resolve to next states$)$; off-by-one would be a bug in level tracking - but game definition is clear.
- Totality test: correct.
- Initial state empty order: correct.
- Encoding soundness: configuration must always represent a valid transited-closed poset; transitions enforce it. ✓
- Completeness of moves: sorter can choose any incomparable pair (existential). Correct (wants to win). ✓

### Potential subtlety (important)
The "global consistency constraint" on adversary is real. In some games this gives structure; it does **not** make the formula unsound. But it does mean this is not a free arbitrary alternating game - it's a game on the poset lattice with specific move rules. Whether this affects PSPACE-completeness is non-obvious. The descriptive complexity capture via ATM still applies to this specific alternating game.

## COMPLEXITY IMPLICATION
An explicit FO(PFP) definition on ordered structures for SORT-BOUND-U is exactly the descriptive-complexity witness for $\text{SORT-BOUND-U}\in\text{PSPACE}$ (uniform). This strengthens the capture claim. The formula structure is in PFP (not obviously LFP). Since $\text{SORT-BOUND-U}$ is sparse and in P/poly, many-one PSPACE-hardness is ruled out under $\text{PSPACE}\nsubseteq\text{P/poly}$ (board evidence), while Turing complexity remains open; the question of collapse to P is equivalent to $P=\text{PSPACE}$ here. So the formula structure clarifies the class placement but does not by itself rule out $P=\text{PSPACE}$ or force membership in smaller classes.
