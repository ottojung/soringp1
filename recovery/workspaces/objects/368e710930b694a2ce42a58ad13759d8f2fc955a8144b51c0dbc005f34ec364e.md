## 1. Fixed signature and address/cell space

`[definition]` Input word `w=1^n # 1^k`, `N=|w|=n+k+1`,
```text
A(w) = (W, <, One, Hash),   W={1,...,N}.
```
FO-definable over `A(w)`: `Succ, Min, Max, HashPos, WellFormed_w, Malformed,
Key, Ctr, Zero, MaxK, SuccCtr, HasBudget, KeyNe, Lex2`, and the key/counter
segments
```text
Key(x) <-> ∃h(HashPos(h) ∧ x < h),          |Key|=n,
Ctr(t) <-> ∃h(HashPos(h) ∧ (t=h ∨ h < t)),   |Ctr|=k+1,  Zero = hash.
```
`[definition]` Fix arity `r:=4` and set
```text
Cell := W^r,   |Cell|=N^r.
```
Lex order `<_lex` on `Cell`, `SuccCell(c̄,d̄)`, `ZeroCell(c̄)`,
`MaxCell(c̄)`, and fixed-constant offsets `AddF(c̄,d̄)` / `PredF(d̄,c̄)`
(FO successor-chain relations for each fixed frame-offset constant `F`) are
FO-definable from `<`.  The DFS evaluator uses polynomially many cells; fixed
`r>=4` gives a polynomial address margin on relevant `N`.  This is standard
PSPACE addressing `[literature]` and does not enumerate all `Pos` states
(`[falsification]` of A001035 tuple-naming).

For readability the formulas use record-like accessors `Field(base,...)`; these
are abbreviations for fixed-offset `Cell` addresses or, equivalently, for the
fixed-arity relations in §2.

## 2. Fixed-arity frame/configuration relations

`[definition]` The deterministic DFS evaluator state is a finite control plus a
stack of frames addressed by `Cell` bases.  We use a fixed finite family of
configuration relations (the standard simultaneous form; §7 states the normal-form
packing residual).  All arities are fixed, independent of `n,k`.

Global/stack relations:
```text
Top(c̄)                    arity r   : c̄ is the base of the current top frame
EmptyStack                  arity 0
HaltAcc, HaltRej            arity 0   : global halting control
```
Finite frame mode (disjoint, exactly one when a frame exists):
```text
M_Eval(c̄), M_BackE(c̄), M_BackA0(c̄), M_BackA1(c̄),
M_RetAcc(c̄), M_RetRej(c̄).
```
Frame-content relations (values in `W` / bits):
```text
CtrlSort(c̄), CtrlAdv(c̄), CtrlAcc(c̄), CtrlRej(c̄)      finite control tag
UsedF(c̄,t)                    used counter: exactly one Ctr value t
HasSel(c̄)                     selected pair is present
SelA(c̄,a), SelB(c̄,b)         selected Key pair (a,b), when HasSel
HasCur(c̄)                     existential cursor is present
CurA(c̄,a), CurB(c̄,b)         lex cursor (a,b) in Key×Key
PosF(c̄,u,v)                   current transitive-closure bit for Key pair (u,v)
Parent(c̄,p̄)                   stack link: p̄ is the frame below c̄ (optional if
                               offsets are used; either form is fixed-arity)
```
`[falsification]` There is **no** relation `NamePos(d̄,u,v)` meaning “tuple
`d̄` names a global poset having edge `(u,v)`” and no relation ranging over all
`A001035(n)` labelled posets.  `PosF(c̄,u,v)` stores only the current closure of
frame `c̄`.

Next-step versions are written `Top'(c̄), PosF'(c̄,u,v), ...` in the transition
schema; the PFP acceptance form instantiates the standard one-step operator on
these relations.

## 3. Initial configuration `Init_{M_D}`

`[definition]`
```text
Init_{M_D}(Top,EmptyStack,HaltAcc,HaltRej,M_*,Ctrl*,UsedF,HasSel,Sel*,HasCur,Cur*,PosF) :=
  WellFormed_w
  ∧ ¬HaltAcc ∧ ¬HaltRej ∧ ¬EmptyStack
  ∧ ∃c̄ (Top(c̄) ∧ ZeroCell(c̄)
         ∧ M_Eval(c̄)
         ∧ (∀d̄ (d̄!=c̄ -> ¬Top(d̄) ∧ ¬M_Eval(d̄) ∧ ¬M_BackE(d̄) ∧ ¬M_BackA0(d̄)
                        ∧ ¬M_BackA1(d̄) ∧ ¬M_RetAcc(d̄) ∧ ¬M_RetRej(d̄)))
         ∧ (TotalEmpty_n(c̄) -> CtrlAcc(c̄))
         ∧ (¬TotalEmpty_n(c̄) -> CtrlSort(c̄))
         ∧ ExactlyOneUsedF(c̄)
         ∧ ∃t(Zero(t) ∧ UsedF(c̄,t))
         ∧ ¬HasSel(c̄) ∧ ∀a¬SelA(c̄,a) ∧ ∀b¬SelB(c̄,b)
         ∧ HasCur(c̄) ∧ ∃a∃b(MinKey(a)∧MinKey(b)∧CurA(c̄,a)∧CurB(c̄,b))
         ∧ ∀u∀v ¬PosF(c̄,u,v)
         ∧ ∀d̄ (d̄!=c̄ -> FrameBlank(d̄))).
```
Here `TotalEmpty_n(c̄)` is FO (`¬∃x∃y KeyNe(x,y)` / `n<=1` consequence) and
`FrameBlank(d̄)` asserts no active frame content at non-initial addresses.
`[deduction]` **(2, ii initial).** `Init_{M_D}` encodes exactly the semantic
initial `N_G`/`G(n,k)` state: antichain `Pos`, `Used=Zero`, no selection,
`CtrlAcc` iff `n<=1` else `CtrlSort`.  The initial frame is at a fixed
FO-definable base `ZeroCell`.

## 4. Local move semantics on the current top frame

`[definition]` Let `c̄` be a frame base.  Abbreviate `P_c(u,v):=PosF(c̄,u,v)`.
```text
Incomp_c(x,y) := KeyNe(x,y) ∧ ¬P_c(x,y) ∧ ¬P_c(y,x).
Total_c       := ∀x∀y(KeyNe(x,y) -> P_c(x,y) ∨ P_c(y,x)).
Budget_c      := ∃t∃s(UsedF(c̄,t) ∧ SuccCtr(t,s)).
CfgAcc_c      := CtrlAcc(c̄) ∨ Total_c.
CfgRej_c      := CtrlRej(c̄).

StepPosBit_c(x,y;u,v) := P_c(u,v)
                      ∨ ((u=x ∨ P_c(u,x)) ∧ (v=y ∨ P_c(y,v))).

PostBudgetTag(P',Used',Acc,Sort,Rej) :=
   (Total(P') ∧ Acc ∧ ¬Sort ∧ ¬Rej)
 ∨ (¬Total(P') ∧ HasBudget(Used') ∧ Sort ∧ ¬Acc ∧ ¬Rej)
 ∨ (¬Total(P') ∧ ¬HasBudget(Used') ∧ Rej ∧ ¬Acc ∧ ¬Sort).
```
`[deduction]` **(ii local).** `StepPosBit_c` is FO in `u,v` with parameters
`x,y` and current `PosF`.  By the incremental transitive-closure lemma
(`[literature]` standard; prior CKS/AV artifact §3.3): if `P_c` is the closure of
a strict partial order and `Incomp_c(x,y)`, then `StepPosBit_c(x,y;·,·)` is the
closure of `P_c ∪ {(x,y)}` and is a strict partial order.

`[definition]` Local yield tests/child constructors (semantic content):
```text
YieldE_c(a,b) := CtrlSort(c̄) ∧ ¬Total_c ∧ Budget_c ∧ Incomp_c(a,b).
ChildE frame at d̄ from c̄,(a,b): PosF'(d̄,·,·)=P_c, UsedF'(d̄,·)=UsedF(c̄,·),
  HasSel'(d̄), Sel'(d̄)=(a,b), CtrlAdv'(d̄), HasCur'(d̄) at MinKey,MinKey.

YieldA0_c(a,b) := CtrlAdv(c̄) ∧ HasSel(c̄) ∧ SelA(c̄,a)∧SelB(c̄,b) ∧ Incomp_c(a,b).
ChildA0 frame at d̄: PosF'(d̄,u,v):=StepPosBit_c(a,b;u,v),
  UsedF'(d̄,·):=SuccCtr(UsedF(c̄,·)), no Sel, Ctrl/accept by PostBudget.

YieldA1_c analogously with StepPosBit_c(b,a;u,v).
```
`[deduction]` **(ii),(iii),(3) local.** These preserve/refine the semantic
`YieldE/YieldA0/YieldA1` of `M_G/G(n,k)`: existential move selects an
incomparable pair with budget and enters adversary phase preserving
`Pos/Used`; universal outcomes apply incremental closure, consume one
`SuccCtr`-budget step, clear selection, and resolve by `PostBudget`.  No
`G(n,k)` rule is altered.

## 5. Complete FO one-step transition `Δ_{M_D}`

`[definition]` `Δ_{M_D}(Conf;Conf')` is the disjunction of the mutually
exclusive deterministic cases below.  `Conf` abbreviates the current family of
§2 relations; `Conf'` their next-step versions.  `FrameEq'(d̄,c̄)` means all
frame-content relations at `d̄` in `Conf'` equal those at `c̄` in `Conf`.
`LowerStackEq'(c̄)` means every frame below top `c̄` is unchanged.

```text
Δ_{M_D}(Conf;Conf') := Δ_halt ∨ Δ_root_acc ∨ Δ_root_rej ∨ Δ_eval_acc_ret
  ∨ Δ_eval_rej_ret ∨ Δ_sort_pick_push ∨ Δ_sort_exhaust_rej
  ∨ Δ_backE_acc_ret ∨ Δ_backE_rej_next ∨ Δ_adv_push_A0
  ∨ Δ_backA0_rej_ret ∨ Δ_backA0_acc_push_A1 ∨ Δ_backA1_ret.
```

### 5.1 Halting and root returns

```text
Δ_halt :=
  (HaltAcc ∨ HaltRej) ∧ Conf'=Conf.

Δ_root_acc :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄ (Top(c̄) ∧ ZeroCell(c̄) ∧ M_Eval(c̄) ∧ CfgAcc_c)
  ∧ HaltAcc' ∧ ¬HaltRej' ∧ EmptyStack' ∧ NoActiveFrames'.

Δ_root_rej :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄ (Top(c̄) ∧ ZeroCell(c̄) ∧ M_Eval(c̄)
      ∧ (CfgRej_c ∨ (CtrlSort(c̄)∧¬Total_c∧¬Budget_c) ∨ NoNextIncomp_c))
  ∧ HaltRej' ∧ ¬HaltAcc' ∧ EmptyStack' ∧ NoActiveFrames'.
```
`NoNextIncomp_c` means `HasCur(c̄)` and no lex pair at/after the cursor is
incomparable:
```text
NoNextIncomp_c := ∃a∃b(CurA(c̄,a)∧CurB(c̄,b)
                  ∧ ¬∃x∃y(Lex2(a,b,x,y) ∧ Incomp_c(x,y))).
```

### 5.2 Non-root accept/reject returns (pop)

```text
Δ_eval_acc_ret :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄∃p̄ (Top(c̄) ∧ ¬ZeroCell(c̄) ∧ M_Eval(c̄) ∧ CfgAcc_c
      ∧ ParentOf(c̄,p̄))
  ∧ PopTo(p̄) ∧ ReturnAccTo(p̄).

Δ_eval_rej_ret :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄∃p̄ (Top(c̄) ∧ ¬ZeroCell(c̄) ∧ M_Eval(c̄)
      ∧ (CfgRej_c ∨ (CtrlSort(c̄)∧¬Total_c∧¬Budget_c) ∨ NoNextIncomp_c)
      ∧ ParentOf(c̄,p̄))
  ∧ PopTo(p̄) ∧ ReturnRejTo(p̄).
```
`ParentOf(c̄,p̄)` is `Parent(c̄,p̄)` or the fixed predecessor-offset relation.
`PopTo(p̄)` sets `Top'(p̄)`, clears frame `c̄`, and leaves lower stack unchanged.
`ReturnAccTo(p̄)` / `ReturnRejTo(p̄)` set the parent mode/result as determined
by the parent's current mode:
```text
ReturnAccTo(p̄): parent M_BackE -> M_RetAcc; M_BackA0 -> M_BackA0 (record A0
  accepted, used by Δ_backA0_acc_push_A1); M_BackA1 -> M_RetAcc.
ReturnRejTo(p̄): parent M_BackE -> M_BackE (continue search); M_BackA0 -> M_RetRej;
  M_BackA1 -> M_RetRej.
```
(Equivalently, the return marker may be encoded as `M_RetAcc/M_RetRej` on the
popped child and consumed by the parent case in the next step; both are fixed
finite deterministic encodings.  The chosen encoding is the one made explicit by
the final symbol-level normal form; §6 proves the discipline.)

### 5.3 Existential sorter: lex cursor, push `ChildE`, backtrack

```text
NextIncomp_c(a,b;x,y) :=
  Lex2(a,b,x,y) ∧ Incomp_c(x,y)
  ∧ ¬∃u∃v(Lex2(a,b,u,v) ∧ Lex2(u,v,x,y) ∧ Incomp_c(u,v)).

AdvanceCurAfter(x,y;x',y') := SuccLex2(x,y,x',y') ∨ (IsLastLex2(x,y) ∧ x'=x ∧ y'=y).
  (SuccLex2 is FO on the linearly ordered Key segment; last-pair is FO.)

Δ_sort_pick_push :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄∃a∃b∃x∃y (Top(c̄) ∧ M_Eval(c̄) ∧ CtrlSort(c̄)
      ∧ ¬Total_c ∧ Budget_c ∧ CurA(c̄,a)∧CurB(c̄,b)
      ∧ NextIncomp_c(a,b;x,y))
  ∧ ∃d̄ (FreshChild(d̄,c̄)
         ∧ PushChildE(d̄,c̄,x,y)
         ∧ SetParentBackE(c̄,x,y)   -- parent stays/records M_BackE, cursor advanced
         ∧ Top'(d̄) ∧ LowerStackEq'(c̄)).

PushChildE(d̄,c̄,x,y) :=
  M_Eval'(d̄) ∧ CtrlAdv'(d̄)
  ∧ (∀u∀v (PosF'(d̄,u,v) <-> PosF(c̄,u,v)))
  ∧ (∀t (UsedF'(d̄,t) <-> UsedF(c̄,t)))
  ∧ HasSel'(d̄) ∧ SelA'(d̄,x) ∧ SelB'(d̄,y)
  ∧ HasCur'(d̄) ∧ MinKeyCur'(d̄)
  ∧ ¬M_BackE'(d̄) ∧ ¬M_BackA0'(d̄) ∧ ¬M_BackA1'(d̄) ∧ ¬M_RetAcc'(d̄) ∧ ¬M_RetRej'(d̄).

Δ_sort_exhaust_rej := special case covered by Δ_root_rej / Δ_eval_rej_ret via
  NoNextIncomp_c.

Δ_backE_acc_ret :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄ (Top(c̄) ∧ M_RetAcc(c̄) ∧ BackEMarker(c̄))
  ∧ (Root(c̄) ? Δ_root_acc effect : PopReturnAccToParent(c̄)).

Δ_backE_rej_next :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄ (Top(c̄) ∧ M_RetRej(c̄) ∧ BackEMarker(c̄)
      ∧ CtrlSort(c̄))
  ∧ ResumeSortSearch'(c̄)  -- continue from advanced cursor as Δ_sort_pick_push
                            -- or reject if exhausted.
```

### 5.4 Universal adversary: push `A0`, sequence `A0 -> A1`, return

```text
Δ_adv_push_A0 :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄∃a∃b (Top(c̄) ∧ M_Eval(c̄) ∧ CtrlAdv(c̄)
      ∧ HasSel(c̄) ∧ SelA(c̄,a)∧SelB(c̄,b) ∧ Incomp_c(a,b))
  ∧ ∃d̄ (FreshChild(d̄,c̄) ∧ PushChildA(d̄,c̄,a,b,0) ∧ SetParentBackA0(c̄) ∧ Top'(d̄)).

PushChildA(d̄,c̄,a,b,side) :=
  M_Eval'(d̄)
  ∧ (∀u∀v (PosF'(d̄,u,v) <-> StepPosBit_c(a,b or b,a by side;u,v)))
  ∧ (∀s (UsedF'(d̄,s) <-> ∃t(UsedF(c̄,t)∧SuccCtr(t,s))))
  ∧ NoSel'(d̄)
  ∧ PostBudgetApplied'(d̄)  -- CtrlAcc'/CtrlSort'/CtrlRej' from PostBudget.

Δ_backA0_rej_ret :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄ (Top(c̄) ∧ M_BackA0(c̄) ∧ ChildReturnedRej(c̄))
  ∧ (Root(c̄) ? HaltRej' : PopReturnRejToParent(c̄)).

Δ_backA0_acc_push_A1 :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄∃a∃b (Top(c̄) ∧ M_BackA0(c̄) ∧ ChildReturnedAcc(c̄)
      ∧ HasSel(c̄) ∧ SelA(c̄,a)∧SelB(c̄,b))
  ∧ ∃d̄ (FreshChild(d̄,c̄) ∧ PushChildA(d̄,c̄,a,b,1) ∧ SetParentBackA1(c̄) ∧ Top'(d̄)).

Δ_backA1_ret :=
  ¬HaltAcc ∧ ¬HaltRej ∧ ∃c̄ (Top(c̄) ∧ M_BackA1(c̄) ∧ ChildReturned(c̄,r))
  ∧ (r=Acc -> (Root(c̄) ? HaltAcc' : PopReturnAccToParent(c̄)))
  ∧ (r=Rej -> (Root(c̄) ? HaltRej' : PopReturnRejToParent(c̄))).
```

`[deduction]` The cases are exhaustive for non-halting well-formed encoded DFS
states: top frame is evaluating (accept/root, reject/root, existential pick,
existential exhaust, or universal push `A0`) or holding a backtrack/return mode
(`BackE`/`BackA0`/`BackA1`/return marker).  Root and non-root boundaries are
split by `ZeroCell(c̄)` / `ParentOf`.  Lex cursor progress is total over the
finite linearly ordered `Key×Key`.

## 6. Discipline proof obligations for `Δ_{M_D}`

Let `I_{M_D}(Conf)` be the frame/stack well-formedness invariant: `WellFormed_w`;
at most one global halt; if not halted, exactly one `Top(c̄)`; `Top` frame has
exactly one mode and valid field combinations; `PosF(c̄,·,·)` on each active
frame is a strict partial order over `Key` (`ValidPos` from §4) with domain in
`Key`; `UsedF` is exactly one `Ctr`; `CtrlAdv` implies `HasSel` and selected
pair in `Key×Key`; `M_BackA0/M_BackA1` preserve the selected pair/cursor
metadata required for `A1`/return; cursor is a valid `Key×Key` value; and stack
links/offsets form a well-founded DFS stack with root at `ZeroCell`.

`[deduction]` **Deterministic/functional.** In every case, tests on `Conf` fix
a unique active case or no case.  The only search is `NextIncomp_c`, which is
FO-unique by the lex-minimality clause.  `SuccCtr` gives a unique used counter.
`StepPosBit_c` and `PostBudget` are functions of the frame contents.  Child
base selection is deterministic (`FreshChild` as fixed successor frame offset or
fixed parent-link discipline).  Therefore for each encoded `Conf`,
`Δ_{M_D}(Conf;Conf') ∧ Δ_{M_D}(Conf;Conf'')` implies `Conf'=Conf''` as the
induced configuration update.

`[deduction]` **Total on non-halting well-formed states.** Assume
`I_{M_D}(Conf)` and `¬HaltAcc ∧ ¬HaltRej`.  Let `c̄=Top`.  If `M_Eval(c̄)`,
then either `CfgAcc_c` (`Δ_root_acc`/`Δ_eval_acc_ret`), or rejecting/exhausted
(`Δ_root_rej`/`Δ_eval_rej_ret`), or `CtrlSort` with budget and some current/future
incomparable (`Δ_sort_pick_push`, using `HasCur` and finite lex order), or
`CtrlAdv` with a valid selected incomparable pair (`Δ_adv_push_A0`, by
invariant).  If backtrack/return-marked, the corresponding `Δ_back*` case
applies.  Thus some disjunct of `Δ_{M_D}` applies.

`[deduction]` **Invariant-preserving.** `I_{M_D}` is preserved: halting cases
are absorbing; push/pop preserve lower-stack frames by `LowerStackEq'`/
`PopTo`; `PushChildE` copies a valid `PosF/UsedF` and sets a valid adversary
selection; `PushChildA` computes `PosF'` by `StepPosBit_c`, which preserves
strict partial-order closure on incomparable inputs (incremental TC lemma), and
advances `UsedF` by unique `SuccCtr`; `PostBudgetApplied'` assigns exactly one
control tag consistently with totality/budget; cursor updates remain in
`Key×Key`; return propagation does not invent new frame content except the
finite parent mode/result transition.

`[deduction]` **No spurious transitions.** Each disjunct requires the
corresponding semantic precondition (`CfgAcc`, `YieldE_c`/`NextIncomp_c`,
`YieldA0_c`, `ChildReturned*`, root/non-root boundary) and produces exactly the
corresponding semantic post-state of the DFS alternating evaluator `M_D^alt`:
root accept/reject, push of `ChildE/ChildA0/ChildA1`, pop-return, existential
cursor advance, and universal `C0`-then-`C1` sequencing.  No disjunct modifies
arbitrary frames, creates multiple tops, invents incomparable pairs absent from
`PosF`, bypasses budget consumption, or accepts/rejects except through the
local `ConfigAcc/ConfigRej/PostBudget` and the alternating return discipline.

These four properties discharge the stack-discipline/content requirements asked
for by `[open:CKS-AV-Δ_D]` relative to the explicit frame layout and local
semantics.  The remaining normal-form residual is stated in the verdict and §7.

## 7. FO(PFP)/IFP acceptance and obligations (2)-(4),(ii)-(v)

`[definition,literature]` Using the standard FO(PFP) (equivalently, on ordered
structures in standard presentations, IFP/PFP) capture of polynomial-space DTM
computation `[Vardi 1982; Immerman 1986; Abiteboul–Vianu 1991, 1995;
Ebbinghaus–Flum; Libkin; Immerman]`, define the halting/acceptance reachability
schema over the packed configuration operator induced by `Δ_{M_D}`:

## 9. Final assessment

The target `[open:CKS-AV-Δ_D]` is **substantially discharged at the
stack-discipline/formula level**: §5 gives a complete, case-closed FO one-step
transition for frame boundaries, push/pop, return propagation, lex cursor, and
universal `C0/C1` sequencing, specialized to the fixed layout and local move
semantics; §6 proves determinism, totality on non-halting well-formed states,
invariant preservation, and absence of spurious transitions.

The note does **not** claim an absolutely complete end-to-end discharged fixed
syntactic FO(PFP)/IFP sentence proof from first principles.  The single minimal
remaining lemma is `[open:CKS-AV-Δ_D/PACK]`: the standard simultaneous/fixed-arity
PFP packing of the explicit configuration-relation family and one-step operator
induced by `Δ_{M_D}`.  Discharging `[open:CKS-AV-Δ_D/PACK]` with the standard
Vardi/Immerman/Abiteboul–Vianu capture theorem and the equivalence chain of §7
would yield the required fixed syntactic FO(PFP)/IFP sentence equivalent to
`S(n)<=k`.
