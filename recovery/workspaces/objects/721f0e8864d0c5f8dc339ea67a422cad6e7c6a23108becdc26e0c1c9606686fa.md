# Obstruction: polynomial quotients are insufficient for root-optimal comparison strategies

**Status:** barrier note (concrete obstruction). Evidence: proof sketch + definitions + falsifier. No Lean, no complexity-class separation claimed.

## 1) Precise question (falsifiable)
Can there exist a function `Q_n` mapping each comparison state `P` reachable from the `n`-antichain under *some* optimal (height `S(n)`) strategy to a "class id" in a set of size `poly(n)` such that:
- (soundness) states in same class have equal `F(P)=S(n)-d(P)`,
- (local checkability) for any class `c = Q_n(P)` and any comparison `x:y`, the classes `c_{xy}=Q_n(P+x<y)`, `c_{yx}=Q_n(P+y<x)` are computable in time `poly(|P|,n)` from `(c, x,y)`,
- (completeness for root optimum) there is a root-optimal strategy whose path labels stay within `poly(n)` classes?

If such `Q_n` exists for all sufficiently large `n`, one could build a polynomial NP certificate for `SORT-BOUND-U = \{1^n\#1^k : S(n)\le k\}` by: (a) give root class, (b) give a local transition function over classes (a DAG of size `poly(n)`), (c) verifier checks local consistency/completeness for sorting all order types. Conversely, polynomial NP membership would force some form of this (up to encoding).

This is falsifiable by an obstruction to any `Q_n` with the above properties.

## 2) Definitions (cost model)
- Model: adaptive pairwise comparisons, distinct labelled keys, worst-case height. `S(n)=\min_T height(T)`. 
- State `P`: transitive strict partial order from comparisons so far; `e(P)` linear extensions; `F(P)=\min_{strategies from P} worst-case remaining` comparisons, `F(\emptyset)=S(n)`, `F(total)=0`.
- Reachable under a strategy: states on some execution path of that strategy.
- Encoding for `SORT-BOUND-U`: unary `N = n + k + 1`, `S(n)\le k`. `SORT-BOUND-U \in NP` (in the usual sense for this tally language) means there is a polynomial-time verifier `V(1^n\#1^k, \pi)$ with $|\pi|\le poly(N)$ accepting iff $S(n)\le k$. A natural candidate `\pi$ is a description of a strategy of height k.

## 3) The obstruction (from the winning frontier)
From [docs/research-winning-frontier-barrier.md] (paper-level, independently auditable):
- For infinitely many $n=2^{2r}$, let $k=\lceil \log_2(n!)\rceil$ (information budget). There is some depth $t$ with >= $2^{(1/4-o(1))n(\log_2 n)^2}$ pairwise **nonisomorphic** $n$-vertex partial orders $P$ such that (1) each is reachable from antichain by exactly $t$ comparison outcomes, (2) $F(P)\le k-t$ (winning at budget k). 
- This holds at the exact optimal budget $k=S(n)$ as well ($S(n)=\log_2(n!)+o(n)$). 
- Finite witness: $n=224$, $>2^{39}$ nonisomorphic reachable winning states at same depth with remaining budget 907.

**Key point:** "winning" = feasible to complete to height k-t from here; the states are on *some* possible paths if we play well, but they are different local configurations.

Now suppose for contradiction such `Q_n$ (poly-size classes, local transitions, covering some root-optimal strategy class system) exists. Consider the set $W_{n,t,k}$ of all $P$ nonisomorphic, reachable at depth t, with $F(P)\le k-t$ (the full winning frontier at that depth under budget k), size $|W_{n,t,k}| >= \exp(\Omega(n (\log n)^2))$. 
Take any class system covering *some* root-optimal strategy $T^*$ (height k): let $V(T^*)$ be states on paths of $T^*$. The system gives a function from $V(T^*)$ to a set $C_n$ with $|C_n|\le poly(n)$.

Also, classes must respect the minimax value in the sense relevant to a *certificate* that is checkable: to verify that following the class transitions gives height <=k from any branch, the class must determine the allowed transitions consistent with some winning completion? Or more directly, if you only know the class $c=Q_n(P)$, the verifier must be able to test local moves without knowing the full labelled structure except through the class - but different $P, P'$ might fall in same class. However, soundness requires $F(P)=F(P')$ if same class; local checkability means transitions are well-defined on classes.

But there is no requirement stated that different winning states *must* go to different classes - quotienting means they can merge. The obstruction is the opposite direction: can a *single* poly-size quotient system represent *all possible* root-optimal strategies or even be used as a certificate that is *complete* for "is there any root-optimal strategy of height k"?

Or more directly, for NP membership: certificate $\pi$ describes some strategy $T_\pi$ of height k. The verifier must check $T_\pi$ sorts every permutation (is correct) and has height <=k. Correctness is a universal property over all $n!$ inputs; height is worst-case. How?
- If $\pi$ describes the tree explicitly as nodes/edges with comparisons, size is >= number of leaves in worst bad case? No - a decision tree for sorting can be balanced in height but have up to $n!$ leaves; describing leaves as orderings is large, but sometimes people describe the tree structure. But $n!$ is exponential in $n\log n$; unary input length $N \approx n+k \le n + O(n\log n)=O(n\log n)$, so exponential-in-$N$ certificate is not polynomial. That’s the standard point: “An optimal sorting tree may be exponentially large, so exhibiting one is not an NP certificate.” (from problem.md)
- Alternative: $\pi$ describes a *compact strategy* (e.g. a comparison rule depending only on class). Then verification is: (1) the rule is well-defined, (2) following it gives height <=k from root, (3) it sorts every permutation. (3) is a universal check - if the state graph of classes is small (poly(n) states total reachable), maybe you can verify by graph traversal over all reachable class states that every class state that is “terminal” in terms of being fully sorted corresponds to a total order and every non-terminal has a move to states with $F = F(current)-1$. But this requires that the class system is a *faithful quotient of the minimax graph* and covers all reachable states of *this* strategy.
- But the winning frontier shows there are exponentially many *different* nonisomorphic winning states. A single strategy makes a choice at each state (picks one comparison) moving to some children; different optimal strategies might traverse different regions of this frontier. Also, different states might not be mergeable without losing the ability to form *some* root-optimal strategy? Or more directly, if you fix any quotient with $< |W_{n,t,k}|$ classes, by pigeonhole principle some class contains two different nonisomorphic winning states $P, P'$ at the same depth with same $F$. That’s always true if quotient is coarser than isomorphism. The question is: can such a coarser quotient still support a *local checkable* description of *some* root-optimal strategy?

But also need that from class of $P$ you can choose a comparison such that both resulting classes are “winning” ($F-1$), and this is consistent. The obstruction is: local transition rules on classes might be ambiguous or might not exist for all classes if classes are too coarse and mix states with different “admissible” move sets in an incompatible way? Or more strongly, the minimax strategy is a kind of “strategy stealing” over the partial order - merging different poset types can destroy the ability to guarantee the minimax bound.

This is similar to some “strategy complexity” obstructions. A concrete falsifier: exhibit that for large n, every quotient system that is sound for $F$ and has $poly(n)$ classes fails local completeness for some root-optimal move, or forces height > k. Or alternatively, show that the “admissible” comparison graph has high “path constraints”.

But to make it precise and falsifiable as requested: give a concrete necessary condition.

## 4) Concrete necessary condition (barrier)
Let $\mathcal{Q} = \{Q_n\}$ be any family of quotient maps with $|image(Q_n)| \le poly(n)$. Define that $\mathcal{Q}$ is *certificate-admissible* if there exists a polynomial-time verifier that can check a strategy described in terms of $\mathcal{Q}$-classes. A necessary condition for $\mathcal{Q}$ to be certificate-admissible for some root-optimal strategy is: the class graph induced by $\mathcal{Q}$ has a path from root class to all-total classes of total “cost” k and is locally consistent.

The obstruction from the winning frontier: take $W = W_{n,t,k}$, $|W| >= \exp(\Omega(n(\log n)^2))$. Let $r(P)$ be the “required” move signature or simply note that the family $\{P+x<y, P+y<x\}$ over all admissible winning moves forms a kind of “hitting”. But more directly, use the fact that if you have exponentially many nonisomorphic states, you can think of them as having “different” comparison profiles. Alternatively, consider the “decision tree” as a function and use information theory? No - states are the configurations, not the inputs. Or think of the strategy as a labeling.

A standard combinatorial obstruction (sometimes called “strategy obfuscation” or just large frontier): if the number of “indecomposable” winning subgames is exponential and they are pairwise “incompatible” under any small quotient, then no small quotient certificate exists. The winning frontier construction gives explicit exponentially many states reachable at same depth with same remaining budget - they are different poset structures (different edge sets on chains with extra edges). It’s not obvious they are pairwise incompatible, but it’s a natural place to look for obstruction.

A more concrete obstruction is: for the class system to be able to represent *some* root-optimal strategy, every class $c$ that is used and is not total must have at least one comparison such that *both* children classes are “admissible” (lead to some root-optimal completion). But also, the move is chosen by the strategy. However, the verifier needs to ensure that *whatever* the adversary does (whatever outcome), the strategy stays within budget - so from class $c$ (representing some state $P$ of that class), the strategy's prescribed comparison must be valid for $P$ and both outcomes must go to classes with remaining budget k-t-1.

But if a single class $c$ contains two states $P, P'$ that have *no comparison in common* that is admissible for both as part of *some* root-optimal strategy, or worse - if the set of admissible first moves differs such that you can't have a single local rule - then coarser quotient breaks local checkability.

Is this true for the winning frontier states? The winning frontier states are built from the same chain structure $(i,x)$ with different extra edges $A$. A comparison might be inside a chain (but chains are already ordered - no, states are partial orders; chains mean those pairs are already compared/known). Or comparisons are between elements not yet ordered. The structure is similar but extra edges differ. It’s plausible they have different “admissible” move sets. That would be a concrete obstruction.

## 5) Falsifier (concrete)
Assume for large $n$ in that family that for the set of nonisomorphic winning states $W$ at depth t, every equivalence class of any $S_n$-preserving quotient (or any quotient that merges some states in $W$) contains two states $P \neq P'$ such that the sets of “minimax-optimal” first moves $M(P), M(P') \subseteq$ pairs are disjoint. If true, no poly-size quotient can support a single local transition function that is valid for some root-optimal strategy covering those states - hence no polynomial NP certificate via class-quotients. This is falsifiable by checking move sets for the $n=224$ witness or by a structural argument about the independent-edge construction.

## Conclusion
The large winning frontier (exponentially many nonisomorphic reachable winning states at fixed depth under optimal/exact budget) is a concrete obstruction to the naive polynomial-quotient (class-DAG) approach to NP membership of `SORT-BOUND-U`. A necessary condition is that the quotient classes used by any polynomial certificate strategy must be “move-universal” across all states in the class; the independent-edge/winning-frontier family is a plausible candidate to violate this for any $poly(n)$ quotient. Residual gaps: (a) prove move-disjointness/incompatibility for that family under any coarser quotient, (b) rule out non-quotient compact certificates (e.g. different representation), (c) relate to the exact sparsity/Mahaney constraints.
