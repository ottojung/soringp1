## Incomplete
- Class C definition (§2): point 2 says "Distinct members of W'(n,k) that are not identified by a *sound exact* equivalence used by the method occupy distinct represented states/keys/objects during the method. Equivalently, the method does not merge two elements of W'(n,k) unless the merge preserves the exact minimax transition/value needed for the root decision." This is a reasonable informal characterization, but it is circular in a small way: "sound exact equivalence used by the method" is defined relative to the method. To be a clean lower-bound class, better to say: there is some sound exact equivalence E used by the method such that elements of W'(n,k) remain in different E-classes (or the method's state graph is a refinement). As written, a clever method could claim a different equivalence, but the barrier gives nonisomorphic states under S_n (the natural quotient). The note acknowledges this implicitly but could state the quotient explicitly.
- "Work lower bound per represented state" (C3): stated as "a standard RAM/TM bookkeeping lower bound on enumerating/distinguishing a set" — acceptable as a heuristic, but not a formal TM lower bound. The note says "does not assume listing as external output, only that distinct states are materialized/distinguished" which is fair, but calling it a lower bound is a bit strong without model details. The theorem states "represented-state count and time T_C(n) >= W(n)" which is reasonable if C3 holds.
- The note says "the theorem supplies W(n) distinct nonisomorphic winning states" — correct (up to isomorphism). But class C requires they are "not identified by a sound exact equivalence used by the method". S_n is sound and gives isomorphism classes; the barrier gives >=W(n) nonisomorphic classes, so any method using only S_n quotient would still have >=W(n) classes. A method using a larger equivalence group would need that group to be sound on these states — but the states are arbitrary posets from that construction (up to isomorphism) and there is no reason a priori they form larger orbits except by chance; the barrier states "pairwise nonisomorphic", so no nontrivial S_n identification applies. The note should be more explicit about this point.

## Open / suggestions
- Tighten C2 to reference S_n (or the quotient actually used) explicitly: the barrier is up to isomorphism under key relabelling, so any exact method that uses only relabelling/duality as state identification is in class C relative to that frontier; methods using other equivalences need to argue soundness on these specific posets.
- Consider noting that the frontier is constructed at fixed depth t with fixed remaining budget k-t — the method must be correct at that budget, so it cannot "avoid" distinguishing them by changing budget strategy except by not being a DP over those states.
- The note says "no repository result supplies a sound aggregation that provably collapses..." — correct. It could also mention that comparability graph failed value-invariance at n=7 and transition at n=5 as stronger evidence it's not just a quotient we haven't found but can be ruled out.

## Overall assessment
The class-C frontier-distinguishing obstruction follows soundly from the winning-frontier barrier and repo results. The note correctly avoids claiming a general time lower bound for S(n), stays within AGENTS/model constraints (unary focus, no P/NP/PSPACE separation claims, labels evidence), and accurately characterizes which natural routes fail. The main issues are minor tightening of the class definition and the bookkeeping lower bound phrasing, not substance.
