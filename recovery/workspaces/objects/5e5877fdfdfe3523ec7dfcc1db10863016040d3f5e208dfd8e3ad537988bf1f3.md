## 3. Gaps, caveats, and possible overclaims

1. **“Θ(N log N) information” for deterministic path descriptions is informal/stronger than proved (minor overclaim risk).** §4 states: “For a history-dependent game with `Θ(n^2)` candidate moves per level and depth `Θ(N)`, the deterministic path description has `Θ(N log N)` information in the general case.” Interpreted literally this is an information-theoretic lower bound on path descriptions; the note does not prove it (and move legality prunes candidates over time). It is directionally plausible for an upper/lower accounting of transcript+cursor *representations* (`t` comparisons/cursors × `O(log n)` bits), and §7 narrows to the standard transcript representation; but the sentence should be read as heuristic/representation-level, not as a theorem. **Recommendation:** label this sentence `[deduction/heuristic]` or weaken to “can be `Θ(N log N)` bits in the worst case for natural representations”.

2. **Resumability quantified over “standard resumable DFS invariant” / transcript representation, not all exact algorithms.** §3–§7 mostly handle this correctly, but §3 says “any exact backtracking evaluator…” before adding the representation caveat. This is acceptable only with the immediate caveat that follows; a hostile reader could misread it. The final obstruction statement is properly scoped.

3. **“Information-theoretic path size” (end of §7) is again heuristic.** The phrase “compresses resumable adaptive transcripts below information-theoretic path size on all relevant instances” suggests a Shannon/information bound that was not established. Better: “below the apparent `Θ(k log n)` size of natural resumable transcript/cursor representations on all relevant instances, or otherwise…”

4. **Non-exhaustive technique survey.** The artifact cannot rule out all recomputation/catalytic/implicit-state methods. Plausible directions not named explicitly include: **Savitch-style space squaring** (gives `DSPACE(s^2)`-type tradeoffs and is not a sub-`s` improvement, but worth stating why irrelevant to `o(N log N)`), **Williams-style time–space tradeoffs** (usually target time with restricted space models), **pebbling / tree-pebbling/checkpointing** formulations (mentioned abstractly as checkpoint/restart but not tied to game-tree pebbling bounds), **reversible simulation details beyond catalytic framing** (Bennett/Turing reversibility), and recent **catalytic/tree-evaluation composition** lines — but naming them without concrete application risks speculation. The artifact’s current choice (state gap, no impossibility claim) is safer than guessing. **No missed technique with a demonstrated `o(N log N)` path was identified from the supplied project documents.**

5. **State-compression connection is omitted but not contradictory.** `research-state-compression.md` shows exact `S_n` quotienting preserves `S(n)` but does not change the `2^{Θ(n^2)}` asymptotic state picture and has canonicalization bottlenecks; it also concerns state counts/practical DP, not the transcript work-tape bound directly. The artifact’s focus on resumable path state is consistent with that: quotienting can identify states, but exact minimax backtracking still needs resumable exploration/cursors unless a new value-preserving compressed evaluation is proved. This could be cited as supporting context, not as a gap.

6. **Minor wording:** “`P(σ_{i-1})`”/resume restores poset and cursor — correct; baseline reconstructs poset from transcript by reachability, so storing transcript is sufficient. The artifact states this (§3, §4). No model mismatch.
