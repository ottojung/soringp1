## 1. Normalized `Enc` schema (applies fixes 1–3)

### 1.1 Frame-field normalization (fix 2)

`[definition]` Canonical frame component tuple and helpers:
```text
Fld(c̄) := ⟨Mode,Ret,Ctrl,UsedF,HasSel,SelA,SelB,HasCur,CurA,CurB,PosF,Parent⟩
Mode  = {M_Eval,M_BackE,M_BackA0,M_BackA1}
Ret   = {RetNone,RetAcc,RetRej}
Ctrl  = {CtrlSort,CtrlAdv,CtrlAcc,CtrlRej}

FrameFieldsEq'(x̄) := equality of all Fld components for x̄ and x̄', with no
                     implicit liveness change.
FrameEq'(x̄)       := FrameFieldsEq'(x̄) ∧ (FrameLive'(x̄) <-> FrameLive(x̄)).
FrameInactive'(x̄) := ¬FrameLive'(x̄).
LowerStackPreservedExcept(S) :=
  ∀x̄(FrameLive(x̄) ∧ ¬S(x̄) -> FrameEq'(x̄)).
```

`[deduction]` `FrameEq'` is for untouched live frames only. Any frame whose
liveness changes, or any row-selected frame whose `Mode`/`Ret`/marker fields
change (`p̄` in pop rows), must be specified by explicit clauses and excluded
from generic `FrameEq'` preservation.

Changed-set discipline:
```text
D_halt (row 1):                 S = ∅, absorbing identity.
Push rows (6,7,10,15):          S = {c̄,d̄}.
Pop/return rows (4,5,8,9,       S = {p̄,c̄}; c̄ becomes FrameInactive'(c̄);
  11,12,13,14,16,17,18,19):     p̄ receives explicit marker/mode/terminal effect
                                and is not preserved by generic FrameEq'.
Root/non-root terminal rows
  without pop target in table:  use explicit terminal global convention.
```

### 1.2 Global tuple priming and allocator (fix 2)

`[definition]`
```text
CurBaseUnchanged := ∃b̄(CurBase(b̄) ∧ CurBase'(b̄)).
CurBaseBump      := ∃b̄∃b̄'(CurBase(b̄) ∧ SuccCell(b̄,b̄') ∧ CurBase'(b̄')).
FreshChild(d̄)    := CurBase(d̄).

Globals_halt_absorb :=
  HaltAcc' <-> HaltAcc ∧ HaltRej' <-> HaltRej ∧
  EmptyStack' <-> EmptyStack ∧ CurBase' = CurBase ∧ Top' = Top.

Globals_push(c̄,d̄) :=
  Top'(d̄) ∧ ¬Top'(c̄) ∧ ∀z(Top'(z) -> z=d̄) ∧ CurBaseBump ∧
  HaltAcc' <-> HaltAcc ∧ HaltRej' <-> HaltRej ∧ EmptyStack' <-> EmptyStack.

Globals_pop(p̄,c̄) :=
  Top'(p̄) ∧ ¬Top'(c̄) ∧ ∀z(Top'(z) -> z=p̄) ∧ CurBaseUnchanged ∧
  HaltAcc' <-> HaltAcc ∧ HaltRej' <-> HaltRej ∧ EmptyStack' <-> EmptyStack.

Globals_root_halt_acc :=
  HaltAcc' ∧ ¬HaltRej' ∧ EmptyStack' ∧ CurBaseUnchanged ∧ ¬∃z Top'(z).

Globals_root_halt_rej :=
  HaltRej' ∧ ¬HaltAcc' ∧ EmptyStack' ∧ CurBaseUnchanged ∧ ¬∃z Top'(z).

Terminal_ClearFrames := ∀x̄ ¬FrameLive'(x̄).
```

### 1.3 Push/pop/marker primitives (fix 2)

`[definition]`
```text
Root(c̄)    := FrameLive(c̄) ∧ ¬∃p̄ Parent(c̄,p̄).
NonRoot(c̄) := FrameLive(c̄) ∧ ∃p̄ Parent(c̄,p̄).

PreserveNonMarkerFields(p̄) :=
  preserve Fld components of p̄ except Ret, and preserve FrameLive'(p̄).

MarkRetAccOn(p̄) :=
  FrameLive'(p̄) ∧ RetAcc'(p̄) ∧ ¬RetRej'(p̄) ∧ ¬RetNone'(p̄) ∧
  PreserveNonMarkerFields(p̄).

MarkRetRejOn(p̄) :=
  FrameLive'(p̄) ∧ RetRej'(p̄) ∧ ¬RetAcc'(p̄) ∧ ¬RetNone'(p̄) ∧
  PreserveNonMarkerFields(p̄).

PopTo_base(p̄,c̄) :=
  Top(c̄) ∧ Parent(c̄,p̄) ∧ FrameLive(c̄) ∧ FrameLive(p̄) ∧
  Globals_pop(p̄,c̄) ∧ FrameInactive'(c̄) ∧ LowerStackPreservedExcept({p̄,c̄}).

ChildFrameBase(d̄,c̄) :=      -- [SYM-TOP]
  Top(c̄) ∧ FreshChild(d̄) ∧
  Globals_push(c̄,d̄) ∧ FrameLive'(d̄) ∧
  LowerStackPreservedExcept({c̄,d̄}).
```

`[deduction]` In `PopTo_base`, `p̄` is in the changed set and is not given by
generic `FrameEq'`; it is completed by `MarkRetAccOn/MarkRetRejOn` or, in
terminal pop-consuming cases, by the terminal convention. Thus no row may
assert `FrameEq'(p̄)` together with a `Ret`/marker change.
