## 1. Fixed objects and input structure

`[definition]` `SORT-BOUND-U = {1^n # 1^k : S(n) <= k}` with input length `N=n+k+1` (`docs/problem.md`).

`[definition]` Intended ordered word structure:
```text
A(w) = (W, <, One, Hash),    w=1^n#1^k, W={1,...,N}, N=n+k+1,
Hash = {n+1}, One = W \ {n+1}.
```
`<` is the standard linear order on positions.

`[definition]` FO parameters/guards (all AC-independent):
```text
HashPos(h)       := Hash(h) ∧ ∀z(Hash(z)->z=h).
WellFormed_w     := ∃h HashPos(h) ∧ ∀h(HashPos(h)->∀x(One(x)<->x!=h)).
Malformed        := ¬WellFormed_w.

Key(x)           := ∃h(HashPos(h) ∧ x < h).
Ctr(t)           := ∃h(HashPos(h) ∧ (t=h ∨ h < t)).        -- {0,...,k}, 0 encoded by hash
Zero(t)          := HashPos(t).
MaxK(t)          := Ctr(t) ∧ ¬∃s(Ctr(s) ∧ t < s).
SuccCtr(t,s)     := Ctr(t) ∧ Ctr(s) ∧ t < s ∧ ¬∃z(Ctr(z) ∧ t < z ∧ z < s).
HasBudget(t)     := ∃s SuccCtr(t,s).

KeyEq(x,y)       := Key(x) ∧ Key(y) ∧ x=y.
KeyNe(x,y)       := Key(x) ∧ Key(y) ∧ ¬(x=y).
```
`[deduction]` `|Key|=n`, `|Ctr|=k+1`. `Key` is disjoint from actual comparison-count successors except the encoding choice `Zero=Hash`; no transition reads `Zero` as a key because keys are restricted by `Key(x)`.

`[definition]` Final sentence shape:
```text
Φ_SORTU  :=  Malformed  ?  reject  :  Φ_game
         :=  WellFormed_w ∧ Φ_game.
```

## 2. Game and ATM equivalence target

`[definition]` `G(n,k)`: states are transitively closed strict partial orders `P` on `n` labelled keys; initial `P0=∅`; budget `k`. A nonterminal sorter move selects an incomparable pair `{a,b}`. The adversary answers `a<b` or `b<a`; the new state is `TC(P∪{answer})`; used comparisons increase by 1. Sorter wins iff a total order is reached within `k` comparisons.

`[literature,deduction]` `S(n)<=k` iff sorter wins `G(n,k)` (`docs/problem.md`, `research-certificates-barriers.md` Claim A).

`[definition]` `M_G` is the alternating game machine over `A(w)$ whose existential states perform legal sorter moves, universal states perform adversary branches, and which accepts on reaching a total order within budget `k`.

`[deduction]` Target simulation lemma:
```text
For well-formed w=1^n#1^k,
  A(w) |= Φ_game
    iff M_G has an accepting alternating computation on A(w)
    iff sorter wins G(n,k)
    iff S(n)<=k
    iff w ∈ SORT-BOUND-U.
Malformed inputs are rejected by Φ_SORTU.
```

## 3. Configuration normal form (cell/state relations)

This section fixes the **local semantic normal form** used by all transition formulas. It is the explicit normal form that a global FO(PFP) simulation must preserve.

### 3.1 Semantic configuration

`[definition]` A complete game configuration is
```text
C = (Pos, Used, Q, Pair, Aux)
```
with intended components:
```text
Pos(u,v)      binary, u,v∈Key   : current strict partial-order edge u<v (transitively closed)
Used(t)       unary,  t∈Ctr     : exactly the number of comparisons used (a Ctr element)
Q_S, Q_A, Q_Acc, Q_Rej  nullary/finite-control flags : control mode
Pair(a,b)     binary, a,b∈Key   : selected sorter pair in adversary mode, else empty
Aux           finite control only (no game-state content beyond above)
```

`[deduction]` `Pos` is a relation over `W`, not content decoded from a fixed tuple in `W^r`; therefore the old fixed-tuple counting blocker does not apply to representing arbitrary poset states.

### 3.2 Global cell-index normal form for FO(PFP) simulation

To instantiate a standard FO(PFP)=PSPACE simulation, the configuration must be presented as fixed-arity relations over `W` in a normal form usable by the capture proof. The explicit normal form chosen here is:

`[definition]` **Normal form N_G (configuration-cell relations over `A(w)`):**
```text
Input relations:    <, One, Hash                                  (arity 1,1,2 as usual)
State relations:
  Pos(u,v)          u<v in current poset                          arity 2, domain Key
  Used(t)           comparisons-used marker                       arity 1, domain Ctr
  QSort()           existential sorter control                    arity 0 (or unary tag)
  QAdv()            universal adversary control                   arity 0
  QAcc()            accepting sink                                arity 0
  QRej()            rejecting sink                                arity 0
  Sel(a,b)          selected pair                                 arity 2, domain Key
  Ok()              global well-formed/configuration-valid flag  arity 0
```
A complete encoded configuration is an interpretation of `(Pos,Used,QSort,QAdv,QAcc,QRej,Sel,Ok)` over `A(w)`.

`[deduction]` This normal form is a fixed finite signature independent of `n,k`. It is sufficient for the local `G(n,k)` semantics because every move reads/writes only the current poset, used budget, control, and selected pair. A standard DTM/ATM tape-cell simulation can be obtained by further compiling `Pos/Used/Sel` into cell-content relations indexed by tuples (see §5.2), but the game-specific semantics is already fully explicit in N_G.

### 3.3 Configuration validity

`[definition]` AC-independent validity:
```text
ValidPos(Pos) :=
  (∀u∀v (Pos(u,v) -> (Key(u)∧Key(v))))
  ∧ (∀x ¬Pos(x,x))
  ∧ (∀x∀y∀z ((Pos(x,y)∧Pos(y,z))->Pos(x,z))).

Irreflexive(Pos) := ∀x ¬Pos(x,x).

Incomparable(Pos,x,y) :=
  Key(x)∧Key(y)∧¬(x=y) ∧ ¬Pos(x,y) ∧ ¬Pos(y,x).

Total(Pos) :=
  ∀x∀y ((Key(x)∧Key(y)∧¬(x=y)) -> (Pos(x,y)∨Pos(y,x))).

ExactlyOneUsed(Used) :=
  ∃t(Used(t)∧Ctr(t)) ∧ ∀t∀s((Used(t)∧Used(s))->t=s).

NoSel(Sel) := ¬∃a∃b Sel(a,b).
OneSel(Sel):= ∃a∃b(Sel(a,b)∧Key(a)∧Key(b)∧∀x∀y(Sel(x,y)->(x=a∧y=b))).

ExactlyOneControl(QSort,QAdv,QAcc,QRej) :=
  (QSort∨QAdv∨QAcc∨QRej)
  ∧ ¬(QSort∧QAdv) ∧ ¬(QSort∧QAcc) ∧ ¬(QSort∧QRej)
  ∧ ¬(QAdv∧QAcc)  ∧ ¬(QAdv∧QRej)  ∧ ¬(QAcc∧QRej).

ValidConfig(Pos,Used,QSort,QAdv,QAcc,QRej,Sel) :=
  ValidPos(Pos) ∧ ExactlyOneUsed(Used)
  ∧ ExactlyOneControl(QSort,QAdv,QAcc,QRej)
  ∧ (QSort -> NoSel(Sel))
  ∧ (QAdv  -> OneSel(Sel))
  ∧ (QAcc  -> Total(Pos))
  ∧ (QRej  -> ¬Total(Pos)).
```
`[falsification target]` The `QAcc -> Total(Pos)` / `QRej -> ¬Total(Pos)` invariants are convenient but stronger than necessary; if a global proof uses sink states without these implications, relax `ValidConfig` accordingly. The local transition formulas below are compatible with either choice.

## 4. Fixed FO local transition formulas (AC-independent)

All formulas in this section are first-order over `A(w)$ and the displayed state relations; they do **not** mention the acceptance fixed-point variable.

### 4.1 Initial and accepting configurations

`[definition]`
```text
Init(Pos,Used,QSort,QAdv,QAcc,QRej,Sel) :=
    (∀u∀v ¬Pos(u,v))
  ∧ (∃t (Used(t)∧Zero(t)) ∧ ∀t∀s((Used(t)∧Used(s))->t=s))
  ∧ NoSel(Sel)
  ∧ ¬QAdv ∧ ¬QRej
  ∧ ((Total(Pos) ∧ QAcc ∧ ¬QSort) ∨ (¬Total(Pos) ∧ QSort ∧ ¬QAcc)).

ConfigAcc(Pos,Used,QSort,QAdv,QAcc,QRej,Sel) := QAcc ∨ Total(Pos).
ConfigRej(Pos,Used,QSort,QAdv,QAcc,QRej,Sel) := QRej.
```

### 4.2 Incremental transitive closure

`[definition]` For a legal answer adding `x<y`:
```text
AddEdge(Pos,x,y; u,v) := (u=x ∧ v=y).

StepPos(Pos,x,y; u,v) :=
    Pos(u,v)
  ∨ ((u=x ∨ Pos(u,x)) ∧ (v=y ∨ Pos(y,v))).
```

`[deduction]` **TC lemma (local).** If `ValidPos(Pos)` and `Incomparable(Pos,x,y)`, then `Pos' := {(u,v) | StepPos(Pos,x,y;u,v)}` is the transitive closure of `Pos ∪ {(x,y)}` and satisfies `ValidPos(Pos')`.
*Proof sketch.* Every added pair `(u,v)` has a path `u=x or Pos(u,x)` and `x->y` and `y=v or Pos(y,v)`, so it is implied by `Pos∪{(x,y)}`. Conversely, any path using the new edge factors through `x->y`. Irreflexivity: a new reflexive edge would require `x=v` and `u=y` giving `Pos(y,x)` or equalities contradicting incomparability/irreflexivity. Transitivity is the standard one-edge incremental closure argument for adding an edge absent in a transitively closed dag.

`[falsification target]` The full proof must check the four combinations `(u=x,u!=x?) × (v=y,v!=y?)` carefully, especially that `Pos` is already transitively closed and has no `x<...<y` or `y<...<x` path.

### 4.3 Existential sorter transition

`[definition]` A legal existential move from a sorter configuration to an adversary configuration with selected pair `(a,b)`:
```text
YieldE(Pos,Used,QSort,QAdv,QAcc,QRej,Sel;
       Pos',Used',QSort',QAdv',QAcc',QRej',Sel') :=
    QSort ∧ ¬Total(Pos)
  ∧ (∃t (Used(t) ∧ HasBudget(t)))
  ∧ (∃a∃b (Sel'(a,b) ∧ Incomparable(Pos,a,b) ∧ ∀x∀y(Sel'(x,y)->(x=a∧y=b))))
  ∧ (∀u∀v (Pos'(u,v) <-> Pos(u,v)))
  ∧ (∀t (Used'(t) <-> Used(t)))
  ∧ QAdv' ∧ ¬QSort' ∧ ¬QAcc' ∧ ¬QRej'.
```

### 4.4 Universal adversary transitions

`[definition]` Outcome 0 answers `a<b`; outcome 1 answers `b<a`.
```text
PostBudget(Pos',Used',QSort',QAdv',QAcc',QRej') :=
    (Total(Pos') ∧ QAcc' ∧ ¬QSort' ∧ ¬QAdv' ∧ ¬QRej')
  ∨ (¬Total(Pos') ∧ ∃s(Used'(s)∧HasBudget(s)) ∧ QSort' ∧ ¬QAdv' ∧ ¬QAcc' ∧ ¬QRej')
  ∨ (¬Total(Pos') ∧ ∃s(Used'(s)∧MaxK(s) ∧ ¬∃r SuccCtr(s,r))? ) -- simplified below
```
Use the explicit form:
```text
PostBudget(Pos',Used',QSort',QAdv',QAcc',QRej') :=
    (Total(Pos') ∧ QAcc' ∧ ¬QSort' ∧ ¬QAdv' ∧ ¬QRej')
  ∨ (¬Total(Pos') ∧ (∃s(Used'(s)∧HasBudget(s))) ∧ QSort' ∧ ¬QAdv' ∧ ¬QAcc' ∧ ¬QRej')
  ∨ (¬Total(Pos') ∧ ¬(∃s(Used'(s)∧HasBudget(s))) ∧ QRej' ∧ ¬QSort' ∧ ¬QAdv' ∧ ¬QAcc').

YieldA0(Pos,Used,QSort,QAdv,QAcc,QRej,Sel;
        Pos',Used',QSort',QAdv',QAcc',QRej',Sel') :=
    QAdv
  ∧ (∃a∃b (Sel(a,b) ∧ Incomparable(Pos,a,b)))
  ∧ (∀u∀v (Pos'(u,v) <-> StepPos(Pos,a,b;u,v)))
  ∧ (∃t∃s (Used(t)∧SuccCtr(t,s)∧Used'(s) ∧ ∀r(Used'(r)->r=s)))
  ∧ NoSel(Sel')
  ∧ PostBudget(Pos',Used',QSort',QAdv',QAcc',QRej').

YieldA1(Pos,Used,QSort,QAdv,QAcc,QRej,Sel;
        Pos',Used',QSort',QAdv',QAcc',QRej',Sel') :=
    QAdv
  ∧ (∃a∃b (Sel(a,b) ∧ Incomparable(Pos,a,b)))
  ∧ (∀u∀v (Pos'(u,v) <-> StepPos(Pos,b,a;u,v)))
  ∧ (∃t∃s (Used(t)∧SuccCtr(t,s)∧Used'(s) ∧ ∀r(Used'(r)->r=s)))
  ∧ NoSel(Sel')
  ∧ PostBudget(Pos',Used',QSort',QAdv',QAcc',QRej').
```

`[deduction]` **Budget lemma (local).** Every complete comparison phase consumes exactly one `SuccCtr` step. `YieldE` is enabled only when `HasBudget(t)`, so at most `k` comparisons can be started from `Zero`. `PostBudget` accepts at `Total(Pos')` (including the state reached by the `k`-th comparison), continues only when remaining budget exists, and rejects a non-total state with no remaining budget. Therefore no accepting run uses more than `k` comparisons.

`[falsification target]` Check `k=0`; `n<=1`; exact exhaustion where `Used'=MaxK`; and that `HasBudget(MaxK)` is false under the `Ctr` encoding.

### 4.5 Local transition relation

`[definition]`
```text
Step(C,C') := YieldE(C;C') ∨ YieldA0(C;C') ∨ YieldA1(C;C').
Universal(C) := QAdv.
Existential(C) := QSort.
TerminalAcc(C) := ConfigAcc(C).
TerminalRej(C) := ConfigRej(C) ∨ (QSort ∧ ¬Total(Pos) ∧ ¬∃t(Used(t)∧HasBudget(t))).
```
(The second disjunct of `TerminalRej` is redundant if transitions are used only when enabled; include/exclude consistently in the global proof.)

## 5. Global FO(PFP)/IFP acceptance: explicit sentence forms and exact normal-form gap

### 5.1 Positive alternating acceptance operator (semantic)

`[definition]` Let `C` range over semantic configurations in normal form N_G. Define the alternating acceptance operator `T`:
```text
C ∈ T(AC)  iff
    ConfigAcc(C)
  ∨ (Existential(C) ∧ ∃C' (YieldE(C;C') ∧ C' ∈ AC))
  ∨ (Universal(C) ∧ ∃C0,C1 (YieldA0(C;C0) ∧ YieldA1(C;C1) ∧ C0 ∈ AC ∧ C1 ∈ AC)).
```

`[deduction]` `T` is monotone in `AC`: `AC` occurs only positively. On the actual finite game `G(n,k)$, each universal phase consumes one comparison, so every play is finite and has length `<=2k+O(1)`. Hence the least fixed point `LFP(T)$ exists and captures sorter-winning configurations:
```text
C ∈ LFP(T) iff C is an accepting alternating configuration of M_G
           iff the G(n,k) position encoded by C is a sorter win.
```
Initial acceptance is:
```text
A(w) accepts iff ∃C (Init(C) ∧ C ∈ LFP(T)).
```

`[deduction]` **No class overclaim.** Although `T$ is positive as an abstract game operator, this does not by itself place `SORT-BOUND-U` in FO(LFP) on the bare ordered word, in P, or in NP/coNP. The reason is the global encoding/capture issue in §5.2–5.3: the LFP is over game configurations, and expressing that LFP as an FO(LFP)/FO(PFP) sentence over `A(w)$ requires the standard global simulation normal form.

### 5.2 Explicit tuple-cell compilation (the normal-form bridge)

`[definition]` A standard tuple-cell compilation of N_G over a domain `W`, `|W|=N$, uses the fact that `Key ⊆ W` and `Ctr ⊆ W`. Since `Pos` already has arity 2 over `Key×Key ⊆ W×W`, and `Used` has arity 1 over `Ctr ⊆ W$, the semantic normal form is already first-order representable with fixed arities over `W$ except for the global alternating acceptance state.

Write the compiled state as
```text
R_Pos(u,v), R_Used(t), R_Sel(a,b), R_Qs(), R_Qa(), R_Qacc(), R_Qrej().
```
The local FO formulas of §4 become FO formulas `Init_R, ConfigAcc_R, YieldE_R, YieldA0_R, YieldA1_R` over `A(w)$ and these relations by replacing `Pos` by `R_Pos`, etc.

`[definition]` **Syntactic acceptance sentence, configuration-as-relations form (explicit schema):**
```text
Φ_game^schema :=
  [PFP_{ACC_R, R_Pos,R_Used,R_Sel,R_Qs,R_Qa,R_Qacc,R_Qrej}
      Δ_accept(ACC_R,R_Pos,R_Used,R_Sel,R_Qs,R_Qa,R_Qacc,R_Qrej)
  ]_init
```
where `Δ_accept` is the global FO operator that, in one stage/normal-form step, updates the encoded accepting-configuration relation according to `Init_R, ConfigAcc_R, YieldE_R, YieldA0_R, YieldA1_R`. The intended initial seed is the encoding of `Init_R`.

`[open, exact]` This schema is **not yet a fully discharged standard FO(PFP) sentence** because FO(PFP) fixed-point variables in the usual syntax are relation variables of fixed arity applied to domain tuples, whereas `ACC_R$ here is intended to range over *acceptance of whole encoded configurations* (i.e., over interpretations of several state relations). Therefore the global instantiation must choose one of the following equivalent standard normal forms and prove the corresponding simulation lemma:

1. **Deterministicization/PSPACE-TM normal form.** Use `APTIME=PSPACE$: from `M_G$ obtain (or appeal to the existence of) a polynomial-space DTM deciding the same language, then instantiate the textbook FO(PFP) capture of that DTM using time/cell tuple indices. *Cost:* explicit connection back to `M_G/G(n,k)$ becomes indirect.
2. **Simultaneous PFP/IFP tuple encoding.** Encode the configuration as a fixed-arity relation `Conf(p̄, ...)$ whose tuple arguments represent a cell index and whose value encodes the cell/control content, and use simultaneous fixed points (or a standard mutual-simulation coding) for `Conf$ and `AccConf$. *Cost:* must supply the full cell-index coding and mutual fixed-point translation.
3. **Stage-indexed ATM acceptance PFP.** Introduce a stage/counter tuple `s̄$ over `W^r` (ordered domain arithmetic), define `AccStage(s̄, ConfCode(...))`, and let PFP compute stages of the alternating backward/forward acceptance operator. *Cost:* must encode configuration codes as tuple arguments and prove the stage correspondence for the alternating `YieldA0/YieldA1$ conjunction.
4. **Inflationary/fixed-point over a configuration universe relation.** Define a relation listing reachable/considered encoded configurations if one can bound them; impossible here in full generality because the configuration space is exponential, so this normal form is rejected.

The project’s closure target needs normal form (2) or (3), or a justified use of (1) with an explicit equivalence proof to `M_G$. None of these has been fully written and proved here.

### 5.3 Most explicit fixed syntactic sentence under normal form (3) (stage-indexed ATM acceptance)

The following is the most explicit fixed syntactic family I can give while keeping the remaining step exact. It is complete as a formula skeleton; the single missing ingredient is the **configuration-code arity/packing lemma** marked `[open:PACK]`.

`[definition]` **Cell code.** Let a configuration code be a tuple
```text
c̄ = (u,v,t,a,b,qS,qA,qAcc,qRej) ∈ W^(9)
```
interpreted relative to boolean/control tags and the following projections:
```text
PosCode(c̄,x,y)  means the poset has edge x<y; in a packed encoding this is represented by
                 storing Pos as a separate relation and letting c̄ carry control+Used+Sel, or by
                 using a standard cell-indexing relation.  [open:PACK]
```
Because `Pos` is binary over `Key×Key$, the natural explicit code is not a single 9-tuple but the relation-valued state
```text
R_Pos(u,v), R_Used(t), R_Sel(a,b), R_Ctrl(q)
```
with `R_Ctrl$ encoding control. The stage-indexed acceptance relation therefore has the form:
```text
ACC(s̄, t, a,b,q ; auxiliary form)   -- schematic; not fully tuple-packed
```
and `[open:PACK]$ is exactly the task of replacing this schematic form by one fixed relation variable of fixed arity over `W$ with a proved encoding/decoding correspondence.

Assuming `[open:PACK]$ supplies a fixed-arity configuration code `Code(C; z̄)$ and decoding formulas `DecodePos, DecodeUsed, DecodeSel, DecodeCtrl$, the explicit stage-indexed FO(PFP) sentence is:
```text
Φ_game :=
  ∃z̄ ( InitCode(z̄) ∧
        [PFP_{ACC(s̄,z̄)}  ψ_ACC(s̄,z̄, ACC)](max̄, z̄) )

InitCode(z̄) :=
  ∃C (Init(C) ∧ Code(C;z̄)).

ψ_ACC(s̄,z̄,ACC) :=
  IsZeroStage(s̄) ∧ AccCode(z̄)
  ∨
  (¬IsZeroStage(s̄) ∧ ∃s̄' (PredStage(s̄',s̄) ∧
      ( AccCode(z̄)
        ∨ (ExistsCode(z̄) ∧ ∃z̄' (YieldECode(z̄,z̄') ∧ ACC(s̄',z̄')))
        ∨ (ForallCode(z̄) ∧ ∃z̄0∃z̄1
              (YieldA0Code(z̄,z̄0) ∧ YieldA1Code(z̄,z̄1)
               ∧ ACC(s̄',z̄0) ∧ ACC(s̄',z̄1)))))).

AccCode(z̄)      := ∃C (Code(C;z̄) ∧ ConfigAcc(C)).
ExistsCode(z̄)   := ∃C (Code(C;z̄) ∧ Existential(C)).
ForallCode(z̄)   := ∃C (Code(C;z̄) ∧ Universal(C)).
YieldECode(z̄,z̄')  := ∃C∃C'(Code(C;z̄)∧Code(C';z̄')∧YieldE(C,C')).
YieldA0Code(z̄,z̄') := ∃C∃C'(Code(C;z̄)∧Code(C';z̄')∧YieldA0(C,C')).
YieldA1Code(z̄,z̄') := ∃C∃C'(Code(C;z̄)∧Code(C';z̄')∧YieldA1(C,C')).
```

`[definition]` Stage arithmetic over the ordered domain (standard): for a chosen fixed `r$, tuples `s̄∈W^r$ are ordered lexicographically by `<$:
```text
IsZeroStage(s̄) := ∀i Min(s̄_i).
MaxStage(s̄)    := ∀i Max(s̄_i).
PredStage(s̄',s̄):= LexSucc(s̄',s̄) or LexPred(s̄,s̄')  (fix one convention; use predecessor)
Lex order and successor/predecessor are FO-definable on every ordered finite structure.
```
The stage bound must be at least the maximum acceptance rank of `M_G$, e.g. `2k+3 <= 2N+3$ phases; choosing `r$ with `N^r >= 2N+3$ (so fixed `r>=2$ suffices for all relevant `N>=2$) gives enough stages.

`[deduction]` If `[open:PACK]$ is discharged, `ψ_ACC$ is a fixed FO formula over `A(w)$ with `ACC$ occurring only positively. Therefore `[PFP_{ACC} ψ_ACC]$ is syntactically well-formed in FO(PFP). (Equivalently, since `ACC$ is positive, the inflationary/least fixed point over stages is available in IFP contexts; the PFP form is stated to match the requested closure path.)

## 6. Simulation lemma (target and proof obligations)

### 6.1 Lemma statement

`[open target, fully explicit statement]` **Global simulation lemma for `M_G` on `A(w)`.** Fix the normal form, `Code/Decode$ from `[open:PACK]$, stage arity `r>=2$, and sentence `Φ_game$ in §5.3. For every `n,k>=0$ and `w=1^n#1^k$:
1. If `Malformed(w)$, then `A(w) ⊭ Φ_SORTU$.
2. If `WellFormed_w$, then `InitCode$ holds for a unique intended initial code `z̄_0$ (up to the chosen encoding equality).
3. If `Code(C;z̄)$ and `Code(C';z̄')$, then `YieldECode/YieldA0Code/YieldA1Code$ hold iff the corresponding `YieldE/YieldA0/YieldA1$ semantic transition holds.
4. For the intended stage bound, `A(w) |= [PFP_{ACC} ψ_ACC](max̄,z̄_0)$ iff the initial semantic configuration of `M_G$ is accepted by the alternating acceptance operator `T$ in §5.1.
5. The initial semantic configuration of `M_G$ is accepted by `T$ iff sorter wins `G(n,k)$ iff `S(n)<=k$.

Consequently `A(w) |= Φ_SORTU$ iff `w ∈ SORT-BOUND-U$.

### 6.2 Proof obligations (minimal remaining work)

`[deduction]` Given §1–4, obligations (1) and (5) are local and discharged at paper level by the existing project definitions plus the local TC/budget lemmas; obligations (2)–(4) are exactly the global instantiation gap.

- **(1)** follows from `Φ_SORTU := WellFormed_w ∧ Φ_game$.
- **(2)** requires defining `Code$ on the empty poset, `Zero$ used marker, sorter/accept initial control, and empty selection.
- **(3)** requires the coding lemma: `Code$ is a faithful encoding of the semantic relations and the FO formulas in §4 are preserved/reflected by `Decode/Encode$.
- **(4)** requires the stage/alternation soundness-completeness proof: `ACC$ at stage successor computes one backward acceptance step of `T$; stages are bounded by the finite rank of the `G(n,k)$ game; PFP reaches that fixed point.
- **(5)** is the `M_G / G(n,k) / S(n)$ correspondence already stated in §2 and supported by `research-certificates-barriers.md`.

The **exact minimal remaining step** is therefore not “use the standard theorem” in the abstract, but:
```text
Discharge [open:PACK] and prove obligations (2)-(4) for the resulting fixed Code/Decode
and ψ_ACC over A(w), using the local FO formulas of §4 as the semantic transition truth
conditions.
```

## 7. Why this is the minimal residual (and not the old blocker)

`[deduction]` The old blocker was: decode arbitrary `Pos$ from a fixed tuple `d̄∈W^r$. That is avoided because `Pos$ is an explicit binary relation in N_G/compiled state; `StepPos$, legality, and budget are explicit FO formulas independent of `AC$. The present blocker is different: **alternating acceptance over relation-valued configurations must be represented as a fixed-arity PFP/IFP over `W$**. This is a genuine global capture instantiation issue (coding a configuration graph into the fixed-point syntax), but it is narrower and fully localized to `[open:PACK]` + obligations (2)–(4).

`[literature]` The existence of *some* FO(PFP) definition follows in principle from Vardi 1982 / Abiteboul–Vianu 1991 and `SORT-BOUND-U ∈ PSPACE` (Claim A). This note does not re-prove that theorem; it supplies all project-specific/local ingredients and identifies the exact remaining coding/proof obligations.

## 8. Falsification targets

1. `Malformed/WellFormed_w$ correctness on edge strings.
2. `StepPos$ TC lemma, especially incomparability precondition and absence of reflexive/transitive glitches.
3. `YieldE$ selects only incomparable pairs and preserves `Pos,Used$.
4. `YieldA0/YieldA1$ are exactly the two adversary outcomes for the selected pair.
5. Budget `<=k$: `HasBudget$ gates, `SuccCtr$ increments, `PostBudget$ accepts on totality and rejects exhausted non-total states.
6. Boundary cases: `n<=1$, `k=0$, totality at `MaxK$, `Zero=Hash$ not used as a key.
7. Any chosen `Code/Decode$ must preserve and reflect all local formulas.
8. Stage bound `r>=2$ (or chosen `r$) must cover acceptance rank `O(k)=O(N)$.
9. No claim is promoted to `P$, `FO(LFP)$ on the bare word, `NP$, or `coNP$.
