## Front and claim attacked

FRONT: can Sergeev-style group insertion be compiled into a polynomial-size
permutation-framed DAG (scripts/check_framed_strategy.py grammar, antichain root)
whose height equals S(n) for all n? FALSIFIER has two disjuncts:
 (F1) superpolynomial size for any framed-DAG representation of Sergeev's group
      insertion, or
 (F2) its exact height formula strictly exceeds S(n) for infinitely many n.
Stated implication: positive compilation => SORT-BOUND-U in NP.

I attacked the positive claim P ("for all n, poly-size sound framed DAG of height
exactly S(n), obtained from Sergeev's group insertion") and both disjuncts of the
falsifier. Result: P is neither proved nor disproved; FJ's no-go method does NOT
transfer, and each falsifier route is blocked by a separate open problem.

## Primary source studied
Sergeev, ECCC TR20-096, "On the asymptotic complexity of sorting" (31 pp,
downloaded and read locally). Theorem 3 (p.29): S(n) = log2(n!) + O(n log^{-1/5} n).
Algorithm: pair-sort n/2 + S(n/2); FJ-insert n0 = n/log n alphas (n+O(n0)
comparisons); split the rest into groups of size m ~ sqrt(n)/log n; insert group k
into an interval of length L_k = 2(n0 + k m) - m via Corollary 2 (group insertion
with a comparison strategy of depth h = 2^{s+3}, width w <= s+4, containers of
capacity 2 attributed to intervals). Recurrence s(n) <= s(n/2) + O(n log^{-1/5} n).
The container count obeys c_{dl+i} <= (dl+i) 2^{(dl+i)(h+1)}; h grows with s,
and s must grow to reach log^{-1/5} n. There is NO explicit constant in the O(.).

## D1. Model-fidelity correction (deduction)
A correct sorter always has comparison count C_A(n) >= S(n). Sergeev's theorem
gives C_A(n) = log2(n!) + o(n), an UPPER bound with non-effective constant; it
gives no lower bound on C_A(n) - log2(n!). Hence:
 - Even a successful framing of Sergeev's algorithm has height C_A(n) >= S(n)
   with C_A(n) - log2(n!) = o(n). It is an NP witness for 1^n#1^k only when
   C_A(n) <= k. For the tight yes-instance k = S(n) this needs C_A(n) = S(n).
 - Therefore the front's complexity implication holds ONLY for EXACT height
   S(n). An o(n)-surplus compilation (C_A(n) > S(n)) does not give
   SORT-BOUND-U in NP. Sergeev's asymptotic algorithm does not by itself supply
   the required exact-height witness. This gap was blurred in earlier fronts.

## D2. The FJ no-go method does not transfer (deduction)
The #301 post fj-exact-barrier-20261124 (2026-11-24T06:36Z) proved
F_FJ(n) - log2(n!) >= 0.01 n for n >= 2048 (explicit linear surplus), so
F_FJ(n) - S(n) = Theta(n) - o(n) -> +infinity. That deduction needs an explicit
surplus LOWER bound on the architecture's height. Sergeev's Theorem 3 supplies
only an upper bound O(n log^{-1/5} n) with unspecified constant: from it one
cannot derive C_A(n) - log2(n!) >= g(n) for any g -> infinity. So the FJ
"height exceeds S(n) eventually" deduction has no analogue here.

## D3. F2 reduces to TWO open problems (deduction)
To prove F2 (C_A(n) > S(n) infinitely often) one needs simultaneously:
 (a) an explicit surplus lower bound C_A(n) >= log2(n!) + g(n), g computable;
 (b) an explicit surplus upper bound S(n) <= log2(n!) + G(n), G computable,
     with g(n) > G(n) infinitely often.
(a) is not in the paper (only O(.) upper bound). (b) is the "effective finite
Sergeev bound" problem, previously blocked (ledger front
sergeev-effective-finite-bound, clearexit). Even granting C_A(n) >= log2(n!)+1
for all large n, F2 would additionally require S(n) = ceil(log2 n!) infinitely
often, which is OPEN (#301 surplus-eventual-flatness-alln: surplus in {0,1} only
through n=22; S(23+) and the surplus-1 density are open). So F2 is a reduction
to open questions about S, not a derivable consequence of Sergeev's theorem.

## D4. F1 is beyond counting and is the general open problem (deduction)
A framed DAG's per-edge permutations encode n! input orders in poly size: the
checker accepts a 19-node, depth-13 certificate for n=7 funnelling all 5040
paths into one leaf (board front framed-optimal-height-polysize-existence).
Thus leaf/path/per-level node-count invariants cannot prove superpolynomial
size; each input corresponds to a distinct composed frame sigma with
sigma(pi)=sorted, and (2V)^{S(n)} >> n! frame products exist. Moreover
SORT-BOUND-U is a tally language in P/poly, so circuit lower bounds cannot
apply (sparsity barrier, problem.md / Mahaney). F1 is therefore at least as hard
as the general all-n exact-height framed-DAG completeness question, which is
open. The "coupled containers vs local rank-envelope joins" obstruction is the
best structural candidate but remains a plausibility argument: the only
concrete counterexample attempted on #301 was RETRACTED (both framed branches
retained the same relation at the meet; the abstract orders were not shown to
occur in Sergeev's section 6), and the join information condition
e(P intersect Q) <= 2^{k-d} is necessary but sufficiency is open with no
reachable counterexample found for n <= 5/6 (fronts framed-join-info-condition-
sufficiency, sergeev-group-framed-dag).

## Conclusion
The front stays OPEN. Honest limits: no all-n theorem, no explicit constant, no
reachable join counterexample, no Lean formalization. The productive next step
is NOT a counting lower bound (ruled out) but either (i) an effective finite
Sergeev surplus bound plus an explicit surplus lower bound for a fixed schedule,
or (ii) a reachable information-gap join witness extending the n<=5/6 checks.
Neither is achieved here. General-poset hardness and certificate soundness are
kept distinct from completeness throughout.
