## 1. `[open:PACK-REPR]` counting falsifier (`A001035(n)` vs `W^r`)

**Claim audited:** for fixed `r >= 1`, no faithful total `Code/Decode` from all valid `N_G` configurations to `W^r` exists, because valid poset states number `A001035(n)=2^{Θ(n^2)}` while `|W|^r = (n+k+1)^r = N^r`.

**Check:**
- `A001035(n)` is the number of labelled partial orders/posets on `n` elements; `research-certificates-barriers.md` §5 confirms the DP/minimax state counts match `1,3,19,219,4231,130023,...` (OEIS A001035) and cites Kleitman–Rothschild `2^{Θ(n^2)}`. **Consistent.**
- `W = {1,...,N}`, `N = n+k+1 = |w|`, so `|W^r| = N^r`. **Correct.**
- The artifact sets `k=n` for the falsifier, giving `N=2n+1`; for fixed `r`, `A001035(n) > (2n+1)^r` for sufficiently large `n`. This is a valid pigeonhole/counting argument. **Sound as an asymptotic falsifier.**
- The constructed family `C_P = (Pos_P, Used_0, Sel_∅, Ctrl_Sort)` uses valid strict partial orders at initial used budget. `ValidPos` requires domain restriction to keys, irreflexivity, transitivity — all satisfied by a strict poset relation restricted to keys. `ExactlyOneUsed` with `Zero`/hash encoding is plausible given §1/§2's intended coding, though the exact `Zero`-position convention must match the final fixed encoding. **Minor encoding-dependence only; does not affect the counting obstruction.**
- The artifact notes non-total vs total control (`QAcc` when total) parenthetically; this does not reduce the family below `2^{Θ(n^2)}` because only one poset is total up to the linear extension detail? More carefully: there are `n!` total orders but `A001035(n)-?` still includes exponentially many non-total posets; the obstruction remains overwhelming. **Falsifier remains valid.**

**Issue noted (non-fatal):** The falsifier states "no function from these valid configurations into `W^r` is injective" — correct. It then concludes no faithful `Code/Decode` for obligations (2)-(4). This is right for *total* representation of all valid/poset states, but a restricted representation could still be possible if one proves reachability/acceptance relevance. The artifact explicitly flags this as an undischarged restriction (§4.4), which is the right residual.

**Verdict:** `[open:PACK-REPR]` total form is **correctly falsified** by the counting argument. The magnitude and source (`A001035`, Kleitman–Rothschild) align with repository literature.
