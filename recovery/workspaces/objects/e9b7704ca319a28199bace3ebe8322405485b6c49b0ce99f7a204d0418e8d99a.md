## 1. Whole-configuration state used by the measure

`[definition]` Let `w=1^n#1^k` be well-formed, `N=n+k+1`, and let
`E=E(\bar R)` be an `I_{M_D}`-reachable encoded DTM configuration for
`δ_{M_D^alt}^{sch}` with `¬HaltAcc(E) ∧ ¬HaltRej(E)`.

By `I_{M_D}` (SYM, preserved by `[SYM-TOP]` and realization Corollary 4.2):
- `ExactlyOneTop`: a unique `Top` frame `c`.
- `ExactlyOneMode`: every live frame is exactly one of
  `M_Eval,M_BackE,M_BackA0,M_BackA1`.
- `Parent` is functional on active non-root frames, giving a unique
  root-to-top path.
- `UsedF` is functional on live frames and ranges over `Ctr={0,...,k}`.
- `HasSel/SelA/SelB`, `HasCur/CurA/CurB`, `RetNone/RetAcc/RetRej`,
  and stored `Ctrl*/PosF` fields are coherent as required by the schema.

Let the unique active stack path be
```text
P(E) = (F_0, F_1, ..., F_d),   F_0 = root, F_d = Top(E),  0 <= d <= 2k+1.
```
The depth bound `d <= 2k+1` is the realization's DFS/space consequence
(Theorem 5.1): only `PushChildA` applies `SuccCtr`; `PushChildE` copies
`UsedF`; `UsedF` ranges over `Ctr`; A1 is pushed only after A0 returns to the
same `BackA0` snapshot; the DFS discipline keeps one active root-to-top path.

For frame `F_i` on `P(E)`, `b(F_i)` is the unique value with
`UsedF(F_i,b(F_i))`.

## 2. Explicit existential cursor rank

`[definition]` Fix `D_lex = Key×Key`, `|D_lex|=n^2 <= N^2`. Let `idx(p)` be
the 1-based position of `p` in the fixed `Lex2` enumeration of `D_lex`,
extended by `idx(exh)=n^2+1` for the `NoNextIncomp_c` exhaustion state. Set
```text
L       := n^2 + 1,
rlex(p) := L - idx(p) in {0,...,n^2}.
```
`rlex(exh)=0`; for a valid cursor position, `rlex > 0` unless it is the last
enumeration point, and in all cases `rlex` is finite.

`[deduction]` `NextIncomp_c(curA,curB;x,y)` returns the lex-minimal
incomparable pair `(x,y)` at or after the cursor (unique by `I_{M_D}` and the
lex-minimality clause). `D_sort_pick` and `D_backE_rej_next` pass that
candidate to `PushChildE` and advance the parent cursor by `SuccLex2(x,y)`.
Thus the advanced cursor position is strictly after `(x,y)`'s consumed
selection point, and
```text
rlex(SuccLex2(x,y)) <= L - (idx(x,y)+1) < L - idx(x,y) <= rlex(curA,curB)
```
(with the `NoNextIncomp` boundary represented as `rlex=0` when exhaustion is
reached). No hidden DFS search order is used.

## 3. Explicit per-frame rank (whole-config / Cphase)

`[definition]` For each active frame `F` on a non-halting
`I_{M_D}`-reachable path, define
```text
V(F) := ( bcost(F),  q(F),  ex(F),  ph(F) )
      in B := {0,...,k} × {0,1,2} × {0,...,L} × {0,...,6},
```
with lexicographic order. Components:

- `bcost(F) := k - b(F)` (remaining `Ctr` capacity; whole-config budget
  component).
- `q(F) ∈ {0,1,2}`: pending adversary outcomes represented at `F`
  (`2` for `CtrlAdv` and `BackA0,RetNone`; `1` for `BackA0,RetAcc`; `0`
  otherwise).
- `ex(F)`: existential cursor rank — `rlex(CurA,CurB)` or the advanced/stored
  cursor for BackE/CtrlSort states, `0` otherwise.
- `ph(F)`: fixed finite control phase.

Complete table for every non-halting `I_{M_D}`-reachable active stack frame
(the `Cphase`/mode/return obligation is explicit and total):

| Reachable frame state | `q` | `ex` | `ph` |
|---|---:|---:|---:|
| `M_Eval,RetNone,CtrlSort,¬Total,Budget,NextIncomp` | 0 | `rlex(Cur)` | 6 |
| `M_Eval,RetNone,CtrlAdv,HasSel` | 2 | 0 | 3 |
| `M_BackA0,RetNone` waiting below A0 | 2 | 0 | 2 |
| `M_BackA0,RetAcc` A1 pending, same snapshot | 1 | 0 | 1 |
| `M_BackA0,RetRej` returnable | 0 | 0 | 0 |
| `M_BackA1,RetNone` waiting below A1 | 0 | 0 | 2 |
| `M_BackA1,RetAcc/RetRej` returnable | 0 | 0 | 0 |
| `M_BackE,RetNone` waiting below E-child (advanced cursor stored) | 0 | `rlex(Cur')` | 4 |
| `M_BackE,RetRej,NextIncomp` retry pending | 0 | `rlex(Cur)` | 3 |
| `M_BackE,RetRej,NoNextIncomp` | 0 | 0 | 0 |
| `M_BackE,RetAcc` | 0 | 0 | 0 |
| `M_Eval,RetNone` non-root returnable terminal (`CtrlAcc∨Total∨RejectEval`) | 0 | 0 | 0 |

**Completeness.** Root terminal eval states take `D_root_acc/D_root_rej` and
are outside the non-halting domain. A `CtrlSort` non-terminal state without
`NextIncomp_c` satisfies `RejectEval_c` and takes a reject/halt case (A7), so
it is a returnable terminal, not `ph=6`. `CtrlAdv` requires `HasSel` by
`I_{M_D}`/schema. Backtrack frames have `RetNone` only while waiting below
their active child and `RetAcc/RetRej` only after a popped child writes the
marker (A1--A3,A6). All other mode/control/return combinations are excluded
by `I_{M_D}` coherence.

## 4. Global well-founded measure

`[definition]` Let
```text
Ω := ⋃_{d=0}^{2k+1} B^(d+1),
μ(E) := (V(F_0), ..., V(F_d)) for P(E)=(F_0,...,F_d),
```
with root-to-top lexicographic order `<_bf`: first index `i` with
`V(F_i) != V'(F_i)` decides by the lex order on `B`.

`[deduction]` `B` is finite; `d <= 2k+1`; therefore `<_bf` is well-founded on
`Ω`.

## 5. Local transition obligations (stated facts only)

`[deduction]`

A1. `PushChildA` (`D_adv_push_A0`, `D_backA0_acc_A1`) sets
`UsedF' = SuccCtr(UsedF(parent))`, so `b(child)=b(parent)+1`,
`bcost(child)=bcost(parent)-1`. `PushChildE` copies `UsedF`.
A2. `PushChildA` children are `M_Eval,RetNone,Ctrl in {Acc,Sort,Rej}` by
`PostBudgetFrom`, never `CtrlAdv`; thus `q(child)=0`.
A3. `PushChildE` children are `M_Eval,RetNone,CtrlAdv,HasSel`, with copied
`PosF/UsedF`; thus `V(child)=(k-b,2,0,3)`.
A4. `D_sort_pick`/`D_backE_rej_next` use `NextIncomp_c` and `SuccLex2`,
store `M_BackE,RetNone` with advanced cursor: `ex` strictly decreases
(§2).
A5. A0/A1 same snapshot: `D_backA0_acc_A1` preserves
`Sel/PosF/UsedF/Cur` of the same `BackA0` parent and pushes A1 with
`StepPosBit(parent,b,a)` and `SuccCtr(UsedF(parent))`.
A6. Return-pop cases remove `Top=F_d` and apply `MarkRetAccOn/MarkRetRejOn`
to the unique `Parent(F_d)=F_{d-1}` (`Parent` functional by `I_{M_D}`),
preserving lower stack except the designated parent marker/mode.
A7. Reject/exhaust: budget-exhausted/non-total, `CtrlRej`, and
`NoNextIncomp_c` after search take reject/halt/exhaust cases, never pushes.
A8. `I_{M_D}` uniqueness gives unique `Top`, unique `Parent` on the active
non-root path, unique mode, unique `UsedF`, and coherent cursor/selection/
return markers.

`D_backE_acc_root`, `D_backE_rej_exh_root`, `D_backA0_rej_root`,

pushed A-children); `ex` decreases whenever a sort/exhaustion cursor is
advanced (A4,§2); `q`/`ph` track the finite A0/A1/E obligations and return
consumption (A1--A6); lower frames are preserved except the designated
return marker (A6,A8). Therefore $\mu(E') <_bf \mu(E)$. ∎

## 8. Halting consequence (closes `[CKS-AV-MDALT-HALT]`)

`[deduction]` **Corollary 1 (halting).** For well-formed $w=1^n#1^k$, every
`I_{M_D}`-reachable non-halting configuration has a `δ_{M_D^alt}^{sch}`
successor with strictly smaller `μ \in Ω`, and `<_bf` is well-founded on
`Ω`. Therefore no infinite `δ_{M_D^alt}^{sch}` computation exists from an
`I_{M_D}`-reachable state, and every run from $Init_{M_D}^{sym}$ reaches
`HaltAcc` or `HaltRej`.

This supplies the explicit well-founded whole-config measure, explicit
$Sphase$/cursor rank (`ex` via `NextIncomp_c/SuccLex2`), explicit stack
obligations for `M_Eval/CtrlSort`, `M_Eval/CtrlAdv`, `M_BackE`, `M_BackA0`,
`M_BackA1`, explicit finite `Cphase`/`ph,q` order, and a case-by-case
decrease proof preserving $I_{M_D}$, using only stated facts.
