`[open, single minimal failing subformula/lemma]` The construction is **not** presented as a complete line-by-line discharged fixed FO(PFP) proof from first principles. The single minimal failing lemma is:

Under `[open:CKS-AV-Δ_D]`, the remaining Vardi/AV acceptance fixed-point and equivalence obligations (2)–(4)/(iv)–(v) are discharged by the standard construction (§6).

This is narrower than “no sentence”: the tape layout, local semantics, control-state table, and fixed-point form are explicit. The residual is the full case analysis of the **stack machine** `M_D^alt` at symbol/tuple level.

A001035 is avoided: `W^r` codes tape cells (`N^r` addresses) and a *current* frame's `Pos` is stored as cell content; no relation names all `A001035(n)` posets.

## 1. Fixed ordered input and address space

`[definition]` Input word `w=1^n # 1^k`, `N=|w|=n+k+1`, structure
```text
A(w) = (W, <, One, Hash),   W={1,...,N}.
```
FO-definable: `Succ, Min, Max, HashPos, WellFormed_w, Malformed, Key, Ctr, Zero, MaxK, SuccCtr, HasBudget, KeyNe, Lex2, LexTuple_r`, exactly as in the prior artifact (§1). `|Key|=n`, `|Ctr|=k+1`.

`[definition]` Fix arity `r := 4` (any fixed `r >= 4` suffices for the bounds below). Tape/address space:
```text
Cell := W^r,   |Cell| = N^r.
```
Lex order `<_lex` on `Cell` and `SuccCell(c̄,d̄)` are FO-definable from `<`. `ZeroCell` / `MaxCell` are the lex endpoints. `AddConst_c(c̄,d̄)` / `Offset_c(c̄,d̄)` for every fixed constant `c` are FO-definable by bounded successor chains.

`[deduction]` `M_D^alt` uses `O(N^3)` space (§6.3 of prior artifact). For fixed ``r>=4` and all sufficiently relevant `N`, `N^r` exceeds the required tape length by a polynomial margin; the FO transition may treat cells beyond the used prefix as blank/forbidden by a fixed FO boundary `UsedCell(c̄)`. Using a fixed `r` independent of ``N` is the standard Vardi/AV/Immerman polynomial-space addressing trick and does **not** enumerate all `Pos` states.

## 2. Tape alphabet, frame layout, and configuration relations

### 2.1 Finite tape alphabet

`[definition]` Finite alphabet `Γ` (fixed, independent of `n,k`):
```text
Γ = { B, 0, 1,                              -- blank, bits
      S, E,                                   -- frame start/end markers
      M_EVAL, M_BACK_E, M_BACK_A0, M_BACK_A1, -- DFS modes
      M_RET_ACC, M_RET_REJ, M_HALT_ACC, M_HALT_REJ,
      Q_SORT, Q_ADV, Q_ACC, Q_REJ,            -- encoded Ctrl tags
      SEP }.
```
(Equivalent fixed codings by bit blocks are acceptable; the symbol-level formulas below use FO predicates/rules over a fixed finite set of cell roles.)

### 2.2 Frame layout

`[definition]` A frame is a fixed-order record stored on consecutive `Cell` addresses inside a delimited stack region. Conceptually:
```text
S  mode  ctrl  used  sel_a sel_b  cursor_a cursor_b  child  pos_matrix  E
```
with fields:
- `mode ∈ {M_EVAL,M_BACK_E,M_BACK_A0,M_BACK_A1,M_RET_ACC,M_RET_REJ,M_HALT_*}`: one fixed symbol/cell.
- `ctrl ∈ {Q_SORT,Q_ADV,Q_ACC,Q_REJ}`: encoded `Ctrl` of the current ``N_G` state.
- `used`: a `Ctr` value encoded by one tape cell carrying a domain value index (or by a unary/binary marker over a fixed `Ctr`-sized subblock). Using the ordered domain, store the unique `t∈`Ctr` with `Used(t)` as the index `t` in a fixed field.
- `sel_a, sel_b`: either a special empty marker or two ``Key` values `(a,b)$.
- `cursor_a,cursor_b`: current lex cursor in `Key×`Key` for existential enumeration.
- `child`: one-bit/marker field for universal sequencing (`0` = ``C0` pending/done status as encoded by mode, `1` = evaluating ``C1`).
- `pos_matrix`: an `n×n$ bit block indexed by `(u,v)∈Key×`Key` in lex order, storing the **current transitive-closure** relation `Pos(u,v)$ as `1/0`.

`[deduction]` The ``Pos` block stores the *current frame's* closure (one state), not names for all posets. Its size is `n^2 <= N^2$ bits plus ``O(log N)` metadata, polynomial in `N`. The DFS stack has depth `<=2k+1 <= 2N+1$, so total tape use is ``O(N^3)` cells, addressable by fixed `r=4`.

### 2.3 Configuration relations (fixed arity)

`[definition]` Standard DTM configuration relations over `Cell=`W^r`:
```text
H(c̄)                     -- head is at cell c̄
Blnk(c̄)                  -- cell c̄ is blank (optional; or a symbol relation)
Sym_σ(c̄)  for each σ∈Γ -- cell c̄ contains symbol/role σ (finite family)
Val(c̄,x)                 -- optional: cell c̄ stores domain value x∈W (for used/sel/cursor)
PosBit(c̄,u,v)            -- cell block at/for frame contains Pos bit for (u,v)∈Key^2
Top(c̄)                   -- c̄ is the start of the current top frame
Frame(c̄)                 -- c̄ belongs to the active stack region
State_q                  -- global finite control state q of M_D^alt (0-ary/finite family)
```
The final symbol-level sentence uses a fixed finite subset/encoding of these (e.g. one relation `T(c̄,s̄)$ packing a finite symbol code `s̄$ in `W^p$ or finitely many unary-in-cell predicates). All arities are fixed.

`[falsification]` Do **not** add a relation `NamePos(d̄,u,v)$ meaning “tuple name ``d̄` codes global poset having edge `(u,v)$”. That would reintroduce total poset tuple-coding and is blocked by A001035.

## 3. Initial tape formula `Init_{M_D}`

`[definition]` ``Init_{M_D}` is a first-order sentence/formula over `A(w)` and the configuration relations asserting:
```text
Init_{M_D} :=
  WellFormed_w
  ∧ State_{q0}
  ∧ ∃c̄ (Top(c̄) ∧ ZeroCell(c̄) ∧ H(c̄))
  ∧ one well-delimited initial frame at the stack bottom encoding Init_{N_G}:
      mode = M_EVAL,
      ctrl = Q_ACC if Total(empty_n) else Q_SORT,
      used = Zero (the Hash/Ctr zero),
      sel_a,sel_b empty,
      cursor_a,cursor_b = MinKey,MinKey (lex first pair),
      child = 0,
      PosBit(c̄,u,v) false for all Key(u),Key(v),
  ∧ every cell outside that frame is blank.
```

`[deduction]` **(2) Initial configuration.** ``Init_{M_D}` encodes exactly the semantic initial ``N_G` configuration ``C0` from CKS/AV §3.2: antichain ``Pos`, `Used=`Zero`, no selection, and `Q_AC`C` iff ``n<=1` else `Q_SORT`. The encoding is FO because `Key,Ctr,Zero,Total(empty_n)$ are FO over `A(w)` and the frame occupies a FO-definable initial block of `Cell$.

## 4. FO evaluation of local `M_G` formulas on the encoded frame

This section discharges the *local semantic* content of obligations (ii), (iii), (2), (3) at tape level: every local move used by `M_D^alt` is computed by FO tests/updates from the current frame.

Let ``F` abbreviate “the current top frame fields accessible from `Top(c̄)$”. Define FO predicates over `A(w)` plus the current frame's encoded fields:

```text
FramePos_F(u,v)      := Key(u)∧Key(v) ∧ PosBit field of F has 1 at (u,v).
FrameUsed_F(t)       := Ctr(t) ∧ used field of F stores t.
FrameSel_F(a,b)      := Key(a)∧Key(b) ∧ sel fields store (a,b) (and non-empty).
FrameCtrlSort_F      := ctrl field = Q_SORT    (similarly Adv/Acc/Rej).

ValidPos_F := ∀u∀v(FramePos_F(u,v)->KeyNe(u,v))
            ∧ ∀x ¬FramePos_F(x,x)
            ∧ ∀x∀y∀z((FramePos_F(x,y)∧FramePos_F(y,z))->FramePos_F(x,z)).
            (The stored matrix is intended to be the closure; validity is an invariant.)

Incomp_F(x,y) := KeyNe(x,y) ∧ ¬FramePos_F(x,y) ∧ ¬FramePos_F(y,x).
Total_F       := ∀x∀y((Key(x)∧Key(y)∧x!=y)->(FramePos_F(x,y)∨FramePos_F(y,x))).
HasBudget_F   := ∃t∃s(FrameUsed_F(t)∧SuccCtr(t,s)).
ConfigAcc_F   := FrameCtrlAcc_F ∨ Total_F.
ConfigRej_F   := FrameCtrlRej_F.
```

### 4.1 Incremental closure update

`[definition]`
```text
StepPosBit_F(x,y;u,v) := FramePos_F(u,v)
                      ∨ ((u=x ∨ FramePos_F(u,x)) ∧ (v=y ∨ FramePos_F(y,v))).
```
`[deduction]` **(ii, local).** ``StepPosBit_F` is first-order in `u,v$ with parameters `x,y$ and access to the current ``Pos` bits. By the incremental TC lemma (prior artifact §3.3; standard): if ``FramePos_F` is a transitive closure and `Incomp_F(x,y)$, then `StepPosBit_F(x,y;·,·)$ is the transitive closure of `FramePos_F ∪ {(x,y)}$ and is a strict partial order.

### 4.2 Post-budget/control resolution

`[definition]`
```text
PostBudget_F(P',U') :=   (Total(P') ∧ Acc)
                       ∨ (¬Total(P') ∧ HasBudget(U') ∧ Sort)
                       ∨ (¬Total(P') ∧ ¬HasBudget(U') ∧ Rej),
```
instantiated by reading `P'$ as either ``FramePos_F` or the bitwise result of ``StepPosBit_F`, and `U'$ as `FrameUsed_`F` or its `Succ`Ctr` advancement.

### 4.3 Local yield tests and child-frame construction

`[definition]` For fixed current frame ``F`:
```text
YieldE_F(a,b) :=
  FrameCtrlSort_F ∧ ¬Total_F ∧ HasBudget_F
  ∧ Incomp_F(a,b).
ChildE_F(a,b) sets: Pos'=FramePos_F, Used'=FrameUsed_F, Sel'=(a,b), Ctrl'=Q_ADV.

YieldA0_F(a,b) :=
  FrameCtrlAdv_F ∧ FrameSel_F(a,b) ∧ Incomp_F(a,b).
ChildA0_F(a,b) sets: Pos'(u,v):=StepPosBit_F(a,b;u,v),
                      Used':=SuccCtr(FrameUsed_F), Sel' empty,
                      Ctrl'/halt by PostBudget_F(Pos',Used').

YieldA1_F(a,b) := same with StepPosBit_F(b,a;u,v).
```
`[deduction]` **(ii),(iii),(3) local/semantic.** These are exactly the prior CKS/AV local formulas evaluated on the encoded closure matrix of the current frame. Preservation/reflection follow as in prior §4: ``YieldE` preserves `Pos/Used$ and moves to an adversary phase with the selected incomparable pair; ``YieldA0/A1` apply incremental closure, consume one `Succ`Ctr` budget step, clear selection, and resolve by `PostBudget`. No `G(n,k)` rule is altered.

## 5. One-step transition `Δ_{M_D}` (symbol-level DFS control)

`[definition]` The FO(PFP) capture uses a one-step configuration update. For a deterministic TM, `Δ_{M_D}` is a first-order formula over current-configuration relations and next-configuration relations (`H', Sym'_σ, Val', PosBit', State'_q, Top', ...`) asserting that the next configuration is the unique result of applying `M_D^alt`'s transition function.

`[deduction]` The global finite control of `M_D^alt` is a fixed deterministic table over the finite mode alphabet and a finite set of FO-test outcomes. The transition is a finite disjunction of cases:
```text
Δ_{M_D}(Conf;Conf') :=  Δ_halt ∨ Δ_eval_acc ∨ Δ_eval_rej
                       ∨ Δ_sort_pick ∨ Δ_sort_fail
                       ∨ Δ_sort_child_ret
                       ∨ Δ_adv_eval_A0 ∨ Δ_adv_A0_to_A1
                       ∨ Δ_adv_A1_ret
                       ∨ Δ_pop/propagate.
```

### 5.1 Terminal/control cases (explicit)

```text
Δ_halt := (State_{M_HALT_ACC} ∨ State_{M_HALT_REJ}) ∧ Conf'=Conf.

Δ_eval_acc := State normal ∧ mode(Top)=M_EVAL ∧ ConfigAcc_F
            ∧ write return-accept to current frame / set halt state as appropriate.

Δ_eval_rej := State normal ∧ mode(Top)=M_EVAL ∧ (ConfigRej_F ∨
              (FrameCtrlSort_F ∧ ¬Total_F ∧ ¬HasBudget_F ∨ no remaining cursor pair))
            ∧ write return-reject / halt-reject as appropriate.
```
The exact return propagation depends on whether `Top` is the root frame (then global `M_HALT_ACC/REJ`) or a child frame (then parent mode becomes `M_BACK_E` / `M_BACK_A0` / `M_BACK_A1` with recorded child result). This is the stack discipline referenced in `[open:CKS-AV-Δ_D]`.

### 5.2 Existential sorter cases (explicit local semantics)

```text
Δ_sort_pick :=
  mode(Top)=M_EVAL ∧ FrameCtrlSort_F ∧ ¬Total_F ∧ HasBudget_F
  ∧ let (a,b) be the first pair at/after cursor with Incomp_F(a,b) in Lex2 order:
      push a new child frame ChildE_F(a,b) above Top, set Top' to child,
      set parent mode/cursor to M_BACK_E with cursor advanced past (a,b),
      preserve lower stack.
```
The existence/uniqueness of the next lex-incomparable pair is FO-definable:
```text
NextIncomp_F(ca,cb;a,b) := Lex2(ca,cb,a,b) ∧ Incomp_F(a,b)
  ∧ ¬∃x∃y(Lex2(ca,cb,x,y) ∧ Lex2(x,y,a,b) ∧ Incomp_F(x,y)).
```
Pushing `ChildE_F(a,b)$ copies `Pos'/`Used'` from ``F` (FO bitwise identity over the ``n^2` block addresses indexed by `Key×`Key`) and writes `Sel'=(a,b), Ctrl'=Q_ADV$.

`Δ_sort_child_ret$ inspects a returned child under ``M_BACK_E`: accept => propagate accept; reject => resume `Δ_sort_pick$ logic from advanced cursor.

### 5.3 Universal adversary cases (explicit local semantics)

```text
Δ_adv_eval_A0 :=
  mode(Top)=M_EVAL ∧ FrameCtrlAdv_F ∧ FrameSel_F(a,b)
  ∧ push ChildA0_F(a,b) with parent set to M_BACK_A0.

Δ_adv_A0_to_A1 :=
  mode(Top)=M_BACK_A0 ∧ child result accept
  ∧ push ChildA1_F(a,b) with parent set to M_BACK_A1.

Δ_adv_A1_ret :=
  mode(Top)=M_BACK_A1 ∧ propagate child result (accept only if A1 accepted;
  A0 reject already propagated at M_BACK_A0).
```
Pushing `ChildA0/A1$ computes ``Pos'` by ``StepPosBit_F` (FO, §4.1), computes ``Used'` by the unique `Succ`Ctr` successor (FO), clears `Sel$, and sets `Ctrl'/mode by `PostBudget$.

### 5.4 Why this is the minimal residual

`[deduction]` Every local mathematical ingredient used above is explicit and FO over the fixed signature plus current frame contents: lex enumeration, incomparability lookup in a stored closure matrix, `StepPosBit$ update, `Succ`Ctr`, and `PostBudget`. The remaining work in `Δ_{M_D}` is not local game semantics but **deterministic stack bookkeeping** on a ``W^r`-addressed tape: address the current frame boundary, allocate the next frame at a fixed offset or at `Top'$ computed from frame size, copy/initialize fields, restore `Top` on pop, and route return values by mode. In standard DTM-to-FO(PFP) constructions this bookkeeping is routine because the tape/head/state transition is a fixed finite function; here the “machine” was specified semantically as `M_D^alt` in the prior artifact. Therefore the minimal failing lemma is the complete, functional, case-closed FO stack transition:

```text
[open:CKS-AV-Δ_D]  complete FO Δ_{M_D} for the full DFS stack discipline of M_D^alt,
with totality/functionality/well-formedness preservation/no-spurious-transition proofs.
```

This is a stronger, more localized statement than `[open:CKS-AV-FORMULA]`: it assumes §§1–4 and isolates only the symbol-level stack/control closure of `M_D^alt`.

## 6. FO(PFP) halting/acceptance fixed point and equivalences

### 6.1 Fixed point form

`[definition,literature]` Under the standard Vardi/Immerman/AV construction, a polynomial-space DTM on an ordered finite structure is captured by an FO(PFP) formula over fixed-arity configuration relations. With a deterministic one-step `Δ_{M_D}`, acceptance can be expressed as a partial/fixed-point reachability/halting condition. Concretely (schema):
```text
ACC(Conf) := Conf is a halting accepting configuration of M_D^alt
           ∨ ∃Conf'(Δ_{M_D}(Conf;Conf') ∧ ACC(Conf')).

Φ_{M_D} := ∃Conf0 (Init_{M_D}(Conf0) ∧ [PFP_{ACC} ψ_ACC](Conf0)).
```
Equivalently an inflationary/IFP form on ordered structures may be used in standard presentations. The exact standard normal form (single PFP over a configuration relation, or simultaneous/stage form) is part of the captured construction; the configuration relations remain fixed-arity over `Cell=`W^r`.

`[deduction]` This normal form does **not** place the property in `FO(LFP) on the bare ordered word and does **not** imply `P`, `NP`, or `coNP`: FO(PFP) capture of PSPACE is used as the descriptive-complexity target, consistent with `SORT-BOUND-U ∈ PSPACE`.

### 6.3 Equivalence chain

`[deduction,literature]` Assuming `[open:CKS-AV-Δ_D] and the standard soundness/completeness of the FO(PFP) DTM-capture fixed point for the resulting deterministic `Δ_{M_D}` on ordered `A(w)`:
```text
A(w) |= WellFormed_w ∧ Φ_{M_D}
  iff  Init_{M_D}(Conf0) and ACC(Conf0) in the PFP semantics
  iff  M_D^alt accepts w
  iff  the alternating DFS evaluation accepts the initial M_G/G(n,k) state
  iff  sorter wins G(n,k)
  iff  S(n) <= k
  iff  w ∈ SORT-BOUND-U.
```
The first equivalence is the FO(PFP) construction; the second is the `Δ_{M_D}` transition correctness; the third/fourth use the local yield/reflection lemmas and `M_D^alt` correctness (prior §§4–6.3); the fifth is the comparison-game characterization of `S(n)$ (`docs/problem.md`, `docs/research-certificates-barriers.md`).

## 7. A001035 / `PACK-REPR` avoidance check

`[deduction,falsification]` The construction avoids the A001035 falsifier at every level:
- `Cell=`W^r` codes polynomially many tape addresses, not poset states.
- `PosBit$ stores the *current* frame's closure (``n^2` bits of content), not a tuple name for an arbitrary member of all ``A001035(n)` labelled posets.
- `StepPosBit$ computes a closure from current bits and a selected edge; it does not decode a global poset code.
- The PFP relation(s) range over configuration/tape/address tuples of fixed arity, as in standard PSPACE capture.

No total tuple-coding of all ``Pos`, no restricted polynomial-capacity poset domain, and no claim that every valid poset has a ``W^r` name.

## 8. Final assessment

The standard Vardi/Immerman/AV FO(PFP) capture construction for the explicit PSPACE DTM `M_D^alt` has been expanded to symbol-level form **as far as the local semantics and fixed encoding permit without a full stack-machine tableau proof**: fixed signature `A(w)`, fixed `r$ and `Cell=`W^r`, explicit finite alphabet/frame layout, explicit configuration relations, explicit ``Init_{M_D}`, explicit FO evaluation of the local ``M_G` formulas on encoded frames (including `StepPosBit$, `PostBudget$, `YieldE/A0/A1$), explicit finite-case DFS control schema, and an explicit FO(PFP) halting/acceptance fixed-point with a conditional equivalence chain.

The construction is **not** claimed as a complete discharged fixed syntactic FO(PFP)/IFP sentence proof. The single minimal failing subformula/lemma is:

> **[open:CKS-AV-Δ_D]** — complete, total, functional, invariant-preserving, no-spurious-transition FO formula `Δ_{M_D}` for the full deterministic DFS stack discipline of `M_D^alt` (frame boundaries, push/pop, return propagation, lex cursor, universal `C0/C1` sequencing), specialized to the layout/relations of §§1–2 and the local move semantics of §4.

Discharging `[open:CKS-AV-Δ_D] would, together with the standard Vardi/Immerman/AV FO(PFP) capture theorem and the equivalences in §6.3, yield the fixed syntactic FO(PFP)/IFP sentence required by the target. No claim of `P`, `FO(LFP)` on the bare word, `NP`, or `coNP` is made.
