### 1.2 Current-frame local semantics

`[definition]` (tape-formulas §§2-4; delta-d-dfs-stack §§2,4). $PosF(c̄,u,v)$ stores the current frame's transitive-closure bit for $Key$ pair $(u,v)$ only. For frame $c$:
```text
Incomp_c(x,y) := KeyNe(x,y) ∧ ¬PosF(c,x,y) ∧ ¬PosF(c,y,x).
Total_c       := ∀x∀y(KeyNe(x,y) -> PosF(c,x,y) ∨ PosF(c,y,x)).
Budget_c      := ∃t∃s(UsedF(c,t) ∧ SuccCtr(t,s)).
CfgAcc_c      := CtrlAcc(c) ∨ Total_c.
CfgRej_c      := CtrlRej(c).

StepPosBit_c(x,y;u,v) := PosF(c,u,v) ∨ ((u=x ∨ PosF(c,u,x)) ∧ (v=y ∨ PosF(c,y,v))).

PostBudget(P',U';Acc,Sort,Rej) :=
   (Total(P') ∧ Acc ∧ ¬Sort ∧ ¬Rej)
 ∨ (¬Total(P') ∧ HasBudget(U') ∧ Sort ∧ ¬Acc ∧ ¬Rej)
 ∨ (¬Total(P') ∧ ¬HasBudget(U') ∧ Rej ∧ ¬Acc ∧ ¬Sort).

YieldE_c(a,b)  := CtrlSort(c) ∧ ¬Total_c ∧ Budget_c ∧ Incomp_c(a,b).
YieldA0_c(a,b) := CtrlAdv(c)  ∧ HasSel(c) ∧ SelA(c,a)∧SelB(c,b) ∧ Incomp_c(a,b).
YieldA1_c(a,b) := YieldA0_c(a,b) with adversary answer b<a.
```
`ChildE_c(a,b)` copies $PosF/UsedF$, sets $Sel=(a,b), CtrlAdv$. $ChildA0_c(a,b)$ sets $PosF'=\!StepPosBit_c(a,b;\cdot,\cdot)$, $Used'=\!SuccCtr(UsedF_c)$, clears selection, applies $PostBudget$. $ChildA1_c$ uses $StepPosBit_c(b,a;\cdot,\cdot)$.

`[literature,deduction]` (CKS/AV §3.3; tape-formulas §4.1; delta-d-dfs-stack §4). **Incremental TC lemma:** if $PosF(c,\cdot,\cdot)$ is the closure of a strict partial order and $Incomp_c(x,y)$, then $StepPosBit_c(x,y;\cdot,\cdot)$ is the closure of $PosF(c,\cdot,\cdot)\cup\{(x,y)\}$ and a strict partial order.

## 3. Target (b): $M_D^{alt}$ halting/space/semantics and alternating-DFS equivalence

### 3.1 Explicit intended machine semantics

`[definition,inherited assumption]` (CKS/AV §§3-4,6.3; tape-formulas §§4-5; delta-d-dfs-stack §§4-5). $M_D^{alt}$ is the deterministic depth-first evaluator of the alternating game/configuration system $M_G/G(n,k)$:
- **State content:** a DFS stack of frames; each frame stores current $Pos$ closure, $Used\in Ctr$, control tag ($Q\_SORT/Q\_ADV/Acc/Rej$), selected pair, lex cursor, DFS backtrack mode (`M_Eval/M_BackE/M_BackA0/M_BackA1`/return markers).

- **Universal step (adversary, $CtrlAdv$):** evaluate $ChildA0(a,b)$ then $ChildA1(a,b)$; accept only if both accept (delta-d-dfs-stack §5.4).
- **Terminal:** $CfgAcc$ or $Total$-after-$PostBudget$ accepts; $CfgRej$ or budget-exhausted non-total or no-next-incomparable rejects (delta-d-dfs-stack §§4,5.1).

### 3.2 Space and halting (paper-level)

A current closure is $n^2\le N^2$ bits; frame metadata is $O(\log N)$; stack depth is $\le 2k+1\le 2N+1$ because each comparison consumes one $SuccCtr$ budget step on $ChildA0/ChildA1$ and $Used\in Ctr$ has $k+1$ values. Halting: the alternating DFS search space is finite — $Ctr$ is finite, lex cursor over $Key\times Key$ is finite and advanced, and each universal comparison branch consumes budget. A standard measure is lexicographic on (remaining budget/stack profile, cursor position, backtrack phase); no infinite path exists in the intended evaluator.

This is **not** a fully discharged DTM halting proof from an explicit $\delta_{M_D^{alt}}$ in this repo; it is the checkable semantic argument that the complete symbol-level machine must establish.

## 4. Target (c): $M_G/G(n,k)$ game equivalence to $S(n)\le k$ and $w\in SORT\!-\!BOUND\!-\!U$

### 4.1 Fixed comparison-game model

`[definition]` ($docs/problem.md$; $research-certificates-barriers.md$ §0/$G(n,k)$; CKS/AV §3). $G(n,k)$ is the finite alternating comparison game on $n$ distinct labelled keys with budget $k$: state $(P,used,ctrl,sel)$ where $P$ is a strict partial order/closure, $used\in\{0,\ldots,k\}$, $ctrl\in\{Sort,Adv,Acc,Rej\}$. Initial: $P=\emptyset$, $used=0$, $ctrl=Acc$ if $n\le 1$ else $Sort$. From $Sort$, if total accept; if $used=k$ and non-total reject; else sorter picks $Incomp_P(a,b)$ and moves to $Adv$ with $sel=(a,b)$. From $Adv$, adversary chooses $a<b$ or $b<a$; set $P':=TC(P\cup\{answer\})$, $used':=used+1$, resolve by $PostBudget(P',used')$. Sorter wins $G(n,k)$ iff it has a strategy forcing $Acc$.

$S(n)$ is the minimum worst-case number of pairwise comparisons of an adaptive decision tree correctly sorting every permutation of $n$ distinct labelled keys ($docs/problem.md$). The decision language is
```text
SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }.
```

### 4.2 Equivalence

`[deduction]` ($research-certificates-barriers.md$ §0: “$S(n)\le k$ iff the sorter wins $G(n,k)$”; $docs/problem.md$ game/ATM characterization; CKS/AV §5.2). The equivalence is the standard adaptive-comparison-tree / adversary-argument bridge:

1. **Tree $\Rightarrow$ sorter strategy.** If $S(n)\le k$, there is a correct adaptive comparison tree $T$ of height $\le k$. Let the sorter follow $T$: at each internal node compare the pair named by $T$; on answer $a<b$ or $b<a$, move to the corresponding child. Every path has $\le k$ comparisons, maintains a partial order consistent with answers, and reaches a leaf that identifies a unique total order because $T$ sorts all permutations; thus $P$ becomes total within budget and sorter wins $G(n,k)$.
2. **Sorter strategy $\Rightarrow$ tree.** A deterministic winning sorter strategy for $G(n,k)$ is a finite decision object: at $Sort$ states select an incomparable comparison (or accept if total), branch on the adversary's two possible answers. Since every play reaches $Acc$ within $k$ comparisons, unfolding this strategy gives a binary comparison tree of height $\le k$. Correctness: any permutation $\pi$ induces a consistent adversary play; the winning strategy reaches $Acc$, which means $Total$ (or an already total/accepted state), so the comparisons on that path determine the order of $\pi$.
3. **Language form.** For well-formed unary $w=1^n\#1^k$, $w\in SORT\!-\!BOUND\!-\!U$ iff $S(n)\le k$ by definition.

Therefore:
```text
A(w) well-formed unary and M_G/G(n,k) accepts initial state
  iff sorter wins G(n,k)
  iff S(n) <= k
  iff w ∈ SORT-BOUND-U.
```

`[deduction]` Compatibility with $M_D^{alt}$: under part (2) of `[open:CKS-AV-MDALT-REALIZE]`, $M_D^{alt}$ accepts $w$ iff alternating DFS accepts initial $M_G/G(n,k)$; combined with the line above, target (c) is discharged as a model bridge once the same $G(n,k)$ move semantics are realized.

### 4.3 Caveat

This is a paper-level model equivalence. A fully formal end-to-end theorem must use the same formal objects for “comparison tree”, “$Pos$ closure”, and “strategy” in the $M_G/G(n,k)$ realization and in the definition of $S(n)$; $docs/problem.md$ notes the Lean kernel checks the minimax correspondence but not the full machine-cost model.
