## 0. Verdict

`[deduction,falsification]` A **complete fixed simultaneous-tuple / ATM-configuration `Code/Decode` over `A(w)` is not discharged here**. The local `N_G`/`G(n,k)`/`M_G` transition layer from the global artifact is retained and made explicit as fixed FO formulas (§1–§3). Two candidate global normal forms are examined:

1. **Tuple-packed configuration codes** `Code(C; z̄)` with `z̄ ∈ W^r` and a stage-indexed acceptance relation `ACC(s̄,z̄)` (§4): this is the normal form targeted by `[open:PACK]`. It is **blocked** by a single minimal failing representability lemma: for every fixed arity `r`, the configuration space of `N_G` has size `2^{Θ(n^2)}` (already `A001035(n)` valid posets), while `|W|^r = N^r` is polynomial in `N=n+k+1`; therefore no faithful total `Code/Decode` ranging over all `N_G` configurations exists (§4.3). A concrete falsifier is given.
2. **Simultaneous PFP over state relations** `R_Pos,R_Used,R_Sel,R_Ctrl` (§5): this gives a fixed simultaneous operator whose semantic least fixed point is the alternating acceptance operator `T` from the global artifact, but standard single-relation FO(PFP) syntax and the usual ATM/DTM capture proof require a fixed-arity tuple coding of the evolving object; the simultaneous form is an equivalent semantic/operator presentation, not by itself a discharged fixed syntactic FO(PFP) sentence over `A(w)` with proved simulation obligations (2)–(4).

**Single minimal failing lemma (isolated):**
> **[open:PACK-REPR] (fails).** There exist fixed `r >= 1` and first-order formulas `Code(C;z̄)`, `DecodePos/DecodeUsed/DecodeSel/DecodeCtrl(z̄,...)` over `A(1^n#1^k)$, with `z̄ ∈ W^r$, such that for all well-formed inputs `w$ and all valid `N_G` configurations `C$ relevant to obligations (2)–(4), there is a unique `z̄$ with `Code(C;z̄)$ and the decoded configuration is FO-equivalent to `C$.

This fails as stated for *all* valid configurations by a counting falsifier (§4.3). Restricting to *reachable* or *acceptance-relevant* configurations is open, but that restriction is exactly a new global coding/proof obligation, not a discharge of `[open:PACK]`.

No smaller complexity class for `SORT-BOUND-U` is claimed.

## 1. Fixed objects

`[definition]` Input word `w=1^n#1^k`, length `N=n+k+1$, structure
```text
A(w) = (W,<,One,Hash),   W={1,...,N},   Hash={n+1},   One=W\{n+1}.
```
FO guards/parameters (as in the global artifact):
```text
HashPos(h), WellFormed_w, Malformed;
Key(x) := ∃h(HashPos(h) ∧ x<h);
Ctr(t) := ∃h(HashPos(h) ∧ (t=h ∨ h<t));   -- {0,...,k}, 0 encoded by hash position
Zero(t):= HashPos(t);  MaxK(t);  SuccCtr(t,s);  HasBudget(t);
KeyNe(x,y) := Key(x)∧Key(y)∧x!=y.
Φ_SORTU := WellFormed_w ∧ Φ_game.
```

`[definition]` `G(n,k)$ is the finite comparison-sorting game on transitively closed strict partial orders over `n$ keys with budget `k$; sorter wins iff a total order is reached within `k$ comparisons. `M_G$ is the alternating machine/game form whose existential moves are legal sorter pair selections and universal moves are adversary outcomes. `[literature,deduction]` `S(n)<=k` iff sorter wins `G(n,k)$ (`docs/problem.md`, `research-certificates-barriers.md`).

## 2. Fixed-arity `N_G` state relations (simultaneous-tuple state)

`[definition]` The explicit `N_G` configuration/state signature over `A(w)$ is
```text
Pos(u,v)    arity 2, u,v ∈ W   intended domain Key×Key : strict partial-order edge u<v
Used(t)     arity 1, t   ∈ W   intended domain Ctr     : comparisons-used marker
Sel(a,b)    arity 2, a,b ∈ W   intended domain Key×Key : selected pair in adversary mode
Ctrl(q)     arity 1, q   ∈ W   finite control tag      : encodes QSort/QAdv/QAcc/QRej
Ok          arity 0                                    : well-formed/config-valid flag (optional)
```
This is a fixed finite signature, independent of `n,k$. It is the concrete simultaneous-tuple/relational state: a complete semantic configuration is an interpretation
```text
C = (Pos^A, Used^A, Sel^A, Ctrl^A)
```
over `A(w)$ satisfying `ValidConfig(C)$.

`[definition]` Finite control coding (example; any fixed FO-definable 4-tag scheme is equivalent):
```text
First(z) := ¬∃y(y<z).
QSort(Ctrl) := ∃q(Ctrl(q)∧First(q)).
QAdv(Ctrl)  := ∃q(Ctrl(q)∧¬First(q)∧∃p(First(p)∧Succ(p,q))).
QAcc(Ctrl)  := ∃q(Ctrl(q)∧¬First(q)∧¬∃p(First(p)∧Succ(p,q))∧∃r∃p(First(p)∧Succ(p,r)∧Succ(r,q))).
QRej(Ctrl)  := ∃q(Ctrl(q)∧¬QSortTag(q)∧¬QAdvTag(q)∧¬QAccTag(q)).   -- or use a 4th fixed position
```
(Any fixed encoding of four control states by first-order definable domain elements is acceptable; the proof obligations require only FO decoding and uniqueness of control.)

## 3. Concrete local FO formulas (obligations, semantic layer)

All formulas below are first-order over `A(w)$ and the displayed `N_G$ state relations.

### 3.1 Validity and configuration predicates
```text
ValidPos(Pos) := ∀u∀v(Pos(u,v)->(Key(u)∧Key(v)))
               ∧ ∀x ¬Pos(x,x)
               ∧ ∀x∀y∀z((Pos(x,y)∧Pos(y,z))->Pos(x,z)).

Incomparable(Pos,x,y) := Key(x)∧Key(y)∧x!=y ∧ ¬Pos(x,y) ∧ ¬Pos(y,x).
Total(Pos) := ∀x∀y((Key(x)∧Key(y)∧x!=y)->(Pos(x,y)∨Pos(y,x))).

ExactlyOneUsed(Used) := ∃t(Used(t)∧Ctr(t)) ∧ ∀t∀s((Used(t)∧Used(s))->t=s).
NoSel(Sel) := ¬∃a∃b Sel(a,b).
OneSel(Sel):= ∃a∃b(Sel(a,b)∧Key(a)∧Key(b)∧∀x∀y(Sel(x,y)->(x=a∧y=b))).

ValidConfig(Pos,Used,Sel,Ctrl) :=
  ValidPos(Pos) ∧ ExactlyOneUsed(Used) ∧ ExactlyOneCtrl(Ctrl)
  ∧ (QSort(Ctrl)->NoSel(Sel))
  ∧ (QAdv(Ctrl) ->OneSel(Sel))
  ∧ (QAcc(Ctrl) ->Total(Pos)).
```

### 3.2 `Init` and acceptance/rejection
```text
Init(Pos,Used,Sel,Ctrl) :=
    (∀u∀v ¬Pos(u,v))
  ∧ (∃t(Used(t)∧Zero(t)) ∧ ∀t∀s((Used(t)∧Used(s))->t=s))
  ∧ NoSel(Sel)
  ∧ ((Total(Pos) ∧ QAcc(Ctrl)) ∨ (¬Total(Pos) ∧ QSort(Ctrl))).

ConfigAcc(Pos,Used,Sel,Ctrl) := QAcc(Ctrl) ∨ Total(Pos).
ConfigRej(Pos,Used,Sel,Ctrl) := QRej(Ctrl).
```

### 3.3 Incremental transitive closure
```text
StepPos(Pos,x,y; u,v) := Pos(u,v) ∨ ((u=x ∨ Pos(u,x)) ∧ (v=y ∨ Pos(y,v))).
```
`[deduction]` **Local TC lemma.** If `ValidPos(Pos)` and `Incomparable(Pos,x,y)$, then `Pos'(u,v) := StepPos(Pos,x,y;u,v)$ is the transitive closure of `Pos ∪ {(x,y)}$ and satisfies `ValidPos(Pos')$. *Proof obligation.* Use transitive closure of `Pos$, absence of paths `x <_Pos ... <_Pos y$ and `y <_Pos ... <_Pos x$, and check irreflexivity/transitivity in the four endpoint combinations.

### 3.4 Existential sorter move `YieldE`
```text
YieldE(Pos,Used,Sel,Ctrl; Pos',Used',Sel',Ctrl') :=
    QSort(Ctrl) ∧ ¬Total(Pos)
  ∧ (∃t(Used(t)∧HasBudget(t)))
  ∧ (∃a∃b(Sel'(a,b) ∧ Incomparable(Pos,a,b) ∧ ∀x∀y(Sel'(x,y)->(x=a∧y=b))))
  ∧ (∀u∀v(Pos'(u,v)<->Pos(u,v)))
  ∧ (∀t(Used'(t)<->Used(t)))
  ∧ QAdv(Ctrl') ∧ ¬QSort(Ctrl') ∧ ¬QAcc(Ctrl') ∧ ¬QRej(Ctrl').
```

### 3.5 Universal adversary moves `YieldA0`, `YieldA1`
```text
PostBudget(Pos',Used',Ctrl') :=
    (Total(Pos') ∧ QAcc(Ctrl') ∧ ¬QSort(Ctrl') ∧ ¬QAdv(Ctrl') ∧ ¬QRej(Ctrl'))
  ∨ (¬Total(Pos') ∧ (∃s(Used'(s)∧HasBudget(s))) ∧ QSort(Ctrl') ∧ ¬QAdv(Ctrl') ∧ ¬QAcc(Ctrl') ∧ ¬QRej(Ctrl'))
  ∨ (¬Total(Pos') ∧ ¬(∃s(Used'(s)∧HasBudget(s))) ∧ QRej(Ctrl') ∧ ¬QSort(Ctrl') ∧ ¬QAdv(Ctrl') ∧ ¬QAcc(Ctrl')).

YieldA0(Pos,Used,Sel,Ctrl; Pos',Used',Sel',Ctrl') :=
    QAdv(Ctrl)
  ∧ (∃a∃b(Sel(a,b) ∧ Incomparable(Pos,a,b)))
  ∧ (∀u∀v(Pos'(u,v)<->StepPos(Pos,a,b;u,v)))
  ∧ (∃t∃s(Used(t)∧SuccCtr(t,s)∧Used'(s) ∧ ∀r(Used'(r)->r=s)))
  ∧ NoSel(Sel')
  ∧ PostBudget(Pos',Used',Ctrl').

YieldA1(Pos,Used,Sel,Ctrl; Pos',Used',Sel',Ctrl') :=
    QAdv(Ctrl)
  ∧ (∃a∃b(Sel(a,b) ∧ Incomparable(Pos,a,b)))
  ∧ (∀u∀v(Pos'(u,v)<->StepPos(Pos,b,a;u,v)))
  ∧ (∃t∃s(Used(t)∧SuccCtr(t,s)∧Used'(s) ∧ ∀r(Used'(r)->r=s)))
  ∧ NoSel(Sel')
  ∧ PostBudget(Pos',Used',Ctrl').
```

`[deduction]` **Local budget lemma.** `YieldE$ requires `HasBudget`. Each of `YieldA0/YieldA1$ advances `Used$ by exactly one `SuccCtr`. `PostBudget$ accepts a total order (including after the `k`-th comparison), continues only while budget remains, and rejects a non-total exhausted state. Hence every accepting run uses at most `k$ comparisons.

## 4. Tuple-packed configuration-code attempt (`Code/Decode`) and minimal failure

This section states the candidate discharge of `[open:PACK]` from the global artifact.

### 4.1 Candidate fixed-arity code

`[definition]` Fix `r>=1$ and let `z̄ = (z1,...,zr) ∈ W^r$. Candidate coding interface:
```text
Code(Pos,Used,Sel,Ctrl; z̄)          -- FO formula/relation linking state to code
DecodePos(z̄; u,v)
DecodeUsed(z̄; t)
DecodeSel(z̄; a,b)
DecodeCtrl(z̄; q)

InitCode(z̄) :=
  ∃Pos∃Used∃Sel∃Ctrl (Init(Pos,Used,Sel,Ctrl) ∧ Code(Pos,Used,Sel,Ctrl;z̄)).

AccCode(z̄) :=
  ∃Pos∃Used∃Sel∃Ctrl (ConfigAcc(Pos,Used,Sel,Ctrl) ∧ Code(Pos,Used,Sel,Ctrl;z̄)).

ExistsCode(z̄) := ∃Pos∃Used∃Sel∃Ctrl (QSort(Ctrl) ∧ Code(Pos,Used,Sel,Ctrl;z̄)).
ForallCode(z̄) := ∃Pos∃Used∃Sel∃Ctrl (QAdv(Ctrl)  ∧ Code(Pos,Used,Sel,Ctrl;z̄)).

YieldECode(z̄,z̄') :=
  ∃Pos∃Used∃Sel∃Ctrl∃Pos'∃Used'∃Sel'∃Ctrl'
    (Code(Pos,Used,Sel,Ctrl;z̄) ∧ Code(Pos',Used',Sel',Ctrl';z̄')
     ∧ YieldE(Pos,Used,Sel,Ctrl;Pos',Used',Sel',Ctrl')).

YieldA0Code, YieldA1Code analogously.
```
The stage-indexed FO(PFP) acceptance form targeted by the global artifact is
```text
Φ_game :=
  ∃z̄ (InitCode(z̄) ∧ [PFP_{ACC(s̄,z̄)} ψ_ACC(s̄,z̄,ACC)](max̄,z̄)),

ψ_ACC(s̄,z̄,ACC) :=
  (IsZeroStage(s̄) ∧ AccCode(z̄))
  ∨ (¬IsZeroStage(s̄) ∧ ∃s̄'(PredStage(s̄',s̄) ∧
      ( AccCode(z̄)
        ∨ (ExistsCode(z̄) ∧ ∃z̄'(YieldECode(z̄,z̄') ∧ ACC(s̄',z̄')))
        ∨ (ForallCode(z̄) ∧ ∃z̄0∃z̄1(YieldA0Code(z̄,z̄0)∧YieldA1Code(z̄,z̄1)
                                      ∧ ACC(s̄',z̄0)∧ACC(s̄',z̄1)))))).
```
with lexicographic stage arithmetic over `s̄∈W^r'$ for fixed `r'>=2$.

### 4.2 Obligations required to discharge this form

The global artifact's obligations, specialized to this candidate:
1. Malformed inputs rejected by `Φ_SORTU$ (local/definitional).
2. `InitCode$ holds for the intended initial configuration code.
3. `Yield*Code$ preserve and reflect the semantic `Yield*` transitions under `Code/Decode`.
4. `ψ_ACC$ PFP computes alternating acceptance of the encoded `M_G/G(n,k)$ computation from the initial code.
5. `M_G$ accepts iff sorter wins `G(n,k)$ iff `S(n)<=k$.

### 4.3 Single minimal failing lemma and falsifier

**Failing lemma [open:PACK-REPR] (total configuration coding).**  For fixed `r$, the tuple-packed interface in §4.1 requires `Code/Decode$ to represent `N_G` configurations by `z̄∈W^r$ faithfully enough for obligations (2)–(4).

`[falsification]` **Counting falsifier.** Let `P_n$ be the set of transitively closed strict partial orders (labelled posets, in strict form) on `n$ keys. For every `P ∈ P_n$ define the valid `N_G$ configuration
```text
C_P := (Pos_P, Used_0, Sel_∅, Ctrl_Sort)
Pos_P(u,v) ⇔ (u <_P v)
Used_0 = {Zero position/hash-encoded 0}, Sel_∅ = ∅, Ctrl_Sort = sorter control.
```
These are all valid when `P$ is not total (or use `Ctrl_Acc$ when total); in particular all non-total strict partial orders are valid sorter configurations at used budget 0. The number of labelled posets is `A001035(n)$ (`[literature]`, OEIS A001035; Kleitman–Rothschild). OEIS values give
```text
A001035(1)=1, 3, 19, 219, 4231, 130023, 6129859, ...
```
and `A001035(n)=2^{Θ(n^2)}$.

The code space has size
```text
|W^r| = N^r = (n+k+1)^r.
```
Choose `k=n$, so `N=2n+1$. For any fixed `r$, `A001035(n) > (2n+1)^r$ for all sufficiently large `n$ (exponential in `n^2$ dominates polynomial in `n$). Therefore no function from these valid configurations into `W^r$ is injective, and hence no fixed-arity `Code/Decode$ can faithfully represent all valid `N_G$ configurations.

Consequently the total form of **[open:PACK-REPR] fails**. This blocks the naive reading of obligations (2)–(3) as “`Code$ is a faithful encoding of the semantic relations” over all configurations, and it blocks using `ACC(s̄,z̄)$, `z̄∈W^r$, as a complete acceptance table over all configurations.

`[deduction]` **Why this is the minimal residual.** The falsifier does not use any local `G(n,k)$ move incorrectly: `Pos_P$ is a legitimate current state relation. The local FO formulas in §3 are unaffected. The failure is only that fixed-arity tuple codes over the `N$-element domain cannot name all relation-valued `N_G` configurations. Thus the residual is exactly a global representation/packing/capture problem.

### 4.4 Possible restrictions (not discharged)

A restriction to a designated subset `Conf_rel ⊆ {valid N_G configs}$ could in principle make coding possible if `|Conf_rel| <= N^r$, but discharging `[open:PACK]` under a restriction requires proving:
- `Init ∈ Conf_rel$ (obligation 2);
- `Yield*`-successors of relevant `Conf_rel$ configurations that matter for acceptance are represented/preserved (obligation 3);
- the PFP over codes of `Conf_rel$ is sound and complete for alternating acceptance of `M_G$ (obligation 4).

The natural candidate `Conf_rel =` configs on some optimal/accepting strategy does not have an a priori polynomial bound: the project notes record the optimal-play state-count question as open (`research-certificates-barriers.md`, §8). The reachable-poset DP state space includes all labelled posets (`A001035(n)$), which is exponential. Therefore no restriction has been proved sufficient to discharge obligations (2)–(4).

## 5. Simultaneous PFP over state relations (semantic normal form)

`[definition]` As a simultaneous fixed-point presentation, let `ACC$ be a distinguished 0-ary acceptance tag or a designated relation and define the monotone operator
```text
T_Pos(Pos,Used,Sel,Ctrl; ACC)      (can be taken as identity projection for state-carrying forms)
...
T_ACC(Pos,Used,Sel,Ctrl; ACC) := 
    ConfigAcc(Pos,Used,Sel,Ctrl)
  ∨ (QSort(Ctrl) ∧ ∃Pos'∃Used'∃Sel'∃Ctrl'(YieldE(...) ∧ ACC'(Pos',Used',Sel',Ctrl')))
  ∨ (QAdv(Ctrl)  ∧ ∃... (YieldA0(...,C0)∧YieldA1(...,C1)∧ACC'(C0)∧ACC'(C1)))
```
interpreted semantically over configurations. `[deduction]` On the finite `G(n,k)$ game, this is exactly the alternating acceptance operator: its least fixed point accepts the initial configuration iff sorter wins `G(n,k)$ iff `S(n)<=k$.

This does **not** by itself supply a fixed syntactic FO(PFP) sentence over `A(w)$: the quantifications/least fixed point are over second-order-like relation interpretations/configurations unless compiled into a fixed-arity tuple domain. The compilation is exactly §4's blocked `[open:PACK-REPR]` (for total coding) or an undischarged restricted coding.

## 7. Precise conclusion

The concrete simultaneous-tuple state of `M_G/G(n,k)$ is fully explicit as fixed-arity relations over `A(w)$: `Pos,Used,Sel,Ctrl$. The local FO transition system (`Init`, `StepPos`, `YieldE`, `YieldA0`, `YieldA1`, `PostBudget`, `ConfigAcc`) is explicit and covers legal moves, incremental TC, both adversary outcomes, and budget `<=k$.

The global `[open:PACK]$ request cannot be discharged in the tuple-packed form `Code(C;z̄)$, `z̄∈W^r$, over all valid `N_G$ configurations: the single minimal failing lemma is **[open:PACK-REPR]**, falsified because `A001035(n)=2^{Θ(n^2)}$ valid poset states exceed `|W|^r=(n+k+1)^r$ for every fixed `r$ at large `n$. Any future closure attempt must either (a) prove a restricted coding domain sufficient for obligations (2)–(4), with an explicit bound/proof, or (b) use a different standard global FO(PFP)/IFP capture normal form and supply its complete simulation/correspondence proof for the local formulas in §3. Neither (a) nor (b) is completed here.
