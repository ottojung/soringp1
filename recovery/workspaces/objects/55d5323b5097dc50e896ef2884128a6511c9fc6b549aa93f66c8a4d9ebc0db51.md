## Proposed representation

Use a per-live-frame cursor record
`(hasCur, curA, curB, curExhausted)`. `hasCur` is true for both normal and
exhausted states. The normal root/child initialization `(MinKey,MinKey,false)`
and exhausted encoding `(MinKey,MinKey,true)` intentionally share the pair;
every cursor consumer must inspect the flag before interpreting the pair.
Normal means `hasCur ∧ ¬curExhausted` and a unique pair. Exhausted means
`hasCur ∧ curExhausted ∧ curA=curB=MinKey`; it is never a normal witness.
Add the flag to the fixed frame record, frame copier, equality/preservation
routine, and decoder. Decode the flag as the `CurExhausted` component of the
schema, rather than deriving it from the pair or from a failed search.

The implementation is a *specification* for P1 compilation: tests and writes
below must be compiled as deterministic finite macro-routines over the existing
polynomial work-tape encoding, and each routine must finish with the stated
encoded poststate. It does not assert that such compiled code has been written
or checked.

## Decoder and exact per-transition updates

Let `decode` read the whole record, including the new flag, and let
`encode` write each record field. All unspecified live records are copied
field-for-field; all global updates and changed sets retain the v2 matrix.

| Path | Required cursor write / decode clause |
|---|---|
| Root initialization | Write `hasCur=1`, `(curA,curB)=(MinKey,MinKey)`, `curExhausted=0`. This is a normal cursor, not exhaustion. |
| `PushChildE` and `PushChildA` | New child gets exactly the same initialized normal tuple `(1,MinKey,MinKey,0)`; it does not inherit the parent's exhausted bit. Parent link, other child fields, and globals follow the existing constructor. |
| Rows 6 and 10 (`SetParentBackE_Advance`) | Guard/decoder first requires a coherent normal parent cursor and the unique selected `NextIncomp` pair `(x,y)`. If `IsLastLex2(x,y)`, write `(1,MinKey,MinKey,1)`. Otherwise find the unique `SuccLex2(x,y,x',y')` and write `(1,x',y',0)`. Row 6/10 then creates its child as above. No search starts from an exhausted cursor. |
| Rows 11/12 (BackE exhausted root/return) | Decode `curExhausted=1` as immediately satisfying `NNI`; for a normal cursor, decode `NNI` only via `NoNextIncomp(curA,curB)`. Row 11 clears all live frames and sets terminal globals. Row 12 inactivates the child and marks parent `RetRej`; parent cursor record is copied exactly, including the flag. |
| BackA parent updates (rows 7/15) | `SetParentBackA0/A1` change only the specified mode/return/control fields. Copy `hasCur,curA,curB,curExhausted` verbatim. Child constructor initializes its cursor independently. |
| All marker/pop returns (rows 4/5/9/12/14/17/19) | Inactivate popped `c`; on receiver `p`, update only `Ret` to the selected marker and copy every other field verbatim, in particular all four cursor fields. Rows 4/5/9/12/14/17/19 retain the v2 `S` and parent relation effects. |
| Identity/absorbing halt (row 1) | Identity on the complete encoded state (or absorbing halt with the v2 globals); do not normalize cursor records. |
| Terminal paths (rows 2/3/8/11/13/16/18) | Set the specified halt/empty-stack globals and clear every live-frame bit. Once a frame is inactive its record is semantically unobserved; implementation may leave stale bytes, but decoder must gate all frame reads on liveness. |
| Other rows / lower stack | For every live frame outside the v2 changed set, copy the full record, including flag, exactly. No default/implicit flag value is permitted for a changed live frame. |

This table covers the v2 rows 1–19: the row classes shown above enumerate
identity, terminals, marker returns, BackE advances, and BackA/child pushes;
the remaining BackA return paths are marker returns with the same receiver
copy rule.

## Component-closure argument (conditional paper deduction)

Assume (A) the source-level v2 update clauses are total and mutually exclusive
on the intended reachable states; (B) the record codec is injective on live
frame fields and each copy/write macro implements its listed field effect
without aliasing; (C) the `Lex2/SuccLex2/IsLastLex2` tests are total, with
functional successor and exact last-pair complement; and (D) the existing
normalized frame/global update clauses, `SYM-TOP` uniqueness, and parent/stack
semantics are valid. Then cursor-component closure follows by cases:

* initialization and child creation establish the normal branch directly;
* rows 6/10 establish exactly one branch by the last/non-last split and the
  successor assumptions;
* BackA updates and marker returns preserve the tuple by literal field copy;
* rows outside the changed set preserve it by whole-record copy;
* terminal rows have no live frames, so no live cursor-coherence obligation is
  left; identity preserves the full state.

In particular, the same pair value at initialization and exhaustion causes no
decoder ambiguity: the flag is represented, copied, and consulted explicitly.
For a v2 state satisfying `CursorCoherent` before the step, these clauses imply
`CursorCoherent` after the step for every live frame, provided the non-cursor
fields/changed-set conditions in (A),(D) hold. This is closure of the proposed
component specification, not evidence that the realization's old DTM already
implements it.

## Revised invariant preservation: attempted, not discharged

The new clauses give the cursor component of an induction, but they do not by
themselves prove the full revised `I_{M_D}` induction. Required remaining
induction cases are:

1. **Top/mode/return/control:** establish unique `Top`, exactly one mode, and
   coherent one-hot `Ret`/`Ctrl` after every row, including push/pop and terminal
   clears. This needs the actual complete row guards/updates, not just cursor
   copies.
2. **Frame and parent discipline:** prove fresh allocator uniqueness, active
   root-to-top path, unique functional parent for active non-root frames, and
   lower-stack preservation for each concrete macro-write. Cursor closure does
   not imply these.
3. **Semantic fields:** prove `PosF`, `UsedF`, selection snapshots, `PostBudget`,
   and BackA1 snapshot correctness; show the decoded local game state matches
   each child/return update.
4. **BackE/eval reader obligations:** prove reachable eval `CtrlSort` states
   enter with normal coherent cursors, BackE consumers see coherent tuples,
   `NI xor NNI` under the finite lex partition, and no intervening mutation of a
   receiver before its marker is consumed. The flag clauses make these
   statements meaningful, not established.
5. **Realization obligations:** extend the actual `E(Rbar)`, `q_init`, frame
   layout, field offsets, copy loops, push/pop/terminal macros and decoder in
   the cited realization. Recheck P1 compilation, uniqueness/equivalence,
   halting and space bounds with the additional per-frame bit and its writes.

Thus the attempted proof reaches a conditional cursor-component closure lemma
but stops before a proved implementation or full `I_{M_D}` preservation. In
particular, no use of the rank audit establishes termination until the full
reachable invariant/frame coverage is proved. No theorem completion or
classification claim follows.
