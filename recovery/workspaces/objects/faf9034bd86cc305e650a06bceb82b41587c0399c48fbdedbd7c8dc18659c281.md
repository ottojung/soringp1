## 1. Fixed state and `I_{M_D}` reachability shape

`[definition]` (realization §§1.1–1.3, SYM/SYM-TOP). Input `A(w)=(W,<,One,Hash)`,
`w=1^n#1^k`, `Cell=W^r`. A whole configuration is the interpretation of
```text
Rbar = (Top,CurBase,EmptyStack,HaltAcc,HaltRej,
        M_Eval,M_BackE,M_BackA0,M_BackA1,
        RetNone,RetAcc,RetRej,
        CtrlSort,CtrlAdv,CtrlAcc,CtrlRej,
        UsedF,HasSel,SelA,SelB,HasCur,CurA,CurB,
        PosF,Parent,FrameLive)
```
with DTM encoding `E(Rbar) = [globals] ⊕ [live-frame table]` storing current
frame-local fields and `PosF(c̄,·,·)` for live `c̄` (no `PACK-REPR`/A001035 tuple
coding).

`[definition]` Local semantic formulas (fixed): `P_c`, `Incomp_c`, `Total_c`,
`Budget_c`, `CfgAcc_c`, `CfgRej_c`, `StepPosBit_c`, `PostBudgetFrom`,
`TotalOf`, `NextIncomp_c`, `NoNextIncomp_c`, `SuccLex2`, `SuccCtr`,
`SuccCell`, `ZeroCell`, `MinKey`, `KeyNe`, `Lex2`, `IsLastLex2`, `Root(c̄)`.

`[definition]` `I_{M_D}`-reachable means: reachable from `Init_{M_D}^{sym}` by
`Δ_{M_D}^{sym,top}`/`δ_{M_D^alt}^{sch}` steps and satisfying invariant
`I_{M_D}` (realization §1.2 / SYM §6 / `[SYM-TOP]`): well-formed input,
`HaltAcc∨HaltRej∨EmptyStack` only in global halting/empty states; on
non-halting states unique `Top(c̄)` with `FrameLive(c̄)`; `ExactlyOneMode(c̄)`
on every live frame; `ExactlyOneCtrl(c̄)` where control is defined; `RetNone`
exclusive with `RetAcc/RetRej` as appropriate; `Parent` functional on active
non-root frames and absent/irrelevant at root as encoded; unique `UsedF(c̄,·)`
in `Ctr`; coherent `HasSel/SelA/SelB`, `HasCur/CurA/CurB`; root-to-top active
path discipline; and `[SYM-TOP]` push `Top'` uniqueness.

`[deduction]` (reachability-shape constraints used by the matrix). The guard
partition uses only these consequences of `I_{M_D}` plus the fixed DFS macro
discipline:
1. **Global priority.** `HaltAcc(E) ∨ HaltRej(E)` is absorbing (`D_halt`).
2. **Unique top.** Every non-halting case tests the unique `Top(c̄)`.
3. **Mode/return coherence.** `ExactlyOneMode(c̄)`. `RetAcc/RetRej` are
   consumed/meaningful on `M_BackE/M_BackA0/M_BackA1` after a child return;
   `M_Eval` live-evaluation steps are read with `RetNone(c̄)` (a returned-to
   parent becomes a `Back*` frame by `MarkRet*On`; an `M_Eval` frame is not a
   pending return marker frame).
4. **Selection/cursor coherence.** `CtrlAdv(c̄)` implies `HasSel(c̄)` with
   unique `SelA/SelB`; existential search states maintain `HasCur(c̄)` with
   unique `CurA/CurB`.
5. **Exhaustive local predicates.** `CfgAcc_c ∨ RejectEval_c` may hold for
   terminal eval states; otherwise `CtrlSort` gives either
   `NextIncomp_c(CurA,CurB;·,·)` or `NoNextIncomp_c(CurA,CurB)` (and the latter
   is reject-exhaust for sort search), while `CtrlAdv` gives `YieldA_c` by
   selected incomparable pair.
6. **Root test.** `Root(c̄)` is the negation/positive root test used by the
   realization (`¬∃p̄ Parent(c̄,p̄)` or the equivalent fixed root mark).

A non-`I_{M_D}`/unreachable malformed encoding is outside the lemma's domain;
the disproof test in §5 asks for an **`I_{M_D}`-reachable** witness.

## 2. Explicit fixed encoding `Enc`

`[definition]` Fix `Enc` as the following concrete symbol-level/DTM
whole-configuration discipline. It is the smallest deterministic instantiation
compatible with the realization's helper names and `[SYM-TOP]`.

```text
Enc := (FreshChild, CurBase', Parent, PopTo_base, FrameInactive',
        LowerStackPreservedExcept, FrameEq', MarkRetAccOn, MarkRetRejOn,
        BackA0/A1/BackE/Ret marker representation, Root test).
```

### 2.1 Allocator

```text
FreshChild(d̄)            := CurBase(d̄).
CurBaseUnchanged          := ∃b̄(CurBase(b̄) ∧ CurBase'(b̄)).
CurBaseBump               := ∃b̄∃b̄'(CurBase(b̄) ∧ SuccCell(b̄,b̄') ∧ CurBase'(b̄')).
```
`[deduction]` `SuccCell` is FO/DTM functional on `Cell=W^r`; `CurBase` is unique
by `I_{M_D}`; thus each push has a unique `d̄` and unique `CurBase'`.

### 2.2 Parent, root, and active-stack link

```text
ParentOf(c̄,p̄)            := Parent(c̄,p̄).
Root(c̄)                  := FrameLive(c̄) ∧ ¬∃p̄ Parent(c̄,p̄).
NonRoot(c̄)               := FrameLive(c̄) ∧ ∃p̄ Parent(c̄,p̄).
```
`[deduction]` `Parent` is functional on active non-root frames by `I_{M_D}`.
`MarkRet*On` is applied only when `NonRoot(c̄)` supplies the unique `p̄`.

### 2.3 Frame liveness, inactivity, and preservation

`[definition]` Global/stack field updates use whole-configuration primed
relations. For a case with active top `c̄`:
```text
FrameLive'(x̄)            : preserved for all frames not explicitly killed/emptied.
FrameInactive'(x̄)        := ¬FrameLive'(x̄).
FrameEq'(x̄)               := same mode/Ret/Ctrl/UsedF/HasSel/SelA/SelB/
                             HasCur/CurA/CurB/PosF/Parent/FrameLive values for x̄.
LowerStackPreservedExcept(S) :=
  ∀x̄(FrameLive(x̄) ∧ ¬S(x̄) -> FrameEq'(x̄) ∧ FrameLive'(x̄)).
```
`S` is the case's designated changed set: empty for `D_halt`; all live frames
cleared for root halts/empty-stack terminals as specified; `{p̄,c̄}` for pop
returns (child inactive, parent marker-updated); `{c̄,d̄}` for pushes (parent
mode/cursor/Ret as specified, child created active as `Top'`, others preserved).

### 2.4 `PopTo_base` and `[SYM-TOP]` child base

```text
PopTo_base(p̄,c̄) :=
  Top(c̄) ∧ Parent(c̄,p̄) ∧
  Top'(p̄) ∧ ¬Top'(c̄) ∧
  ∀z̄(Top'(z̄) -> z̄=p̄) ∧
  FrameInactive'(c̄) ∧
  CurBaseUnchanged ∧
  LowerStackPreservedExcept({p̄,c̄}).
```
(Fields of `p̄` not mentioned are then set by `MarkRet*On`; no other frame is in
`{p̄,c̄}`.)

```text
ChildFrameBase(d̄,c̄) :=      -- [SYM-TOP]
  Top(c̄) ∧ FreshChild(d̄) ∧ ¬FrameLive(c̄ as d̄ conflict impossible by allocator) ∧
  FrameLive'(d̄) ∧
  Top'(d̄) ∧ ¬Top'(c̄) ∧
  ∀z̄(Top'(z̄) -> z̄=d̄) ∧
  CurBaseBump ∧
  LowerStackPreservedExcept({c̄,d̄}).
```
`[deduction]` `ChildFrameBase` is the `[SYM-TOP]` amendment: it makes `d̄` the
unique new top and removes `c̄` from `Top'`.

### 2.5 Return markers and mode/return representation

`[definition]` Marker/state representation is the fixed component reading:
```text
Mode(c̄)=Eval    iff M_Eval(c̄).
Mode(c̄)=BackE   iff M_BackE(c̄).
Mode(c̄)=BackA0  iff M_BackA0(c̄).
Mode(c̄)=BackA1  iff M_BackA1(c̄).
Ret(c̄)=None/Acc/Rej iff RetNone/RetAcc/RetRej(c̄) respectively.
```
`ExactlyOneMode` and return coherence are in `I_{M_D}`. A push to evaluate a
child sets child `M_Eval ∧ RetNone`; the parent enters the corresponding
`M_BackE/M_BackA0/M_BackA1` state with `RetNone` until `MarkRet*On`.

### 2.6 `MarkRetAccOn` / `MarkRetRejOn` (deterministic table)

`[definition]` The marker write affects only the designated parent `p̄` and only
the fields listed; all other fields of `p̄` are preserved except those a case
explicitly changes after the mark (BackE reject-exhaust/next is handled by the
BackE cases, not by this primitive alone). Primitive parent marker update:
```text
MarkRetAccOn(p̄) :=
  FrameLive'(p̄) ∧
  RetAcc'(p̄) ∧ ¬RetNone'(p̄) ∧ ¬RetRej'(p̄) ∧
  PreserveNonMarkerFields(p̄).

MarkRetRejOn(p̄) :=
  FrameLive'(p̄) ∧
  RetRej'(p̄) ∧ ¬RetNone'(p̄) ∧ ¬RetAcc'(p̄) ∧
  PreserveNonMarkerFields(p̄).

PreserveNonMarkerFields(p̄) :=
  preserve Ctrl*/UsedF/HasSel/SelA/SelB/HasCur/CurA/CurB/PosF/Parent and the
  current Back* mode bits of p̄, unless the enclosing case specifies a mode
  transition (none of the pop-return rows below change mode).
```

Deterministic parent-marker table (rows are the only `PopTo_base+MarkRet*`
combinations used by `Enc`):

| Parent mode at `p̄` | Child return | Primitive used | `Ret'` on `p̄` | Mode' on `p̄` | NextIncomp/NoNextIncomp relevance |
|---|---|---|---|---|---|
| `M_BackA0` | `RetAcc` (child pop) | `PopTo_base+MarkRetAccOn` | `RetAcc` | `M_BackA0` | N/A — next macro-case is `D_backA0_acc_A1` from `p̄`. |
| `M_BackA0` | `RetRej` (child pop) | `PopTo_base+MarkRetRejOn` | `RetRej` | `M_BackA0` | N/A — next macro-case is `D_backA0_rej_*`. |
| `M_BackA1` | `RetAcc` (child pop) | `PopTo_base+MarkRetAccOn` | `RetAcc` | `M_BackA1` | N/A — next macro-case is `D_backA1_acc_*`. |
| `M_BackA1` | `RetRej` (child pop) | `PopTo_base+MarkRetRejOn` | `RetRej` | `M_BackA1` | N/A — next macro-case is `D_backA1_rej_*`. |
| `M_BackE`  | `RetAcc` (child pop) | `PopTo_base+MarkRetAccOn` | `RetAcc` | `M_BackE`  | N/A — next macro-case is `D_backE_acc_*`. |
| `M_BackE`  | `RetRej` (child pop) | `PopTo_base+MarkRetRejOn` | `RetRej` | `M_BackE`  | **Both** branches are defined and mutually exclusive by the BackE return cases: after `RetRej` is on `p̄`, `D_backE_rej_next` applies iff `NextIncomp_c(CurA_p,CurB_p;x,y)`, else `D_backE_rej_exh_*` applies iff `NoNextIncomp_c(CurA_p,CurB_p)`. |

`[deduction]` The table has no row for `M_Eval` as a return-marker receiver:
`M_Eval` live frames are evaluated, not awaiting a child marker by this
primitive. A non-root `M_Eval` terminal produces a pop to its already-back
parent (`D_eval_acc_ret/D_eval_rej_ret` call `PopTo_base+MarkRet*On` on the
parent, whose mode is the stored `Back*` mode). Therefore no `M_Eval + Ret*`
receiver ambiguity arises on `I_{M_D}`-reachable states.

### 2.7 Deterministic update templates

```text
PushChildE(d̄,c̄,x,y) :=
  ChildFrameBase(d̄,c̄) ∧
  FrameLive'(d̄) ∧ M_Eval'(d̄) ∧ RetNone'(d̄) ∧ CtrlAdv'(d̄) ∧
  HasSel'(d̄) ∧ SelA'(d̄,x) ∧ SelB'(d̄,y) ∧
  HasCur'(d̄) ∧ CurA'(d̄,MinKey) ∧ CurB'(d̄,MinKey) ∧
  UsedF'(d̄,·)=UsedF(c̄,·) ∧ PosF'(d̄,·,·)=PosF(c̄,·,·) ∧ Parent'(d̄,c̄).

PushChildA(d̄,c̄,a,b,side) :=
  ChildFrameBase(d̄,c̄) ∧
  FrameLive'(d̄) ∧ M_Eval'(d̄) ∧ RetNone'(d̄) ∧ ¬HasSel'(d̄) ∧
  HasCur'(d̄) ∧ CurA'(d̄,MinKey) ∧ CurB'(d̄,MinKey) ∧
  PosF'(d̄,u,v) ↔ StepPosBit_c(side;u,v) ∧
  UsedF'(d̄,·)=SuccCtr(UsedF(c̄,·)) ∧
  PostBudgetFrom(PosF'_d,UsedF'_d; CtrlAcc',CtrlSort',CtrlRej') ∧
  Parent'(d̄,c̄),
where side=(a,b) for A0 and (b,a) for A1.

SetParentBackE_Advance(c̄,x,y) :=
  M_BackE'(c̄) ∧ RetNone'(c̄) ∧ FrameLive'(c̄) ∧
  HasCur'(c̄) ∧ SuccLex2((x,y),(CurA'(c̄),CurB'(c̄))) adjusted to last if needed ∧
  preserve Sel/PosF/UsedF/Ctrl-snapshot fields of c̄ required by DFS discipline.

SetParentBackA0(c̄) :=
  M_BackA0'(c̄) ∧ RetNone'(c̄) ∧ FrameLive'(c̄) ∧
  preserve HasSel/SelA/SelB/PosF/UsedF/HasCur/CurA/CurB of c̄.

SetParentBackA1(c̄) :=
  M_BackA1'(c̄) ∧ RetNone'(c̄) ∧ FrameLive'(c̄) ∧
  preserve HasSel/SelA/SelB/PosF/UsedF/HasCur/CurA/CurB of c̄.
```

`[deduction]` `StepPosBit_c`, `SuccCtr`, `PostBudgetFrom`, `SuccLex2`,
`FreshChild` are functional by the fixed local formulas and `I_{M_D}` uniqueness
of source fields; hence every primed field above is uniquely determined.

## 3. Complete case matrix

### 3.1 Reachability-closed partition keys

The matrix is over `I_{M_D}`-reachable states, keyed by
```text
K(E) = (Halt, Mode(Top), Ctrl(Top), Ret(Top), RootTop, HasSel, HasCur, NextIncomp_c/NoNextIncomp_c/NA)
```
with `Halt ∈ {yes,no}`, `Mode ∈ {Eval,BackE,BackA0,BackA1}`, `Ctrl/Ret` the
unique control/return readings, `RootTop ∈ {Root,Parent}`, selection/cursor
booleans coherent, and the final component `NA` unless a BackE/sort-exhaust
branch needs it. Rows unreachable by `I_{M_D}` are excluded and justified in
§3.4.

`NextIncomp_c/NoNextIncomp_c` is total relative to a fixed cursor on a live
`PosF` snapshot: either some incomparable pair at/after cursor exists (unique
lex-minimal witness by `NextIncomp_c`) or `NoNextIncomp_c` holds.

### 3.3 Exhaustivity and mutual exclusion
