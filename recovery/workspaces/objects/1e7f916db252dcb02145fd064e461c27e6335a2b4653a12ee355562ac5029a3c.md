## 1. Revised `Rbar` / frame schema

`[definition]` The whole configuration remains an interpretation of `Rbar`
with globals and live-frame table `E(Rbar)` as in normalized `Enc` §0. The
BackE cursor fields are revised by adding the consumer-visible exhaustion
component `CurExhausted`.

```text
Rbar := (Top,CurBase,EmptyStack,HaltAcc,HaltRej,
         M_Eval,M_BackE,M_BackA0,M_BackA1,
         RetNone,RetAcc,RetRej,
         CtrlSort,CtrlAdv,CtrlAcc,CtrlRej,
         UsedF,HasSel,SelA,SelB,
         HasCur,CurA,CurB,CurExhausted,   -- revised BackE cursor
         PosF,Parent,FrameLive).

Globals := (Top,CurBase,EmptyStack,HaltAcc,HaltRej).
E(Rbar) := [Globals] ⊕ [live-frame table: FrameLive(c̄) fields, incl. PosF(c̄,·,·)].
```

`[definition]` Revised canonical frame component tuple:

```text
Fld(c̄) := ⟨Mode,Ret,Ctrl,UsedF,HasSel,SelA,SelB,
            HasCur,CurA,CurB,CurExhausted,PosF,Parent⟩
Mode  = {M_Eval,M_BackE,M_BackA0,M_BackA1}
Ret   = {RetNone,RetAcc,RetRej}
Ctrl  = {CtrlSort,CtrlAdv,CtrlAcc,CtrlRej}

CurState(c̄) := Normal(a,b) | Exhausted.

CurExhausted(c̄)      -- unary frame predicate: cursor is exhausted.
CurNormal(c̄,a,b) := HasCur(c̄) ∧ CurA(c̄,a) ∧ CurB(c̄,b) ∧ ¬CurExhausted(c̄).

CursorWellFormed(c̄) :=
      (CurExhausted(c̄) ∧ ¬∃a∃b CurNormal(c̄,a,b))
    ∨ (¬CurExhausted(c̄) ∧ HasCur(c̄)
       ∧ ∃!a∃!b(CurA(c̄,a) ∧ CurB(c̄,b))).
```

`CurExhausted(c̄)` is the explicit field tuple/component realization of the
`Normal|Exhausted` state (equivalently, it is the distinguished exhausted
cursor encoding). No `SentinelLast` predicate on an ordinary `CurA/CurB` pair
is consulted by BackE consumers.

`[definition]` Revised frame-equality helpers (liveness discipline unchanged):

```text
FrameFieldsEq'(x̄) :=
  equality of all Fld components for x̄ and x̄', including CurExhausted,
  with no implicit liveness change.

FrameEq'(x̄)       := FrameFieldsEq'(x̄) ∧ (FrameLive'(x̄) <-> FrameLive(x̄)).
FrameInactive'(x̄) := ¬FrameLive'(x̄).
LowerStackPreservedExcept(S) :=
  ∀x̄(FrameLive(x̄) ∧ ¬S(x̄) -> FrameEq'(x̄)).

PreserveNonMarkerFields(p̄) :=
  preserve Fld components of p̄ except Ret, and preserve FrameLive'(p̄).
  -- in particular preserves HasCur,CurA,CurB,CurExhausted,PosF,UsedF,
  -- HasSel,SelA,SelB,Parent,Ctrl,Mode.

MarkRetAccOn(p̄) :=
  FrameLive'(p̄) ∧ RetAcc'(p̄) ∧ ¬RetRej'(p̄) ∧ ¬RetNone'(p̄)
  ∧ PreserveNonMarkerFields(p̄).

MarkRetRejOn(p̄) :=
  FrameLive'(p̄) ∧ RetRej'(p̄) ∧ ¬RetAcc'(p̄) ∧ ¬RetNone'(p̄)
  ∧ PreserveNonMarkerFields(p̄).
```

`[deduction]` Because `CurExhausted` is in `Fld` and `FrameFieldsEq'`, any row
that does not change `S(x̄)` or does not name `x̄` in an explicit cursor update
preserves `CurExhausted` by `FrameEq'` / `PreserveNonMarkerFields`. Reject-
producing pops (rows 5,9,12,14,17,19) therefore preserve the receiving frame's
`Normal|Exhausted` BackE cursor state.

## 2. Revised BackE cursor update: `SetParentBackE_Advance`

`[definition]` Local/semantic formulas `Lex2, SuccLex2, IsLastLex2, Incomp_c,
Total_c, Budget_c, P_c, NextIncomp_c, NoNextIncomp_c, SuccCtr, StepPosBit_c,
PostBudgetFrom, Root, NonRoot, CfgAcc_c, CfgRej_c` are as fixed in normalized
`Enc` §0/§1.5, except that BackE NI/NNI consumers below are revised to consult
`CurExhausted`.

```text
NextIncomp_c(a,b;x,y) := Lex2(a,b,x,y) ∧ Incomp_c(x,y)
                       ∧ ¬∃u∃v(Lex2(a,b,u,v) ∧ Lex2(u,v,x,y) ∧ Incomp_c(u,v)).
NoNextIncomp_c(a,b)   := ¬∃x∃y(Lex2(a,b,x,y) ∧ Incomp_c(x,y)).

SetParentBackE_Advance(c̄,x,y) :=
    FrameLive'(c̄)
  ∧ M_BackE'(c̄) ∧ ¬M_Eval'(c̄) ∧ ¬M_BackA0'(c̄) ∧ ¬M_BackA1'(c̄)
  ∧ RetNone'(c̄) ∧ ¬RetAcc'(c̄) ∧ ¬RetRej'(c̄)
  ∧ CtrlSort'(c̄) ∧ ¬CtrlAdv'(c̄) ∧ ¬CtrlAcc'(c̄) ∧ ¬CtrlRej'(c̄)

  -- consumer-visible cursor advance:
  ∧ (
        ( ¬IsLastLex2(x,y)
          ∧ ¬CurExhausted'(c̄)
          ∧ HasCur'(c̄)
          ∧ ∃x'∃y'(SuccLex2(x,y,x',y') ∧ CurA'(c̄,x') ∧ CurB'(c̄,y'))
          ∧ ∀a∀a'(CurA'(c̄,a)∧CurA'(c̄,a')->a=a')
          ∧ ∀b∀b'(CurB'(c̄,b)∧CurB'(c̄,b')->b=b')
        )
      ∨
        ( IsLastLex2(x,y)
          ∧ CurExhausted'(c̄)
          ∧ HasCur'(c̄)
          ∧ ¬∃a∃b(CurA'(c̄,a)∧CurB'(c̄,b))
        )
    )

  -- preserved non-cursor frame fields:
  ∧ HasSel'(c̄)<->HasSel(c̄)
  ∧ ∀a(SelA'(c̄,a)<->SelA(c̄,a)) ∧ ∀b(SelB'(c̄,b)<->SelB(c̄,b))
  ∧ ∀t(UsedF'(c̄,t)<->UsedF(c̄,t))
  ∧ ∀u∀v(PosF'(c̄,u,v)<->PosF(c̄,u,v))
  ∧ ∀p̄(Parent'(c̄,p̄)<->Parent(c̄,p̄)).
```

`[deduction]` The `IsLastLex2(x,y)` branch no longer introduces an uninterpreted
`SentinelLast` ordinary pair. It sets `CurExhausted'(c̄)` and removes any
normal `CurA'/CurB'` witness; consumers test `CurExhausted` directly. The
non-last branch uses `SuccLex2` and sets a unique normal cursor with
`¬CurExhausted'`.

`[open]` This update assumes `Cell×Cell` has a fixed FO/DTM-expressible
`SuccLex2/IsLastLex2` discipline and that the `∃!x'∃y' SuccLex2(...)` branch is
total on non-last pairs. The `IsLastLex2` branch requires no `CurA'/CurB'`
witness; realizations that keep `HasCur'` functional on all fields must still
satisfy `¬∃a∃b(CurA'∧CurB')` or an equivalent exhausted encoding — this is an
`Enc_Component_Closure` obligation (§5).

## 3. Revised BackE NI/NNI consumers and rows 10–12

`[definition]` `CurExhausted` is consulted before normal Lex2/no-next search:

```text
NI_c  := ¬CurExhausted(c̄)
       ∧ ∃a∃b(CurNormal(c̄,a,b) ∧ ∃x∃y NextIncomp_c(a,b;x,y)).

NNI_c := CurExhausted(c̄)
       ∨ (¬CurExhausted(c̄)
          ∧ ∃a∃b(CurNormal(c̄,a,b) ∧ NoNextIncomp_c(a,b))).

RejectEval_c :=
    CfgRej_c
  ∨ (CtrlSort(c̄) ∧ ¬Total_c ∧ ¬Budget_c)
```

## 4. Restated BackE obligations with corrected schema

The three obligations below are restated for the `Normal|Exhausted` schema.
Each is `[open]` unless its proof is supplied under `I_{M_D}` reachability,
`Enc_Component_Closure`, and row preservation; this note supplies no such
proof.

### 4.1 `BackE_Cursor_Preservation`

`[definition]` A BackE-reject-producing pop is any row whose target frame `p̄`
is a live BackE receiver and whose effect includes `MarkRetRejOn(p̄)` under the
corrected `PreserveNonMarkerFields(p̄)` (includes `CurExhausted`). The primary
producers are rows 5 and 12; rows 14,19 similarly preserve non-marker fields of
BackA receivers and are outside the BackE-cursor obligation except for shared
frame-schema closure.

`[open][lemma BackE_Cursor_Preservation]`
For every `I_{M_D}`-reachable transition
`E --D_i,S={p̄,c̄}--> E'` that is a BackE-reject-producing pop with
`M_BackE(E,p̄)` or `M_BackE(E',p̄)` as applicable, the BackE cursor state is
preserved until the next consuming BackE `RetRej` step on `p̄`:

```text
I_{M_D}(E) ∧ MarkRetRejOn-producing(E,D_i,p̄,c̄)
->  (CurExhausted(E',p̄) <-> CurExhausted(E,p̄))
  ∧ HasCur(E',p̄)=HasCur(E,p̄)
  ∧ (¬CurExhausted(E,p̄)
       -> ∃!a∃!b(CurNormal(E,p̄,a,b) ∧ CurNormal(E',p̄,a,b)))
  ∧ PosF(E',p̄)=PosF(E,p̄) ∧ UsedF(E',p̄)=UsedF(E,p̄)
  ∧ HasSel/SelA/SelB(E',p̄)=HasSel/SelA/SelB(E,p̄)
  ∧ Parent(E',p̄)=Parent(E,p̄) ∧ Ctrl(E',p̄)=Ctrl(E,p̄)
  ∧ M_BackE(E',p̄).
```

Moreover, no reachable row outside the named changed set mutates these fields
of `p̄` before the next `Top(p̄)∧M_BackE(p̄)∧RetRej(p̄)` consumer row.

**Proof obligations / shape.** (1) `MarkRetRejOn` preserves all non-`Ret`
components of `Fld`, including `CurExhausted,HasCur,CurA,CurB`. (2)
`LowerStackPreservedExcept(S)` preserves `FrameEq'` for live frames outside
`S`. (3) `Enc_Component_Closure` gives every row an explicit priming or
preservation clause for `CurExhausted` and cursor fields. (4) `I_{M_D}`
induction shows no alias/fresh-child/frame-live collision targets `p̄`'s
cursor slots while `p̄` is lower in the stack.

`[falsification-shape]` Cursor mutation between pop and consumer:
```text
I_{M_D}(E0) ∧ E0 --row 5 or 12, MarkRetRejOn(p̄)--> E1
  ⊢* E2 --D_j--> E3
with Top(E2,p̄)∧M_BackE(E2,p̄)∧RetRej(E2,p̄) as next consumer target
and ( (CurExhausted(E3,p̄) xor CurExhausted(E1,p̄))
    ∨ (¬CurExhausted(E1,p̄) ∧ CurNormal(E1,p̄,a,b) ∧ ¬CurNormal(E3,p̄,a,b))
    ∨ PosF/UsedF/HasSel/SelA/SelB/Parent/Ctrl/Mode of p̄ changed ).
```

`[falsification-shape]` Omitted `CurExhausted` from preservation:
```text
Row text/schema omits CurExhausted from PreserveNonMarkerFields or
FrameFieldsEq'; a realization leaves CurExhausted'(p̄) underdetermined after
row 5/12, making NI_c/NNI_c non-total at the next BackE_RetRej_Top(p̄).
```

### 4.2 `BackE_NI_NNI_Total_Complement`

`[open][lemma BackE_NI_NNI_Total_Complement]`
For every `I_{M_D}`-reachable state with
`BackE_RetRej_Top(c̄) := Top(c̄)∧FrameLive(c̄)∧M_BackE(c̄)∧RetRej(c̄)`:

```text
I_{M_D}(E) ∧ BackE_RetRej_Top(E,c̄)
->  CursorWellFormed(E,c̄)
  ∧ (NI_c(E) xor NNI_c(E))
  ∧ (NI_c(E) -> ∃!x∃y∃a∃b(
        CurNormal(E,c̄,a,b) ∧ NextIncomp_c(E,a,b;x,y))).
```

`[deduction]` (schema consequence, conditional on the antecedents). With
`CursorWellFormed`, fixed strict total `Lex2`, and fixed `Incomp_c` under the
preserved `PosF(c̄)` snapshot: if `CurExhausted(c̄)` then `NNI_c` and `¬NI_c`;
otherwise the unique `CurNormal(c̄,a,b)` makes `∃x∃y NextIncomp_c(a,b;x,y)` xor
`NoNextIncomp_c(a,b)` a total complement over finite `Cell×Cell`, and
`NextIncomp_c` selects a unique lex-first witness. This is not a full
reachability proof: `CursorWellFormed`, `PosF` coherence, and the uniqueness
of cursor fields remain `[open]`.

**Proof obligations / shape.** (1) `I_{M_D}` preserves `CursorWellFormed` for
live BackE frames. (2) `SetParentBackE_Advance` establishes the two branches:
non-last => unique `CurNormal`, last => `CurExhausted` and no normal witness.
(3) `Enc_Component_Closure` and row preservation prevent half-updated
`CurExhausted/HasCur/CurA/CurB` states. (4) `PosF(c̄)` used by `Incomp_c` is
the coherent state snapshot for the frame.

`[falsification-shape]` Non-total/overlapping consumer partition:
```text
I_{M_D}(E*) ∧ BackE_RetRej_Top(E*,c̄)
∧ ( (NI_c(E*) ∧ NNI_c(E*)) ∨ (¬NI_c(E*) ∧ ¬NNI_c(E*)) ).
```

`[falsification-shape]` Ill-formed cursor:
```text
I_{M_D}(E*) ∧ BackE_RetRej_Top(E*,c̄)
∧ ¬CursorWellFormed(E*,c̄),
e.g. CurExhausted(c̄)∧CurNormal(c̄,a,b), or
     ¬CurExhausted(c̄)∧¬∃a∃b CurNormal(c̄,a,b), or
     two distinct CurNormal witnesses.
```

`[falsification-shape]` NI witness non-unique:
```text
I_{M_D}(E*) ∧ BackE_RetRej_Top(E*,c̄) ∧ NI_c(E*)
∧ two distinct (x,y)!=(x',y') satisfy NextIncomp_c from the same CurNormal.
```

### 4.3 `BackE_AfterSelected_NoReselect`

`[open][lemma BackE_AfterSelected_NoReselect]`
Let `E --D_i--> E1` be an `I_{M_D}`-reachable BackE selection step that
selects incomparable pair `(x,y)` by row 6 or row 10 and applies
`SetParentBackE_Advance(c̄,x,y)`. Then every later reachable
`BackE_RetRej_Top(E2,c̄)` state for the same live BackE frame `c̄`, reached
without another selection/advance on `c̄` that overwrites its cursor, cannot
NI-witness `(x,y)` again.

Formally:

```text
I_{M_D}(E) ∧ SelectsBackE(E,D_i,c̄,x,y)
∧ E --D_i--> E1 ⊢* E2
∧ BackE_RetRej_Top(E2,c̄)
∧ CursorOf(c̄) not overwritten between E1 and E2
-> ¬NIWitness(E2,c̄,x,y).
```

**Case split (schema-level).** If `¬IsLastLex2(x,y)`, `E1` stores
`CurNormal(c̄,x',y')` with `SuccLex2(x,y,x',y')`; strict total `Lex2` implies
`¬Lex2(x',y',x,y)`, so `NextIncomp_c(x',y';x,y)` is impossible. If
`IsLastLex2(x,y)`, `E1` stores `CurExhausted'(c̄)` and no normal witness; the
corrected `NI_c` requires `¬CurExhausted(c̄) ∧ CurNormal(...)`, so
`NI_c(E2)` cannot witness `(x,y)` or any pair from an exhausted cursor.

**Proof obligations / shape.** (1) `BackE_Cursor_Preservation` along the path
`E1 ⊢* E2` for the unchanged cursor. (2) Uniqueness of `NextIncomp_c` witness
and functional NI selection in rows 6,10. (3) `SetParentBackE_Advance`
establishes the post-advance cursor as above. (4) `I_{M_D}` excludes any row
that overwrites `c̄`'s cursor except the intended BackE advance rows.

`[falsification-shape]` Last-pair reselect (sentinel regression):
```text
I_{M_D}(E) ∧ IsLastLex2(x,y)
∧ E --row 6 or 10, SetParentBackE_Advance(c̄,x,y)--> E1
  ⊢* E2
∧ BackE_RetRej_Top(E2,c̄) ∧ NIWitness(E2,c̄,x,y).
```
This is the refutation's explicit trace locus; under the corrected schema it
requires violating `CurExhausted'(c̄)` or `NI_c`'s `¬CurExhausted` guard.

`[falsification-shape]` Non-last reselect:
```text
¬IsLastLex2(x,y) ∧ SuccLex2(x,y,x',y')
∧ post-advance cursor CurNormal(c̄,x',y') preserved to E2
∧ BackE_RetRej_Top(E2,c̄) ∧ NIWitness(E2,c̄,x,y).
```
This requires breaking strict `Lex2`/`SuccLex2`/preservation.

`[falsification-shape]` Spurious exhaustion or spurious normal cursor:
```text
¬IsLastLex2(x,y) ∧ SetParentBackE_Advance(c̄,x,y) makes CurExhausted'(c̄),
or IsLastLex2(x,y) makes CurNormal'(c̄,·,·).
```

## 5. Remaining obligations

`[open]` This revision does not discharge `[CKS-AV-POST-HALT/I_M_D-DET-SUCC]`.
The following obligations remain, including obligations introduced or made
explicit by the `CurExhausted` field:

1. **`Enc_Component_Closure` for `CurExhausted`.** Every matrix row `D_i` must
   have an FO/DTM-expressible total update `U_i` on `Rbar∪Globals` with
   `CurExhausted'` explicitly primed in rows that change the BackE cursor
   (`SetParentBackE_Advance` / row 6 / row 10 and any eval cursor-init path),
   and otherwise in `LowerStackPreservedExcept(S_i)` or an explicit global
   preservation clause. Terminal rows must fix `Top'/FrameLive'/EmptyStack'/
   CurBase'` and not leave `CurExhausted'` underdetermined on cleared frames.
   `[falsification-shape]` any `D_i` whose update omits `CurExhausted'` on a
   changed or live cursor-bearing frame.

2. **`I_M_D` preservation for the revised cursor schema.** Induction over all
   19 rows must preserve: unique `Top'`; `ExactlyOneMode`; coherent
   `Ret`/`Ctrl`; `CursorWellFormed` on relevant live/BackE frames; unique
   `HasCur/CurA/CurB/CurExhausted` interpretation; functional `Parent` on
   active non-root frames; unique `UsedF`; coherent `HasSel/SelA/SelB`;
   root-to-top active path discipline; `[SYM-TOP]` push/pop uniqueness; and
   no-spurious alignment of local semantic formulas. `[falsification-shape]`
   any reachable row producing a half-updated or duplicated cursor state.

3. **`BackE_Cursor_Preservation`** (§4.1), **`BackE_NI_NNI_Total_Complement`**
   (§4.2), **`BackE_AfterSelected_NoReselect`** (§4.3), all under
   `I_{M_D}` reachability and component closure.

4. **Eval/initial cursor coherence.** The first `CtrlSort`/BackE-relevant
   cursor state (root initialization, `PushChildE`, and any `CtrlSort` eval
   entry) must initialize `CurExhausted/HasCur/CurA/CurB` to satisfy
   `CursorWellFormed` and make row 6 / `RejectEval_c` use the intended NI/NNI
   partition. `[falsification-shape]` reachable `M_Eval,CtrlSort` or initial
   BackE parent with missing/exhausted/normal cursor not matching row 6 and
   reject-exhaustion guards.

5. **Unchanged normalized obligations.** Marker-receiver reachability
   (`MarkerReceiver_Is_BackStar`, `No_Eval_RetMarker_Top`,
   `No_BackStar_RetNone_Consuming_Top`), A1 preserved snapshot
