# exec-report: framed-DAG certificate for n=7 at height 13

## Summary

Constructed and verified an explicit permutation-framed comparison DAG
certificate showing `S(7) <= 13`. Since `S(7)=13` is known (information
bound meets Ford–Johnson for n<=11), this is an optimal-height
certificate for n=7. The final certificate has **19 nodes, 36 edges, 1
leaf** and maximum path length **13**. It was accepted by the existing
checker `scripts/check_framed_strategy.py`.

Artifact: `artifacts/framed_n7_canonical_opt.json`
SHA-256: `1887b20a2376a2f84cb50174f20f596b5dded3fae013a1455988180527643bb1`

## Evidence labels

- **Literature**: `S(7)=13` (research-plan.md baseline table; Ford–Johnson
  meets `ceil(log2 7!) = 13`).
- **Definition**: framed certificate grammar and soundness checker in
  `scripts/check_framed_strategy.py` and `docs/research-framed-certificate-frontier.md`.
- **Experiment**: minimax DP over all reachable posets for n=7; canonical
  poset quotient and optimal-move DP.
- **Deduction**: chosen comparisons satisfy `F(P)=1+max(F(P+a<b),F(P+b<a))`,
  so by induction every path sorts within 13 comparisons.
- **Kernel-checked**: none for this artifact (checker is executable Python,
  not Lean).

## Construction method

1. Computed exact minimax values `F(P)` for every poset reachable for n=7
   using the recurrence in `scripts/strategy_dag_probe.py` (memoized poset
   DP). Result: `6,129,859` states in `185.11 s`; `F(empty)=13`.
2. Enumerated, for each canonical poset, all comparison pairs `(a,b)` that
   are optimal (i.e. `1+max(F(P+a<b),F(P+b<a))=F(P)`).
3. Canonicalized posets under `S_7`: for a poset `Q`, its canonical
   representative is the lexicographically smallest `_rename(Q, pi)` over
   all `pi in S_7`, and the argmin `pi` is retained as the edge frame.
   This makes all isomorphic slot-labelled posets share one node.
4. Chose, at each canonical state, the optimal comparison minimizing the
   size of the union of reachable canonical-state sets in its two
   subtrees (dynamic programming with memoization). This reduced the
   reachable state count from 36 (first-move policy) to 19.
5. Hash-consed nodes by canonical poset, topologically numbered so every
   edge goes from a lower index to a higher index, and emitted the checker
   JSON format with `budget=13`.

The DP and canonicalization scripts were run locally
(`/tmp/opencode/build_opt_canonical_cert.py`); the resulting JSON is the
only certificate artifact retained.

## Limits

- The certificate covers only `n=7`; it is not an all-`n` construction and
  does not by itself imply `SORT-BOUND-U in NP`.
- 19 nodes is minimal within this canonical-poset sharing scheme and chosen
  optimal-move DP, but global minimality over arbitrary framed DAGs with
  non-isomorphic joins/intersections is not proved.
- The minimax value computation is an experiment (memoized Python DP), not a
  Lean proof; no Lean files were added or changed.
- No claim is made about polynomial-size certificates for all n.
