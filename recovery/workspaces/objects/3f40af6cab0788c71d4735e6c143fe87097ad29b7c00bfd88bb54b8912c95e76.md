## Sharp falsifiable all-`n` question

**Q (effective finite Sergeev bound).** Does Sergeev's group-insertion argument yield an explicit finite function `W : ℕ → ℕ` with
`S(n) ≤ ⌈log₂(n!)⌉ + W(n)` for all `n` (or for all `n ≥ N0` with explicit `N0`, constants), where `W(n)` is computable in time polynomial in the unary input length `n` (equivalently in the threshold input `N=n+k+1` context) and such that the resulting upper window `k ≤ ⌈log₂(n!)⌉ + W(n)` strictly improves/shrinks the decision window used to evaluate `S(n)` / `SORT-BOUND-U` compared to currently explicit uniform bounds (e.g. merge-sort/Ford–Johnson-style explicit envelopes)?

**Falsifiers / decision criteria:** (a) an explicit extracted `(N0,C,W)` with a verifiable derivation from the published construction; or (b) a demonstrated violation on a known `n` for a proposed explicit `(N0,C)`; or (c) a precise, proof-localized obstruction showing why the published argument is non-effective as stated (which parameters/constants/steps are untracked or require a non-finitary choice).

## Consequence for evaluating `S(n)` / `SORT-BOUND-U`

- **If an effective, polynomial-time computable `W(n)` with `S(n) ≤ C(n)+W(n)` were obtained (all sufficiently large `n`, explicit):** it would give a *sound* explicit upper endpoint for the threshold search window. For the budgeted-DFS/unary-threshold perspective (depth/cost driven by `k = S(n)` on the final yes-instance), narrowing the *a priori* upper search limit from an `O(n log n)` envelope to `C(n)+W(n)=n log₂ n - n log₂ e + O(log n)+W(n)` can reduce binary-search/verification work in practice and, if `W(n)` is sublinear and explicit, would sharpen the known effective upper envelope on `S(n)-C(n)`. It would **not by itself** imply `SORT-BOUND-U ∈ NP`, `∈ P/FP`, or any separation; and because the dominant exponential term is governed by the true/near-true depth `~n log n`, an `o(n)` improvement in window width alone does not change the established asymptotic time-exponent form `2^{O(n log^2 n)}` of the current DFS analysis.
- **Current state (blocker):** no explicit finite computable `W(n)` is extracted from the published Sergeev proof as written; therefore Sergeev's asymptotic theorem presently constrains theory (`S(n)-C(n)=o(n)`) but does **not** provide an effective finite decision-window shrinkage for uniform evaluation of `S(n)`/`SORT-BOUND-U`. Known explicit algorithms (e.g. merge-insertion/Ford–Johnson envelopes) remain the effective finite upper bounds.
