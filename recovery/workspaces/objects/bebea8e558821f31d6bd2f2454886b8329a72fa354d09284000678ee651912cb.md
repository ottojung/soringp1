**Date:** 2026-11-17.  
**Scope:** unary/adaptive comparison model as fixed in `docs/problem.md`; function/value question is `S(n)` (not a complexity-class separation claim).

## 1. Falsifiable question and consequence

**Question.** Is there a *global/strategic* computable invariant, beyond local scalars of a single state, that characterizes when the information bound is non-tight, i.e. when `S(n) > C(n)` with `C(n)=⌈log₂ n!⌉`, for all `n`?

To make this falsifiable I fix a natural candidate class and test it:

> **Class `L_k` (k-ply extension-balance / lookahead information bound).**
> For a poset state `P`, depth `d`, and total height budget `h`, define recursively
> - `L₀(P,d,h) = 0` if `e(P) ≤ 2^(h-d)`, else `+∞` (leaf-count admissibility);
> - `L_{k}(P,d,h) = 0` if `P` is total, else `1 + min_{(u,v)∈Inc(P)} max(L_{k-1}(P+u<v,d+1,h), L_{k-1}(P+v<u,d+1,h))`, with the convention `+∞` dominates.
>
> Let `Cert_k(n)` mean `L_k(A_n,0,C(n)) < +∞`, where `A_n` is the antichain on `n`.

**Hypothesis H (global/strategic characterization by bounded ply).** There exists a fixed `k` (or a uniform computable `k(n)` in a specified small class) such that for all `n`, `S(n)=C(n) ⇔ Cert_k(n)`.

**Consequence if true.** A uniform finite-ply certificate/refutation at the root would give a *strategic* necessary-and-sufficient condition for tightness stronger than the global leaf count, potentially localizing the obstruction to bounded-depth balance constraints and guiding search/pruning for `S(n)` (an upper/lower-bound structural result, not a complexity separation).  
**Consequence if false (for the class).** It rules out the entire natural family of bounded-lookahead extension-balance invariants as all-`n` characterizations: the `S(n)>C(n)` gap can be a deep strategic phenomenon invisible to any fixed horizon of leaf-count reasoning from the root.

## 2. Known baseline (literature)

## 3. Derivation: what bounded ply can and cannot see

### 3.1 `L_k` is a sound strategic necessary condition

**Deduction.** By induction on `k`:
- `k=0`: if a height-`h` tree sorts `P` from depth `d`, it has `≤2^(h-d)` leaves above `P`, so `e(P) ≤ 2^(h-d)`.
- step: if `m(P) ≤ h-d` (true remaining minimax value), some comparison yields both children with `m(child) ≤ h-d-1`, hence by IH with horizon `k-1` both satisfy `L_{k-1}(...)=0`, so `L_k(P,d,h)=0`.

Therefore `S(n) ≤ h ⇒ Cert_k(n)` for all `k,n`. Equivalently, **`¬Cert_k(n)` is a computable sufficient witness that `S(n)>C(n)`** (a k-ply refutation). This is genuinely global/strategic: it quantifies over root moves and adversarial replies up to depth `k`.

### 3.2 Root symmetry collapses ply 1

**Deduction.** From `A_n`, every comparison is symmetric and splits linear extensions exactly in half: `e = n!/2` and `n!/2`. Thus for budget `h=C(n)`,
`L₀(child,1,C(n))=0` because `⌈log₂(n!/2)⌉ = C(n)-1 = h-1`. Hence
`L₁(A_n,0,C(n)) = 1 + max(0,0)=1 < +∞` for all `n ≥ 2`. So **ply 1 never separates any `n`**.

### 3.3 Ply 2 already needs a realized 1/2-balance path, but does not detect `n=12`

**Deduction / elementary calculation.** Let `P₁` be the root child (one fixed comparison). `Cert₂(n)` holds iff there exists some second comparison in `P₁` with both grandchildren satisfying `e ≤ 2^(C(n)-2)`. Since `e(P₁)=n!/2`, a grandchild has `e ≤ 2^(C(n)-2)` iff its split fraction is `≤ 2^(C(n)-2)/(n!/2)=2^(C(n)-1)/n! = 2^(C(n))/ (2 n!)`.

- For `n=12`, `2^(C)/n! = 2^29/479001600 = 536870912/479001600 ≈ 1.1208`, so the admissible grandchild fraction threshold is `≈0.5604` of `e(P₁)`. Any comparison in `P₁` that produces a 1/2 split (e.g. comparing two elements still free/unrelated in that state) gives grandchildren of size `n!/4` with fraction `0.5 ≤ 0.5604`, hence `L₀=0` at depth 2. Therefore `L₂(A_12,0,29) < +∞` (**`Cert₂(12)` holds**).  
- But **literature** gives `S(12)=30>29`.

This matches the "forced balanced prefix" discussion in `docs/research-n12-nontightness.md` (H4): at `n=12` 1/2-split second moves are admissible while 2/3,5/6 are not, yet global tightness still fails deeper. The 2-ply invariant correctly captures the *local* prefix constraint but is globally unsound as a characterization (it yields a false positive for tightness at `n=12`).

### 3.4 General form of the ply-`k` root condition

**Deduction.** Unfolding `L_k(A_n,0,C(n)) < +∞` gives: there exists a rooted comparison strategy prefix of depth `k` such that along every adversarial reply within it, the state at depth `j ≤ k` has
`e(P_j) ≤ 2^(C(n)-j)`, i.e. cumulative split fractions satisfy
`∏_{i<j} f_i ≤ 2^(C(n)-j)/n! = (2^{C(n)}/n!) / 2^j`, where `f_i ∈ (0,1)` is the heavier-child fraction at step `i`.

Define the *global slack* `σ(n)=2^{C(n)}/n! ∈ (1,2]`. Ply `k` requires sustaining a root-to-depth-`k` path whose per-step information debt never exhausts `σ(n)` early. This is a **global/strategic balance invariant of horizon `k`** (it constrains an adversarial path, not a single scalar of one unrelated state except through the path), and it strictly refines pure leaf counting by enforcing all intermediate levels.

## 4. All-`n` attempt: can any bounded ply characterize tightness?

### 4.1 Necessary direction holds uniformly; sufficiency is the obstruction

**Deduction.** For all `k,n`, `S(n)=C(n) ⇒ Cert_k(n)` (§3.1). So the class is a sound family of necessary conditions/certificates for tightness, and `¬Cert_k` is a sound gap witness. The characterization question reduces to the converse: does `Cert_k(n)` ever fail to imply `S(n)=C(n)`? Yes at finite `k`: §3.3 shows `Cert₂(12)` but `S(12)>29`.

### 4.2 Finite-horizon obstruction (specified class)

**Deduction (obstruction for fixed `k`).** Fix any constant `k ≥ 0`.
- `Cert_k(n)` inspects only the induced minimax/playout constraints within depth `k` from the root (a `k`-ply game tree prefix scored by `L₀`).
- `S(n)>C(n)` means *every* full height-`C(n)` strategy eventually violates the leaf-count constraint at some depth `d ≤ C(n)`.

A fixed-horizon certificate `Cert_k(n)` can only refute tightness when a violation is forcible within `k` plies; it cannot express obstructions that first become unavoidable at some depth `d(n)>k`. But `n=12` is exactly such a case relative to `k=2` (and relative to `k=1` trivially), with the actual emptiness/obstruction certified deeper by exhaustive search (Wells/Stober–Weiß; `docs/research-n12-nontightness.md` §4,8). Since `C(n) ~ n log₂ n` grows unbounded while fixed `k` does not, a fixed `k` examines a vanishingly small prefix of the height-`C(n)` strategy space as `n` increases.

**Therefore (obstruction, class `L_k` with fixed `k`):** no fixed bounded-ply extension-balance invariant characterizes `S(n)>C(n)` for all `n`; each fixed `k` is sound but incomplete for sufficiency, with `n=12` a concrete counterexample already for `k ≤ 2`.

### 4.3 What about adaptive/unbounded `k(n)`?

**Deduction.**
- If `k(n) ≥ C(n)`, then `L_{C(n)}(A_n,0,C(n)) < +∞` ⇔ `S(n) ≤ C(n)` by definition/unfolding (the horizon reaches the leaves). This is a characterization but it is **tautological/strategic-complete**: it is equivalent to solving the full height-`C(n)` minimax game, not a simplifying invariant.
- If `k(n)=o(C(n))` or any function not covering the full depth, the finite-horizon obstruction schema applies: sufficiency would require that every global gap be witnessed within the first `k(n)` plies for all `n`, a strong uniform-depth property for which there is no evidence and which fails the spirit of a "beyond full search" invariant. (No counterexample is computed here beyond `n=12,k=2`; status of intermediate growth rates is **open**.)

## 6. Consequence and next decisive obstacle

**What this establishes (fresh, scoped).** The `k`-ply extension-balance family `L_k` is a rigorous hierarchy of **global/strategic, computable necessary conditions** for `S(n)=C(n)` that strictly generalize the root leaf count by enforcing pathwise balance over a horizon. It is sound for all `k,n`, collapses at `k=1`, and is already insufficient at `k=2` for `n=12`. Hence, within this natural class, **no bounded-lookahead leaf-count invariant can characterize the gap for all `n`**; the gap is not a bounded-prefix phenomenon even when prefix balance is forced.

**Relation to prior work (distinct tack).** Prior notes falsified *state-local* scalars and exhibited *poset-level* strengthenings (`L₁` at states, merge/series factors). This report lifts the question to a *rooted strategic horizon* class and gives a finite-horizon obstruction argument with an explicit all-known-`n` consistency check, targeting "characterizes when `S(n)>C(n)` across all `n`" rather than explaining a single state.

**Decisive obstacle.** Any non-tautological invariant that truly characterizes `S(n)>C(n)` for all `n` must either (a) be sensitive to properties that may only certify infeasibility at unbounded/late depth (beyond any fixed `k`), or (b) compress the full height-`C(n)` adversarial game into a polynomially-checkable global predicate. Option (a) demands identifying a *depth-uniform structural obstruction* (not visible at fixed ply) that persists to the leaves; option (b) is tantamount to a succinct certificate/characterization of the minimax value and runs into the exponential-tree witness barrier (`docs/problem.md`, `docs/research-certificates-barriers.md`). Pinpointing which of (a)/(b) is even plausible for the antichain family — e.g. by proving a lower bound on the *first* forced-failure depth as a function of `n` — is the next sharp question.
