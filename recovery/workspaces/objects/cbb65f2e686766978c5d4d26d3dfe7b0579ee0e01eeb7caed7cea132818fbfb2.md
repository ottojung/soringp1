## 2. Sharp falsifiable question

For all sufficiently large `n`, with unary input `1^n` for `S_unary` or `1^n # 1^k` of length `N=n+k+1` for `SORT-BOUND-U`:

- Is there a uniform deterministic algorithm that computes/decides exactly, using `o(n log^2 n)` ordinary (free) bits, polynomial-size catalytic or reversible workspace, and time `sub-2^{O(n^2)}`?
- Or does every such exact method require `Ω(n log^2 n)` ordinary bits?

**Consequence.** A positive result would improve the unary space upper bound below `n log^2 n`. A negative result would extend the winning-frontier barrier from path- and state-storing paradigms to catalytic/reversible computation. Neither outcome is obtained here.

## 3. Known baseline

- Standard transcript-only budgeted DFS decides `SORT-BOUND-U` in time `2^{O(N log N)}` and space `O(N log N)` bits; for the numeric function `S_unary(1^n)` it gives `2^{O(n log^2 n)}` time and `O(n log^2 n)` space (`docs/research-budgeted-dfs.md`).
- The winning-frontier construction gives `2^{(1/4-o(1)) n log^2 n}` pairwise nonisomorphic winning partial orders at budget `S(n)` (`docs/research-winning-frontier-barrier.md`; tests pass).
- This construction is a sound family of winning states: each `P_A` is reachable in `t` comparisons and satisfies `F(P_A) <= S(n)-t`. It is not a completeness/certificate result: it does not provide a polynomial certificate for `SORT-BOUND-U`, and it does not prove that every exact evaluator must store one of these states.

## 4. What the state-storing barrier does and does not cover

**Covered (paper-level).** Path/transcript-storing DFS and state-storing/checkpoint-resumable paradigms must distinguish `2^{Ω(n log^2 n)}` winning states, hence require `Ω(n log^2 n)` bits. This is a barrier for paradigms whose current configuration is (or determines) a resumable poset state.

**Not covered.** Catalytic and reversible paradigms are not state-storing in this sense:
- Catalytic space may transform polynomial-size auxiliary memory and restore it at the end; its intermediate contents can encode state without being a classical poset state.
- Reversible computation may use trace/uncompute strategies and need not expose a single resumable poset configuration.
- Implicit, oracle, and algebraic methods may evaluate the minimax value without enumerating the frontier at all.

Therefore the existing barrier does not, by itself, imply `Ω(n log^2 n)` for catalytic/reversible algorithms. This is the precise open gap.

## 5. Candidate routes examined

### 5.1 Catalytic simulation of the standard DFS

**Idea.** Store the current transcript/poset in catalytic memory and use `O(log n)` free bits to address/update it, simulating the standard DFS.

**Obstruction.** This requires a catalytic procedure that works for arbitrary initial catalytic contents and restores them exactly. No such general simulation of this adaptive comparison game is known. Known catalytic tree-evaluation results apply to explicitly given trees, not to an implicitly generated game tree whose nodes are poset states of size `Θ(n log^2 n)` bits. The recent "polynomial-time almost logarithmic free space" tree-evaluation claim (Asadi-Cleve, 2026) is withdrawn and cannot be relied on.

### 5.2 Reversible (Bennett-style) simulation

**Idea.** Make the DFS reversible, using catalytic/reversible workspace to avoid storing the transcript.

**Obstruction.** Reversible simulation of an irreversible computation generally requires storing history or paying a large time/space tradeoff. No concrete scheme yields `o(n log^2 n)` free bits for exact backtracking in the adaptive AND-OR game tree while keeping `sub-2^{O(n^2)}` time. Standard reversible pebbling does not obviously reduce below the `log` of the tree size, which here is `Θ(n log^2 n)`.

### 5.3 Tree-evaluation methods

The game `CanSort(∅,k)` is an AND-OR tree of depth `O(n log n)` and branching `O(n^2)`, hence size `2^{O(n log^2 n)}`. The standard DFS already uses `O(log size)=O(n log^2 n)` bits. Cook-Mertz-style tree evaluation gives `O(log size log log size)` bits, which is larger, not smaller, than the standard bound. Catalytic pebbling for explicit trees uses free space `Θ(log size)`, the same order. Thus these methods do not beat `n log^2 n`; they are designed for trees whose height is large relative to `log size`, which is not our bottleneck.

### 5.4 Counting the winning frontier

The frontier has `2^{Ω(n log^2 n)}` states. But a catalytic machine with polynomial memory has `2^{poly(n)}` possible tape contents, so counting possible states does not, by itself, force `Ω(n log^2 n)` free bits. A stronger argument would need to show that the frontier states are incompressible under polynomial-size catalytic memory or that the catalytic transformation must be (approximately) identity on a large subset. No such argument is currently available.

### 5.5 General-poset hardness

Hardness results for minimax over arbitrary partial orders do not transfer to the fixed family `S(n)` without an encoding-preserving reduction. This report does not use such a transfer. The frontier family is specific to the sorting game, but its lower-bound force is paradigm-specific.

## 6. Soundness vs completeness distinction

- **Soundness:** accepting a certificate implies `S(n) ≤ k`. The winning-frontier theorem does not provide certificates; it counts states.
- **Completeness:** every true instance has a small certificate. The frontier count says many winning states exist, not that they can be described succinctly.
- A future catalytic algorithm would be an upper-bound/algorithmic result, not a certificate-completeness result. A future barrier should be stated as a lower bound on computation, not confused with NP/coNP membership.

## 7. Falsification attempts

- **Lower-bound side:** tried to extend the state-storing barrier to catalytic/reversible paradigms by counting winning states and by arguing that catalytic memory must restore its initial contents. The first fails because catalytic contents can vary; the second is not a proof for this problem. No general lower bound obtained.
- **Upper-bound side:** tried to find an explicit uniform algorithm with `o(n log^2 n)` free bits among catalytic simulation, reversible uncomputation, tree evaluation, and frontier compression. No construction with proved space accounting was found.
- **Small/experimental evidence:** existing winning-frontier tests pass (`4 tests`), confirming the state count. No new discriminating experiment was run; none is known that would settle the catalytic question.

## 8. Conclusion

The question is **open**. The current best upper bound remains `O(n log^2 n)` ordinary bits. The state-storing barrier explains this bound for path- and state-storing paradigms, but it does not cover catalytic or reversible computation. We have neither an explicit `o(n log^2 n)`-bit catalytic/reversible algorithm nor a proof that such an algorithm is impossible. Progress requires either a genuine catalytic/reversible evaluation construction with exact accounting, or a new lower-bound technique for catalytic space on implicitly defined game trees.
