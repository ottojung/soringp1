# Critical-depth reachable-class barrier for canonical memoisation

**Status:** research note (2026-10-27). Everything below is a **deduction**
(all-n paper proof) plus a **bounded experiment** (`scripts/critical_depth_memo_barrier.py`,
`tests/test_critical_depth_memo_barrier.py`). No Lean file and no complexity-class
separation is claimed. This refines `docs/research-time-exponent.md`: its
staircase family has Θ(n²) move orbits but needs Θ(n²) comparisons to be
*reached*, so it is invisible to a budgeted DFS within the critical
comparison depth `Θ(n log n)`. The barrier below repairs exactly that gap.

## Precise question (front F301-time)

Can `S_unary(1^n)` be computed in `2^{O(n log n)}` or `2^{O(n)}` time by a
memoization / interface-summary evaluator that provably stores or recomputes
everything it needs, or is there an all-n family of reachable states forcing
any such evaluator to distinguish an `Ω(n²)`-bit state summary?

The known transcript-only budgeted DFS bounds are `2^{O(N log(N+2))}` time on
`1^n # 1^k` (`N = n+k+1`, `research-budgeted-dfs.md` §5.3) and
`2^{O(n log² n)}` time for the numeric function. Both come from the recursion

    CanSort(P, b) = 1  iff  P total, or some incomparable pair x,y has
                             both CanSort(P+x<y, b−1) and CanSort(P+y<x, b−1) = 1,

which on a **no-instance** threshold `k < S(n)` explores *every* node of the
full depth-`k` game tree: every legal comparison sequence is walked.

## Theorem (deduction, all n ≥ 8; quantitative for n ≥ 16)

For `n ≥ 8` let `m = ⌊n/2⌋` and `k = ⌈log₂ n!⌉ − 1`. The decision-tree
information bound gives `S(n) ≥ ⌈log₂ n!⌉ > k`, so the threshold instance
`1^n # 1^k` is a **no-instance** (this holds even when the information bound
is tight, as it is for n ≤ 6). For `j ≤ k` let `H_j` be the family of
posets on `2m` labelled keys whose only relations are `a < b` for the edges
`b` of some `j`-element subset of a fixed bipartition `A ⊔ B`, `|A| = |B| = m`
(see `research-time-exponent.md` §1 — this is a height-2 poset, transitive
because no relation leaves a `B`-element or enters an `A`-element).

1. **(Exact reachability at minimal depth.)** Every member of `H_j` is
   reachable from the antichain by **exactly j** legal comparisons, each
   adding exactly one comparable pair; its minimal comparison depth is
   exactly `j`.
   *Proof.* Edges only go `A → B`, so no `A`-element has a predecessor and
   no `B`-element has a successor; adding the absent edge `a < b` therefore
   creates comparability for `(a,b)` only (a `z < a` would give `z < b`, but
   `a` has no predecessors; a `b < w` analogously fails). The current state
   after a sequence of edges is a subset of the target's relations, and edges
   are never implied by other edges (an implication chain would need a
   vertex in `A ∩ B`, which is empty). Hence each edge is a legal comparison
   when added. A state of `H_j` has exactly `j` comparable pairs and the
   antichain has none, while every comparison adds at least one comparable
   pair: minimal depth is exactly `j`. ∎ (machine-checked for `m ≤ 6`,
   random edge sets, 400 trials each size)

2. **(Implication for exhaustive no-instance evaluation.)** The depth-`k`
   deterministic DFS evaluates *every* state reachable by a legal sequence
   of `≤ k` comparisons (each node tries every incomparable pair and
   recurses into both outcomes). Since `j = min(k, ⌊m²/2⌋) ≤ k`, every member
   of the *no-isolated subfamily* `H'_j` (both bipartition sides fully
   covered by edges) is visited. Every member of `H'_j` is its own
   isomorphism type up to the group `S_m × S_m`: with no isolated vertex, an
   isomorphism maps out-degree>0 vertices to out-degree>0 vertices and
   in-degree>0 to in-degree>0, hence preserves `A` and `B` as sets, so each
   orbit has size ≤ `(m!)²`. Hence the visited state set contains at least

       CS(n) ≥ CI(m, j) / (m!)²

   pairwise distinct (canonical-memo-key) classes, where

       CI(m, j) = Σ_{a,b ≤ m} (−1)^{a+b} C(m,a) C(m,b) C((m−a)(m−b), j)

   is the exact number of `j`-edge subsets covering both parts
   (union bound: `CI(m,j) ≥ C(m², j)·(1 − 2m(1−1/m)^j)`, and
   `2m·(1−1/m)^j ≤ 2m·e^{−j/m} ≤ 17.9·n^{−1.885} < 1` for `n ≥ 5` by
   `lg n! ≥ n lg n − 1.4427n`, so the multiplier is uniformly positive).

   Consequently:
   - a **canonical-memoised** evaluator (memo keys = isomorphism classes)
     must both *visit* ≥ `CS(n)` distinct classes — exhaustive recursion
     reaches every legal trajectory, hence every class, at least once;
     memoisation only shortcuts *repeat* visits — and *populate* ≥ `CS(n)`
     table entries ⇒ time and space ≥ `2^{L(n)}`;
   - a **non-memoised** evaluator visits ≥ `CS(n)` distinct labelled states
     ⇒ time ≥ `2^{L(n)}`;

   where

       L(n) = log₂ CI(m, j) − 2 log₂(m!)
            = n log₂ n · (log₂ n − log₂ log₂ n + O(1)) − Θ(n log n)
            = Θ(n log² n) = ω(n log n).

   Verified by exact big-integer inclusion–exclusion `CI(m, j)` for all
   `16 ≤ n ≤ 88` (`m ≤ 44`) and by the analytic union bound for all
   `n ≥ 89`. Values: `L(16)=30.0`, `L(24)=82.4`, `L(32)=161.8`,
   `L(64)=646.5`, `L(256)=6385.5`, `L(1024)=47662.7` bits, where
   `n log₂ n = 10 240` at `n = 1024`. The table is monotone for `n ≥ 16`
   in steps of two and checked positive for every `8 ≤ n ≤ 24`.

**Corollary (barrier).** Every evaluator in the *canonical-memoisation
family* — exhaustive budgeted game-tree recursion for the threshold decision,
with isomorphism-class memo keys — takes at least `2^{L(n)} = 2^{Θ(n log² n)}`
time on the no-instance `1^n # 1^{⌈log₂ n!⌉ − 1}`. In particular:

- this family **cannot** reach `2^{O(n log n)}` or `2^{O(n)}` time: since
  `L(n)/(n log n) → ∞`, its cost on this input exceeds `2^{c·n log n}` for
  every fixed `c` once `n` is large enough (the ratio is already ≈ 2.84 at
  `n = 199` and grows; `L(16) = 2^{30.0}` already). Numerically `L` increases
  with every even step of `n` across `16 ≤ n ≤ 198`;
- the §5.3 threshold bound `2^{O(N log N)}` is exponent-tight for this
  family: at the critical budget `k = Θ(n log n)` one has `N = Θ(n log n)`,
  `N log N = Θ(n log² n)` and the exponent ratio `L(n)/(N log N) → 1`, so the
  remaining slack is the sub-leading `Θ(n log n log log n)` difference;
- the number of forced canonical memo keys on this family is `2^{Θ(n log² n)}`,
  so the *state identity* such a table must carry is `Θ(n log² n)` bits —
  **not** `Ω(n²)` bits. The countable reachability universe at critical depth
  does not by itself deliver a super-`n log² n`-bit obstruction, and this note
  does not establish (or refute) the `Ω(n²)`-bit forced-seed hypothesis of the
  front statement.

## What this does and does not rule out

*Soundness vs completeness.* The theorem constrains evaluators whose memo
keys are at least as fine as isomorphism classes (a *complete* state
identity). It does **not** rule out a coarser "interface summary": two
reachable states that are non-isomorphic could still share a sound summary
(a bisimulation-style congruence), and designing/proving such a coarser
sound summary — or ruling one out — is exactly the open residue of this
front, unchanged by this note. The `n=5` linear-extension-count falsification
in `research-state-compression.md` (Finding 3a) already shows that popular
coarse invariants fail, but no all-n lower bound on the *bisimulation rank*
of reachable states at critical depth is known here.

*Which evaluators are affected.* Only those that instantiate per-class state
and evaluate a no-instance exhaustively. The `S(n)` numeric function can in
principle be computed by a method that never runs an exhaustive no-instance
recursion at depth `k = ⌈log₂ n!⌉`; no argument in this note lower-bounds
such a method's cost. Any exact evaluator must however distinguish
`S(n)` from `S(n)−1` somehow; making that precise is the continuing gap.

*Relation to earlier notes.* `research-time-exponent.md` exhibited `Θ(n²)`
move orbits (trivial `Aut`) but its staircase posets need `Θ(n²)` comparisons
to be built — outside the critical depth, hence not visited by any
budget-`Θ(n log n)` search. The present family is *inside* the reachable
set at every critical budget, and its pairwise rigidity up to `(m!)²`
removes the orbit coalescence: this is the first family here where the
pairwise-non-isomorphic reachable-state count is super-`2^{O(n log n)}` at
the critical depth. `research-state-compression.md` Finding 3 showed the
relabel quotient already collapses practise to `A000112(n)` classes, but
those counts (`2^{Θ(n²)}`) concerned the *full* state space; the sharper
message is the *critical-depth* class count `2^{Θ(n log² n)}`, which matches
the DFS exponent instead of exceeding it, and pins the family.
