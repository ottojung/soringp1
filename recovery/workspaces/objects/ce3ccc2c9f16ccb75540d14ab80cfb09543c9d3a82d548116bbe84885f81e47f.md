**Front:** `fj-exact-barrier-20261124` (independent executive research delivery,

**Verdict: BLOCKED — a clean no-go theorem for the standard Ford–Johnson

## 0. Question and short answer

The framed-certificate frontier (`research-framed-certificate-frontier.md`,
§3) describes an all-`n` polynomial-size framed DAG for the **standard
Ford–Johnson upper bound**

```
F_FJ(n) = sum_{j=1}^{n} ceil(log2(3j/4))          (classical merge-insertion bound)
```

and explicitly warns that `F_FJ(n) != S(n)` in general: it certifies an
**upper bound**, not exact optimality. The unresolved implication is whether
every true `SORT-BOUND-U` instance has a polynomial certificate **at the exact
budget `S(n)`**. This note settles the status of *this architecture*:

1. For every `n` where `S(n)` is known exactly (`n <= 22`), `F_FJ(n) = S(n)`:
   **there is no small counterexample** (§2).
2. Nevertheless `F_FJ(n) - log2(n!) = Theta(n)`, with explicit constants
   (§3): liminf `(F_FJ(n)-log2 n!)/n = 0.02766... > 0`, limsup
   `= 1/ln2 - 4/3 = 0.10936... > 0`.
3. Sergeev's `S(n) = log2(n!) + o(n)` then forces
   `F_FJ(n) - S(n) -> +infinity` (§4). Hence for all sufficiently large `n`,
   `F_FJ(n) > S(n)` and the FJ DAG **cannot** be a depth-`S(n)` certificate.

The threshold is **ineffective** (Sergeev's `o(n)` carries no explicit
constant) and no explicit `n` with `F_FJ(n) > S(n)` is known — indeed none
exists for `n <= 22`. The divergence is a rigorous existence statement, not
a named small witness. This is stated honestly in §6.

## 1. Definitions and sources

- **[definition]** `S(n)` = minimum worst-case number of adaptive pairwise
  comparisons to sort `n` distinct labelled keys (`docs/problem.md`). The
  unary threshold language is `SORT-BOUND-U = {1^n#1^k : S(n) <= k}`.
- **[literature]** `F_FJ(n) = sum_{j=1}^n ceil(log2(3j/4))` is the classical
  Ford–Johnson / merge-insertion worst-case comparison bound (Ford & Johnson,
  *A Tournament Problem*, 1959; Knuth, *TAOCP* Vol. 3 §5.3.1). The project's
  authoritative statement is `docs/research-framed-certificate-frontier.md`
  §3, which gives the framed rank-envelope construction and the formula.
- **[literature]** `L(n) = ceil(log2(n!))` is the information bound (OEIS
  [A003070](https://oeis.org/A003070)).
- **[literature]** Exact `S(n)` values: OEIS
  [A036604](https://oeis.org/A036604) (b-file fetched this session); Knuth
  §5.3.1; Wells (`S(12)=30`, reported in Peczarski 2012); Stober–Weiß,
  *Lower Bounds for Sorting 16, 17, and 18 Elements*, ALENEX 2023
  (`S(16)=46, S(17)=50, S(18)=54`). Exact values are known for all `n<=22`;
  `n=23` is open (`docs/research-plan.md`).
- **[literature]** Sergeev, *On the asymptotic complexity of sorting*, ECCC
  TR20-096 (2020), Theorem 3: `S(n) = log2(n!) + O(n/(log n)^{1/5}) =
  log2(n!) + o(n)`. Ineffectivity of the constant documented on #301 by
  `effective-sergeev-constant-20261124` (2026-11-24).
- **[definition]** Exact integer evaluation used below (no floating point):
  `ceil(log2(3j/4)) = (3j-1).bit_length() - 2`, and
  `ceil(log2(n!)) = (n!-1).bit_length()`. Verified in `../scripts/fj_exact.py`.

## 3. `F_FJ(n) - log2(n!) = Theta(n)` with explicit constants

### 3.1 Exact per-block structure

**[deduction]** Put `g(j) = ceil(log2(3j/4))`. For
`j in B_m := {2^m, ..., 2^{m+1}-1}` (so `floor(log2 j) = m`, write `a = 2^m`):

```
g(j) = m     if j <= floor(4a/3),      because 2^{m+1} < 3j <= 2^{m+2};
g(j) = m+1   if j >  floor(4a/3),      because 2^{m+2} < 3j <  2^{m+3}.
```

Let `phi(j) = g(j) - log2 j`, so `F_FJ(n) - log2(n!) = sum_{j=1}^n phi(j)`.
On `B_m`, `phi(j) = m - log2 j` for `j <= K := floor(4a/3)` and
`phi(j) = m+1 - log2 j` for `j > K`; both branches are **decreasing** in `j`.

### 3.2 Full-dyadic-block bound

**[paper proof]** For a decreasing real function `f`,
`sum_{j=p}^{q} f(j) >= int_p^{q+1} f(x) dx`. Apply to each branch and add, with
`u = K+1 in (4a/3, 4a/3+1]`:

```
S_m := sum_{j in B_m} phi(j)
     >= int_a^u (m - log2 x) dx + int_u^{2a} (m+1 - log2 x) dx
     =  a/ln2 - u
     >= a(1/ln2 - 4/3) - 1.
```

Numerically `c0 := 1/ln2 - 4/3 = 0.1093617075... > 0`. (Check at `a=2^m`,
`m=1..20`, in `../scripts/verify_bounds.py`: all hold, and `S_m/a -> c0`.)

### 3.3 Partial-block bound

**[paper proof]** Let `2^M <= n < 2^{M+1}`, `a = 2^M`, `M >= 1`. The unfinished
block `{a,...,n}` contributes at least the integral over its negative first
piece; the second piece is nonnegative since `phi(j) > 0` for `j < 2a`.
With `p := -int_1^{4/3} log2 x dx = 0.0724849854...` and `u <= 4a/3+1`,

```
sum_{j=a}^{n} phi(j)  >=  int_a^{K+1}(m - log2 x) dx  >=  -p*a - 1.
```

(Verified for `m=1..20` in `../scripts/verify_bounds.py`.)

### 3.4 Theta(n) statement

**[deduction]** Summing full blocks `m=0..M-1` and the partial block:

```
c0 - p = 0.0368767... > 0,
F_FJ(n) - log2(n!)  >=  (c0-p)*2^M - M - 1 - c0
                    >=  0.01843*n - log2(n) - 1.11        (2^M >= n/2),
```

and trivially `phi(j) < 1` gives `F_FJ(n) - log2(n!) < n`. Hence for all
`n >= 2048` (`log2 n <= 11`),

```
0.01 * n  <=  F_FJ(n) - log2(n!)  <  n.
```

**Theorem A. `F_FJ(n) - log2(n!) = Theta(n)` with explicit constants
`c = 0.01`, `C = 1` for `n >= 2048`.**

Refining the Riemann-sum profile (not needed for the no-go, recorded for
completeness): with `r = n/2^M in [1,2)`, the limiting ratio is
`[c0 + P(r)]/r`, where `P(r) = -int_1^r log2 x dx` for `r <= 4/3` and
`P(r) = -p + int_{4/3}^r (1 - log2 x)dx` for `r > 4/3`. Its minimum is at
`r = 4/3` and its maximum at `r = 1,2`:

```
liminf (F_FJ(n)-log2 n!)/n = (3/4)(c0 - p) = 0.02766... > 0,
limsup (F_FJ(n)-log2 n!)/n = c0 = 1/ln2 - 4/3 = 0.10936... > 0.
```

So the ratio **oscillates** and the ordinary limit does **not** exist — a
contrary fact preserved deliberately. `[experiment]` corroboration:
`surplus/n = 0.10937, 0.09310, 0.02762, 0.07999, 0.11312` at
`n/2^10 = 1, 1.1, 4/3, 1.5, 1.9`, reproduced identically at `2^16` and `2^18`
(`../scripts/fj_exact.py`).

## 4. Consequence: `F_FJ(n) - S(n) -> +infinity`

**[deduction]** Write

```
F_FJ(n) - S(n) = [F_FJ(n) - log2(n!)] - [S(n) - log2(n!)].
```

By Theorem A the first bracket is `>= 0.01 n` for `n >= 2048`. By Sergeev
(§1) the second bracket is `o(n)`: for every `eps > 0` there is `N(eps)` with
`S(n) - log2(n!) <= eps n` for `n >= N(eps)`. Taking `eps = 0.005`,

```
F_FJ(n) - S(n)  >=  (0.01 - 0.005) n  =  0.005 n  >  0
    for all n >= max(2048, N(0.005)).
```

**Theorem B (no-go). `F_FJ(n) - S(n) -> +infinity`.** Consequently there is an
`N*` such that `F_FJ(n) > S(n)` for every `n >= N*`; the standard FJ
comparison schedule is **provably not optimal** for all large `n`, and the
linear excess grows without bound.

**Why this blocks the architecture (model fidelity).** A sound framed DAG
with longest path `k` implies `S(n) <= k`; conversely the FJ construction
produces a polynomial-node framed DAG whose longest path is exactly the
worst-case path of the merge-insertion algorithm, `F_FJ(n)` (the all-`n`
identity `D(n) = F_FJ(n)` is proved on #301, 2026-10-24). DAG sharing/joins
do **not** change path lengths, so every framed DAG implementing *this
comparison schedule* has height `F_FJ(n)`. By Theorem B that height exceeds
`S(n)` for all `n >= N*`. Therefore no DAG of the FJ architecture is a
depth-`S(n)` certificate for all `n`. Certifying `F_FJ(n)` is certifying an
upper bound, **not** exact optimality.

## 5. Serious falsification attempts (all failed to break the verdict)

1. **Small counterexample to the premise.** Checked all known `n<=22`:
   `F_FJ(n) = S(n)` exactly, so the premise `F_FJ(n) > S(n)` cannot be
   witnessed at moderate `n`. This does not refute Theorem B — it explains
   why the issue went unnoticed and why an asymptotic route is necessary.
2. **Is `F_FJ(n) - log2(n!)` maybe sublinear?** No: the per-dyadic-block
   identity (§3.1–3.2) gives a strictly positive block surplus `~c0*2^m`, and
   the partial-block loss is only `~p*2^m < c0*2^m`. Numerics at `n` up to
   `2^18` confirm a positive ratio bounded away from zero (liminf `0.02766`).
3. **Could Sergeev's `o(n)` cancel the `~0.01n` FJ surplus?** No: `o(n)` tends
   to `0` relative to `n`, while the FJ surplus is `Theta(n)`. Any positive
   constant lower bound eventually dominates.
4. **Could a different sharing of the FJ *schedule* reduce the DAG height?**
   No: sharing changes node count, not longest-path length; the worst-case
   path remains `F_FJ(n)`.
5. **Could the FJ rank-window invariant itself be unsound, invalidating the
   bound `F_FJ`?** That would only *increase* the surplus over `S(n)` and
   strengthen the no-go; soundness of the certified upper `F_FJ(n)` is not
   the issue. Prior #301 work (2026-10-24) established the frame-composition
   and stage-cost identities; a value-dependent-frame sharing obstruction at
   `n=5` (2026-11-21) affects polynomial node count, not the height fact used
   here.
6. **Is the question already settled in the cited notes?** Checked:
   `research-framed-certificate-frontier.md` §2 proves the *merge-DAG*
   architecture blocked at large powers of two, and §3 explicitly says the
   FJ DAG certifies `F_FJ(n)`, "`which is not equal to S(n) for every n`.
   Nothing here proves NP membership" — but it does **not** prove
   `F_FJ(n)-S(n) -> infinity`. A full #301 scan (3,508 messages) found FJ
   certificate/height work at `n=5,6` and the `D(n)=F_FJ(n)` identity, but no
   prior no-go from the FJ surplus + Sergeev. This note closes that specific
   gap; it does not claim novelty for the FJ bound itself or for Sergeev.

## 6. VERDICT, scope, and uncertainty

**BLOCKED (architecture-specific no-go).** The standard Ford–Johnson
rank-envelope/insertion framed DAG, whose height is `F_FJ(n) =
sum_{j=1}^n ceil(log2(3j/4))`, cannot certify the exact sorting budget `S(n)`
for all `n`: `F_FJ(n) - S(n) -> +infinity` (Theorems A, B). This is a genuine
negative result about a whole polynomial-size certificate architecture, and
it is independent of the size of the DAG (node-count improvements cannot
repair a comparison-count deficit).

**Preserved contrary evidence / honest uncertainty:**
- No explicit `n` with `F_FJ(n) > S(n)` is produced. `F_FJ(n) = S(n)` for
  every known `n <= 22`, and the crossover threshold `N*` is **ineffective**
  because Sergeev's `o(n)` has no explicit constant. Theorem B is an
  existence/divergence statement, not a named small witness. If a future
  effective version of Sergeev with an explicit threshold becomes available,
  `N*` could in principle be bounded; none exists in the cited sources.
- This does **not** show `SORT-BOUND-U ∉ NP`. It rules out one architecture.
  The general open question — does *some* polynomial-size sound framed DAG
  attain height `S(n)` for all `n`? — remains **OPEN**. In particular
  Sergeev's own *modified* group-insertion algorithm (a different insertion
  architecture with `o(n)` surplus) is not excluded by this no-go; whether it
  admits a polynomial framed DAG at height `S(n)` is a separate question.
- The merge-DAG no-go (frontier §2, large powers of two) is a distinct,
  already-known obstruction; this note adds the FJ-insertion obstruction.
- All claims are paper-level/exact-integer-arithmetic, not Lean-checked, and
  no claim is made about computing `S(n)` itself or about complexity-class
  separation. `S(n)` and `SORT-BOUND-U` remain OPEN.
