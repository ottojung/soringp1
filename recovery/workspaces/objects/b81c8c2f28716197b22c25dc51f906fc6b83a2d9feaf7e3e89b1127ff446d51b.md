# Exact series/parallel decomposition and evaluation of `S(n)` (all `n`)

**Task.** Falsifiable question (all `n`): does exact series/parallel (ordinal sum, disjoint union) decomposition of posets arising in optimal sorting yield a provable asymptotic reduction in state space or evaluation exponent for `S(n)`, or is there a precise obstruction/counterexample showing no such gain despite exactness?

**Answer (deduction + literature/experiment from repo).** No provable asymptotic reduction in the reachable state space or in the evaluation exponent for `S(n)` follows from exact series/parallel decomposition. Ordinal-sum (series) decomposition is an exact value identity but is inapplicable at the root and does not asymptotically compress the exact minimax state space; disjoint-union (parallel) decomposition has no exact additive/minimax recurrence for `F`, so it does not yield an exact evaluation decomposition at all. The general case remains obstructed rather than refuted as an "impossible in every algorithm" statement, but no decomposition-based exponent/state-count reduction is established.

*Scope note.* This reports the consequences for computing the exact sorting number `S(n)=F(\varnothing_n)` (unary target `SORT-BOUND-U` per `docs/problem.md`, `AGENTS.md`). No complexity-class separation is claimed.

## 1. Definitions (fixed model)

- **Adaptive comparison sorting / minimax value** (`docs/problem.md`, `docs/upper-bound.md`, `SoringP1/Minimax.lean` A24). A state is a strict partial order `P` on labelled keys `[n]`. Let `e(P)` be its linear-extension set/count context and
  - `F(P)=0` if `P` is total,
  - `F(P)=1+\min_{x\parallel y}\max(F(P+x<y),F(P+y<x))` otherwise,
  with `S(n)=F(\varnothing_n)`. `L(P)` denotes linear extensions and `F(P)=\mathrm{adv}(L(P))`.
- **Ordinal sum (series composition).** For disjoint posets `A,B`, `A\oplus B` has all relations of `A`, all of `B`, and `a<b` for every `a\in A,b\in B` (`docs/research-series-decomposition.md`).
- **Disjoint union (parallel composition).** `A\parallel B` has all relations of `A`, all of `B`, and every cross pair incomparable (`docs/research-compression-next.md`, `docs/research-parallel-duality.md`).
- **Exact decomposition (for evaluation).** A decomposition usable for asymptotic state-space/exponent reduction of exact `S(n)` evaluation would need (i) an exact recurrence reducing `F` of reachable states to smaller factors and (ii) applicability yielding a provably smaller asymptotic class of states/transitions than the baseline poset DP (`2^{\Theta(n^2)}` labelled posets / A001035 reachable states, `docs/research-compression-next.md`).

## 2. Ordinal-sum decomposition: exact but not an asymptotic gain for `S(n)`

### 2.1 Exactness (literature/deduction, established)
**Theorem (ordinal-sum additivity).** `F(A\oplus B)=F(A)+F(B)` for finite disjoint posets. Upper bound by concatenating optimal trees; lower bound by adversary potential/product argument. This is the deterministic direct-sum theorem for decision-tree complexity specialized to ordinal sums (Jain–Klauck–Sántha 2010, Thm. 1, as cited in `docs/research-series-decomposition.md` §2). The maximal decomposition is unique via incomparability-graph components and detectable in `O(n^2)` from the closure (`docs/research-series-decomposition.md` §3).

### 2.2 Obstructions to asymptotic reduction of `S(n)` (deduction)
1. **Root obstruction.** The initial state for `S(n)` is the antichain `\varnothing_n`. For `n\ge 2`, every pair is incomparable, so its incomparability graph is connected (`K_n`) and `\varnothing_n` is series-prime: it has no nontrivial ordinal-sum decomposition (`docs/research-series-decomposition.md` §7). Thus the identity cannot decompose the root instance `S(n)` itself.
2. **Reachable-state obstruction.** Every labelled poset on `[n]` is reachable from `\varnothing_n` (Lemma/reachability argument in `docs/research-compression-next.md` §1), so the exact minimax state space is the full set of labelled posets (A001035, size `2^{\Theta(n^2)}` in numeric `n`). Series-prime posets remain states that must be valued unless some *other* quotient applies; the ordinal-sum shortcut only replaces evaluation *at* decomposable states, it does not remove the need to represent/evaluate reachable series-prime states.
3. **No state-space shrinkage in exact DP accounting (deduction from mechanism).** Applying `F(P)=\sum_i F(P_i)` on a decomposable `P` avoids exploring `P`'s children but introduces/queries component induced-subposet states (on proper subsets). Therefore the memo/state set is not reduced in general; component states are additional entries (`docs/research-series-decomposition.md` §5). An asymptotic reduction in *evaluation exponent* would require a provably subexponential (relative to baseline `2^{O(n^2)}` poset DP / stronger bounds) domination of the remaining work; the series-prime reachable core blocks this conclusion.

### 2.3 Evidence / falsification (experiment, finite)
From `docs/research-series-decomposition.md` / `scripts/series_decomposition_probe.py` (bounded, deterministic, `n\le 5`): `S(n)` values are preserved (exactness) and the rule is verified exhaustively on all posets for `n\le 4` (`2/2, 12/12, 122/122` non-series-prime, zero failures) with `219/219` genuine ordinal-sum checks at `n=4`. Practical impact: stored states increase while child expansions decrease:

| n | S(n) | states plain → decomposed | expansions plain → decomposed | decomposition hits |
|---|-----:|---------------------------:|-------------------------------:|-------------------:|
| 2 | 1 | 3 → 4 | 1 → 1 | 2 |
| 3 | 3 | 19 → 23 | 13 → 8 | 14 |
| 4 | 5 | 219 → 230 | 195 → 105 | 124 |
| 5 | 7 | 4231 → 4381 | 4111 → 2356 | 2024 |

Decomposable fraction among all posets decreases in this range (`67%, 63%, 56%, 47%` for `n=2..5`; series-prime fraction grows). The note explicitly treats this as a negative empirical observation with **no asymptotic runtime conclusion** by itself; combined with the root/series-prime-core obstruction (§2.2) it falsifies the hypothesis that ordinal-sum decomposition yields a provable asymptotic state-space reduction for exact `S(n)` evaluation.

**Counterexample to naive generalization (exactness boundary).** Additivity requires the full linear-extension product `L(A)\times L(B)`. For correlated subsets `S\subseteq L(A\oplus B)` it fails: with `A,B` 2-element antichains and `S={0123,1032}`, `F(L(P))=2`, `F(S)=1`, while projected sum `F(S_A)+F(S_B)=2` (`docs/research-series-decomposition.md` §4). This limits decomposition to true poset states, not arbitrary search subsets.

## 3. Disjoint-union (parallel) decomposition: no exact evaluation recurrence

### 3.1 Non-additivity / obstruction (deduction)
Parallel composition is not additively decomposable for `F`: `F(a\parallel b)=1` but `F(a)+F(b)=0` (`docs/research-series-decomposition.md` §6, `docs/research-compression-next.md` §8). Comparisons may interleave components, so the joint minimax value is not a function of component values alone in the manner of ordinal sums. Consequently "no general series-parallel recurrence for `F` follows from the ordinal rule alone" and no sound merge recurrence is known (`docs/research-series-decomposition.md` §6, `docs/research-compression-next.md` §8).

**Root note.** Unlike series decomposition, `\varnothing_n` *is* a disjoint union of smaller antichains (`\varnothing_a \parallel \varnothing_b`), but because `S(n)\neq S(a)+S(b)` in general there is no exact value split; this is a direct obstruction, not a compression.

### 3.2 Related exact parallel-module results (deduction/experiment, not a decomposition gain)
`docs/research-parallel-duality.md` proves a restricted symmetry: if `B` is self-dual, `F(A^{op}\parallel B)=F(A\parallel B)` (hence parallel-quotient module reversal preserves `F`); exhaustive `n\le 7` checks find no general violation but the non-selfdual case is unresolved (evidence, not theorem). `docs/research-orientation-modules.md` shows module/MDT reversal is not a sound general `F`-symmetry (first failures at `n=7`, prime quotients) though interval modules are sound. These are equivalences/symmetries, not a disjoint-union *decomposition recurrence* for `F`, and they do not establish an asymptotic reduction in reachable state space or evaluation exponent for `S(n)`; known exact quotients (iso, iso+dual) give constant-factor class reductions, not an exponent change (`docs/research-compression-next.md` §3–§5).

## 4. Consequence

- **Falsification of the stated gain (for established decompositions).** Exact ordinal-sum decomposition does **not** yield a provable asymptotic reduction in state space or evaluation exponent for computing `S(n)`: the antichain root is indecomposable, the full reachable poset space remains, and measured memo/state counts do not shrink (`n\le 5`) despite exactness. Exact disjoint-union decomposition does **not** yield such a reduction because no exact minimax recurrence/merge for `F` is available (and parallel additivity is false).
- **What remains open (not ruled out by this report).** A different, currently unknown, sound recurrence or state quotient exploiting series-parallel structure in a way compatible with interleaving (e.g. a provably correct merge/transition giving asymptotically fewer classes) is not exhibited here; existing evidence gives no such construction. Any future claim must supply an all-`n` correctness argument for `F`/`S(n)`, an asymptotic state/transition or time-exponent bound against the unary input/`2^{O(n^2)}` baseline, and survive falsification on known values/counterexample patterns above.
- **Central-question relevance.** These decompositions provide structural identities/shortcuts but, on current evidence, do not move the upper-bound/exponent frontier for `SORT-BOUND-U` or exact evaluation of `S(n)`.
