# Selective / succinct exact minimax: scoped obstruction below `O(N log N)` work space

**Status:** research note (audit/synthesis). Labels: `[definition]`,
`[literature]`, `[deduction]`, `[open]`. No Lean, no unconditional space
lower bound, no complexity-class separation, and no improved algorithm is
claimed.

**Question.** For selective or exact minimax evaluation methods that do
**not** enumerate the winning frontier — e.g. DFS backtracking,
proof-number / alpha-beta-like selection, symbolic or succinct game
evaluation — is there a proved or precisely scoped obstruction to
deterministic uniform `o(N log N)` work space for
`SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }` on actual unary input length
`N = n + k + 1`, or a concrete candidate representation achieving it?

**Answer (scoped): (B)-leaning, not a universal obstruction.** No
`o(N log N)` deterministic uniform algorithm for the full selective/symbolic
family is established here, and no proved unconditional obstruction over
all such methods is claimed. What is established is a precise obstruction
for the **resumable adaptive-transcript** evaluation strategy that covers
standard exact DFS/backtracking and, in their usual realizations, selective
tree-search variants that maintain resumable game state/cursors. Symbolic
or succinct game evaluation avoids explicit winning-frontier enumeration,
but only becomes a concrete `o(N log N)` candidate if it supplies an exact,
resumable representation of the adaptive comparison game below the
path/cursor information size; no such representation is established.

---

## 1. Model and baseline `[definition]`+`[literature]`

Input is `w = 1^n # 1^k`, `N = |w| = n + k + 1`, on a standard uniform
deterministic multi-tape Turing machine with read-only input; work space
excludes the input. Correctness is the exact adaptive comparison-sort
minimax value of `docs/problem.md`:
```
V(P,0)=IsTotal(P),  V(P,d)=OR_{(x,y) incomparable in P} [V(P+x<y,d-1) AND V(P+y<x,d-1)],
S(n) <= k iff V(empty_n,k).
```
After the `k >= U(n)` trivial accept, the budgeted DFS / transcript-only
evaluator decides `V(empty_n,k)` in deterministic time
`2^{O(k log(n+2))} poly(N) <= 2^{O(N log(N+2))}` and work space
`O((k+n)log(n+2)) <= O(N log(N+2))` bits (`docs/research-budgeted-dfs.md`
§2–5.3). The space comes from a depth-`k` transcript of ordered comparisons
plus resumable cursors, with reachability recomputed in reusable
`O(n log n)` workspace.

The winning-frontier barrier (`docs/research-winning-frontier-barrier.md`)
rules out methods that necessarily enumerate all winning states at a budget;
it is an enumeration obstruction, **not** a time or space lower bound for
selective/symbolic solvers. The present question asks whether avoiding that
enumeration removes the `O(N log N)` work-space barrier.

---

## 2. What "selective / succinct, non-frontier-enumerating" means `[definition]`

The methods in scope are exact evaluators of `V(empty_n,k)` or an equivalent
exact game value that do **not** output/list all winning frontier states:

- **DFS backtracking**: exact AND/OR search with backtracking, possibly with
  move ordering and short-circuiting.
- **Proof-number / alpha-beta-like selection**: exact selective search that
  expands or orders nodes by bounds/proof/disproof numbers or analogous
  cutoffs, but still proves the minimax value.
- **Symbolic / succinct game evaluation**: exact evaluation over an implicit
  or compressed representation of states, moves, or strategy/game graph,
  rather than explicit path/state enumeration.

Excluded are algorithms whose correctness argument requires listing the full
winning frontier. The space question is about *work space while proving the
exact value*, not about the size of an output certificate unless the method
stores that certificate.

---

## 3. Scoped obstruction: resumable adaptive transcripts `[deduction]`

The following obstruction is precise for exact depth-first minimax evaluation
and extends to standard selective variants that keep resumable tree state.

1. **History-dependent move legality.** A sorter move at depth `i` is a pair
   incomparable in `P(σ_{i-1})`, the transitive closure of the prefix
   transcript `σ_{i-1}=((a_1,b_1),..., (a_{i-1},b_{i-1}))`. The legal move set
   is not fixed: it is a function of the whole adaptive history.
2. **Exact adversarial branching.** For a chosen incomparable pair, both
   orientations must be verified (`AND`), and each answer changes future
   legality. The minimax value is exact; pruning may avoid some branches but
   cannot, in general, avoid maintaining enough state to resume correct exact
   evaluation of unexplored necessary branches.
3. **Resumable cursor/state.** After a child return, the evaluator must resume
   at the correct ancestor with the correct untried candidate/branch. Given
   `σ_{i-1}`, `P(σ_{i-1})` is recomputable in reusable polynomial workspace;
   but the standard DFS/selective stack still stores, for the current path,
   the information needed to identify the current prefix and the next untried
   move/branch. In the transcript/cursor representation this is
   `O(log n)` bits per level and `O(t log n)` bits at depth `t`.
4. **Unary worst case.** For `SORT-BOUND-U`, the relevant exact decision path
   has `t <= k <= N` and `n <= N`, so the resumable path/cursor state is
   `O(N log(N+2))` bits in the baseline and `Θ(N log N)` bits in the natural
   transcript/cursor worst case.

This is the same bottleneck audited for recomputation/implicit-state/
catalytic-style attempts in
`/home/lubko/soring-fronts/catalytic-space-recompute-audit-20261105/docs/space-recompute-audit.md`:
recomputing reachability from the transcript removes closure-matrix storage,
but does not remove the resumable adaptive transcript/cursor itself.
It is a **representation/evaluation-strategy obstruction**, not an
unconditional lower bound for `SORT-BOUND-U`.

### Selective search variants `[deduction]`+`[open]`

Proof-number, best-first, or alpha-beta-like selection changes *which*
nodes are expanded and may cut branches, but exact minimax/proof search in
the usual form maintains node records, bounds, or a resumable search
frontier/path. Those records are not the full winning frontier of final game
states; however, avoiding that final frontier does not automatically imply
`o(N log N)` work space. A genuine space improvement would need a proof that
the exact selective evaluator's resumable state (path, transposition/keyed
state, or proof/disproof bookkeeping restricted to the adaptive comparison
game) is representable in `o(N log N)` bits with exact restoration. No such
proof is given here. Conversely, no proof is given that every exact selective
variant must store `Ω(N log N)` bits.

## 4. Concrete candidate representations `[open]`

The following are *candidate* directions only; none is established as an
`o(N log N)` exact uniform algorithm.

| Candidate representation | Why it avoids full winning-frontier enumeration | What it would still have to prove |
|---|---|---|
| Reversible/catalytic resumable DFS | Stores temporary search state on a restored catalytic tape rather than clean work tape alone | A concrete reversible simulation for history-dependent AND/OR backtracking, exact restoration on every branch, and clean work space `o(N log N)` with explicit time |
| Succinct resumable transcript/path scheme | Compresses the adaptive comparison transcript + cursor below `k log n` | Exact decompress/reconstruct/resume for every minimax-relevant path; correctness under adversarial branch returns, not average-case compression |
| Symbolic state/strategy predicates | Represents many states/strategy obligations implicitly (e.g. BDD-like or algebraic predicates over poset/comparison facts) | Exact evaluation of the adaptive minimax game, operations in `o(N log N)` peak work space, and no hidden expansion to explicit frontier/path objects |
| Succinct game-graph or proof-DAG evaluation | Evaluates the value over an implicit/canonical game graph or proof structure smaller than the frontier | Construction/access without enumerating winning frontier states; exact resumable evaluation and space accounting in the unary TM model |
| Low-space tree-evaluation reduction | Adapts Cook–Mertz-style or related tree-evaluation ideas | A presented/fixed or on-the-fly constructible structure with the required degree/regularity, preserving exact adaptive move legality, in `o(N log N)` work space |

The first row targets the space bottleneck directly; the others target
representation. Any successful candidate must be checked against model
fidelity: actual unary length `N`, read-only input, uniform deterministic
work space, exact `S(n) <= k` semantics, and an explicit time bound.

---

## 5. What is not claimed `[deduction]`

- No unconditional `Ω(N log N)` work-space lower bound for `SORT-BOUND-U`.
- No lower bound for all selective, symbolic, catalytic, or randomized
  algorithms; randomized/catalytic models are outside the stated target
  unless explicitly simulated as standard deterministic work space.
- No complexity-class separation (`P != PSPACE`, `NP != PSPACE`, etc.).
- No claim that the winning-frontier barrier implies a space lower bound.
- No claim that proof-number/alpha-beta-like search is impossible in
  `o(N log N)` work space; only that ordinary resumable realizations are not
  known to achieve it and inherit the transcript/cursor accounting issue
  unless a new representation is proved.

## 6. Decisive next step `[open]`

Close the gap in one of two directions, with an explicit model:

1. **Upper-bound direction:** give an exact deterministic evaluator for
   `SORT-BOUND-U` using `o(N log(N+2))` work bits on input `1^n # 1^k`, with
   a proof of correctness, resumability (if path-based), and an explicit time
   bound. A concrete starting point is a reversible/catalytic simulation of the
   transcript-only DFS whose clean workspace excludes the restored catalytic
   tape only in that model; to improve the stated standard TM work-space bound
   it must count as standard work space.
2. **Barrier/lower-bound direction:** prove, under stated restrictions (e.g.
   resumable adaptive-transcript protocols, read-only access to an implicit
   game oracle, or another precise model), that exact evaluation requires
   `Ω(N log N)` work space. Such a result must be labeled as conditional on
   those restrictions, not as an unconditional lower bound for the language.

Until one of these is established, the status is: **precisely scoped
resumable-transcript obstruction, no proved universal obstruction, no known
`o(N log N)` concrete representation for exact selective/succinct minimax
evaluation of `SORT-BOUND-U`.**
