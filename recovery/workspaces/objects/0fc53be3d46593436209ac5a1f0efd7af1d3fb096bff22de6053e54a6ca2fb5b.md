## 2. Question (all n)

Many-one NP-hardness of `SORT-BOUND-U` would imply `P = NP` (Mahaney), and
adaptive Turing NP/PSPACE-hardness would imply a nonuniform hierarchy collapse
(Karp-Lipton). Is there an **encoding-faithful target** for a *meaningful
unconditional lower bound* for the sparse unary threshold language, or is every
suggested hard-reduction route blocked by sparsity / isomorphism / encoding
constraints? "Sparse membership in `P/poly`" must not be stated as uniform
`P` membership.

## 3. Method

Paper-first audit of the reduction landscape, with exact statement of

## 4. Result: concrete barrier (no encoding-faithful reduction target)

**Barrier theorem (encoding-faithful reduction routes).** Let
`A = SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }`, input length `L = n+k+1`.

1. **Sparsity (exact).** `A` is sparse: `|A ∩ Σ^{≤L}| = O(L²)`
   (Lemma 3.1 of `research-encoding-consequences.md`; verified by
   `hardness_boundaries` counting for `L ≤ 40`).

2. **Many-one NP route (blocked).** If a sparse set is NP-hard under
   polynomial-time many-one reductions, then `P = NP` (Mahaney 1982).
   Hence `A` is **not** NP-hard under `≤_m^p` unless `P = NP`. The same
   blocks coNP-hardness (Fortune 1979) and bounded truth-table hardness
   (Ogiwara-Watanabe 1991).

3. **Turing route (blocked).** If `SAT` is polynomial-time Turing reducible
   to a sparse set, then `PH = Σ₂P` (Karp-Lipton 1980; Kadin refinement).
   Hence adaptive Turing NP-hardness of `A` is not available without a
   nonuniform hierarchy collapse. This is a *conditional* barrier, not a
   membership statement.

4. **EXPTIME route (unconditionally blocked).** No polynomially sparse
   language is EXPTIME-complete under polynomial-time many-one reductions
   (Berman-Hartmanis 1977). Since `A` is sparse and `A ∈ EXPTIME`
   (`research-encoding-consequences.md` Thm 2.1), `A` is **unconditionally not
   EXPTIME-hard** under `≤_m^p`. This does not exclude Turing reductions and
   gives no separation.

5. **Nonuniform upper bounds are not uniform membership.** `A ∈ P/poly` with
   `O(L log L)` advice (`S(0..L)` table) and `A ∈ P/log` with `O(log L)`
   advice (length cutoff `t_L`), plus `A ∈ nonuniform AC⁰` (depth-2 circuits,
   `O(L²)` literals). None implies `A ∈ P`, `A ∈ NP`, or any uniform class:
   the advice `t_L` need not be computable. The diagonal tally language
   `TALLY-DIAG` (`research-encoding-consequences.md` §6.1) is an explicit
   unconditionally decidable sparse language with `P/1` advice that is **not**
   in `P`, exhibiting the distinction without an unproved separation.

6. **Binary transfer route (blocked by encoding).** `SORT-BOUND-B` is not
   sparse, so Mahaney does not apply to it. However, the antichain embedding
   `φ_B(bin(n)#bin(k)) = ⟨A_n⟩ # bin(k)` outputs `n² = 2^{Θ(m)}` bits for
   input length `m = Θ(log n)` and is **not** polynomial-time
   (`research-hardness-boundaries.md` Lemma 1.2). Thus hardness of
   `GEN-SORT` does not transfer to `SORT-BOUND-B` via that route, and no
   hardness for `SORT-BOUND-B` is established. A direct hardness proof for the
   binary language would be for a single natural number sequence and remains
   open and unprecedented.

7. **No succinct certificate either.** The only known witnesses (explicit
   comparison tree `≥ n!` leaves = `2^{Θ(L)}` unary; memoized poset table
   `2^{Θ(n²)}`) are super-polynomial; `log₂ e(P)` is `#P`-complete and not
   tight (`S(12)=30 > 29`). Hence `NP`/`coNP` membership is open, and no
   "target" reduction can be validated by a polynomial certificate.

**Conclusion.** There is **no encoding-faithful target** for a meaningful
unconditional lower bound on `SORT-BOUND-U` obtainable by a reduction from a
known hard problem: every many-one/Turing/EXPTIME route is blocked by sparsity
or by encoding constraints, and the nonuniform upper bounds (`P/poly`, `P/log`,
`AC⁰`) do not yield uniform `P` membership. Fixed-polynomial lower bounds
(e.g. `∉ DTIME(N²)`) remain *not blocked* by any known separation but have
no known technique; they are not established here. The productive frontier
remains upper bounds, barrier theorems, and structural theorems about the
minimax game (per `AGENTS.md` "Realistic outcomes").

## 5. Independent checks

- **Encoding analysis.** `transfer_sizes(n)` (script) confirms matrix size
  `n²`: polynomial in unary length `n`, exponential in binary length
  `⌊log₂ n⌋+1` (test `test_matrix_is_polynomial_in_unary_but_exponential_in_binary`
  passes for `n = 8,16,32,64`).
- **Sparsity count.** `binary_guaranteed_count(m) > 2^{m-3}` for `m = 12,16,20`
  (test passes), establishing non-sparsity of `SORT-BOUND-B`.
- **P/log cutoff.** `plog_cutoffs(7) = [(1,0),(2,1),(3,1),(4,2),(5,2),(6,2),(7,3)]`
  (test passes), consistent with known `S(0..6)`.
- **Poset non-reduction.** `P1=(8,12,8,0,12)`, `P2=(26,0,10,0,8)` both have
  `e=8` but `F=3` vs `F=4` (test passes), so exact cost is not a function of
  `e`; `#P`-completeness of counting does not explain sorting hardness.
