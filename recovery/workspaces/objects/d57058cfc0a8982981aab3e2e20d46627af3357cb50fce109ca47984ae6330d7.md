# Exec report: compress-exact-space-evaluator

## Scope and claim discipline

- **Question addressed.** Construct and rigorously analyze a uniform exact evaluation algorithm for `S(n)` with asymptotically smaller workspace than the existing recurrence, explicitly accounting for representation and branch recomputation. (`[definition]` target from `docs/problem.md`, front brief.)
- **Encoding/model.** Unary threshold language `SORT-BOUND-U = { 1^n # 1^k : S(n) <= k }` and function `S_unary(1^n)`; work space measured in bits against actual unary input length `N = n+k+1` where stated. Adaptive comparison decision-tree model only (`docs/problem.md`, `AGENTS.md`).
- **Baseline (“existing recurrence”).** The memoized poset-DP recurrence/materialization baseline visits/stores `A001035(n)=2^{Θ(n^2)}` labelled posets (`docs/upper-bound.md`, `docs/research-certificates-barriers.md` §5, `docs/research-budgeted-dfs.md` §8). A naive matrix-per-frame implementation of pure budgeted DFS stores an `n×n` transitive-closure bitmatrix per recursion frame and uses `S_space^matrix(n,d)=O(d·n^2)` bits (`docs/research-budgeted-dfs.md` §5.1). The transcript-only budgeted DFS already improves this to `O((d+n) log(n+2))` bits per call and `O(n log^2 n)` bits for computing `S(n)` (`docs/research-budgeted-dfs.md` §5.2–5.3), while keeping time `2^{O(d log n)}`. `[literature/deduction, repository docs]`
- **No class-separation claim.** `SORT-BOUND-U ∈ PSPACE` is already established (`docs/problem.md`, `docs/research-certificates-barriers.md` Claim A). Any space refinement below is an upper-bound strengthening only, not NP/P separation and not claimed tight. `[deduction]`

## Algorithm/representation candidates

### Candidate A (baseline transcript DFS, known). `[deduction, docs/research-budgeted-dfs.md]`

- **State representation:** current comparison transcript `σ=((a1,b1),...,at,bt))`, `t<=d`, the path in `CanSort`.
- **Storage:** one frame = comparison `(a_s,b_s)` + cursor in `binom(n,2)` = `O(log n)` bits; whole stack = `O(d log n)` bits.
- **Branch recomputation:** no child poset matrix retained. Comparability/totality/incomparability are recomputed on demand by reachability in digraph `([n], σ)` using one BFS/DFS workspace: visited bit-vector `n` bits + queue/stack of <=n labels `O(n log n)` bits. Peak = stack + one reachability workspace = `O((d+n)log(n+2))` bits. Popping a frame discards only the last comparison; the parent transcript is unchanged.
- **Cost:** per node `poly(n)` time for recomputation, absorbed into `2^{O(d log n)}` node bound; total time unchanged.
- **Assessment:** asymptotically smaller than matrix-per-frame `O(d·n^2)` and exponentially smaller than memoized `2^{Θ(n^2)}` state storage, but carries an additive `O(n log n)`-bit workspace term independent of depth `d`.

### Candidate B (logspace-reachability refinement of transcript DFS). `[deduction]`

**Idea.** Keep the same transcript representation and backtracking control as Candidate A, but replace the BFS/visited-array reachability subroutine by a deterministic logspace reachability procedure (Savitch-style path-existence test) so that comparability queries do not allocate an `n`-bit visited array or label queue.

**Representation.**
- Transcript/path stack: identical to Candidate A, `<= d+1` frames, `O(d log n)` bits total.
- Search control: current pair cursor, budget counter, loop indices in `O(log n)` bits.
- No `n×n` closure matrix, no materialized incomparable-pair list, no visited bit-vector, no adjacency structure beyond reading the transcript (or recomputing incidences by scanning it).

**Reachability subroutine.** For query `Reach(u,v,ℓ)` = “is there a directed path of <=`ℓ` edges from `u` to `v` in `G_σ=([n],σ)`?”, use the standard halving recurrence: if `ℓ<=1` test direct edge by scanning `σ`; else existentially over midpoint `w` in `[n]` (implemented deterministically by iterating `w=1..n`) test `Reach(u,w,⌈ℓ/2⌉) ∧ Reach(w,⌈ℓ/2⌉,v)` sequentially, reusing space. Each recursion level stores `(u,v,ℓ,w,phase)` = `O(log n)` bits, depth `O(log n)`, so one query uses `O(log^2 n)` bits of work tape and `n^{O(log n)} · |σ|^{O(1)}` time. This is a standard consequence of Savitch’s theorem / directed st-connectivity in deterministic `O(log^2 n)` space (`[literature]`, Savitch 1970; reachability form). `[literature]+[deduction]`

**Comparability/totality tests.**
- `x ≺_{P(σ)} y` iff `Reach(x,y,n-1)`.
- `P(σ)` total iff for every `{x,y}`, `Reach(x,y,n-1)` or `Reach(y,x,n-1)`.
- “incomparable pair” in cursor scan is decided by two reachability queries and no stored list.

**Branch recomputation and backtracking.** On descent append `(a_s,b_s)` to the transcript prefix; on child return pop it and continue the parent cursor. The only mutable long-lived state is the transcript/control stack. Reachability work is allocated inside a query, completed, and released before any recursive `CanSort` child call, so peak space is transcript/control plus one `O(log^2 n)` reachability workspace, not per-frame or per-query accumulation. Acyclicity is preserved because `CanSort` only compares currently incomparable pairs (`docs/research-budgeted-dfs.md` §5.2). `[deduction]`

**Rigorous space bound.**
- Stack/transcript: `O(d log n)` bits.
- Reachability workspace: `O(log^2 n)` bits.
- Counters/cursor/input heads: `O(log n)` bits.
- Total: `S_B(n,d) = O(d log n + log^2 n)` bits. `[deduction]`

**Relation to baselines.**
- Versus naive matrix DFS: `O(d log n + log^2 n)` vs `O(d·n^2)` — asymptotically smaller for all nontrivial `d,n`. `[deduction]`
- Versus memoized recurrence: exponentially smaller than `2^{Θ(n^2)}`. `[deduction]`
- Versus transcript+BFS Candidate A (`O((d+n)log n)`): removes the additive `O(n log n)` term. For fixed/slow-growing `d` this is an asymptotic improvement (e.g. `d=O(log n)` gives `O(log^2 n)` vs `O(n log n)`); for the function-evaluation regime `d=Θ(n log n)` both are `O(n log^2 n)` and the improvement is in lower-order/additive terms only. `[deduction]`

**Time bound.** Each node performs `poly(n)` reachability queries × `n^{O(log n)}` per query = `n^{O(log n)}` work. With at most `(2·binom(n,2))^d = 2^{O(d log n)}` nodes, total time is `2^{O(d log n)} · n^{O(log n)} = 2^{O(d log n + log^2 n)}`. For `d <= U(n)=O(n log n)` this remains `2^{O(n log^2 n)}` in numeric `n`; no time improvement is claimed. `[deduction]`

**Unary input-length accounting.** For `SORT-BOUND-U` input `1^n#1^k`, `N=n+k+1`, `d=k`, and a uniform read-only-input TM has `S_B(n,k)=O(k log n + log^2 n)=O(N log(N+2))` work-tape bits and `2^{O(N log(N+2))}` time by the same preprocessing as `docs/research-budgeted-dfs.md` §5.3. Compared to Candidate A’s worst-case per-call statement `O((k+n)log(n+2))`, this is a strict bit-level strengthening whenever `k=o(n)` and matches when `k=Θ(n)` or larger; it does **not** improve the already-recorded function space class `O(n log^2 n)` for computing `S_unary(1^n)`. `[deduction]`

### Candidate C (transcript compression / poset canonicalization). `[open/conjecture]`

Compress `σ` below `O(d log n)` bits (e.g. store a transitive reduction/generating set, run-length/combinatorial code, or a canonical representative over equivalent transcripts/posets). A uniform lossless encoding would need to distinguish all transcripts/states that remain behaviorally relevant; no representation with a proved all-`n` worst-case bound below `O(d log n)` for the exact budgeted game is established here. `[open]`

## Evidence and falsification attempts

- **Repository evidence reviewed.** `docs/research-budgeted-dfs.md` states and accounts for Candidates A/baselines, including the note that Savitch-based reachability could remove the `+n` workspace term at quasi-polynomial per-query cost (absorbed in time). `scripts/transcript_dfs.py` / `tests/test_transcript_dfs.py` experimentally exercise the transcript representation for `n<=5` and all posets for `n<=4` (reproduced above: values/depth/edge counts consistent). `[experiment, repository]`
- **Targeted falsification attempt 1 — hidden recursive stack in Candidate B:** Savitch reachability is itself recursive/iterative over `O(log n)` levels with `O(log n)` bits per level; this is included as the `O(log^2 n)` workspace term and must not be implemented via an unaccounted host-language call stack in a formal accounting. No hidden per-node graph workspace remains because visited structures/lists are eliminated. **Not falsified as a bit-space bound; implementation-fidelity risk remains.** `[deduction]`
- **Targeted falsification attempt 2 — superpolynomial independent decisions in compact representation:** Candidate B stores no compact summary of past choices except the explicit transcript of `d` comparisons (`2d log n` bits of labels plus control). It does not claim to encode superpolynomial independent branch information in sublinear form; the potential compression question is deferred to Candidate C and remains open. **No proposed compact representation here is forced to store superpolynomial independent decisions.** `[deduction/open]`
- **Targeted falsification attempt 3 — branch recomputation omission:** Candidate B recomputes reachability from the current transcript for every comparability test and never caches closures across backtracks or sibling branches except the transcript prefix itself. Correctness follows the same `P(σ)`-equivalence argument as Candidate A (`docs/research-budgeted-dfs.md` §5.2) because Savitch reachability decides directed reachability in `G_σ`. **Not falsified.** `[deduction]`
- **No new heavy computation run.** I did not run exhaustive searches beyond existing small scripts; none would discriminate an all-`n` space theorem from these polynomial/counting arguments. `[experiment scope]`

## Findings

1. **`[deduction]`** The memoized recurrence is not the relevant space floor: transcript-only DFS already gives exponential space compression over `2^{Θ(n^2)}` and polynomial compression over `O(d·n^2)` matrix frames, but with an additive `O(n log n)` recomputation workspace.
2. **`[deduction]`** A uniform exact evaluator (Candidate B) can decide `CanSort(∅,d)` in `O(d log n + log^2 n)` bits by storing only the comparison transcript/control stack and recomputing reachability in deterministic `O(log^2 n)` space, at `n^{O(log n)}` per-query time overhead absorbed into `2^{O(d log n)}`. This yields `SORT-BOUND-U ∈ DTIME(2^{O(N log(N+2))}) ∩ DSPACE(O(N log(N+2)))` with the refined per-call workspace term (strengthening the worst-case additive term in `docs/research-budgeted-dfs.md` §5.3) and `S_unary` computable in `2^{O(n log^2 n)}` time and `O(n log^2 n)` bits.
3. **`[deduction]`** Relative to Candidate A this is a genuine workspace reduction (`O((d+n)log n)` -> `O(d log n + log^2 n)`), but it is **not** an asymptotic improvement of the leading function-computation bound `O(n log^2 n)` when `d=Θ(n log n)`. Relative to matrix/memoized recurrences it is asymptotically smaller.
4. **`[open]`** No candidate here achieves workspace asymptotically below `O(d log n)` for the exact budgeted game. Any such improvement would need either a shorter-than-transcript exact state representation or a proof that parts of the decision history need not be retained while still supporting correct backtracking/recomputation.

## Obstacles

- **Transcript/path dependence:** the DFS decision procedure is defined by the current history-dependent poset `P(σ)`; forgetting comparisons while remaining on the same search branch appears to lose information needed to test comparability and to restore the parent state after backtracking. `[open]`
- **No canonical succinct state identified:** reachable-poset state counts are large in general (`docs/research-certificates-barriers.md` §5, A001035), and optimal-play compression is a separate open question; current evidence does not supply a polynomial or `o(d log n)` exact representation. `[open/literature]`
- **Time-space tradeoff pressure:** removing the `n`-bit reachability workspace required superpolynomial time per reachability query in the standard method; further space compression may incur larger recomputation costs or require new structure. `[deduction/open]`
- **Model fidelity:** space claims must count Turing-machine work tape (including reachability recursion/control), exclude read-only input, and not count omitted recomputation work; any implementation-level shortcut can hide a violation. `[deduction]`

## Next decisive question

Can the exact budgeted DFS be simulated while storing only `o(d log n)` bits of mutable path information for `d=Θ(S(n))`, e.g. by a provably correct transcript-compression scheme, a catalytic/reversible backtracking representation, or a canonical state identifier whose reconstruction cost is explicitly bounded, without enumerating the winning frontier/state DAG? A concrete falsifier would be an explicit family of forced comparison paths or a proof that `Ω(d log n)` bits are necessary to distinguish DFS configurations consistent with correct backtracking on the `S(n)` game. `[open]`
