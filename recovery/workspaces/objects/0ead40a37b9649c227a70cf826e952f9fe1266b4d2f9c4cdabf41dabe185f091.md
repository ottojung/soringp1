## 2. Fixed syntactic FO(PFP)/IFP sentence — not complete

**Not discharged as a complete fixed sentence.**

Concrete elements present:
- Final sentence shape: `Φ_SORTU := WellFormed_w ∧ Φ_game` (§1, §2), with `Malformed`/`WellFormed_w` fixed FO formulas.
- Input structure: `A(w)=(W,<,One,Hash)`, `w=1^n#1^k`, `N=n+k+1` (§1).
- A stage-indexed FO(PFP) schema is written explicitly (§5.3): `Φ_game := ∃z̄ (InitCode(z̄) ∧ [PFP_{ACC(s̄,z̄)} ψ_ACC(s̄,z̄,ACC)](max̄,z̄))`, with fixed FO stage arithmetic (`IsZeroStage`, `PredStage`, lex order over `W^r`, `r>=2`) and a fixed positive operator body `ψ_ACC` using `AccCode/ExistsCode/ForallCode/YieldECode/YieldA0Code/YieldA1Code`.

Blocking gaps:
- `ψ_ACC` is **not fully instantiated** as a sentence over `A(w)` alone because `Code/Decode` and all `*Code` predicates depend on `[open:PACK]` (§5.2–5.3). The artifact states this explicitly: `AccCode(z̄) := ∃C(Code(C;z̄) ∧ ConfigAcc(C))` etc. are semantic abbreviations pending the configuration-code/packing lemma.
- The configuration-as-relations schema `Φ_game^schema` (§5.2) is explicitly described as a schema, not a fully discharged standard FO(PFP) sentence, because PFP fixed-point variables in standard syntax are relation variables of fixed arity over domain tuples while whole relation-valued configurations are being discussed.
- Section 5.3 marks the cell code as schematic (`PosCode... [open:PACK]`) and states: assuming `[open:PACK]` supplies `Code(C;z̄)` and decoding formulas, `ψ_ACC` becomes fixed; but `[open:PACK]` is not discharged.

Therefore there is no complete, syntactically closed, fully interpreted FO(PFP)/IFP sentence in the artifact that can be evaluated without the missing `Code/Decode` instantiation.

## 3. Config normal form / cell-index encoding — explicit locally, global packing not discharged

**Partially discharged.**

Concrete normal forms provided:
- **Semantic/game normal form N_G** (§3.2): fixed signature over `A(w)` with input relations `<,One,Hash`; state relations `Pos(u,v)` (arity 2, `Key`), `Used(t)` (arity 1, `Ctr`), control tags `QSort,QAdv,QAcc,QRej`, selected pair `Sel(a,b)` (arity 2), and global validity flag `Ok`. This is a fixed finite signature independent of `n,k`.
- **Configuration validity** is given as explicit FO formulas: `ValidPos`, `Irreflexive`, `Incomparable`, `Total`, `ExactlyOneUsed`, `NoSel`, `OneSel`, `ExactlyOneControl`, `ValidConfig` (§3.3).
- The artifact correctly distinguishes relation-valued state representation from the old fixed-tuple decoding blocker (§7): `Pos` is an explicit binary relation, so arbitrary posets are representable.

Global/cell-index encoding gap:
- The standard global capture instantiation requires representing configurations/acceptance as fixed-arity PFP/IFP relations over `W` in a chosen normal form. The note lists equivalent standard options (§5.2): DTM/PSPACE normal form, simultaneous PFP/IFP tuple encoding, stage-indexed ATM acceptance PFP, and rejects a bounded reachable-universe relation.
- `[open:PACK]` is the precise missing encoding task: replace the schematic relation-valued/state-code form by one fixed relation variable of fixed arity over `W` with a proved encoding/decoding correspondence (§5.3). This is a **cell-index/tuple-packing/configuration-coding** obligation, not a local `G(n,k)` rule gap.

Assessment: the artifact gives an explicit local config normal form and several plausible global normal-form routes, but it does **not** discharge a complete fixed cell-index encoding usable by a standard FO(PFP) simulation proof.

## 4. Simulation lemma and obligations (2)–(4) — stated, not discharged

**Not discharged.** The artifact gives an explicit target lemma and localizes the remaining proof work correctly.

Target lemma (§6.1): for every `n,k>=0`, `w=1^n#1^k`,
1. malformed inputs are rejected;
2. well-formed inputs have the intended initial code;
3. `YieldECode/YieldA0Code/YieldA1Code` preserve/reflect `YieldE/YieldA0/YieldA1` under `Code`;
4. the PFP stage acceptance on the initial code equals acceptance by semantic alternating operator `T`;
5. `T` accepts the initial `M_G/G(n,k)` configuration iff `S(n)<=k`.

Obligation status:
- **(1)** is locally discharged by definition: `Φ_SORTU := WellFormed_w ∧ Φ_game` (§6.2).
- **(5)** is the intended `M_G / G(n,k) / S(n)<=k` correspondence, supported by project definitions and `research-certificates-barriers.md`; the artifact states it as a target correspondence rather than supplying a full machine-level formalization of `M_G`.
- **(2), (3), (4)** are explicitly open and depend on `[open:PACK]` (§0, §5.3, §6.2). Obligation (2) requires initial-code correctness; (3) requires faithfulness of `Code/Decode` for the §4 FO formulas; (4) requires stage/alternation soundness-completeness and rank/stage bounds.

The local ingredients needed by (3)–(5) are mostly explicit:
- `Init/ConfigAcc/ConfigRej` (§4.1).
- Incremental TC formula `StepPos` with a local TC lemma sketch and falsification target (§4.2).
- Existential sorter move `YieldE` requiring a non-total state, available budget, and an incomparable selected pair (§4.3).
- Universal adversary moves `YieldA0/YieldA1` applying `StepPos` for `a<b`/`b<a`, consuming one `SuccCtr` step, and using `PostBudget` to accept total states, continue with remaining budget, or reject exhausted non-total states (§4.4). This addresses legal `G(n,k)` transitions and `budget <= k`.
- Monotone alternating acceptance operator `T` and the finite-rank acceptance intuition (§5.1).

These local formulas are strong progress, but they do not by themselves discharge the global simulation lemma over the fixed PFP sentence.

## 5. Equivalence to `M_G` / `S(n)<=k` — target stated, proof not completed

The equivalence chain is stated in the right places (§2, §5.1, §6.1, §7):
```text
A(w) |= Φ_SORTU (intended)
  iff M_G accepts A(w)
  iff sorter wins G(n,k)
  iff S(n)<=k
  iff w ∈ SORT-BOUND-U
```
for well-formed `w`, with malformed rejection.

This is **not** proved end-to-end in the artifact. The local semantic equivalence `sorter wins G(n,k) iff S(n)<=k` is the intended project/game meaning and is consistent with `docs/problem.md` and `docs/research-certificates-barriers.md`. The machine/game layer `M_G` is defined as the alternating game machine for `G(n,k)` but not formalized to the level of a complete ATM normal form with a completed capture proof. The formula-level equivalence to `Φ_game` is conditional on `[open:PACK]` and obligations (2)–(4).

Thus equivalence is **precisely targeted but not discharged**.

## 6. Minimal residual step — precisely stated

The artifact states the exact minimal remaining step clearly and more sharply than a vague appeal to “standard FO(PFP)=PSPACE capture”.

Primary statement (§0): the gap is
> “Global PFP/IFP simulation instantiation for the explicit `M_G` normal form below: prove a simulation/correspondence lemma for the chosen fixed FO(PFP) ... sentence family over `A(w)` showing that, on every well-formed input, the global fixed point accepts the encoded initial configuration iff the alternating computation defined by the local FO transition formulas in §4 has an accepting run iff `S(n)<=k`. Concretely this requires (a) fixing one standard configuration/cell normal form among the equivalent ones in §5, (b) writing the corresponding global update operator as a single FO formula in that normal form, and (c) proving soundness/completeness of the alternating acceptance fixed point for that operator. No local `G(n,k)` rule is missing; the gap is this global proof for the chosen normal form.”

Operational residual (§6.2): discharge `[open:PACK]` and prove obligations (2)–(4) for the resulting fixed `Code/Decode` and `ψ_ACC` over `A(w)`, using the §4 local FO formulas as semantic transition truth conditions.

This localization is accurate: local `G(n,k)` rules, TC, legality, and budget are explicit; the remaining work is global configuration coding and the alternating PFP acceptance proof for that coding.

## 7. Smaller-class / overclaim check

**No smaller complexity-class overclaim found.** The note contains appropriate caveats:
- §0 states that a complete line-by-line discharged FO(PFP) proof from scratch is not produced.
- §5.1 explicitly warns: positivity of `T` as an abstract game operator does **not** place `SORT-BOUND-U` in FO(LFP) on the bare ordered word, in `P`, or in `NP`/`coNP`; the global encoding/capture issue remains.
- §7 cites Vardi/Abiteboul–Vianu and `SORT-BOUND-U ∈ PSPACE` only as in-principle existence context, not as a discharged project-specific sentence/proof.
- §8 falsification targets include “No claim is promoted to `P`, `FO(LFP)` on the bare word, `NP`, or `coNP`.”

Minor caution: the semantic fixed-point discussion could be misread out of context as if local positivity already yields the final descriptive-complexity class. The artifact itself guards against this, and an audit should preserve that guard.
