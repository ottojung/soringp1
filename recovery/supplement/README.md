# Additional recovered mathematical material

The manifest maps original source paths to content-addressed text objects,
including Viche research and referee records, historical retired worktree
archives, and the filesystem of a broken Git worktree. Identical records
across government worktrees are deduplicated. No unrelated agent configuration
or database is included. The omitted list records references to scratch paths
that no longer exist at the time of recovery; the corresponding findings may
still be preserved in the board or ledger. Credential-like strings are redacted.
