## 0. Model and encodings (fixed)

`[definition]` From `docs/problem.md`:

- `S(n)` = minimum height (worst-case number of pairwise comparisons) of a
  **deterministic adaptive comparison decision tree** that correctly sorts every
  permutation of `n` distinct labelled keys.
- `SORT-BOUND-U = { 1^n # 1^k : S(n) ≤ k }` — both parameters **unary**.
- Input length: `N = n + k + 1`.
- `L(n) = ⌈log₂ n!⌉` (information lower bound); `U(n)` = Ford–Johnson bound.
- Surplus parameter `s = k - L(n)`.

The game `G(n,k)` (from `docs/research-certificates-barriers.md` §0):

> State = transitively closed poset `P` on `n` labelled elements. Start at the
> empty order. While `P` is not total and fewer than `k` comparisons remain:
> the **sorter** picks an incomparable pair `{x,y}`; the **adversary** answers
> `x<y` or `y<x`; replace `P` by its transitive closure. Sorter wins iff a
> total order is reached within `k` comparisons.
>
> `S(n) ≤ k` iff the sorter wins `G(n,k)`. `[deduction]`

## 1. The VAR hierarchy and VAR[3] = DSPACE(N²)

### 1.1 Definition of VAR[j] `[definition]`

`[literature]` (Immerman-Buss-Barrington 2001, JSL 66(3):1217–1230,
doi:10.2307/2695103):

> **VAR[k+1] = DSPACE[n^k]** on ordered word structures.

That is, the set of properties describable by a uniform sequence of first-order
sentences using at most `k+1` distinct variables is exactly the set of properties
checkable by a Turing machine in deterministic space `n^k` (where `n` is the size
of the universe).

The key feature of VAR[j]: a **quantifier block** (a list of quantifiers over
`j` variables) may be **iterated exponentially many times** — as a function of the
input size — while reusing only `j` distinct variables. This is what gives VAR[j]
its power beyond plain FO^j.

### 1.2 VAR[j] is NOT plain FO^j `[deduction]`

`[literature]` (Immerman's descriptive complexity page, https://people.cs.umass.edu/~immerman/descriptive_complexity.html):

- **FO[n^O(1)]** (quantifier blocks iterated polynomially many times, with a fixed
  number of requantified variables) = **P** = FO(LFP).
- **FO[2^{n^O(1)}]** (quantifier blocks iterated exponentially many times) = **PSPACE** = FO(PFP).

So VAR[O(1)] = P and VAR[O(1)] with exponential iteration = PSPACE. But VAR[j] for
**fixed** `j` is a proper subclass: VAR[j] = DSPACE[n^{j-1}], which is strictly
contained in PSPACE for fixed `j`.

**FO^j** (the `j`-variable fragment of first-order logic) is **not** the same as
VAR[j]:
- FO^j: formulas using at most `j` variables, with **no iteration** of quantifier
  blocks (just the usual FO quantifier structure).
- VAR[j]: formulas using at most `j` variables, but with **exponential iteration**
  of the quantifier block.

VAR[j] is vastly more expressive than FO^j. For example, VAR[3] = DSPACE[n²]
contains all of P (since P ⊆ DSPACE[n²]), while FO³ (3-variable FO) is a tiny
fragment of FO that cannot even express all of AC⁰.

### 1.3 The connection to the O(N log N) work-bit bound `[deduction]`

`[deduction]` From `docs/research-budgeted-dfs.md` §5.3 (commit d85bd1f):

> **SORT-BOUND-U ∈ DTIME(2^{O(N log(N+2))}) ∩ DSPACE(O(N log(N+2)))**

where `N = n+k+1` is the unary input length. The workspace is `O(N log(N+2))`
bits (quasilinear in the input length).

Since `O(N log(N+2)) ⊆ O(N²)` for all `N ≥ 2`, we have:

> **SORT-BOUND-U ∈ DSPACE(N²) = VAR[3]** on ordered word structures.

This is a **much more precise** descriptive complexity classification than just
"PSPACE" or "FO(PFP)": it says the language is definable by a uniform sequence
of FO sentences using at most **3 distinct variables** (with exponential iteration
of the quantifier block).

### 1.4 What this does NOT imply `[deduction]`

- **Does NOT imply VAR[2]** = DSPACE[N]: the O(N log N) bound is not known to be
  O(N), and the DFS uses Θ(log N) bits per stack frame.
- **Does NOT imply FO(LFP) = P**: VAR[3] = DSPACE[N²] is much larger than P.
  The language being in VAR[3] places it in DSPACE[N²], but P ⊆ DSPACE[N²] is
  a one-way inclusion.
- **Does NOT imply FPT**: VAR[3] = DSPACE[N²] is polynomial space, while FPT
  requires f(s)·poly(N) time. The VAR[3] upper bound does not constrain the FPT
  question.

## 2. Trivial capture theorem vs explicit FO(PFP) sentence

### 2.1 The capture theorem (trivial direction) `[literature]`

`[literature]` (Abiteboul-Vianu 1991, "Fixed-point logics, relational machines,
and computational complexity"; see also Immerman's descriptive complexity page):

> **PSPACE = FO(PFP)** on ordered finite structures.

This means: every PSPACE property is definable by a partial fixed-point formula.
Since SORT-BOUND-U ∈ PSPACE (by Claim A of `docs/research-certificates-barriers.md`),
there **exists** an FO(PFP) sentence defining it.

### 2.2 The explicit formula (non-trivial) `[open]`

The capture theorem is **non-constructive**: it guarantees existence but does not
give the formula. Constructing an **explicit** FO(PFP) sentence for SORT-BOUND-U
is a separate, harder research problem. It would require:

1. Explicitly encoding the game `G(n,k)` as a PFP formula.
2. Showing that the PFP iteration correctly simulates the alternating Turing
   machine of Claim A.
3. Verifying that the formula is faithful to the sorting-game semantics.

This is analogous to the distinction between "P = FO(LFP) by Immerman-Vardi"
(existence) and "here is an explicit LFP formula for this specific P problem"
(construction). The capture theorem is a **classification**; an explicit formula
is a **witness**.

### 2.3 The VAR[3] classification is also non-constructive `[deduction]`

The Immerman-Buss-Barrington theorem says SORT-BOUND-U ∈ VAR[3], i.e., there
exists a uniform sequence of FO sentences with 3 variables defining it. But
constructing these sentences explicitly is a separate problem. The theorem
guarantees existence but does not give the formula.

## 3. Structural restrictions for FO(LFP)=P and ESO=NP

### 3.1 FO(LFP) = P requires order `[literature]`

`[literature]` (Immerman 1986, Vardi 1982; see also Hodkinson's survey
https://www.doc.ic.ac.uk/~imh/papers/swansea.pdf):

> **P = FO(LFP)** on the class of **ordered** finite structures.

The structural restriction is the **presence of a total order** on the universe.
Without order, FO(LFP) does **not** capture P on all finite structures:

- On unordered structures, FO(LFP) ⊊ P. The most basic reason: FO(LFP) cannot
  express **evenness** (whether the universe has even cardinality), which is
  trivially in P.
- FO(LFP) + counting (FPC) still does not capture P on all structures
  (Cai-Fürer-Immerman 1992).

**Precise characterization** (Dawar, Hella-Kolaitis-Luosto; see Hodkinson's survey
Theorem 2.1): For any class of finite structures, the following are equivalent:

1. The class is of **bounded rigidity** (k-rigid for some k: any two distinct
   elements have different L^k-types).
2. There is an **FP-definable linear order** on the class.
3. There is an **L^{ω}_{∞ω}-definable linear order** on the class.

So the structural restriction that produces FO(LFP)=P is: **the class admits an
FP-definable linear order** (equivalently, bounded rigidity).

### 3.2 ESO = NP requires NO restriction `[literature]`

`[literature]` (Fagin 1974):

> **NP = SOE** (existential second-order logic) on **all** finite structures.

This is a **universal** capture: no structural restriction is needed. Fagin's
theorem holds on the class of all finite structures, ordered or unordered.

### 3.3 The asymmetry `[deduction]`

There is a fundamental asymmetry between the two captures:

| Capture | Structural restriction | Reason |
|---|---|---|
| FO(LFP) = P | **Total order** (or FP-definable order) | Without order, FP cannot count or encode computation |
| ESO = NP | **None** (universal) | Existential second-order quantification is powerful enough without order |

This asymmetry is why the surplus language (a language over **words**, which are
naturally ordered) is in FO(LFP) = P **iff** it is in P, but the question of whether
it is in ESO = NP is independent of the ordering.

### 3.4 Connection to the surplus problem `[deduction]`

The surplus language `{(n,s) : S(n) ≤ L(n)+s}` is a language over words (strings
`1^n # 1^k`), which are naturally ordered structures. So:

- **FO(LFP) = P** applies: the surplus language is in FO(LFP) iff it is in P.
  This is **open** (equivalent to the FPT question).
- **ESO = NP** applies: the surplus language is in ESO iff it is in NP.
  This is **open** (blocked by Mahaney for many-one reductions).
- **VAR[3] = DSPACE(N²)** applies: the surplus language is in VAR[3].
  This is **established** (by the O(N log N) work-bit bound).

The parameter `s` does not reduce the alternation depth of the game `G(n, L(n)+s)`:
the depth is `L(n)+s = Θ(n log n) + s = Θ(n log n)` (since `s ≤ Θ(n)` in the
informative regime). So the parameter `s` is "swamped" by the base alternation
`L(n) = Θ(n log n)`.

## 4. Falsification attempt

### 4.1 Hypothesis: VAR[3] classification helps with the FPT question `[conjecture]`

**Falsified.** The VAR[3] = DSPACE(N²) upper bound is much weaker than FPT.
FPT requires `f(s)·poly(N)` time, while VAR[3] allows `poly(N)` **space** (which
can be used for `2^{poly(N)}` time). The VAR[3] classification places the language
in a class that is **strictly larger** than FPT (assuming FPT ≠ PSPACE), so it
does not constrain the FPT question.

### 4.2 Hypothesis: the parameter s reduces the alternation depth `[conjecture]`

**Falsified.** The game `G(n, L(n)+s)` has depth `L(n)+s = Θ(n log n) + s`. Since
`s ≤ U(n) - L(n) = Θ(n)` in the informative regime, we have `L(n)+s = Θ(n log n)`.
The parameter `s` adds only `O(s) = O(n)` alternations, which is negligible compared
to the `Θ(n log n)` base. So the alternation depth is **Ω(n log n) regardless of s**.

### 4.3 Hypothesis: the surplus language is in FO(LFP) = P `[open]`

**Not falsified, not confirmed.** This is equivalent to the central FPT question.
The descriptive complexity classification is:

| Logic | Class | Surplus language membership |
|---|---|---|
| VAR[3] | DSPACE(N²) | **Yes** (established) |
| FO(PFP) | PSPACE | **Yes** (established, by capture) |
| FO(LFP) | P | **Open** (= FPT question) |
| ESO | NP | **Open** (blocked by Mahaney) |

## 6. Next obstacle `[open]`

The central obstruction is the **gap between VAR[3] = DSPACE(N²) and FO(LFP) = P**.
The surplus language is known to be in VAR[3] (3 variables, exponential iteration),
but whether it is in FO(LFP) (polynomial time) is open and equivalent to the FPT
question. The parameter `s` does not reduce this gap because the alternation depth
is `Θ(n log n)` regardless of `s`.

**Concrete next step:** construct an **explicit** FO(PFP) sentence for SORT-BOUND-U
(not just existence by capture), and investigate whether the 3-variable VAR[3]
definition can be tightened to a 2-variable or LFP definition. Either outcome
would be a substantive research result.

## 7. Summary

> **Theorem (informal, deduction).** SORT-BOUND-U is in VAR[3] = DSPACE(N²) on
> ordered word structures, by the O(N log N) work-bit bound of the budgeted DFS
> (§5.3) and the Immerman-Buss-Barrington capture VAR[3] = DSPACE(N²). This is
> a more precise classification than PSPACE = FO(PFP), but it does not imply
> FO(LFP) = P or FPT. The parameter `s` does not reduce the alternation depth
> of the game `G(n, L(n)+s)`, which is `Θ(n log n)` regardless of `s`. The
> structural restriction for FO(LFP)=P is the presence of a total order (or
> FP-definable linear order); ESO=NP requires no restriction. The surplus
> language is in VAR[3] (established), in FO(PFP) (established by capture),
> and its membership in FO(LFP) = P and ESO = NP is open.
