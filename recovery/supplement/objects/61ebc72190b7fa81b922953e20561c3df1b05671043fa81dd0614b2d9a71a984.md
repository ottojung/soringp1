## 3. Fortune/Yesha: the coNP-hard barrier stands without membership `[literature]`+`[deduction]`

**Theorem (Fortune 1979).** No `coNP`-hard set is sparse unless `P=NP`
(equivalently, no `NP`-hard set is co-sparse unless `P=NP`). Proof: replace the
`SAT` self-reduction tree in Mahaney's argument by the `TAUT` tree
(`φ` tautology iff *every* formula at a level is a tautology; combine with `∧`);
the sparse target's membership is never used (Grochow, Remark 2.2).

**Theorem (Yesha 1983).** If a `coNP`-hard set is `≤^P_bptt`-reducible to a
sparse set, then `P=NP`; this generalizes Fortune to bounded positive
truth-table reductions and drops the target membership hypothesis.

Hence `SORT-BOUND-U` sparse and `coNP`-hard (many-one) implies `P=NP`; the
repo's Theorem 4.2 and §4.2 item 4 are correct **as written**. The earlier
proposed `SORT-BOUND-U ∈ coNP` hypothesis is retracted.

## 4. Berman–Hartmanis EXPTIME: unconditional and non-redundant `[literature]`+`[deduction]`

**Known separations/containments.** `PSPACE ⊆ EXPTIME` (simulate a
space-`n^k` machine for its at-most-`2^{n^k}` steps) and `P ⊊ EXPTIME` (time
hierarchy). Whether `PSPACE = EXPTIME` is **open** (Wikipedia *PSPACE*;
Clingerman–Luu arXiv:2304.14575). No strictness of `PSPACE` vs `EXPTIME` is
assumed here.

**Theorem (Berman–Hartmanis 1977, Thm. 12).** No `p`-sparse language is
complete for `EXPTIME` under polynomial-time many-one reductions.
Unconditional. Mechanism: there is an `A₀ ∈ EXPTIME` that is not `p`-sparse
and to which every `p`-reduction must be one-one almost everywhere, so an
`EXPTIME`-complete set must be dense.

**Consequence for `SORT-BOUND-U`.** `SORT-BOUND-U` is sparse (Lemma 3.1: at
most `O(L²)` strings of length `≤ L`) and lies in `PSPACE`
(`docs/research-certificates-barriers.md`, Claim A). By Berman–Hartmanis,
`SORT-BOUND-U` is **not `EXPTIME`-complete** under polynomial-time many-one
reductions. This is unconditional and is **not** redundant with
`SORT-BOUND-U ∈ PSPACE`: since `PSPACE` vs `EXPTIME` is open, `PSPACE`
membership alone does not exclude `EXPTIME`-completeness. (An earlier version
of this note wrongly claimed `PSPACE ⊊ EXPTIME` and called the consequence
redundant; both are retracted in §0.)

## 5. Ukkonen 1983: PSPACE conjunctive sparse-hard barrier `[literature]`+`[deduction]`

**Theorem (Ukkonen 1983, SICOMP 12(3), DOI 10.1137/0212038, Thm. 8).** If
`PSPACE` has a sparse hard set for conjunctive polynomial-time reductions,
then `P=PSPACE`. Equivalently: no sparse `PSPACE`-hard set (conjunctive)
exists unless `P=PSPACE`.

**Definitions (from the paper).** `A ≤^P_conj B` iff `A ≤^P_T B` via an oracle
machine whose reject states contain only the `NO` state; i.e. the machine
rejects only when a query is answered "no", so `x ∈ A` iff **every** query it
makes is in `B`. Many-one is a special case: a many-one reduction `f` is the
conjunctive reduction that makes the single query `f(x)` and accepts iff
`f(x) ∈ B`. Hence `≤^P_m ⊆ ≤^P_conj ⊆ ≤^P_T`.

**Exact scope.** The hypothesis is "PSPACE has a sparse hard set": there is a
sparse set `S` with `PSPACE ⊆ conj-P(S)`. The target `S` is only required to be
**sparse**; it need **not** lie in `PSPACE` (hardness, not completeness). The
proof uses the self-reducibility of `QBF` and enumerates the sparse `S` up to
the relevant length; `S`'s membership in `PSPACE` is never used.

**Application to `SORT-BOUND-U`.** `SORT-BOUND-U` is sparse and lies in
`PSPACE`. Suppose it were `PSPACE`-hard under polynomial-time many-one
reductions. Since `≤^P_m ⊆ ≤^P_conj`, it would be a sparse `PSPACE`-hard set
for conjunctive reductions; by Ukkonen's Theorem 8, `P=PSPACE`. Therefore:

> `SORT-BOUND-U` is **not `PSPACE`-hard under polynomial-time many-one
> reductions unless `P=PSPACE`.**

**Stronger unconditional consequence?** None for `PSPACE` is available from
the audited sources: Ukkonen's result is **conditional** (`P=PSPACE`), and the
paper does not claim an unconditional `PSPACE` sparse-hardness separation. The
unconditional sparse result in this area is Berman–Hartmanis **EXPTIME**
(§4). So the two results are complementary: BH gives an unconditional
non-`EXPTIME`-completeness, Ukkonen gives a conditional non-`PSPACE`-hardness.

**Distinctions.** (i) BH EXPTIME: unconditional, `EXPTIME`-completeness,
many-one. (ii) Ukkonen PSPACE: conditional (`P=PSPACE`), `PSPACE`-hardness,
conjunctive. (iii) Fortune/Yesha coNP: conditional (`P=NP`), `coNP`-hardness,
many-one/`bptt`. These are three different classes, hypotheses, and reduction
types; none is implied by another.

## 6. Does `P/log` give a stronger *uniform* bound? `[deduction]`

The advice in Theorem 3.7 is the cutoff
`t_L = max{ n ≤ L−1 : n + S(n) ≤ L−1 }`. Computing `t_L` requires
`S(0),…,S(L−1)`, i.e. exactly the function `S_unary`. Since `S_unary ∈ FPSPACE`
(binary search on `k` plus the budgeted DFS of
`docs/research-budgeted-dfs.md`, which runs in `DSPACE(O(N log N)) ⊆ PSPACE`),
`t_L` is computable in `FPSPACE`. Feeding this advice to the `P/log` verifier
therefore yields `SORT-BOUND-U ∈ PSPACE` — **already known**, with no
improvement. The `P/log` bound is genuinely nonuniform and does not transfer.

**Strongest exact uniform bounds (unchanged).**
`SORT-BOUND-U ∈ DSPACE(O(N log N)) ⊆ PSPACE` and
`∈ DTIME(2^{O(N log N)})`. No stronger uniform bound is obtained here; the
frontier theorem (`docs/research-winning-frontier-barrier.md`) only rules out
methods that necessarily enumerate all reachable winning states.

   Fortune/`coNP` barrier, and the Ukkonen `PSPACE` barrier are all correctly

   stronger unconditional `PSPACE` consequence is claimed.
4. **No stronger uniform bound** follows from `P/log`; the strongest exact
   uniform bounds are unchanged (`PSPACE` space, `2^{O(N log N)}` time).
