# Unary SORT-BOUND-U: why the natural 2^{O(N)} evaluators fail

**Status:** paper-level analysis + exact integer witnesses. **Not Lean-checked.**
**Scope:** unary threshold `SORT-BOUND-U = {1^n # 1^k : S(n) <= k}`, actual
input length `N = n+k+1`. No binary claim, no complexity-class separation.
Model: adaptive comparison sorting of `n` distinct labelled keys; `S(n)` =
minimax worst-case comparisons; the threshold is a fixed function of `n` alone
(`S(n) <= k` is monotone in `k`), so deciding it is exactly evaluating `S(n)`
and comparing. Every item is labelled `[definition]` / `[literature]`
(n) / `[deduction]` / `[experiment]` / `[open]`.

## 1. Exact AND-OR recurrence `[definition]`

State = transitively closed poset `P` on `[n]` (a comparison transcript's
closure). `CanSort(P,d)` = "the sorter determines the total order from `P`
within `d` comparisons":

```
CanSort(P,d) = True                       if P is total
             = False                      if d = 0 and P not total
             = OR over incomparable (i,j)  of
               CanSort(P+(i<j),d-1) AND CanSort(P+(j<i),d-1)
```

`S(n) <= k` iff `CanSort(empty,k)`. This is kernel-checked equal to `S n`
(`S_eq_adv_univ`, A24) — `docs/problem.md`, `docs/research-budgeted-dfs.md` §1-3.
The OR is the sorter's pair choice; the AND is the adversary's worst answer.

## 2. Honest accounting of the budgeted DFS `[deduction]`

- Branching: at most `B = C(n,2)` incomparable pairs, two answers, so `<= 2B
  = n(n-1)` children per node.
- Depth: `d = k <= N`.
- Nodes: `<= (2B)^k = (n(n-1))^k = 2^{O(k log n)}`. Per-node work is `poly(n)`
  (closure, `is_total`, comparability).
- **Time** `2^{O(k log n)}·poly(n) = 2^{O(N log N)}` since `k,n <= N`.
- **Space** `O((k+n) log(n+2)) = O(N log N)` bits (transcript + one
  reachability workspace; `docs/research-budgeted-dfs.md` §5.2-5.3).

The `log N` factor comes from branching over `Theta(n^2)` pairs (`2 log n`
bits/level) over depth up to `k = Theta(N)` near the hard threshold.

## 3. The DFS is selective — it does NOT enumerate all winning states `[deduction]`

The DFS backtracks and short-circuits (OR returns on the first winning pair;
AND skips the second child when the first fails). It explores a `2^{o(n^2)}`
subset of the `2^{Theta(n^2)}` posets (`docs/research-budgeted-dfs.md` §13) and
keeps no memoization table. **PR32** (`docs/research-winning-frontier-barrier.md`)
excludes only algorithms that *output all* reachable winning states; it
therefore does **not** apply to this DFS. Verified the DFS reproduces `S(0..5)`.

## 4. Blockers for each listed 2^{O(N)} method `[deduction]`+`[experiment]`+`[literature]`

Take the information-tight threshold `k0 = ceil(log2(n!))`, where the answer is
NO for most `n` (`S(n) > k0`). Counts below are measured in `N = n+k+1 = Theta(n
log n)` there.

1. **Isomorphism coarsening / canonical generation.** Nonisomorphic posets on
   `n` points number `2^{n^2/4 + o(n^2)}` (Kleitman–Rothschild). Verified
   A001112: `log2` is `0.72–0.85 × n^2/4` for `n ≤ 12`. Any method enumerating
   canonical classes needs `2^{Theta(n^2)} = 2^{Theta(N^2)} = 2^{omega(N)}`.
   Symmetry collapses all `C(n,2)` pairs to **1 orbit** at the root (verified
   for `n ≤ 10`), but posets become rigid deep in the tree, so the asymptotic
   branching is unchanged. No `2^{O(N)}`.

2. **Winning-state enumeration.** PR32: at `k0` there are
   `2^{(1/4-o(1)) n log^2 n}` nonisomorphic reachable winning states; exact
   witnesses `2^39` at `n=224`, `2^148` at `n=256` (tests pass). Enumeration is
   `2^{Omega(n log^2 n)} = 2^{Omega(N log^2 N)}`. No `2^{O(N)}` (not even
   `2^{O(N log N)}`).

3. **Information / leaf-count pruning.** At `k0` the root has `n! <= 2^k`
   linear extensions, so the information bound is exactly tight and prunes
   nothing; barrier states have `<= 2^{k-t}` extensions and also survive. Leaf
   counting cannot collapse the threshold.

4. **Bidirectional coverage.** The meeting frontier has
   `2^{Omega(n log^2 n)}` states (PR32). `[literature]` For *selection*,
   Dörrer–Gendle–Betz–von Smercek–Steding (SEA 2025) note classical
   meet-in-the-middle fails: at any meeting point one side already covers
   `>99%` of its space. No `2^{O(N)}`.

5. **Concise certificate search.** No short NO-certificate is known.
   `[literature]` Cremer 2026 (arXiv:2610.18740, *selection*): proof-number
   search was decisive for finding a budget (`YES`) but "refuting a comparison
   budget remained substantially more expensive"; a leaf-count-only lower bound
   cannot even establish `V_8(16) >= 29`. The NO case is the expensive side.

## 5. YES/NO asymmetry `[deduction]`+`[literature]`

- **Trivial YES:** `k >= U(n) = O(n log n)` (merge-sort theorem) accepts in
  `O(N)` — no search.
- **Hard YES** (`S(n) <= k < U(n)`) and **NO** (`k < S(n)`): the DFS is
  `2^{O(N log N)}`; no `2^{O(N)}` is known. The NO case must examine *all*
  `Theta(n^2)` pairs at the root (one refuting answer each) and recurse; this
  `n^2` branching over depth `Theta(N)` is exactly where the `log N` enters.
- `[literature]` Stober–Weiß 2023 (ALENEX, arXiv:2206.05597) compute
  `S(16)=46,S(17)=50,S(18)=54` by exhaustive search with a *bidirectional*
  idea — confirming exact `S(n)` needs search and that bidirectional is the
  known lever, yet still exponential for `n` up to 18.

## 6. Conclusion `[open]`

The honest uniform bound stays `2^{O(N log N)}` time / `O(N log N)` space. The
listed exact methods cannot reach `2^{O(N)}`: coarsening is `2^{Theta(n^2)}`,
enumeration is `2^{Omega(n log^2 n)}`, leaf-counting is vacuous at the tight
threshold, and bidirectional/certificate search hit the same frontier or are
NO-expensive. The **budget-refutation (NO) case is the precise obstruction**;
a `2^{O(N)}` evaluator needs a genuinely new selective principle (strong
proof-number/disproof-number bounds or an algebraic recurrence), not currently
available. No improved bound is claimed beyond the established `2^{O(N log N)}`.
