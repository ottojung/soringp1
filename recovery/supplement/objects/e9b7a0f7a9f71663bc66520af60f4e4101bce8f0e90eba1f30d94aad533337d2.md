# A large winning frontier survives exact information pruning

**Status:** paper-level theorem, independently auditable; not Lean checked.
**Target:** the exact comparison-sorting minimax cost `F(P)`, and the special input `S(n)=F(A_n)`.
**Encoding:** all asymptotics measure the *numeric* number of keys `n`, not the length of its binary encoding.

## Statement

**Theorem (winning-frontier counting obstruction).** There are constants `c>0` and `n_0` such that for every `n=2^(2r)>=n_0`, if `k=ceil(log2(n!))`, then for some integer `t<=k` there are at least

```
2^(c * n * (log2 n)^2)
```

pairwise **nonisomorphic** `n`-element posets `P` satisfying BOTH:

1. `P` is reachable from the `n`-element antichain by exactly `t` legal comparison outcomes;
2. `F(P)<=k-t`: the sorter can finish in the remaining budget, not merely pass the information bound.

Thus enumerating *all* reachable winning posets at a certain depth, even modulo relabelling and even after exact extension-count pruning, takes `2^(Omega(n log^2 n))` output time on infinitely many `n`.

This is **not** a time lower bound for computing `S(n)`: an algorithm may avoid enumerating these states. In particular `k` is just the information lower bound, and the antichain root may itself be losing at this budget.

## 1. Fixed graph skeleton

Fix an integer `r>=2`, set `s=2^r` and `n=s^2`. Partition the labels into `s` consecutive levels

```
L_0, L_1, ..., L_(s-1),    L_i = { (i,x) : x in Z/sZ }.
```

Between every adjacent level `i,i+1`, include the two edges

```
(i,x) < (i+1, 2x mod s),
(i,x) < (i+1, (2x+1) mod s)
```

for each `x`. There are exactly `2s(s-1)<2n` fixed edges.

**Reachability lemma.** After exactly `d` levels, the destinations from `(i,x)` have the form

```
(i+d, (2^d*x+b) mod s),    b=0,...,2^d-1.
```

The binary choices determine `b`. If `d>=r=log2 s`, the residues cover all of `Z/sZ`. Consequently, **every vertex of level `i` precedes every vertex of level `j` when `j-i>=r`** (for existing levels).

All edges increase the level by exactly one. Hence an unselected adjacent-level relation cannot be implied by another path: a path from level `i` to `i+1` must consist of exactly that edge.

## 2. Many independent choices

The adjacent-level pairs not in the skeleton number

```
M=(s-1)*(s^2-2s) = s*(s-1)*(s-2) = Theta(n^(3/2)).
```

Let `m=(r/2)*n=(n/4)*log2 n` (an integer) and choose **any** subset `A` of exactly `m` of these `M` pairs. Append them as additional forward edges to form the poset `P_A`.

Each skeleton edge and each chosen additional edge can be added in arbitrary order as a legal comparison outcome starting at the antichain: edges always go forward between adjacent levels; their endpoints were incomparable before that particular edge was added. Each history has exactly

```
t=2s(s-1)+m = (n/4)*log2 n + O(n)
```

comparisons. Distinct subsets `A` yield distinct labelled posets because comparability between adjacent levels is **exactly** the chosen edge set.

In particular there are `binom(M,m)` distinct *labelled* reachable states at this same depth.

## 3. Every constructed state is actually winning

The fixed skeleton, unaffected by adding relations, makes vertices in levels separated by at least `r` comparable. An antichain can therefore occupy **at most `r` consecutive levels**, so the width `w(P_A)` is at most `rs`.

By Dilworth's theorem, `P_A` admits a partition into `w<=rs` chains, computable from its known partial order. Each chain is already internally sorted. A tournament tree merges the `w` sorted chains using at most `w-1` initial comparisons and at most `ceil(log2 w)` comparisons after each of the first `n-1` outputs: update the selected chain's next head along its winner-tree path (empty chains have sentinel infinity).

This gives the **constructive** bound

```
F(P_A) <= (w-1) + (n-1)*ceil(log2 w)
       <= rs + n*(r+ceil(log2 r)).
```

The right side is `n*(r+O(log r))`.

Meanwhile the classical factorial lower bound `n! >= (n/e)^n` gives

```
k = ceil(log2(n!)) >= n*(2r-log2(e)).
```

Therefore the remaining budget satisfies

```
k-t >= n*( (3/2)*r - 2 - log2(e) ).
```

For all sufficiently large `r`, `(3/2)r-O(1) > r+O(log r)`, so `F(P_A)<=k-t`. In particular **these are all winning states**, and automatically `e(P_A)<=2^(k-t)`; the ordinary *exact* linear-extension information cutoff cannot discard them.

The bound is about comparison count, not preprocessing time for the already-known poset. Width and a chain partition are computable in polynomial time; the tournament updates use pairwise key comparisons.

## 4. Counting isomorphism classes

For sufficiently large `r`, `m<=M`, and

```
binom(M,m) >= (M/m)^m.
```

Since `s>=4` implies `M>=s^3/4` and `m=rs^2/2`, we have `M/m>=s/(2r)`. Thus

```
log2 binom(M,m)
  >= (rn/2)*(r-1-log2 r)
  = (1/2)*n*r^2 - O(n*r*log r).
```

Every isomorphism class on `n` labelled vertices has at most `n!<=n^n=2^(2rn)` distinct labellings. Consequently,

```
log2(number of isomorphism classes)
  >= log2 binom(M,m) - log2(n!)
  >= (1/2)*n*r^2 - O(n*r*log r)
  = Omega(n*(log2 n)^2).
```

This proves the theorem.

## 5. Exactly what is (and is not) excluded

* **Excluded:** A proposed uniform `2^(O(n log n))` algorithm that must explicitly materialize **every** reachable winning poset at every relevant budget layer, even when states are merged by isomorphism. There are too many states to output.
* **Not excluded:** A selective forward or backward search, symbolic descriptions, a proof calculus, algebraic compression stronger than isomorphism, or any algorithm evaluating the initial antichain without listing the whole winning frontier.
* **Not claimed:** NP-hardness, PSPACE-hardness, a P-vs-NP separation, or an unconditional time lower bound for `SORT-BOUND` or `S(n)`. Also, no small-`n` experiment can establish the asymptotic counting theorem.

The construction directly addresses the question left by `docs/research-budgeted-dfs.md` and the October 19 steering discussion: large *raw* reachable frontiers can be ruled out by information pruning for naive height-two families, but a more structured high-height family retains a comparably large *genuinely winning* frontier. An asymptotic time improvement must exploit selectivity or structure beyond exhaustive isomorphism-quotient enumeration.
