# Descriptive complexity of the unary threshold language SORT-BOUND-U

**Status (2026-10-19, phoebe-dev).** Research note / paper analysis. It is
**not** Lean-checked. Every item is labelled `[definition]`, `[literature]`,
`[deduction]`, `[conjecture]`, `[experiment]` or `[open]`. **No lower bound,
no hardness, no separation, and no new complexity-class membership is
claimed.** The result is a faithful descriptive-complexity *translation* of
already-known upper bounds, plus a precise statement of what the natural
minimax recurrence is (and is not) in fixed-point logic. Scope is deliberately
limited to the **unary** language; the binary encoding is untouched.

---

## 0. Precise proposition / question

`[definition]` From `docs/problem.md`:

- `SORT-BOUND-U = { 1^n # 1^k : S(n) ≤ k }`, both parameters unary; input
  length `m = n + k + 1`.
- `S(n)` = minimum height of a deterministic adaptive comparison decision tree
  sorting `n` distinct labelled keys; equivalently `S(n) = adv univ`
  (kernel-checked, A24, `S_eq_adv_univ`).

The question of this note:

> **Q.** What is the faithful *ordered finite-word-structure* fixed-point
> definition of `SORT-BOUND-U`? In particular, is the natural comparison-game
> minimax recurrence an `FO(PFP)` (first-order partial-fixed-point) object, or
> a genuinely *second-order* fixed point? And which capture theorem supplies
> the strongest correct upper bound?

**Answers (summary).**

1. `[deduction]` The natural minimax "winning-region" recurrence is a
   **least fixed point over a set of posets**, i.e. a *second-order* fixed
   point. Its faithful logic shape is `SO(LFP)`, giving the **EXPTIME** upper
   bound — the "easy" bound corresponding to materialising the exponential
   state space.
2. `[deduction]` The **PSPACE** upper bound is *not* obtained from that
   recurrence. It comes from the **succinct-game / single-play** view: one
   configuration of a polynomial-space game solver is a first-order object
   (a fixed-arity relation), so the solver is an `FO(PFP)` object. This is the
   strongest correct descriptive bound for `SORT-BOUND-U`.
3. `[literature]` The capture theorems used are Immerman–Vardi
   (`FO(LFP) = P` on ordered structures), Abiteboul–Vianu
   (`FO(PFP) = PSPACE` on ordered structures), and Grädel/Immerman
   (`SO(LFP) = EXPTIME` on ordered structures).
4. `[deduction]` The `FO(PFP)` definition has **constant fixed-point
   arity/variable count**, independent of `n` and `k`; the transcript-only
   deterministic DFS of `docs/research-budgeted-dfs.md` (space
   `O(n log² n)` bits `⊆ DSPACE(n²)`) places it at **3 variables** by
   Immerman's variable–space correspondence `VAR[k+1] = DSPACE[n^k]`.
   Reducing to 2 variables would be *equivalent* to a linear-space algorithm
   (`VAR[2] = DSPACE[n]`) and is **open**.
5. `[deduction]` Why it matters for `S(n)`: the descriptive framing turns the
   `P`-question into an `FO(LFP)`-definability question and supplies an
   **unconditional space lower-bound target** (the PFP arity hierarchy), not
   blocked by Mahaney. See §7.

## 1. Ordered word structure and encodings

`[definition]` Fix the finite relational vocabulary
`σ = { <, P₁, P_# }` (`<` binary; `P₁`, `P_#` unary). A word
`w = w₀…w_{m−1} ∈ {1,#}*` yields the ordered finite structure

```
A_w = ( {0,…,m−1}, <, P₁, P_# ),   P₁(x) ⇔ w_x = 1,  P_#(x) ⇔ w_x = #.
```

The structure is **ordered** (the word order is part of the structure), which
is exactly the hypothesis under which the capture theorems of §2 hold.

`[deduction]` The following are FO-definable in `A_w`:

- the delimiter `d = ιx P_#(x)` (when well-formed: exactly one `#`);
- the key set `Key(x) := x < d` (the `n` positions before `#`), inheriting the
  order, giving a canonical labelling `0,…,n−1` of the `n` keys;
- the budget `k = |{x : d < x}|`, represented as the subset
  `{x : d < x}` of the post-delimiter positions (unary `k`);
- the "first key", "next key", "last key" via `<`.

Well-formedness (one `#`, unary blocks) is FO-definable and does not change
any class below. **Keys are positions of `U`**, so a poset on the keys is a
binary relation on `U` — this is what makes the *single* state first-order.

`[deduction]` The game / minimax semantics (fixed in the repo). For a
transitively closed strict partial order `P` on the keys,

```
F(P) = 0                                        if P is total,
F(P) = 1 + min_{(x,y) incomparable in P} max( F(P+xy), F(P+yx) )   otherwise,
```

`S(n) = F(∅)`; and `S(n) ≤ k` iff the sorter wins the game `G(n,k)` (sorter
chooses an incomparable pair, adversary answers, total order must be reached
within `k` moves) — `[deduction]`, matching `docs/research-certificates-barriers.md` §0 and
the kernel-checked `S_eq_adv_univ`.

`[deduction]` Unary horizon: for informative inputs `k = O(n log n)`, so
`m = Θ(n log n)`; the threshold language is **sparse** (`O(m²)` strings of
length `≤ m`).

## 2. Capture theorems used (primary sources)

`[literature]` All statements are on **finite ordered** structures
(`docs/problem.md` requires the encoding be stated; the word order is the
order used).

| Logic | Captures (ordered finite structures) | Primary source |
|---|---|---|
| `FO(LFP)` | `P` | N. Immerman, *Relational queries computable in polynomial time*, Inform. and Control **68**(1–3) (1986) 86–104; M. Y. Vardi, *The complexity of relational query languages*, STOC 1982, 137–146 |
| `FO(PFP)` | `PSPACE` | S. Abiteboul, V. Vianu, *Datalog extensions for database queries and updates*, J. Comput. System Sci. **43**(1) (1991) 62–124 (Abiteboul–Vianu/Vardi); see also Ebbinghaus–Flum, *Finite Model Theory*, ch. 7 |
| `SO(LFP)` | `EXPTIME` | E. Grädel, *Capturing complexity classes by fragments of second-order logic*, Theoret. Comput. Sci. **101**(1) (1992) 35–57; N. Immerman, *Languages that capture complexity classes*, SIAM J. Comput. **16**(4) (1987) 760–778; N. Immerman, *Descriptive Complexity*, Springer 1999 (chart `EXPTIME = SO(LFP) = SO[2^{n^{O(1)}}]`) |
| `SO` (∃SO) | `NP` | R. Fagin, *Generalized first-order spectra and polynomial-time recognizable sets*, in *Complexity of Computation*, SIAM–AMS Proc. 7 (1974) 43–73 |

`[literature]` **Variable/arity–space correspondence.** Immerman's chart gives
`VAR[k+1] = DSPACE[n^k]` (queries expressible by a quantifier block iterated
exponentially — the fixed-point/iteration form — using `k+1` domain
variables). The PFP **arity hierarchy** is strict: `PFP_k` (fixed-point
operators of arity `≤ k`) strictly exceeds `PFP_{k−1}` for every `k`
(M. Grohe, *Bounded-arity hierarchies in fixed-point logics*, CSL 1994;
M. Grohe, *Arity hierarchies*, Ann. Pure Appl. Logic **82**(2) (1996) 103–163;
posed by Chandra–Harel 1982). Hence the *arity* of the fixed point is tied to
the space degree.

`[deduction]` Model-fidelity caveat: `FO(PFP)` defines **boolean queries**
(languages), not numeric functions. The correct object is the threshold
language `SORT-BOUND-U`; the function `S_unary ∈ FPSPACE` follows by binary
search on `k` over the `O(n log n)`-wide window (`docs/problem.md`).

## 3. The two fixed points

### 3.1 The natural recurrence is second-order (`SO(LFP)`, `EXPTIME`)

`[deduction]` Let `B = { P ⊆ Key×Key : P is a strict partial order }` be the
set of poset states. Define the operator `Φ` on subsets `X ⊆ B`:

```
Φ(X) = { P ∈ B : Tot(P) }
     ∪ { P ∈ B : ∃ x,y ∈ Key, Inc_P(x,y) and (P+xy) ∈ X and (P+yx) ∈ X }.
```

- `Φ` is **monotone** (`X ⊆ X' ⇒ Φ(X) ⊆ Φ(X')`), so its least fixed point
  `W = lfp(Φ)` exists and is the winning region; `X_i = {P : F(P) ≤ i}` and
  `W = X_{n(n−1)/2}`.
- `S(n) ≤ k` iff `∅ ∈ X_k ⊆ W`.

`[deduction]` **Claim.** This recurrence is a **second-order** fixed point.
`X` ranges over a set of *relations* (posets), not over a relation on `U`.
A first-order fixed-point variable is a relation on `U`; a set of posets is a
third-order object relative to `U` and is not a fixed-arity relation on `U`
(a set of binary relations on `n` keys needs `2^{Θ(n²)}` bits, whereas a
fixed-arity relation on `U` holds `m^{O(1)}` bits). Hence the natural
recurrence cannot be written as an `FO(LFP)`/`FO(PFP)` fixed point with a
first-order variable; its faithful shape is `SO(LFP)` (`LFP` over a
second-order variable), equivalently `FO(LFP)` read over the *expanded*
universe of assignments of a second-order block (Immerman's `SO[·]`; the
"universe = block assignments" view). By §2, `SO(LFP) = EXPTIME`.

`[deduction]` **Evaluation.** One step `Φ(X_i) → X_{i+1}` examines all
`|B| = 2^{Θ(n²)}` posets, so materialising the winning region is `2^{O(n²)}`
time and `2^{O(n²)}` space in numeric `n`; for unary `m = Θ(n)` this is
`EXPTIME`. This reproduces, in logic, the naive memoised DP of
`docs/upper-bound.md` / `docs/research-encoding-consequences.md`.

**Conclusion.** The minimax recurrence is a first-order least fixed point
*over the exponentially expanded state space*. It yields `EXPTIME`, and it is
**not** the route to `PSPACE`.

`[experiment]` Falsification check of §3.1 (`/tmp/opencode/desc_falsify.py`,
self-contained; posets as transitive-closure successor bitmasks, exact
memoised `F`). The iterative operator `X_{i+1} = Φ(X_i)` from `X_0 = {totals}`
was run to closure and compared with `{P : F(P) ≤ n(n−1)/2}`:

```
 n   |B| (labelled posets)   S(n)   max F   LFP steps   |W|    log2|W|
 2                3            1       1         1         3       1
 3               19            3       3         3        19       4
 4              219            5       5         5       219       7
```

The LFP closes in exactly `max F = S(n)` steps and agrees with the
`F`-defined region. Because `F(P) ≤ S(n)` for **every** poset (`docs/research-hardness-boundaries.md`
Fact 0.1), the budget-`S(n)` winning region is the **entire** poset set `B`,
whose size is `A001035(n) = 2^{Θ(n²)}` — confirming that `W` is not a
fixed-arity relation on `U` and that §3.1's second-order claim is the right
shape. (This is a check of the recurrence/iteration bookkeeping, not a
complexity claim.)

### 3.2 The succinct-game view is first-order (`FO(PFP)`, `PSPACE`)

`[deduction]` A **single play / solver configuration** *is* a first-order
object: it is a polynomial-size stack of posets, encodable as a fixed-arity
relation on `U`. The state *set* `B` is exponential, but `FO(PFP)` never
stores it: its fixed-point variable encodes **one** configuration, and the
iteration walks the machine's configurations (up to `2^{m^r}` steps for arity
`r`).

`[deduction]` `SORT-BOUND-U ∈ PSPACE` by the game/ATM (`Claim A` of
`docs/research-certificates-barriers.md`) and, more concretely, by the
deterministic transcript-only budgeted DFS of `docs/research-budgeted-dfs.md`
§5.2: time `2^{O(n log² n)}`, work space `O((d+n) log(n+2))` bits with
`d ≤ U(n) = O(n log n)`, i.e. `O(n log² n)` bits. By `FO(PFP) = PSPACE`
(§2), `SORT-BOUND-U` is `FO(PFP)`-definable on the ordered structures `A_w`.

`[deduction]` **Why this is not visible from the recurrence.** The game
`G(n,k)` is a *succinctly presented* reachability game: states are posets
(exponentially many) and moves are FO-definable. The recurrence solves it by
unfolding the whole arena (exponential); the `FO(PFP)` definition solves it by
simulating one polynomial-space play/solver. This is precisely the
succinct-game phenomenon that separates the two fixed-point shapes.

## 4. Explicit constructions

### 4.1 Explicit `SO(LFP)` formula (natural; `EXPTIME`)

`[deduction]` Over `A_w`, with a second-order variable `X` (a set of posets)
and FO-definable `Tot`, `Inc`, and the map `(P,x,y,o) ↦ P+o` (transitive
closure), the following is a well-formed `SO(LFP)` sentence:

```
ψ := [ LFP_{X,P}  Tot(P)
                 ∨ ( Inc_P(x,y) ∧ X(P+xy) ∧ X(P+yx) ) ](∅)
```

read with `P` ranging over poset states (elements of the expanded universe),
`x,y` first-order over keys, and `X(P+o)` the second-order membership atom.
`ψ` holds iff `∅ ∈ W`, i.e. iff `S(n) ≤ k`. This is the exact
minimax recurrence written as a fixed point; it is *explicit* and *natural*,
and it is `SO(LFP)` (hence `EXPTIME`).

### 4.2 Explicit `FO(PFP)` formula (machine simulation; `PSPACE`)

`[deduction]` Let `M` be the deterministic transcript-only DFS
(`docs/research-budgeted-dfs.md` §5.2): a decider for `SORT-BOUND-U` running
in space `s(m) = O(n log² n) = O(m log² m)` bits, `≤ m²` for every `m ≥ 2`
(verified numerically; `m² ≥ n log² n`). Encode a configuration of `M` as a
relation on `U`:

- the tape (stack of transcripts + one reachability workspace) is `≤ m²` bits,
  so a **binary** relation `C ⊆ U²` holds it (`C(i,j)` = tape cell `(i,j)`);
- the head position (`≤ m²`) and finite state are stored in `O(log m)` of the
  `m²` cells; no extra arity is needed.

Let `φ(C,C')` be the FO formula expressing `C' = Next_M(C)` (the transition
function is local; FO-definable), with `φ(C,C') := (C' = C)` on halting
configurations (stuttering). Then

```
χ := [ PFP_{C} φ ](accept-marker)
```

holds iff the iteration from the initial configuration converges to a halting
accepting configuration — exactly when `M` accepts `1^n#1^k`, i.e.
`S(n) ≤ k`. This is a single `FO(PFP)` sentence uniform in `n,k`.

`[deduction]` **Fixed arities.** The fixed-point variable is binary
(arity 2), and the total number of domain variables is a constant independent
of `n,k`. The matrix-per-frame DFS (space `O(n³ log n)`) would give arity 4;
the transcript-only DFS (`⊆ DSPACE(n²)`) gives **3 variables** by Immerman's
`VAR[k+1] = DSPACE[n^k]` (`VAR[3] = DSPACE[n²]`). The distinction
**arity of the fixed point** vs **number of variables** is the technical point
that `VAR` measures; both are `O(1)` here, which is what "constructible with
fixed arities" requires.

### 4.3 Existence vs explicit formula

`[deduction]`

- **Existence theorem.** `SORT-BOUND-U ∈ PSPACE` ⇒ (capture, `FO(PFP)=PSPACE`)
  *there exists* an `FO(PFP)` sentence defining it. The capture proof is a
  machine simulation, so the sentence is effectively obtainable — but as an
  abstract existence it says nothing about the formula's shape.
- **Explicit formula.** §4.2 supplies the shape: a binary fixed-point variable
  simulating the poly-space solver. This is the strongest explicit definition.
- **Natural-but-weaker formula.** §4.1 is the recurrence's own formula; it is
  `SO(LFP)` (`EXPTIME`), not `FO(PFP)`. It is explicit and natural, but it is
  the *easy* bound.

The gap between §4.1 and §4.2 is exactly the gap between *unfolding the arena*
and *solving one play*.

## 5. Falsification of naive formulas

`[deduction]` Each attempt below is a plausible but **false or unsupported**
route; none of them is a lower bound.

**F1. "The minimax recurrence is `FO(LFP)` (hence `P`)."** False as stated.
The LFP variable would have to hold a *set of posets*; a first-order
fixed-point variable is a relation on `U`. The recurrence is `SO(LFP)`
(§3.1), giving `EXPTIME`. (No lower bound: a *different* `FO(LFP)` formula is
not excluded.)

**F2. "A fixed quantifier-depth FO formula decides `S(n) ≤ k`."** False. The
game depth is `k`, unbounded in the input; the minimax needs `k` levels of
alternation. Concretely, one-ply / balanced-greedy rules are *not* exact
(`docs/research-one-ply-obstruction.md`; `S(12) = 30 > ⌈log₂ 12!⌉ = 29`).

**F3. "`SO(LFP)` gives the strongest bound."** False. `SO(LFP) = EXPTIME`
and `FO(PFP) = PSPACE`; if `SO(LFP)` captured no more than `PSPACE`, then
`EXPTIME = PSPACE`, a major collapse. The `SO(LFP)` formula is the *weaker*
bound; `FO(PFP)` is the strongest.

**F4. "A fixed-arity second-order quantifier can guess the optimal tree
(hence `SO`/`NP`)."** False. A reduced optimal tree has `n! = 2^{Θ(n log n)}`
leaves; indexing it needs `Θ(n log n)` bits, i.e. a relation of arity
`Θ(n)` — **not fixed**. Hence `SO(LFP)`-definability must go through the
fixed-point mechanism (§4.1), never a direct guess of the tree
(`docs/research-strategy-certificates.md` Thm 5.2).

**F5. "The word order is cosmetic."** False. `FO(LFP) = P` and
`FO(PFP) = PSPACE` hold only on **ordered** structures; over unordered
structures `FO(LFP) = P` is open. The order on `A_w` is essential and must be
part of the encoding.

**F6. "`S(n)` itself is `FO(PFP)`-definable."** Category error. `FO(PFP)`
defines boolean queries; the correct object is `SORT-BOUND-U` (§2,
model-fidelity caveat).

**F7. "A unary (arity-1) fixed point suffices."** Not for the constructions
here: the transcript DFS tape `O(n log² n) > m`, so a unary relation (`m`
bits) cannot hold it; the matrix DFS needs even more. Whether *some* arity-1
definition exists is **equivalent** to a linear-space algorithm
(`VAR[2] = DSPACE[n]`) and is `[open]` — the `O(n log² n)` algorithm does not
settle it. This is a falsification of the naive claim, honestly labelled open,
not a lower bound.

## 6. What is actually established

`[deduction]` / `[literature]`:

- `SORT-BOUND-U ∈ FO(PFP)` over the ordered word structures `A_w`, with an
  explicit binary-fixed-point machine-simulation translation and `O(1)`
  variables (`PSPACE`).
- `SORT-BOUND-U ∈ SO(LFP)` via the *natural* winning-region recurrence
  (`EXPTIME`); the natural recurrence is **not** `FO(PFP)`.
- `SORT-BOUND-U ∈ DSPACE(O(n log² n))` deterministically
  (`docs/research-budgeted-dfs.md`), hence `∈ FO(PFP)` with `3` variables by
  `VAR[k+1] = DSPACE[n^k]`.
- The `FO(LFP)`-definability of `SORT-BOUND-U` is equivalent to
  `SORT-BOUND-U ∈ P`; the naive LFP route fails (F1), but no non-definability
  is proved.

`[open]` **Not established:** any non-definability / lower bound;
`SORT-BOUND-U ∈ FO(LFP)` (⇔ `∈ P`); `SORT-BOUND-U ∈ NP`/`coNP`;
minimality of arity 3; any hardness.

## 7. How this could change the uniform complexity of `S(n)`

`[deduction]` / `[conjecture]` The translation is not itself a new bound; its
value is that it converts the classification into *definability* questions
with new targets:

1. **`P`-membership ⇔ `FO(LFP)`-definability (Immerman–Vardi).** A proof that
   `SORT-BOUND-U` is `FO(LFP)`-definable would be a polynomial-time algorithm;
   conversely, a *pebble-game* argument (Ehrenfeucht–Fraïssé invariance for
   fixed-point logic, Dawar–Lindell–Weinstein) showing non-definability would
   give `SORT-BOUND-U ∉ P` — an unconditional lower bound that Mahaney does
   **not** block (Mahaney concerns sparse NP-hardness, not `P`-membership).
   This is a genuinely different attack surface from the poset-search front.
2. **The arity hierarchy is an unconditional space lower-bound target.**
   `VAR[2] = DSPACE[n]`, `VAR[3] = DSPACE[n²]`, and the `PFP` arity hierarchy
   is strict (Grohe). Current algorithms give space `O(n log² n)`
   (`∈ DSPACE(n²)`, `3` variables) but not `DSPACE(n)`. Proving
   `SORT-BOUND-U ∉ VAR[2]` would give an unconditional `ω(n)`-space lower
   bound; exhibiting an arity-2 (`VAR[2]`) definition would give a
   **linear-space** algorithm. Either is a real result, and neither is a
   time lower bound.
3. **Negative/conceptual.** The succinct-game phenomenon explains why the
   recurrence cannot be improved directly: any definition that "materialises
   the arena" is inherently exponential. A better upper bound must be a better
   *single-play* solver (smaller space / fewer variables), not a smaller DP.

`[conjecture]` The most likely route to progress is (2): the `PFP` arity/space
ladder gives a *non-relativising, unconditional* target, whereas (1) is
equivalent to `P` vs. the problem and is at least as hard as the original
question.

## 9. Status and next obstacle

**Status.** The translation is complete and faithful: the natural recurrence
is `SO(LFP)` (`EXPTIME`); the strongest bound is `FO(PFP)` (`PSPACE`) via the
succinct-game/single-play simulation, with constant fixed-point arity
(`≤ 3` variables by Immerman's `VAR` correspondence). The two are genuinely
different fixed-point shapes, and the difference is the succinct-game
phenomenon. No lower bound is claimed.

**Decisive next obstacle (one question).**

> Is `SORT-BOUND-U ∈ VAR[2] = DSPACE[n]` (linear space)? Equivalently, is
> there an arity-2 / 2-variable `FO(PFP)` definition, equivalently a
> linear-space algorithm?

- A **yes** gives a linear-space algorithm (improving `O(n log² n)`).
- A **no** gives an unconditional `ω(n)`-space lower bound (via the space
  hierarchy), with no Mahaney-style caveat.
- A concrete first move: an Ehrenfeucht–Fraïssé / `k`-pebble-game
  (`k = 2`) argument over the ordered word structures `A_w`, or a linear-space
  reformulation of the transcript DFS. Either outcome is decisive and small
  enough to attempt on paper before any code.
