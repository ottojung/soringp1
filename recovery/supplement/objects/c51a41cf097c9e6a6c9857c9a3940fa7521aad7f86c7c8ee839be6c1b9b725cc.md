# FO(LFP)-definability of the unary sorting threshold language SORT-BOUND-U

**Status:** research note (descriptive-complexity analysis; paper argument plus
literature). **Not Lean-checked.** No P/NP/EXPTIME/PSPACE separation is claimed.
The descriptive-complexity question is *reduced* to the open P-membership
problem, not resolved. Every item is labelled `[definition]`, `[deduction]`,
`[literature]`, `[experiment]`, `[conjecture]` or `[open]`. No new code, no PR.

This note responds to a unary-only packet: *construct a single fixed FO(LFP)
sentence defining `SORT-BOUND-U`, or prove it is not FO(LFP)-definable.*

---

## 0. Model, encoding, and the fixed question

`[definition]` From `docs/problem.md`:

- `S(n)` = minimum height (worst-case number of pairwise comparisons) of a
  **deterministic adaptive comparison decision tree** that correctly sorts every
  permutation of `n` distinct labelled keys.
- `SORT-BOUND-U = { 1^n # 1^k : S(n) ≤ k }` — both parameters **unary**.
- Input length `N = n + k + 1`.

`[definition]` **Word encoding.** Encode `w = 1^n # 1^k` as the ordered finite
structure

```
A_w = ( D_w , < , P_# ),   D_w = {0, 1, …, N-1},
```

where `<` is the natural order and `P_#` is the singleton predicate holding at
the `#` position. Equivalently, use one unary predicate per alphabet symbol. This
is the standard faithful encoding for ordered structures; `n` is the position of
`#` and `k = N - n - 1`.

`[literature]` **Capture theorems used throughout** (all on ordered finite
structures unless stated):

- **Immerman–Vardi:** `P = FO(LFP)` (Immerman 1986; Vardi 1982).
- **Immerman's lifting:** `EXPTIME = SO(LFP)`.
- **Abiteboul–Vianu:** `PSPACE = FO(PFP)`.

The model-checking direction (a fixed FO(LFP) sentence is decidable in P on
ordered structures) is the other half of Immerman–Vardi.

`[definition]` The packet asks for **one** parameter-free FO(LFP) sentence `φ`
with `SORT-BOUND-U = { w : A_w ⊨ φ }`, for **all** `n, k` simultaneously.

## 1. Exact equivalence: the descriptive-complexity reformulation

**Theorem 1 (equivalence).** `[deduction]` The following are equivalent:

1. `SORT-BOUND-U ∈ P`.
2. `S_unary ∈ FP` (the unary function problem).
3. There exists a single fixed FO(LFP) sentence `φ` over the ordered word
   vocabulary with `SORT-BOUND-U = { w : A_w ⊨ φ }`.

*Proof sketch.*

- **(1) ⟺ (2).** `docs/problem.md`, `docs/research-certificates-barriers.md`
  §0: `S_unary(1^n)` is computed by binary search on
  `k ∈ [0, n⌈log₂ n⌉]` against the merge-sort bound, using the threshold
  decider on inputs of length `n + k + 1 = O(n log n)`; `O(log n)` probes give
  `S_unary ∈ FP`. Conversely, given `1^n # 1^k`, compute `S(n)` and compare.
- **(3) ⟹ (1).** A fixed FO(LFP) sentence is decidable in P on ordered
  structures (Immerman–Vardi, model-checking direction). Hence its language is
  in P.
- **(1) ⟹ (3).** Immerman–Vardi gives a **uniform** translation from a
  polynomial-time machine to an FO(LFP) sentence; applying it to a machine for
  `SORT-BOUND-U` yields `φ`. ∎

**Corollary 2 (the packet, reformulated).** `[deduction]` The packet's two
deliverables are each equivalent to an open problem:

- Task (1) (construct a single FO(LFP) sentence) is **equivalent to proving
  `SORT-BOUND-U ∈ P`**, i.e. to a polynomial-time algorithm for `S(n)`. No such
  algorithm is known (`docs/research-certificates-barriers.md` §3: exact `S(n)`
  known only for `n ≤ 22`; no poly-time algorithm known; Stober–Weiß 2022 use
  exponential searches).
- Task (2) (prove non-definability) is **equivalent to proving
  `SORT-BOUND-U ∉ P`**, an unconditional lower bound. No such lower bound is
  known.

Thus the descriptive-complexity question is *exactly* the central open question
of this project, not a rephrasing that makes it easier. The equivalence is
semantic and exact: it is not relativizing, because it is a theorem, not a
heuristic.

## 2. Attempt (1): the natural formula is SO(LFP), not FO(LFP)

`[definition]` The natural object is the value function of the sorting game
`G(n,k)` of `docs/research-certificates-barriers.md` §0:

```
F(P) = 0                       if P is a total order,
F(P) = 1 + min_{x,y incomparable} max( F(P+xy), F(P+yx) )   otherwise.
```

`[deduction]` **Why FO(LFP) does not directly work.** `F` is a **minimax**:
the sorter existentially chooses a comparison, the adversary universally
chooses the answer. FO(LFP) has only **existential** least fixed points and no
universal quantification over relations; it cannot, in general, express the
adversary's universal choice. The two standard ways out are:

1. **Existentially quantify a strategy** `σ` (a second-order function from
   posets to comparisons) and use an LFP to verify that `σ` wins within `k`
   rounds. This is `SO(LFP)`: existential second-order + LFP.
2. **Materialize the game tree** by the recurrence of `docs/upper-bound.md`.
   The reachable states are all labelled posets (`2^{Θ(n²)}`, A001035), giving
   time `2^{O(n²)}` in numeric `n`, i.e. EXPTIME in `N`.

By Immerman's lifting, `SO(LFP) = EXPTIME`, so route 1 also lands in EXPTIME.
This is the sense in which "the natural recurrence is SO(LFP)".

`[deduction]` **The decision problem is in fact cheaper.** The ATM of
`docs/research-certificates-barriers.md` Claim A decides `G(n,k)` in time
`O(k·n²) = O(N³)` and space `O(n²) = O(N²)`, so

```
SORT-BOUND-U ∈ PSPACE,  and it is FO(PFP)-definable.
```

The EXPTIME bound is the cost of *materializing the recurrence*, not of
*deciding the game*. The gap that matters for the packet is therefore
**P vs PSPACE** (or, for the value function, **P vs EXPTIME**).

`[deduction]` **Where a construction would have to break.** To convert the
`SO(LFP)` formula to `FO(LFP)` one must eliminate the second-order strategy
quantifier. By Theorem 1 this is possible **iff** `SORT-BOUND-U ∈ P`. No
elimination is known, and no poly-time algorithm for `S(n)` is known. Hence the
construction of a single FO(LFP) sentence is not available. `[open]`

## 3. Attempt (2): the LFP pebble game is equivalent to the lower bound

`[literature]` The **LFP pebble game** (Ebbinghaus–Flum, *Finite Model Theory*,
ch. 7; McColm 1995) characterizes FO(LFP): for ordered structures,

```
A ≡_{FO(LFP)} B   ⇔   the duplicator wins the k-pebble LFP game for every k.
```

**Proposition 3.** `[deduction]` `SORT-BOUND-U` is not FO(LFP)-definable **iff**
the duplicator wins the LFP pebble game against every formula **iff**
`SORT-BOUND-U ∉ P`.

*Proof sketch.* By Theorem 1, non-definability is equivalent to `∉ P`; by the
pebble-game characterization, non-definability is equivalent to the duplicator
winning the game. ∎

**Corollary 4 (no EF shortcut).** `[deduction]` A pebble-game/Ehrenfeucht–
Fraïssé non-definability proof for `SORT-BOUND-U` would *itself* be a proof of
`SORT-BOUND-U ∉ P`. Winning the game is exactly as hard as the lower bound.

`[deduction]` **Why the naive EF intuition fails.** One might hope for two
words `1^n # 1^k ∈ L` and `1^{n'} # 1^{k'} ∉ L` that are FO(LFP)-equivalent.
By the characterization such a pair exists **iff** `SORT-BOUND-U ∉ P`. Since
that is open, no such pair is known. The parameters `n` and `k` are directly
readable in the structure (`n` is the position of `#`, `k = N - n - 1`), so the
game is not a purely structural indistinguishability argument; it is equivalent
to the arithmetic question of whether FO(LFP) can compute the predicate
`(n,k) ↦ [S(n) ≤ k]`.

(For plain FO such pairs *are* easy to build — §5 — which is why the FO game is
non-trivial. The FO(LFP) game, being a characterization of P, is not.)

**Supporting analogy.** `[literature]` Canavoi, Grädel, Lessenich, Pakusa,
*Defining Winning Strategies in Fixed-Point Logic* (LICS 2015): for finite
parity games, LFP-definability of winning *strategies* is equivalent to the
open question of whether parity games are in P, "despite the fact that LFP is,
in general, strictly weaker than polynomial time." The present situation is
the boolean analogue: FO(LFP)-definability of the *winning region* is
equivalent to P membership. This is further evidence that the logical question
inherits the full algorithmic difficulty.

## 4. Capture theorem vs explicit construction

`[literature]`/`[deduction]` The packet's warning is correct and is worth
stating precisely:

- **Immerman–Vardi is a semantic capture theorem.** It asserts the *class
  equality* `P = FO(LFP)`. It guarantees that **if** `SORT-BOUND-U ∈ P` then
  *some* FO(LFP) sentence defines it. It does **not** construct that sentence,
  and it says nothing when membership is open.
- The established `PSPACE` upper bound likewise guarantees the existence of an
  **FO(PFP)** sentence. But `FO(PFP) ≠ FO(LFP)` and `PSPACE ≠ P`; this is a
  *different logic and a different class*. It does not address task (1) or (2).
- Therefore the packet's requirement stands: a capture theorem is not a
  construction. One must either **exhibit the sentence** (which would prove P
  membership) or **prove impossibility** (which would prove a P lower bound).

## 5. A genuine (weak) partial result: SORT-BOUND-U is not FO-definable

`[deduction]` **Proposition 5.** `SORT-BOUND-U` is not definable in plain
first-order logic FO (no fixed-point operator).

*Proof sketch.* Let `φ` be any FO sentence of quantifier rank `q`. Put
`r = max(q, 3)` and consider

```
w  = 1^{r+1} # 1^{S(r+1)},        w' = 1^{r+2} # 1^{S(r+2)-1}.
```

Then `w ∈ L` (since `S(r+1) ≤ S(r+1)`) and `w' ∉ L` (since
`S(r+2) > S(r+2)-1`). For `r ≥ 3` we have `r+1, r+2, S(r+1), S(r+2)-1 > r`,
so the `r`-neighbourhoods of the start, the `#`, and the end agree in `w` and
`w'`; hence `w ≡_r w'` in the FO Ehrenfeucht–Fraïssé game. Since `q ≤ r`,
`φ` cannot separate `w` and `w'`. ∎

`[deduction]` This is a real theorem but **very weak**: FO is far below P, so
it does not bear on the P question. Its value is negative and clarifying: the
language is not "trivially" definable, and the obstruction is the computation
of `S(n)`, not the word structure. It also shows that any FO(LFP) definition
would have to use the fixed-point operator essentially.

`[open]` Stronger non-definability (e.g. `∉ FO+TC`, `∉ FO(PFP)`) would require
`∉ NL`, `∉ PSPACE`, etc., each of which is at least as hard as the
corresponding complexity-class separation.

## 6. Audit of the prior "SO(LFP), not FO(LFP)" claim

`[deduction]` The packet's premise contains one correct half and one overclaim:

- **Correct:** the natural minimax recurrence is `SO(LFP)`-definable, and
  `SO(LFP) = EXPTIME` on ordered structures. The decision problem is moreover
  in `PSPACE` (Claim A), so `FO(PFP)` suffices.
- **Not established:** "not FO(LFP)". By Theorem 1 this is equivalent to
  `SORT-BOUND-U ∉ P`, which is open. The claim should be read as
  "**no FO(LFP) definition is known**", not as a proved non-definability.

---

## 7. Exact result, next obstacle, sources

**Exact result.** `[deduction]` The question "Is `SORT-BOUND-U`
FO(LFP)-definable?" is **exactly equivalent** to "Is `SORT-BOUND-U ∈ P`?"
(equivalently, "Is `S_unary ∈ FP`?"). Consequently:

- Task (1) cannot be completed without a polynomial-time algorithm for `S(n)`;
  none is known.
- Task (2) cannot be completed without an unconditional lower bound against P;
  none is known.
- The natural recurrence is `SO(LFP)` (EXPTIME); the decision problem is
  `PSPACE` (`FO(PFP)`); the gap to `FO(LFP)` (P) is the open P-membership
  question.
- The LFP pebble game is a *characterization*, not a shortcut: winning it is
  equivalent to the lower bound.
- Genuine weak theorem: `SORT-BOUND-U` is not FO-definable.

**Next obstacle.** `[open]` The same obstruction as throughout this project:
the absence of a succinct certificate / compact canonical object for optimal
comparison play. Any FO(LFP) definition would yield a polynomial-size
certificate for `S(n) ≤ k` (since `P ⊆ NP`), and none is known
(`docs/research-certificates-barriers.md` §6, §8). The decisive next step is
not more logic but a compact object for optimal comparison play.
