# Partial-order quotient compression and `DSPACE(O(N))` for `SORT-BOUND-U`

**Status:** research note (2026-10-20). Deduction, counting and literature only.
Not Lean-checked. No complexity-class separation is claimed. The class counts are
reproduced by `scripts/state_compression.py` and
`scripts/benchmark_symmetry_quotients.py`; the transcript-entropy table is a
plain calculation.

## 0. Question and short answer

`SORT-BOUND-U = {1^n # 1^k : S(n) <= k}` with `N = n+k+1`. The transcript-only
budgeted DFS of `docs/research-budgeted-dfs.md` §5.3 decides it in
`DSPACE(O(N log N))`. The question investigated here is whether quotienting the
partial-order minimax state space by its known symmetries (relabelling `S_n`,
order duality `Z_2`, `Aut(P)` move orbits) can lower the work space to `O(N)`.

**Answer: no, not by this route.** The quotient is exact, but it removes only a
sub-exponential factor `2^{Theta(n log n)}` from the class count, which stays
`2^{Theta(n^2)}`; and a DFS that tracks the current class still stores
`Theta((k+n) log n)` bits. In the informative regime `k = Theta(n log n)` (forced,
since `S(n) = Theta(n log n)` by the information bound and merge sort), this is
`Theta(n log^2 n) = Theta(N log N)`. The log factor is not an artifact of the
transcript encoding: a transcript of `k` comparisons carries `k log(2B) =
2k log n` bits, and the quotient class is a function of the same transcript.

## 1. Baseline: the `O(N log N)` bound

`CanSort(P,d)` (the sorter/adversary game) is decided by a DFS whose state is the
transitive closure of the comparisons on the current root-to-node path. The
implementation (`docs/research-budgeted-dfs.md` §5.2, `scripts/transcript_dfs.py`)
stores one ordered pair per frame (`2 ceil(log2 n)` bits) plus a cursor, so the
stack costs `O(d log n)` bits at budget `d`; an on-demand reachability workspace
adds `O(n log n)`. Total `O((d+n) log(n+2))`. For the decision language,
`d = k <= N` and `n <= N`, giving `O(N log(N+2))`. The minimax recurrence is
kernel-checked (`adv univ`, A24); the DFS itself is a paper deduction, not a Lean
theorem.

## 2. The quotient-based algorithm

`F` descends to isomorphism classes under `S_n x Z_2` (relabelling and duality;
`docs/research-compression-next.md` Theorems 3, and §2). A quotient DFS stores
the class `[P]` instead of a labelled representative and recurses on

    G([P]) = 0                                  if P is total,
    G([P]) = 1 + min_{{x,y} incomparable} max( G([P+x<y]), G([P+y<x]) ).

The multiset of unordered successor-class pairs is class-independent (equivariance
of `extend`), so the recurrence is well defined on classes. To run it one needs
a representative of `[P]`: either a canonical form (an `n x n` closure matrix,
`Theta(n^2)` bits) or the generating relations of `P` (the added comparisons).

## 3. Space analysis

**Class count.** `A000112(n) = 2^{Theta(n^2)}` (Kleitman-Rothschild for labelled
posets; the unlabelled count has the same exponent). Measured `log2 A000112`:
`5.98, 8.31, 11.00, 14.05, 17.48` for `n = 5..9`. So a *generic* class needs
`Theta(n^2)` bits; `O(n)` bits is impossible on average by counting.

**Classes reachable within `k` comparisons.** Such a poset has at most `k`
generating relations, so it can be stored as an explicit set of `k` pairs:
`O(k log n)` bits. This is exactly the transcript representation, so the
quotient is no smaller. (A canonical form would be `Theta(n^2)` bits, worse.)

**Per level and total.** The DFS stores one class per frame. With the generating
relations this is `O(k log n)` total; with canonical forms it is `O(k n^2)`,
strictly worse. Adding the reachability workspace, the quotient DFS costs
`Theta((k+n) log n)`, the same as the transcript DFS. For `k = Theta(n log n)`:
`Theta(n log^2 n) = Theta(N log N)`.

**Move orbits.** Reducing the move set to one representative per `Aut(P)` orbit is
exact (Theorem 5 of `docs/research-compression-next.md`) but cuts transitions by
only about 30% at `n <= 6`; it does not touch the state representation.

## 4. Why `O(N)` fails for this route

At depth `d` the current state is determined by `d` comparisons, each an element
of a set of size `2B = n(n-1)`. Hence the transcript has entropy `d log(2B) =
2d log n` bits. Any DFS that maintains the current state must store enough to
reconstruct it, so it needs `Omega(d log n)` bits on instances where the states
are distinct. In the informative regime `d = k = Theta(n log n)`, this is
`Omega(n log^2 n) = Omega(N log N)`. Quotienting by `S_n x Z_2` cannot remove
this, because the class is a function of the same `k` moves and, for a generic
(trivial-automorphism) state, is represented by those `k` moves up to
relabelling — still `Theta(k log n)` bits. The entropy table confirms the order:
for `k ~ n log2 n`, the transcript entropy is `5.8 n log^2 n`, `7.9 n log^2 n`,
`10.0 n log^2 n`, `12.0 n log^2 n` at `n = 8, 16, 32, 64`.

## 5. Quotient constructions and their limits

| Construction | Sound for `F`? | Effect on state space | Space effect |
|---|---|---|---|
| relabelling `S_n` | yes | count `A001035 -> A000112`, factor `2^{Theta(n log n)}` | none asymptotically |
| duality `Z_2` | yes | factor `~2` | none |
| combined `S_n x Z_2` | yes | still `2^{Theta(n^2)}` classes | none |
| `Aut(P)` move orbits | yes | no class reduction; ~30% fewer moves | none |
| comparability graph | **no** (`n=7` value witness; `n=5` transition witness) | — | — |
| linear-extension count | **no** (`n=5` witness) | — | — |
| value `F(P)` | value-only; not a sound DP state | `O(n^2)` values | not computable from values alone |

No intermediate invariant between the comparability graph and the full poset is
known to determine `F` (`docs/research-compression-next.md` §6, §8).

## 6. Decision versus function

The decision only needs the boolean `CanSort(P,d)`, and `S(n) <= k` is a single
threshold. Two temptations do not help. (i) The *value* quotient has only
`O(n^2)` classes, but the recurrence `min` over moves cannot be evaluated from
successor values alone: the move set is part of the structure. (ii) The
information bound `ceil(log2 e(P)) <= F(P)` is a sound pruning rule, but it
neither shrinks the state representation nor bounds the DFS depth below `k` on
adversarial answers. The coarsest sound state quotient remains `S_n x Z_2`.

## 7. Conclusion and limitations

Partial-order quotient compression is exact and useful (it extends practical
exact computation from `n=7` to `n=9`), but it is **not asymptotic**: it changes
the state count by `2^{Theta(n log n)}` and the per-class representation not at
all. It therefore does not achieve `DSPACE(O(N))`; the quotient DFS stays at
`Theta(N log N)` in the informative regime, and an information-theoretic lower
bound on the DFS path shows the log factor is intrinsic to that approach.

This does not settle whether `SORT-BOUND-U in DSPACE(O(N))` holds by some
non-DFS algorithm; no such algorithm is known, and no unconditional lower bound
is claimed here. The decisive next question is whether a representation of the
current poset smaller than its generating relations — or a non-path-search
decision procedure — exists; the counting and entropy arguments above say that
no quotient of the poset by the known symmetries can supply it.
