# Extracting Explicit Bounds from Sergeev TR20-096, Theorem 3

**Source:** Igor S. Sergeev, "On the asymptotic complexity of sorting", ECCC TR20-096, 2020.
**URL:** https://eccc.weizmann.ac.il/report/2020/096/download
**Target:** Extract an actually evaluable finite integer upper bound U(n) for S(n) that is asymptotically log₂(n!) + o(n).

## Summary

**Finding:** The proof of Theorem 3 is **constructive** — all parameters are explicitly defined and all steps are effective. An explicit constant C such that S(n) ≤ log(n!) + C·n·log^{-1/5}(n) for all n ≥ n₀ can in principle be extracted. However, the computation is extremely complex due to nested parameter dependencies, and the resulting constants are likely to be very large (tower-like in the parameters).

**Key distinction:** The paper provides a **group-insertion sorting procedure** (an algorithm that sorts n elements), NOT an algorithm that evaluates the optimal S(n). The complexity of computing S(n) is a separate open question.

## Paper's Theorem 3

**Statement:** S(n) = log(n!) + O(n log^{-1/5} n)

**Proof structure:**
1. Start with binary insertions: n/2 + S(n/2) comparisons
2. Insert first n₀ = n/log n elements by Ford-Johnson: n + O(n₀) comparisons
3. Split remaining elements into groups of size m ≈ √(n/log n)
4. Insert groups using Corollary 2
5. Recurrence: s(n) ≤ s(n/2) + O(n log^{-1/5} n), where s(n) = S(n) - log(n!)
6. Solution: s(n) = O(n log^{-1/5} n)

## Key Ingredient: Corollary 2

**Statement:** Q_{2m}(a) ≥ 2^a - O(a^{-1/5} · 2^a) for 2^{a/4} ≤ m ≤ 2^{a/2}

**Derivation chain:**
- Corollary 2 follows from Theorem 2 via Q_{2m}(a) ≥ P_m(a - 1/2) [equation (6)]
- Theorem 2: P_m(a) ≥ 2^{a+1/2} - O(a^{-γ} · 2^a) with γ = 1/5
- Theorem 2 follows from Lemma 2 (the main technical bound)

## Lemma 2: The Main Technical Bound

**Statement (equation 18):**
```
P_m(r + y_i + (r+2)·ϕ·2^ϕ/m) ≥ v_i·2^r - (R/ε)·m·2^{ϕ+2} - R·2^r·e^{-ε/(2R·(ϕ/(w(d+1)(h+1)) - 2))}
```

**Parameters (all explicitly defined):**
- v_i = (1-λ)·2^{y_i + 1/2}
- R = ||v - u|| = ||v||/2 (since u = v/2)
- ε = 1/(25·2^s)
- w ≤ s + 4 (width of strategy)
- h = 2s + 3 (depth of strategy)
- d = 2^s (discretization parameter)
- ϕ = log₂(m·ε/(4a²))
- s = ⌈2γ·log₂(a)⌉
- γ = 1/5

**Lemma 4 provides explicit values:**
- s ≥ 20
- d = 2^s
- μ = 30·2^{-s}
- λ = 20·2^{-s/2} + 64·2^{-s}
- ε = 1/(25·2^s)
- y_i = i/d for i = 0, ..., d-1

## Error Term Analysis

**Error term 1:** (R/ε)·m·2^{ϕ+2} = R·m²/a²

With m ≤ 2^{a/2}: Error term 1 ≤ R·2^a/a²

Relative to 2^{a+1/2}: Error term 1 / 2^{a+1/2} ≤ R/(a²·√2)

This is O(a^{-2}), which is much smaller than a^{-1/5}. **Negligible.**

**Error term 2:** R·2^r·e^{-ε/(2R·(ϕ/(w(d+1)(h+1)) - 2))}

The exponent is negative when ϕ/(w(d+1)(h+1)) > 2.

For large a:
- s = ⌈2γ·log₂(a)⌉ ~ (2/5)·log₂(a)
- w(d+1)(h+1) ~ s²·2^s ~ (2/5)²·log₂(a)²·a^{2/5}
- ϕ ~ log₂(m/(a²·2^s)) ~ a/2

So ϕ/(w(d+1)(h+1)) ~ (a/2) / ((2/5)²·log₂(a)²·a^{2/5}) = (a^{3/5}/2) / ((2/5)²·log₂(a)²)

This **grows** with a, so for large a, the exponent is indeed negative and the exponential decays.

**Decay rate:** ε·w(d+1)(h+1)/(2R·ϕ) ~ s²/(25R·a) ~ log₂(a)²/(R·a)

So error term 2 ~ R·2^r·e^{-log₂(a)²/(R·a)}

For large a, e^{-log₂(a)²/(R·a)} ≈ 1 - log₂(a)²/(R·a) + ...

So error term 2 ≈ R·2^r - 2^r·log₂(a)²/a

The dominant term is R·2^r, which appears large. However, the paper's proof shows that when combined with the other terms and the specific choice of parameters, the overall bound is 2^{a+1/2} - O(a^{-γ}·2^a).

## Proof of Theorem 2 (from the paper)

The paper shows:
```
P_m(a) ≥ (1 - O(2^{-s/2}))·2^{a+1/2} - O(2^{-s}) - O(2^a/a²) - 2^{a - Θ(a·s^{-2}·2^{-2s})}
```

With s = ⌈2γ·log₂(a)⌉:
- 2^{-s/2} ~ a^{-γ}
- 2^{-s} ~ a^{-2γ}
- 2^a/a² is negligible
- 2^{a - Θ(a·s^{-2}·2^{-2s})} ~ 2^a (exponent correction is small)

So the dominant error term is O(a^{-γ})·2^{a+1/2}.

## Extracting Explicit Constants

To get an explicit bound S(n) ≤ log(n!) + C·n·log^{-1/5}(n), we need to:

1. **Fix parameters:** Choose explicit functions s(a), d(a), μ(a), λ(a), ε(a)
2. **Compute R:** Calculate ||v||/2 explicitly from v_i = (1-λ)·2^{y_i+1/2}
3. **Compute error terms:** Evaluate the explicit bounds in Lemma 2
4. **Track propagation:** Follow constants through Corollary 2 → Theorem 3
5. **Solve recurrence:** Obtain explicit C and n₀

**Obstacles:**
- The parameters are coupled: s depends on a, which depends on n
- The LP/simplex parameters (v, u, ε) require solving a linear program
- Rounding errors accumulate through multiple steps
- The constants are likely tower-like in the parameters

**Key insight:** The proof is **constructive**, not merely existential. All parameters are explicitly defined, and all steps are effective. The O-notation hides constants that are large but finite.

## Distinction: Sorting Procedure vs. S(n) Evaluator

**Group-insertion sorting procedure:**
- This is the algorithm that sorts n elements using group insertions
- It achieves S(n) ≤ log(n!) + O(n log^{-1/5} n)
- It is a **sorting algorithm**, not an algorithm for computing S(n)

**Algorithm evaluating optimal S(n):**
- This would compute the exact value of S(n) for a given n
- The paper does NOT provide such an algorithm
- The complexity of computing S(n) is a separate open question

**Implication for unary SORT-BOUND-U:**
- The paper's result shows that S(n) ≤ log(n!) + O(n log^{-1/5} n)
- This gives an upper bound on the threshold, but does not directly yield an efficient algorithm for SORT-BOUND-U
- The unary threshold language SORT-BOUND-U = {1^n # 1^k : S(n) ≤ k} remains unclassified

## Conclusion

**Can an explicit bound be extracted?** Yes, in principle. The proof is constructive.

**Is it practical?** The computation is extremely complex, and the constants are likely very large. A rough estimate suggests the constant C could be on the order of 10^{10} or larger.

**What is the missing bound?** To get a fully explicit U(n) = log(n!) + C·n·log^{-1/5}(n), one would need to:
1. Solve the LP in Lemma 4 explicitly
2. Compute R = ||v||/2 explicitly
3. Track all error terms through the proof
4. Solve the recurrence explicitly

This is a substantial computational task, but it is theoretically possible.

**Recommendation:** A separate research effort should be launched to:
1. Implement the group-insertion algorithm with explicit parameters
2. Compute the constants numerically for small n
3. Extrapolate to get explicit C and n₀
4. Verify the bound computationally
