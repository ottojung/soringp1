# DSPACE(O(N)) for SORT-BOUND-U: Independent Research Report

**Date:** 2026-10-20
**Agent:** Independent Phoebe-only unary SORT-BOUND-U research
**Status:** Paper analysis (not Lean-checked). No complexity-class separation claimed.

## 0. Question and Summary

**Question:** Can SORT-BOUND-U = {1^n # 1^k : S(n) ≤ k} be decided in DSPACE(O(N)) where N = n+k+1, via recomputation, Savitch-style implicit reachability, balanced recursion/strategy game, or partial-order quotient?

**Answer:** No known approach achieves O(N) space. The existing certified threshold DFS uses O(N log N) work-tape bits. Five independent investigation fronts converge on the conclusion that O(N) space is not achievable by any known technique, and a rigorously qualified information-state barrier applies to tree-exploration algorithms.

## 1. Audit of Previous Agent 510a18001478's False Lower Bound

### 1.1 The False Claim

The previous agent claimed an "Ω(d log n) lower bound" based on the existence of 2^{O(d log n)} reachable posets. This is **FALSE**.

### 1.2 Why It Is False

The claim conflates an **upper bound** on the number of nodes in one particular search tree with a **lower bound** on the memory any algorithm must use:

- **Premise:** The budgeted DFS visits at most (2B)^d = 2^{O(d log n)} nodes at depth d.
- **Error:** An upper bound on state count does not imply a lower bound on space complexity.
- **Reason:** An algorithm may recompute states, represent them compactly, avoid them entirely, or decide the one-bit question without enumeration.

### 1.3 What Would Be Needed

A valid space lower bound requires:
- Statement in the unary input length N = n+k+1
- Application to all machines in an explicit model
- An adversary, crossing-sequence, pebbling, or communication-complexity argument
- Not derived from the size of a search space

### 1.4 The Winning-Frontier Construction

The 2^{Ω(n log² n)} poset construction is a valid counting theorem but:
- Only applies for astronomically large n (n = 2^{2r} with r "sufficiently large")
- Counts states, not steps or bits
- Does not lower-bound time or space for the decision problem
- An algorithm need not enumerate winning states

## 2. Savitch-Style Implicit Reachability

### 2.1 Proposed Algorithm

Formulate as reachability in the poset transition DAG and apply Savitch's REACH algorithm:
- Nodes: posets reachable from the antichain within k comparisons
- Edges: P → P+(i<j) for each incomparable pair (i,j)
- Question: is there a path of length ≤ k from ∅ to a total order?

### 2.2 Space Analysis

- **Poset representation:** A poset reachable within k steps is determined by its transcript (sequence of comparisons). Each comparison requires O(log n) bits. Total: O(k log n) bits.
- **Recursion depth:** O(log k) for Savitch's algorithm.
- **Total space:** O(k log n · log k) = O(N log² N) for the threshold problem.

### 2.3 Why Savitch Fails Here

Savitch's theorem achieves DSPACE(log² M) for STCON because node names cost O(log M) bits. Here:
- The graph is implicit, not explicit
- Iterating over candidate intermediate posets requires generating them
- The recursion stores O(log k) configurations simultaneously
- Result: O(N log² N) — **worse than the existing budgeted DFS** (O(N log N)) by a log factor

### 2.4 Conclusion

Savitch-style implicit reachability does **not** achieve DSPACE(O(N)).

## 3. Recomputation-Based Approaches

### 3.1 Key Idea

Instead of storing intermediate results (memoization), recompute them as needed. This trades time for space.

### 3.2 Space Analysis

- Pure DFS without memoization needs O(depth × state_size) space
- Depth is at most S(n) = O(n log n)
- State size is O(n log n) bits for a poset
- Total: O(n log² n) bits

### 3.3 The Per-Frame Cursor Barrier

The per-frame cursor costs Ω(log n) bits and cannot be recomputed or compressed:
- It encodes failed-subtree history
- Checkpointing fails because transcripts are cumulative
- At hard instances k = Θ(n log n), this gives Ω(k log n) = Θ(N log N) = ω(N)

### 3.4 Conclusion

Recomputation does **not** achieve O(N) space. The log factor is intrinsic to backtracking.

## 4. Partial-Order Quotient Compression

### 4.1 Quotient Constructions

| Construction | Sound for F? | Effect | Space Effect |
|---|---|---|---|
| S_n (permutation symmetry) | yes | A001035→A000112, factor 2^{Θ(n log n)} | none asymptotically |
| Duality Z_2 | yes | factor ~2 | none |
| S_n × Z_2 | yes | still 2^{Θ(n²)} classes | none |
| Aut(P) move orbits | yes | ~30% fewer moves | none |
| Comparability graph | **no** (n=7 witness) | — | — |
| Linear-extension count | **no** (n=5 witness) | — | — |

### 4.2 Space Analysis

- **Class count:** A000112(n) = 2^{Θ(n²)}; a generic class needs Θ(n²) bits
- **Classes within k comparisons:** O(k log n) bits — same as transcript representation
- **Total:** Θ((k+n) log n), same as transcript DFS
- For k = Θ(n log n): Θ(n log² n) = Θ(N log N)

### 4.3 Conclusion

Quotient compression is exact and useful (extends exact computation n=7→9) but **not asymptotic**. It does not achieve DSPACE(O(N)).

## 5. Rigorously Qualified Information-State Barrier

### 5.1 The Barrier Statement

**Qualified Barrier:** Any exact algorithm for SORT-BOUND-U that:
1. Explores the game tree G(n,k), and
2. Represents state at a granularity finer than e(P), the comparability graph, and the degree sequence

must use Ω(n log n) bits of work space on NO instances with k = Θ(n log n).

### 5.2 Why This Is Rigorous

- **Information-theoretic counting:** Among 2^{Θ(n²)} labelled posets, the fraction representable in o(n²) bits is negligible.
- **Invariant-insufficiency witnesses:** No small sufficient statistic exists:
  - e(P) does not determine F (n=5 witness)
  - Comparability graph does not determine F (n=7 witness)
  - Degree sequence does not determine move values (n=6 witness)

### 5.3 Why This Is Qualified

The barrier applies to a **class** of algorithms (tree-exploration with sufficient state), not to all conceivable approaches. It does not rule out:
- A mathematical characterization of S(n) (e.g., closed form)
- A non-uniform advice table
- A fundamentally non-exploration algorithm

### 5.4 Implications

| Regime | Space Needed | Barrier Type |
|---|---|---|
| NO instances, tree exploration | Ω(n log n) = Ω(N) | adversary-forces-state-complexity |
| YES instances, explicit certificate | ≥ 2n! - 1 nodes | certificate-size |
| Any algorithm, state compression | Ω(n log n) bits | invariant-insufficiency |

The O(N) space question is **not ruled out**—the lower bound Ω(n log n) = Ω(N) is consistent with O(N) being achievable. The barrier shows that o(N) space is impossible for tree-exploration algorithms.

## 6. Summary of Findings

| Approach | Space Achieved | Status |
|---|---|---|
| Budgeted DFS (transcript) | O(N log N) | Existing certified algorithm |
| Savitch-style REACH | O(N log² N) | Worse than DFS by log factor |
| Recomputation | O(N log N) | Same as DFS, cursor barrier |
| Partial-order quotient | O(N log N) | No asymptotic improvement |
| **Lower bound (qualified)** | **Ω(N)** | For tree-exploration algorithms |

## 7. Open Problems

1. **Does a representation of the current poset smaller than its generating relations exist?**
2. **Does a non-path-search decision procedure for S(n) ≤ k exist?**
3. **Can the gap between Ω(N) and O(N log N) be closed?**

## 8. Conclusion

Five independent investigation fronts converge on the conclusion that **DSPACE(O(N)) is not achievable by any known technique** for SORT-BOUND-U. The existing transcript-based budgeted DFS is space-optimal up to log factors among algorithms that maintain explicit poset states. Achieving O(N) space would require a fundamentally different approach—either a compressed poset representation that defeats the information-theoretic lower bound, or a non-game-theoretic decision procedure for S(n) ≤ k.

The qualified information-state barrier establishes that **Ω(N) space is necessary for tree-exploration algorithms**, which is consistent with O(N) being achievable but does not prove it. The central open problem remains whether a fundamentally non-exploration algorithm exists.
