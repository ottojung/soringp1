# The exact sorting number is not k-regular in any base

**Status:** paper proof. No Lean. The proof uses one external analytic
theorem (Sergeev's comparison-sorting bound) and one transcendence fact
(Lindemann's theorem). It does not use any unproved exact value of `S(n)`.

## Result

Let `S(n)` be the minimum worst-case number of adaptive pairwise
comparisons needed to sort `n` distinct labelled keys, and let `k >= 2`
be an integer.

**Theorem.** `S` is not `k`-regular. Equivalently, the `k`-kernel of `S`
spans an infinite-dimensional `Q`-vector space.

This holds for every integer base `k >= 2`. Consequently there is no
finite linear representation

```
S(n) = u A_{n_0} ... A_{n_{d-1}} v
```

with fixed rational matrices indexed by base-`k` digits. In particular,
`S` cannot be evaluated on unary input by a fixed-size digit-DP matrix
product, so the proposed `O(n)` finite-dimensional linear evaluator for
`S_unary(1^n)` does not exist.

The obstruction is not growth, monotonicity, a finite prefix, or the
leading `n log_2 n` term: it is the exact second-order coefficient
`-n / ln 2` coming from Stirling's formula and Sergeev's bound.

## Definitions and standard facts

A sequence `f: N -> Q` is `k`-regular if the `Q`-vector space spanned by
the `k`-kernel

```
K_k(f) = { n |-> f(k^e n + r) : e >= 0, 0 <= r < k^e }
```

is finite-dimensional. Equivalently, `f` has a finite linear
representation as above.

**Fact 1 (kernel subsequences are linear recurrences).** If `f` is
`k`-regular, then for every fixed `r >= 0` the sequence

```
m |-> f(k^m + r)
```

satisfies a linear recurrence with constant rational coefficients. For
`r = 0` this is immediate from a linear representation: `k^m` has base-`k`
digits `1` followed by `m` zeros, so

```
f(k^m) = u A_1 A_0^m v      (or u A_0^m A_1 v, by convention),
```

a linear recurrence whose characteristic polynomial is that of `A_0`.
The same argument applies to `f(k^m + r)` after fixing the low digits
of `r`.

**Fact 2 (asymptotics of a convergent linear recurrence).** Let `(v_m)`
be a sequence over `Q` satisfying a linear recurrence with constant
coefficients. If `v_m = C m + D + o(1)`, then `C` and `D` are algebraic
numbers.

Indeed, write `v_m = sum_j P_j(m) alpha_j^m` with algebraic `alpha_j` and
polynomials `P_j` over the algebraic closure of `Q`. Since
`v_m = O(m)`, no `|alpha_j| > 1` occurs. If some `|alpha_j| = 1` with
`alpha_j != 1` occurred with nonzero `P_j`, then `v_m - C m` would retain
a nonconstant oscillatory component and could not converge; equivalently,
the rational generating function of `v_m - C m` would have a pole on the
unit circle other than `z = 1`. Hence only `alpha = 1` contributes, with
`P_1(m) = C m + D`, and `C, D` lie in the field generated by the
eigenvalues of a rational recurrence, hence are algebraic.

**Fact 3 (transcendence of `1 / ln 2`).** `ln 2` is transcendental by
Lindemann's theorem: if `ln 2` were a nonzero algebraic number, then
`e^{ln 2} = 2` would be transcendental. Therefore its reciprocal
`1 / ln 2` is transcendental as well (a nonzero algebraic reciprocal
would make `ln 2` algebraic).

## Proof

Sergeev's theorem gives the sorting upper bound

```
S(n) = log_2(n!) + O(n / (log n)^{1/5}).
```

The information lower bound gives `S(n) >= log_2(n!)`, so the equality is
two-sided. By Stirling,

```
log_2(n!) = n log_2 n - n / ln 2 + O(log n).
```

Therefore

```
S(n) = n log_2 n - n / ln 2 + o(n).
```

Assume for contradiction that `S` is `k`-regular. Put `n = k^m` and

```
v_m = S(k^m) / k^m.
```

By Fact 1, `v_m` satisfies a linear recurrence with constant rational
coefficients. By the asymptotic above,

```
v_m = m log_2 k - 1 / ln 2 + o(1).
```

Fact 2 now implies that `-1 / ln 2` is algebraic. This contradicts
Fact 3. Hence `S` is not `k`-regular. The argument is uniform in `k`; no
property of `k` other than `k >= 2` was used.

## Why the existing barrier models do not evade this

This theorem is compatible with the board's earlier automatic-model
barrier and with the companion `k-regular-asymptotic-barrier` front.

* One can build `k`-regular sequences with `n log_2 n + O(n)` growth,
  nondecreasing, and even with increments `O(log n)`. For example
  `sum_{j<=n} floor(log_k j)` is `k`-regular and has that shape. Such a
  model blocks arguments that use only growth, monotonicity, or the
  leading `n log_2 n` term.
* The theorem does **not** block those models; it uses the exact linear
  coefficient. A `k`-regular model with unspecified `O(n)` error may
  exist. What cannot exist is a `k`-regular model with
  `S(n) = n log_2 n - n / ln 2 + o(n)`.
* Sanity checks with known `k`-regular sequences: for
  `A(n) = sum_{j<=n} floor(log_2 j)` one has
  `A(n) = n log_2 n - 2n + O(log n)`, and for
  `B(n) = sum_{j<n} s_2(j)` (binary digit sum) one has
  `B(n) = (1/2) n log_2 n + O(log n)`. In both cases the linear
  coefficient is algebraic (`-2` and `0`), exactly as Fact 2 requires.

## What this does and does not establish

* **Proved:** the `k`-kernel of `S` is infinite-dimensional for every
  integer base `k >= 2`. This answers the front negatively and rules out
  all finite-dimensional linear digit representations, equivalently all
  `k`-regular representations over `Q`.
* **Not proved:** any separation of `SORT-BOUND-U` from `P`, `NP`, or
  `PSPACE`, or any lower bound on ordinary exact evaluation. The result
  is a barrier to one algorithmic family, not a complexity-class
  separation. `SORT-BOUND-U` remains in `PSPACE` by the existing
  budgeted-DFS argument.
* **Not covered:** nonlinear digit recursions, recurrences of unbounded
  order, algorithms that use non-`k`-regular intermediate sequences, and
  nonuniform advice or circuits. The theorem also says nothing about
  `S` modulo a fixed modulus beyond what is already in the
  `s-residue-automaticity` note.
* **Dependency:** Sergeev's asymptotic is a primary literature theorem,
  not kernel-checked. The LRS and transcendence steps are standard.
